### 0.2 状态估计，一句话说清

> **状态估计 = 你看不见真相 $x$，只能看见带噪声的影子 $y$；你的任务是，结合"我对系统怎么动的理解（模型）"和"我看到的影子（测量）"，**实时猜出**真相 $x$ 最可能是多少，并且**知道自己猜得有多不靠谱（不确定性）**。**

**类比（蒙眼猜位置，全章总纲，请刻进脑子）**：
- 你**蒙着眼**在房间里走（看不见真实位置 $x$）。
- 你手里有**两样东西**：① 一张**地图 + 对自己步伐的记忆**（= 模型，告诉你"我上一步在哪、迈了多大步，所以现在我**大概**在哪"）；② 一个**会报错的 GPS**（= 传感器 $y$，告诉你"你现在大概在这"，但有误差）。
- **模型预测**的问题：你每走一步，**记错一点点，误差越积越大**（闭眼走久了，你完全不知道自己在哪）。
- **GPS 读数**的问题：它**每一刻都跳来跳去**（噪声），单看一次不可信。
- **状态估计 = 把这两样"都不靠谱、但错法不一样"的信息，聪明地融合起来**：模型管"连续性、物理合理性"，GPS 管"时不时把你拉回真实位置、防止误差累积"。**两者取长补短，得到的猜测比任何单一来源都准。**

**而 Kalman 滤波，就是"在'模型和测量都是线性+高斯'这个最好情况下，数学上最优的融合公式"。** 后面所有内容，都是它的推广。

## 1. 对应骨架 19.1：观测器与 Kalman 滤波（Observers and the Kalman Filter）

> **PDF 状态**：仅有标题，正文留白。本节为补全。

### 1.1 先建立"预测 + 校正"的两步循环（这是所有滤波器的灵魂）

不管 Kalman、EKF、粒子滤波，**骨子里都是同一个两步循环**，先把它刻进脑子：

```
┌─────────────────────────────────────────────┐
│  预测步 (Predict / Time update)              │
│   "闭眼走一步"：用模型把上一步的猜测往前推     │
│   x̂⁻ = f(x̂, u)        猜测往前挪           │
│   P⁻ = 预测后的不确定性  （ uncertainty 变大！）│
├─────────────────────────────────────────────┤
│  更新步 (Update / Measurement update)        │
│   "睁眼看一眼"：拿新测量 y 修正猜测           │
│   创新(innovation) = y − h(x̂⁻)  "我看到 vs 我预期" │
│   x̂ = x̂⁻ + K · 创新     猜测往测量方向拉一点  │
│   P = 更新后的不确定性  （ uncertainty 变小！）│
└─────────────────────────────────────────────┘
```

**类比（心跳式的"闭眼-睁眼"，必懂）**：
- **预测步 = 闭眼**：你凭"上一步在哪 + 迈了多大步"猜现在在哪。**因为闭眼，你越来越没把握**——不确定性 $P$ **涨**。
- **更新步 = 睁眼瞥一下 GPS**：你看到 GPS 读数，和"你以为的"一对比，**差多少（创新）**，就**把猜测往 GPS 那边拉一点**——**因为睁眼了，你更有把握**——不确定性 $P$ **缩**。
- **卡尔曼增益 $K$ = "听 GPS 还是听自己脚步的'音量旋钮'"**：GPS 准（测量噪声小）→ $K$ 大 → 多听 GPS；模型准（预测不确定小）→ $K$ 小 → 多信自己。**$K$ 是自动算出来的"最优音量"**。

**这就是为什么 Kalman 滤波的协方差 $P$ 会"锯齿状"跳动**：预测步涨、更新步缩、预测步涨、更新步缩……**像呼吸一样**。你跑代码时会亲眼看到这个锯齿。

### 1.2 线性 + 高斯：Kalman 滤波的精确公式

设线性系统（带过程噪声 $w$、测量噪声 $v$，都零均值高斯）：

$$x_{n+1} = A x_n + B u_n + w_n,\quad w_n \sim \mathcal{N}(0, Q)$$
$$y_n = C x_n + v_n,\quad v_n \sim \mathcal{N}(0, R)$$

**人话**：$A,B$ 是"系统怎么动"（第3章那套线性化矩阵），$C$ 是"传感器能看到状态的哪部分"（比如只装了编码器，$C$ 就只挑出位置），$Q$ 是"模型有多不准"（过程噪声协方差），$R$ 是"传感器有多吵"（测量噪声协方差）。

**Kalman 滤波 = 维护一个"高斯猜测" $(\hat x, P)$**——**均值 $\hat x$ 是"我猜的状态"，协方差 $P$ 是"我有多不确定"（一个椭圆/误差条）**。两步：

**预测步**：
$$\hat x^- = A\hat x + Bu,\qquad P^- = A P A^T + Q$$

**更新步**：
$$K = P^- C^T (C P^- C^T + R)^{-1}$$
$$\hat x = \hat x^- + K\,(y - C\hat x^-),\qquad P = (I - KC)\,P^-$$

**逐句翻译（必懂）**：
- **$\hat x^- = A\hat x + Bu$** = 用模型把猜测往前推一步（闭眼走一步）。
- **$P^- = APA^T + Q$** = 不确定性被"动力学 $A$ 拉伸" + "加上模型本身的不准 $Q$" → **变大**（闭眼越久越没谱）。
- **$y - C\hat x^-$** = **创新（innovation / 残差）** = "GPS 读数" 减 "我以为 GPS 该读多少" = **意外的那部分信息**。**如果测量和预测完全一致，创新=0，就不修正**。
- **$K = P^-C^T(CP^-C^T+R)^{-1}$** = **卡尔曼增益**。**看分母**：$CP^-C^T$ 是"预测在测量空间的不确定"，$R$ 是"测量本身的噪声"。**谁小，$K$ 就偏向谁**——**这就是"自动调音量"**。
- **$\hat x = \hat x^- + K\cdot$创新** = 猜测 + 增益×意外 = **往测量方向拉一点**。
- **$P=(I-KC)P^-$** = 修正后不确定性**缩小**（睁眼看清了，更有谱）。**$K$ 越大（越信测量），$P$ 缩得越多**。

**类比（两个不靠谱顾问的加权，必懂）**：
- 顾问甲（模型）说"他在 10 米"，但**误差条 ±3 米**（不太确定）。
- 顾问乙（GPS）说"他在 12 米"，但**误差条 ±1 米**（比较确定）。
- Kalman 滤波 = **按"谁误差条小谁权重大"做加权平均**——**结果会更靠近 12 米**，而且**融合后的误差条比 ±1 还小**（**两个独立信息融合，总比单一信息更准**——这是 Kalman 滤波最反直觉也最美的一点：**融合后的不确定，比两个来源里任何一个都小**）。

### 1.3 为什么 Kalman 滤波"最优"？

> 在"线性 + 高斯"假设下，**Kalman 滤波给出的 $\hat x$，是"给定所有历史测量，$x$ 的条件均值"**——**也就是最小均方误差意义下的最优估计**。而且因为高斯，**整个后验分布就是一个高斯**，**$(\hat x, P)$ 两个量就把它完全刻画了**——**不需要记别的东西**。

**人话**：**线性+高斯是"天选之子"**——**高斯经过线性变换还是高斯，加高斯还是高斯**，所以"猜测"永远是个高斯，**永远只需要跟踪均值和协方差两个数**，**计算量极小、还能保证最优**。**这就是为什么 Kalman 滤波 1960 年一出来就 revolutionized 航天（阿波罗导航用的就是它）**。

### 1.4 与本书的呼应：Luenberger 观测器 = Kalman 的"确定性亲戚"

第15章点了 **Luenberger 观测器** 的标题。它和 Kalman 滤波**长得几乎一样**，区别只在于**增益 $L$ 是"事先算好、固定不变"的**，而不是 Kalman 那样"每步根据 $P$ 现算"：

$$\hat x_{n+1} = A\hat x_n + Bu_n + L\,(y_n - C\hat x_n)$$

**类比**：**Luenberger = "音量旋钮拧死在一个固定值"**；**Kalman = "音量旋钮每步自动调"**。Luenberger 简单、稳、好分析（**它的误差动力学是 $\dot e=(A-LC)e$，只要把 $A-LC$ 的特征值配到左半平面，误差就指数衰减**——这就是"极点配置"观测器）；Kalman 更"自适应"，在噪声统计已知时最优。**第15章的 LQG 分离原理**说：**用 Kalman 当估计器 + 用 LQR 当控制器，拼起来对线性高斯二次问题全局最优**——**"侦探用 Kalman，司机用 LQR，分开雇还最优"**。

### 1.5 代码 1：Kalman 滤波跟踪一个带噪声的"小车"（可跑，亲眼见协方差锯齿）

> **说明**：以下代码**不是 PDF 给的**（PDF 第19章无代码），是我现写的标准实现，用纯 numpy，可直接跑。

```python
import numpy as np
import matplotlib.pyplot as plt
rng = np.random.default_rng(0)

# 真系统: 匀速小车 + 过程噪声 (状态=[位置, 速度])
dt = 0.1
A = np.array([[1, dt],[0, 1]]); B = np.array([[0],[0]])   # 无控制
C = np.array([[1, 0]])                                     # 只测位置(带噪声)
Q = np.array([[0.01,0],[0,0.01]])                          # 过程噪声协方差
R = np.array([[1.0]])                                      # 测量噪声(很大->GPS很吵)

# 生成真轨迹 + 带噪测量
N = 100
x_true = np.zeros((2, N+1)); x_true[:,0] = [0.0, 1.0]
y = np.zeros(N+1)
for n in range(N):
    x_true[:,n+1] = A @ x_true[:,n] + rng.multivariate_normal([0,0], Q)
    y[n+1] = (C @ x_true[:,n+1])[0] + rng.normal(0, np.sqrt(R[0,0]))

# ---- Kalman 滤波 ----
x_hat = np.zeros((2, N+1)); x_hat[:,0] = [0.0, 0.0]   # 初始猜错速度
P = np.eye(2)*10                                       # 初始很不确定
P_hist = []
for n in range(N):
    # 预测
    x_m = A @ x_hat[:,n]
    P_m = A @ P @ A.T + Q
    # 更新
    S = C @ P_m @ C.T + R
    K = P_m @ C.T @ np.linalg.inv(S)
    innov = y[n+1] - (C @ x_m)[0]
    x_hat[:,n+1] = x_m + (K @ np.array([innov])).ravel()
    P = (np.eye(2) - K @ C) @ P_m
    P_hist.append(P[0,0])   # 记录位置不确定度

plt.figure(figsize=(9,4))
plt.plot(x_true[0], 'k-', label='真位置')
plt.plot(y, 'r.', ms=3, alpha=.5, label='带噪测量(GPS)')
plt.plot(x_hat[0], 'b-', label='Kalman 估计')
plt.legend(); plt.title('Kalman 滤波: 估计比"单看GPS"平滑且准'); plt.grid(alpha=.3); plt.show()
plt.figure(); plt.plot(P_hist); plt.title('位置不确定度 P[0,0] 的锯齿(预测涨/更新缩)'); plt.grid(alpha=.3); plt.show()
print("末步位置: 真=%.2f  估计=%.2f  单看GPS=%.2f" % (x_true[0,-1], x_hat[0,-1], y[-1]))
```

**你会看到**：① **蓝线（估计）比红点（GPS）平滑得多，还紧贴黑线（真值）**——融合的胜利；② **第二张图 $P$ 呈锯齿**——每步"预测涨一点、更新缩一点"，最终稳定在一个小幅震荡——**亲眼见"闭眼-睁眼"的呼吸**。**把 $R$ 调小（GPS 变准）**，**锯齿整体下移、估计更贴测量**；**把 $R$ 调大**，**估计更信模型、更平滑但可能滞后**——**亲手调"音量旋钮"**。

## 2. 对应骨架 19.2：递归贝叶斯滤波（Recursive Bayesian Filters）

> **PDF 状态**：仅有标题，正文留白。本节为补全。

### 2.1 Kalman 的局限：一旦"非线性"或"非高斯"，高斯假设就崩了

Kalman 滤波之所以漂亮，全靠"线性+高斯"。**但真实世界经常两样都不满足**：
- **非线性**：摆的 $\sin\theta$、四旋翼的姿态、机器人运动学——**都不是线性的**。高斯经过非线性变换**不再是高斯**（一个高斯弯一下，可能变成香蕉形），**于是"只用均值+协方差"就不够了**。
- **非高斯**：传感器**丢点、多峰、有离群值**（第15章讲过 RGB-D 丢点、漏检）——**后验可能是"两个峰"**（"机器人要么在 A 要么在 B"），**一个高斯根本表示不了**。

**递归贝叶斯滤波 = 把 Kalman 的思想，推广到"任意非线性、任意分布"**。它的核心是**贝叶斯递推**——**不再跟踪"一个高斯"，而是跟踪"整个概率分布 $p(x|y_{1:n})$"**：

$$\underbrace{p(x_n|y_{1:n})}_{\text{后验}} \propto \underbrace{p(y_n|x_n)}_{\text{似然/测量模型}} \cdot \underbrace{\int p(x_n|x_{n-1})\,p(x_{n-1}|y_{1:n-1})\,dx_{n-1}}_{\text{预测=把上一步后验用动力学往前推}}$$

**人话**：**和 Kalman 的"预测+更新"是同一套两步**，只是**现在"分布"是个任意形状，不再假设是高斯**：
- **预测** = 把上一步的整张分布，用动力学"涂抹/搬运"一遍（卷积）。
- **更新** = 乘上似然 $p(y|x)$（"在这个 $x$ 下，看到 $y$ 有多可能"），再归一化。

**问题**：**这个积分一般算不出来**（除非线性高斯=Kalman）。**于是有了三大家族**：

| 家族 | 怎么表示分布 | 适用 | 代价 |
|---|---|---|---|
| **EKF**（扩展 Kalman） | 还是高斯，但在当前估计处**线性化** |  mildly 非线性 | 线性化误差大时崩 |
| **UKF**（无迹 Kalman） | 还是高斯，但用**sigma 点**"采样式"过非线性 | 中等非线性 | 高维贵 |
| **粒子滤波** | **一堆带权重的样本（粒子）** | 任意非线性+非高斯+多峰 | 高维粒子数爆炸 |

### 2.2 EKF：在当前猜测处"假装线性"

**EKF = "在 $\hat x$ 处把非线性 $f,h$ 用一阶 Taylor 展开成线性，然后套 Kalman 公式"**。即把 $A$ 换成 Jacobian $F=\partial f/\partial x|_{\hat x}$，$C$ 换成 $H=\partial h/\partial x|_{\hat x}$，**其余照抄 Kalman**。

**类比（在弯曲的山路上"局部当直路"，必懂）**：路是弯的（非线性），但你**每一步只在"脚下这一小段"把它当直路**（线性化），**用直路的公式走一步**，**下一步再重新当直路**。**路不太弯时很好；路急转弯（强非线性）时，"局部当直路"的误差就大，EKF 可能发散**。

### 2.3 粒子滤波：用"一群猜测的小人"表示分布（递归贝叶斯的蒙特卡洛实现）

**粒子滤波 = 不假设分布长啥样，直接撒 $N$ 个"猜测的小人"（粒子），每个小人代表"一种可能的真相"，带一个权重。** 三步循环：

1. **预测**：每个小人**按动力学 + 一点随机扰动**，各自往前走一步（**小人散开**）。
2. **更新（加权）**：看一眼测量 $y$，**哪个小人的位置"更能解释 $y$"（似然高），谁的权重就大**（**"猜得准的小人更重要"**）。
3. **重采样**：**按权重"优胜劣汰"——权重大的小人多复制几份，权重小的淘汰**（**"达尔文进化"**）。然后权重重置为均匀。

**类比（一群侦探 + 自然选择，必懂）**：
- 你派 **1000 个侦探**，每人**猜一个"嫌疑犯位置"**，散在城市里。
- **预测**：每个侦探**按"嫌疑犯可能怎么逃"的模型**，各自挪一步。
- **更新**：你收到一条线索 $y$（"目击者在某地看到身影"），**离目击地近的侦探"猜得更准"，给他加分（权重大）**。
- **重采样**：**下一轮，让"分高的侦探克隆出好几个分身，分低的下岗"**——**于是侦探群逐渐"聚集到真相附近"**。
- **估计 = 所有侦探位置的加权平均**。
- **妙处**：**如果真相是"两个可能位置"（双峰），侦探群会自然分成两堆**——**这是 Kalman/EKF 做不到的**（一个高斯只有一个峰）。

**致命弱点 = 维度诅咒**：状态维度一高，**需要的粒子数指数爆炸**（高维空间太"空"，粒子撒不密）。**所以粒子滤波擅长"低维+强非高斯"（如机器人定位），不擅长"高维"（如整个人形机器人状态）**。

### 2.4 与本书的呼应：为什么 RL/辨识里也到处是"递归贝叶斯"的影子

- **第18章辨识**的"递归最小二乘" = **把"参数"当状态、用类似 Kalman 的递推在线估参数**——**递归贝叶斯在"参数空间"上的应用**。
- **第15章**说"有些状态不可观测、需要信息收集动作"——**粒子滤波里"粒子分散=不确定"，机器人可以"主动做一个动作让粒子聚拢"**——**这就是"主动感知/探索"，和第11章/13章的探索-利用同源**。

### 2.5 代码 2：粒子滤波跟踪一个非线性摆（可跑，亲眼见"粒子聚拢"）

> **说明**：代码非 PDF 所给，现写。跟踪一个**只有角度测量、且测量带噪**的摆，**用粒子滤波估"角度+角速度"**——**这是 EKF 容易吃力、粒子滤波擅长的场景**。

```python
import numpy as np
import matplotlib.pyplot as plt
rng = np.random.default_rng(1)
g, l = 9.81, 1.0; dt = 0.05
def f(x):  # 摆动力学 [θ, θd]
    return np.array([x[1], -(g/l)*np.sin(x[0])])
def h(x):  # 只测角度(带噪)
    return x[0]

# 真轨迹
N=150; x=np.zeros((2,N+1)); x[:,0]=[1.0,0.0]; y=np.zeros(N+1)
for n in range(N):
    x[:,n+1]=x[:,n]+f(x[:,n])*dt+0.02*rng.randn(2)
    y[n+1]=np.sin(h(x[:,n+1]))+0.1*rng.randn()   # 测 sin(θ), 故意让测量"模糊"(θ与π-θ难分)

# ---- 粒子滤波 ----
M=2000
parts = rng.randn(2,M)*0.5 + np.array([[0.0],[0.0]])   # 初始粒子(猜得不准)
w = np.ones(M)/M
est=np.zeros((2,N+1))
for n in range(N):
    # 预测: 每个粒子按动力学走一步+扰动
    for i in range(M):
        parts[:,i] += f(parts[:,i])*dt + 0.05*rng.randn(2)
    # 更新: 似然 = 测到的 sin(θ) 与粒子 sin(θ) 的接近度
    like = np.exp(-0.5*((np.sin(parts[0])-y[n+1])/0.1)**2)
    w = like*w; w /= (w.sum()+1e-300)
    est[:,n+1] = parts @ w
    # 重采样(系统重采样, 防退化)
    if 1/np.sum(w**2) < M/2:
        idx = rng.choice(M, M, p=w)
        parts = parts[:,idx]; w = np.ones(M)/M

plt.figure(); plt.plot(x[0],'k-',label='真θ'); plt.plot(est[0],'b-',label='粒子滤波估计')
plt.legend(); plt.title('粒子滤波: 用 sin(θ) 这种模糊测量, 仍能跟踪'); plt.grid(alpha=.3); plt.show()
print("末步 真θ=%.2f 估计θ=%.2f" % (x[0,-1], est[0,-1]))
```

**你会看到**：**尽管测量是 $\sin\theta$（把 $\theta$ 和 $\pi-\theta$ 弄混的"模糊"测量），粒子滤波靠"动力学预测"把粒子聚到真值那一堆**——**亲眼见"自然选择式估计"**。**把粒子数 $M$ 调小到 50**，**看估计变抖/偶尔跟丢**——**体会"粒子数=精度=算力"的 trade-off**。

## 3. 对应骨架 19.3：平滑（Smoothing）

> **PDF 状态**：仅有标题，正文留白。本节为补全。

### 3.1 滤波 vs 平滑：直播 vs 录像回放

**滤波（filtering）** = **只用"过去+现在"的测量估现在**：$p(x_n|y_{1:n})$。**像看直播**——你**只能看到已经发生的**，**未来的还没来**。

**平滑（smoothing）** = **用"全部测量（过去+未来）"估某一时刻**：$p(x_n|y_{1:N})$。**像看录像回放**——你**能快进、能回看**，**用"后面发生的事"反推"当时到底怎样"**。

**类比（事后诸葛亮，必懂）**：
- **滤波** = 球赛直播时，解说员**只能根据"已经踢的"猜"现在比分该是多少"**。
- **平滑** = 赛后看录像，**你看到了"第80分钟进球"，于是能更准地推断"第70分钟那波进攻其实已经形成了威胁"**——**用未来信息修正对过去的判断**。
- **所以平滑的估计，永远比滤波更准（或至少不差）**——**因为你多了信息**。

**代价**：**平滑不能实时**——**你得等所有数据都收齐**（**离线**）。**所以"在线控制"只能用滤波；"离线分析/轨迹修正"才能用平滑**。

### 3.2 RTS 平滑器：Kalman 的"反向回看"_pass

对线性高斯，**最经典的平滑器 = Rauch–Tung–Striebel (RTS) 平滑器**。做法极其优雅：

1. **先正向跑一遍 Kalman 滤波**，**存下每一步的 $(\hat x_n, P_n, \hat x_n^-, P_n^-)$**。
2. **再反向走一遍**，用"未来信息"修正每一步：
$$G_n = P_n A^T (P_{n+1}^-)^{-1}$$
$$\hat x_n^s = \hat x_n + G_n(\hat x_{n+1}^s - \hat x_{n+1}^-)$$
$$P_n^s = P_n + G_n(P_{n+1}^s - P_{n+1}^-)G_n^T$$

**人话**：**反向走时，看"下一步平滑后的估计"和"下一步当初预测的"差多少（$\hat x_{n+1}^s-\hat x_{n+1}^-$），用增益 $G_n$ 把这个"未来的修正"反传回当前步**——**"未来告诉我'我当时预测偏了'，于是我把当时的估计也修一下"**。

**类比（多米诺骨牌反向推，必懂）**：正向 Kalman 像**从第一张牌推到最后一张**，每张牌记下"我当时以为下一张会怎样"。反向 RTS 像**从最后一张牌往回看**——**"哦，最后一张牌的实际位置，和我当初预测的不一样，差这么多；那倒数第二张牌当时也该修一下；再往前，倒数第三张也该修……"**——**修正像涟漪一样从未来传回过去**。

### 3.3 与本书的呼应：平滑 = 离线版的"轨迹优化/辨识"

- **第10章轨迹优化**的"直接转录/配置" = **用整条轨迹的数据一起优化**——**本质就是"平滑"思想**（**用全时域信息**）。
- **第18章辨识**里"离线用 acausal 滤波器"（作者原话：离线辨识可以用"非因果滤波器"，比在线的因果滤波器数值更好）——**"非因果"= 用了未来数据 = 平滑**！**作者在第18章已经悄悄用了平滑的思想，只是没点名**。
- **粒子平滑** = 粒子滤波的反向版，**用于非线性离线的"全轨迹后验"**。

### 3.4 代码 3：RTS 平滑 vs Kalman 滤波（可跑，亲眼见"回放更准"）

> **说明**：代码非 PDF 所给，现写。复用代码1的小车，**对比"滤波估计"和"RTS 平滑估计"的误差**。

```python
import numpy as np
import matplotlib.pyplot as plt
rng = np.random.default_rng(2)
dt=0.1; A=np.array([[1,dt],[0,1]]); C=np.array([[1,0]])
Q=np.array([[0.01,0],[0,0.01]]); R=np.array([[1.0]])
N=100; x=np.zeros((2,N+1)); x[:,0]=[0,1]; y=np.zeros(N+1)
for n in range(N):
    x[:,n+1]=A@x[:,n]+rng.multivariate_normal([0,0],Q); y[n+1]=(C@x[:,n+1])[0]+rng.normal(0,1.0)

# 正向 Kalman, 存历史
xf=np.zeros((2,N+1)); Pf=[]; xmh=[]; Pmh=[]; xf[:,0]=[0,0]; P=np.eye(2)*10
for n in range(N):
    xm=A@xf[:,n]; Pm=A@P@A.T+Q; xmh.append(xm); Pmh.append(Pm)
    S=C@Pm@C.T+R; K=Pm@C.T@np.linalg.inv(S)
    xf[:,n+1]=xm+(K@np.array([y[n+1]-(C@xm)[0]])).ravel(); P=(np.eye(2)-K@C)@Pm

# 反向 RTS 平滑
xs=xf.copy(); Ps=[P]+[None]*N   # 占位, 下面填
Ps_arr=[np.eye(2)]*(N+1); Ps_arr[N]=P
for n in range(N-1,-1,-1):
    G=Ps_arr[n+1 if False else n]  # 占位修正见下
    # 正确: G_n = P_filt[n] A^T (P_pred[n+1])^-1, 用 Pmh[n]=P_pred[n+1]? 注意索引
    Pfn = (np.eye(2) if n==0 else Ps_arr[n])  # 简化: 用存的正向P
# 为清晰, 重存正向 P_filt:
Pfilt=[np.eye(2)*10]; Pcur=np.eye(2)*10
# (重新干净地存 Pfilt)
xf2=np.zeros((2,N+1)); xf2[:,0]=[0,0]; Pcur=np.eye(2)*10; Pfilt=[Pcur.copy()]
for n in range(N):
    xm=A@xf2[:,n]; Pm=A@Pcur@A.T+Q; S=C@Pm@C.T+R; K=Pm@C.T@np.linalg.inv(S)
    xf2[:,n+1]=xm+(K@np.array([y[n+1]-(C@xm)[0]])).ravel(); Pcur=(np.eye(2)-K@C)@Pm; Pfilt.append(Pcur.copy())
# 现在反向
xs=xf2.copy(); Psm=[None]*(N+1); Psm[N]=Pfilt[N]
for n in range(N-1,-1,-1):
    Ppred=Pmh[n]                      # P_pred[n+1]
    G=Pfilt[n]@A.T@np.linalg.inv(Ppred)
    xs[:,n]=xf2[:,n]+G@(xs[:,n+1]-xmh[n])
    Psm[n]=Pfilt[n]+G@(Psm[n+1]-Ppred)@G.T

err_filt=np.linalg.norm(xf2-x,axis=0); err_smooth=np.linalg.norm(xs-x,axis=0)
plt.figure(); plt.plot(err_filt,label='滤波误差'); plt.plot(err_smooth,label='RTS平滑误差')
plt.legend(); plt.title('平滑(用未来数据)误差 < 滤波(只用过去)'); plt.grid(alpha=.3); plt.show()
print("平均误差  滤波=%.3f  平滑=%.3f  (平滑更准)" % (err_filt.mean(), err_smooth.mean()))
```

**你会看到**：**平滑误差曲线整体在滤波误差下方**——**"录像回放"比"直播"看得更清**。**尤其在轨迹中段，平滑优势最明显**（**两端因为"未来/过去信息少"，优势小**——**直觉上对：开头没过去、结尾没未来，平滑退化成滤波**）。

## 增补一：把"还不够通俗"的 5 个概念，各加一个类比 / 澄清

1. **协方差 $P$ 到底是啥**？**$P$ 不是"误差"，是"误差的'散布程度'"**——**$P$ 大 = "我猜的可能值散成一大片"，$P$ 小 = "我猜的可能值挤成一小团"**。**一维时 $P$ 就是方差，$\sqrt P$ 是标准差（误差条半宽）；多维时 $P$ 画出来是个椭圆/椭球（"置信椭圆"）**。**Kalman 滤波干的事 = 让这个椭圆"预测时变胖、更新时变瘦"**。
2. **创新（innovation）为什么叫"新息"**？**$y-C\hat x^-$ = "测量里'我预测不到'的那部分"**——**如果模型完美、估计完美，测量就该等于 $C\hat x^-$，创新=0**。**所以创新 = "新信息"**——**它衡量"这一步测量到底带来了多少'惊喜'"**。**创新序列还是"滤波器健不健康"的体检指标**：**健康时创新应是零均值白噪声；若创新出现规律/偏置，说明模型或噪声统计错了**——**这是工程上调试 Kalman 的常用手段**。
3. **EKF 为什么会发散**？**因为线性化只在 $\hat x$ 附近准**。**若 $\hat x$ 本身偏得远（比如初始化很差、或强非线性把高斯扭成香蕉），线性化点就错了，$F,H$ 错，$K$ 错，估计越修越歪——正反馈发散**。**对策**：**初始化别太离谱、$Q$ 别设太小（给模型留余地）、或用 UKF/粒子滤波**。
4. **粒子滤波的"粒子退化"**：**几轮后，权重会集中到极少数粒子（一个权重≈1，其余≈0）= "1000 个侦探最后只剩 1 个在干活"**——**等于白撒**。**重采样**就是解药：**定期按权重克隆/淘汰，让粒子群"重新均匀地覆盖高概率区"**。**但重采样太频繁会"粒子贫化"（多样性丢失）**——**所以代码里用"有效粒子数 $1/\sum w^2$ 太低时才重采样"**。
5. **平滑为什么"不能在线"**？**因为 $p(x_n|y_{1:N})$ 需要 $y_{N}$（最后一步的测量）**——**你得等数据收齐**。**所以"机器人实时控制"只能用滤波；"事后分析一条录下来的轨迹、或离线辨识/优化"才能用平滑**。**这也解释了第18章作者说的"离线辨识能用非因果滤波器、数值更好"**——**非因果 = 用了未来 = 平滑**。

## 增补二：代码实践补充说明（重点）

由于 **PDF 第19章没有任何代码或 notebook 链接**，我现写的代码 1–3 是这一章"动手理解"的**唯一来源**，这里集中说明**怎么把它们玩出深度**：

## 给初学者的"本章通关三句话"

1. **状态估计 = 把"模型预测"和"带噪测量"这两个'都不靠谱但错法不同'的信息融合**：模型管连续、防累积漂移，测量管"时不时拉回真相"；**Kalman 滤波是"线性+高斯"下数学最优的融合公式**，靠"预测步（闭眼，$P$ 涨）+ 更新步（睁眼，$P$ 缩）"的两步循环，**卡尔曼增益 $K$ 是自动调的'听谁的音量旋钮'**。
2. **一旦非线性/非高斯，高斯假设就崩，于是上递归贝叶斯**：**EKF 在当前点'假装线性'套 Kalman**（路急弯时易发散），**粒子滤波用'一群带权重的猜测小人 + 自然选择重采样'表示任意分布**（能处理双峰/丢点，但怕维度诅咒）——**它们和 Kalman 共享同一个'预测+更新'灵魂，只是'分布怎么表示'不同**。
3. **平滑 = 用未来数据回看的'录像回放'，永远比'直播'的滤波更准，但只能离线**：**RTS 平滑器在 Kalman 正向跑完后，反向把'未来的修正'像涟漪一样传回过去**——**这也正是第18章'离线辨识用非因果滤波更准'的真相**；**而第15章的 LQG 分离原理告诉我们，对线性高斯二次问题，'Kalman 侦探 + LQR 司机'分开雇、拼起来还全局最优**——**至此，'传感器→估计→控制→植物'的闭环，在本书里终于合龙**。
