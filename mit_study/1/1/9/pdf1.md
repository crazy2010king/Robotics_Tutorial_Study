# 用大白话讲透《Underactuated Robotics》第9章：李雅普诺夫分析（Lyapunov Analysis）

> 这一章要解决一个核心问题：**"我怎么在不求解微分方程的情况下，证明一个机器人系统最终会安定下来？"** 上一章动态规划告诉我们"最优控制 = 最小化代价函数"，但求解最优控制对非线性系统来说太难了。这一章换个思路：**找一个"能量桶"函数，证明这个桶里的水只会越来越少，最终流干**——这就是李雅普诺夫（Lyapunov）分析的核心思想。
>
> 下面我用完全通俗的方式，把这一章从头到尾拆给你看，并配上代码实践说明。

## 🏞️ 一、核心直觉：下山类比与"能量桶"

想象一个**小球放在山谷里**。如果你推它一下，它会来回滚动，但最终会因为摩擦而停在谷底。为什么？因为**高度（重力势能）一直在减少**，直到达到最小值（谷底）。

李雅普诺夫函数的想法一模一样：
- 给系统的每个状态 x 分配一个"高度值" V(x)
- 证明沿着系统演化的轨迹，这个高度值**只会下降或保持不变**
- 那么系统最终一定会"滑到" V(x) 最小的地方（通常是平衡点）

📌 **李雅普诺夫直接法（Theorem 9.1）**：如果能找到一个函数 V(x) 满足：
1. **正定**：V(0)=0，且对所有 x≠0 有 V(x)>0（像一个碗的形状）
2. **导数非正**：V̇(x) = ∂V/∂x · f(x) ≤ 0（沿着系统轨迹，V 只会下降或不变）

那么原点 x=0 是**稳定**的（在 Lyapunov 意义下，i.s.L.）。

如果 V̇(x) < 0（严格小于零），那么原点是**渐近稳定**的。
如果 V̇(x) ≤ -αV(x)（α>0），那么原点是**指数稳定**的。

### 单摆的经典例子

无阻尼单摆的总能量：
$$E(\theta,\dot{\theta}) = \frac{1}{2}ml^2\dot{\theta}^2 - mgl\cos\theta$$

求导得到：
$$\dot{E} = -b\dot{\theta}^2 \leq 0$$

**这就是李雅普诺夫分析的原型**：能量函数 E 就像一个"能量桶"，阻尼让桶里的水（能量）只减不增，最终流到最小值 E = -mgl（即 θ=2πk，单摆垂直向下）。

> 💡 **关键洞察**：我们不用求解单摆复杂的微分方程，只要看到"能量一直在减少"，就能断定它最终会停下。这就是李雅普诺夫分析的威力。

## 🌍 二、全局稳定性与 LaSalle 不变集原理

### 2.1 全局稳定性（Theorem 9.2）

如果 V(x)≻0、V̇(x)≺0，并且 **V(x)→∞ 当 ||x||→∞**（称为"径向无界"），那么原点是**全局渐近稳定（G.A.S.）**的。

**"径向无界"是什么意思？** 直观地说：离原点越远，V 的值越大，没有"天花板"限制。这保证了轨迹不可能"逃逸到无穷远"。

### 2.2 LaSalle 不变集原理（Theorem 9.3）

回到单摆例子：能量导数 Ė = -bθ̇² 在 **θ̇=0 的所有状态**上都为零，不只平衡点。那怎么证明最终会收敛到平衡点呢？

LaSalle 定理说：如果 V̇(x)≤0，那么系统会收敛到**"最大不变集"**——即 V̇(x)=0 的那些状态中，一旦进入就永远离不开的集合。

对单摆而言：
- V̇=0 当 θ̇=0
- 但当 θ̇=0 且 θ≠2πk 时，下一刻 θ̇ 就不为零了（重力会让它动起来）
- 只有 θ̇=0 **且** θ=2πk（平衡点）才是真正"不变"的
- 所以最大不变集 = 所有平衡点的并集

**LaSalle 定理让我们用"半负定"的 V̇ 也能证明渐近稳定性**——这是比李雅普诺夫直接法更弱的条件。

### 2.3 小车-倒立摆的 swing-up 例子

教材用部分反馈线性化设计了 swing-up 控制器，得到：
$$\dot{\tilde{E}} = -k\dot{\theta}^2\cos^2\theta\cdot\tilde{E}$$

定义 Lyapunov 函数 V(x) = ½Ẽ²(x)，则 V̇ ≤ 0。由 LaSalle 定理，系统会收敛到最大不变集 **Ẽ(x)=0**（即整个同宿轨道）。要真正稳定在上直立点，还需要切换到 LQR 控制器。

> 这展示了**李雅普诺夫分析的实际工程价值**：它能证明"swing-up 控制器能把摆杆带到直立位置附近"，但不能证明"稳定停在直立"——后者需要 LQR 接力。

## 🔗 三、李雅普诺夫函数与 HJB 方程的关系

你可能会问：上一章的动态规划里，代价函数 J*(x) 也是个标量函数，描述了系统的长期行为。它和李雅普诺夫函数 V(x) 有什么关系？

**HJB 方程**：0 = min_u [ℓ(x,u) + ∂J*/∂x · f(x,u)]

如果找到了最优控制 u*(x)，则：
$$\dot{J}^*(x) = -\ell(x, u^*) \quad \text{vs.} \quad \dot{V}(x) \preceq 0$$

**关键区别**：
- **HJB 要求严格相等**：J* 的梯度必须精确匹配每个状态的代价率——这是个极难的偏微分方程
- **李雅普诺夫只要求不等式**：V 只要在任意状态下"下坡"就行——宽松得多

**结论**：
1. 如果我们找到了最优代价函数 J*，那么它也可以作为李雅普诺夫函数（只要 ℓ(x,u*)≽0）
2. 但李雅普诺夫分析**远远更容易**——任何下坡函数都行，不必是最优的
3. 这就是为什么李雅普诺夫分析在非线性控制中如此强大：**它把 HJB 的等式放宽为不等式**

## 🎯 四、吸引域估计：李雅普诺夫函数的集不变性

李雅普诺夫函数的一个重要性质：**任何子水平集（sublevel set）{x | V(x) ≤ ρ} 都是不变集**。

**定理 9.4（吸引域定理）**：如果能找到 V(x)≻0 和有界子水平集 G = {x | V(x) ≤ ρ}，使得在 G 上 V̇(x)≼0，那么 G 是不变集。由 LaSalle 定理，x 会收敛到 G 中 V̇=0 的最大不变集。

如果 V̇(x)≺0 在 G 内，那么原点是局部渐近稳定的，且 G 包含在吸引域内。

### 4.1 一维例子：ẋ = -x + x³

这个系统在原点有稳定平衡点，在 x=±1 有不稳定的平衡点。

取 V(x) = ½x²，则 V̇ = -x² + x⁴。
- 当 |x|<1 时，V̇<0
- 当 |x|>1 时，V̇>0

因此子水平集 V<½（即 |x|<1）是不变集，且 **x∈(-1,1) 在吸引域内**。这个估计是紧的（tight）！

### 4.2 鲁棒性分析：公共李雅普诺夫函数

如果系统参数有不确定性，比如 ẋ = -x + αx³，其中 ¾<α<3/2：

用同一个 V(x)=½x²，得到 V̇ = -x² + αx⁴。
要使 V̇<0 对所有 α 成立，需要 |x| < 1/√(α_max) = √(2/3) ≈ 0.816。

因此 **|x|<0.816 是鲁棒吸引域**——比 α=1 时的吸引域 (-1,1) 小，但保证了对所有 α 值都稳定。

> 💡 **"公共李雅普诺夫函数"**：一个函数能同时为所有参数值证明稳定性——这是鲁棒控制的核心思想。

### 4.3 障碍函数（Barrier Functions，定理 9.5）

李雅普诺夫函数证明"系统会收敛到某点"；障碍函数则证明"系统**不会进入**某个禁区"。

如果找到 B(x) 使得 Ḃ(x) ≤ 0，那么系统**永远不会访问** B(x) > B(x(0)) 的状态。

**应用**：自动驾驶汽车不会撞车、行走机器人不会摔倒。只要确保失败区域满足 B(x)>0，那么从 B(x(0))<0 出发的轨迹就永远不会进入失败集。

## 💻 五、用凸优化做李雅普诺夫分析

### 5.1 线性系统：矩阵不等式

对线性系统 ẋ = Ax，李雅普诺夫函数取二次型 V(x) = xᵀPx，P≻0。

条件 PA + AᵀP ≺ 0 等价于**矩阵李雅普诺夫方程** PA + AᵀP = -Q（Q≻0）有正定解。

**关键突破**：这个条件可以写成**半定规划（SDP）**：
```
find P
subject to P ≽ 0, PA + AᵀP ≼ 0
```

SDP 是凸优化问题，有高效算法保证找到全局最优解！

**公共李雅普诺夫函数（线性系统鲁棒性）**：
如果 A 是不确定矩阵，可以表示为顶点矩阵的凸组合 A = ΣᵢβᵢAᵢ，那么：
```
find P
subject to P ≽ 0, ∀i: PAᵢ + AᵢᵀP ≼ 0
```
只要所有顶点都满足，整个不确定集合都满足（因为 βᵢ>0）。

### 5.2 多项式系统：平方和（SOS）优化

对于非线性系统，我们用**平方和多项式**来推广 SDP 思想。

**SOS 优化**：约束形式为"p(x) 是平方和"，即 p(x) = Σᵢ fᵢ²(x) ≥ 0。

这可以转化为 SDP：p(x) = m(x)ᵀPm(x)，P≽0，其中 m(x) 是单项式基。

#### 验证李雅普诺夫候选函数（Example 9.7）

系统：
```
ẋ₀ = -x₀ - 2x₁²
ẋ₁ = -x₁ - x₀x₁ - 2x₁³
```
给定 V(x) = x₀² + 2x₁²，验证 V̇ 是否负定：

```python
prog = MathematicalProgram()
x = prog.NewIndeterminates(2, "x")
f = [-x[0] - 2*x[1]**2, -x[1] - x[0]*x[1] - 2*x[1]**3]
V = x[0]**2 + 2*x[1]**2
Vdot = V.Jacobian(x).dot(f)
prog.AddSosConstraint(-Vdot)
result = Solve(prog)
assert result.is_success()
```

#### 搜索李雅普诺夫函数（Example 9.8）

```python
prog = MathematicalProgram()
x = prog.NewIndeterminates(2, "x")
# 参数化 V 为二次多项式
V = prog.NewSosPolynomial(Variables(x), 2)[0].ToExpression()
prog.AddLinearConstraint(V.Substitute({x[0]:0, x[1]:0}) == 0)  # V(0)=0
prog.AddLinearConstraint(V.Substitute({x[0]:1, x[1]:0}) == 1)  # 归一化
Vdot = V.Jacobian(x).dot(f)
prog.AddSosConstraint(-Vdot)
result = Solve(prog)
```

**重要认识**：SOS 是充分（不是必要）条件。有些稳定的多项式系统可能没有多项式李雅普诺夫函数（Ahmadi 等人给出了反例）。但在实践中，SOS 方法**出奇地有效**。

### 5.3 吸引域估计：S-procedure

要估计**区域**吸引域，需要用 S-procedure 把"在区域 G 内 V̇<0"转化为 SOS 约束。

**基本形式**（Example 9.10）：
```
find λ(x)
subject to -V̇(x) + λ(x)(V(x)-ρ) is SOS
           λ(x) is SOS
```

通过一维线搜索找到最大的 ρ。

**等式约束形式**（更强大）：
```
max ρ
subject to (xᵀx)^d (V(x)-ρ) + λᵀ(x)V̇(x) is SOS
```
这里 λ(x) 不需要是 SOS——这给出了对 ρ 和 λ 的联合凸优化。

#### 三次多项式系统的完整代码实践

Drake 中的 C++ 实现核心逻辑：

```cpp
// 系统: ẋ = -x + x³
// V(x) = x²
const Expression V = x.dot(x);
const Expression Vdot = (Jacobian(Vector1(V), xvar) * derivatives->CopyToVector())[0];

// 最大化 ρ: (V-ρ)x² - λV̇ is SOS
const Variable rho = prog.NewContinuousVariables("rho").coeff(0);
const Expression lambda = prog.NewSosPolynomial(Variables(xvar), 4).first.ToExpression();
prog.AddSosConstraint((V - rho) * x.dot(x) - lambda * Vdot);
prog.AddLinearCost(-rho);

const auto result = Solve(prog);
// 验证 ρ ≈ 1.0
```

### 5.4 外近似：障碍函数方法

内近似（上面讲的）保证"认证区域 ⊆ 真实吸引域"。外近似则从另一侧逼近：

搜索障碍函数 B(x) 使得 -Ḃ(x) is SOS 且 B(0)=1。那么 **{x | B(x) ≥ 0} 是吸引域的外近似**。

最小化 ∫W(x)dx，其中 W(x)≥0 且 W(x)≥B(x)+1。

## 🦾 六、刚体动力学也是（有理）多项式

你可能会问：单摆动力学里有 sinθ，这不是多项式啊？教材给出了漂亮的答案：

**关键洞察**：刚体运动学本质上是多项式的（因为欧几里得距离约束 |p₁-p₂|₂²=常数 是多项式）。我们做变量替换：
- s = sinθ, c = cosθ
- 添加约束 s² + c² = 1

这样，单摆动力学变成：
```
ṡ = c·θ̇
ċ = -s·θ̇
θ̈ = -(1/ml²)(bθ̇ + mgl·s)
```

**所有项都是多项式**！势能、动能也都是多项式。

### 6.1 单摆的全局稳定性 SOS 验证（Example 9.19）

```python
# 坐标: x = [s, c, θ̇]ᵀ
# 李雅普诺夫候选: 二次多项式
V = α₀ + α₁s + α₂c + ... + α₉s² + α₁₀sc + α₁₁sθ̇

# S-procedure 处理约束 s²+c²=1
find α, λ
subject to V is SOS
           -V̇ - λ(x)(s²+c²-1) is SOS
```

**计算结果**：优化得到的 V 看起来很像机械能，但多了一些小项，能直接证明指数稳定性而无需调用 LaSalle 定理。

### 6.2 隐式形式验证

对于多体系统，显式动力学 ẋ = f(x) 可能是有理函数（因为需要求 M⁻¹）。但隐式形式 g(x,ẋ)=0 是多项式的。

我们可以用 S-procedure 直接在隐式形式上验证李雅普诺夫条件，避免显式求逆。

## ⏱️ 七、有限时间可达性

李雅普诺夫分析不仅能分析 t→∞ 的稳定性，还能分析**有限时间**行为。

### 7.1 前向可达集（Forward Reachable Set, FRS）

证明：如果从初始集 𝒳₁ 出发，那么在时间 t₂ 时系统状态一定在 𝒳₂ 内。

应用：证明无人机在未来 5 秒内不会撞树。

### 7.2 后向可达集（Backward Reachable Set, BRS）

证明：如果要求 t₂ 时系统在 𝒳₂ 内，那么 t₁ 时系统必须在 𝒳₁ 内。

### 7.3 用李雅普诺夫函数认证可达性

核心思想：构造时变李雅普诺夫函数 V(t,x)，使得在水平集边界 V(t,x)=ρ(t) 上有 V̇ ≤ ρ̇(t)。这样轨迹就永远无法离开这个时变不变集。

## 🎮 八、控制器设计：与李雅普诺夫分析结合

### 8.1 交替优化（Alternations）

同时搜索李雅普诺夫函数 V(x) 和控制器 K(x) 是非凸问题（因为 V 和 K 相乘）。

**解决方案**：交替固定一个、优化另一个：
1. 固定 V，优化 K 和 λ
2. 固定 K 和 λ，优化 V
3. 重复直到收敛

教材在 Acrobot 的例子（Majumdar et al. 2013）中展示了这种方法能显著扩大认证吸引域。

### 8.2 线性系统的状态反馈

对于 ẋ = Ax + Bu，搜索 u = Kx 使得 PA + AᵀP ≺ 0 是非凸的（双线性）。

**巧妙的变量替换**：令 Q = P⁻¹, Y = KP⁻¹，得到**线性矩阵不等式（LMI）**：
```
Q ≻ 0, AQ + QAᵀ + BY + YᵀBᵀ ≺ 0
```
这是凸优化问题！解出 Q, Y 后，K = YQ⁻¹。

### 8.3 控制李雅普诺夫函数

定义：V(x) 是控制李雅普诺夫函数，如果对 ∀x≠0，∃u 使得 V̇(x,u)<0。

**特点**：可以先设计 V 而不必显式参数化控制器 u。执行时再在线求解"使 V 下降的 u"。

### 8.4 SOS 近似动态规划

利用李雅普诺夫条件和 HJB 的关系：
$$\dot{J}^*(x) = -\ell(x,u^*) \quad \text{vs.} \quad \dot{V}(x) \preceq 0$$

把 HJB 的等式放宽为不等式，可以用 SOS 凸优化处理：

```
max ∫ Ĵ(x)dx
subject to ℓ(x,u) + ∂Ĵ/∂x·f(x,u) is SOS (∀x,∀u)
           Ĵ(0) = 0
```

这给出了最优代价函数的**下界逼近**。随着多项式次数增加，逼近越来越紧。

#### 实践例子
- **三次多项式最优控制**（Example 9.21）：ẋ = x - 4x³ + u, ℓ = x²+u²
- **单摆 swing-up**（Example 9.22）
- **小车-倒立摆 swing-up**（Example 9.23）

**观察**：超水平集是真实吸引域的紧外近似。

### 实验六：控制设计与交替优化
**文件**：Example 9.24（Acrobot 吸引域扩大）
- 初始化：用 LQR 得到二次李雅普诺夫函数
- 三步交替：
  1. 固定 V 和 ρ，求解 K 和 λ
  2. 固定 V 和 λ，最大化 ρ 搜索 K
  3. 固定 λ 和 K，最大化 ρ 搜索 V
**观察**：交替优化能显著扩大认证吸引域。

### 实验七：SOS 近似动态规划

**观察**：得到的 Ĵ 是最优代价函数的下界逼近。

### 通俗性补充（针对基础薄弱读者的额外解释）

1. **为什么叫"李雅普诺夫函数"？** 俄罗斯数学家 Aleksandr Lyapunov 在 1892 年博士论文中提出。他问："不求解微分方程，能否判断稳定性？"答案是：找一个能量类的函数，看它是否单调下降。

2. **"正定"是什么意思？** 直观说，V(x) 像一个碗：在原点 V=0（碗底），离原点越远 V 越大（碗壁越高）。数学上：V(0)=0 且对所有 x≠0 有 V(x)>0。

3. **"径向无界"为什么重要？** 想象 V(x) 像一个帐篷：如果帐篷顶部是封死的（V 有最大值），那么轨迹可能"逃到帐篷顶部之外"。径向无界确保帐篷向四面八方都无限延伸，没有"天花板"让轨迹逃逸。

4. **SOS（平方和）为什么强大？** 判断一个多项式是否对所有 x 都 ≥0 是 NP-hard 问题。但判断它是否能写成"平方和"（如 x⁴+2x²+1 = (x²+1)²）可以转化为 SDP——**凸优化问题**！这是 Parrilo 和 Lasserre 在 2000 年左右的突破性工作。

5. **S-procedure 的直觉**：想象你要证明"在圆内，函数 p(x)≥0"。直接证明很难，但如果你能找到另一个函数 λ(x)≥0，使得 p(x) + λ(x)(1-x²) 是平方和，那么就间接证明了 p(x)≥0 在圆上。λ(x) 像个"调节旋钮"，帮你在圆内凑出非负性。

## 🎁 十一、整体综合：李雅普诺夫分析在机器人控制中的真正地位

把这一章放到整个机器人控制版图里看：

```

```

**李雅普诺夫分析是连接"理论稳定性"与"计算可解性"的桥梁**。理解了这一章，你就理解了：

- 为什么 LQR 的解 P 可以作为非线性系统的本地李雅普诺夫函数
- 为什么 HALOS 安全层可以用障碍函数证明"机器人不会摔倒"
- 为什么 MPC 的约束优化与李雅普诺夫不变集是同构的
- 为什么"端到端神经网络控制"需要神经李雅普诺夫函数提供稳定性证书
- 为什么 SOS 优化在多项式系统上能给出严格的稳定性证明

### 五个最关键的认识

1. **稳定性证明 = 找下坡函数**：李雅普诺夫函数 V(x) 满足 V̇≤0，系统就像小球滚向谷底
2. **LaSalle 定理**：V̇≤0（不是严格<0）也能证明渐近稳定性，只要看"最大不变集"
3. **凸优化赋能**：线性系统用 SDP，多项式系统用 SOS——把 NP-hard 的稳定性证明转化为凸优化
4. **吸引域估计**：任何子水平集 V(x)≤ρ 都是不变集，可以认证"从这儿出发一定能稳定"
5. **障碍函数**：反向使用李雅普诺夫思想，证明"系统永远不会进入禁区"——安全控制的核心

### 对工程实践的五个启示

1. **SOS 是充分非必要条件**：有些稳定系统找不到多项式李雅普诺夫函数，但实践中 SOS 极其有效
2. **度数选择是艺术**：多项式度数越高，表达能力越强，但数值条件越差。通常从二次开始，逐步提升
3. **隐式形式处理三角函数**：用 s=sinθ, c=cosθ 替换，添加约束 s²+c²=1，刚体动力学全部多项式化
4. **交替优化设计控制器**：V 和 K 双线性，固定一个优化另一个，递归可行且单调改进
5. **Drake 的 RegionOfAttraction 函数**：封装了最佳实践，但实际使用时必须理解底层 SOS 原理

### 三个深度洞察

**洞察一**：HALOS 安全层的数学本质是障碍函数。定义 B(x) 为"距离摔倒的裕度"，要求 Ḃ(x)≤0，那么从安全状态出发的轨迹永远不会进入 B(x)>0 的禁区。这是比紧急停机更主动的安全策略。

**洞察二**：MPC 与 HJB 的关系。MPC 在每个控制周期求解有限时域动态规划，本质上是 HJB 方程的离散时间、有限时域版本。MPC 的"滚动优化"就是值迭代的"在线版"；而 ADRC/PID 底层，恰好是 HJB 在"控制仿射 + 二次代价"假设下的特例。

**洞察三**：Sim2Real 与 SOS 证书的关系。仿真中通过 SOS 优化找到的李雅普诺夫函数 V(x)，如果在真机上因为模型误差导致 V̇>0，这就是"Sim2Real Gap 的安全边界被突破"的数学信号。HALOS 安全层监测 V̇ 的符号，一旦发现 V̇>0 立即触发降级——这是用控制理论本身的工具来解决 Sim2Real Gap。
