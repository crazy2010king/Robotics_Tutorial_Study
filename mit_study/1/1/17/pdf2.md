## 0. 开篇：从"光滑冰面"到"会撞墙的碎石路"

### 0.1 一句话概括

> **前面的工具都假设运动方程"处处光滑"；但接触让方程"会瞬跳（碰撞）、会被卡住（不穿透）"。本章用"混合系统"的语言（模式 + 守卫 + 重置）把这种"光滑段 + 离散跳变"统一描述，然后把轨迹优化、LQR、Lyapunov 一套套"改装"进去——核心技巧是"在碰撞处加一条重置约束、在接触期加一条不穿透约束"。**

### 0.2 作者引言的逐句翻译

**第一层：承认"光滑世界"的局限。**
> 到目前为止，我们对"**光滑**"系统——运动方程由一个**处处光滑**的函数描述的系统——已经发展出一套相当强的规划与控制工具箱。但对简单腿式机器人模型的讨论表明，**与世界接触/脱离接触的动力学更复杂**——它们常被建模成**混合动力学（hybrid dynamics）**：**碰撞事件处有冲击不连续，接触期间有约束动力学**（软约束或硬约束）。

**类比（光滑 vs 接触，全章总纲，请刻进脑子）**：
- **光滑系统** = **在结冰的湖面上滑冰**——你的运动**连续、平滑**，没有"突然一下"，方程处处可微，前面的工具全好使。
- **接触系统** = **在碎石路上跑步、还会撞墙**——**脚落地那一瞬间，你的速度"啪"地变一下**（碰撞不连续）；**脚踩在地上时，你不能把脚插进地里**（不穿透约束）。**这两件事让方程"带棱角、带开关"**，光滑工具直接套用会出错。

**第二层：本章目标 = 把工具扩展进去，而且好消息是"很多工具仍能改装"。**
> 本章目标是把我们的计算工具扩展到这类更丰富的模型。**许多核心工具仍然有效**：**轨迹优化、Lyapunov 分析（如 SOS）、LQR 都有自然的对应（natural equivalents）**。

**第三层：从一个热身开始。**
> 让我们从一个热身练习开始：**轮辐轮的轨迹优化**。我们基本上已经有了所需的一切，它将作为**整章推广方法的良好基础**。

## 1. 热身：轮辐轮的轨迹优化（Example 17.1）—— 给"找极限环"加上"碰撞"

### 1.1 回顾：光滑系统怎么找极限环

> 轮辐轮是我们**最简单的被动动力行走器**——**没有控制输入**，却展现一个**被动稳定的滚动不动点**。我们也已经看到，**轨迹优化能用来找光滑被动系统的极限环**，比如表述成一个**直接配置（direct collocation）** 问题：

$$\text{find}_{x[\cdot],h}\quad \text{subject to}\quad \text{collocation constraints}(x[n],x[n+1],h),\ \forall n\in[0,N-1],\quad x[0]=x[N],\quad h_{\min}\le h\le h_{\max}$$

其中 $h$ 是轨迹断点之间的时步。

**人话（复习第16章）**：
- **直接配置** = 把轨迹画成一段段三次样条，**在每段中点强制"样条斜率 = 动力学"**。
- **$x[0]=x[N]$** = **首尾系橡皮筋**（周期约束，找极限环用）。
- **$h$ 当变量** = **让优化器自己决定每段多长**，好凑出真实周期。

### 1.2 加上碰撞：改"周期性条件"

> 把这套用到轮辐轮**相当直接**。我们仍想找周期轨迹，但**现在必须考虑碰撞事件**。我们可以**修改周期性条件**来做到。

> **强制初始状态在"碰撞刚结束"，最终状态在"碰撞刚发生前"，并确保它俩通过碰撞方程关联**：

$$\text{find}_{x[\cdot],h}\quad \text{subject to}\quad \text{collocation constraints}(x[n],x[n+1],h),\ \forall n\in[0,N-1]$$
$$\theta[0]=\gamma-\alpha,\quad \theta[N]=\gamma+\alpha,\quad \dot\theta[0]=\dot\theta[N]\cos(2\alpha),\quad h_{\min}\le h\le h_{\max}$$

**人话（逐条翻译这三个新约束，必懂）**：
- **$\theta[0]=\gamma-\alpha$** = **轨迹的起点 = "碰撞刚结束那一刻"的腿角度**（回忆第4章：碰撞后支撑腿角度正好是 $\gamma-\alpha$）。
- **$\theta[N]=\gamma+\alpha$** = **轨迹的终点 = "下一次碰撞刚发生前那一刻"的腿角度**（腿摆到 $\gamma+\alpha$ 就撞地）。
- **$\dot\theta[0]=\dot\theta[N]\cos(2\alpha)$** = **这就是第4章的"碰撞方程"**——**撞地瞬间速度乘一个 $\cos(2\alpha)<1$ 的系数（漏气/丢能量）**。**它把"终点速度"和"起点速度"用碰撞物理缝起来**。

**类比（把"碰撞"缝进周期里，必懂）**：
- 光滑极限环 = **画一个闭合的圆圈**，首尾直接接上（$x[0]=x[N]$）。
- 带碰撞的极限环 = **画一段弧（一次迈步的摆动），弧的两头不直接接，而是中间隔了一次"撞地"**——**所以首尾不能相等，而要"通过撞地这一下"接上**。**$\dot\theta[0]=\dot\theta[N]\cos(2\alpha)$ 就是"撞地这一下"的数学描述**——**它告诉优化器"终点速度经过撞地漏气后，正好等于起点速度"**。
- **形象**：光滑环像**一个完整的呼啦圈**；带碰撞环像**一段弧线 + 一个"折角"（撞地）**，折角把弧的两端折回来接上。

### 1.3 再加一条"中间不许撞地"的保险

> 虽然这个简单例子**很可能不需要**（因为动力学足够受限），但**为完整性**，还应加约束**确保中间点都不接触**：

$$\gamma-\alpha\le\theta[n]<\gamma+\alpha,\quad \forall n\in[1,N-1]$$

**人话**：**迈步的"途中"，腿角度必须严格在 $(\gamma-\alpha,\ \gamma+\alpha)$ 之间**——**即"脚悬在空中，没碰地"**。**只有首尾两点才允许碰地**。**这是防止优化器"作弊"在中间偷偷撞一下地**。

> **结果是一个简单、干净的数值算法，用于找轮辐轮的滚动极限环解。请自己跑一跑。**

**类比**：**整件事 = "画一段空中摆动的弧 + 在两头各加一个'撞地折角'约束 + 途中不许碰地"**——**优化器就在这些规矩下，找出那条"摆得刚好、撞得刚好、能循环下去"的弧**。

## 2. （自主）混合系统（17.1）—— 给"会撞会卡"的世界一套统一语言

### 2.1 回忆：我们之前是怎么"凑合"建模接触的

> 回忆我们怎么建模简单腿式机器人。**先对每种可能的接触配置，独立推导运动方程**——例如 SLIP 模型，**飞行相**一组方程（管质心位置），**支撑相**完全另一组方程（用极坐标写）。**然后做一点额外工作描述模型之间的转换**——例如 SLIP 从飞行转到支撑，当脚首次触地。**仿真这个模型时，意味着有一个离散"事件"在脚碰撞那一刻发生，机器人状态立即不连续变化**（这里我们甚至**换掉了状态变量**）。

**类比（"换地图"式建模，必懂）**：
- 这就像玩一个**有多个"场景"的游戏**：**空中场景**用一套物理规则，**落地场景**用另一套物理规则（连坐标都换了）。
- **场景之间怎么切**？靠一个**触发条件**（脚碰地）。
- **切的时候状态怎么变**？靠一个**切换规则**（速度瞬跳、甚至换坐标）。
- **这种"多场景 + 触发器 + 切换规则"的拼盘，就是混合系统**。

### 2.2 混合系统的"三件套"：模式 / 守卫 / 重置

> **混合系统的语言**给了我们一套**丰富的语言**来描述这种系统，以及**一套分析和控制它们的工具**。"混合系统"这个词有点** overloaded（一词多义）**——这里我们用 "hybrid" 指**同时含离散时间和连续时间**；我们这里考虑的特定系统有时叫**自主混合系统（autonomous hybrid systems）**，因为**内部动力学自己就能引起离散变化，不需要外部输入**。

> **在混合系统表述里，我们用三样东西描述一个系统**：
> - **一组模式（modes）**：每个模式由（理想上光滑的）**连续动力学**描述；
> - **一组守卫（guards）**：这里是连续函数，**它的零水平集（=0 的地方）描述"触发一个事件"的条件**；
> - **一组重置（resets）**：描述**守卫触发时，状态的离散更新**。
>
> **每个守卫关联一个特定模式，每个模式可以有多个守卫。每个守卫至多一个重置。** 你偶尔会听到守卫被叫作 **"witness functions"（见证函数）**——因为它们在仿真里扮演这个角色；重置有时被叫作 **"transition functions"（转移函数）**。

**类比（游戏引擎的三件套，必懂，这是理解混合系统的钥匙）**：
- **模式（mode）** = **游戏的一个"关卡/场景"**，每个关卡有自己的物理规则（连续动力学 $f_i$）。比如"脚在空中"是一个关卡，"脚跟踩地"是另一个关卡。
- **守卫（guard）$\phi_{i,j}$** = **关卡里的"触发器/机关"**——一个连续函数，**当它等于 0 时，机关被触发**（比如"脚跟离地距离 = 0"= 脚跟撞地了）。**$\phi_{i,j}(x_i)>0$ 表示"在模式 $i$ 里、机关还没触发"**。
- **重置（reset）$\Delta_{i,j}$** = **机关触发后的"传送门/状态改写"**——**把状态从"关卡 $i$ 的结尾"瞬间改写成"关卡 $j$ 的开头"**（比如撞地后速度瞬跳、换坐标）。
- **"每个守卫至多一个重置"** = **一个机关触发后，去哪个下一关卡是确定的**（不会"既可能去 A 又可能去 B"，那是另一类问题）。

> **我心里对混合系统的意象**，用一个简单例子画在下面——**机器人脚跟撞地**。混合系统的一条解轨迹，**在每个模式内是一段连续轨迹，被"轨迹击中守卫零水平集"时的离散更新打断**（这里脚跟与地面的距离变成 0），**重置描述状态变量的离散变化**。

**Figure 17.2**：把接触建模为混合系统。

**类比（脚的四种"着地姿势"=四个关卡，必懂）**：
- 你走路时，脚的状态在**四种姿势**间切换：**腾空 → 脚跟先着地 → 全脚掌着地 → 脚趾蹬地离地**。
- **每种姿势 = 一个模式**，有自己的运动方程（比如"全脚掌着地"时脚不能转，"腾空"时脚自由摆）。
- **姿势之间怎么切** = **守卫**（比如"脚跟高度=0"触发"腾空→脚跟着地"）。

- **整条走路轨迹 = 在这四个关卡间，被触发器串起来的一串连续片段**。

### 2.3 混合轨迹优化（17.1.1）—— 把"多段连续 + 多个跳变"缝成一个优化

#### 2.3.1 两种问题：模式序列"已知" vs "要自己找"

> 用模式/守卫/重置这套更一般的语言，我们就能开始表述**"混合轨迹优化"** 问题。在混合轨迹优化里，有一个**重大区别**：**模式序列先验已知**（优化只解连续时间轨迹）**vs 必须同时发现模式序列**。

**类比（已知路线 vs 自己探路，必懂）**：
- **模式序列已知** = **导航已经告诉你"先走 A 路、再走 B 路、再走 C 路"**，你只需**算出每段路具体怎么开**（连续轨迹）。**这相对好做**。
- **模式序列未知** = **导航没给路线，连"该走哪几条路、按什么顺序"都要你自己想**——**这难得多**（因为"顺序"是离散的、组合的，17.2/17.3 才碰）。
- **本节先攻"已知序列"这一种**。

#### 2.3.2 固定模式序列：把多个数学规划"缝"成一个

> **模式序列固定时**，混合轨迹优化**可以简单到**：**把多个独立的数学规划"缝"成一个数学规划**，**用边界条件约束来强制守卫/重置约束**。

> 用 $x_k$ 表示**序列第 $k$ 段的状态**，$m_k$ 表示**第 $k$ 段的模式**，我们可以写：

$$\text{find}_{x_k[\cdot],h_k}\quad \text{subject to}\quad x_0[0]=x_0$$
$$\forall k,\ \forall n_k\in[0,N_k-1],\quad \text{collocation constraints}_{m_k}(x_k[n_k],x_k[n_k+1],h_k[n_k]),\quad h_{\min}\le h_k[n_k]\le h_{\max}$$
$$\forall k\in[0,K-1],\quad \phi_{m_k,m_{k+1}}(x_k[N_k])=0,\quad x_{k+1}[0]=\Delta_{m_k,m_{k+1}}(x_k[N_k])$$
$$\forall k,n_k,m\in\mathcal{G},\quad \phi_{m_k,m}(x_k[n_k])>0$$

**人话（逐行翻译，必懂）**：
- **第 1 行 $x_0[0]=x_0$** = **第一段的起点 = 给定的初始状态**。
- **第 2 行** = **每一段 $k$ 内部，用"该段模式 $m_k$ 的动力学"做直接配置**（样条中点强制符合 $f_{m_k}$），**每段时步 $h_k$ 在上下界内**。
- **第 3 行（缝合的关键！）** = **段与段之间，用守卫+重置接起来**：
  - **$\phi_{m_k,m_{k+1}}(x_k[N_k])=0$** = **第 $k$ 段的终点，正好触发"从 $m_k$ 到 $m_{k+1}$"的守卫**（机关踩中了）。
  - **$x_{k+1}[0]=\Delta_{m_k,m_{k+1}}(x_k[N_k])$** = **第 $k+1$ 段的起点 = 第 $k$ 段终点经过重置 $\Delta$ 改写后的状态**（穿过传送门）。
- **第 4 行** = **"途中不许误触发别的机关"**——对**所有"没被调度的"守卫**（集合 $\mathcal{G}$ 列出除调度外的所有守卫和时间），**要求 $\phi>0$**（机关没被踩中）。**这就是"中间不许偷偷撞地"的一般版**。

**类比（缝衣服，必懂）**：
- 每一段连续轨迹 = **一块布**。
- 守卫 $\phi=0$ = **两块布的接缝处"对齐标记"**。
- 重置 $\Delta$ = **接缝处的"针脚"**——把上一块的尾和下一块的头**按碰撞物理缝起来**。
- 第 4 行 = **保证"布的其他地方没有意外的破洞/误缝"**。
- **整个混合轨迹优化 = 把 $K$ 块布，按指定的顺序，用针脚缝成一件衣服**。

> **然后自然可以加控制输入**（作为额外决策变量），**加目标函数和更多约束**。

### 2.4 Example 17.2（篮球花式投篮 trick shot）—— 把"弹跳"当混合系统玩

#### 2.4.1 先从简单的"反弹传球"开始

> 作为混合轨迹优化的一个简单例子，我觉得**看看能否表述"搜索优化篮球花式投篮初值"** 会很有趣。

> **先从更简单的"反弹传球（bounce pass）"开始**。我们可以用**非常简单的动力学**捕捉**弹跳球**（平面，忽略旋转）：

$$q=\begin{bmatrix}x\\z\end{bmatrix},\quad \ddot q=\begin{bmatrix}0\\-g\end{bmatrix}$$

**人话**：**球在空中 = 自由落体**（水平匀速、垂直受重力）。**这是"飞行模式"的动力学**。

> **在任何一段无接触、时长为 $h$ 的区间里，我们其实可以完美积分这动力学**：

$$x(t+h)=\begin{bmatrix}x(t)+h\dot x(t)\\ z(t)+h\dot z(t)-\tfrac12 gh^2\\ \dot x(t)\\ \dot z(t)-hg\end{bmatrix}$$

**人话**：**因为自由落体的解是解析已知的**（抛物线），**我们不用数值积分，直接套公式就能算出"$h$ 秒后球在哪、速度多少"**。**这是"每段动力学可解析积分"的奢侈情况**（作者后面会说这是例外）。

> **反弹传球里，我们只考虑与地面的碰撞**，所以**守卫 $\phi(x)=z$**（**球高度 = 0 时触发**），**重置映射假设弹性碰撞、恢复系数 $e$**：

$$x^+=\Delta(x^-)=\begin{bmatrix}x^-\\ z^-\\ \dot x^-\\ -e\dot z^-\end{bmatrix}^T$$

**人话**：**撞地时，水平位置/速度不变，垂直位置保持 0，垂直速度反向并乘 $e$**（$e=1$ 完全弹性，$e<1$ 撞一下矮一点）。**这就是"撞地传送门"**。

> **我们把问题表述成这样**：给定**初始球位置 $(x=0,z=1)$**，**4 米外的最终球位置 $(x=4,z=1)$**，**找初速度在 5 秒内达成目标**。显然这意味 $\dot x(0)=4/5$。**有趣的问题是——$\dot z(0)$ 该怎么办？** **有多个解——涉及不同次数的弹跳**。我们可以用一个简单的混合轨迹优化**把它们全找出来**，利用一个观察：**每个弹跳次数有两个解——一个以正 $\dot z(0)$ 开始、一个以负 $\dot z(0)$ 开始**。

**Figure 17.4**：找"反弹传球"解的轨迹优化。

### 2.5 直接射击（Direct shooting）—— 不告诉优化器模式序列，让它"自己撞"

> **也可以通过"取穿过守卫/重置映射的梯度"，用单次射击优化轨迹。** 这方法**不需要显式的模式序列**，但**容易陷入局部极小**（因为**没有梯度能把轨迹"拉向"一个标称轨迹没访问到的守卫**）。

**类比（蒙眼找机关，必懂）**：
- **固定模式序列** = **你告诉优化器"第 3 秒会撞墙"**，它就知道"在第 3 秒附近要小心算碰撞"。
- **直接射击** = **你不告诉它，让它自己模拟、自己撞**——**但如果初猜的轨迹"根本没碰墙"，那么"碰墙这件事"对代价的梯度 = 0**（**没碰就没梯度**），**优化器就"感觉不到墙的存在"，永远不会主动去撞它**——**这就是"没有梯度把轨迹拉向没访问的守卫"**，**所以容易卡局部极小**。

#### 2.5.1 混合伴随梯度 + saltation 矩阵

> 为此，我们需要**取代价相对轨迹参数的梯度**。我们前面用**伴随方法**（如"反向传播通过时间"）在离散和连续时间算梯度的方法，**可以组合起来处理混合情况**。推导**几乎和"用连续伴随方程解连续模式（从最终时间向前）"一样简单**，**加上离散伴随方程处理跳跃不连续**。**唯一的细节是，我们还要考虑"相对接触时间的变分"**；**这个梯度常被称为 "saltation matrix"（跳跃矩阵/盐化矩阵）**。

**人话（saltation 矩阵到底在补什么，必懂）**：
- 普通伴随梯度 = **"状态怎么随参数变"** 一路反传。
- 但混合系统里，**接触时间 $t_c$ 本身也随参数变**（你改一点初值，撞墙的时刻就早一点/晚一点）。
- **如果忽略"撞墙时刻会移动"这件事，梯度就算错了**——**因为撞墙那一刻状态跳变，跳变的"时机"变了，下游全变**。
- **saltation 矩阵 = 专门补"接触时机移动"带来的那部分梯度**的修正项。**"saltation" 拉丁文原意是"跳跃"**——**它修正的就是"跳跃时刻漂移"的影响**。

#### 2.5.2 两模式一转换的混合代价

> 考虑我们标准混合系统图里的**两模式、一转换**情况。那么可以写**总代价**为：

$$J_\alpha=\int_0^{t_c^-}\ell_1(x_1,u_\alpha)\,dt+\int_{t_c^+}^{t_f}\ell_2(x_2,u_\alpha)\,dt$$
$$\dot x_1=f_1(x_1,u_\alpha),\quad \dot x_2=f_2(x_2,u_\alpha),\quad x_2(t_c^+)=\Delta_{1,2}(x_1(t_c^-))$$

> 我们想取 $J$ 相对轨迹参数 $\alpha_i$ 的梯度。**第一和第二积分的梯度正是熟悉的连续情况**，但**第二个积分必须用 $\frac{\partial x_2(t_c^+)}{\partial\alpha_i}$ 初始化**，**它应通过离散转换与 $\frac{\partial x_1(t_c^-)}{\partial\alpha_i}$ 关联**。**重要的一点是，要捕捉这个转换不仅依赖 $x_1$、还依赖 $t_c$ 的依赖关系，而这两者都依赖 $\alpha$**。把它写出来，我们有……（PDF 此处推导省略，正文以"we have..."收尾，详细在参考文献/附录）。

**人话**：**两段积分的梯度好算（就是普通伴随）；难的是"接缝处"**——**第二段反传的"起点灵敏度" $\partial x_2(t_c^+)/\partial\alpha$，不能简单等于第一段的"终点灵敏度" $\partial x_1(t_c^-)/\partial\alpha$**，**因为中间隔了一次重置 $\Delta$，而且重置发生的时刻 $t_c$ 也在动**。**saltation 矩阵就是把"重置 $\Delta$ 的雅可比 + 接触时刻漂移的修正"打包起来的矩阵**，**用它把第一段灵敏度"翻译"成第二段灵敏度的初值**。

### 2.6 推导混合模型：最小坐标 vs 浮动基坐标 —— 两种"建模哲学"

#### 2.6.1 最小坐标法：优雅但"每加一种接触就要重写"

> 推导这种形式的运动方程**有些工作要做**。还记得轮辐轮和圆规步态例子我们怎么做的吗？**两种情况我们都假设"恰好一只脚附着地面、且不滑"**，**这允许我们写拉格朗日量，仿佛有一个销关节把脚连到地面**，从而得到运动方程。**对 SLIP 模型，我们用独立的拉格朗日方程分别推导飞行相和支撑相，各有不同的状态表示**。我把这称为**最小坐标建模方法（minimal coordinates modeling approach）**——**它优雅，且有我们下面会欣赏到的重要计算优势**。

> **但它工作量巨大！** 例如，**若我们还想考虑轮辐轮脚接触的摩擦**，我们就得**推导又一组方程描述滑动模式**（比如加一个**沿斜坡移动脚的棱柱关节**），**再加上"计算给定状态接触力、以及离摩擦锥边界距离"的守卫**，**如此等等，没完没了**。

**类比（手工定制 vs 通用框架，必懂）**：
- **最小坐标法** = **为每种"脚的状态"手工定制一套方程**——**"脚钉死"一套、"脚滑动"一套、"脚腾空"一套**。**每套都精简（变量最少）、算得快**，**但每加一种新接触情况，就要从头推导一套**——**累死**。

#### 2.6.2 浮动基坐标法：一次推导，接触当"约束力"加上去

> **幸好，有另一种建模方法**来推导接触的模式/守卫/重置，**更一般**（虽然它让**每个模式的动力学稍复杂一点**）。我们可以**用浮动基坐标（floating-base coordinates）建模机器人**——**加一个虚构的六自由度"浮动基"关节，把机器人的某部分连到世界**（平面模型里只用三自由度，如 $(x,z,\theta)$）。**我们可以对浮动基机器人推导一次运动方程，不考虑接触**，**然后把"来自接触"的额外约束，作为施加到物体上的接触力加进去**。

> **结果的机械臂方程取这种形式**：

$$M(q)\ddot q+C(q,\dot q)\dot q=\tau_g(q)+Bu+\sum_i J_i^T(q)\lambda_i \qquad (1)$$

> 其中 $\lambda_i$ 是**约束力**，$J_i$ 是**约束雅可比**。**方便的是，若我们接触方程里的守卫函数是"接触的符号距离" $\phi_i(q)$，那么这个雅可比简单就是 $J_i(q)=\frac{\partial\phi_i}{\partial q}$**。常见情况（位置约束、速度约束、碰撞方程等）的基本推导我写在附录。**这里重要的是理解**：**这是"模式/守卫/重置方程"的一种替代表述，但它不再是最小坐标系统**——**运动方程用状态变量写，但系统可能实际上只被约束着沿一个低维流形演化**（若我们用三个浮动基构型变量写轮辐轮方程，**它在支撑时、且在摩擦锥内，仍然只绕脚趾转**）。**这会对我们的算法产生影响**。

**人话（浮动基法的精髓，必懂）**：
- **不预先假设"脚钉死"**，而是**给机器人"完全自由"（浮动基，能在空中飞）**，**写一套"通用方程"**。
- **接触 = 往通用方程里"加一个力 $\lambda$"**，**这个力的作用是"把脚按在地上/不让它穿地"**。
- **$J_i^T\lambda_i$** = **接触力对广义坐标的等效贡献**（**$J_i^T$ 把"笛卡尔空间的接触力"翻译成"关节空间的等效力矩"**）。
- **$\lambda_i$ 是未知数**，**由"接触约束必须满足"（脚不穿地、不滑）解出来**。
- **守卫 = 符号距离 $\phi_i(q)=0$**（脚刚好碰地），**它的雅可比 $J_i=\partial\phi_i/\partial q$ 自动给出**。

**类比（通用方程 + 接触当"外力"，必懂）**：
- **最小坐标法** = **事先把脚焊死在地上，写"焊死后的方程"**。
- **浮动基法** = **先写"脚能飞"的通用方程，然后说'接触时，地面会施加一个力 $\lambda$ 把脚顶住'**——**$\lambda$ 多大由'脚不能穿地'这个条件解出**。
- **好处** = **一套通用方程走天下**，**加摩擦？加一个"切向不滑"的约束力就行，不用重写整套方程**。
- **代价** = **变量多了**（多了浮动基自由度 + 接触力 $\lambda$），**而且系统"看起来自由、实际被约束在低维流形上"**（轮辐轮浮动基有 3 个构型变量，但支撑时实际只绕脚趾 1 个自由度转）——**这种"冗余"会让某些算法（如直接配置）出微妙问题**，见下。

#### 2.6.3 浮动基 + 直接配置的微妙 + 最大坐标

> **注意，对"浮动基坐标 + 额外接触约束"的系统用直接配置方法，有些微妙**——**直接配置的朴素实现，可能在样条里没有足够的自由度，去在节点点和配置点都精确满足动力学约束**。**[1] 展示了直接配置到约束系统的自然扩展**；**并更完整地描述了"把接触力参数化为决策变量"的优势**。

**人话**：**朴素直接配置假设"样条能自由拟合动力学"**，**但浮动基系统带"接触约束"，样条的自由度可能不够同时满足"动力学 + 不穿地"**——**[1] 的解法 = 把接触力 $\lambda$ 也当成决策变量，让优化器一边拟合样条、一边解出 $\lambda$**（**这正是 17.2 接触隐式优化的伏笔**）。

> **完整性起见**：你可能还听到 **"最大坐标（maximal coordinates）"**。**这是极端情况**——**每个刚体都用自己的浮动基参数化，连机器人关节都实现成"把连杆连在一起的约束"**。**一些著名仿真引擎用过**（如 Open Dynamics Engine），**对某些计算方法可能有优势**。**但对我们的目的，用浮动基坐标的动力学通常有效得多**。

**类比（坐标系的"三档"，必懂）**：
- **最小坐标** = **只记"真正能动的关节"**（变量最少，但要为每种接触手写方程）。
- **浮动基坐标** = **记"躯干在空间的位姿 + 关节"**（中等，接触当约束力加，通用）。
- **最大坐标** = **每个零件都记"在空间的位姿"，关节也当约束**（变量最多，最冗余，但仿真引擎爱用，因为"统一"）。
- **作者的选择** = **浮动基**（**通用性和效率的折中**）。

### 2.7 离散控制（事件之间）（17.1.3）—— 占位 + 概念

> 在我们对 SLIP 跑步机器人的讨论里，我们引入了一种**惊人简单但有效**的方法来实现 "deadbeat" 控制器——**控制决策每周期只发生一次**。**这个思想有一个自然的推广，到更一般的混合系统**……

**补充概念（把占位背后的"该懂的东西"补齐，必懂）**：
- **deadbeat 控制**（第4章 SLIP 讲过）= **一次决策，下一拍就精确到目标**——**对跑步，就是"每跳一次，决定一次落脚角"**。
- **推广到一般混合系统** = **"每发生一次离散事件（如一次撞地），才做一次控制决策；两次事件之间，控制保持不变或按开环走"**——**这正好契合混合系统"事件驱动"的天然节奏**。
- **为什么合理**？因为**很多接触任务，"决策"本来就发生在事件时刻**——**落脚角在脚离地时就定了，脚在空中那段时间不太改**（第16章 16.3 也讲过这个直觉）。**所以"每事件一决策"不是偷懒，而是"匹配任务的天然粒度"**。

## 3. 接触隐式轨迹优化（17.2）—— 占位 + 概念

> **Coming soon。（入门见 [5]，或近期综述 [6]）。**

**补充概念（这是接触规划里"最革命"的思想之一，必懂）**：
- **前面的混合轨迹优化** = **你得先告诉优化器"模式序列"**（先飞、再撞墙、再撞地……）。
- **接触隐式（contact-implicit）轨迹优化** = **你不告诉它任何模式序列**，**让优化器自己决定"何时接触、接触哪、用多大力"**——**把"接触"也变成优化变量**。
- **怎么做**？用**互补约束（complementarity constraints）** 把接触物理写成等式/不等式，比如：
  - **力 $\lambda\ge 0$**（地面只能顶、不能拉）；
  - **间隙 $g\ge 0$**（脚不能穿地）；
  - **$\lambda\cdot g=0$**（**互补**：**要么脚离地 $g>0$ 且力 $\lambda=0$，要么脚踩地 $g=0$ 且力 $\lambda\ge 0$**——**两者不能同时为正**）。
- **这一条 $\lambda g=0$ 就把"接触/不接触"的离散开关，编码进了优化**——**优化器自己解出"哪几步踩地、哪几步腾空"**，**不需要你剧透模式序列**。
- **代价** = **互补约束是非凸的**，**难解**——**所以 [5]（Posa 的 Direct Method）、[7]（凸松弛）都在啃这块硬骨头**。

**类比（让优化器"自己决定何时撞墙"，必懂）**：
- **混合轨迹优化** = **你给机器人一张"剧本"：第 1 幕飞、第 2 幕撞墙、第 3 幕落地**，它照剧本演。
- **接触隐式优化** = **你只给"起点、终点、物理定律"，连剧本都不给**——**机器人自己琢磨出"哦，我得先撞一下墙再落地"**。**自由度高、更通用，但也更难算**。

## 5. 练习 17.1（找圆规步态极限环）—— 逐条讲透 + 约束编码

> 在这个练习里，我们用**轨迹优化**识别**圆规步态的极限环**。我们用**相当一般的方法**：**机器人动力学用浮动基坐标描述，摩擦接触被精确建模**。在 notebook 里，要求你**编码该优化问题所需的许多约束**：

### (a) 在所有断点，强制支撑脚与地面接触

**人话**：**支撑脚 = 踩地那只脚**。"**接触**" = **脚的位置 = 地面高度**（位置约束 $\phi_{stance}(q)=0$），**且最好速度也 = 0**（脚踩地不滑不弹）。**在直接配置的每个断点都加这条**——**保证"整段支撑期，脚都钉在地上"**。

### (b) 在初始时间，强制摆动脚与地面接触

**人话**：**极限环是周期的**——**"一步的开始" = "上一步摆动脚刚撞地、即将变成支撑脚"的那一刻**。**所以初始时刻，那只"将要支撑"的脚必须正好在地上**（**这是周期缝合的一部分**，呼应 17.1 轮辐轮的 $\theta[0]=\gamma-\alpha$）。

### (c) 在所有断点，防止摆动脚穿透地面

**人话**：**摆动脚 = 在空中甩的那只脚**。它**不能插进地里**——**所以在每个断点加 $z_{swing}\ge 0$**（**间隙非负**）。**注意是"≥"不是"="**——**摆动脚在空中，$z>0$；只有撞地那一刻 $z=0$**。（**练习说明：忽略摆动腿经过支撑腿时，摆动脚擦地的 scuffing**——即允许摆动脚"擦着地过"而不建模那次接触。）

### (d) 确保所有断点，支撑脚接触力在摩擦锥内

**人话**：**支撑脚踩地时，地面给它的力 $\lambda$ 不能"太斜"**——**否则脚会滑**。**摩擦锥约束** = **切向力 ≤ 摩擦系数 × 法向力**，即 $|\lambda_{tan}|\le\mu\lambda_{norm}$，**且 $\lambda_{norm}\ge 0$**（地面只能顶）。**在每个断点都加**——**保证"支撑期脚真的踩得住、不打滑"**。**这是浮动基法里 $\lambda$ 作为决策变量后，才能加的约束**（最小坐标法里 $\lambda$ 不显式出现，加不了）。

### (e) 确保摆动脚撞地产生的冲量在摩擦锥内

**人话**：**撞地那一瞬间，不是"力"而是"冲量"（力×极短时间 = 速度瞬跳的来源）**。**这个冲量也得在摩擦锥内**——**否则撞地那一下脚就滑了**。**所以重置/碰撞方程里，对碰撞冲量加同样的锥约束** $|j_{tan}|\le\mu j_{norm}$。**这是"碰撞也守摩擦规矩"**。

**类比（练习 17.1 的"五条规矩"= 把走路物理全写进优化，必懂）**：
- (a) **支撑脚钉地**（位置=0）；
- (b) **周期起点脚也在地**（缝合周期）；
- (c) **摆动脚不穿地**（间隙≥0）；
- (d) **支撑脚不打滑**（力在锥内）；
- (e) **撞地那一下也不打滑**（冲量在锥内）。
- **五条加齐 = 一个"物理上站得住、走得稳、不滑不穿"的圆规步态极限环**——**优化器在这些规矩下，搜出那条周期步态**。**注意 (d)(e) 只有用浮动基法（$\lambda$、冲量是变量）才加得了**——**这就是 2.6 节"浮动基法更通用"的实战体现**。

## 增补一：把"还不够通俗"的 5 个概念，各加一个类比 / 澄清

1. **为什么"中间不许误触发"要写成 $\phi_{m_k,m}(x)>0$ 而不是 $\ne 0$**？因为守卫约定是 **$\phi>0$ = 安全/未触发，$\phi=0$ = 触发，$\phi<0$ = 已穿透/非法**。所以"途中不许撞" = **保持 $\phi>0$**（严格在安全侧）。**类比**：离墙距离 $>0$ = 没撞墙；$=0$ = 贴墙；$<0$ = 穿墙（非法）。
2. **重置 $\Delta$ 为什么"至多一个"**？因为**一个守卫触发后，下一个模式是确定的**（脚撞地 → 必然进"支撑模式"，不会"有时进支撑有时进腾空"）。**若一个事件后有多种可能去向**（如"撞地后可能滑也可能不滑"），那需要**多个守卫**分别描述，或归入 17.2/17.3 的"组合/隐式"框架。**类比**：一个机关触发后"传送门通向哪"是写死的；"通向哪取决于你怎么撞"= 那是多个机关。
3. **浮动基法里 $\lambda$ 是"解出来的"还是"决策变量"**？在**仿真/正向求解**里，$\lambda$ 由"接触约束 + 动力学"**解出来**（给定状态，求让脚不穿地的力）。在**接触隐式轨迹优化（17.2）** 里，$\lambda$ 被**提升为决策变量**，**和轨迹一起被优化**，**互补约束 $\lambda g=0$ 保证物理自洽**。**这就是 [1] "把接触力参数化为决策变量"的含义**。
4. **saltation 矩阵的名字由来**：saltation 拉丁文 = "跳跃/舞蹈"。在动力系统理论里，**saltation matrix 描述"轨迹穿过不连续面时，扰动（变分）怎么被'跳变'地映射"**——**因为状态在接触面跳了一下，"稍微改一点初值"导致的"轨迹偏移"，在穿过接触面时会被一个非平凡的矩阵'折射'一下**（像光穿过介质的折射），**这个折射矩阵就是 saltation matrix**。**忽略它 = 假设"接触面是透明的、不折射扰动"，梯度就错了**。
5. **互补约束 $\lambda\ge0,\ g\ge0,\ \lambda g=0$ 为什么非凸**？因为 **$\lambda g=0$ 描述的是"坐标轴的两条射线"的并**（$\lambda=0,g\ge0$ 这条射线 ∪ $\lambda\ge0,g=0$ 这条射线）——**这是个"L 形"，非凸**（L 形两臂中点的连线穿过非法区）。**所以接触隐式优化天生非凸**，**[5]/[7] 的工作就是"怎么把这个 L 形松弛/处理成能算的形式"**。

```python
    times = []
    for k in range(n_bounce):
        # 解本段飞行到 z=0 的时间 (z0+vz t-0.5 g t^2=0)
        # 0.5 g t^2 - vz t - z = 0
        a, b, c = 0.5*g, -vz, -z
        disc = b*b - 4*a*c
        if disc < 0: return 1e6
        t = (-b + np.sqrt(disc))/(2*a)           # 取正根(下一次落地)
        if t <= 1e-9: return 1e6
        x, z, vx_, vz = fly(x, z, vx_, vz, t); times.append(t)
        x, z, vx_, vz = bounce(x, z, vx_, vz)
    # 末段飞剩余时间
    t_last = T - sum(times)
    if t_last <= 1e-9: return 1e6
    x, z, vx_, vz = fly(x, z, vx_, vz, t_last)
    return (x-xf)**2 + (z-zf)**2

# 扫描 vz0 正负, 找 n_bounce=1 的解
for nb in [1, 2]:
    for sgn in [+1, -1]:
        vz_grid = np.linspace(0.1, 12, 4000) * sgn
        err = np.array([final_err(v, nb) for v in vz_grid])
        # 找误差局部极小且小的
        idx = np.where(err < 1e-2)[0]
        if len(idx):
            v_sol = vz_grid[idx[np.argmin(err[idx])]]
            print(f"n_bounce={nb}, sign={'+' if sgn>0 else '-'}: vz0≈{v_sol:.3f}, err={err[idx].min():.2e}")
```

**你会看到**：**对每个弹跳次数，正/负初速各找到一个解**（误差≈0）——**亲手复现"每个弹跳次数两个解"**。**改 $e$**（恢复系数），**解会移动**（弹得越"软"，需要的初速越大）。**这就是 Figure 17.4 的数值内核**——**混合系统"飞-撞-飞"的缝合，在 numpy 里就是"循环 fly+bounce"**。

### 实验 2：轮辐轮混合轨迹优化 —— 直接配置 + 碰撞重置约束（骨架 + 可跑核心，对照 Example 17.1）

**用第16章的直接配置找"一段摆动弧"，加上"首尾通过碰撞方程缝合 + 途中不撞地"**——**这里给可跑的"打靶+碰撞"核心**（完整直接配置见 Drake notebook）。

```python
import numpy as np
from scipy.integrate import solve_ivp
from scipy.optimize import root
g, l = 9.8, 1.0; alpha = np.pi/8; gamma = 0.15     # 第4章参数
cos2a = np.cos(2*alpha)
def stance(t, x):                                  # 支撑相动力学 = 无阻尼摆
    th, thd = x; return [thd, (g/l)*np.sin(th)]
# 找周期极限环: 初态 th0=gamma-alpha, thd0=? 使得摆到 th=gamma+alpha 时,
# 经碰撞 thd_after = thd_before*cos2a 正好 = 初速 thd0 (周期)
def residual(thd0):
    sol = solve_ivp(stance, [0, 10], [gamma-alpha, thd0[0]],
                    events=lambda t,x: x[0]-(gamma+alpha), dense_output=True)
    if sol.t_events[0].size==0: return [1e3]
    thd_before = sol.y[1, -1]                      # 撞地前速度
    thd_after  = thd_before*cos2a                  # 碰撞重置
    return [thd_after - thd0[0]]                   # 周期: 撞后速=初速
res = root(residual, [1.5])
print("轮辐轮混合极限环: thd0≈", round(res.x[0],4),
      " (碰撞重置 cos2a=%.3f 把首尾缝起来)" % cos2a)
# 验证: 用此初速积分一步, 看是否回到 (gamma-alpha, thd0)
sol = solve_ivp(stance, [0,10], [gamma-alpha, res.x[0]],
                events=lambda t,x:x[0]-(gamma+alpha))
thd_after = sol.y[1,-1]*cos2a
print("  一步后撞后速=", round(thd_after,4), "≈ 初速", round(res.x[0],4), "-> 周期闭合")
```

**你会看到**：**root 解出的 $\dot\theta_0$，使得"摆到 $\gamma+\alpha$ 撞地、速度乘 $\cos 2\alpha$ 后，正好等于初速"**——**这就是 Example 17.1 那三条约束（$\theta[0],\theta[N],\dot\theta[0]=\dot\theta[N]\cos2\alpha$）的"打靶法替身"**。**直接配置版**只是把"积分一步"换成"样条中点强制动力学 + 把这三条当等式约束"——**思想完全一致**。

### 实验 3：saltation 矩阵 —— 混合梯度里"接触时刻漂移"的修正（可跑，对照 2.5）

** toy 系统：$\dot x=v,\ \dot v=-g$（自由落体），撞地 $z=0$ 时 $v\to -e v$。演示"忽略接触时刻漂移 vs 加上 saltation 修正"对"末状态对初速的梯度"的影响**。

```python
import numpy as np
g=9.81; e=0.8; T=1.0; z0=1.0
# 解析: 撞地时刻 tc 满足 z0+vz0*tc-0.5*g*tc^2=0; 撞后 vz1=-e*(vz0-g*tc); 末速 vz(T)=vz1-g*(T-tc)
def vz_end(vz0):
    a,b,c=0.5*g,-vz0,-z0; tc=(-b+np.sqrt(b*b-4*a*c))/(2*a)
    vz_before=vz0-g*tc; vz_after=-e*vz_before
    return vz_after-g*(T-tc), tc
# 数值梯度(真值)
dv=1e-6
vz_end0,_=vz_end(0.0); vz_endp,_=vz_end(dv)
true_grad=(vz_endp-vz_end0)/dv
# "忽略tc漂移"的错误梯度: 假设tc固定, 只传 vz_after=-e*vz_before 的链式
#   dvz_after/dvz0 (忽略tc对vz0的依赖) = -e*1 = -e; 再传末段 *1 -> -e
wrong_grad = -e
# 加 saltation 修正: tc 依赖 vz0: dtc/dvz0 = -1/(vz0-g*tc) (由隐函数对 z=0 求导)
_,tc=vz_end(0.0); vz_before=0.0-g*tc
dtc_dvz0 = -1.0/(vz0_init:=0.0 - g*tc)        # =-1/vz_before
# saltation: dvz_after/dvz0 = -e*(1 - g*dtc_dvz0)  (vz_before=vz0-g*tc 对vz0全导数=1-g*dtc)
dvzbefore_dvz0 = 1 - g*dtc_dvz0
salt_grad = -e*dvzbefore_dvz0                  # 末段对vz_after线性, 系数1
print("真梯度(数值)=%.4f" % true_grad)
print("忽略tc漂移(错)=%.4f" % wrong_grad)
print("加saltation修正=%.4f" % salt_grad, " -> 应≈真梯度")
```

**你会看到**：**"忽略接触时刻漂移"的梯度 $-e$ 与真梯度差很多，加上 saltation 修正后≈真梯度**——**亲手验证 2.5 的警告**：**穿过碰撞取梯度，必须补"接触时刻随参数漂移"的那一项（saltation matrix），否则梯度是错的**。**这就是"直接射击穿过 guard/reset"的精度命门**。

### 实验 4：浮动基接触力 —— 解 $M\ddot q+\cdots=\tau_g+Bu+J^T\lambda$ 里的 $\lambda$（可跑，对照 2.6 方程 (1)）

** toy：平面一个点质量"脚"，浮动基 $(x,z)$，要求"脚钉在原点"（接触约束 $x=0,z=0$）。给定"想让它产生的加速度"，解出接触力 $\lambda$**。

```python
import numpy as np
m=1.0; g=9.81
# 浮动基无接触: M q̈ = τ_g + Bu, q=[x,z], M=mI, τ_g=[0,-mg]
M = m*np.eye(2); tau_g = np.array([0., -m*g]); B_u = np.array([0.,0.])  # 无控制
# 接触约束: 脚钉原点 -> J=I (约束 x=0,z=0), 加速度约束 q̈=0
J = np.eye(2)
# 方程(1): M q̈ = τ_g + Bu + Jᵀ λ, 加约束 q̈=0 (脚不动)
# => 0 = τ_g + Bu + Jᵀ λ  =>  λ = -(Jᵀ)⁻¹(τ_g+Bu) = -(τ_g+Bu)  (J=I)
qdd_des = np.array([0.,0.])                       # 接触期脚加速度=0
lam = np.linalg.solve(J.T, M@qdd_des - tau_g - B_u)
print("接触力 λ =", np.round(lam,3), " (z方向=+mg 顶住重力, x方向=0)")
# 验证摩擦锥: |λx| <= μ λz ?
mu=0.5
print("摩擦锥满足? |λx|=%.3f <= μ λz=%.3f ? %s" % (abs(lam[0]), mu*lam[1], abs(lam[0])<=mu*lam[1]))
```

**你会看到**：**$\lambda_z=+mg$（地面顶住重力）、$\lambda_x=0$**——**这就是方程 (1) 里"接触力 $\lambda$ 由约束解出"的最简演示**。**改 $q̈_{des}$**（比如想让脚水平加速但又被钉住，矛盾）或加控制 $Bu$，**看 $\lambda$ 怎么变、何时出摩擦锥（脚要滑）**——**这就是练习 17.1 (d) "接触力在摩擦锥内"要检查的东西**。

### 实验 5：接触隐式优化思想 —— 互补约束 $\lambda\ge0,g\ge0,\lambda g=0$（骨架，对照 17.2）

**展示"接触隐式"如何把"接触/不接触"写进优化**——**用 penalty 松弛互补约束，让 scipy 自己决定"踩不踩地"**。

```python
import numpy as np
from scipy.optimize import minimize
m=1.0; g=9.81; mu=0.6
# 决策: 接触力 λz (>=0), 间隙 g (>=0); 互补 λz*g≈0 用 penalty
# 物理: 脚垂直运动 m z̈ = -mg + λz; 接触时 g=0,z̈>=0; 离地时 λz=0,g>=0
# 简化静态: 给定"想要的z̈", 求自洽的 (λz,g)
def cost(vars_, zdd_want):
    lamz, gap = vars_
    pen = 0.0
    if lamz < 0: pen += 1e6*lamz**2          # λz>=0
    if gap < 0:  pen += 1e6*gap**2           # g>=0
    pen += 1e4*(lamz*gap)**2                 # 互补 λz*g=0
    # 物理自洽: 若 gap==0 (接触) 则 z̈ 由 λz 定; 若 λz==0 则 z̈=-g
    # 这里用软约束: 希望 (gap>0 => λz=0) 且 (λz>0 => gap=0 且 z̈=zdd_want)
    zdd = (-m*g + lamz)/m
    pen += 1e2*((gap<1e-6)*(zdd-zdd_want))**2   # 接触时加速度=想要值
    return pen
# 例: 想让脚"踩地且 z̈=0"(站着) -> 应解出 λz=mg, gap=0
res = minimize(cost, [m*g, 0.0], args=(0.0,), method='Nelder-Mead')
print("想站着: λz≈%.3f (应=mg=%.3f), gap≈%.3f (应=0)" % (res.x[0], m*g, res.x[1]))
# 例: 想让脚"离地 z̈=-g"(自由落体) -> 应解出 λz=0, gap>0
res2 = minimize(cost, [0.0, 0.1], args=(-g,), method='Nelder-Mead')
print("想离地: λz≈%.3f (应=0), gap≈%.3f (应>0)" % (res2.x[0], res2.x[1]))
```

**你会看到**：**"想站着"→ 优化器自己给出 $\lambda_z=mg,\ g=0$（接触）；"想离地"→ $\lambda_z=0,\ g>0$（腾空）**——**没人告诉它"该接触还是该离地"，互补约束 $\lambda g=0$ 让它自己选**——**这就是 17.2 接触隐式优化的核心思想**：**把"接触开关"编码进互补约束，优化器自决**。**真实接触隐式轨迹优化 = 把这个互补约束铺在整条轨迹的每个时间点上**（[5] 的 direct method）。

## 给初学者的"本章通关三句话"

1. **接触让方程"会瞬跳、会卡住"，用混合系统的"模式+守卫+重置"统一描述**：每个"脚的状态"是一个**模式**（连续动力学），**脚碰地=守卫 $\phi=0$ 触发**，**撞地那一下速度跳变=重置 $\Delta$**——**整条走路轨迹 = 被触发器串起来的一串连续片段**。
2. **混合轨迹优化 = 把多段连续轨迹"缝"成一个优化**：段内用该模式的直接配置，**段间用 $\phi=0$（踩中机关）+ $x^+=\Delta(x^-)$（穿传送门）缝合**，**途中加 $\phi>0$（不许误撞）**；**若不想剧透模式序列，就用直接射击"穿过 guard/reset 取梯度"，但必须补 saltation 矩阵修正"接触时刻漂移"，否则梯度是错的**。
3. **建模两派 + 接触隐式 = 通用性的两级跳**：**最小坐标法**为每种接触手写方程（精简但累），**浮动基法**一次推导、把接触当约束力 $J^T\lambda$ 加进 $M\ddot q+\cdots=\tau_g+Bu+\sum J^T\lambda$（通用，且 $\lambda$ 当变量后才能加摩擦锥约束）；**而接触隐式优化更进一步，用互补约束 $\lambda\ge0,g\ge0,\lambda g=0$ 让优化器自己决定"何时接触、接触哪"**——**从"你给剧本"到"机器人自己编剧本"**，**这正是 [5]/[7] 在啃的"接触非凸"硬骨头，也是练习 17.1 让你用浮动基+摩擦接触编码五条物理规矩、搜出圆规步态极限环的实战目标**。
