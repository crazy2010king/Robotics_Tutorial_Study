## 🎲 一、为什么需要"鲁棒与随机控制"：三个生活场景

### 场景1：无人机在风中飞行
你设计了一个完美的 LQR 控制器让四旋翼悬停。但外面刮风了——风是**时间相关的随机扰动**，不是简单的"白噪声"。你的控制器还管用吗？

### 场景2：机器人抓取未知重量的物体
机械臂去抓杯子，但杯子里可能有水也可能没水。物体的**动力学参数未知**，你的控制器能适应吗？

### 场景3：火星探测器在未知地形行驶
地面摩擦系数、坡度都不确定。你需要一个**"最坏情况也能不出事"**的控制器——这就是"鲁棒控制"的核心诉求。

📌 **教材的精确表述**：随机性有多种形式——我们可能不知道支配方程（如关节摩擦系数）、机器人可能在未知地形上行走、受到未知扰动、甚至抓取未知物体 。

### 核心建模思路

把所有不确定性打包成一个新的"随机输入信号" w：
$$\dot{x} = f(x, u, w, t) \quad \text{或} \quad x[n+1] = f(x[n], u[n], w[n], n)$$

**为什么用离散时间？** 教材选择主要讨论离散时间系统，因为记号更简洁、直觉更清晰。连续时间的维纳过程（Wiener process）虽然也可处理，但离散时间 w[n] 作为"每步的随机冲击"更好理解 。

## 📊 二、随机系统的代价与约束：六种写法

既然 x[n] 现在是随机变量，怎么写"代价函数"来捕捉我们关心的性能？教材给出了**六种自然选择** ：

### 1. 期望分布（Desired state distribution）
指定一个"理想状态分布" $p^d_n(x)$，最小化实际分布与它的差异。直观但计算困难。

### 2. 平均代价（Average cost）⭐ 最常用
$$\min_u \mathbb{E}\left[\sum_n \ell(x[n], u[n])\right]$$
**这是强化学习的标准形式**——因为它保持了动态规划的递归结构。

### 3. 最坏情况代价（Worst-case cost）
$$\min_{u[\cdot]} \max_{x[0], w[\cdot]} \sum_n \ell(x[n], u[n])$$
如果能为这个代价上界提供保证，就叫**"保证代价控制"（Guaranteed Cost Control）**。

### 4. 相对最坏情况（Relative worst-case / Gain bounds）
对线性系统，给绝对性能定界会得到**空洞的界**（vacuous bounds）。更好的做法是**相对评估**——把性能度量**相对于扰动输入的幅度**来评估。这就是后面要讲的 **L₂ gain**。

### 5. 风险价值（VaR）与条件风险价值（CVaR）
来自经济学：VaR(α) 是"忽略尾部概率不超过 α 的最坏情况"。VaR 直观但数学性质不好；**CVaR 有更好的数学性质，且与凸优化有深刻联系** 。

### 6. Regret 公式
最小化"设计的控制器"与"拥有特权信息的最优控制器"之间的差异。在线优化领域流行，控制领域也开始有"regret bounds"。

### 约束的随机化推广

确定性的约束 $g(x) \leq 0$ 怎么推广？

- **机会约束（Chance constraints）**：$P(g(x) > 0) \leq \alpha$。例如保证飞机撞树的概率小于 α。即使高斯不确定性+多面体约束，精确计算也很难，常需近似 。
- **最坏情况约束**：α→0 时的极限，计算更友好，与可达性分析直接相连。

> 💡 **"鲁棒控制" vs "随机控制"的术语区分**：
> - **鲁棒控制** = 保证最坏情况性能或最坏情况界（如 gain bounds）
> - **随机控制** = 推理随机性但不提供严格鲁棒性保证的其他方法 
>
> 鲁棒控制的哲学：建模真实随机性的分布太难，不如只定义"随机变量可能取值的集合"——"只要峰值阵风低于 35mph，这架无人机就不会坠毁"比要求详细的风速概率分布更实用。但代价是：**最坏情况证书通常过于悲观，优化最坏情况性能会导致保守的设计** 。

## 🎯 三、随机 LQR：噪声让代价发散，但最优反馈不变

### 3.1 问题设定

离散时间线性系统受加性高斯白噪声：
$$x[n+1] = A x[n] + B u[n] + w[n]$$
$$E[w[i]] = 0, \quad E[w[i]w^T[j]] = \delta_{ij}\Sigma_w$$

平均代价：
$$\min \mathbb{E}\left[\sum_{n=0}^\infty x^T[n]Qx[n] + u^T[n]Ru[n]\right]$$

### 3.2 第一个惊人发现：代价到无穷大！

教材诚实地指出 ：线性系统受高斯噪声后，状态会有高斯稳态分布——**系统无法驱动状态到零并停留在零**（否则噪声会持续累积代价）。所以**无穷时域代价是无穷大的**！

但是！代价虽然发散，它仍有足够的**结构**让我们继续工作。

### 3.3 贝尔曼方程与里卡蒂方程

我们"猜"代价函数的形式：
$$J_n(x) = x^T S_n x + c_n$$

推导贝尔曼方程时，关键一步：**x 和 u 与 w 不相关，且 E[w]=0，所以交叉项的期望为零**。

剩下的项与确定性 LQR 完全相同，除了多了一个常数项 $tr(\Sigma_w S_{n+1})$：

$$J_n(x) = \min_u \left[x^TQx + u^TRu + (Ax+Bu)^TS_{n+1}(Ax+Bu) + c_{n+1} + tr(\Sigma_w S_{n+1})\right]$$

**结论** ：
- $S_n$ 满足离散里卡蒂方程，收敛到代数里卡蒂方程的稳态解
- $c_n = c_{n+1} + tr(\Sigma_w S_{n+1})$，随着 n→∞ 增长到无穷
- **但最优控制仍然是 $u^* = -Kx$，与确定性 LQR 完全相同！**

> 💡 **"确定性等价原理"（Certainty Equivalence）** ：对集中式线性系统+加性噪声+二次代价，最优控制与没有噪声时完全相同。这是随机控制中最漂亮的结论之一。

### 3.4 如何处理代价发散？

强化学习中常用的两个技巧 ：
1. **折扣代价**：$\sum \gamma^n \ell(x[n], u[n])$，$0<\gamma<1$
2. **平均代价**：$\lim_{N\to\infty} \frac{1}{N}\sum_{n=0}^N \ell(x[n], u[n])$

### 3.5 非独立同分布扰动：相关噪声怎么办？

许多扰动是时间相关的——比如风。标准风模型是**高斯白噪声通过线性低通滤波器**的输出 。

**天才的处理方法**：把"风+无人机"作为**联合系统**来设计 LQR 控制器：
$$u = -K\begin{bmatrix} x_{uav} \\ x_{wind} \end{bmatrix}$$

实践中，控制器需要依赖**在线风状态估计器**（除了标准的无人机状态估计器）。

## 🛡️ 四、有界不确定性下的最坏情况控制

### 4.1 公共李雅普诺夫函数回顾

我们在第9章见过一个很好的鲁棒性分析例子：寻找**公共李雅普诺夫函数**来证明不确定线性系统的稳定性。那时研究的是 $x[n+1]=Ax[n]$，其中 A 的系数未知但有界。

同样的技术可以认证**抗扰动**的稳定性：
$$x[n+1] = A x[n] + w[n], \quad w[n] \in \mathcal{W}$$

其中 $\mathcal{W}$ 描述可能的扰动集合。为兼容凸优化，$\mathcal{W}$ 通常选为椭球或多面体 。

> ⚠️ **重要认识**：在有加性扰动的情况下，我们**不能再期望系统稳定收敛到原点**。之前的例子用公共李雅普诺夫函数只认证了**区域的不变性**——如果我从一个区域内出发，就永远停留在该区域内 。

### 4.2 多胞体动力学（Polytope Dynamics）

**多胞体（Polytope）**是有界多面体。两种常见表示：
- **H-rep（半空间表示）**：$Hx \leq h$
- **V-rep（顶点表示）**：顶点的凸包

为优化方便，教材引入 **AH-多胞体（AH-polytope）**：
$$X = \mathcal{AH}(T, t, P) := \{Tx + t \mid x \in P \subset \mathbb{R}^m\}$$

**AH-多胞体的美妙性质** ：
- **仿射变换封闭**：$AX + b = \mathcal{AH}(AT, Ab + b, P)$
- **闵可夫斯基和封闭**：给定 $X, Y$，有 $X \oplus Y = \mathcal{AH}\left([T_x, T_y], t_x + t_y, \mathcal{H}\begin{bmatrix} H_x & 0 \\ 0 & H_y \end{bmatrix}, \begin{bmatrix} h_x \\ h_y \end{bmatrix}\right)$

**不确定线性系统的传播** ：
$$x[n+1] = A x[n] + w[n], \quad x[0] \in X_0, w[n] \in W$$
$$X_{n+1} = A X_n \oplus W$$

> ⚠️ **关键细节**：由于与 W 的闵可夫斯基和，多胞体的描述大小**每一步都在增长**。长时间传播后集合会变得非常复杂。

### 4.3 鲁棒 MPC：Tube MPC

把上述多胞体传播与反馈控制结合：
$$x[n+1] = A x[n] + B u[n] + w[n]$$
$$X_{n+1} = (A X_n + B u_n) \oplus W$$

这就是著名的 **Tube MPC**（管模型预测控制）：优化 $u_n$ 和 $X_n$ 的描述，使用凸优化服从这些线性动力学。可以进一步结合**扰动反馈参数化**同时搜索时变反馈增益 $K_n$ 。

### 4.4 多胞体包含（Polytopic Containment）

一个常见优化目标：最终时刻的整个可达集都在目标集内，即 $X_N \subseteq X_{goal}$。

检查这个条件是计算几何中的经典问题。Sadraddini & Tedrake 2019 给出了**只用线性约束的高效编码**来认证包含关系；他们 2021 年的工作给出了**充分必要**的条件，但可能需要指数数量的线性约束 。

具体方程略复杂，但关键洞察是：在线性约束中，$T_x, t_x, t_{\hat{x}}, h_{\hat{x}}$ 与包含决策变量**线性出现**，可以同时优化。不幸的是，$T_{\hat{x}}, H_x, h_x, \hat{H}_{\hat{x}}$ 与包含决策变量**双线性出现**，所以通常视为固定 。

## 🔄 五、扰动反馈参数化：绕过双线性陷阱

### 5.1 问题：双线性困境

在鲁棒 MPC 框架中，把反馈增益 $K_n$ 作为决策变量看似诱人，但传统参数化 $K_n x_n$ 中同时搜索 $K_n$ 和 $x_n$ 会导致**双线性（从而非凸）**问题。

### 5.2 扰动反馈参数化：Youla 参数化

老但重要的想法：**Youla 参数化**（或称 Q-参数化）。时域中通常导致"随时间展开"的控制器，依赖**可能无限的扰动历史**。常见实践是**用有限冲激响应（FIR）截断**来近似 。

### 5.3 输出反馈策略的参数化

考虑如下参数化 ：
$$u[n] = K_0[n]x_0 + \sum_{i=1}^{n-1} K_i[n]w[n-i]$$

闭环状态在控制参数 K 中是**凸的**：
$$x[n] = \left(A^n + \sum_{i=0}^{n-1}A^{n-i-1}B K_0[i]\right) x_0 + \sum_{j=0}^{n-1}\sum_{i=0}^{n-1}A^{n-i-1}B K_j[i]w[i-j]$$

因此，在 x 和 u 中凸的目标（如 LQR）在 K 中也是凸的！而且，给定我们对 $x[n+1], x[n]$ 的观测和 $u[n]$ 的知识，我们能在需要时计算出 $w[n]$。

> 💡 **这是鲁棒 MPC 中同时优化时变反馈增益的数学基础**——Sadraddini & Tedrake 2020 将其应用于鲁棒输出反馈控制并保证约束满足 。

## 📐 六、L₂ Gain：相对增益界

### 6.1 为什么需要相对界？

通过限制 w 取自**有界（多面体）集**，我们能有效做可达性分析。但利用 w 的线性依赖性，可以做**更自然、更紧**的界：系统响应（与无扰动情况的偏差）的幅度与扰动 w 的幅度**成比例**。

### 6.2 L₂ Gain 定义

典型的标量 "L₂ gain" γ：
$$\min_\gamma \quad \text{s.t.} \quad \sup_{w[\cdot] \in \sum_n\|w[n]\|^2 \leq \infty} \frac{\sum_0^N \|z[n]\|^2}{\sum_0^N \|w[n]\|^2} \leq \gamma^2$$

其中 z[n] 是**性能输出**：
$$z[n] = \begin{bmatrix} \sqrt{Q}x[n] \\ \sqrt{R}u[n] \end{bmatrix}$$

**直觉**：L₂ gain 衡量"输出能量"与"输入能量"之比的上界。γ 越小，系统对扰动的抑制能力越强。

### 6.3 H₂ 范数与 H∞ 范数

- **H₂ 范数**：系统从输入 w 到输出 z 的脉冲响应能量；当 z 如上表示二次调节代价时，对应于期望 LQR 代价
- **H∞ 范数**：系统从 w 到 z 的传递函数的最大奇异值；**对应于 L₂ gain** 

### 6.4 耗散不等式（Dissipation Inequalities）

认证系统 L₂ gain 的机制之一，是**将李雅普诺夫分析推广**以考虑系统输入的贡献——所谓"耗散不等式" 。

核心思想：将李雅普诺夫条件 $V(x) \succ 0, \dot{V}(x) \preceq 0$ 推广为更一般的形式：
$$V(x) \succ 0, \quad \dot{V}(x) \preceq s(x, w)$$

其中 w 是感兴趣的输入，s() 是代表"供给率（supply rate）"的标量。

两边对时间积分：
$$\forall x(0), \quad V(x(T)) \leq V(x(0)) + \int_0^T s(x(t), w(t)) dt$$

### 6.5 L₂ Gain 的耗散不等式形式

为获得从输入 w 到输出 z 的 L₂ gain 界，感兴趣的供给率是：
$$s(x, w) = \gamma^2\|w\|^2 - \|z\|^2$$

这产生：
$$\forall x(0), \quad V(x(T)) \leq V(x(0)) + \int_0^T \gamma^2\|w(t)\|^2 dt - \int_0^T\|z(t)\|^2 dt$$

由于这对所有 x(0) 成立，它对 x(0)=0 也成立。且 V(x(T)) 非负，所以：
$$0 \leq V(x(T)) \leq \int_0^T \gamma^2\|w(t)\|^2 dt - \int_0^T\|z(t)\|^2 dt$$

因此，如果能找到满足上述耗散不等式的 V，我们就认证了 γ 是系统的 L₂ gain：
$$\frac{\int_0^T\|z(t)\|^2 dt}{\int_0^T\|w(t)\|^2 dt} \leq \gamma^2$$

## 🎖️ 七、鲁棒 LQR 即 H∞ 控制

### 7.1 鲁棒 LQR 问题

考虑 LQR 的鲁棒变体 ：
$$\min_{u[\cdot]} \max_{w[\cdot]} \sum_{n=0}^\infty x^T[n]Qx[n] + u^T[n]Ru[n] - \gamma^2 w^T[n]w[n]$$
$$x[n+1] = A x[n] + B u[n] + B_w w[n]$$

**为什么这样选代价函数？** 直觉是：我们奖励控制器对大 w 的小响应。

**注意与随机 LQR 的关键区别** ：这里**不指定 w[n] 的分布**，甚至不限制它有界。我们只知道每步一个"全知的对手"可以选择 w[n] 来最大化这个目标。

为简洁，教材在连续时间做推导：
$$\min_{u[\cdot]} \max_{w[\cdot]} \int_0^\infty \left[x^T Q x + u^T R u - \gamma^2 w^T w\right] dt$$
$$\dot{x} = A x + B u + B_w w$$

### 7.2 求解：博弈论的里卡蒂方程

再次猜二次代价函数 $J(x) = x^T S x$。贝尔曼方程：
$$\forall x, \quad 0 = \min_u \max_w \left[x^T Q x + u^T R u - \gamma^2 w^T w + \frac{\partial J^*}{\partial x}[Ax + Bu + B_w w]\right]$$

**先解对手（最大化者）**：
$$\frac{\partial}{\partial w} = -2\gamma^2 w^T + 2x^T S B_w$$
$$w^* = \frac{1}{\gamma^2} B_w^T S x$$

**再解控制者（最小化者）**：
$$\frac{\partial}{\partial u} = 2u^T R + 2x^T S B$$
$$u^* = -R^{-1}B^T S x = -Kx$$

代入贝尔曼方程得到：
$$0 = Q + S\left[\gamma^{-2}B_w B_w^T - BR^{-1}B^T\right]S + S^TA + A^TS$$

这就是**原来的 LQR 里卡蒂方程，多了一项含 γ 的项**。

### 7.3 γ 的阈值现象

如果系统可控且 γ 足够大，方程有正定解 S≻0。但随着 γ 向零减小，**会有一个阈值 γ，低于它里卡蒂方程就没有正定解**。

直觉：γ 太小时，对手被奖励注入如此大的扰动以至于破坏收敛 。

### 7.4 鲁棒 LQR = H∞ 控制

神奇的事 ：这个鲁棒 LQR 代价函数中的 γ 可以被解释为系统的 L₂ gain。回顾贝尔曼方程与李雅普诺夫方程的联系，可以得到：
$$\forall x, \quad \dot{J}^*(x) \leq \gamma^2 w^T(t)w(t) - x^T(t)Qx(t) - u^T(t)Ru(t)$$

这意味着代价到函数是对供给率的**有效耗散不等式**，为性能输出 $z = \begin{bmatrix} \sqrt{Q}x \\ \sqrt{R}u \end{bmatrix}$ 提供 L₂ gain。

而且，我们可以通过**寻找最小的 γ>0** 使得里卡蒂方程有正定解，来找到**最小的 L₂ gain**。由于里卡蒂方程的性质，这可以通过对 γ 的**线搜索**完成。

**因为 L₂ gain 是系统的 H∞ 范数**，所以搜索最小 γ 并取里卡蒂解的方法就是 **H∞ 控制设计的一个实例**。

> 💡 **深刻理解**：鲁棒 LQR（博弈论形式）与 H∞ 控制（L₂ gain 最小化）是**同一枚硬币的两面**。这是鲁棒控制理论最优雅的结论之一。

## 🌊 八、线性指数二次高斯（LEQG）

Jacobson 1973 观察到 ：可以最小化目标
$$J = \mathbb{E}\left[\prod_{n=0}^\infty e^{x^T[n]Qx[n]} e^{u^T[n]Ru[n]}\right] = \mathbb{E}\left[e^{\sum_{n=0}^\infty x^T[n]Qx[n] + u^T[n]Ru[n]}\right]$$

由于代价与 log J 单调相关，因此有相同的最小值（同样的技巧构成了"几何规划"的基础 ）。

**这就是 LEQG（线性指数二次高斯）**：
- **确定性版本**（无过程噪声和测量噪声）：解与 LQR 问题**完全相同**，不增加建模能力
- **有噪声时**：LEQG 最优控制器**不同于 LQG**，它们**显式依赖于噪声的协方差**

Whittle 1990 对此框架做了广泛处理 ：几乎所有 LQR/LQG 的分析（包括里卡蒂方程、哈密顿公式等）都有指数代价版本的对应物，他认为 LQG 和 H∞ 控制都可以（应该？）理解为这种方法的特例。

## 🧠 九、自适应控制：在线的模型更新

### 9.1 两个批评

- **对 H₂ 最优控制的批评**：最小化期望值不提供任何性能保证
- **对 H∞ 最优控制的批评**：关注最坏情况，因此可能过于保守——尤其是预先选择的扰动分布可能不必要地保守

### 9.2 希望：在线适应

如果能在线更新不确定性模型，适应实际接收扰动的统计特性，或许能找回一些性能。这是**自适应控制**的目标之一。

### 9.3 探索与利用的权衡

在线自适应控制的基本问题：**探索与利用的权衡**。某些输入可能驱动系统快速建立更准确的动力学/不确定性模型，从而带来更好的性能。但如何形式化这个权衡？

### 9.4 多臂老虎机（Multi-Armed Bandit）的启示

机器学习中在（上下文）多臂老虎机问题上取得了不错进展。可以把老虎机理解为最优控制问题的一个极限情况——没有动力学（一个控制动作的效果不影响下一个控制动作的结果）。

在这个简化设定下，在线优化社区开发了基于**最小化后悔（regret）**的探索-利用策略——通常是我的在线算法实现的性能与"如果我开始前就掌握实验数据"会实现的性能之间的累积差异。

这导致了利用 **UCB（上置信界）** 概念的方法，以及最近使用**最小二乘置信界**的方法 来提供后悔界。

过去几年，我们看到这些结果被转化到线性最优控制的设定中……

### 通俗性补充（针对基础薄弱读者的额外解释）

1. **"确定性等价原理"为什么叫这个名字？** 因为最优控制与"假设没有噪声"时完全相同——仿佛控制器"假装"系统是确定性的，但奇迹般地这对随机系统也是最优的。

2. **为什么代价到无穷大但最优反馈不变？** 想象一个浴缸：水龙头不断加水（噪声），排水口也在排水（系统动力学）。稳态时水位（状态协方差）恒定，但水一直在流动——所以总"水量"（总代价）是无限的。但"水位多高"（反馈增益 K）由浴缸形状（A, B, Q, R）决定，与水龙头流速无关。

3. **H∞ 控制 vs H₂ 控制的通俗对比**：
   - **H₂ 控制**："平均意义上表现好"——像买保险，期望损失最小，但极端情况可能很糟
   - **H∞ 控制**："最坏情况也能接受"——像防弹衣，保证即使最坏的子弹也打不穿，但平时穿起来笨重

4. **Tube MPC 的直觉**：想象机器人在走廊里走。机器人本体是一个点，但"安全走廊"是一个管道（tube）。控制器保证机器人始终在管道内，而管道本身在传播时考虑扰动边界。这就像给机器人划了一条"安全隧道"。

5. **Youla 参数化为什么强大？** 传统反馈 u = Kx 中 K 和 x 相乘导致双线性。Youla 参数化改为 u = K₀x₀ + ΣKᵢw[i]，让 u 对参数 K 是线性的——凸优化可以求解！这就像把"乘法"问题通过引入新变量转化为"加法"问题。

6. **LEQG 的指数代价意味着什么？** 平方代价惩罚大误差是"温和的"；指数代价惩罚大误差是"严厉的"——指数增长意味着偶尔的大误差会让总代价爆炸。所以 LEQG 控制器**极度厌恶大误差**，对噪声协方差敏感。这与 H∞ 的"最坏情况"哲学相通。

### 实验五：鲁棒 LQR 即 H∞ 的线搜索

**目的**：通过线搜索 γ 找到最小 L₂ gain。

**动手要点**：
```python
def h_infinity_lqr(A, B, B_w, Q, R):
    """找到最小的 γ 使得里卡蒂方程有正定解"""
    def riccati_has_pd_solution(gamma):
        # 求解修正里卡蒂方程：
        # 0 = Q + S(γ⁻² B_w B_w^T - B R⁻¹ B^T)S + S^T A + A^T S
        # 返回 S 是否正定
        S = solve_riccati_modified(A, B, B_w, Q, R, gamma)
        return np.all(np.linalg.eigvals(S) > 0)
    
    # 线搜索最小 γ
    gamma_low, gamma_high = 0.1, 100.0
    while gamma_high - gamma_low > 1e-6:
        gamma_mid = (gamma_low + gamma_high) / 2
        if riccati_has_pd_solution(gamma_mid):
            gamma_high = gamma_mid
        else:
            gamma_low = gamma_mid
    
    gamma_opt = gamma_high
    S_opt = solve_riccati_modified(A, B, B_w, Q, R, gamma_opt)
    K = R⁻¹ B^T S_opt
    return K, gamma_opt, S_opt

# 测试：对不同的 B_w 观察 γ_opt 的变化
# γ_opt 越小，系统对扰动的抑制能力越强
```

**预期现象**：
- 当 B_w 很大（扰动通道强）时，γ_opt 较大
- 当 B_w 很小（扰动通道弱）时，γ_opt 较小
- 存在 γ 的阈值，低于它里卡蒂方程无解

## 🎁 十二、整体综合：鲁棒与随机控制在机器人栈中的真正地位

把这一章放到整个机器人控制版图里看：

```
确定性控制（LQR/LQG/MPC）
    ↓ 现实世界有不确定性
随机建模（w[n] 捕获所有随机性）
    ↓ 两条路线
路线A：平均代价优化（H₂/LQG）→ 期望性能好但无保证
路线B：最坏情况优化（H∞/Tube MPC）→ 有保证但保守
    ↓ 结合
自适应控制（在线更新模型）+ 域随机化（Sim2Real）
    ↓ 进一步结合
MPC + RL + World Model + HALOS 安全层
```

### 五个最关键的认识

1. **确定性等价原理**：对线性系统+加性噪声+二次代价，最优反馈与无噪声时完全相同——这是随机 LQR 最漂亮的结论

2. **鲁棒 vs 随机的权衡**：H₂ 优化平均性能但无保证；H∞ 优化最坏情况但有保证且保守

3. **Tube MPC**：通过多胞体传播显式处理扰动边界，保证"机器人始终在安全隧道内"

4. **H∞ = 鲁棒 LQR**：通过博弈论里卡蒂方程求解；γ 既是代价函数的参数，也是 L₂ gain；线搜索最小 γ 即 H∞ 控制设计

5. **LEQG 是统一框架**：LQG 和 H∞ 都可以理解为 LEQG 的特例

### 对工程实践的五个启示

1. **风/扰动建模用增广系统**：把扰动动力学（如低通滤波的风）作为系统的一部分，联合设计 LQR——这比"忽略风"的 LQR 效果好得多

2. **多胞体传播描述大小会爆炸**：长时间传播需用"最小体积多胞体近似"来限制复杂度，代价是保守性增加

3. **Youla 参数化绕开双线性**：将扰动历史作为状态增广，用 FIR 截断，让反馈增益的搜索变成凸优化问题

4. **H∞ 控制通过线搜索 γ 实现**：对修正里卡蒂方程做二分搜索，找到最小的正定解 γ

5. **自适应控制是活跃前沿**：探索-利用权衡、UCB、最小二乘置信界——这些机器学习技术正在进入线性控制理论
