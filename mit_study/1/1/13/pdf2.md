## 1. 随机模型（13.1）—— 把"捣乱的世界"塞进方程

### 1.1 不确定从哪来？

>  finora 我们主要关心**已知、确定**的系统。在随机系统章我们开始研究**非线性随机动力学**（很美！）。本章开始考虑**分析和控制这些系统的计算工具**。

> **随机性有很多形式**……我们可能**不知道控制方程**（如关节摩擦系数），机器人可能**走在未知地形上**、**受未知扰动**、甚至**抓取未知物体**。

**类比（四种"不知道"，必懂）**：
1. **模型参数不知道** = 你买了辆二手车，**不知道刹车片磨成啥样**（摩擦系数未知）。
2. **环境不知道** = 你**闭着眼开车**，不知道前面是柏油路还是冰面（地形未知）。
3. **扰动不知道** = 突然**一阵横风**把车吹偏（外部扰动）。
4. **任务不知道** = 你伸手去抓，**不知道杯子里有没有水**（抓取未知物体）。

### 1.2 统一的数学形式：加一个 $w$

> 有许多数学框架处理这种不确定；本章我们把思路推广到这种形式的方程：

$$\dot x = f(x,u,w,t)\quad\text{或}\quad x[n+1]=f(x[n],u[n],w[n],n)$$

> 其中 $w$ 是一个**新的随机输入信号**，** capturing 所有这些潜在的可变性**。虽然完全可以在连续时间做、把 $w(t)$ 当连续时间随机信号（如 Wiener 过程），但**记号和直觉在离散时间 $w[n]$ 下更简单**。所以本章专注离散时间系统。

**人话**：**和你前几章的方程相比，只多了一个 $w$**——**这个 $w$ 就是"世界捣乱的那只手"**。它**同时**代表了上面四种"不知道"。

### 1.3 怎么定义 $w$ 的"性格"？—— i.i.d. 与白化滤波

> 要仿真这种方程、或针对它设计控制器，我们得**定义产生 $w$ 的随机过程**。通常假设**独立同分布（i.i.d.）**，即 $w[i]$ 和 $w[j]$ 在 $i\ne j$ 时**不相关**。因此我们通常用**概率密度** $w[n]\sim p_w(w)$ 定义分布。

> **这没听起来那么受限**……若想处理**时间相关的噪声**（如"有色噪声 colored noise"），我们的方程格式**足够丰富**——**加额外的状态变量**就行；下面会举一个**给阵风建模的"白化滤波器（whitening filter）"** 的例子。

**类比（白噪声 vs 有色噪声，必懂）**：
- **i.i.d. 白噪声** = **每秒独立掷一次骰子**——这一秒的风和下一秒的风**毫无关系**（电视雪花）。
- **有色噪声** = **真实的阵风**——**风不会一秒内从 0 飙到 10 级又回 0**，它**有惯性、有持续**，这一秒的风和下一秒**高度相关**。
- **怎么把"有色"变"白"来建模**？**白化滤波器** = 你**承认风是"白噪声过一个低通滤波器"的产物**——**白噪声是"原料"，低通滤波器把它"抹平滑"成真实的阵风**。于是**把"滤波器的内部状态"也加进系统状态**，**原料就又是白的了**——**这就是"加额外状态变量"的含义**（13.4.1 会用到）。

### 1.4 初始条件的随机 + Drake 的"更一般"情况

> 我们将考虑的**另一个随机源** = **初始条件的随机**；同样用概率密度 $x[0]\sim p_0(x)$ 定义。

> 这个建模框架**足够丰富**，能传达关键思想；但**对我感兴趣的某些系统还不够**。在 Drake 里我们**额外下功夫**支持更一般的随机系统，包括：**每次模型初始化时随机抽取、但在一次仿真期间固定**的系统参数；把它们建模成"无动力学的额外状态变量"是**可能但低效**的。

> **在另一些问题里，连状态向量的维度都可能在不同实现里变化！** 比如**机器人在水槽里操作随机数量的盘子**。我不知道有多少控制表述能好好处理这种随机，**我认为这是该多想的高优先级问题！**（我们会在输出反馈章开始触及。）

**类比（"参数随机" vs "维度随机"，必懂）**：
- **参数随机** = 你**每次出门前抽一张牌**，牌上写着"今天车重 1000kg 还是 1200kg"，**抽完这一天就定了**——**车重在一次行程里不变，但你不知道抽到哪张**。
- **维度随机** = 你**每次出门，车上坐几个人都不一定**——**连"要管几个变量"都变了**！水槽里**盘子是 3 个还是 7 个**，状态维度直接不同。**这是控制论至今没解决好的硬骨头**。

## 2. 随机系统的代价与约束（13.2）—— "打包票"的标准怎么选？

> 有了随机模型，**该写什么样的代价函数**，才能捕捉我们想要的性能？有很多自然选择，在"捕捉想要的现象"和"算得动"之间做权衡。

> 记住 $x[n]$ **现在是随机变量**，所以我们要**用分布**写代价和约束。 broadly，代价可以这么指定：

### 2.1 六种代价形式（逐个翻译）

**① 期望状态分布（Desired state distribution）**
> 你可以**用"期望的状态分布" $p_d^n(x)$ 指定目标**，然后**最小化"实际分布"与"期望分布"的差异**。
**类比**：你不要求车**精确停在某个点**，你要求"**停车位置的散布**长得像某个钟形"——**比如 90% 停在车位内**。

**② 平均代价（Average cost）—— 最流行**
> $\mathbb{E}[\sum_n \ell(x[n],u[n])]$，或它的时间平均/折扣变体。**这是迄今为止最流行的选择（尤其 RL）**，**因为它保留了加性代价的动态规划递归**。
**类比**：**精算师算"长期平均赔多少"**——**和 RL 的"期望回报"是一回事**。

**③ 最坏情况代价（Worst-case cost）**
> $\min_{u[\cdot]}\max_{x[0],w[\cdot]}\sum_n \ell(x[n],u[n])$。当我们能**给这个代价一个上界并往下压**时，有时叫 **guaranteed cost control（保证代价控制）**。
**类比**：**悲观工程师算"哪怕最倒霉，最多赔多少"**——**然后把这个"最多"尽量压低**。

**④ 相对最坏情况 / 增益界（Relative worst-case / gain bounds）**
> 即使对线性系统，**界住绝对性能（对所有 $w$）也会导致空洞的界**；**相对扰动输入的幅值**评估性能，能做得好得多。
**类比**：你不问"**风多大时车偏多少**"（绝对，风无穷大偏无穷大，没意义），你问"**车偏的幅度 / 风的幅度 ≤ 多少**"（**相对，一个比值**）——**这就是"增益"，13.4.4 的主角**。

**⑤ VaR 与 CVaR（风险价值 / 条件风险价值）**
> 来自经济学和运筹学。$\text{VaR}(\alpha)$ = **忽略分布尾部**（合计概率至多 $\alpha$ 的更坏结果）后的**最大代价**。VaR 好懂，但相关的 **CVaR 数学性质更好**，包括**与凸优化的连接** [3]。
**类比（买保险，必懂）**：
- **VaR** = "**99% 的情况下，我最多亏 1 万**"——**但那 1% 的"黑天鹅"亏多少，它不管**（可能亏 100 万！）。
- **CVaR** = "**在那最倒霉的 1% 里，我平均亏多少**"——**它把尾部也算进去了**，**所以更稳健**，**而且能写成凸优化**（算得动）。

**⑥ Regret formulations（遗憾 / 后悔值）**
> 试图**最小化"你设计的控制器"与"某个能访问特权信息的最优控制器"的差距**——比如**事先知道扰动 $w[n]$**。这在线优化领域很流行，我们开始看到控制的 "regret bounds"。
**类比**：**事后诸葛亮**——"**如果我早知道今天刮大风，我会开得更稳；我现在的开法，比'早知道'差了多少？**" 这个差 = **regret**。

### 2.2 约束的推广：机会约束 vs 最坏约束

> 类似地，我们想怎么把确定性约束（如 $g(x)\le 0$）推广到随机框架？

**机会约束（Chance constraints）**
> 形如 $\mathbb{P}(g(x)>0)\le\alpha$。比如我们想**保证飞机撞树的概率小于某值**。即使对**高斯不确定 + 多面体约束**，这些量也**难精确算**；我们常做**近似** [4]，但**有希望用 Lyapunov 类论证给严格界** [5]。
**类比**：**"我接受 0.1% 的概率撞树"**——**不是绝对不撞，而是把撞的概率压到可接受**。

**最坏情况约束（Worst-case constraints）**
> 是机会约束在 $\alpha\to 0$ 时的**极限**，**往往更易计算**，**直接连到可达性分析**。
**类比**：**"我要求 100% 不撞树"**——**比机会约束更严，但反而更好算**（因为它退化成"可达集不碰树"这种几何问题）。

### 2.3 术语 + 哲学：鲁棒派不是天生悲观

> "**鲁棒控制**"通常指**试图保证某种最坏情况性能或最坏情况界**（如增益界）的那类技术。"**随机最优控制 / 随机控制**"通常当**其他推理随机性、但不一定给严格鲁棒保证**的方法的统称。

> **要明白**：鲁棒控制的支持者**不是天生悲观**；这背后是一种**哲学立场**——**关于"控制系统在真实世界面对的随机分布，到底有多难建模"**。

> **最坏情况分析通常只需定义"随机变量可能取值的集合"，而不需这些值上的详细分布**。把"**只要峰值阵风低于 35 mph，这架无人机就不会坠毁**"这种概念**操作化**，可能比**要求一份详细的阵风概率分布**更实际。但这种更简单的规格**有代价**——**最坏情况证书常对系统真实性能悲观，优化最坏情况性能会导致控制设计保守**。

**类比（两派性格，必懂）**：
- **随机派** = **赌徒型精算师**：他**相信概率分布**，敢"**用 0.1% 的翻车概率，换 99.9% 时开得更快**"。
- **鲁棒派** = **保守型工程师**：他**不信分布**（"谁知道分布准不准？"），他**只认"风不超过 35 mph 就绝不翻车"**——**代价是平时开得慢（保守）**。
- **谁对？** **看场景**：**送外卖**可以随机派（偶尔迟到没关系）；**载人飞机**必须鲁棒派（绝不允许那 0.1%）。

## 4. 线性最优控制（13.4）—— 把两派哲学落到"能算"

### 4.1 随机 LQR（13.4.1）—— "账单付不完，但每月该还多少是确定的"

> 考虑 LQR 的随机扩展，系统现在受**加性高斯白噪声**：

$$x[n+1]=Ax[n]+Bu[n]+w[n],\quad \mathbb{E}[w[i]]=0,\quad \mathbb{E}[w[i]w^T[j]]=\delta_{ij}\Sigma_w$$

> 其中 $\delta_{ij}$ 在 $i=j$ 时为 1、否则为 0，$\Sigma_w$ 是扰动协方差；取**平均代价**：

$$\min \mathbb{E}\Big[\sum_{n=0}^\infty x^T[n]Qx[n]+u^T[n]Ru[n]\Big],\quad Q\succeq 0,\ R\succ 0$$

> 注意我们在讨论 LQR 的 policy search 时，**已经见过这个的一个版本**。

**人话**：**和确定性 LQR 比，只多了 $+w[n]$**——**每步被随机踢一脚**。

#### 关键问题：cost-to-go 还是二次的吗？

> 标准 LQR 推导里，我们**先假设 cost-to-go 是二次型**。对这个随机版，这还合适吗？我们研究过**线性系统受高斯噪声**的动力学，知道**（充其量）该期望它有一个高斯稳态分布**。

> **但这听起来有问题，不是吗？** 如果系统**不能把状态驱到零并停在那**（因为噪声一直踢它），**那无限时域代价不就无穷了吗**（无论什么控制器）？

> **是的。这个问题的 cost-to-go 是无穷的！** 但它**仍有足够的结构**让我们能用。特别地，我们"猜"一个 cost-to-go：

$$J_n(x)=x^TS_nx+c_n$$

> 其中 $c_n$ 是（标量）常数。现在写 Bellman 方程、做代数：

$$J_n(x)=\min_u \mathbb{E}_w\big[x^TQx+u^TRu+[Ax+Bu+w]^TS_{n+1}[Ax+Bu+w]+c_{n+1}\big]$$
$$=\min_u\big[x^TQx+u^TRu+[Ax+Bu]^TS_{n+1}[Ax+Bu]+c_{n+1}+\operatorname{tr}(\Sigma_w)\big]$$

**人话（这两行的"魔法"，务必吃透）**：
- **第二行怎么来的**？把 $[Ax+Bu+w]^TS_{n+1}[Ax+Bu+w]$ 展开，会有**含 $w$ 的交叉项**（如 $[Ax+Bu]^TS_{n+1}w$）。但 **$x,u$ 与 $w$ 不相关、且 $\mathbb{E}[w]=0$** → **这些交叉项的期望 = 0**，**消失！**
- 剩下的 $\mathbb{E}[w^TS_{n+1}w]=\operatorname{tr}(S_{n+1}\Sigma_w)$……（PDF 此处简记为 $\operatorname{tr}(\Sigma_w)$ 量级项；**严格应是 $\operatorname{tr}(S_{n+1}\Sigma_w)$**，我在增补里澄清）。
- **关键观察**：**除了 $c_{n+1}$ 和那个 $\operatorname{tr}$ 项，其余和确定性离散 LQR 完全一样！**

#### 惊人的结论：最优控制 = 确定性 LQR 的控制

> 因此我们**用 $S_n$ = 离散 Riccati 方程的解**、$c_n=c_{n+1}+\operatorname{tr}(\Sigma_w)$，就能完成 DP 递归。当 $n\to\infty$，$S_n$ 收敛到**代数 Riccati 方程的稳态解**，**只有 $c_n$ 增长到无穷**。结果，**尽管 cost-to-go 无穷，最优控制仍良定义：它和确定性 LQR 得到的完全相同！** $u^*=-Kx$。

**类比（这是全章最反直觉也最漂亮的结论之一，必懂）**：
- 想象你**欠一笔永远还不完的债**（cost-to-go = 无穷，因为噪声一直踢你，你一直扣分）。
- 但**"这个月该还多少"是确定的**（最优控制 $u^*=-Kx$ 良定义）！
- **为什么**？因为**噪声是"零均值"的**——**它平均不偏向任何方向**，所以**"最优的应对姿势"和没有噪声时一样**——**噪声只让你"一直付出代价"，但不改变"该怎么应对"**。
- **$c_n$ 就是"那笔永远还不完、越积越多的债"**；**$S_n$（决定 $K$）就是"该怎么应对"，它收敛到一个定值**。

> **注意 cost-to-go 爆炸到无穷这件事**。在 RL 里，**常用折扣代价或平均代价来避免这种爆炸**。

#### 非 i.i.d. 扰动：把"风"也拉进系统

> 上面的推导假设扰动 **i.i.d.**。但我们想建模的许多扰动**不是 i.i.d.**。比如 **UAV 在风中飞**。**风在时间上相关**——**有时积聚成阵风，但即使阵风，相对控制系统的采样率也算"长"**。

> 事实上，**标准的风模型通常是"高斯 i.i.d. 随机信号过一个线性低通滤波器"的输出** [6]。这暗示了一个**非常自然的方法**：**对"风 + UAV"的联合系统做 LQR**。这个系统的状态**既含 UAV 状态、也含风状态**，所以控制器形如：

$$u=-K\begin{bmatrix}x_{uav}\\ x_{wind}\end{bmatrix}$$

> **实践中**，这意味着控制器**除了标准的（UAV）状态估计器，还要靠一个在线估计器估计风状态**。

**类比（把天气预报员拉进控制回路，必懂）**：
- 风**不是白噪声**（它"有记忆"）→ **直接套随机 LQR 不对**。
- 但风 = **白噪声过低通滤波器** → **把"滤波器的内部状态 $x_{wind}$"当系统的一部分** → **联合系统又"白"了** → **套 LQR**！
- **代价**：控制器 $u$ 现在**依赖 $x_{wind}$**，**但你测不到风的状态** → **你得另装一个"估计风的卡尔曼滤波器"**，**实时猜风现在多大**。
- **一句话**：**你不再"无视风"或"把风当随机踢"，而是"把风当成系统的一部分，并实时估计它"**。

#### Example 13.1（在风中飞的四旋翼）

### 4.2 有界不确定性的最坏情况控制（13.4.2）—— 给状态"套一根管子"

#### 公共 Lyapunov 函数（回顾）

> 我们见过**对不确定线性系统找公共 Lyapunov 函数**的小优化。那个例子研究 $x[n+1]=Ax[n]$，**$A$ 的系数未知但有界**。

> 我们也见过**本质上同样的技术能证对扰动稳定**，如 $x[n+1]=Ax[n]+w[n],\ w[n]\in W$，$W$ 描述某个**有界的可能不确定集合**。为兼容凸优化，我们常选 $W$ 为**椭球**或**凸多面体** [7]。

> **但要记住一个极重要的点**：**在加性扰动的情况下，我们不能再期望系统稳定收敛到原点**。我们之前的例子**只用公共 Lyapunov 函数证一个区域的不变性**（**若我从某区域出发，就永不离开**）。

**类比（不能停，但能"圈住"，必懂）**：
- **没有扰动**时，LQR 能把车**精确停到原点**。
- **有持续扰动**时，车**永远被踢，停不下来**——**原点不再是平衡点**。
- **但你仍能保证**："**只要车一开始在某个圈里，它就永远不出这个圈**"——**这个圈 = 不变集**。**这就是"退而求其次的保证"**。

#### 多面体动力学（Polytope dynamics）—— 用几何"画"可达集

> **多面体（polytope）** = **有界多面体（polyhedron）**。花点时间理解**多面体怎么穿过线性动力系统传播**。多面体有多种表示：

| 表示 | 人话 | 记号 |
|---|---|---|
| **H-rep**（半空间） | 用**一堆线性不等式** $Hx\le h$ 围出区域（"每面墙一个不等式"） | $P=\mathcal{H}(H,h):=\{x\mid Hx\le h\}$ |
| **V-rep**（顶点） | 用**顶点的凸包**（"把角点连起来"） | 凸包 |
| **zonotopes** | **单位立方体的仿射投影** | —— |
| **AH-polytopes** | **H-多面体的仿射投影**（更一般） | $X:=\mathcal{AH}(T,t,\mathcal{P}):=\{Tx+t\mid x\in\mathcal{P}\subset\mathbb{R}^m\}$ |

> 对优化，我们还研究 **zonotopes** 和更一般的 **AH-polytopes** [8,9]。**Drake 有这些凸集的库**，许多常用操作都实现了、且兼容 `MathematicalProgram`。

**类比（四种"画圈"的方式，必懂）**：
- **H-rep** = **用篱笆围地**——**每根篱笆是一面墙（一个不等式）**，**地在所有墙的"内侧"**。
- **V-rep** = **钉钉子拉橡皮筋**——**钉子是顶点，橡皮筋围出的形状就是地**。
- **zonotope / AH-polytope** = **把一个标准形状（立方体/盒子）"拉伸+旋转+投影"** 得到地——**好处是"拉伸/旋转/相加"这些操作，在这种表示下特别好算**。

#### Minkowski 和：多面体怎么"穿过"动力学

> **AH-polytopes 对线性系统所需的许多基本操作封闭** [9]，包括**仿射变换**：

$$AX+b=\mathcal{AH}(AT,\ At+b,\ \mathcal{P})$$

> 和 **Minkowski 和**。给定两个 AH-多面体 $X,Y$，它们的 Minkowski 和为：

$$X\oplus Y=\mathcal{AH}\Big([T_x,T_y],\ t_x+t_y,\ \mathcal{H}\big(\begin{bmatrix}H_x&0\\0&H_y\end{bmatrix},\begin{bmatrix}h_x\\h_y\end{bmatrix}\big)\Big)$$

> 现在我们能**直接用集合记号**写**多面体（在状态上）穿过不确定线性动力系统的动力学**：

$$x[n+1]=Ax[n]+w[n],\quad x[0]\in X_0,\ w[n]\in W$$

> 结果是：

$$\boxed{X_{n+1}=AX_n\oplus W}$$

> **漂亮！** 但请注意一个重要细节：**多面体的描述大小**（底层 H-多面体的环境维度）**每步都在增长**，**因为和 $W$ 做 Minkowski 和**。**长时域 rollout 时，集合会变得很复杂**。

**类比（影子叠加 / 水管变粗，必懂）**：
- $AX_n$ = **把当前的"状态云" $X_n$ 用动力学 $A$ 变形**（拉伸/旋转）。
- $\oplus W$ = **再"糊上"扰动 $W$ 的形状**——**像给云"加一圈毛边"**。
- **Minkowski 和** = **把两个形状"叠"在一起**：$X\oplus W=\{x+w\mid x\in X,w\in W\}$——**$X$ 的每个点，都按 $W$ 的形状"膨胀"一遍**。
- **每步都加一圈毛边 → 毛边越叠越多 → 描述越来越复杂**（H-rep 的墙越来越多）。**这就是"长时域变贵"的根**。

**类比（TubeMPC 的名字来源）**：$X_0,X_1,X_2,\dots$ 这一串"状态云"在时间上排开，**像一根"管子"**——**状态被保证"在这根管子里流"**。**TubeMPC = 优化这根管子的形状 + 让管子最终流进目标**。

#### Robust MPC / TubeMPC

> 虽然 finora 我写的是**闭环线性系统（+噪声）** 的多面体可达性，**同样能传播带反馈 $u$ 的多面体动力学**：

$$x[n+1]=Ax[n]+Bu[n]+w[n]\quad\Rightarrow\quad X_{n+1}=(AX_n+Bu_n)\oplus W$$

> 这导出一类鲁棒 MPC，常称 **"TubeMPC"** [10]。可以**用凸优化**优化 $u_n$ 和 $X_n$ 的描述，**受这些线性动力学约束**。而且能**结合基于扰动的反馈参数化**，**同时搜索时变反馈增益 $K_n$** [11]。

> 我们可能想指定的一个目标 = **最终时刻的整个可达集在目标集内**，如 $X_N\subseteq X_{goal}$。

> 检查这个条件是 **"多面体包含"** 问题——**计算几何的经典问题**。但我们想**优化 $X_N$ 的形式**（通过优化控制决策序列），所以想**把多面体包含作为额外约束嵌进 MPC**。

### 4.3 基于扰动的反馈参数化（13.4.3）—— 绕开"双线性"的死结

> 虽然**很想在 Robust MPC 框架里把反馈增益当决策变量**，但**同时搜 $K_n$ 和 $x_n$** 的传统参数化 $K_nx_n$，**会产生决策变量里双线性（因此非凸）的项**。**基于扰动的反馈参数化绕开了这个**。这是个**老但重要的思想**，最早以 **Youla 参数化**（又称 **Q 参数化**）出名。**在时域**，这通常导致**"在时间上展开"、依赖可能无限长扰动历史**的控制器；**常用有限脉冲响应（FIR）截断近似**。可以想象**用线性系统辨识的技术** [12] **提取这些 FIR 响应的状态空间实现**。

> 我们可以**用 LQR 最小二乘推导的一个简单扩展**理解这个思想的本质：

> 给定状态空间方程 $x[n+1]=Ax[n]+Bu[n]+w[n]$，考虑参数化一个**输出反馈策略**：

$$u[n]=K_0[n]x_0+\sum_{i=1}^{n-1}K_i[n]w[n-i]$$

> 则**闭环状态对控制参数凸**：

$$x[n]=\Big(A^n+\sum_{i=0}^{n-1}A^{n-i-1}BK_0[i]\Big)x_0+\sum_{j=0}^{n-1}\sum_{i=0}^{n-1}A^{n-i-1}BK_j[i]w[i-j]$$

> 因此**对 $x,u$ 凸的目标（如 LQR）对 $K$ 也凸**。

> 而且，**给定我们对 $x[n+1],x[n],u[n]$ 的观测、以及对动力学的了解，我们能在需要时算出 $w[n]$**。

**人话（这是"换变量让非凸变凸"的又一绝招，必懂）**：
- **死结**：想搜 $K_n$，但 $K_nx_n$ 里 $K_n$ 和 $x_n$ **相乘** → **双线性 → 非凸 → 难算**。
- **绝招**：**别用 $K_nx_n$（对当前状态反馈），改用 $K_i[n]w[n-i]$（对"过去的扰动"反馈）**！
- **为什么这就凸了**？因为 **$x_n$ 能写成 $w$ 的线性函数**（上面那个长公式，$x_n$ 对 $K$ 是**线性**的！）→ **$K$ 不再和 $x$ 相乘** → **凸**！
- **直觉**：**$w[n]$ 你能"反推"出来**（$w[n]=x[n+1]-Ax[n]-Bu[n]$，**都测得到**）→ **所以"对过去 $w$ 反馈"是"可实现"的**。

**类比（不盯"现在在哪"，盯"过去被踢了几脚"，必懂）**：
- 传统 $u=Kx$ = **司机盯着"车现在偏哪"打方向**——**但 $K$ 和 $x$ 一起调就打架（双线性）**。
- 扰动反馈 $u=\sum K_i w[n-i]$ = **司机不盯车，盯"过去每一阵风吹了多大"，按"风的记忆"打方向**——**因为风是"已知的外因"，这么调 $K$ 就不和状态打架了（凸）**。
- **FIR 截断** = **司机记性有限，只记"最近 5 阵风"**，**更早的忘掉了**——**近似，但够用**。

### 4.4 L2 增益（13.4.4）—— "音响的放大倍数"

> 通过**限制 $w$ 取自一个有界（多面体）集**，我们能做高效可达性分析。但**知道对 $w$ 的依赖是线性的**，让我们能做**可能更自然、能导致更紧的界**的事。特别地，我们**期望 $x$ 相对无扰动情况的偏离幅度，正比于扰动幅度**。所以**对线性系统，一个也许更自然的界 = 响应幅度（从零初值）相对扰动幅度的相对界**。

> 通常用标量 **"L2 增益" $\gamma$** 做，定义为：

$$\min_\gamma\ \text{s.t.}\ \sup_{w(\cdot):\int\|w\|^2<\infty}\frac{\int_0^T\|x(t)\|^2dt}{\int_0^T\|w(t)\|^2dt}\le\gamma^2$$

（离散版同构：把积分换成求和。）

> **"L2 增益"的名字**来自对信号 $w(t),x(t)$ 用 **L2 范数**（离散用 ℓ2），**只假设它有限**。

> **更常见的是**，这些增益**不直接用 $x[n]$ 写，而用某个"性能输出 $z[n]$"写**。比如若想**界住二次调节器代价作为扰动幅值的函数**，可最小化：

$$\min_\gamma\ \text{s.t.}\ \sup_{w}\frac{\sum_0^N\|z[n]\|^2}{\sum_0^N\|w[n]\|^2}\le\gamma^2,\quad z[n]=\begin{bmatrix}\sqrt{Q}x[n]\\ \sqrt{R}u[n]\end{bmatrix}$$

> **这是个简单但重要的思想，理解它是理解鲁棒控制语言的钥匙**。特别地，**系统的 H2 范数**（输入到输出）= **脉冲响应的能量**；当 $z$ 选成上面的二次调节器代价时，**它对应期望 LQR 代价**。**系统的 H∞ 范数**（$w$ 到 $z$）= **传递函数的最大奇异值**；**它对应 L2 增益**。

**类比（音响放大倍数 / 麦克风啸叫，必懂）**：
- 把系统想成**一台音响**：$w$ = **对着话筒喊的音量**，$z$ = **喇叭出来的音量**。
- **L2 增益 $\gamma$** = **这台音响"最多把声音放大几倍"**——**你喊 1 分贝，喇叭最多出 $\gamma$ 分贝**。
- **$\gamma$ 小** = **音响"不放大扰动"** = **系统对扰动不敏感** = **鲁棒**！
- **麦克风啸叫** = **增益太大**（$\gamma$ 爆表）→ **一点杂音被无限放大** → **系统不稳定**。
- **H2 vs H∞**：**H2** = "**平均**放大多少"（脉冲响应总能量）；**H∞** = "**最坏频率**放大多少"（最大奇异值）——**H∞ 管"最坏情况"，正是鲁棒派要的**。

#### 耗散不等式（Dissipation inequalities）—— 给 Lyapunov "开个收支账户"

> **证系统 L2 增益的机制之一**，来自 **Lyapunov 分析的推广**——**通过所谓的"耗散不等式"考虑系统输入的贡献**。耗散不等式是**通用工具**，**L2 增益分析只是它的一个应用**。

> **非正式地**，思想是把 Lyapunov 条件 $V(x)\succ 0,\ \dot V(x)\preceq 0$ 推广到更一般的形式：

$$V(x)\succ 0,\quad \dot V(x)\preceq s(x,w)$$

> 其中 $w$ 是此设定下感兴趣的输入，$s(\cdot)$ 是代表 **"供给率（supply rate）"** 的标量。**一旦系统有输入，$V$ 的值可能升也可能降**，但**若我们能"用输入的简单函数"界住它升的方式**，**就仍能给系统提供输入-状态或输入-输出界**。**对导数条件两边关于时间积分**得：

$$\forall x(0),\quad V(x(T))\le V(x(0))+\int_0^T s(x(t),w(t))dt$$

> 为得**输入 $w(t)$ 到输出 $z(t)$ 的 L2 增益界**，感兴趣的供给率是：

$$s(x,w)=\gamma^2\|w\|^2-\|z\|^2$$

> 它给出：

$$\forall x(0),\quad V(x(T))\le V(x(0))+\int_0^T\gamma^2\|w(t)\|^2dt-\int_0^T\|z(t)\|^2dt$$

> 现在，**因为这必须对所有 $x(0)$ 成立，它对 $x(0)=0$ 成立**。而且**我们知道 $V(x(T))$ 非负**，所以也有：

$$0\le V(x(T))\le\int_0^T\gamma^2\|w(t)\|^2dt-\int_0^T\|z(t)\|^2dt$$

> 因此，**若我们能找到一个 $V$ 满足该存储函数的耗散不等式，我们就证了 $\gamma$ 是 L2 增益**：

$$\frac{\int_0^T\|z(t)\|^2dt}{\int_0^T\|w(t)\|^2dt}\le\gamma^2$$

**类比（银行账户 / 收支规则，必懂，这是理解耗散不等式的钥匙）**：
- **$V$ = 你的银行存款**（必须 $\ge 0$，不能透支）。
- **$\dot V\le s(x,w)$ = 一条"收支规则"**：**存款的变化率 ≤ 供给率**。
- **供给率 $s=\gamma^2\|w\|^2-\|z\|^2$** = **"收入 − 支出"**：**$w$（扰动）是"存进来的钱"，$z$（输出）是"花出去的钱"**，**$\gamma^2$ 是"汇率"**。
- **积分形式** = "**到时刻 $T$ 的存款 ≤ 初始存款 + 累计收入 − 累计支出**"。
- **从空账户出发**（$x(0)=0\Rightarrow V=0$），**存款又 ≥ 0** → **累计支出 ≤ 累计收入** → **$\int\|z\|^2\le\gamma^2\int\|w\|^2$** → **$\gamma$ 是 L2 增益**！
- **一句话**：**"只要我能找到一个'存款永远不透支'的账户规则，我就证明了'花的钱永远不超过赚的钱的 $\gamma^2$ 倍'"**——**这就是耗散不等式证 L2 增益的全部逻辑**。

> **Small-gain theorem**：**Coming soon.**
> **Model uncertainty as a special case**（模型不确定性作为特例）。

**人话（补概念）**：**小增益定理** = "**若两个系统串起来，各自增益的乘积 < 1，则闭环稳定**"——**像"两个音响串联，总放大倍数 = 两者相乘；若乘积 < 1，就不会啸叫"**。**模型不确定作为特例** = **把"模型误差"也看成一个"增益有界的小系统"，反馈连回去** → **用小增益定理证"误差不会让系统失稳"**。

### 4.5 鲁棒 LQR 作为 H∞（13.4.5）—— "和全知对手下棋"

> 考虑 LQR 的鲁棒变体：

$$\min_{u[\cdot]}\max_{w[\cdot]}\sum_{n=0}^\infty x^TQx+u^TRu-\gamma^2w^Tw,\quad x[n+1]=Ax[n]+Bu[n]+B_ww[n]$$

> **选这个代价函数的原因**推导里会清楚，但**直觉是**：我们想**奖励控制器"对大 $w$ 有小响应"**。注意**不像随机 LQR**，这里**我们不指定 $w$ 的分布**，**事实上甚至不限它有界集**。我们只知道**每步一个全知的对手被允许选 $w$，试图最大化这个目标**。

> 事实上，**因为我们不需要指定连续时间随机过程、且连续时间推导既更干净、到现在也更熟悉**，**这个我们用连续时间做**：

$$\min_{u[\cdot]}\max_{w[\cdot]}\int_0^\infty\big[x^TQx+u^TRu-\gamma^2w^Tw\big]dt,\quad \dot x=Ax+Bu+B_ww$$

> 我们**再次猜二次 cost-to-go**：$J(x)=x^TSx,\ S\succ 0$。**DP 递归对这个问题仍成立**，得 Bellman 方程：

$$\forall x,\quad 0=\min_u\max_w\Big[x^TQx+u^TRu-\gamma^2w^Tw+\frac{\partial J^*}{\partial x}(Ax+Bu+B_ww)\Big]$$

> 因为**内部对 $w$ 是凹二次**，我们能**求对手的最大值**：

$$\frac{\partial}{\partial w}=-2\gamma^2w^T+2x^TSB_w\quad\Rightarrow\quad w^*=\gamma^{-2}B_w^TSx$$

> **这是能造成最大代价的扰动输入——对手的最优招**。现在我们能**像原 LQR 那样解剩下的**：

$$\frac{\partial}{\partial u}=2u^TR+2x^TSB\quad\Rightarrow\quad u^*=-R^{-1}B^TSx=-Kx$$

> 代回 Bellman 方程得：

$$0=Q+S\big[\gamma^{-2}B_wB_w^T-BR^{-1}B^T\big]S+SA+AS$$

> **这是原 LQR Riccati 方程，加了一项含 $\gamma$ 的**。和原 LQR Riccati 一样，我们要问**它是否有正定解**。**结果**：**若系统可稳定、且 $\gamma$ 够大，则有 PD 解**。但**当 $\gamma$ 减小到零，会有某个阈值 $\gamma^*$，低于它这个 Riccati 方程没有 PD 解**。

> **直觉**：**若 $\gamma$ 太小，对手被奖励注入"大到破坏收敛"的扰动**。

> **迷人之处**：**这个鲁棒 LQR 代价里的 $\gamma$，可解释为系统的 L2 增益**。回忆我们联系 Bellman 与 Lyapunov 时观察到 Bellman 可写成 $\dot J^*(x)\le-\ell(x,u)$？**这里这给出**：

$$\forall x,\quad \dot J^*(x)\le\gamma^2w^Tw-x^TQx-u^TRu$$

> 这意味着 **cost-to-go 是供给率的有效耗散不等式**，**给性能输出 $z=\begin{bmatrix}\sqrt{Q}x\\ \sqrt{R}u\end{bmatrix}$ 的 L2 增益**。而且**我们能找最小 L2 增益 = 找 Riccati 有 PD 解的最小 $\gamma$**。由 Riccati 的性质，**这能用 $\gamma$ 的线搜索做到**。

> **因为 L2 增益 = 系统的 H∞ 范数**，**这个"搜最小 $\gamma$ 取 Riccati 解"的配方，是 H∞ 控制设计的一个实例**。

**类比（和全知对手下棋，必懂）**：
- **随机 LQR** = **和"掷骰子的运气"对局**——**运气零均值，不针对你**。
- **鲁棒 LQR** = **和一个"全知、且专门害你"的对手下棋**——**他每步看你怎么走，然后选"最让你疼"的 $w$**（$w^*=\gamma^{-2}B_w^TSx$）。
- **你的目标** = **在"对手最狠"的前提下，仍把代价压住**。
- **$\gamma$ 的角色** = **你给对手"使坏的预算"**：$\gamma$ 大 = **对手被限制"不能使太狠的坏"**（$-\gamma^2w^Tw$ 罚他使大 $w$）→ **你容易赢（Riccati 有解）**；$\gamma$ 小 = **对手几乎不被限制** → **你赢不了（Riccati 无解）**。
- **最小 $\gamma^*$** = **"你还能赢的、对手最狠的极限"** = **系统的 H∞ 范数** = **L2 增益**！
- **一句话**：**鲁棒 LQR = "假设最坏的对手，求你仍能稳住的最小放大倍数"**。

### 4.6 线性指数-二次高斯 LEQG（13.4.6）—— "风险厌恶的精算师"

> [15] 观察到，**最小化下面这个目标也很直接**：

$$J=\mathbb{E}\Big[\prod_{n=0}^\infty e^{x^TQx}e^{u^TRu}\Big]=\mathbb{E}\Big[e^{\sum_{n=0}^\infty x^TQx+u^TRu}\Big],\quad Q\succeq 0,\ R\succ 0$$

> 观察到**代价与 $\log J$ 单调相关**，因此**有相同的最小值**（**同一技巧是"几何规划 geometric programming"的基础** [16]）。这称 **Linear Exponential-Quadratic Gaussian（LEG / LEQG）**；**对确定性版（无过程/测量噪声），解与 LQR 相同**——**不加新建模能力**。**但有噪声时，LEQG 最优控制器不同于 LQG 控制器**；**它们显式依赖噪声的协方差**。

> [17] 给了此框架的广泛处理；**LQR/LQG 几乎所有分析（Riccati、Hamiltonian 等）都有指数代价版的对应**；他论证 **LQG 和 H∞ 控制可（应？）理解为该方法的特例**。

**类比（风险厌恶 vs 风险中性，必懂）**：
- **普通 LQG（期望代价）** = **风险中性**：他**只在乎"平均亏多少"**——**亏 100 一次和亏 1 一百次，对他一样**。
- **LEQG（指数代价）** = **风险厌恶**：**指数函数 $e^{(\cdot)}$ 把"大亏损"放大得极狠**——**他**宁可平均多亏一点，也绝不要那一次"亏 100"**（因为 $e^{100}$ 是天价）。
- **所以 LEQG 控制器"更怕大扰动"**，**它的行为依赖噪声协方差**（噪声越大，它越保守）——**而普通 LQR 的 $K$ 与噪声协方差无关**（13.4.1 的结论）。
- **统一视角**：[17] 说 **LQG（风险中性）和 H∞（最坏情况）都是 LEQG 的"极限特例"**——**LEQG 是"风险态度"的总旋钮**。

### 4.7 自适应控制（13.4.7）—— "边开车边学路况"

> **最优控制的标准批评**：**最小化期望不允许任何性能保证**。**鲁棒控制的标准批评**：**它关心最坏情况，因此可能保守**，**尤其因为先验选的扰动分布可能不必要地保守**。人们**希望**：**若能在在线更新不确定性模型、适应实际收到的扰动统计**，**能挽回一些性能**。**这是自适应控制的目标之一**。

> **在线自适应控制的一个基本问题** = **探索-利用（exploration-exploitation）权衡**。某些输入**可能驱动系统更快建立更准的动力学/不确定性模型**，**从而带来更好性能**。但**怎么形式化这个权衡**？

> **ML 在（上下文）多臂老虎机问题上对此有不错的进展**。对我们的目的，**你可以把老虎机看作最优控制的一个极限情况——没有动力学**（一个控制动作不影响下一个控制动作的结果）。**在这个更简单的设定里**，在线优化社区**基于最小化 regret 的概念**开发了探索-利用策略——**通常是我的在线算法达到的性能、与"若我事先知道实验数据"能达到的性能之间的累积差**。这导出了**用上置信界（UCB）** 的方法，**以及最近用最小二乘置信界** [18] **给 regret 界**的方法。

> **最近几年**，我们看到**这些结果被翻译到线性最优控制的设定**……

**类比（边开车边学 + 老虎机，必懂）**：
- **自适应控制** = **你开一辆陌生的车，边开边摸"这车刹车灵不灵"**——**模型在线更新**。
- **探索-利用** = **你是"继续按已知的开法稳稳开"（利用），还是"故意猛踩一脚刹车试试，好摸清刹车特性"（探索）**？**探索当下危险，但长远让你开得更好**。
- **老虎机** = **简化版**：**面前 10 台老虎机，每台赔率未知，你拉杆学赔率**——**没有"动力学"（这次拉不影响下次）**，**纯学"哪台好"**。
- **regret** = "**我拉的总和，比'一开始就知道哪台最好'少赚了多少**"——**越小越好**。
- **UCB / 最小二乘置信界** = "**给每台机一个'乐观估计 + 不确定度'，优先拉'不确定度大的'（探索）或'估计高的'（利用）**"——**自动平衡两者**。

> **13.4.8 Structured uncertainty（结构化不确定性）**：**占位。**
> **13.4.9 Linear parameter-varying (LPV) control**：**占位。**

**人话（补概念）**：**结构化不确定** = **不确定不是"一团乱"，而有"结构"**（如"只有某个子块不确定"）→ **能用更细的工具（结构化奇异值 $\mu$）给更紧的界**。**LPV 控制** = **系统矩阵 $A(\rho)$ 随一个"可测的参数 $\rho$"变**（如飞机随速度变）→ **把 $\rho$ 当"调度变量"，在线查一组预算好的增益**——**介于 LQR 和全非线性之间**。

## 增补一：把"还不够通俗"的 6 个概念，各加一个类比 / 澄清

1. **随机 LQR 里 $\operatorname{tr}$ 项的严格形式**：展开 $[Ax+Bu+w]^TS_{n+1}[Ax+Bu+w]$，**含 $w$ 的唯一非零期望项**是 $\mathbb{E}[w^TS_{n+1}w]=\operatorname{tr}(S_{n+1}\Sigma_w)$（**用 $\mathbb{E}[w^TMw]=\operatorname{tr}(M\Sigma_w)$**）。PDF 简记为 $\operatorname{tr}(\Sigma_w)$ 量级，**正确递推是 $c_n=c_{n+1}+\operatorname{tr}(S_{n+1}\Sigma_w)$**。**这不影响结论**（$c_n\to\infty$、$S_n$ 与确定性同），**但写代码时要用 $\operatorname{tr}(S_{n+1}\Sigma_w)$**。
2. **为什么"加性扰动下不能收敛到原点"**：因为 $x=0$ 时 $x[n+1]=w[n]\ne 0$——**原点根本不是平衡点**！**噪声每步把状态踢离原点**，所以**只能"圈住"（不变集），不能"停住"**。**这是 13.4.2 那个"重要点"的数学根**。
3. **Minkowski 和为什么"描述增长"**：H-rep 下 $X\oplus W$ 的约束数 ≈ $X$ 的墙数 + $W$ 的墙数（见核查表里的分块矩阵）→ **每步加 $W$ 的墙数** → **$N$ 步后墙数线性涨** → **V-rep 顶点更糟（可能指数涨）**。**zonotope 的好处**：**Minkowski 和只是"把生成元拼起来"，不增加约束数**（只增生成元列）→ **更省**——**这是 TubeMPC 爱用 zonotope 的原因**。
4. **耗散不等式 vs 普通 Lyapunov**：普通 Lyapunov 要求 $\dot V\le 0$（**只出不进**）；耗散不等式允许 $\dot V\le s$（**可以进，但进多少被 $s$ 管住**）。**当 $w=0$ 时 $s\le 0$（若 $s=\gamma^2\|w\|^2-\|z\|^2$ 则 $s=-\|z\|^2\le 0$）→ 退回普通 Lyapunov**。**所以耗散不等式是"带输入版"的 Lyapunov**。
5. **鲁棒 LQR 的 $\gamma$ 线搜索为什么可行**：$\gamma$ 大 → Riccati 的 $-\gamma^{-2}B_wB_w^T$ 项小 → **接近普通 LQR → 有 PD 解**；$\gamma$ 减小 → 该项变大 → **$S$ 被推大 → 到 $\gamma^*$ 时 $S$ 爆/无 PD 解**。**$S$ 的存在性关于 $\gamma$ 单调** → **可二分/线搜索找最小 $\gamma^*$**。
6. **LEQG 为什么"显式依赖噪声协方差"**：因为 $e^{(\cdot)}$ 是**凸的**，**Jensen 不等式让"噪声的散布"直接影响期望**——**噪声越大，$e^{\text{代价}}$ 的期望被"大代价尾巴"抬得越高** → **控制器被迫"压尾巴"= 更保守** → **$K$ 依赖 $\Sigma_w$**。**而普通 LQR 的 $e$ 没有（线性期望），噪声只加常数 $c_n$，不影响 $K$**——**这正是 13.4.1 vs 13.4.6 的对比**。

### 实验 1：随机 LQR —— 验证"cost-to-go 无穷但 $K$ = 确定性 LQR"（可跑，对照 13.4.1）

**反向递推 $S_n,c_n$，看 $S_n$ 收敛到确定性 ARE、$c_n$ 线性增长；并验证 $K$ 与确定性 LQR 相同**。

```python
import numpy as np
from scipy.linalg import solve_discrete_are
A = np.array([[1,1],[0,1]]); B = np.array([[0],[1]])
Bw = np.eye(2); Q = np.eye(2); R = np.eye(1); Sw = 0.1*np.eye(2)   # 扰动协方差
# 确定性 ARE 解（应 = 随机 LQR 的 S 极限）
S_inf = solve_discrete_are(A, B, Q, R); K_det = np.linalg.solve(R+B.T@S_inf@B, B.T@S_inf@A)
# 随机 LQR 反向递推 S_n, c_n（注意 tr 项 = tr(S_{n+1} Σw)，见增补一.1）
N = 300; S = np.zeros((2,2)); c = 0.0; hist_c = []
for n in range(N):
    K = np.linalg.solve(R+B.T@S@B, B.T@S@A)
    S = Q + A.T@S@A - (A.T@S@B)@np.linalg.solve(R+B.T@S@B, B.T@S@A)   # 与确定性同！
    c = c + np.trace(S@Sw)                                             # c_n = c_{n+1} + tr(S_{n+1}Σw)
    hist_c.append(c)
print("随机LQR 终值 K =", np.round(K,4))
print("确定性LQR  K =", np.round(K_det,4), " -> 应相同（噪声不改 K）")
print("c_n 最后5值 =", np.round(hist_c[-5:],2), " -> 线性增长到无穷（那笔还不完的债）")
print("c_n 每步增量 ≈", round(hist_c[-1]-hist_c[-2],4), "（趋于常数 tr(S_inf Σw)）")
```

**你会看到**：**两个 $K$ 完全相同**（**噪声不改最优控制**），**$c_n$ 一路线性涨**（**cost-to-go 无穷**），**每步增量趋于常数 $\operatorname{tr}(S_\infty\Sigma_w)$**——**亲手验证 13.4.1 的全部结论**。

### 实验 2：风模型 + 联合 LQR（Example 13.1 的 numpy 版，可跑）

**用一阶低通滤波把白噪声变成"阵风"，构造"风+车"联合系统，对比"无视风"vs"联合"LQR 在阵风下的表现**。

```python
import numpy as np
rng = np.random.default_rng(0)
# 车（双积分器）+ 风（一阶低通：xwind[k+1]=a*xwind[k]+(1-a)*white，作用为加性力）
a = 0.9; dt = 0.1
Ac = np.array([[1,dt],[0,1]]); Bc = np.array([[0],[dt]]); Bwc = np.array([[0],[dt]])  # 风当力
Aw = np.array([[a]]); Bw = np.array([[1-a]]); sigma_white = 2.0
# 联合系统状态 [x_car(2); x_wind(1)]
A = np.block([[Ac, Bwc],[np.zeros((1,2)), Aw]]); B = np.vstack([Bc, np.zeros((1,1))])
Bw_joint = np.vstack([np.zeros((2,1)), Bw]); Sw = np.array([[sigma_white**2]])
Q = np.block([[np.eye(2), np.zeros((2,1))],[np.zeros((1,3))]]); R = np.eye(1)*0.1
# 联合 LQR（忽略 Sw，因 K 与噪声无关，见实验1）
from scipy.linalg import solve_discrete_are
S = solve_discrete_are(A, B, Q, R); K_joint = np.linalg.solve(R+B.T@S@B, B.T@S@A)
# 传统 LQR（只在车上，无视风）
Sc = solve_discrete_are(Ac, Bc, np.eye(2), R); K_car = np.linalg.solve(R+Bc.T@Sc@Bc, Bc.T@Sc@Ac)
# 仿真对比
def sim(K, use_wind_in_ctrl):
    x = np.array([1.,0.]); w = np.array([0.]); cost=0.
    for _ in range(200):
        white = rng.normal(0, sigma_white); w = a*w + (1-a)*white          # 阵风
        state = np.concatenate([x,w]) if use_wind_in_ctrl else x
        u = -K@state
        x = Ac@x + Bc@u + Bwc@w; cost += x@np.eye(2)@x + u@R@u
    return cost
print("无视风 LQR 代价 =", round(sim(K_car, False),2))
print("联合风 LQR 代价 =", round(sim(K_joint, True),2), " -> 应更小（把风当系统一部分+估风）")
```

**你会看到**：**联合 LQR 代价明显更低**——**因为它"知道风的状态并据此补偿"**（**实践中 $x_{wind}$ 要靠卡尔曼滤波估，这里直接给真值做上限对比**）。**把 `a` 调小（风更"白"）**，**两者差距缩小**（**风越白，"无视风"越不吃亏**）——**亲手验证"有色噪声才需要联合建模"**。

### 实验 3：多面体 Minkowski 和 + 管动力学 $X_{n+1}=AX_n\oplus W$（可跑，对照 13.4.2）

**用 zonotope（生成元表示）做 Minkowski 和——和只是"拼生成元"，看"管子"怎么变粗**。

```python
import numpy as np
import matplotlib.pyplot as plt
# zonotope = {c + G @ s | s∈[-1,1]^m}，c=中心，G=生成元列
def zono_plot(c, G, ax, **kw):
    # 枚举 2D 顶点（m 小才行）
    from itertools import product
    m = G.shape[1]; verts = [c + G@np.array(s) for s in product([-1,1], repeat=m)]
    # 凸包排序
    vs = np.array(verts); ang = np.arctan2(vs[:,1]-c[1], vs[:,0]-c[0]); vs = vs[np.argsort(ang)]
    ax.fill(np.append(vs[:,0],vs[0,0]), np.append(vs[:,1],vs[0,1]), alpha=.25, **kw)
A = np.array([[1,0.5],[0,1]]); W_c = np.zeros(2); W_G = 0.1*np.eye(2)   # 扰动 zonotope
X_c = np.array([0.,0.]); X_G = 0.2*np.eye(2)                            # 初始 zonotope
fig, ax = plt.subplots(); 
for n in range(6):
    zono_plot(X_c, X_G, ax, label=f'n={n}')
    X_c = A@X_c; X_G = np.hstack([A@X_G, W_G])                          # X_{n+1}=A X_n ⊕ W：拼生成元！
ax.set_aspect('equal'); ax.legend(); ax.set_title('X_{n+1}=AX_n⊕W：每步拼W的生成元->管子变粗(描述增长)')
plt.show()
print("生成元列数随步增长:", [2+2*n for n in range(6)], " -> 长时域描述爆炸的根")
```

**你会看到**：**一串"状态云"沿 $A$ 方向排开、且越来越胖**——**这就是 TubeMPC 的"管子"**；**生成元列数线性涨**——**亲手见 13.4.2 的"描述大小每步增长"**。**这就是为什么 TubeMPC 要"每步用最小体积 zonotope 重近似"以控住复杂度**。

### 实验 4：耗散不等式 / L2 增益数值验证（可跑，对照 13.4.4）

**对一个稳定系统，验证"找到的 $V=x^TPx$ 满足 $\dot V\le\gamma^2\|w\|^2-\|z\|^2$"，并数值估 L2 增益**。

```python
import numpy as np
from scipy.linalg import solve_continuous_are, solve_continuous_lyapunov
A = np.array([[-1,1],[0,-2]]); Bw = np.eye(2); C = np.eye(2)   # z=Cx, 无控制输入
# 用 H∞/有界实引理思路：取 gamma 略大于真 H∞ 范数，解 P 验证耗散不等式
# 真 H∞ 范数 = max singular value of C(jwI-A)^-1 Bw，数值估
import scipy.signal as sig
sys = sig.ss(A, Bw, C, 0); w, H = sig.freqresp(sys, w=np.logspace(-2,2,2000))
gamma_true = np.max(np.linalg.svd(H, axis=2).max(axis=1))   # 峰值奇异值
gamma = gamma_true*1.05                                      # 略大->应有解
# 验证：需 P>0 使 (AᵀP+PA) + CᵀC + (1/γ²)P Bw Bwᵀ P < 0 （有界实引理 LMI 的 Riccati 形式）
# 这里用简单数值检查：取 P=Lyapunov(A, CᵀC)，看 V̇ - γ²‖w² + ‖z‖² 的"最坏方向"
P = solve_continuous_lyapunov(A.T, -C.T@C)                  # AᵀP+PA=-CᵀC (V̇=-‖z‖² when w=0)
# 对随机 w,x 抽样检查 V̇ <= γ²‖w²-‖z‖²
ok = True
rng = np.random.default_rng(1)
for _ in range(5000):
    x = rng.randn(2); w = rng.randn(2)
    Vdot = 2*x@P@(A@x + Bw@w)
    if Vdot > gamma**2*(w@w) - (C@x)@(C@x) + 1e-6: ok = False; break
print("数值 H∞ 范数 ≈", round(gamma_true,4))
print("γ=%.4f 时耗散不等式 V̇<=γ²‖w‖²-‖z‖² 抽样全满足? %s" % (gamma, ok))
```

**你会看到**：**取 $\gamma$ 略大于数值 H∞ 范数时，耗散不等式在抽样点上全部满足**——**亲手验证"耗散不等式 ⟺ L2 增益界"**。**把 $\gamma$ 取小于 $\gamma_{true}$**，**会看到 `ok=False`**——**因为 $\gamma$ 太小，"账户会透支"**。

### 实验 5：鲁棒 LQR = H∞ —— $\gamma$ 线搜索找最小可行 $\gamma^*$（可跑，对照 13.4.5）

**对鲁棒 LQR 的 Riccati $0=Q+S[\gamma^{-2}B_wB_w^T-BR^{-1}B^T]S+SA+AS$，二分搜最小 $\gamma$ 使有 PD 解**。

```python
import numpy as np
from scipy.linalg import solve_continuous_are
A = np.array([[0,1],[0,0]]); B = np.array([[0],[1]]); Bw = np.array([[0],[1]])
Q = np.eye(2); R = np.eye(1)
def feasible(gamma):
    try:
        # 广义/修改 Riccati：把 -γ⁻²BwBwᵀ 并入"负定项"，用 scipy 解 S(A)+... 形式
        # 写成 0 = Q + S(A) + (A)ᵀS - S(BR⁻¹Bᵀ - γ⁻²BwBwᵀ)S
        M = B@np.linalg.solve(R,B.T) - (1/gamma**2)*(Bw@Bw.T)
        S = solve_continuous_are(A, np.linalg.cholesky(M).T if np.all(np.linalg.eigvalsh(M)>0) else np.eye(2), Q, np.eye(2))
        # 更稳妥：直接检测 M 正定 + 标准 ARE 有解
        if not np.all(np.linalg.eigvalsh(M) > 1e-8): return False, None
        S = solve_continuous_are(A, np.eye(2), Q, M)   # 0=Q+SA+AᵀS-S M S
        return np.all(np.linalg.eigvalsh(S) > 1e-8), S
    except Exception:
        return False, None
# 二分搜最小 gamma
lo, hi = 0.5, 10.0
for _ in range(40):
    mid = 0.5*(lo+hi)
    ok, _ = feasible(mid)
    if ok: hi = mid
    else: lo = mid
print("最小可行 γ* ≈", round(hi,4), " = 系统 H∞ 范数（鲁棒LQR 的极限）")
ok, S = feasible(hi*1.01)
print("γ 略大于 γ* 时 Riccati 有 PD 解? %s" % ok, " S 最小特征值 =", round(min(np.linalg.eigvalsh(S)),4))
```

**你会看到**：**二分搜出一个 $\gamma^*$**，**低于它 Riccati 无 PD 解（对手太强你赢不了），高于它有解**——**亲手验证 13.4.5 的"$\gamma$ 阈值 + 线搜索 = H∞ 控制"**。**$\gamma^*$ 就是"和全知对手下棋，你还能赢的、对手最狠的极限"**。

```python
diag = builder.Build()

K_joint, _ = LinearQuadraticRegulator(diag, context, Q, R)     # 联合系统

```

## 给初学者的"本章通关三句话"

1. **不确定 = 方程里加一个 $w$，打包票 = 选一种标准**：摩擦/地形/阵风/未知物体**全塞进 $w$**；然后选**期望（精算师，最流行/保 DP 递归）**、**最坏（悲观工程师，guaranteed cost）**、或**增益界（相对放大倍数）**——**机会约束"接受 0.1% 翻车"，最坏约束"100% 不翻车但更保守"**。
2. **随机 LQR 的反直觉 + 管子的几何**：**噪声零均值 → cost-to-go 无穷但最优 $K$ 和没噪声时一样**（"债还不完但每月该还多少确定"）；**有色噪声（风）→ 把风当系统一部分联合 LQR + 在线估风**；**持续扰动下不能停原点，只能"圈住" → 多面体 $X_{n+1}=AX_n\oplus W$ 画出"管子" = TubeMPC，管子最终要"流进目标"（多面体包含）**。
3. **绕开非凸 + 耗散账户 + 和对手下棋**：**搜反馈增益会撞上 $Kx$ 双线性 → 换成"对过去扰动反馈" $u=\sum K_iw[n-i]$ 就凸（Youla/FIR）**；**L2 增益 = 音响放大倍数，用"耗散不等式"（给 Lyapunov 开个收支账户，$V$ 不透支就证了增益界）**；**鲁棒 LQR = 和全知对手下棋，$\gamma$ 是对手使坏的预算，最小可行 $\gamma^*$ = 系统 H∞ 范数，用线搜索找**——**而 LEQG 用指数代价把"风险态度"拧成一个总旋钮，自适应控制则"边开边学"用 regret/UCB 平衡探索与利用**。
