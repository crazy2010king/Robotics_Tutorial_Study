这是一份关于 Russ Tedrake 教授《欠驱动机器人》第20章“无模型策略搜索”的深度通俗解读。
这一章标志着我们进入了**强化学习**的核心领域。之前的章节我们都在做“白盒”优化——我们知道机器人的物理方程（模型），我们利用导数、梯度来精确计算最优解。
但在现实中，很多系统太复杂了（比如流体动力学、复杂的软体机器人），我们根本写不出物理方程，或者方程太复杂算不动。这时候，我们必须把机器人看作一个**黑盒**。我们只能通过“试错”来学习：给它一个动作，看它反应如何，然后根据结果调整策略。
这就像教一只小狗学动作，你不懂狗的大脑结构（黑盒），但只要它做对了就给吃的（奖励），做错了就罚（代价），它最终能学会。

# 无模型策略搜索：在黑暗中摸索出最优解
## 1. 引言：为什么需要“无模型”？
想象你在玩一个完全陌生的游戏，而且没有说明书。
*   **模型控制（之前学的）**：你知道游戏背后的代码和物理规律。你可以计算出完美的操作。
*   **无模型策略搜索（本章学的）**：你只知道手里有个手柄。你按“上”，屏幕上的小人可能跳起来，也可能掉下去。你不知道为什么，你只能通过大量的尝试来总结规律：“按这个键在这个情况下通常得分高。”
**适用场景**：
*   **流体动力学**：比如控制无人机在狂风中飞行，或者设计一个高效的游泳机器人。流体力学的方程（纳维-斯托克斯方程）太难解了。
*   **复杂接触**：比如机器人玩叠叠乐，或者抓取软布。每一次摩擦和碰撞都极其复杂，难以建模。
**代价**：这种“盲搜”的方法效率通常比利用模型的方法低，而且只能保证找到“局部最优解”。但它的通用性极强，只要能跑仿真，就能训练。

## 2. 策略梯度：那个神奇的“对数似然”技巧
我们要解决的问题是：找到一组参数 $\alpha$（比如神经网络的权重），使得长期的**期望代价**最小。
$$ \min_\alpha E[\sum \ell(x[n], u[n])] $$
这里有个难点：代价是一个**期望值**（平均值），它依赖于随机的环境状态和随机动作。我们怎么求这个期望值的导数（梯度）呢？
### 2.1 REINFORCE 算法（似然比方法）
这是一个在强化学习里非常有名的数学技巧，看起来像魔术。
**核心公式**：
$$ \frac{\partial p_\alpha(x)}{\partial \alpha} = p_\alpha(x) \frac{\partial \ln p_\alpha(x)}{\partial \alpha} $$
**通俗解释**：
把求概率的导数，变成了“概率乘以对数的导数”。这有什么用？
它把原本很难处理的“概率密度积分”，变成了简单的“求平均值”。
**直观理解（驯兽师比喻）**：
*   假设你训练了一轮，机器人走完了一条轨迹。
*   如果这轮代价很低（表现好），REINFORCE 算法就会说：“嘿，把你刚才在那几个时刻采取的**那些动作**的概率调高一点！”
*   它不需要知道机器人为什么那样做（不需要模型梯度），它只需要知道：“**这些具体的动作**导致了好结果，那就多做这些动作。”
**代码/实验实践补充**：
*   在写 REINFORCE 代码时，你需要计算 `log_prob`（动作的对数概率）。
*   **注意**：这通常需要你的策略（Policy）输出一个概率分布（比如高斯分布），而不是一个确定性的数值。
*   **方差大**：这是 REINFORCE 最大的弱点。虽然平均来看它是对的，但单次更新的方向可能完全是错的（因为一次试验的运气成分太重）。你需要跑成千上万次才能收敛。

## 3. 权重扰动：更简单的“乱按”法
REINFORCE 还是要算策略的导数，对于复杂神经网络来说还是有点麻烦。有没有更“笨”但更通用的办法？
有，这就是**权重扰动**。
### 3.1 算法逻辑
想象你要调试一个收音机，但你看不懂电路图。
1.  **当前状态**：旋钮在位置 $\alpha$，声音很杂音（代价高）。
2.  **随机扰动**：你把旋钮随机往右拧一点，加个噪音 $\beta$，变成 $\alpha + \beta$。
3.  **试听**：现在的声音变好了吗？
    *   如果变好了（$g(\alpha+\beta) < g(\alpha)$）：说明刚才往右拧是对的。更新时，就往右走（$\Delta \alpha \propto -\beta$）。
    *   如果变差了：说明往右拧错了。更新时，就往反方向走（往左）。
**数学直觉**：
如果我们在随机方向上移动了一小步，结果发现下坡了（代价减小），那么这个随机方向大概率就是梯度的反方向。
**代码/实验实践补充**：
这是实现起来最简单的算法，甚至不需要自动求导库（如 PyTorch/TensorFlow）。
```python
# 伪代码
theta = 初始化参数
for i in range(10000):
    # 1. 生成随机扰动（高斯噪声）
    noise = np.random.randn(*theta.shape) * sigma
    
    # 2. 在原参数基础上加点噪音，跑一次仿真，得到代价 J_plus
    J_plus = run_simulation(theta + noise)
    
    # 3. (可选) 计算基准代价 J_base（可以是一个常数或运行平均）
    J_base = baseline  # 初始可以是0
    
    # 4. 更新参数
    # 如果 J_plus < J_base，括号里是负数，theta 往 noise 方向走
    # 如果 J_plus > J_base，括号里是正数，theta 往 noise 反方向走
    theta = theta - learning_rate * (J_plus - J_base) * noise
    
    # 5. 更新基准值（指数移动平均）
    baseline = 0.9 * baseline + 0.1 * J_plus
```
*   **优点**：极其简单，适用于任何黑盒系统。
*   **参数选择**：`sigma`（扰动大小）很关键。太小了，信号被噪声淹没；太大了，梯度的线性近似就不准了。
### 3.2 带基线的权重扰动
上面的算法每更新一次，都要跑两次仿真（一次加噪音，一次不加）。
能不能只跑一次？可以，用**基线**来代替 $g(\alpha)$。
*   **基线 $b$**：就是你过去所有表现的平均值。
*   **逻辑**：不要问“这次是不是比上次好？”，要问“这次是不是比我**平时的水平**好？”
*   **好处**：极大地降低了方差。比如你平时的平均分是 80 分，这次考了 85 分，那就是进步了。

## 4. 性能分析：信噪比（SNR）
既然是无模型搜索，充满了随机性，我们怎么知道算法好不好呢？文档引入了**信噪比（SNR）**。
*   **信号**：有用的更新方向（真实的梯度）。
*   **噪声**：无用的随机抖动。
公式推导很复杂，但结论很实用：
$$ SNR \approx \frac{1}{N - 2 + \frac{\mu_4}{\sigma^4}} $$
**通俗解读**：
1.  **$N$ 是参数维度**：参数越多（比如神经网络很大），SNR 越低，训练越难。就像要在几万维的迷宫里找路，纯靠瞎撞效率很低。
2.  **噪声分布**：
    *   **高斯噪声**（正态分布）：最常用。
    *   **均匀分布**：在某些特定情况下，它的 SNR 比高斯分布稍好一点点。
    *   **尖峰噪声**：如果噪声分布太奇怪（中间特别尖），$\mu_4$ 很大，SNR 会暴跌。
**工程实践建议**：
*   在设计算法时，如果你发现参数更新方向乱跳，根本不收敛，说明 SNR 太低。
*   **解决方法**：增加采样次数（多跑几次取平均），或者减小扰动幅度（但如果太小又没信号）。

## 6. 给工程师的最后建议
如果你决定在项目中使用无模型策略搜索：
1.  **首选权重扰动**：除非你的策略网络极其复杂，否则权重扰动比完整的策略梯度更容易实现、更稳定，且不需要复杂的自动求导图。
2.  **一定要用基线**：不要用 $J(\alpha+\beta) - J(\alpha)$，一定要维护一个 `running_cost`。这能帮你过滤掉一半以上的噪声。
3.  **关注并行化**：这些算法天然适合并行。你可以同时启动 100 个仿真进程，每个进程加不同的随机噪音，然后统一更新参数。这是加速训练的唯一出路。
4.  **调试技巧**：先把环境设为确定性的（没有随机噪声），看看算法能不能收敛。如果确定性环境都收敛不了，算法肯定写错了。确定收敛后，再加回环境噪声。
