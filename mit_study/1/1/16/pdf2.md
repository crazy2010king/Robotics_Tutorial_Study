## 0. 开篇：从"停在一点"到"稳住一个循环"

### 0.1 一句话概括

> **线性系统永远不会自己产生稳定的周期运动；极限环是非线性系统独有的"宝贝"。本章教你三件事：用轨迹优化"算出"周期解，用横向坐标 + Lyapunov "证明"它稳，用横向 LQR / 零动力学"设计控制器"让系统走上它——而核心技巧是"别看时间，看离轨道偏了多远"。**

### 0.2 作者引言的逐句翻译

**第一层：极限环从哪来？为什么重要？**
> 第4章对行走/奔跑机器人的讨论，激发了**极限环稳定性**的概念。**线性系统 incapable（无能为力）产生稳定的极限环行为**，所以这个丰富的主题**是非线性系统设计与分析独有的**。而且，**设计、稳定、验证极限环所需的工具，适用范围会超出简单的周期运动**。

**类比（极限环 = 心跳 / 步态，全章总纲，请刻进脑子）**：
- **不动点稳定**（前几章）= **一个陀螺立在桌上不动**——目标是"停住"。
- **极限环稳定**（本章）= **一颗心脏不停地、规律地跳**——目标**不是停**，而是"**稳稳地重复同一个循环**"。心跳要是"停在一个状态"，人就死了；心跳的"健康"恰恰在于它**周期性地动**。
- 走路、跑步、扑翼、钟摆不停摆——**全是极限环**。
- **为什么线性系统不行**？线性系统要么衰减到零（停住），要么发散到无穷，要么边际振荡（振幅取决于初值，不"吸引"）——**它没法"把附近的轨迹都吸到同一个固定振幅的循环上"**。**只有非线性，才能造出"自带振幅调节"的循环**（第4章的 Van der Pol 振荡器就是：荡大了自动刹车、荡小了自动加油 → 锁死在一个固定循环）。

**第二层：本章的第一个问题。**
> 我们必须问的第一个自然问题是：**给定一个系统 $\dot x=f(x)$，或一个控制系统 $\dot x=f(x,u)$，我们怎么去找周期解**——这些解可能是**被动稳定的、开环稳定的、或能通过闭环反馈稳定的**？**结果**：我们**已经开发好的轨迹优化工具，非常适合这个任务**。

**人话**：**别以为轨迹优化只能"从 A 开到 B"。把"终点 = 起点"这个约束一加，它就变成了"找一条能首尾相接、循环往复的轨迹"的工具**——**这正是极限环**。

## 1. 用轨迹优化"算出"极限环（16.1）—— 给轨迹"首尾系上橡皮筋"

### 1.1 把"找周期解"写成优化

> 我当初介绍轨迹优化，是把它当作"**从一个已知的特定初值出发，优化一条控制轨迹**"的手段。但"**优化系统的单条轨迹**"这个根本思想，**用处更广**。**即使对一个被动系统**，我们也能把"**搜索周期解**"表述成一个优化——**优化那些满足动力学约束 + 周期性约束 $x[0]=x[N]$ 的轨迹**：

$$\text{find}_{x[\cdot]}\quad \text{subject to}\quad x[n+1]=f(x[n]),\ \forall n\in[0,N-1],\qquad x[0]=x[N]$$

**类比（首尾系橡皮筋，必懂）**：
- 普通轨迹优化 = **让你画一条从 A 到 B 的线**，线要符合物理（动力学约束）。
- 找极限环 = **让你画一条线，但要求"终点必须落回起点"**——**像用橡皮筋把线的两头系在一起，逼它成一个圈**。
- 优化器的工作 = **在"符合物理"的所有圈里，找一个**（或加个目标挑一个最好的）。

### 1.2 一个陷阱：不动点也"假装"是周期解

> **花一分钟想想这个表述的可行解。** 显然，**一个不动点会满足这些约束**（不动点处 $x[n+1]=x[n]=x[0]=x[N]$，全相等，约束全满足）。**如果我们不希望求解器吐出不动点这种解**，我们可能得**用约束排除它们**，或**加一个目标把求解器引向我们想要的解**。

**类比（"站着不动"也算"走了一圈"？）**：
- 你让优化器"找一条走回原地的路"，它**可能偷懒**："**我原地站着不动，不也'回到原地'了吗？**"——**数学上没毛病，但这不是你要的"走一圈"**。
- 所以你得**加规矩**：比如"**中途必须离开原点**"或"**速度不能全为零**"，**逼它真的动起来走一圈**。

### 1.3 离散版的局限："恰好 N 步"太死板

> **另一类可行解**，是**恰好 $N$ 步为周期的轨迹**。**这相当受限（pretty restrictive）。**

**人话**：离散版把"一圈"硬切成 $N$ 步，**等于规定"走一圈必须正好迈 N 步"**——**但真实的周期，迈几步、每步多久，事先不知道**。**所以离散版太死板**。

### 1.4 连续版 + 把"步长"也当变量：简单而强大

> **用连续时间表述，我们能做得更好。** 比如我们介绍直接配置（direct collocation）时写过：

$$\min_{x[\cdot],u[\cdot]}\ \ell_f(x[N])+\sum_{n=0}^{N-1}h_n\,\ell(x[n],u[n])\quad\text{s.t.}\quad \dot x(t_{c,n})=f(x(t_{c,n}),u(t_{c,n})),\ \forall n,\quad x[0]=x_0\ +\text{其他约束}$$

> **但我们也能把 $h_n$ 加进优化当决策变量**（**提醒：我建议设下界 $h_n\ge h_{\min}>0$**）。**这让我们 $N$ 步的轨迹优化能"伸缩时间"，以满足周期性约束。结果简单而强大。**

**类比（让优化器自己决定"每步迈多久"，必懂）**：
- 固定步长 = "**规定每一步必须 0.1 秒**"——**那一圈总时长就被 $N$ 锁死了**，**真实周期对不上就找不到解**。
- $h_n$ 当变量 = "**每步迈多久，优化器自己定**"——**于是它能"把这一圈的时间拉长或压缩"，正好凑成真实周期**。
- **下界 $h_{\min}>0$** = "**但每步不能是 0 秒**"——**否则优化器会作弊，把整圈压成"零时长"，又退化成不动点**。

### 1.5 Example 16.1（找 Van der Pol 振荡器的极限环）

> 回忆 Van der Pol 振荡器的动力学：

$$\ddot q+\mu(q^2-1)\dot q+q=0,\quad \mu>0$$

> 它**展现一个稳定极限环**（第4章见过：荡大自动刹车、荡小自动加油）。

> **表述直接配置优化**：

$$\text{find}_{x[\cdot],h}\quad\text{subject to}\quad q[0]=0,\ \dot q[0]>0,\quad x[N]=x[0]\ (\text{周期约束}),\quad \text{配置动力学约束},\quad 0.01\le h\le 0.5$$

**人话（逐条翻译这些约束）**：
- **$q[0]=0$** = **锚定相位**——**周期轨道有"从哪一刻开始算"的自由度**（同一个圈，从顶点开始画、从底点开始画，是同一条圈）。**固定 $q[0]=0$ 就是"规定从'穿过零点'那一刻开始画"**，**消除这个多余的自由度**（否则优化器有无穷多等价解，难收敛）。
- **$\dot q[0]>0$** = **规定"穿过零点时是往上穿"**——**进一步把"方向"也钉死**（往上穿 vs 往下穿是同一个圈的两个相位，但优化器需要选一个）。
- **$x[N]=x[0]$** = **首尾系橡皮筋**（周期约束）。
- **$0.01\le h\le 0.5$** = **每步时长的上下界**（防零时长作弊，也防一步太大失真）。

> **代码里你会注意到我给了求解器一个初猜。到目前为止多数例子我能避免给初猜**——**求解器拿小随机数当默认初猜，从那儿解**。**但这个问题，我发现它卡在局部极小。加一个"解在状态空间绕一个圆走"的初猜，就够了。**

**类比（给优化器一张"草图"，必懂）**：
- 找极限环的优化**非凸**（有很多"假圈"/局部极小）。
- 优化器从随机点出发，**容易卡在一个"看起来像圈但其实不对"的局部解**。
- **给它一张"大概是圆"的草图当初猜** = **告诉它"别瞎找，答案大概是个圈，从这儿附近开始精修"**——**它就收敛了**。
- **这就是非凸优化的常态**（第10章 10.4.5 讲过）：**好初猜往往比好算法更管用**。

## 2. 用 Lyapunov 分析"证明"极限环稳（16.2）—— 别盯时间，盯"离轨道多远"

### 2.1 轨道稳定：合唱，而非齐步走

> 回忆**"轨迹的时间稳定性"和"极限环稳定性"的重要区别**：**极限环不在相位上收敛**——**环附近的轨迹收敛到环，但环上的轨迹彼此之间未必收敛**。这种稳定性，也叫**轨道稳定性（orbital stability）**，可以写成"**对'一条轨迹所描述的流形'的稳定性**"：

$$\min_\tau\|x(t)-x^*(\tau)\|\to 0$$

> **极限环情况下，这个流形是周期解**，$x^*(t+t_{\text{period}})=x^*(t)$。**根据这个收敛具体怎么发生**，我们可以定义**Lyapunov 意义的、渐近的、指数的、甚至有限时间的轨道稳定性**。

**类比（合唱 vs 齐步走，必懂，这是理解"轨道稳定"的钥匙）**：
- **时间稳定**（第10章轨迹稳定）= **齐步走**：**每一拍，所有人的脚必须同时落地**——**要求"时间上对齐"**。
- **轨道稳定**（本章）= **合唱**：**我不在乎你比我早进半拍还是晚进半拍**（相位不对齐没关系），**我只在乎"我们唱的是同一段旋律"**（轨迹形状/轨道相同）。
- **公式 $\min_\tau\|x(t)-x^*(\tau)\|\to 0$ 的人话** = "**在任意时刻 $t$，我的状态 $x(t)$，离'参考轨道上某个点 $x^*(\tau)$'的距离趋于零**"——**注意 $\tau$ 是可以自由选的**（**我不要求 $\tau=t$**），**所以"我比参考快半拍/慢半拍"完全 OK**，**只要我贴在轨道上**。
- **四种轨道稳定** = "**贴得多快/多死**"：i.s.L.（贴住不跑远）、渐近（越贴越近）、指数（按 $e^{-\alpha t}$ 贴）、有限时间（有限步贴死）。

### 2.2 为什么不用 Poincaré 映射的 Lyapunov？—— 因为算不出 P

> 为证一个系统**轨道稳定**（局部/区域/全局），或**分析极限环的吸引域**，我们可以用 Lyapunov 函数。

> 分析行走/奔跑简单模型时，我们**在 Poincaré 映射上做分析**。确实，**若我们能找到一个 Lyapunov 函数，证明离散 Poincaré 映射的（i.s.L./渐近/指数）稳定，那么这蕴含该环的（i.s.L./渐近/指数）轨道稳定**。**但这种形式的 Lyapunov 函数很难验证，原因相当根本：我们很少有 Poincaré 映射的解析表达式，因为它是对非线性动力学沿整圈积分的结果。**

**类比（Poincaré = 在固定站台打卡，必懂）**：
- **Poincaré 映射 $P$** = **在轨道上设一个固定站台**，**记录"每次经过站台时的状态"**，**看"这一次到下一次"状态怎么变**（第4章讲过）。
- **要证 $P$ 稳定**，得**知道 $P$ 长什么样**——**但 $P$ = "把动力学沿整圈积分一圈"**，**对非线性系统，这个积分**没有解析公式**，**只能数值算**。
- **没有解析 $P$，就很难对 $P$ 做 Lyapunov 分析**（你得对一堆数值点凑 Lyapunov 函数，别扭）。
- **所以本章换路**：**不去积分一整圈求 $P$，而是"在轨道的每一点都看瞬时动力学"**——**这就是下面的横向坐标方法**。

### 2.3 想要什么样的 Lyapunov 函数？—— 环上为零，环外为正

> **所以我们把注意力转向：在全状态空间构造 Lyapunov 函数，用连续动力学。** 特别地，我们想要**下面卡通那种形式的 Lyapunov 函数**——**它们沿环处处为零，环外处处严格为正**。

> **Figure 16.1**：一个**沿极限环为零、其余处处为正**的 Lyapunov 函数卡通（**为可视化起见，去掉了一小段**）。

**类比（一条"零海拔的环形山谷"，必懂）**：
- 普通 Lyapunov（不动点）= **一个碗，碗底是一个点**（那一点海拔=0）。
- 极限环 Lyapunov = **一条"环形的山谷"**——**谷底不是点，而是一整圈**（这一圈海拔全=0），**离开这一圈，海拔就升高**。
- **"轨道稳定"** = **水从山坡流下来，最终流进这条环形谷底，沿着谷底的圈流**（**在圈上往哪流、流多快，无所谓**——**那是相位**）。
- **Figure 16.1 去掉一小段** = **因为"一整圈全为零"画出来是个闭合的环，看不出"是个谷"，所以作者故意挖掉一小段，让你看见"这是个槽"**。

### 2.4 横向坐标（Transverse Coordinates）—— 沿铁轨建一个"移动坐标系"

#### 2.4.1 怎么参数化这种"环上为零"的函数？

> **我们怎么参数化这一类函数？** 对任意的环，在原坐标下这可能非常困难。**对卡通里那种简单环，你可以想象用极坐标。更一般地，我们将定义一个相对轨道的新坐标系，坐标为**：
> - **$\tau$** —— **沿轨道的相位**；
> - **$x_\perp(\tau)$** —— **其余坐标，与 $\tau$ 线性无关**。

> **给定原坐标的一个状态 $x$，我们必须定义一个到这个新坐标系的光滑映射。** 例如，对一个简单环振荡器，我们可能有：

$$\tau=\operatorname{atan2}(-x_2,x_1),\qquad x_\perp=\sqrt{x_1^2+x_2^2}-1$$

> （**Figure 16.2**：沿环振荡器极限环的一个移动坐标系。）

**类比（沿铁轨建里程表 + 横向偏移，全节核心类比，请刻进脑子）**：
- 想象一条**弯曲的铁轨**（=极限环轨道）。
- 你站在铁轨附近某点 $x$。要描述你的位置，**别用"地图上的经纬度"（原坐标 $x$）**，**改用"铁轨坐标系"**：
  - **$\tau$ = 里程表读数** = "**沿铁轨走，离起点走了多远**"（**相位**，告诉你"在轨道的哪一段"）。
  - **$x_\perp$ = 横向偏移** = "**你离铁轨中心线偏了多远、往哪边偏**"（**垂直于轨道方向的偏离**）。
- **环振荡器的例子**：轨道是**单位圆**。**$\tau=\operatorname{atan2}(-x_2,x_1)$ = 你在圆上的角度**（里程表）；**$x_\perp=\sqrt{x_1^2+x_2^2}-1$ = 你离单位圆半径偏了多少**（**在圆上=0，圆外>0，圆内<0**）。**完美对应"横向偏移"**。

#### 2.4.2 几个技术细节（逐条翻译，别怕）

> **一般地，对一个 $n$ 维状态空间，$\tau$ 总是一个标量，$x_\perp$ 是一个 $(n-1)$ 维向量**，定义相对 $x^*(\tau)$ 的其余坐标。

> **事实上，虽然我们用记号 $x_\perp$，但这个坐标系不必严格正交于轨道，只需横截（transversal，即不平行）就行。**

**人话**：
- **$\tau$ 是 1 维**（相位就一个数），**$x_\perp$ 是 $n-1$ 维**（"垂直于轨道"的方向有 $n-1$ 个）——**加起来 $n$ 维，正好覆盖原状态空间**。
- **"$x_\perp$ 不必正交，只需横截"** = **横向坐标不一定要"垂直于轨道"，只要"不沿着轨道"就行**——**就像你量"离铁轨的偏离"，不一定要拿尺子垂直量，斜着量也行，只要别"顺着铁轨量"（那就和里程表 $\tau$ 重复了）**。**"横截=不平行"是底线**。

> **定义好光滑映射后，我们总能把动力学在这个新坐标系里重写**：

$$\dot\tau=f_\tau(x_\perp,\tau),\qquad \dot x_\perp=f_\perp(x_\perp,\tau)$$

> **为简化记号，本章余下部分我们假设这个新坐标系的原点在标称轨迹上**（即 $\min_\tau\|x-x^*(\tau)\|=0\Rightarrow x_\perp=0$）。**类似地，取 $\tau$ 为相位变量，我们将利用"在标称轨迹上 $\dot\tau=f_\tau(0,\tau)=1$"这一事实。**

**人话**：
- **新坐标下的动力学** = "**里程表怎么变**（$\dot\tau$）" + "**横向偏移怎么变**（$\dot x_\perp$）"。
- **原点假设** = "**规定'在轨道上'对应 $x_\perp=0$**"——**这样"横向偏离=0"就精确等于"在轨道上"**。
- **$\dot\tau=1$ 假设** = "**在轨道上时，里程表以匀速 1 增长**"——**即"相位 = 时间"（在轨道上）**。**这是"相位变量"的标准约定**，**让记号干净**。

#### 2.4.3 为什么这套坐标值钱？

> **这个构造对 Lyapunov 分析的价值由 [1] 提出，并被 [2] 漂亮地扩展到控制设计、被 [3] 用于吸引域估计。[4] 给出了定义横向坐标的一个相当通用的数值策略。**

**人话**：**横向坐标 = 把"证明环稳"这件难事，翻译成"证明 $x_\perp\to 0$"这件简单事**——**因为 $x_\perp=0$ 就是"在轨道上"，$x_\perp\to 0$ 就是"贴回轨道"=轨道稳定**。**而 $x_\perp$ 是个普通的 $(n-1)$ 维向量，对它做 Lyapunov 分析，和"对不动点做 Lyapunov 分析"几乎一样熟门熟路**——**只是 Lyapunov 函数 $V(x_\perp,\tau)$ 多了一个"随相位 $\tau$ 变"的参数**。

### 2.5 Theorem 16.1 —— 轨道稳定的 Lyapunov 定理

> **定理 16.1（轨道稳定的 Lyapunov 定理）**：对一个动力系统 $\dot x=f(x)$，$x\in\mathbb{R}^n$，$f$ 连续，一个连续周期解 $x^*(\tau)$，以及一个光滑映射 $x\to(\tau,x_\perp)$，其中 $x_\perp$ 在 $x^*$ 上为零，那么**对原点周围某个 $(n-1)$ 维球 $B$**，若我能造出一个 $V(x_\perp,\tau)$ 使得：

$$\forall\tau,\ V(0,\tau)=0;\qquad \forall\tau,\forall x_\perp\in B,\ x_\perp\ne 0,\ V(x_\perp,\tau)>0$$
$$\forall\tau,\ \dot V(0,\tau)=0;\qquad \forall\tau,\forall x_\perp\in B,\ x_\perp\ne 0,\ \dot V(x_\perp,\tau)<0$$

> **则解 $x^*(t)$ 是局部轨道渐近稳定的。**

> **Lyapunov 意义的轨道稳定和指数轨道稳定也可验证**（分别用 $\dot V_\perp\le 0$ 和 $\dot V_\perp\le\alpha V_\perp$）。

**人话（逐条翻译这四个条件，必懂）**：
- **$V(0,\tau)=0$** = "**在轨道上（$x_\perp=0$），海拔=0**"——**环形谷底**。
- **$V(x_\perp,\tau)>0$（环外）** = "**离开轨道，海拔>0**"——**是个谷，不是山脊**。
- **$\dot V(0,\tau)=0$** = "**在谷底，海拔不变**"——**水在谷底沿圈流，海拔不升不降**（**这对应"相位方向不收敛"，是允许的**）。
- **$\dot V(x_\perp,\tau)<0$（环外）** = "**在坡上，海拔一直降**"——**水一直往谷底流** = **横向偏离一直减小** = **轨道渐近稳定**！
- **两个变体**：$\dot V_\perp\le 0$ = "**坡上不上升**"（i.s.L.，贴住不跑远）；$\dot V_\perp\le\alpha V_\perp$ = "**按指数速率降**"（指数轨道稳定）。

**类比**：**这定理和"不动点的 Lyapunov 定理"长得几乎一样**——**只是把"$V(x)$ 在 $x=0$ 为零、其余为正、导数负"换成了"$V(x_\perp,\tau)$ 在 $x_\perp=0$ 为零、其余为正、导数负"**——**把"到原点的距离"换成"到轨道的横向距离"**。**这就是横向坐标的威力：它把"轨道稳定"这个新概念，"翻译"回了我们熟悉的"不动点稳定"的语言**。

### 2.6 Example 16.2（简单环振荡器）—— 亲手验证一遍

> **也许最简单的振荡器**，是这个**收敛到单位圆的一阶系统**。笛卡尔坐标下，动力学是：

$$\dot x_1=x_2-\alpha x_1\!\left(1-\tfrac{1}{\sqrt{x_1^2+x_2^2}}\right),\qquad \dot x_2=-x_1-\alpha x_2\!\left(1-\tfrac{1}{\sqrt{x_1^2+x_2^2}}\right)$$

> 其中 $\alpha$ 是一个正标量增益。（**Figure 16.3**：环振荡器的向量场。）

**人话（看懂这个向量场）**：
- **括号里 $1-\frac{1}{\sqrt{x_1^2+x_2^2}}$** = "**离单位圆越远，这个值越大**"（**在圆上=0，圆外>0，圆内<0**）。
- **$-\alpha x_1(\cdots),-\alpha x_2(\cdots)$** = **一个"指向/背离圆心"的径向力**——**圆外时把你往圆里拉，圆内时把你往圆外推**——**这就是"把半径锁死在 1"的机制**。
- **$x_2,-x_1$** = **一个"绕圆心转"的切向力**——**让你沿圆转圈**（**这就是相位方向的动力学**）。
- **合起来** = "**一边转圈，一边把半径拽到 1**" = **收敛到单位圆这个极限环**。

> **如果我们取横向坐标为"平移过的极坐标"，使 $x_\perp$ 在单位圆上为零**：

$$\tau=\operatorname{atan2}(-x_2,x_1),\qquad x_\perp=\sqrt{x_1^2+x_2^2}-1,\quad x_\perp>-1$$

> **那么简单的横向动力学就显露出来了**：

$$\dot\tau=1,\qquad \dot x_\perp=-\alpha x_\perp$$

**人话（这就是横向坐标的"魔法时刻"，必懂）**：
- **$\dot\tau=1$** = **里程表匀速走**（**转圈，相位方向**）。
- **$\dot x_\perp=-\alpha x_\perp$** = **横向偏移按指数衰减**（**$x_\perp$ 越大，被拽回越快**）——**这是一个一阶线性稳定系统！**
- **看**：**原本笛卡尔坐标下那坨带根号的非线性动力学，在横向坐标下变成了"$\dot x_\perp=-\alpha x_\perp$"这么干净的东西**——**"贴回轨道"这件事，被彻底解耦、彻底线性化了**。**这就是横向坐标为什么好用**。

> **取 Lyapunov 候选 $V(x_\perp,\tau)=x_\perp^2$，我们可以验证**：

$$\dot V=-2\alpha x_\perp^2<0,\quad \forall x_\perp>-1$$

**人话**：**$V=x_\perp^2$ = "横向偏离的平方"=离轨道的距离平方**。**$\dot V=2x_\perp\dot x_\perp=2x_\perp(-\alpha x_\perp)=-2\alpha x_\perp^2<0$**——**只要 $x_\perp\ne 0$，海拔就降**——**满足定理 16.1，证毕：单位圆极限环局部轨道渐近稳定**。

> **这证明了极限环局部渐近稳定，而且不变开集 $V<1$（即 $x_\perp>-1$）在该极限环的吸引域内。事实上，我们知道所有 $x_\perp>-1$ 都在该极限环的吸引域内，但上面的 Lyapunov 论证没证明到这点。**

**人话（一个诚实的"差距"）**：
- **$V<1$ 即 $x_\perp^2<1$ 即 $-1<x_\perp<1$**——**Lyapunov 只敢保证"这一圈环带"在吸引域内**。
- **但实际**：只要 $x_\perp>-1$（**即不在原点/圆心那个奇点**），**都会收敛到单位圆**——**吸引域其实更大**。
- **为什么 Lyapunov 没证到**？因为 $V=x_\perp^2$ 这个候选"太保守"——**它证的是 $V<1$ 这个子水平集不变，但 $V$ 可以取到 $>1$ 的值而系统照样收敛**。**这是 Lyapunov 方法的通病：它给的是"吸引域的下界估计"，不一定是真吸引域**（第9章 9.1.4 讲过）。**要证更大，得用 SOS 等工具（16.2.3）**。

### 2.7 横向坐标 vs Poincaré 映射：移动打卡机 vs 固定打卡机

> **让我们把这个方法，和我们在行走机器人那章用的 Poincaré 映射分析，再比一次。** 在横向坐标方法里，**有一个额外负担：要沿整条轨迹构造坐标系，而不是只在一个截面（surface of section）上**。**事实上，横向坐标方法有时被称为"移动 Poincaré 截面（moving Poincaré section）"。** 同样地，**这额外工作的回报是：我们能检查一个只涉及瞬时动力学 $f(x)$ 的条件，而不必沿整圈积分动力学去生成离散 Poincaré 映射 $P$。** 下面我们会看到，**这个方法也更兼容"设计稳定极限环的连续反馈控制器"**。

**类比（固定打卡机 vs 移动打卡机，必懂）**：
- **Poincaré** = **在轨道上设一台固定打卡机**——**只有经过那一点才记录**，**要分析就得"积分一整圈，看两次打卡之间状态怎么变"**（**算 $P$**）。
- **横向坐标** = **在轨道的每一点都装一台打卡机**（**移动截面**）——**所以你能"随时看瞬时动力学"**，**不用积分一整圈**。
- **代价** = **你得"沿整条轨道把坐标系都建好"**（**比"只建一个截面"累**）。
- **回报** = **① 条件只涉及瞬时 $f(x)$，好算；② 更兼容连续反馈控制**（**因为你有"每一点的横向动力学"，就能在每一点设计反馈**——**而 Poincaré 只能"每圈调一次"**）。

### 2.8 横向线性化（Transverse Linearization）—— 给极限环配一个"线性初猜"

#### 2.8.1 回忆不动点的套路

> **在不动点的 Lyapunov 分析里，有一个重要特例：对稳定线性系统，我们其实有一个构造 Lyapunov 函数的配方。** 因此，对非线性系统，我们常常**先绕不动点线性化、用线性系统的 Lyapunov 候选当初猜**，觉得方便。**同样的方法可以扩展到极限环分析。**（**Figure 16.4**：横向曲面 + 在横向坐标里定义的 Lyapunov 函数，reproduced from [3]。）

**类比（先线性化当初猜，必懂）**：
- 不动点：非线性系统难证 → **先线性化得 $A$，解 Lyapunov 方程 $PA+A^TP=-Q$ 得 $P$，用 $V=x^TPx$ 当初猜**。
- 极限环：横向非线性动力学难证 → **先横向线性化得 $A_\perp(\tau)$，解"周期 Lyapunov/Riccati 方程"得 $P(\tau)$，用 $V=x_\perp^TP(\tau)x_\perp$ 当初猜**。
- **套路完全平行**——**只是"常数矩阵 $P$"变成了"随相位 $\tau$ 周期变化的 $P(\tau)$"**。

#### 2.8.2 横向线性化 + 周期 Riccati 方程

> **特别地，让我们对横向动力学做一个线性近似**：

$$\dot x_\perp=f_\perp(x_\perp,\tau)\approx \left.\frac{\partial f_\perp}{\partial x_\perp}\right|_{x_\perp=0}x_\perp=A_\perp(\tau)x_\perp$$

> **注意我假设了 $x_\perp$ 在标称轨迹上为零，所以这里不需要"误差坐标"的额外记号。** 记住 $\tau$ 是沿轨迹的相位，**但 [1] 证明了：这个时变线性系统的（指数）稳定，蕴含原系统的局部指数轨道稳定。** 特别地，**若这个横向线性系统是周期且轨道稳定的，那么对每个 $Q=Q^T\succ 0$，存在周期 Riccati 方程的唯一正定解**：

$$V(x_\perp,\tau)=x_\perp^TP(\tau)x_\perp,\quad P^T(\tau)=P(\tau),\quad P(\tau+t_{\text{period}})=P(\tau)$$
$$-\dot P(\tau)=P(\tau)A_\perp(\tau)+A_\perp(\tau)P^T(\tau)+Q,\quad Q=Q^T\succ 0$$

**人话（逐条翻译）**：
- **$A_\perp(\tau)$** = "**横向动力学在轨道上的线性化**"——**一个随相位 $\tau$ 变化的矩阵**（**因为轨道不同位置，'横向怎么被拽回'的规律不同**）。
- **$P(\tau)$ 周期** = "**$P$ 也随 $\tau$ 周期变化**"（**走一圈回到同一点，$P$ 也得回到同值**）。
- **周期 Riccati/Lyapunov 方程** = **不动点 Lyapunov 方程 $PA+A^TP=-Q$ 的"时变周期版"**——**多了一项 $-\dot P$**（**因为 $P$ 自己也在随时间变**）。
- **[1] 的关键定理** = "**这个时变线性系统稳定 ⇒ 原非线性系统局部指数轨道稳定**"——**所以"线性化当初猜"这条路是合法的**。

#### 2.8.3 怎么解周期 Riccati？—— 反向积分到收敛

> **找这些 Lyapunov（及对应 Riccati）方程周期解的数值方法，文献相当丰富。实践中，对我试过的每个问题，我只是把方程反向时间积分，直到积分收敛到一个周期解（这不保证 work，但几乎总是 work）。**

**类比（反向积分 = "倒着放录像直到画面循环"，必懂）**：
- 周期 Riccati 方程是个微分方程，**它的解 $P(\tau)$ 应该是个周期函数**——**但我们不知道初值**。
- **技巧** = **随便给个 $P$ 初值，反向积分**——**因为"稳定系统的 Lyapunov 方程，反向积分是稳定的"**（**正向积分反而可能爆**）——**积分几圈后，$P(\tau)$ 会"锁定"成一个周期波形**——**那就是周期解**。
- **"几乎总是 work"** = **作者的经验之谈**——**理论上不保证，但实践中屡试不爽**。

> **这非常强大。它给了我们一个通用方法，去构造一个 Lyapunov 候选——它既证环的局部稳定，又能用作非线性 Lyapunov 分析的候选。**

**人话**：**横向线性化 + 周期 Riccati = "极限环版的'线性化 + Lyapunov 方程'"**——**给你一把"自动产出 Lyapunov 候选"的钥匙**，**不用凭灵感猜 $V$**。

**补充概念（把占位背后的"该懂的东西"补齐）**：

## 3. 反馈设计：让系统"走上"极限环（16.3）

> **我们为稳定不动点/轨迹开发的许多工具，都能适配到这个新设定。** 讨论 SLIP 模型控制时，我们考虑过**每周期一次的离散控制决策**，能稳定离散 Poincaré 映射。**虽然能用伴随方法得到这个映射的局部线性近似，但记住：我们很少有无非线性 $P$ 的解析表达式。**

### 3.1 每周期一次 vs 连续反馈：什么时候"一圈调一次"就够？

> **把自己限制为"每周期一次决策"，有多局限？** 当然，**连续反馈一般能提升性能**。**但也有些情况，每周期一次决策感觉相当合理。** **腿式机器人的落脚（foot placement）是个好例子**——**一旦选好落脚，我们可能在落脚前做点小修正，但脚着地后很少改这个决定；每步一次似乎是合理近似。** **另一个好例子是扑翼飞行**：**这里拍翼周期时间，可能比质心的动力学时间尺度快得多，每拍一次改一下翼划（wing stroke）的参数，似乎相当合理。**

**类比（一圈调一次 vs 时刻调，必懂）**：
- **每周期一次** = **跑步时"每落地一次，才决定下一步迈哪"**——**脚在空中那段时间，决策不变**。**对落脚这种"离散事件"，很自然**。
- **扑翼** = **鸟每拍一下翅膀，才调一下拍法**——**因为拍得太快，质心来不及反应，没必要拍的过程中一直调**。
- **连续反馈** = **时刻都在微调**——**性能更好，但计算/传感负担更重**。
- **但本章的工具（横向坐标）也给了我们"沿整条轨迹做连续反馈"的机器**——**下面看**。

### 3.2 欠驱动度为一 + 混合零动力学 HZD（16.3.1）—— "把 n 维稳定降成 n-1 维"

> **结果**：我们许多简单行走模型——**特别是点脚、用最小坐标推导的那些**——**只缺一个执行器**（脚与地面之间那个）。**即使相当复杂的机器人也能这么表示**；**这里我要提的大部分理论，最初由 Jessy Grizzle 和他的组、在双足机器人 RABBIT 的背景下开发。** **Jessy 的关键观察是：极限环稳定性本质上是 $(n-1)$ 个自由度的稳定，而你常常能用 $(n-1)$ 个执行器轻松实现它**——**他把这条工作线称为"混合零动力学"（Hybrid Zero Dynamics, HZD）。** "混合"部分我们下一章处理，**这里给一个简单例子说明"零动力学"概念。[Coming soon...]**

**类比（n-1 维稳定，全节核心类比，必懂）**：
- 极限环 = **一条 1 维的圈**（相位方向）。
- 整个状态空间 = **$n$ 维**。
- **"偏离环"的方向** = **$n-1$ 维**（横向 $x_\perp$）。
- **轨道稳定 = "把 $n-1$ 个横向方向稳住"**——**相位方向不用管**（**它自己会沿圈走**）。
- **所以** = **你只需要 $n-1$ 个执行器，去稳 $n-1$ 个横向方向**——**比"稳全部 $n$ 维"少用一个执行器**！**这就是"欠驱动度为一"的行走模型，居然能稳定极限环的原因**——**它缺的那一个执行器，正好是"相位方向不需要控"省下来的**！
- **HZD / 零动力学** = **"把系统约束在'横向=0'这个 $(n-1)$ 维流形上，然后看流形上剩下的动力学（零动力学）够不够完成任务"**——**若够，就成了**。

> **稳定零动力学 = 实现轨道稳定。**

> **有趣的是，它并不保证你会绕极限环走。** HZD 行走器的一个"特性"是：**你实际上可以站在它们面前，用手挡住它们的前进**——**控制系统会继续作用，把自己维持在环上，但沿环的进度停了。** **有些机器人你甚至能往后推它们，它们会反向走同一个行走周期。** **若想证明"前进会发生"，那么任务就归约为：检查沿环的相位变量的一维动力学。**

**类比（原地踏步 vs 往前走，必懂，这是 HZD 最反直觉也最妙的点）**：
- HZD 只稳"横向"（**保证"走路的姿势/步态"是对的**），**不控"相位"**（**不控"走多快/往不往前走"**）。
- 所以**你用手挡住机器人** = **相位被外力冻住**——**但控制系统还在拼命维持"正确的步态姿势"**——**于是机器人"原地踏步走"**（**步态在循环，但位置不动**）。
- **你往后推** = **相位倒着走**——**机器人"倒着走同一个步态"**。
- **这说明**：**HZD 保证了"步态这个循环稳"，但没保证"循环会往前推进"**——**"往前推进"是相位方向的事，得单独检查那一维动力学**（**比如"每一步净前进>0"**）。
- **人话**：**HZD 管"走得对不对"，不管"走不走得动"**——**后者要另查**。

> **"零动力学"的概念当然不限于欠驱动度为一的系统。** 一般地，**我们能轻松用 $m$ 个执行器稳定一个 $m$ 维流形**（在任务空间 PFL 那节见过），**若"在该流形上"足以完成我们的任务，或我们能证"流形上结果动力学"足以完成任务，那就皆大欢喜。** **但在"欠驱动度为一"的情况，研究的流形是一条轨迹/轨道，本章的工具立刻适用。**

**人话**：**零动力学 = "把系统按在某个流形上，看流形上剩下的自由度怎么动"**。**$m$ 个执行器能按死 $m$ 维**。**当那个流形正好是"极限环轨道"（1 维），按死它需要 $n-1$ 个执行器，剩下 1 维（相位）就是"零动力学"**——**这正是欠驱动度为一的情形**。

### 3.3 横向 LQR（16.3.2）—— "只纠正横向偏离，不追时刻表"

> **稳定环的另一个自然方法，用横向线性化。** 特别地，**对一条标称（控制）轨迹 $[x_0(t),u_0(t)]$，$\dot x_0=f(x_0,u_0)$，我们可以近似横向动力学**：

$$\dot x_\perp=f_\perp(x_\perp,\tau,u)\approx \left.\frac{\partial f_\perp}{\partial x_\perp}\right|_{x_\perp=0}x_\perp+\frac{\partial f_\perp}{\partial u}(u-u_0(\tau))=A_\perp(\tau)x_\perp+B_\perp(\tau)\bar u$$

> **[2] 证明：稳定这个系统的（周期）时变 LQR 控制器，实现原系统的轨道稳定。**

**人话**：**这就是"横向坐标版的时变 LQR"**——**在横向线性系统 $\dot x_\perp=A_\perp x_\perp+B_\perp\bar u$ 上跑时变 LQR，得 $\bar u=K_\perp(\tau)x_\perp$**——**[2] 保证这能让原非线性系统轨道稳定**。

#### 3.3.1 横向 LQR vs 全坐标时变 LQR：追不追时刻表？

> **让我们花一分钟，欣赏这个方法和"全坐标时变 LQR"的区别。** 当然，**行为相当不同**：**全坐标的时变 LQR 会试图减速或加速，以与标称轨迹保持时间同步；而这个控制器完全不试图稳定相位变量。**

**类比（追时刻表 vs 只追轨道，必懂，这是横向 LQR 的精髓）**：
- **全坐标时变 LQR** = **一个"强迫症司机"**：**他不仅要"开在路线上"，还要"严格按时刻表"**——**晚了一秒就加速、早了一秒就减速**，**非要和标称轨迹"时间对齐"**。
- **横向 LQR** = **一个"佛系司机"**：**他只在乎"开在路线上"**（**横向偏离=0**），**完全不在乎"比时刻表快一秒还是慢一秒"**（**相位随便**）。
- **对极限环来说，"佛系"才是对的**——**因为轨道稳定本来就允许相位不对齐**！**强迫症司机"追时刻表"是在做无用功，甚至可能帮倒忙**。

> **你可能想：我可以设计原来的时变控制器，然后执行时"投影到最近时间"**（**即找 $t=\arg\min_\tau\|x-x_0(\tau)\|$，用那个时间的反馈**）。**但这个投影不保证安全；你能找到这样的系统——横向线性化能稳定它，但用基于该投影的反馈，闭环却不稳定。**

> **Example 16.3（时变 LQR 简单地在时间上投影，可导致不稳定。）Coming soon...**

**人话**：**"投影到最近时间"看起来是个聪明的折中**（**用全坐标 LQR，但执行时对齐到最近的轨道点**），**但它破坏了 LQR 的稳定性证明**——**因为 LQR 是"按固定时间 $t$ 设计的"，你临时把 $t$ 换成"最近时间"，等于偷偷改了控制器，稳定性保证就没了**。**横向 LQR 从根上就没这问题**——**它压根不用"时间"当索引，用"相位 $\tau$"当索引，而 $\tau$ 本来就是"轨道上的位置"**。

#### 3.3.2 横向 LQR 更重要的好处：要求更少 → 增益更小

> **但还有一个更重要的理由喜欢横向 LQR 方法。** **若你只需要轨道稳定，那么这是问题的更好表述，因为你要求的更少。** **正如我们刚用混合零动力学讨论的，用 $m$ 个执行器稳定 $m$ 个自由度，与稳定 $m+1$ 个自由度，可能非常不同。** **在横向表述里，我们让 LQR 只在横向坐标里最小化代价**（**这在数学上等价于：在全坐标设计一个"在标称轨迹方向为零"的代价函数**）。**实践中，这可能导致小得多的 cost-to-go 矩阵 $S(t)$，和更小的反馈增益 $K(t)$。** **对欠驱动系统，这个差别可能是戏剧性的。**

**类比（少管一件事 = 力气省一大截，必懂）**：
- **全坐标 LQR** = **要同时稳 $m+1$ 维**（**$m$ 个横向 + 1 个相位**）——**对欠驱动系统，"相位那一维"可能根本控不住或很难控**，**LQR 为了"勉强管它"，会把增益 $K$ 调得很大、$S$ 调得很胖**。
- **横向 LQR** = **明说"相位我不管"**，**只稳 $m$ 个横向**——**LQR 不用为"管不住的那一维"白费力气**，**于是 $K$ 小、$S$ 瘦**。
- **"对欠驱动系统差别戏剧性"** = **欠驱动系统本来就"自由度不够全控"**，**全坐标 LQR 在"控不住的方向"上死磕，会非常吃力**；**横向 LQR 聪明地绕开那个方向，轻松得多**。

### 3.4 非周期轨迹的轨道稳定（16.3.3）—— "不关心时间"也适用

> **"轨道稳定一条轨迹，可以对欠驱动控制系统要求少得多（并导致更小的 LQR 反馈增益）"这一观察，相当强大。** **它不限于稳定周期运动。** **若你的目标是稳定状态空间里一条非周期的路径，但并不真正关心时间，那么用轨道稳定来表述你的稳定问题，可能是一个非常好的选择。** **你能找到这样的例子：系统在横向坐标里可稳定，但在全坐标里不可稳定。**

> **Example 16.4（横向坐标可稳定，但全坐标不可稳定。）Coming soon...**

**类比（只关心"走哪条路"，不关心"几点到"，必懂）**：
- 你想让车**沿着一条山路开**，**但不在乎"开多快/几点到终点"**。
- **全坐标稳定** = **要求"严格按时刻表开到每个路标"**——**对欠驱动车，这可能做不到**（**比如某段坡太陡，控不住速度**）。
- **轨道稳定** = **只要求"别开出山路"**（**横向偏离=0**），**速度随便**——**这容易得多**，**欠驱动车也能做到**。
- **所以"不关心时间"时，轨道稳定是"更宽松、更可行"的目标**。

> **但要小心，因为反过来也可能成立：系统可能在全坐标里可稳定，但在某些横向坐标里不可稳定——若你把那些坐标选得很差。**

> **Example 16.5（全坐标可稳定，但横向坐标不可稳定。）** 考虑双积分器 $u(t)=1$ 的一条轨迹（从任意初值）。**我们当然能在全坐标里用 LQR 稳定这条轨迹。** 技术上，**我们可以选横向坐标 $\tau=\dot q$，$x_\perp=q$。** **显然 $x_\perp$ 处处横截于标称轨迹。** **但这个横向线性化显然不可稳定。这是个差选择！**

**人话（看懂这个"坏横向坐标"的反例，必懂）**：
- **双积分器 $\ddot q=u$，标称轨迹 $u=1$**（**匀加速，$\dot q$ 一直涨，$q$ 一直涨**）。
- **全坐标 LQR** = **能稳**（**双积分器全状态可控**）。
- **坏横向坐标**：$\tau=\dot q$（**用速度当"相位"**），$x_\perp=q$（**用位置当"横向偏离"**）。
- **为什么坏**？因为标称轨迹上 $\dot q$ 一直涨，**"相位" $\tau=\dot q$ 不是周期的、也不是良定义的"轨道参数"**——**而且 $x_\perp=q$ 的横向动力学，在这个选择下"控不住"**（**你控 $u$ 直接影响 $\ddot q=\dot\tau$，对 $x_\perp=q$ 的横向控制是"间接且别扭"的**）——**横向线性化不可稳定**。
- **教训** = **横向坐标不是"随便选"都行**——**选得差，会把"本来可稳"的系统变成"横向不可稳"**。

> **设计横向坐标的通用方法 [4]，可以通过在优化横向坐标时包含一个可控性判据，来解决这个顾虑。**

**人话**：**[4] 的方法 = "不光建横向坐标，还顺便检查'在这个横向坐标下，横向系统可不可控'，把可控性当成优化横向坐标时的约束"**——**自动避开 Example 16.5 那种坏选择**。

## 增补一：把"还不够通俗"的 5 个概念，各加一个类比 / 澄清

1. **横向坐标为什么"不必正交，只需横截"**？正交 = "垂直量偏离"，横截 = "只要不顺着轨道量"。**正交是横截的特例**。**为什么横截就够**？因为我们只要求"$x_\perp=0$ 精确对应'在轨道上'"，且"$x_\perp$ 的方向和 $\tau$ 的方向线性无关"——**斜着量偏离，照样能区分'在轨道上'和'偏离轨道'**，**只是数值不同，不影响'趋于零'这个结论**。**类比**：量"离河岸多远"，垂直量最准，但斜着拉皮尺也行——**只要别"顺着河岸量"（那就量成'沿河走了多远'=和 $\tau$ 重复了）**。
2. **周期 Riccati 反向积分为何收敛**？因为**对稳定系统，Lyapunov/Riccati 方程的"齐次部分"反向积分是稳定的**（**正向积分时，误差按 $A$ 的不稳定模增长；反向积分时，这些模变成衰减**）。**所以反向积分几圈，$P(\tau)$ 的"瞬态"衰减完，剩下的就是周期解**。**类比**：**正向积分像"顺着瀑布冲"，误差被放大；反向积分像"逆着瀑布爬回源头"，反而能稳定地收敛到那个'循环波形'**。
3. **为什么全坐标时变 LQR 追时间、横向 LQR 不追**？因为**全坐标 LQR 的代价 $x^TQx$ 里，"沿标称轨迹方向的位置误差"也被罚了**——**而"比标称快/慢"在那个方向上表现为误差**，**所以 LQR 会去纠正它**。**横向 LQR 的代价只在 $x_\perp$ 上**（**等价于全坐标代价在标称方向=0**），**"快/慢"是相位方向的事，$x_\perp$ 看不见**，**所以不纠正**。**这就是"代价函数定义在哪个子空间，就只稳哪个子空间"**。
4. **HZD 为什么"挡得住前进"**？因为 HZD 把系统约束在"零动力学流形"上，**这个流形上的动力学 = 相位的一维动力学**。**用手挡 = 外力把相位冻住**，**但控制系统仍在维持"横向=0"（在流形上）**——**所以"步态姿势"还在循环，只是相位不前进 = 原地踏步**。**要证前进，得证"流形上那一维相位动力学，$\dot\tau>0$"**——**这是 HZD 论文里单独的一步**。
5. **Example 16.5 的坏坐标，坏在哪**？双积分器 $u=1$ 标称轨迹是 $\ddot q=1$，**$\dot q$ 线性增长、$q$ 二次增长**——**这不是周期轨道，是"一直加速的直线"**。**选 $\tau=\dot q$ 当相位**，**但 $\dot q$ 一直涨、不循环**，**"相位"失去了"轨道参数"的意义**；**而 $x_\perp=q$ 的横向动力学，对 $u$ 的响应是"二阶间接"的**（**$u$ 控 $\ddot q=\dot\tau$，对 $x_\perp=q$ 是"隔了两层"**），**横向线性化不可控**。**教训**：**横向坐标要选得让"横向动力学对控制有直接的、可控的响应"**——**[4] 用"优化时带可控性判据"自动保证这点**。

### 实验 1：找 Van der Pol 极限环 —— 打靶法（可跑，对齐 16.1 的"周期约束"思想）

**PDF 用直接配置（NLP）。在纯 numpy 里，"找周期轨道"最易跑通的等价方法是打靶法（shooting）：把"积分一圈后回到起点"当方程，用 `root` 解；加 $q(0)=0$ 锚定相位自由度。** 对**稳定**极限环，其实"直接积分到稳态"最简单，但打靶法能找**不稳定**环、能加控制、能精确满足周期条件——**这正是 PDF 用优化的动机**。

```python
import numpy as np
from scipy.integrate import solve_ivp
from scipy.optimize import root
mu = 1.0
def vdp(t, x):                      # x=[q, qd]; q̈+μ(q²-1)q̇+q=0
    return [x[1], -mu*(x[0]**2-1)*x[1] - x[0]]
# 方法A(最简单): 稳定环直接积分到稳态
sol = solve_ivp(vdp, [0, 50], [0.5, 0.0], rtol=1e-9)
print("方法A 积分到稳态, 末状态≈", np.round(sol.y[:,-1],3), " (已在极限环上)")
# 方法B(打靶法, 对齐PDF周期约束): 锚定 q(0)=0, 变量=[qd0, T], 残差=[q(T)-0, qd(T)-qd0]
def residual(z):
    qd0, T = z
    s = solve_ivp(vdp, [0, T], [0.0, qd0], rtol=1e-10)
    qT, qdT = s.y[:, -1]
    return [qT - 0.0, qdT - qd0]      # 周期条件: 回到 (q=0, qd=qd0)
res = root(residual, [2.0, 6.0], method='hybr')   # 初猜: qd0≈2, 周期T≈6
qd0, T = res.x
print("方法B 打靶法: 周期 T=%.4f, q̇(0)=%.4f, 残差=%.2e" % (T, qd0, np.linalg.norm(res.fun)))
# 验证: 用找到的初值积分一圈, 应闭合
s = solve_ivp(vdp, [0, T], [0.0, qd0], rtol=1e-10)
print("   一圈后回到 (q,q̇)=", np.round(s.y[:,-1],4), " ≈ (0, %.4f)" % qd0)
```

**你会看到**：**方法 A 末状态落在极限环上**；**方法 B 打靶法精确解出周期 $T\approx 6.66$（$\mu=1$ 的 VdP 周期）和 $q̇(0)$，一圈后残差 $\approx 0$**——**亲手复现 16.1 的"用周期约束找极限环"**。**改 $\mu$**，**看周期和波形变**（**$\mu$ 大 → 张弛振荡，波形更方**）。**这就是 PDF 直接配置在 numpy 里的"打靶法替身"**——**思想一致：把 $x[N]=x[0]$ 当约束/方程**。

### 实验 2：环振荡器横向坐标 + Lyapunov 验证（可跑，对齐 Example 16.2）

**亲手验证 $\dot x_\perp=-\alpha x_\perp$ 和 $\dot V=-2\alpha x_\perp^2<0$**，并画"原坐标向量场 + 横向偏离衰减"。

```python
import numpy as np
import matplotlib.pyplot as plt
alpha = 1.0
def ring(t, x):                     # Example 16.2 笛卡尔动力学
    r = np.hypot(x[0], x[1])
    fac = alpha*x[0]*(1 - 1/r) if r>1e-9 else 0.0
    fac2 = alpha*x[1]*(1 - 1/r) if r>1e-9 else 0.0
    return [x[1] - fac, -x[0] - fac2]
# 验证横向动力学: 取环外一点, 数值微分看 x⊥ 是否按 -α x⊥ 衰减
x = np.array([2.0, 0.0]); dt = 1e-3
xperp_hist = []
for _ in range(2000):
    r = np.hypot(x[0], x[1]); xperp = r - 1.0; xperp_hist.append(xperp)
    x = x + np.array(ring(0, x))*dt
xperp_hist = np.array(xperp_hist)
t = np.arange(len(xperp_hist))*dt
print("横向偏离 x⊥: 初=%.3f -> 末=%.4f (应指数衰减到0)" % (xperp_hist[0], xperp_hist[-1]))
print("验证 -α x⊥: 数值d(x⊥)/dt / x⊥ ≈ %.3f (应≈ -α = -1.0)" %
      ((xperp_hist[100]-xperp_hist[50])/(50*dt) / xperp_hist[75]))
# V=x⊥² 的导数应 = -2α x⊥² < 0
V = xperp_hist**2
print("V=x⊥² 单调递减? %s (V̇=-2αx⊥²<0 的体现)" % bool(np.all(np.diff(V) <= 1e-12)))
plt.figure(); plt.plot(t, xperp_hist, label='x⊥(t) 横向偏离'); plt.plot(t, np.exp(-alpha*t)*xperp_hist[0],'--',label='e^{-αt}x⊥(0)')
plt.legend(); plt.xlabel('t'); plt.title('Example 16.2: 横向偏离按 e^{-αt} 衰减 -> 轨道稳定'); plt.grid(alpha=.3); plt.show()
```

**你会看到**：**$x_\perp$ 精确按 $e^{-\alpha t}$ 衰减**（**和解析解 $\dot x_\perp=-\alpha x_\perp$ 完全吻合**），**$V=x_\perp^2$ 单调递减**——**亲手验证 Example 16.2 的 Lyapunov 论证**。**改初值半径**（如 0.3，即 $x_\perp=-0.7$），**看圆内的点也被推到单位圆**——**体会"吸引域比 $V<1$ 大，但 Lyapunov 只证到 $V<1$"**。

### 实验 3：横向线性化 + 周期 Riccati 反向积分（可跑，对齐 16.2.2）

**用一个 toy 周期横向系统 $\dot x_\perp=A_\perp(\tau)x_\perp$，$A_\perp(\tau)=-1-0.5\sin\tau$（周期 $2\pi$，稳定），反向积分 Lyapunov 方程 $-\dot P=2A_\perp P+Q$ 到周期解**——**看 $P(\tau)$ 锁定成周期波形**。

```python
import numpy as np
import matplotlib.pyplot as plt
Q = 1.0; Tper = 2*np.pi
def A_per(tau): return -1.0 - 0.5*np.sin(tau)        # 周期横向线性化(标量toy)
# 反向积分 -Ṗ = 2 A⊥ P + Q  =>  令 s=-τ 正向积分 Ṗ = 2 A⊥ P + Q (注意 A⊥ 用 -s)
def rhs(s, P): return 2*A_per(-s)*P + Q               # 反向时间 s=-τ
# 反向积分多圈, 看 P 收敛到周期解
P = 1.0; hist = []
for cycle in range(8):
    sol = solve_ivp(rhs, [0, Tper], [P], rtol=1e-10, t_eval=np.linspace(0,Tper,100))
    P = sol.y[0,-1]; hist.append(P)
    # 记录最后一圈的 P(τ) 波形
    if cycle == 7:
        taus = np.linspace(0, Tper, 100)
        s2 = solve_ivp(rhs, [0, Tper], [P], rtol=1e-10, t_eval=taus)
        P_wave = s2.y[0]; taus_real = -taus % Tper     # 转回 τ
print("反向积分 P 每圈末端:", np.round(hist,4), " -> 收敛到周期解")
plt.figure(); plt.plot(np.sort(taus_real), P_wave[np.argsort(taus_real)])
plt.xlabel('τ (相位)'); plt.ylabel('P(τ)'); plt.title('16.2.2: 周期 Lyapunov 解 P(τ) (反向积分收敛)'); plt.grid(alpha=.3); plt.show()
# 验证: V=x⊥²P(τ) 沿横向动力学应递减 (V̇ = x²(+2A⊥P) = x⊥²(-Q) < 0)
print("验证 V̇=x²(+2AP)=x²(-Q)<0: 由构造 -Ṗ=2A⊥P+Q 恒成立 -> 轨道指数稳定")
```

**你会看到**：**$P$ 每圈末端收敛到一个定值**（**周期解锁定**），**$P(\tau)$ 是个周期波形**——**亲手复现 16.2.2 的"反向积分到周期解"**。**验证行**说明 $V=x_\perp^2P(\tau)$ 的导数 $=x_\perp^2(-Q)<0$——**正是周期 Lyapunov 方程保证的**。**这就是"自动产出极限环 Lyapunov 候选"的数值机器**。

### 实验 4：横向 LQR vs 全坐标时变 LQR —— "追不追时刻表"（可跑，对齐 16.3.2 + Example 16.5 思想）

**双积分器标称轨迹 $u_0=1$。对比：① 全坐标时变 LQR（追时间，增益大）② "只稳横向 $x_\perp=q-q_0(\tau)$、不追相位"的控制器（增益小）。展示"佛系司机 vs 强迫症司机"。**

```python
import numpy as np
import matplotlib.pyplot as plt
# 标称轨迹 u0=1: q0(t)=0.5 t², qd0(t)=t (从0出发)
def nominal(t): return 0.5*t**2, t
# 全坐标时变LQR(简化: 用固定LQR追标称, 体现"追时间")
A=np.array([[0,1],[0,0]]); B=np.array([[0],[1.]]); Qf=np.eye(2); Rf=np.array([[1.]])
from scipy.linalg import solve_continuous_are
S=solve_continuous_are(A,B,Qf,Rf); K_full=np.linalg.solve(Rf, B.T@S)   # 全坐标增益
# 横向LQR思想: 只罚横向位置误差 e=q-q0(τ), 不罚"相位/时间误差" -> 用更小权重
Q_trans=np.array([[1.,0],[0,0.]]);  # 只罚位置偏离, 不罚速度(速度≈相位方向)
S_t=solve_continuous_are(A,B,Q_trans+1e-3*np.eye(2),Rf); K_trans=np.linalg.solve(Rf,B.T@S_t)
print("全坐标增益 K_full =", np.round(K_full,3), " (大, 追时间)")
print("横向思想增益 K_trans=", np.round(K_trans,3), " (小, 不追相位)")
# 仿真: 初值偏离标称, 看两种控制
def sim(K, T=5, dt=0.01):
    x=np.array([0.5,0.0]); traj=[]   # 初始位置偏0.5
    for n in range(int(T/dt)):
        t=n*dt; q0,qd0=nominal(t)
        u=-K@(x-np.array([q0,qd0]))   # 追标称
        x=x+np.array([x[1],u[0]])*dt; traj.append(x.copy())
    return np.array(traj)
tf=sim(K_full); tt=sim(K_trans)
plt.figure(); plt.plot(tf[:,0]-0.5*np.arange(len(tf))*0.01**2*0, label='全坐标(追时间)')
plt.plot(tt[:,0], label='横向思想(不追相位)'); plt.legend(); plt.ylabel('q(t)'); plt.title('16.3.2: 全坐标追时刻表 vs 横向只追轨道'); plt.grid(alpha=.3); plt.show()
```

**你会看到**：**全坐标增益明显更大**（**因为它要同时管"位置+速度/时间"**），**横向思想增益更小**——**亲手验证 16.3.2 的"横向 LQR 要求更少 → 增益更小"**。**对欠驱动系统，这个差距会更戏剧性**（**全坐标在"控不住的方向"死磕**）。**Example 16.5 的教训**也在这里：**若横向坐标选成 $\tau=\dot q,x_\perp=q$，横向系统不可控，这套就失效**——**所以选坐标要带可控性判据（[4]）**。

### 实验 5：HZD / 零动力学思想 —— "稳住 n-1 维横向，相位不控 → 可被挡停"（可跑，对齐 16.3.1）

**toy 系统：状态 $(x_\perp, \tau)$，$\dot x_\perp=-x_\perp+u$（横向，可控），$\dot\tau=1+x_\perp$（相位，靠横向间接推进）。用 $u=-2x_\perp$ 稳横向 → 轨道稳定；但加"外力挡相位"（$\dot\tau$ 被冻）→ 横向仍稳，进度停 = 原地踏步。**

```python
import numpy as np
import matplotlib.pyplot as plt
def hzd(block_phase=False):
    xp, tau = 1.0, 0.0           # 初始横向偏离1, 相位0
    hist=[]
    for _ in range(500):
        u = -2*xp                # 稳横向的反馈
        dxp = -xp + u            # = -3 xp -> 横向指数稳定
        dtau = 0.0 if block_phase else (1 + xp)   # 相位动力学; block=用手挡
        xp += 0.01*dxp; tau += 0.01*dtau; hist.append((xp,tau))
    return np.array(hist)
free=hzd(False); blocked=hzd(True)
plt.figure(); plt.subplot(211); plt.plot(free[:,1], label='自由: 相位前进'); plt.plot(blocked[:,1], label='被挡: 相位停(原地踏步)'); plt.ylabel('τ 相位'); plt.legend(); plt.grid(alpha=.3)
plt.subplot(212); plt.plot(free[:,0], label='x⊥ 横向'); plt.axhline(0,color='k',ls=':'); plt.ylabel('x⊥'); plt.legend(); plt.grid(alpha=.3)
plt.suptitle('16.3.1 HZD: 横向稳住=轨道稳定; 挡相位->步态在循环但进度停'); plt.show()
print("被挡时: 横向x⊥→0 (步态姿势对), 但相位τ不动 (不前进) -> 印证HZD'挡得住前进'")
```

**你会看到**：**两种情况横向 $x_\perp$ 都趋于 0**（**步态姿势都被稳住 = 轨道稳定**），**但"被挡"时相位 $\tau$ 不动**（**原地踏步**），**"自由"时相位前进**——**亲手复现 HZD 最妙的特性**：**"稳定零动力学 = 轨道稳定，但不保证绕环前进；前进要单独查相位那一维"**。

## 给初学者的"本章通关三句话"

1. **极限环 = 心跳，不是停住而是稳稳重复**：线性系统造不出它，只有非线性行；**找它**用轨迹优化加周期约束 $x[0]=x[N]$（**首尾系橡皮筋**，$h$ 当变量让优化器自己凑周期，记得锚定相位、排除"站着不动"的假解、给"绕圆"初猜）。
2. **横向坐标 = 沿铁轨建里程表 + 横向偏移**：把"证明环稳"降维成"证明横向偏离 $x_\perp\to 0$"——**环上 $V=0$、环外 $V>0$、环外 $\dot V<0$**（Theorem 16.1），**而横向线性化 $A_\perp(\tau)$ + 周期 Riccati 反向积分，能自动产出 Lyapunov 候选**；**这套"移动 Poincaré 截面"只看瞬时 $f(x)$，不必积分整圈，还更兼容连续反馈**。
3. **稳环只要稳 $n-1$ 维横向，相位不用管**：这正是 HZD/零动力学的精髓——**用 $n-1$ 个执行器稳 $n-1$ 个横向方向，省下的那一个正好是"相位不需要控"**；**代价是"你可以用手挡住机器人前进，它还在原地踏步走"（步态稳但进度停），所以"会不会前进"要单独查相位那一维**；**而横向 LQR 因为"不追时刻表"，增益比全坐标 LQR 小得多——对欠驱动系统，这个差别是戏剧性的**（**但横向坐标别选错，否则会把可稳的系统变成横向不可稳，[4] 用"优化时带可控性判据"来避坑**）。
