## 开篇：为什么走路比飞行更难？

作者Tedrake教授在开头提出了一个反直觉的观点：**双足行走控制可能比飞行更难**。

为什么？因为**接触（Contact）**。

> 🦶 **类比**：想象你在溜冰场上。当你双脚着地时，地面可以推你；当你双脚离地时，地面完全不管你了。这种"有时有支撑、有时没有"的**间歇性接触**，给系统引入了根本性的**离散/组合复杂性**。

作者还说了一句很有哲理的话："看到那么多机器人一辈子都在避免接触，真让人难过。**控制接触意味着你的机器人能够对物理环境做功**——这不正是机器人的意义所在吗？"

## 4.1 极限环（Limit Cycles）：从"停住"到"循环"

前两章我们研究的是系统**最终停在哪里**（固定点稳定性）。但行走和奔跑是**周期性的**——每一步都在重复。所以我们需要把"稳定性"的概念从**固定点**推广到**周期轨道**。

### 🎯 极限环是什么？

**极限环**就是系统在相空间中画出的一条**闭合轨道**，而且附近的轨迹都会被"吸引"到这条轨道上。

> 🎡 **类比**：固定点像是一个**漏斗底**——东西掉进去就停住了。极限环像是一个**跑步机**——你上去之后不会停在一个位置，而是以一个固定的节奏循环运动。周围的轨迹就像被跑步机"吸"过去一样。

### 例4.1：范德波尔振荡器（Van der Pol Oscillator）

方程：
$$\ddot{q} + \mu(q^2 - 1)\dot{q} + q = 0, \quad \mu > 0$$

**通俗拆解**：
- 如果 $|q| > 1$（摆动很大）：$(q^2-1) > 0$，阻尼项为正 → **消耗能量**（像刹车）
- 如果 $|q| < 1$（摆动很小）：$(q^2-1) < 0$，阻尼项为负 → **增加能量**（像踩油门）

> 🚗 **类比**：想象一个智能巡航系统。当你开得太慢时，它自动加速；当你开得太快时，它自动刹车。最终你会稳定在一个**固定速度**上循环——不快也不慢。这就是范德波尔振荡器的核心思想：**系统自己调节能量，最终稳定在一个极限环上**。

**相图（左）**：所有轨迹（红、绿、蓝）最终都卷到同一个闭合轨道上。
**时域图（右）**：不同初始条件的轨迹最终**同步**到同一个振幅和频率，但**不一定同步相位**（时间上可能对不齐）。

### ⚠️ 关键洞察：轨道稳定性 ≠ 轨迹稳定性

在时域中，即使两个轨迹都收敛到同一个极限环，它们的**时间差**可能不会消失：

$$\lim_{t\to\infty} |x(t) - x^*(t)| = 0 \quad \text{（不一定成立！）}$$

因为相位可能永远差半拍。

所以我们重新定义**轨道稳定性**：
$$\min_\tau ||x(t) - x^*(\tau)|| < \epsilon$$

> 🎭 **类比**：轨迹稳定性要求你和朋友**每一步都同步**（同手同脚）。轨道稳定性只要求你和朋友**在同一个跑道上**——你可以领先他半圈，只要你们跑的速度和圈数一样就行。

### 4.1.1 庞加莱映射（Poincaré Maps）：把周期问题"切片"

这是分析极限环的**核武器**。

**思想**：与其盯着连续的时间看，不如在轨道上**切一刀**，只看系统每次"经过"这个切面的状态。

> 🎠 **类比**：想象你在看旋转木马。你不需要盯着每一匹马看一整圈。你只需要站在门口，记录每次同一匹马经过门口时的**速度**和**高度**。如果每次记录的值都一样，木马就在稳定循环。

**数学定义**：
- 在 $n$ 维状态空间中，选一个 $(n-1)$ 维的**截面** $S$（比如 $q=0$ 且 $\dot{q}>0$ 的线）
- 要求 $S$ **横截**于流（轨迹穿过它，而不是平行于它）
- **庞加莱映射**：$x_p[n+1] = P(x_p[n])$

**极限环稳定性 ⇔ 庞加莱映射固定点稳定性**：
- 如果 $x_p^* = P(x_p^*)$ 是映射的稳定固定点，那么对应的连续系统轨道就是稳定极限环。

### 例4.2：范德波尔振荡器的庞加莱映射

选截面 $S$：$q=0, \dot{q} \geq 0$（每次穿过纵轴向上时）。

因为系统是2维的，截面是1维的（只有 $\dot{q}$ 一个坐标）。我们可以画出**返回映射**：
- 横轴：本次穿过时的速度 $\dot{q}_p[n]$
- 纵轴：下次穿过时的速度 $\dot{q}_p[n+1]$

**楼梯法（Cobweb/Staircase）分析**：
1. 画出返回映射曲线 $y = P(x)$ 和 $y = x$ 的45度线
2. 从初始点 $(x_0, x_0)$ 出发，垂直走到曲线上 $(x_0, P(x_0))$
3. 水平走到对角线上 $(P(x_0), P(x_0))$
4. 重复

> 🪜 **类比**：楼梯法就像你在两个镜子之间来回反射光线。曲线是一面镜子，对角线是另一面。光线（状态）在两面镜子间弹跳，最终停在哪里，取决于镜子的形状。

**稳定性判据**：
- 固定点 = 曲线与对角线的交点
- **局部指数稳定**：固定点处曲线斜率的绝对值 $|dP/dx| < 1$
- 如果斜率为负（$\lambda < 0$），迭代会在固定点两侧**振荡逼近**

**特征值分析**：
- 在原始 $n$ 维坐标中分析时，总有一个特征值为0（对应沿着极限环方向的扰动，不改变返回状态）
- 其余 $n-1$ 个特征值的模都小于1 $\Rightarrow$ 极限环局部指数稳定

## 4.2 行走的简单模型

### 背景：从被动行走到现代机器人

**McMahon的弹道行走（Ballistic Walking, 1980）**：
通过肌电图（EMG）发现，人走路时**支撑腿**肌肉活动很强，但**摆动腿**肌肉活动很弱——大部分时间摆动腿是"被动摆动"的。于是他提出了三链摆模型。

**McGeer的被动动态行走者（Passive-Dynamic Walking, 1990）**：
建造了没有电机、没有控制器的机器人，仅靠重力从斜坡走下，就能产生稳定的周期性步态。

> 🎿 **类比**：想象一个穿着硬底靴的人从缓坡滑下来。他不需要大脑控制，身体的惯性和重力会自动让他走出一种"跌跌撞撞但稳定"的步伐。这就是被动动态行走的核心——**稳定性来自机械设计，而非主动控制**。

---

### 4.2.1 无轮缘轮（The Rimless Wheel）：最简单的"腿"

**结构**：一个中心质量 $m$，连接 $N$ 根刚性辐条（腿），长度均为 $l$，相邻腿夹角 $2\alpha$。放在倾角为 $\gamma$ 的斜坡上。

> 🎡 **类比**：想象一个车轮，但把轮胎和轮辋全去掉，只剩几根辐条像蜘蛛腿一样。它走路的方式就是"摔"——一条腿着地，身体绕它转，直到下一条腿"啪"地拍在地上。

**建模假设**：
1. 与地面碰撞是**非弹性、冲量式**的（只有角动量守恒，能量有损失）
2. 支撑脚是**理想铰链**，不打滑
3. 支撑切换是**瞬时**的（没有双支撑期）
4. $0 \leq \gamma < \pi/2$，$0 < \alpha < \pi/2$，$l > 0$

**坐标系注意**：这里的 $\theta=0$ 定义在**竖直向上**（与单摆章不同！），且角度正方向是**顺时针**。

#### 站立相动力学（Stance Dynamics）

当一条腿着地时，系统就是一个**简单单摆**：

$$\ddot{\theta} = \frac{g}{l}\sin(\theta)$$

> 🎯 **关键**：这和无阻尼单摆完全一样！所以你可以直接认出它的相图——围绕不稳定平衡点（$\theta=0$，竖直向上）的双曲线型轨道。

**初始条件**：每次碰撞后，$\theta(0^+) = \gamma - \alpha$（新支撑腿刚着地时的角度）。

**前进条件**：必须有足够的初始动能"翻过去"：
$$\dot{\theta}(0^+) > \omega_1 = \sqrt{2\frac{g}{l}[1-\cos(\gamma-\alpha)]}$$

> 🏔️ **类比**：$\omega_1$ 就像过山车的"最高点高度"。如果你的初始速度不够，车就会在最高点前退回来。只有速度超过阈值，才能"翻"过支撑腿，迈出下一步。

**碰撞前速度**：当下一条腿触地时，$\theta = \gamma + \alpha$，此时速度为：
$$\dot{\theta}(t^-) = \sqrt{\dot{\theta}^2(0^+) + 4\frac{g}{l}\sin\alpha\sin\gamma}$$

注意：这里重力做了正功（下坡），所以速度比初始时大了。

#### 足部碰撞（Foot Collision）

碰撞瞬间，系统绕**新的碰撞点**的角动量守恒。

碰撞前绕新支点的角动量：
$$L(t^-) = -ml^2\dot{\theta}(t^-)\cos(2\alpha)$$

碰撞后：
$$L(t^+) = -ml^2\dot{\theta}(t^+)$$

因此：
$$\dot{\theta}(t^+) = \dot{\theta}(t^-)\cos(2\alpha)$$

> 💥 **类比**：想象你单脚跳，每次落地时"啪"地换脚。因为碰撞是非弹性的（像沙袋砸地），一部分动能被"吃"掉了。$\cos(2\alpha)$ 就是每次碰撞剩下的能量比例。腿越多（$\alpha$ 越小），每次损失的能量越少。

#### 庞加莱映射与固定点

定义**步到步返回映射**（step-to-step return map），以碰撞后的角速度为状态：

$$\dot{\theta}_{n+1}^+ = \cos(2\alpha)\sqrt{(\dot{\theta}_n^+)^2 + 4\frac{g}{l}\sin\alpha\sin\gamma}$$

（适用于 $\gamma \leq \alpha$ 且 $\dot{\theta}_n^+ > \omega_1$ 的情况）

**两个固定点**：
1. **站立固定点**：$\omega_{stand}^* = 0$（停住不动）
2. **滚动固定点**：$\omega_{roll}^* = \cot(2\alpha)\sqrt{4\frac{g}{l}\sin\alpha\sin\gamma}$（稳定行走）

> 🎚️ **分岔现象（图4.8）**：
> - 斜坡很缓（$\gamma$ 很小）：只有站立固定点，能量损失 > 重力补充，走不起来
> - $\gamma$ 增大：出现滚动固定点（稳定极限环），碰撞损失 = 重力补充
> - $\gamma > \alpha$：站立变得不可能（质心永远超出支撑多边形）

**稳定性分析**：
- 滚动固定点是**稳定的**（吸引域是图中阴影区域）
- 站立固定点在滚动固定点出现后是**不稳定的**（一侧阴影区被"吸"到滚动，另一侧回到零）

#### 站立的稳定性

虽然本章主要讲周期稳定性，但作者提到：在混合模型中，"站立不动"其实是**无限频繁碰撞**的极限情况。

### 4.2.2 指南针步态（The Compass Gait）：两条腿的质量

无轮缘轮假设"总有腿在正确位置等着着地"。现在我们把辐条减到**两根**，在髋部加一个铰链——这就是**指南针步态**。

> 🧭 **类比**：想象一个圆规（compass）。一条腿扎在地上（支撑腿），另一条腿在空中摆动（摆动腿），绕髋部转动。整个系统靠重力下坡行走。

**参数**：
- $m_h$：髋部质量
- $m$：每条腿的质量（集中在距髋部 $b$、距足尖 $a$ 处）
- $l = a + b$：腿长
- $\theta_{st}$：支撑腿角度（顺时针从竖直起）
- $\theta_{sw}$：摆动腿角度（相对支撑腿）
- $\tau$：髋部力矩（驱动）

**被动动力学**（$\tau = 0$ 时）：

操作器方程形式：
$$M(q)\ddot{q} + C(q,\dot{q})\dot{q} = \tau_g(q) + Bu$$

其中：
$$M = \begin{bmatrix} (m_h+m)l^2+ma^2 & -mlb\cos(\theta_{st}-\theta_{sw}) \\ -mlb\cos(\theta_{st}-\theta_{sw}) & mb^2 \end{bmatrix}$$

$$C = \begin{bmatrix} 0 & -mlb\sin(\theta_{st}-\theta_{sw})\dot{\theta}_{sw} \\ mlb\sin(\theta_{st}-\theta_{sw})\dot{\theta}_{st} & 0 \end{bmatrix}$$

$$\tau_g = \begin{bmatrix} (m_h l + ma + ml)g\sin(\theta_{st}) \\ -mbg\sin(\theta_{sw}) \end{bmatrix}, \quad B = \begin{bmatrix} -1 \\ 1 \end{bmatrix}$$

> 🦵 **直观**：支撑腿受到重力拉回（正弦项），摆动腿也受到重力影响。两条腿通过 $M$ 矩阵的耦合项相互影响——摆动腿的运动会"拖拽"支撑腿。

#### 足部碰撞推导

这比无轮缘轮复杂，因为涉及**两条腿之间的切换**。

**步骤**：
1. **添加浮动基**：在碰撞前的支撑脚尖处添加自由 $(x,y)$ 关节，得到 $q_{fb} = [x, y, \theta_{st}, \theta_{sw}]^T$
2. **计算浮动基质量矩阵** $M_{fb}$
3. **写出摆动脚尖位置** $\phi(q_{fb})$，计算其Jacobian $J = \partial\phi/\partial q_{fb}$
4. **碰撞后速度**（使摆动脚尖速度为零）：
   $$\dot{q}^+ = \left[I - M_{fb}^{-1}J^T(JM_{fb}^{-1}J^T)^{-1}J\right]\dot{q}^-$$

> 🎯 **物理意义**：方括号里的矩阵是**投影矩阵**，把速度投影到"满足约束（新支撑脚不动）"的子空间上。这本质上就是**非弹性碰撞的广义反射定律**。

5. **交换支撑腿和摆动腿**的标签

### 4.2.3 带膝行走者（The Kneed Walker）：更拟人的步态

为了更像人走路（有膝盖弯曲），每条腿变成**两段**（大腿+小腿），中间有膝关节。

> 🚶 **类比**：人走路时，摆动腿不是像棍子一样直着甩出去，而是**先屈膝抬起小腿，然后伸直落地**。这个"屈膝-伸直"的动作让脚能 clearance（离地间隙），不会刮地。

**一个完整步态周期**：

```
三链摆动力学（摆动腿屈膝） → 膝碰撞（knee-strike） → 
二链摆动力学（腿伸直摆动） → 足碰撞（heel-strike） → 
交换支撑腿 → 回到三链摆
```

**膝碰撞（Knee-Strike）**：
- 当小腿甩到与大腿对齐时（$q_3 = 0$，腿伸直），发生**非弹性碰撞**
- 角动量守恒，速度瞬时改变
- 碰撞后膝关节"锁定"，系统从三链摆退化为二链摆（指南针步态）

**足碰撞（Heel-Strike）**：
- 摆动脚触地，发生另一次碰撞
- 两条腿交换角色

**相图（图4.13）**：
- 右腿角度 vs 角速度
- 可以看到**四个速度跳变点**：两次膝碰撞 + 两次足碰撞
- 上半圆是摆动相，下半是支撑相

> 🎢 **类比**：这就像过山车有多个"刹车点"。每次碰撞都是一个刹车，把速度降下来，然后重力再加速，再刹车——最终形成一个稳定的能量循环。

### 4.2.4 弯曲足（Curved Feet）

指南针步态和带膝行走者的吸引域都很窄。一个改进方法是给脚加上**弯曲的足弓**（弧形足底）。

> 🦶 **类比**：想象穿高跟鞋和平底鞋走路的区别。高跟鞋的细跟是"点接触"，一旦歪一点就容易倒；而弧形足底像摇椅，允许一定程度的晃动后自动回正。**弯曲足通过被动机械设计扩大了稳定区域**。

### 4.2.5 其他变体：从McGeer到Strandbeest

**McGeer的带膝行走者**：实物视频展示了被动行走的魅力。

**Theo Jansen的Strandbeest**：
- 荷兰艺术家创造的"风能海滩行走者"
- 仅靠风力驱动，没有任何电子控制
- 使用巧妙的连杆机构（Jansen Linkage）将旋转运动转化为流畅的步态

> 🌬️ **类比**：Strandbeest就像"机械生命"——它不需要大脑，仅靠风力和机械结构的"本能"就能在海滩上行走。这提醒我们：**智能不仅存在于算法中，也可以存在于机械设计里**。

**MIT学生的仿真**：Robin Deits在Drake中复现了Strandbeest的行走。

## 4.3 奔跑的简单模型

### 背景：MIT腿实验室（Leg Laboratory）

Marc Raibert在1980年代建造了一系列**跳跃机器人**。当时大多数步行机器人笨拙缓慢，而他的机器人却能以巨大动能腾空跳跃。

> 🦘 **类比**：Raibert的洞察是——**奔跑本质上就是"受控跌倒"的跳跃**。与其小心翼翼地保持平衡，不如大胆地跳起来，在空中调整姿态，落地再跳。这种"动态稳定"比"静态稳定"更高效。

### 4.3.1 弹簧负载倒立摆（SLIP）：奔跑的"万能模板"

SLIP是机器人学和生物力学中最成功的简单模型之一。

**结构**：
- 一个质点 $m$（身体）
- 一根**无质量**的弹簧腿（自然长度 $l_0$，刚度 $k$）
- 腿与地面夹角 $\theta$

> 🦘 **类比**：想象袋鼠跳跃。它的身体是一个球，腿是一根弹簧。落地时弹簧压缩储能，蹬地时弹簧释放能量把身体弹起。整个过程中，腿的质量可以忽略（像一根轻竹竿）。

**分段动力学**：

**飞行相（Flight Phase）**：
状态：$x = [x, z, \dot{x}, \dot{z}]^T$

$$\ddot{x} = 0, \quad \ddot{z} = -g$$

> 就是抛体运动！腿可以瞬时调整到任意角度（因为无质量）。

**站立相（Stance Phase）**：
状态：$x = [r, \theta, \dot{r}, \dot{\theta}]^T$（极坐标，以触地点为原点）

$$m\ddot{r} - mr\dot{\theta}^2 + mg\cos\theta - k(l_0 - r) = 0$$
$$mr^2\ddot{\theta} + 2mr\dot{r}\dot{\theta} - mgr\sin\theta = 0$$

> 🎯 **物理意义**：
> - 第一个方程：径向运动 = 离心力 + 重力分量 + 弹簧力
> - 第二个方程：角向运动 = 科氏力 + 重力力矩

**相变条件**：
- 飞行→站立：$z - l_0\cos\theta \leq 0$（身体高度低于腿长，触地）
- 站立→飞行：$r \geq l_0$（弹簧恢复到自然长度，离地）

**重要**：由于腿无质量且触地点无滑动，**碰撞不损失能量**！这与行走模型不同。

#### 顶点-顶点映射（Apex-to-Apex Map）

SLIP的状态有4维，庞加莱映射似乎是3维的。但我们可以聪明地选择截面：

**选择顶点（Apex）为截面**：$\dot{z} = 0$（最高点）

在顶点处：
- 水平位置 $x$ 无关（平移对称）
- 腿角度 $\theta$ 在飞行中可以任意设定（控制输入）
- 只剩两个状态：水平速度 $\dot{x}$ 和 高度 $z$

**但还有约束**：总能量守恒！
$$E_{apex} = \frac{1}{2}m\dot{x}^2 + mgz = E_0$$

所以知道 $z$ 就知道 $\dot{x}$（符号除外）。**映射实际上是一维的！**

**无量纲化**：
$$\tilde{E} = \frac{E}{mgl_0}, \quad \tilde{k} = \frac{kl_0}{mg}$$

> - 如果 $z$ 太高（能量相对水平速度太小），身体会"后坐"——压缩弹簧后向后倒，无法前进

#### 能量守恒与"部分稳定性"

SLIP是保守系统（无能量损失），这带来一个微妙问题：

> ⚠️ **陷阱**：顶点-顶点映射显示"稳定"固定点，但这是因为我们在**假设能量守恒**的前提下把二维状态投影到了一维。这种分析只能证明**部分稳定性**（对不改变总能量的扰动稳定）。如果扰动改变了总能量（比如一阵风吹来），系统可能不再稳定。

> 🎈 **类比**：想象一个无摩擦的摆。如果你只关心"最大摆角"，它确实会收敛到一个固定值（由能量决定）。但如果你给它额外推一把（改变能量），它就会到一个新的"稳定"摆角。所以每个能量层级都有自己的"稳定轨道"，但跨层级的扰动会破坏这种稳定。

尽管如此，这种"分段哈密顿系统"的**部分稳定性**仍然非常有趣，甚至引起了理论物理学界的关注。

#### SLIP控制：死拍控制（Deadbeat Control）

由于腿无质量，我们可以在飞行中**瞬时调整触地角** $\theta$。这给了我们一个离散控制输入。

**关键洞察**：触地角与下一次顶点高度之间存在**可逆关系**（在能量约束范围内）。

> 🎯 **死拍控制**：选择触地角，使得**一步之内**精确到达期望顶点高度！

这在连续时间中是不可能的（除非控制无界），但在离散时间系统中完全可以实现——而且控制输入是有界的。

```python
# 死拍控制器概念代码
def deadbeat_touchdown_angle(current_state, desired_apex_height):
    # 根据当前能量和期望高度，反解触地角
    # 这是一个可逆映射的求逆
    theta_td = inverse_apex_map(current_state.energy, desired_apex_height)
    return theta_td
```

**更惊人的结果**：触地角与奔跑速度的关系是**光滑函数**。因此，我们可以让腿在飞行中按一个**开环轨迹**摆动（仅基于离上次顶点的时间），使得**无论地面在哪里**，只要脚碰到地面，触地角恰好是死拍角度！

> 🦯 **盲跑粗糙地形**：不需要地形传感器！腿在空中自动摆动，像钟摆一样。地面高低只影响**何时触地**，不影响**触地角度**——因为角度是时间的函数。这意味着机器人可以**盲跑**过起伏地形！

这与生物力学中的**"地速匹配"（ground-speed matching）**现象一致：人和动物会主动摆动腿，使脚在触地时匹配地面速度。

### 4.3.2 MIT腿实验室的跳跃机器人

Raibert的跳跃机器人采用**三层解耦控制策略**：
1. **跳跃高度**：通过腿部弹簧的预压/推力控制
2. **身体姿态**：通过腿部力矩在空中调整
3. **前进速度**：通过触地角控制

> 🦘 **类比**：袋鼠跳跃时，它不需要同时思考"跳多高""身体朝哪""往前多快"。它把问题分解了：腿负责弹跳，尾巴负责平衡，角度负责方向。这就是解耦控制的生物原型。

**四足奔跑**：Raibert还发现，四足机器人可以像**单足**一样控制——把四条腿的动作协调成"虚拟单腿"的弹跳。

## 4.5 抛接球（Juggling）：接触控制的另一扇窗

虽然抛接球不是腿式机器人，但它使用了**完全相同的数学工具**（混合系统、庞加莱映射、镜像律）。

### 线抛接球（The Line Juggler）

**结构**：
- 一个球，只能在竖直线上运动（想象球被限制在竖直轨道里）
- 一个平板（机器人），也只能在竖直线上运动
- 控制输入：平板的速度 $\dot{r}$

**球在空中**：$\ddot{b} = -g$（自由落体）

**碰撞**：球与平板发生**弹性碰撞**，恢复系数 $0 \leq e \leq 1$

> 🎾 **类比**：想象你在用球拍颠网球。球拍上下移动，球在空中飞行。你要让球稳定在一个高度上弹跳。

### 镜像律（Mirror Law）

Buehler和Koditschek提出了一个巧妙的参数化方法：

$$r = -k(b, \dot{b}) \cdot b$$

即：平板位置是球位置的**负镜像**（缩放后）。

更具体地，选择：
$$k(b, \dot{b}) = \kappa_0 + \frac{\kappa_1}{m}(E_d - E)$$

其中 $E = mgb + \frac{1}{2}m\dot{b}^2$ 是球的当前总能量，$E_d$ 是期望能量。

> 🪞 **类比**：镜像律就像你站在镜子前跳舞。你的动作是球的"镜像"，但缩放比例根据球的能量动态调整。球能量太低时，你用力大一点（$\kappa_1$ 项补偿）；能量正好时，你正常跟随（$\kappa_0$ 项）。

**庞加莱映射**（从一次碰撞前到下一次碰撞前）：

$$\dot{b}[n+1] = f(\dot{b}[n]; \kappa_0, \kappa_1) = \dot{b}[n]\left[1 - \frac{1+e}{2}\kappa_1(\dot{b}^2[n] - \dot{b}_d^2)\right]$$

> 🎯 **分析**：当 $\dot{b} > \dot{b}_d$（球太快）时，括号内 < 1，下次速度减小；当 $\dot{b} < \dot{b}_d$（球太慢）时，括号内 > 1，下次速度增大。系统收敛到 $\dot{b}_d$！

## 4.6 练习：一维跳跃机（Exercise 4.1）

这是本章唯一的练习，但内容非常丰富——**实现一个完整的混合系统控制器**。

### 目标

控制一个**一维跳跃机**的垂直运动，使其在期望高度上产生稳定的共振弹跳。

### 方法：能量分析

通过仔细分析跳跃周期的能量变化，设计控制器。

### 代码任务

**任务a**：写一个函数，给定跳跃机状态，返回其总机械能。

```python
def total_energy(state):
    z, zdot = state  # 高度和速度
    # 假设质量 m=1，弹簧自然长度 l0，刚度 k
    # 如果脚在地面上（z < l0），弹簧被压缩
    if z < l0:
        spring_potential = 0.5 * k * (l0 - z)**2
    else:
        spring_potential = 0
    kinetic = 0.5 * m * zdot**2
    gravitational = m * g * z
    return kinetic + spring_potential + gravitational
```

**任务b**：编写跳跃控制器类（Drake LeafSystem）

```python
class HoppingController(LeafSystem):
    def __init__(self, desired_height):
        super().__init__()
        self.desired_height = desired_height
        # 定义输入端口：读取跳跃机状态
        # 定义输出端口：返回弹簧预压量（或推力）
        
    def DoCalcOutput(self, context, output):
        state = self.EvalVectorInput(context, 0).get_value()
        energy = total_energy(state)
        desired_energy = m * g * self.desired_height  # 顶点能量
        
        # 控制器逻辑：根据能量差调整弹簧预压
        # 使得系统在下次起跳时达到期望能量
        preload = compute_preload(energy, desired_energy)
        output.SetAtIndex(0, preload)
```

> 🦘 **物理直觉**：跳跃就像蹦床。你要在最低点（弹簧压缩最大）时用力蹬地，把机械能"泵"到期望水平。如果每次补充的能量 = 飞行中损失的能量（这里主要是碰撞损失），就能形成稳定的极限环。

## 总结：第四章教给我们的六件事

| 核心概念 | 模型中的体现 | 实践意义 |
|---------|-------------|---------|
| **极限环稳定性** | 无轮缘轮、SLIP的周期轨道 | 行走/奔跑不是"停住"，而是"循环" |
| **庞加莱映射** | 把连续周期问题切片成离散映射 | 用固定点稳定性分析周期轨道 |
| **混合系统** | 飞行/站立相切换，碰撞事件 | 机器人必须处理"接触/不接触"的跳变 |
| **能量整形** | SLIP的弹簧储能，无轮缘轮的重力补能 | 被动动力学+主动控制 = 高效运动 |
| **死拍控制** | SLIP单步收敛到期望高度 | 离散控制可以实现连续系统做不到的"一步到位" |
| **解耦策略** | Raibert的三层控制（高度/姿态/速度） | 复杂问题分解为简单子问题 |

## 给初学者的寄语

Tedrake教授在本章展示了**简单模型的力量**：

> 从**无轮缘轮**（1个自由度）到**指南针步态**（2个自由度）到**带膝行走者**（3个自由度），再到**SLIP**（奔跑模板），每一步都在增加生物拟真度，但核心数学工具始终是**混合系统 + 庞加莱映射 + 能量分析**。

**关键洞察**：
- **被动稳定性**（机械设计）比**主动稳定性**（控制算法）更节能
- **接触**不是敌人，而是机器人与环境交换能量和信息的桥梁
- **简单模型**可以解释从蟑螂到马匹的广泛生物现象（SLIP的普适性）

> 🌟 **一句话记住这章**：行走和奔跑的本质，不是"保持平衡"，而是**管理能量的周期性流动**——在重力、惯性和碰撞之间找到稳定的循环。
