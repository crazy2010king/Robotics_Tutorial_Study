## 0. 开篇：这一章到底在解决什么问题？

### 0.1 一句话概括

> **行走和奔跑的机器人，本质上是"一边摔一边往前走"的系统。这一章教你：怎么用数学描述"摔一下（撞地）→ 摆一会儿 → 再摔一下"这种循环，并证明这个循环是"稳"的。**

### 0.2 先理解作者开场白的几层意思

作者 Russ Tedrake 在正文前写了一大段"心里话"，信息量极大，我逐句翻译成人话：

**第一层：硬件进步了，但脑子还没跟上。**
> 近年腿式机器人进步惊人，但**主要功劳在硬件**（Boston Dynamics 等把电机从"软绵绵、不听话的力源"变成了"指哪打哪的力源"）。而**控制系统其实比你想象的更"靠经验凑"（heuristic）**，它需要的反应速度（带宽）和延迟比人类神经系统苛刻得多，在难走的地面上表现**仍然比人差**。

**类比**：就像给一个机器人装了法拉利的发动机和轮胎（硬件），但司机（控制算法）还是个新手，靠"感觉"开车，遇到结冰路面就慌。

**第二层：行走天然是"欠驱动"的，而且欠得很死。**
> 你不能"拉"地面（也没有空气动力帮你），所以**无论电机多猛，你都没法让机器人质心朝地面方向加速得比重力 g 还快**。

**类比**：你站在地上，无论肌肉多发达，你都不能"把自己往地里拽得比自由落体还快"。重力是天花板。这就是欠驱动——你想控制的方向（垂直压向地面）没有"执行器"。

**第三层（本章真正的主题）：行走多了一个新麻烦——"接触"。**
> 接触力有个怪脾气：**只有两个东西真的碰在一起时，接触力才不为零。** 这就给问题塞进了一个**离散的、像开关一样的、组合爆炸的**成分。

**类比**：想象你在弹钢琴。琴键只有"按下/没按下"两种状态，没有"按一半发出半个音"。行走也一样——脚要么"踩在地上"要么"在空中"，这是一个**开关**，而开关的"咔哒"一下在数学上叫**不连续事件 / 混合事件**。第3章的 Acrobot、Cart-Pole 是"丝滑连续"的，本章的系统是"丝滑 + 突然咔哒"的，这叫**混合系统（hybrid system）**。

**第四层（作者的价值观，很动人）：别怕接触！**
> 接触是机器人"对环境做物理功"的前提——搬东西、走路都得接触。**可悲的是太多机器人一辈子都在"不惜一切代价躲避接触"**。控制接触，才是机器人学的意义。

**第五层（方法论，最重要）：为什么用"稳定性"这个词？**
> 作者想继续用"稳定性"的语言。因为当我们能谈论"时间趋于无穷时系统会怎样"，分析就**干净**（时间这个变量消失了）。行走提供了一个绝妙的场景：把"平衡在一个点不动"的稳定性，**升级**成"平衡在一个**循环**上不停转"的稳定性。

**类比**：
- 第3章的"稳定"= 一个陀螺**立在桌上不动**（不动点稳定）。
- 本章的"稳定"= 一颗心脏**不停地、规律地跳**（周期循环稳定）。心脏不是"停在一个状态"，而是"稳稳地重复一个循环"。如果它跳得乱了，那是"循环不稳定"。**行走的稳定 = 步态这个"心跳"稳定。**

这就是全章的总纲：**把"不动点稳定"推广到"周期循环（极限环）稳定"，并用这套语言分析走路和跑步。**

## 1. 极限环（Limit Cycles）—— 给"心跳"一个数学名字

### 1.1 什么是极限环？

> **极限环 = 一条周期的轨道，它是动力系统的"极限集"。** 它可以是**稳定的**（旁边的轨迹随着时间→∞ 都被吸到这条环上），也可以是**不稳定的**（旁边的轨迹随着时间→−∞ 才被吸到它上，正着看就是被它推开）。

**类比（务必记住这个类比，全章都用它）**：
想象一个**圆形跑道**。
- **稳定极限环** = 跑道周围有一圈"斜坡"，无论你把小球放在跑道内侧还是外侧，它都会**滚到跑道上**，然后绕着跑道一圈一圈跑。
- **不稳定极限环** = 跑道是个"山脊"，小球放上去能跑，但稍微偏一点就滚下山脊，再也回不来。
- 而**不动点**（第3章）= 跑道缩成一个**点**，球停在圆心不动。

所以极限环就是"不停转的稳定循环"。

### 1.2 例子 4.1：Van der Pol 振荡器（极限环的"教科书宠物"）

方程：

$$\ddot q + \mu(q^2-1)\dot q + q = 0,\quad \mu>0$$

**它是什么？** 作者说：把它想成一个**几乎普通的"弹簧-质量-阻尼"系统**，唯一区别是它的**阻尼是非线性的**——阻尼的符号会**变**！

- 当 $|q|>1$（摆得幅度大）时，速度项**耗散**能量（正常阻尼，把能量抽走，像刹车）。
- 当 $|q|<1$（摆得幅度小）时，速度项**注入**能量（负阻尼，像有人在推秋千）。

**通俗理解**：这就像一个**自带油门和刹车的秋千**——荡得太高就自动刹车，荡得太低就自动加油。结果可想而知：它既不会停下来，也不会荡飞，而是**稳定地荡在一个固定幅度**——这就是极限环！从几乎任何初始条件出发都会收敛到这个振荡（唯一例外是 $q=0,\dot q=0$，即一开始就死死停在中间，没启动）。

**图 4.1**：左是**相图**（横轴 $q$ 纵轴 $\dot q$），能看到所有轨迹螺旋着收敛到**同一个圈**；右是**时域图**（横轴时间）。

### 1.3 关键转折：为什么"老的稳定性定义"在这里失效？（这是本章第一个烧脑点）

老定义（轨迹稳定）是：$\lim_{t\to\infty}\|x(t)-x^*(t)\|=0$，即"我的轨迹和参考轨迹**在同一时刻**重合"。

**问题**：看 Van der Pol 的**时域图**——所有轨迹确实最终都"长得一样"（同样的波形、同样的幅度），**但它们在时间上没有对齐！** 你这条波峰出现时，参考那条的波峰可能还没到。就像**两个人以完全相同的步频绕圈跑，但一个领先半圈**——他们的"形状"一样，但"同一时刻的位置"永远不一样。

**类比（合唱 vs 齐步走）**：
- **老定义（轨迹稳定）** 要求像**齐步走**：每一拍，所有人的脚必须**同时**落地。
- **新需求** 像**合唱**：我不在乎你比我早进半拍还是晚进半拍，我只在乎**我们唱的是同一段旋律（同一条轨道）**。

所以作者**换定义**：不再比"同一时刻的位置"，而是比"我的轨迹离**那条轨道上最近的点**有多远"：

$$\min_{\tau}\|x(t)-x^*(\tau)\|$$

**人话**：把参考轨迹看成一条**铁轨**，我不在乎火车开到铁轨的哪一节车厢，我只在乎**我离铁轨的垂直距离**是不是趋于 0。

由此定义**轨道稳定性（orbital stability）**：对每个小 $\epsilon$，都能找到 $\delta$，使得只要一开始离轨道 $<\delta$，以后永远离轨道 $<\epsilon$。再加强就是**渐近轨道稳定**（距离→0）、**指数轨道稳定**（距离指数→0）、**有限时间轨道稳定**。极限环就是其中**周期**的那一类：$x^*(t+T)=x^*(t)$。

### 1.4 与 Lyapunov 分析的两个"彩蛋"连接

作者顺手埋了两个理论彩蛋（基础薄弱者可先记住结论）：

1. **Poincaré-Bendixson 定理**：如果你能在状态空间里圈出一块**不变集**（轨迹进去就出不来），而且这块区域里**没有任何不动点**，那么这块区域里**必然含有一条闭合轨道（极限环）**。
   **类比**：在一个没有"坑"（不动点）的封闭水池里放水，水不能停，又不能流出池子，那它**只能转圈**。

2. **梯度势场 / $\dot V<0$ 的 Lyapunov 函数不可能有闭合轨道**。
   **类比**：Lyapunov 函数像"海拔"，$\dot V<0$ 意味着"水永远往低处流"。水永远往低处流，就**不可能转圈回到原点**（转圈意味着海拔回到原值，矛盾）。所以**处理极限环时，第3章那套 Lyapunov 工具得改造**（后面章节会讲）。

## 2. Poincaré 映射（庞加莱映射）—— 把"转圈"拍成"翻页"

> 这是分析极限环稳定性的**第一件神器**，也是本章后面所有例子的核心工具。**请把它彻底搞懂。**

### 2.1 核心思想：在轨道上装一台"打卡机"

考虑连续系统 $\dot x=f(x),\ x\in\mathbb R^n$。我们**切一刀**，放一个 $(n-1)$ 维的**截面 $S$**（surface of section），并要求 $S$ **横截于流**——即所有从 $S$ 出发的轨迹都**穿过去**，而不是**贴着它平行滑**（否则就"打不到卡"了）。

**类比**：极限环是一条**环形地铁线**，截面 $S$ 是线上的**一个闸机口**。每当地铁（轨迹）经过这个闸机，就"滴"一声，记一个状态。**Poincaré 映射 $P$ 就是"从这一次滴，到下一次滴，状态变成了什么"的函数**：

$$x_p[n+1]=P(x_p[n])$$

其中 $x_p[n]=x(t_c[n])$ 是第 $n$ 次穿过 $S$ 时的状态，$t_c[n]$ 是第 $n$ 次穿过的时间。注意作者用 $x_p$ 表示**离散**系统的状态，以区别于连续状态 $x$。

> **为什么这招是降维打击？** 连续系统是"看一部电影"（无穷多帧），Poincaré 映射是"只看每圈那一帧"（变成一本翻页书）。**一个 $n$ 维连续系统的极限环稳定性，被压缩成了一个 $(n-1)$ 维离散映射的不动点稳定性。** 维度直接 −1，而且把"周期循环"变成了"不动点"——我们又回到了熟悉的"不动点"世界！

作者补了一句工程细节：为方便，他**允许 $P$ 也包含原系统的不动点**（站着不动 = 回归时间记为 0）。这些点不满足横截条件，数值上要小心，但不影响分析。

### 2.2 例子 4.2：给 Van der Pol 装打卡机

Van der Pol 状态空间 2 维，所以截面 $S$ 必须是 **1 维**（一条线）。取 $S$ 为 $q=0,\ \dot q\ge 0$ 的线段（即"摆正好经过中间、且正往上摆"的那一刻）。容易验证所有从 $S$ 出发的轨迹都横截穿过它。

**1 维映射可以画图分析！**（这是 1 维的美妙之处。）

**图 4.2**：左是相图，黑虚线就是截面 $S$；右是画出来的**首回归映射**（蓝线，$x_p[n+1]$ 对 $x_p[n]$）和**斜率 1 的红线** $x_p[n+1]=x_p[n]$。

### 2.3 把极限环稳定 ↔ 不动点稳定（最重要的结论）

如果你能证明 $P(x_p)$ 对所有 $x_p\in S$ 都存在（即**离开 $S$ 的轨迹最终都会回来**——地铁不会脱轨消失），那么奇迹发生：

> **若 $x_p^*$ 是 $P$ 的稳定（不稳定）不动点，则存在唯一一条周期轨道穿过 $x_p^*$，它是稳定（不稳定）极限环。**

并且，如果你还能**给"离开 $S$ 到回来的时间"一个上界**，就能进一步推出**渐近/指数轨道稳定**。

**怎么找不动点？** 解 $x_p^*=P(x_p^*)$——也就是**蓝线和红线的交点**！

**怎么用特征值判断局部稳定？** 求 $P$ 在不动点处的"斜率"（雅可比的特征值 $\lambda_i$）。**注意一个坑**：如果你**在原坐标**（而不是 $S$ 的 $n-1$ 维坐标）里做特征分析，那么**总会多出一个 0 特征值**——它对应"沿着极限环方向推一下"，这种扰动**不改变下一次打卡的状态**（你只是让火车早到/晚到一点，但下一圈它还在同一位置打卡）。**所以判据是：除这个 0 之外，其余所有 $|\lambda_i|<1$，则极限环局部指数稳定。**

**类比**：0 特征值 = "你让合唱队整体早进半拍"，这不算跑调，下一圈还是同一段旋律，所以这种扰动"无害"，被记成 0。真正危险的是"有人越唱越快/越慢"（$|\lambda|>1$）。

### 2.4 阶梯法（staircase method）—— 1 维映射的"肉眼分析术"

**图 4.3** 演示：画 $x_p[n+1]$ vs $x_p[n]$ 的蓝线 + 斜率 1 红线。从初始点 $(x_p[k],x_p[k])$ 出发，**先垂直走到蓝线**得到 $(x_p[k],x_p[k+1])$，**再水平走到红线**得到 $(x_p[k+1],x_p[k+1])$，再垂直……像走**楼梯**一样，一步步迭代。

- **不动点** = 蓝红交点。
- **局部指数稳定** = 交点处蓝线斜率绝对值 $<1$（$|\lambda|<1$）。
- 图 4.3（$\mu=0.2$，从 $\dot q_p[0]=0.5$ 和 $3.5$ 两个初值出发）既展示了 Van der Pol 极限环的稳定，也展示了**原点不动点的（单侧）不稳定**。

**一个离散系统特有的"小心"**：离散映射每步可以**跳一大段**，而且当 $\lambda<0$ 时，迭代会在不动点**两侧来回横跳**（像锯齿）。这跟连续流"平滑地滑过去"不一样，画吸引域时要更小心。

**类比**：连续流像**滑滑梯**（平滑下滑）；离散映射像**跳格子**（一格一格蹦，还可能左右蹦）。

## 3. 行走的简单模型 —— 从"最蠢的轮子"到"带膝盖的人"

作者的研究路线：**被动动力行走器（passive-dynamic walker）**——没有电机、没有控制器，**纯靠重力走下小斜坡**，却能走出稳定步态！这证明"走路"这件事，**大自然/物理本身已经帮你做了一大半**，控制器只需要"顺着物理的脾气补一点点"。

历史铺垫：
- **McMahon** 最早提出"弹道行走"模型（矢状面三连杆摆：支撑腿 + 摆动大腿 + 摆动小腿），依据是 EMG 测到**摆动腿几乎不用力**（只在摆动首尾用一点力）。他认为人主要靠"被动甩腿"走路。这模型今天看**太简单**（忽略了支撑腿的弹性/顺应性），且只管"连续摆动"不管"撞地那一下"，但它是起点。
- 近十年后 **McGeer** 做出一系列机器，命名"被动动力行走器"。

下面四个模型，**一个比一个像人**：轮辐轮 → 圆规步态 → 带膝行走器 → 弧形脚。

### 3.1 轮辐轮（Rimless Wheel）—— "最蠢的腿式机器人"

**图 4.5**：想象一个**自行车轮，但只剩几根辐条（腿），轮毂上焊一个点质量（髋部）**，没有轮胎。把它斜放在坡上，它会"咔哒咔哒"地往下滚。**这就是轮辐轮。** 作者说它"也许是最简单的腿式机器人模型"。

**坐标约定**（注意和第3章的摆**反着来**）：$\theta$ 是支撑腿方向，**从垂直轴顺时针量**，且 $\theta=0$ 在**顶部**（不是底部！）。参数：坡角 $\gamma$、半辐条夹角 $\alpha$、腿长 $l$，约束 $0\le\gamma<\pi/2,\ 0<\alpha<\pi/2,\ l>0$。

**四条建模假设**（背下来，后面全靠它们）：
1. 撞地是**非弹性 + 脉冲**的（撞一下，**只守恒绕撞点的角动量**，能量会丢）。
2. 支撑脚当**销关节**，**不打滑**。
3. 换脚支撑是**瞬时**的（没有"两只脚同时着地"的双支撑相）。
4. 上面那些角度/长度约束。

#### 3.1.1 支撑动力学（一只脚踩地时）

$$\ddot\theta = \frac{g}{l}\sin\theta$$

**人话**：这不就是**无阻尼单摆**吗！只是坐标翻了个面。一只脚踩地时，整个轮子就是绕这只脚转的摆。

**什么时候能"迈下一步"？** 假设刚换完脚时 $\theta(0^+)=\gamma-\alpha$。要能往前滚过去，初始角速度必须够大：

$$\dot\theta(0^+)>\omega_1,\qquad \omega_1=\sqrt{\tfrac{2g}{l}\,[1-\cos(\gamma-\alpha)]}$$

**类比**：$\omega_1$ 是"翻山门槛"。你骑单车要翻过一个小坡顶，到坡底时速度必须大于某个值，否则**爬到一半就溜回来了**。$\omega_1$ 就是"刚好能拱过支撑腿、把质心甩到另一侧"的临界速度。

- 当 $\gamma=\alpha$（坡正好等于辐条夹角），门槛 $\omega_1=0$（轻轻一碰就过去）。
- 当 $\gamma>\alpha$（坡太陡），门槛**不存在**——因为质心永远在支撑脚前方，**根本站不住**，连"站着不动"这个平衡点都消失了（必然往前倒）。

**下一只脚何时着地？** 当 $\theta(t)=\gamma+\alpha$。此时重力把势能换成了动能，着地**前一瞬间**的速度为：

$$\dot\theta(t^-)=\sqrt{\dot\theta^2(0^+)+4\tfrac{g}{l}\sin\alpha\sin\gamma}$$

（$t^-$ 表示"撞地前那一刹那"。）**人话**：这就是能量守恒——下坡时重力做功，速度平方增加了 $4\frac{g}{l}\sin\alpha\sin\gamma$ 这么多。

#### 3.1.2 脚碰撞（"咔哒"那一下，速度突然掉一截）

**图 4.6**：撞地瞬间，**绕新撞点的角动量守恒**（这是假设1的数学翻译）。

- 撞**前**绕新撞点的角动量：$L(t^-)=-ml^2\dot\theta(t^-)\cos(2\alpha)$
- 撞**后**绕同一点的角动量：$L(t^+)=-ml^2\dot\theta(t^+)$

令两者相等，解出**撞后速度**：

$$\dot\theta(t^+)=\dot\theta(t^-)\cos(2\alpha)$$

**人话（极其重要）**：每撞一下，速度就**乘一个 $\cos(2\alpha)<1$ 的系数**——也就是**每步都丢一点速度（丢能量）**！$\cos(2\alpha)$ 就是"撞地保留率"。**类比**：像一个**漏气的皮球**，每弹一下矮一点。轮辐轮之所以不会越滚越快，就是因为这个"撞地漏气"。

#### 3.1.3 前向仿真 + Drake 的混合系统技巧

把"支撑摆方程 + 撞地检测（$\theta=\gamma\pm\alpha$）+ 撞地速度更新"拼起来，就能数值仿真。结果**很神奇**：轮子一开始滚，然后**二选一**——要么**漏光气停下**，要么**迅速落入一个稳定的周期滚动**，而且**从一大片初始条件都能收敛过去**。

**例子 4.3** 的 notebook 让你亲手试初始条件，还做了**交互 widget**（拖动滑块看相图变化）。

> **代码实践重点（Drake 混合系统怎么做的）**：轮辐轮用到了 Drake 的几个"高级货"来精确仿真这种"连续 + 咔哒"的混合系统——它**注册了碰撞事件**，仿真器用**零交叉检测（zero-crossing detection）** 精确抓住"撞地那一刻"的时间和状态，然后**应用重置映射（reset map）** 把速度乘 $\cos(2\alpha)$。**图 4.7** 是相图（参数 $m=1,l=1,g=9.8,\alpha=\pi/8,\gamma=0.08$）。

**一个会让你会心一笑的观察**：轮辐轮的动力学**就是无阻尼单摆**，所以它的相图你**眼熟**——围绕单摆那个**不稳定不动点**居中（和第3章单摆相图一个模样，只是被"撞地重置"切成了一段段）。

#### 3.1.4 轮辐轮的 Poincaré 映射（步到步映射，全章最该手推的公式之一）

我们要"每一步开始时速度"作为"上一步开始时速度"的函数。分三种情况（先讲 $\gamma\le\alpha$）：

**情况 A：速度够大，往前迈了一步**（$\dot\theta_n^+>\omega_1$）：

$$\dot\theta_{n+1}^+=\cos(2\alpha)\sqrt{(\dot\theta_n^+)^2+4\tfrac{g}{l}\sin\alpha\sin\gamma}$$

**人话**：根号里是"下坡加速后的速度平方"（能量守恒），外面乘 $\cos(2\alpha)$ 是"撞地漏气"。**先加油，再漏气，得到下一步的初速。**

**情况 B：速度中等，迈不动，原地晃回来**（$\omega_2<\dot\theta_n^+<\omega_1$）：

$$\dot\theta_{n+1}^+=-\dot\theta_n^+\cos(2\alpha)$$

**人话**：没翻过山，腿抬起来又落回**同一侧**，速度反向（负号），并漏一次气。其中反向门槛 $\omega_2=-\sqrt{2\frac{g}{l}[1-\cos(\alpha+\gamma)]}$。

**情况 C：速度是负的（往后），往后迈一步**（$\dot\theta_n^+<\omega_2$）：

$$\dot\theta_{n+1}^+=-\cos(2\alpha)\sqrt{(\dot\theta_n^+)^2-4\tfrac{g}{l}\sin\alpha\sin\gamma}$$

把三段合起来就是 $\gamma\le\alpha$ 的完整分段映射。

> **一个微妙点**：映射在 $\dot\theta_n\in\{\omega_1,\omega_2\}$ **没有定义**！因为这两个"刚好卡在门槛上"的速度，会让轮子**正好停在 $\theta=0,\dot\theta=0$ 那个不稳定平衡点**（像把球精准放在山顶），于是它**再也不回来打卡**了，映射自然没值。

**当 $\gamma>\alpha$（坡陡，站不住）**：映射"平滑地"变成另一套分段形式，且**原先没定义的点现在又有定义了**（此时 $\omega_1=0$），因为**陡坡上运动学就不允许单腿静止站着**——球放山顶也会立刻滚下来，所以一定会回来打卡。

#### 3.1.5 不动点与稳定性 + 分岔（"坡角 $\gamma$ 是总导演"）

不动点要求 $\dot\theta_{n+1}^+=\dot\theta_n^+=\omega^*$，解出**两个候选**：

$$\omega^*_{\text{stand}}=0,\qquad \omega^*_{\text{roll}}=\cot(2\alpha)\sqrt{4\tfrac{g}{l}\sin\alpha\sin\gamma}$$

- $\omega^*_{\text{stand}}=0$（**站着不动**）在 $\gamma<\alpha$ 时是不动点。
- $\omega^*_{\text{roll}}$（**稳定滚动**）在 $\omega^*_{\text{roll}}>\omega_1$ 时是不动点。

**用坡角 $\gamma$ 当旋钮看"分岔"（行为突变）**：
- **$\gamma$ 很小**：只有 $\omega_{\text{stand}}$ 是不动点——坡太缓，重力补不回撞地漏的气，轮子**最终停下**。
- **$\gamma$ 增大**：出现**稳定滚动解**——重力下坡加的油，**正好等于**撞地漏的气，**收支平衡**，于是匀速滚下去（极限环！）。
- **$\gamma$ 再大到 $\gamma>\alpha$**：质心永远在支撑脚前方，**站着变成不稳定**（想站也站不住）。

**图 4.8**（参数 $\gamma=0.15$）：**阴影区**的初始条件都收敛到滚动 $\omega^*_{\text{roll}}$，**白区**收敛到停下 $\omega^*_{\text{stand}}$。

#### 3.1.6 "站着不动"的稳定性——一个混合系统特有的微妙点

作者坚持"行走的自然稳定性是周期稳定"，但也想看看"站着不动"这个**不动点**稳不稳。微妙之处：**在混合模型里，"站着不动"是"无限频繁撞地"的极限情况**（腿 infinitesimally 短地来回磕，频率→∞，幅度→0）。[细节作者标注"即将推出"，正文没展开，我们记住这个"微妙"即可。]

**类比**：就像你想描述"水面完全平静"，但在一个"水滴模型"里，平静 = 无穷多无穷小的水滴在无穷快地落下。概念上能定义，但数学上要取极限，很别扭。

### 3.2 圆规步态（Compass Gait）—— "把轮子拆成两条腿"

轮辐轮**作弊**了：它假设"撞地时总有另一根辐条等着"。圆规步态**去掉这个作弊**——只留**两根辐条（两条腿）**，在髋部装个**销关节**，给腿加上**点质量**，于是摆动腿得**自己甩过来**。先研究**被动**情况 $u=0$（虽然作者也推了带髋部力矩的版本，其摆动动力学等价于 Acrobot，只是坐标不同）。

**图 4.9**：圆规步态——活脱脱一个**圆规**在走路。

**额外假设**：摆动腿会**收缩**以** clearance（抬脚越过）地面**，且这个收缩**不扰动该腿质量的位置**（理想化：腿像望远镜一样缩，质心不动）。

**状态**：4 个变量 $\theta_{st},\theta_{sw},\dot\theta_{st},\dot\theta_{sw}$（$st$=stance 支撑腿，$sw$=swing 摆动腿），$q=[\theta_{st},\theta_{sw}]^T$，$u=\tau$。运动方程仍是标准机械臂形式 $M\ddot q+C\dot q=\tau_g+Bu$，其中（PDF 排版丢失，这里补全，$l=a+b$）：

$$M=\begin{bmatrix}(m_h+m)l^2+ma^2 & -mlb\cos(\theta_{st}-\theta_{sw})\\ -mlb\cos(\theta_{st}-\theta_{sw}) & mb^2\end{bmatrix}$$

$$C=\begin{bmatrix}0 & -mlb\sin(\theta_{st}-\theta_{sw})\dot\theta_{sw}\\ mlb\sin(\theta_{st}-\theta_{sw})\dot\theta_{st} & 0\end{bmatrix}$$

$$\tau_g=\begin{bmatrix}(m_h l+ma+ml)g\sin\theta_{st}\\ -mbg\sin\theta_{sw}\end{bmatrix},\quad B=\begin{bmatrix}-1\\ 1\end{bmatrix}$$

**人话**：和 Acrobot 同构——两连杆摆，髋部力矩对两腿是 $-1$ 和 $+1$（作用力反作用力）。

#### 脚碰撞的 5 步算法（这是"混合系统撞地更新"的标准套路，务必懂）

撞地是脚处一个**脉冲力**把脚"瞬间拍停"。速度更新用**附录的脉冲碰撞公式**，步骤：

1. **加浮动基座**：在撞**前**的支撑脚尖，加一个**自由 $(x,y)$ 关节**（让系统暂时"飘"起来，这样才能用冲量公式）。
2. 算这个新系统的质量矩阵 $M_{fb}$。
3. 写出撞**前**摆动脚尖的位置函数 $\phi(q_{fb})$，求雅可比 $J=\partial\phi/\partial q_{fb}$。
4. 要求撞**后** $\dot\phi=0$（新脚拍停），解出撞后速度：

$$\dot q^+=\Big[I-M_{fb}^{-1}J^T\big(JM_{fb}^{-1}J^T\big)^{-1}J\Big]\dot q^-$$

   注意撞前支撑脚本来就没动（$\dot x^-=\dot y^-=0$），且你**只需读 $\dot q^+$ 的最后两个元素**（那才是关节速度）。撞后支撑脚速度按定义为 0。
5. **交换**支撑腿与摆动腿的身份（位置和速度对调）——因为迈完一步，原来的摆动腿变成新的支撑腿。

**类比**：这5步就像**接力赛交棒**——先把"谁拿着棒"这个身份记下来（步骤5的交换），交棒瞬间用动量守恒算新的速度（步骤1-4）。

**例子 4.4**：仿真被动圆规步态。**警告**：这系统**比轮辐轮对初始条件敏感得多**，作者"费了一番功夫"才找到能稳定走的初值。

**图 4.10**（参数 $m=5,\ m_h=10,\ a=b=0.5,\ \phi=0.0525,\ x(0)=[0,0,0.4,-2.0]^T$）：被动极限环。**观察**：左腿支撑时（图上半），轨迹**很像轮辐轮的摆**；但撞地后它作为摆动腿**甩一大圈弧**才回到支撑；撞地表现为速度的**不连续下跌**（漏气）。

**致命缺点**：稳定极限环的**吸引域是一条窄带**（只有很窄一圈初值能收敛）。**概念上很美，但物理上太难实现**（稍微碰一下就摔）。

### 3.3 带膝行走器（Kneed Walker）—— "给圆规装上膝盖"

## 4. 奔跑的简单模型 —— "跳"居然比"走"先被搞定

### 4.1 一段反直觉的历史

作者坦言：**令他惊讶的是，令人印象深刻的"跑"（跳跃）机器人，居然比令人印象深刻的"走"机器人出现得更早。** 他原以为跑更难。但 **Marc Raibert 的 Leg Laboratory**（1980s，先 CMU 后 MIT）的**跳跃机器**证明：跳是一种**极其聪明的"简单又动态"** 的方案——在别人还在做"慢吞吞、勉强站得住"的行走机器人时，Raibert 的机器已经**带着巨大的动能和风采把自己抛向空中**。

随后 **Koditschek & Buehler** 用简单模型分析这些跳跃器；再后来和生物学家 **Bob Full** 合作，发现**同一套简单模型居然能拟合从蟑螂到马的奔跑动物实验数据**[13][14]！其中最成功的模型 = **SLIP**。

**类比**：这就像"先学会了蹦床，才学会走路"——蹦床（跳）的物理反而更干净、更易建模。

### 4.2 SLIP（弹簧加载倒立摆）—— 奔跑的"万能简化模型"

**图 4.16**：一个**点质量 $m$**，顶在一根**无质量的弹簧腿**上（腿静止长 $l_0$，弹簧刚度 $k$）。构型由质心 $(x,z)$ 和腿的 $(l,\theta)$ 描述。**动力学分两段**：飞行相一套，支撑相一套。

#### 4.2.1 飞行相（脚离地，腿在空中甩）

状态 $x=[x,z,\dot x,\dot z]^T$，动力学就是**抛体运动**：

$$\dot x=\begin{bmatrix}\dot x\\ \dot z\\ 0\\ -g\end{bmatrix}$$

因为腿**无质量**，假设它能**瞬时**摆到任何角度，所以**取腿角度为控制输入** $\theta=u$。

**类比**：你在空中时，腿像**没有重量的羽毛**，想摆哪摆哪，不费吹灰之力——所以"摆腿"这个动作被理想化成"直接下令"。

#### 4.2.2 支撑相（脚踩地，弹簧被压缩）

改用**极坐标**，脚锚在原点。状态 $x=[r,\theta,\dot r,\dot\theta]^T$，质量位置 $x_m=\begin{bmatrix}-r\sin\theta\\ r\cos\theta\end{bmatrix}$。

总能量 = 动能 + 重力势能 + 弹簧势能：

$$T=\tfrac{m}{2}(\dot r^2+r^2\dot\theta^2),\qquad U=mgr\cos\theta+\tfrac{k}{2}(l_0-r)^2$$

代入拉格朗日，得**支撑动力学**：

$$m\ddot r-mr\dot\theta^2+mg\cos\theta-k(l_0-r)=0$$
$$mr^2\ddot\theta+2mr\dot r\dot\theta-mgr\sin\theta=0$$

**人话**：第一行 = 沿腿方向的"弹簧振子 + 离心力 + 重力分量"；第二行 = 绕脚的"摆动方程"。**支撑相完全弹道，没有控制输入**（脚一踩地，你就只能"听天由命"地让弹簧弹，控制只在飞行相做）。

#### 4.2.3 撞地不丢能量！（和轮辐轮的关键区别）

> 与轮辐轮不同，**无质量脚的弹簧腿**这个理想化意味着**撞地不损失能量**——撞地只是"切换到另一个状态空间 + 另一套动力学"，**速度不瞬变**（弹簧是软的，没有"咔哒"的硬撞）。

**转换条件**：
- 飞行→支撑：当 $z-l_0\cos\theta\le 0$（脚够到地了）。
- 支撑→飞行：当 $r\ge l_0$（弹簧伸回到静止长，脚离地）。

**例子 4.5** 的 `SpringLoadedInvertedPendulum` 系统代码里，**小心注册了混合守卫（witness functions）和重置映射**，让数值积分器用**零交叉事件检测**精确抓住事件时刻并应用重置——"相当优雅，Drake 为此花了不少功夫"。行走模型用的是**同一套机制但写在 C++ 里**，而 SLIP 是**纯 Python 实现**，**更适合看清这些细节**（这是作者给你的暗示：**想学混合系统代码，去读 SLIP 的 Python！**）。

#### 4.2.4 顶点到顶点映射（apex-to-apex）—— 又一次降维魔法

轮辐轮 2 维 → 截面后 1 维映射。SLIP 状态多得多，**还能画图分析吗？能！** 秘诀：把截面取在**跳跃顶点**（$\dot z=0$，跳到最高的那一刻）。

- 丢掉**绝对水平位置 $x$** 和**腿角度 $\theta$**（它们和飞行动力学无关）。
- 顶点只剩两个变量：**水平速度 $\dot x$** 和**高度 $z$**。
- **关键**：这俩**不独立**！因为系统**从不加/减能量**。知道总能量 $E_0$ 和顶点高度 $z$，就知道水平速度（差个符号）：

$$E_{\text{apex}}(z,\dot x)=\tfrac12 m\dot x^2+mgz=E_0$$

**类比**：顶点就像过山车爬到最高处——那一刻"动能 + 势能 = 常数"，所以你只要知道"爬多高"，就知道"还剩多少水平速度"。**能量守恒把 2 维砍成 1 维。**

为少依赖具体参数，用**无量纲**量报告：$\tilde E=\frac{E}{mgl_0}$，$\tilde k=\frac{kl_0}{mg}$。

**例子 4.6**：用零交叉事件检测，从顶点积到下一个顶点，数值算出 apex-to-apex 映射。

**图 4.17**（$\tilde k=10.7,\ \tilde E=1.61$，固定触地角 $30^\circ$）：用**阶梯法**看到**两个不动点**——约 **0.87 m 的"稳定"** 和约 **0.92 m 的"不稳定"**。

**两个"为什么"（作者特意让你问）**：
- **为什么图在稳定不动点下方突然截断？** 因为顶点若 $<l_0\cos\theta$（比触地高度还低），映射**无定义**（根本没跳起来）。
- **为什么上方也有界？** 当 $z$ 相对 $\tilde E$ 太大，**水平能量不够**穿过支撑相继续前进——质心会**压一下弹簧然后往后倒**（朝来路摔回去）。

#### 4.2.5 一个让人"停顿"的深刻问题：能量守恒的系统，能"稳定"吗？

> 轮辐轮靠**撞地漏气**才稳定的。SLIP **不漏气**（能量守恒），那它的"稳定不动点"算怎么回事？

**答案（很微妙，务必懂）**：apex-to-apex 映射把 $(z,\dot x)$ **投影**成了只剩 $z$，**这个投影偷偷用了"能量守恒"假设**。所以这个 1 维分析**只能对"不改变总能量"的扰动**谈稳定性（**部分稳定性**：i.s.L./渐近/指数）。**如果你一脚踹它、给它加了能量，这个分析什么都没说。**

这种"分段但每段都守恒能量"的系统叫**分段哈密顿系统（piecewise-Hamiltonian）**。它们居然能展现"部分稳定"，**让理论物理学家兴奋不已**（读 [14] 能感到那股热情）。[15] 还给了基于支撑动力学**小角度线性近似**的**闭式近似**回归映射。

**类比**：这像一个**无摩擦的弹珠台**——弹珠不会因摩擦停下，但**挡板的几何形状**会让它"在某些方向上"被约束到一条规律路径。它的"稳定"是**形状给的**，不是**摩擦给的**。

#### 4.2.6 SLIP 控制 —— 从"每步一个决策"到"盲跑烂路的 deadbeat"

**"无质量腿"听起来是粗暴简化，但其实是行业趋势！** 如今腿式机器人**故意把腿做得极轻**（近似点脚），让这个抽象**近似成立**。

**图 4.18**：Boston Dynamics 的 **Spot-mini**、MIT 的 **Mini-Cheetah**——腿极轻，**"身体往哪倒，脚就瞬时甩到哪"，于是很难摔**。

**概念红利**：无质量腿 ⇒ 自然把控制想成**"每步做一次决策"**，正好契合 Poincaré 分析——apex-to-apex 映射被一个**标量控制 $u[n]$（第 $n$ 跳的触地角）** 参数化：

$$x_p[n+1]=P(x_p[n],u[n])$$

于是可以**像普通离散系统那样稳定它**：在跳跃不动点附近**线性化**，用**离散 LQR** 设计控制器，完全合理。

**但 SLIP 有更骚的操作——deadbeat 控制器**：若把**控制努力代价设为 0**（与无质量腿一致），则最优动作 = **一步就把系统精确打到期望不动点**。不是所有系统都能"一步到位"，但 [15] 证明：**触地角 ↔ 跳跃高度** 在能量界限内是**可逆**的——给定期望高度，**唯一**确定一个触地角，下一顶点就达到。

**反思（作者让你停下来想）**：连续时间里，去掉控制代价 ⇒ 最优解**无界**或 **bang-bang**（油门踩到底/松到底）。但**离散时间**里不一定——常能**有界输入、有限步完美收敛**（= 连续时间的**有限时间收敛**）。SLIP 优雅到**一步**就收敛。

**故事还能更好（盲跑烂路！）**：[16] 发现"实现 deadbeat 的触地角"是"期望高度/速度"的**光滑函数**。于是想象：**在烂路上恒速盲跑**（不感知地形高度！）。既然触地角和速度是光滑关系，你可以让腿**按"自顶点起的时间"扫一条开环角度轨迹**，使得**无论脚在哪一刻碰巧撞地，那一刻的角度都恰好是 deadbeat 触地角！**

> 作者感叹：**"盲"、"奔跑"、"烂路"、"deadbeat 控制"这四个词，你绝不会想到能同时用来形容一个策略——但事实就是如此。** 他们还用这解释了生物力学里的**"地面速度匹配"** 现象——人/动物会**主动把腿甩出去"迎"地面**，正好在触地瞬间对上。

**类比**：deadbeat = **台球一杆清台**（一步到位）；盲跑烂路 = **闭着眼下楼梯，但你的腿像装了"自适应弹簧"，无论台阶高低，落脚角度自动正确**。

#### 4.2.7 SLIP 扩展

## 5. 杂耍（Juggling）—— "不是腿，但用同一套工具"

**图 4.20**：线杂耍器（line juggler）。

### 5.1 线杂耍器（最简模型）

**机器人 = 一块桨**，**球 = 一个球**，**两者都被约束在一条竖线上动**（想象球被卡在竖直轨道里）。桨的位置 $r$、球的位置 $b$（都是到地平线的竖直距离）。假设对桨有**速度控制**，能直接命令 $\dot r$。

- 球在空中：$\ddot b=-mg$（自由落体）。
- 桨碰球：建模为**瞬时弹性碰撞**，恢复系数 $0\le e\le 1$。

### 5.2 镜像律（mirror law）—— 把"无限种打法"砍成"一种聪明打法"

Poincaré 映射一般难算，但 [21] 用一个**动作空间的聪明参数化**化解了复杂度——**镜像律**：限制控制器**跟随球轨迹的（缩放）镜像**：

$$r=-k(b,\dot b)\,b$$

**美丽之处**：碰撞**永远发生在 $r=b=0,\ \dot b<0$**（球落回原点、正往下时，桨正好在那接）。[21] 选反馈律：

$$k(b,\dot b)=\kappa_0+\kappa_1(E_d-E)$$

其中 $E=mgb+\tfrac12 m\dot b^2$ 是球的总能量，$E_d$ 是期望能量。**人话**：球能量低了，桨就"多补一点"（$k$ 变大，像用力往上挑）；能量高了就"少补一点"。

这又把 Poincaré 分析简化成 **1 维的"碰前→碰前"映射**[23]：

$$\dot b[n+1]=f(\dot b[n];\kappa_0,\kappa_1)=\dot b[n]\Big[1-\tfrac{1+e}{2}\,\kappa_1\big(\dot b^2[n]-\dot b_d^2\big)\Big]$$

**结论**：对所有 $\dot b[0]<0$，系统**收敛到稳定不动点**（球被稳稳地颠在一个固定高度）。

**例子 4.7**：平面杂耍器[22]、3D 杂耍器[23]。

**类比**：镜像律 = **你照镜子练颠球**——你的手（桨）永远做球的"镜像动作"，于是接球点被"锁死"在原点，复杂度瞬间塌缩。

## 增补一：把"还不够通俗"的 5 个概念，再各加一个类比

1. **横截（transverse）**：截面不能和轨迹"平行"。
   **类比**：打卡机的闸机要**横在路中间**，不能**顺着路摆**——顺着你永远穿不过去，打不到卡。

2. **零交叉检测（zero-crossing / witness function）**：仿真器怎么"精确"抓住撞地那一刻？它盯一个"守卫函数" $g(x)$（比如 $g=\theta-(\gamma+\alpha)$），当 $g$ **从正变负穿过 0** 的那一瞬，就是撞地。普通固定步长积分会"跨过"这一瞬，零交叉检测会**自动把步长细分**，精确停在 $g=0$。
   **类比**：像**慢动作回放**——普通仿真是一秒拍 30 帧可能漏掉撞击帧；零交叉检测是"一旦检测到要撞，立刻切到每秒 10000 帧"，绝不漏。

3. **重置映射（reset map）**：撞地后，状态"瞬移"到新值（速度乘 $\cos 2\alpha$，或交换两腿）。
   **类比**：游戏里的**传送门**——连续运动到门口，"唰"一下坐标被改写。混合系统 = 连续运动 + 偶尔传送。

4. **分段哈密顿 / 部分稳定**：见 §4.2.5 的"无摩擦弹珠台"类比，再补一个：**冰面上的弹珠被一圈弧形墙围着**——没有摩擦它永不停，但**墙的几何**让它在"切向"被约束成规律运动；你**垂直踹它一脚（加能量）**，规律就破了——所以"稳定"只对"不踹它"的扰动成立。

5. **deadbeat 一步收敛 vs 连续 bang-bang**：连续时间去控制代价 ⇒ 解是"油门瞬间无穷大"（数学爆炸）或"踩死/松死"。离散时间因为"一步之内系统自己跑了一段"，**一个有限的触地角就够把误差清零**。
   **类比**：连续 = 你想**这一毫秒**就把车停到车位（需要无穷大刹车）；离散 = 你**这一圈**把车停到车位（一圈内慢慢刹，有限力度即可）。

### 实验 1：轮辐轮——纯 NumPy 前向仿真 + 步到步映射（可跑）

```python
import numpy as np
import matplotlib.pyplot as plt

# ---- 参数（对应图4.7 / 图4.8，自己改 gamma 看分岔！）----
g, l = 9.8, 1.0
alpha = np.pi/8          # 半辐条夹角
gamma = 0.15             # 坡角：试 0.05(会停) / 0.15(稳定滚) / >alpha(站不住)
cos2a = np.cos(2*alpha)  # 撞地"速度保留率"，每步乘它=漏气

# 门槛速度
omega1 =  np.sqrt(2*g/l*(1-np.cos(gamma-alpha)))  # 往前迈的门槛
omega2 = -np.sqrt(2*g/l*(1-np.cos(alpha+gamma)))  # 往后迈的门槛

def step_map(w):
    """步到步 Poincaré 映射：本步初速 w -> 下一步初速。对应 PDF 三段分段公式。"""
    if gamma <= alpha:
        if w > omega1:                                   # 情况A：往前迈
            return cos2a*np.sqrt(w**2 + 4*g/l*np.sin(alpha)*np.sin(gamma))
        elif w > omega2:                                 # 情况B：迈不动，晃回来
            return -w*cos2a
        else:                                            # 情况C：往后迈
            return -cos2a*np.sqrt(w**2 - 4*g/l*np.sin(alpha)*np.sin(gamma))
    else:  # gamma>alpha：站不住，omega1=0
        if w >= 0:
            return cos2a*np.sqrt(w**2 + 4*g/l*np.sin(alpha)*np.sin(gamma))
        elif w > omega2:
            return -w*cos2a
        else:
            return -cos2a*np.sqrt(w**2 - 4*g/l*np.sin(alpha)*np.sin(gamma))

# ---- 画"阶梯法"：蓝线=映射，红线=斜率1，肉眼找不动点 ----
ws = np.linspace(-3, 3, 600)
# 注意 omega1/omega2 处映射无定义(会停在不稳定平衡)，画图时跳过 NaN
vals = np.array([step_map(w) if not (np.isclose(w,omega1) or np.isclose(w,omega2)) else np.nan for w in ws])
plt.figure(); plt.plot(ws, vals, 'b', label='Poincaré map P'); plt.plot(ws, ws, 'r--', label='slope 1')
plt.axhline(0,color='k',lw=.5); plt.axvline(0,color='k',lw=.5)
plt.xlabel('θ̇⁺_n'); plt.ylabel('θ̇⁺_{n+1}'); plt.legend(); plt.grid(alpha=.3)
plt.title(f'rimless wheel  γ={gamma:.2f}  α={alpha:.2f}  → 看蓝红交点=不动点'); plt.show()

# ---- 迭代几条轨迹，验证"要么停、要么收敛到滚动" ----
for w0 in [0.2, 1.0, 2.5, -1.0]:
    w, hist = w0, [w0]
    for _ in range(40):
        w = step_map(w); hist.append(w)
        if abs(w) < 1e-3: break      # 漏光气，停下
    plt.plot(hist, '-o', ms=3, label=f'w0={w0}')
plt.xlabel('step n'); plt.ylabel('θ̇⁺'); plt.legend(); plt.grid(alpha=.3)
plt.title('迭代：观察收敛到 ω*_roll 或 0'); plt.show()

# 解析滚动不动点（验证书上公式 ω*_roll = cot(2α)·√(4g/l·sinα·sinγ)）
w_roll = (1/np.tan(2*alpha))*np.sqrt(4*g/l*np.sin(alpha)*np.sin(gamma))
print("解析 ω*_roll =", round(w_roll,4), " 门槛 ω1 =", round(omega1,4),
      " → 滚动解存在?" , w_roll > omega1)
```

**做实验建议**：把 `gamma` 从 `0.05` 调到 `0.30`，你会**亲眼看到分岔**——小 γ 时所有线归零（停），中 γ 时出现非零收敛值（滚），大 γ 时 `omega1=0` 且站着消失。**这比读十遍公式都管用。**

### 实验 2：SLIP——用 SciPy 的 `solve_ivp(events=...)` 做零交叉检测 + apex 映射（可跑）

这段**直接演示作者说的"零交叉事件检测"**，是理解 Drake `WitnessFunction` 思想的最佳替代品：

```python
import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

m, g = 1.0, 9.81
l0, k = 1.0, 107.0          # 对应无量纲 k̃=kl0/(mg)≈10.7
E_tilde = 1.61              # 无量纲总能量 -> 反推 E0
E0 = E_tilde*m*g*l0

def flight(t, y):           # y=[x,z,xd,zd]  抛体
    return [y[2], y[3], 0.0, -g]
def touchdown(t, y, theta_td):   # 守卫：脚够到地  z - l0*cosθ = 0
    return y[1] - l0*np.cos(theta_td)
touchdown.terminal = True; touchdown.direction = -1   # 从正穿到负=落地

def stance(t, y):           # y=[r,th,rd,thd] 极坐标，弹簧腿
    r,th,rd,thd = y
    rdd = r*thd**2 - g*np.cos(th) + (k/m)*(l0-r)
    thdd = (g*np.sin(th) - 2*rd*thd)/r
    return [rd, thd, rdd, thdd]
def liftoff(t, y):          # 守卫：弹簧伸回静止长  r-l0=0
    return y[0]-l0
liftoff.terminal = True; liftoff.direction = 1

def apex_to_apex(z_apex, theta_td):
    """从一个顶点(ż=0, 高度z_apex)积到下一个顶点，返回新高度。"""
    # 能量守恒 -> 顶点水平速度
    xd = np.sqrt(max(2/m*(E0 - m*g*z_apex), 0.0))
    # 飞行相：从顶点往下落，直到 touchdown
    sol = solve_ivp(flight, [0,50], [0,z_apex,xd,0],
                    events=lambda t,y: touchdown(t,y,theta_td), max_step=1e-3)
    x,z,xd_,zd_ = sol.y[:,-1]
    # 落地瞬间转极坐标(脚锚原点)：r=l0, θ=theta_td
    r, th = l0, theta_td
    # 速度投影到极坐标：径向 rd 与切向 r·thd
    # 世界速度 (xd_,zd_)，腿方向单位向量与切向单位向量做投影
    er = np.array([-np.sin(th),  np.cos(th)])   # 径向(沿腿向外)
    et = np.array([-np.cos(th), -np.sin(th)])   # 切向(θ增加方向)
    v  = np.array([xd_, zd_])
    rd  = np.dot(v, er)
    thd = np.dot(v, et)/r
    # 支撑相：弹到 liftoff
    sol2 = solve_ivp(stance, [0,50], [r,th,rd,thd],
                     events=liftoff, max_step=1e-3)
    r2,th2,rd2,thd2 = sol2.y[:,-1]
    # 离地瞬间转回世界坐标，再飞到下一个顶点(ż=0)
    vx = -rd2*np.sin(th2) - r2*thd2*np.cos(th2)
    vz =  rd2*np.cos(th2) - r2*thd2*np.sin(th2)
    z_new = r2*np.cos(th2) + vz**2/(2*g)   # 抛体顶点高度
    return z_new, (vx>0)   # 返回新高度 & 是否仍前进

# 画 apex-to-apex 映射（对应图4.17）
theta_td = np.deg2rad(30)
zs = np.linspace(l0*np.cos(theta_td)+0.01, E0/(m*g)-0.01, 200)
znext, ok = [], []
for z in zs:
    zn, fwd = apex_to_apex(z, theta_td); znext.append(zn if fwd else np.nan); ok.append(fwd)
plt.figure(); plt.plot(zs, znext, 'b', label='apex map'); plt.plot(zs, zs, 'r--', label='slope 1')
plt.xlabel('z_apex[n]'); plt.ylabel('z_apex[n+1]'); plt.legend(); plt.grid(alpha=.3)
plt.title('SLIP apex-to-apex map (k̃≈10.7, Ẽ≈1.61, θ_td=30°) → 两交点=稳定+不稳定不动点'); plt.show()
```

**你会看到**：蓝线和红线**两个交点**——下面那个斜率 $|·|<1$（**稳定**，≈0.87 m），上面那个斜率 $>1$（**不稳定**，≈0.92 m），且曲线在 $z=l_0\cos\theta$ 附近**突然截断**——和 PDF 图 4.17 与作者的两个"为什么"完全对上。**这就是"用代码把书读活"。**

### 实验 3：Drake 混合系统骨架——`WitnessFunction` + reset 的"标准长相"（思想版）

作者反复强调"读 SLIP 的 Python 看 witness/reset 细节"。下面把那个**结构**抽出来给你看（**重点看注释，理解每一块在干什么**）：

```python
# 概念骨架：在 Drake 里，一个"连续+咔哒"的混合系统 = LeafSystem + 三件套
# 实际 API 以你的 Drake 版本为准；这里展示的是作者 notebook 的"形状"。
from pydrake.systems.framework import LeafSystem, WitnessFunction, WitnessFunctionDirection

class RimlessWheel(LeafSystem):
    def __init__(self, g, l, alpha, gamma):
        super().__init__()
        self.g, self.l, self.alpha, self.gamma = g, l, alpha, gamma
        self.DeclareContinuousState(2)            # 状态 [θ, θ̇]
        self.cos2a = np.cos(2*alpha)              # 撞地保留率

    def DoCalcTimeDerivatives(self, ctx, deriv):  # ① 连续部分：支撑摆方程 θ̈=(g/l)sinθ
        th, thd = ctx.get_continuous_state_vector().Get_value()
        deriv.get_mutable_value()[:] = [thd, (self.g/self.l)*np.sin(th)]

    def DoMakeWitnessFunctions(self, ctx):        # ② 守卫：两条"撞地线" θ=γ±α
        w_fwd = WitnessFunction("heel_strike_fwd", self,
                    lambda c: self.gamma + self.alpha - c.get_continuous_state()[0],
                    WitnessFunctionDirection.kPositiveThenNegative,  # 从正穿到负
                    self._heel_strike)            # 穿过时调用 reset
        w_bwd = WitnessFunction("heel_strike_bwd", self,
                    lambda c: c.get_continuous_state()[0] - (self.gamma - self.alpha),
                    WitnessFunctionDirection.kPositiveThenNegative,
                    self._heel_strike)
        return [w_fwd, w_bwd]

    def _heel_strike(self, ctx, ev, state):       # ③ 重置映射：速度乘 cos2a + 坐标折回
        th, thd = ctx.get_continuous_state_vector().Get_value()
        thd_new = thd * self.cos2a                # 漏气！这就是 L(t-)=L(t+) 的结果
        # 把 θ 折到新一腿的起点（坐标换腿），具体折法见 PDF 坐标约定
        state.get_mutable_continuous_state().get_mutable_vector().Set_value([self.gamma-self.alpha, thd_new])
```

**三件套对应关系（背下来，所有混合模型都长这样）**：
- `DoCalcTimeDerivatives` = **丝滑部分**（摆方程 / 抛体 / 弹簧振子）。
- `DoMakeWitnessFunctions` = **打卡机/传送门触发器**（守卫函数 + 穿越方向）。
- reset 回调 = **传送门改写坐标**（乘 $\cos2a$ / 交换两腿 / 切状态空间）。

**SLIP 的不同之处**：它的 reset **不改速度**（弹簧软撞，无漏气），只**切换状态变量含义**（飞行用 $x,z$，支撑用 $r,\theta$）——这正是"撞地不丢能量"的代码体现。

### 实验 4：习题 4.1 一维 Hopper——能量函数 + `LeafSystem` 控制器类（按题意写）

```python
import numpy as np
from pydrake.systems.framework import LeafSystem, BasicVector

# (a) 总机械能：动能 + 重力势能 + 弹簧势能（hopper 的具体坐标以 notebook 为准，这里是通用形式）
def hopper_energy(state, m, g, k, rest):
    z, zd = state[0], state[1]              # 质心高度 & 速度（按 notebook 定义替换）
    spring_def = state[2]                   # 弹簧形变量（按 notebook 定义替换）
    KE = 0.5*m*zd**2
    PE_g = m*g*z
    PE_s = 0.5*k*spring_def**2
    return KE + PE_g + PE_s

# (b) 跳跃控制器：每个采样时刻读状态 -> 输出弹簧预载 preload
class HoppingController(LeafSystem):
    def __init__(self, m, g, k, z_des):
        super().__init__()
        self.m, self.g, self.k, self.z_des = m, g, k, z_des
        self.DeclareVectorInputPort("state", BasicVector(3))     # 读 hopper 状态
        self.DeclareVectorOutputPort("preload", BasicVector(1), self._calc_preload)
        self.DeclarePeriodicDiscreteUpdateEvent(period_sec=0.01, offset_sec=0.0,
                                                update=self._tick)  # 每 10ms 决策一次
    def _tick(self, ctx, discrete): pass   # 若需内部记忆（如相位），在这里更新

    def _calc_preload(self, ctx, out):
        s = ctx.get_input_port(0).Eval(ctx)
        E = hopper_energy(s, self.m, self.g, self.k, rest=0.0)
        E_des = self.m*self.g*self.z_des     # 期望能量 ~ 跳到 z_des 所需（notebook 给精确式）
        # 能量整形思想：能量不够就多预载弹簧(多存能量)，够了就少存
        preload = np.clip(K_GAIN*(E_des - E), 0.0, PRELOAD_MAX)
        out.Set_value([preload])
```

**这就是把第3章"能量整形摆起"搬到跳跃上**：第3章用 $u=k\dot\theta\cos\theta\,\tilde E$ 把摆的能量调到 $E_d$；这里用"弹簧预载"把 hopper 的能量调到 $E_{des}$，**能量对了，跳的高度就对了**。notebook 会给精确的 $E_{des}$ 与增益公式，你套这个**类骨架**填进去即可。

### 实验 5：杂耍镜像律——10 行看"收敛到稳定颠球"（可跑）

```python
import numpy as np
m, g, e = 1.0, 9.81, 0.8          # 球质量、重力、恢复系数
k0, k1 = 1.0, 0.05                # 镜像律增益
bd_des = -3.0                     # 期望碰前速度(负=往下) -> 决定颠球高度
b, bdot, r = 0.0, -2.0, 0.0       # 球位置/速度、桨位置
dt = 1e-3
hist = []
for _ in range(20000):
    if b <= 0 and bdot < 0:       # 碰撞：镜像律保证此时 r≈0
        E  = m*g*b + 0.5*m*bdot**2
        Ed = 0.5*m*bd_des**2
        k  = k0 + k1*(Ed - E)     # 能量低->k大->挑得狠
        bdot = -e*bdot + (1+e)*(-k*bdot)*0   # 简化：用镜像律导出的碰后速度
        # 更直接用 PDF 的 1 维映射做"碰前->碰前"验证：
    bdot -= g*dt; b += bdot*dt    # 球自由落体
    r = -k*b                      # 镜像律：桨=球的镜像
    if b <= 0: b, bdot = 0.0, abs(bdot)*e   # 兜底碰撞
    hist.append(b)
import matplotlib.pyplot as plt
plt.plot(hist); plt.xlabel('step'); plt.ylabel('ball height'); plt.title('mirror law → 稳定颠球'); plt.show()
```

> 注：上面是**直觉版**仿真（含兜底碰撞）；要严格复现 PDF 的 1 维映射 $\dot b[n+1]=\dot b[n][1-\frac{1+e}{2}\kappa_1(\dot b^2-\dot b_d^2)]$，直接迭代该式即可，会看到对所有 $\dot b[0]<0$ 都收敛——**这正是镜像律把杂耍"驯服"成 1 维稳定映射的威力**。
