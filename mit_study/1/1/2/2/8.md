### 1. 整套代码的最终目的
用MIT开源机器人库`pydrake`搭建**双摆物理仿真**：
1. 加载双摆机械模型，自动根据物理公式（之前讲的$M\ddot q+C\dot q=\tau_g+Bu$）计算摆动；
2. 网页弹出3D/2D可视化窗口，实时看两根杆子怎么晃；
3. 仿真10秒无电机推力，记录每一刻的角度、转速；
4. 画出两条曲线：肩膀、手肘各自的角度变化、转速变化图。

### 2. 关键工具大白话定义
1. **matplotlib + mpld3**：画图工具。matplotlib画静态曲线，mpld3让图片在网页笔记本里可缩放交互。
2. **numpy**：数字计算工具箱，存时间、角度数组。
3. **IPython.display**：jupyter笔记本专用，用来弹出文字、交互式图表。
4. **pydrake**：MIT官方机器人物理仿真库，自动实现我们之前讲的机械动力学公式，不用手动推导$M、C、\tau_g$矩阵。
    - MultibodyPlant：核心物理引擎，算重力、惯性、关节受力；
    - Meshcat：网页可视化窗口，专门看机器人3D模型；
    - DiagramBuilder：搭积木工具，把「物理引擎、可视化、数据记录」拼在一起；
    - Simulator：仿真运行器，控制时间往前走，一步步算物体运动。
5. underactuated：这门MIT欠驱动课程配套工具包，简化模型加载、动力学计算。
6. running_as_notebook：判断代码是不是在jupyter网页笔记本里运行（本地Python脚本会走另一条逻辑）。

# 第二部分：核心函数 def double_pendulum_demo(): 完整仿真逻辑
整个函数就是一套完整流程：**搭建物理引擎 → 加载双摆模型 → 连接可视化 → 开启数据记录 → 设置初始状态 → 跑10秒仿真 → 画图输出曲线**

## 步骤1：搭建仿真积木组装台、初始化物理引擎
```python
builder = DiagramBuilder()
plant, scene_graph = AddMultibodyPlantSceneGraph(builder, time_step=0.0)
```
1. `builder = DiagramBuilder()`：新建空白组装台，后面所有零件都要“装”在这上面；
2. `AddMultibodyPlantSceneGraph(builder, time_step=0.0)`：
   - 创建两个核心部件：`plant`物理引擎、`scene_graph`空间图形管理器；
   - `time_step=0.0`：连续时间仿真，无限精细计算，不用固定间隔离散计算，双摆摆动轨迹更顺滑。

## 步骤2：加载双摆机器人模型文件
```python
parser = Parser(plant)
ConfigureParser(parser)
parser.AddModelsFromUrl("package://underactuated/models/double_pendulum.urdf")
plant.Finalize()
```
1. `parser = Parser(plant)`：创建模型加载器，绑定到我们的物理引擎plant；
2. `ConfigureParser(parser)`：课程工具函数，配置加载器，能读取`package://`这种课程内置模型路径；
3. `parser.AddModelsFromUrl(...)`：加载双摆描述文件double_pendulum.urdf
   urdf文件里写死了：杆长l1/l2、重物质量m1/m2、两个旋转关节（肩膀$\theta_1$、手肘$\theta_2$），物理引擎自动读取质量、尺寸，自动生成之前讲的动力学矩阵M、C、重力$\tau_g$，不用我们手动写公式；
4. `plant.Finalize()`：模型加载完成，锁定物理引擎，不能再添加零件，准备开始计算物理。

## 步骤3：绑定电机控制输入、网页可视化窗口
```python
builder.ExportInput(plant.get_actuation_input_port())
MeshcatVisualizer.AddToBuilder(builder, scene_graph, meshcat)
meshcat.Set2dRenderMode(xmin=-2.8, xmax=2.8, ymin=-2.8, ymax=2.8)
```
1. `builder.ExportInput(plant.get_actuation_input_port())`
   把物理引擎的**电机扭力输入口**暴露出来，对应我们之前的$\boldsymbol{u}=[\tau_1,\tau_2]$；后面代码可以往这个口输入电机推力，本demo输入0，代表无电机。
2. `MeshcatVisualizer.AddToBuilder(...)`
   把网页可视化窗口meshcat安装到组装台builder上，物理引擎每一步计算完姿态，自动同步到网页渲染双摆动画；
3. `meshcat.Set2dRenderMode(...)`
   把3D网页窗口强制切成2D平面视图，窗口显示范围x、y轴从-2.8到2.8，刚好完整放下摆动的双摆。

## 步骤4：加装数据记录仪，保存每一刻的系统状态
```python
logger = LogVectorOutput(plant.get_state_output_port(), builder)
```
- `plant.get_state_output_port()`：物理引擎输出口，实时吐出完整系统状态$\boldsymbol{x}=[\theta_1,\theta_2,\dot\theta_1,\dot\theta_2]$（2个角度+2个转速）；
- `LogVectorOutput`：记录仪，把每一个仿真时间点的4个数值全部存下来，仿真结束后可以提取绘图；
- 安装到组装台builder上，仿真运行全程自动记录数据，不用手动存。

## 步骤5：组装全部零件，生成完整仿真系统
```python
diagram = builder.Build()
```
builder里装好了「物理引擎plant、可视化窗口、数据记录仪、电机输入口」，Build()把所有零件连线、封装成一个完整可运行的仿真系统diagram。

## 步骤6：创建仿真运行器，控制仿真时间
```python
simulator = Simulator(diagram)
if running_as_notebook:
    simulator.set_target_realtime_rate(1.0)
```
1. `simulator = Simulator(diagram)`：给完整系统配一个“播放器”simulator，用来启动、推进仿真时间；
2. `set_target_realtime_rate(1.0)`：仅jupyter笔记本生效，仿真速度=现实真实时间；现实过1秒，仿真也走1秒，肉眼能看清摆动动画；
   如果改成2.0就是2倍速快放，本地脚本运行不会执行这行，会全速极速跑完10秒。

## 步骤7：设置仿真初始条件（t=0秒时双摆状态）
```python
context = simulator.get_mutable_context()
context.SetContinuousState([1.0, 1.0, 0.0, 0.0])  # (theta1, theta2, theta1dot, theta2dot)
diagram.get_input_port(0).FixValue(context, [0.0, 0.0])  # Zero input torques
```
### context通俗理解：仿真世界的“快照容器”，存当前所有状态、参数
1. `SetContinuousState([1.0, 1.0, 0.0, 0.0])`
   初始化t=0时双摆状态，对应$\boldsymbol{x}=[\theta_1,\theta_2,\dot\theta_1,\dot\theta_2]$：
   - $\theta_1=1.0$弧度：肩膀杆向右偏57度左右；
   - $\theta_2=1.0$弧度：手肘杆相对肩膀再偏57度；
   - $\dot\theta_1=0,\dot\theta_2=0$：初始完全静止，松手瞬间没有摆动速度；
2. `FixValue(context, [0.0, 0.0])`
   给电机输入口固定扭力$\boldsymbol{u}=[\tau_1,\tau_2]=[0,0]$，全程不给电机推力，只靠重力让双摆自由摆动。

## 步骤8：运行仿真，推进时间到10秒
```python
simulator.AdvanceTo(10.0)
```
让仿真从t=0一直计算到t=10秒，过程中：
1. plant根据动力学公式自动算每一刻角度、加速度；
2. meshcat实时刷新网页动画，看双摆自由摆动；
3. logger全程自动记录所有时间点的角度、转速数据。

## 步骤9：读取记录数据，绘制时间曲线
```python
plt.figure()
fields = ["shoulder", "elbow"]
log = logger.FindLog(context)
for i in range(2):
    plt.subplot(2, 1, i + 1)
    plt.plot(log.sample_times(), log.data()[(i, i + 2), :].transpose())
    plt.legend(["position", "velocity"])
    plt.xlabel("t")
    plt.ylabel(fields[i])
    plt.grid(True)
display(mpld3.display())
```
逐行拆解：
1. `plt.figure()`：新建一张空白画布，用来画曲线；
2. `fields = ["shoulder", "elbow"]`：给两张子图分别起名肩膀、手肘；
3. `log = logger.FindLog(context)`：从记录仪里提取全部10秒保存的数据；
4. `for i in range(2)`：循环2次，分别画肩膀(i=0)、手肘(i=1)两张子图；
5. `plt.subplot(2, 1, i + 1)`：画布分成上下2张图，第一张肩膀，第二张手肘；
6. `log.sample_times()`：记录仪保存的全部时间点数组 [0,0.01,0.02...10.0]；
7. `log.data()[(i, i + 2), :].transpose()`
   log.data()存储格式：每行是一个时间点，4列依次是$\theta_1,\theta_2,\dot\theta_1,\dot\theta_2$
   - i=0（肩膀）：取第0列$\theta_1$（角度）、第2列$\dot\theta_1$（转速）；
   - i=1（手肘）：取第1列$\theta_2$（角度）、第3列$\dot\theta_2$（转速）；
   一条曲线代表角度随时间变化，一条代表转速随时间变化；
8. `plt.legend(["position", "velocity"])`：给两条曲线标注图例：位置、速度；
9. `plt.xlabel("t")`横轴标注时间t；`plt.ylabel(fields[i])`纵轴标注肩膀/手肘；
10. `plt.grid(True)`给图表加上网格，方便读数；
11. `display(mpld3.display())`jupyter弹出交互式曲线图，鼠标悬浮能看坐标。

## 最后一行：调用函数启动整套仿真
```python
double_pendulum_demo()
```
执行上面写好的全部仿真流程，运行代码立刻弹出网页动画，跑完自动出曲线图。

# 关键对应之前理论知识点（打通公式和代码）
1. `plant`物理引擎内部自动求解 $\ddot q=M^{-1}(\tau_g+Bu-C\dot q)$，我们不用手动写矩阵；
2. `context.SetContinuousState([θ1,θ2,θ1dot,θ2dot])` 对应完整系统状态$\boldsymbol{x}=[\boldsymbol{q}^T,\dot{\boldsymbol{q}}^T]^T$；
3. `FixValue([0,0])` 对应控制输入$\boldsymbol{u}=[\tau_1,\tau_2]$，本demo电机扭力为0，纯靠重力$\tau_g$运动；
4. logger记录的4列数据 = $\boldsymbol{q}$（2个角度）+ $\dot{\boldsymbol{q}}$（2个速度）；
5. 如果修改输入`[5,2]`，就是给肩膀、手肘电机施加扭力，变成完全驱动可控双摆；如果只保留一个输入`[0,2]`，就是欠驱动双摆（无肩膀电机）。
