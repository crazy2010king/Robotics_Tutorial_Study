## 前置必看基础（没这些看不懂全文）
### 1. 图里物体：双摆（两根杆、两个重物）
图片画的是**简单双摆**：
- 顶端固定在天花板，第一根杆长$l_1$，末端挂质量$m_1$；
- $m_1$再接第二根杆$l_2$，末端挂质量$m_2$；
- $\theta_1$ = 第一根杆和竖直向下方向的夹角（肩膀关节角度）；
- $\theta_2$ = 第二根杆相对第一根杆的夹角（手肘关节角度）；
- $g$ = 重力，所有东西都会往下掉的拉力来源。

### 2. 统一符号大白话字典（全文通用）
| 加粗符号 | 普通人翻译 | 双摆对应例子 |
| ---- | ---- | ---- |
| $\boldsymbol{q}$ | 位置向量：一组数字，记录所有关节现在摆到什么角度/位置 | $\boldsymbol{q}=[\theta_1,\theta_2]^T$，两个角度，代表双摆当前姿势 |
| $\dot{\boldsymbol{q}}$ | 上面一点=速度：关节转动快慢 | $\dot{\theta_1}$肩膀转多快，$\dot{\theta_2}$手肘转多快 |
| $\ddot{\boldsymbol{q}}$ | 上面两点=加速度：转动速度变快/变慢的力度 | 杆子突然猛地加速摆动的程度 |
| $\boldsymbol{u}$ | 控制输入：电机能主动输出的转动力（扭矩），我们唯一能手动调节的东西 | $\tau_1$肩膀电机扭力、$\tau_2$手肘电机扭力 |
| $\boldsymbol{M}(\boldsymbol{q})$ | 惯性矩阵：整套摆锤的“总重量阻力”，姿势不同阻力大小会变 | 两根杆张开越大，摆动起来越难加速 |
| $\boldsymbol{C}(\boldsymbol{q},\dot{\boldsymbol{q}})$ | 拉扯力矩阵：杆子转起来后，两根杆互相甩、互相拖拽产生的额外阻力 | 转秋千时，外圈人会被甩着拉扯支架 |
| $\tau_g(\boldsymbol{q})$ | 重力自带的拉扯力：地球一直往下拽重物，不用电机也会自己往下垂 | 松手后双摆自己晃来晃去全靠这个力 |
| $\boldsymbol{B}$ | 动力转换矩阵：把电机输出的扭力，转换成能让杆子加速的力 | 电机拧一下，通过$\boldsymbol{B}$换算成关节实际受力 |
| $(\cdot)^T$ | 转置，简单理解：把一横行数字改成一竖列数字，纯书写格式 | $[\theta_1,\theta_2]^T$ = 竖排两个角度 |
| $\mathrm{rank}$（秩） | 能独立控制的方向数量 | 有2个电机=能单独控制2个方向；1个电机只能控制1个方向 |
| $\dim(\cdot)$（维度） | 括号里有多少个独立变量 | $\dim(\boldsymbol{q})=2$：双摆有2个角度；$\dim(\boldsymbol{u})=1$：只有1台电机 |

### 3. 两个核心概念（全文分界线）
1. **完全驱动（fully actuated）**
电机数量 = 需要控制的关节自由度，想单独让任意一根杆子加速/减速，电机都能做到。
双摆装2台电机：肩膀、手肘各一台，就是完全驱动。
2. **欠驱动（underactuated）**
电机数量 < 需要控制的关节自由度，没法单独操控某一根杆子，只能靠重力、杆子互相拉扯联动控制。
双摆只装1台手肘电机、肩膀无电机，就是欠驱动。

# 第一部分：图片第一段——双摆基础动力学公式讲解
## 公式1：标准机械臂通用方程 $\boldsymbol{M(q)\ddot{q}+C(q,\dot{q})\dot{q}=\tau_g(q)+Bu}$
### 1. 上下文原文意思
不管是机械手臂、双摆、倒立摆，所有硬杆+重物组成的机械结构，运动受力全部遵守这条公式，也叫“操纵器标准方程”。我们先把等式左右两边拆开讲。
### 2. 等式左边：所有阻碍物体加速的阻力
$$\boldsymbol{M(q)\ddot{q}} + \boldsymbol{C(q,\dot{q})\dot{q}}$$
1. $\boldsymbol{M(q)\ddot{q}}$：惯性阻力
想让杆子改变摆动速度（产生加速度$\ddot{q}$），必须克服整套摆锤的总重量惯性。杆子摆的姿势$\boldsymbol{q}$不一样，惯性大小$\boldsymbol{M(q)}$也会变。
类比：拎一根短木棍随便甩，惯性小；拎一根长钢管很难甩动，惯性大。
2. $\boldsymbol{C(q,\dot{q})\dot{q}}$：旋转拖拽阻力
只要杆子在转动（有速度$\dot{q}$），两根杆子就会互相甩、互相拉扯，凭空多出一份阻碍运动的力。
类比：你坐在旋转椅子上转圈，伸开手臂会被向外甩，手臂拉扯你的身体，这就是同类拖拽力。

### 3. 等式右边：所有推动物体运动的动力
$$\tau_g(\boldsymbol{q}) + \boldsymbol{B}\boldsymbol{u}$$
1. $\tau_g(\boldsymbol{q})$：重力天然动力
地球引力永远往下拽两个重物，就算关掉所有电机，松开手摆锤也会自己晃荡，完全不受我们控制，只和当前摆的姿势$\boldsymbol{q}$有关。
2. $\boldsymbol{B}\boldsymbol{u}$：电机可控动力
$\boldsymbol{u}$是电机拧出多大扭力，$\boldsymbol{B}$负责把电机动力转换、传递到关节上；这是整道公式里**唯一人类能主动调节、操控**的部分。

### 4. 整句大白话翻译
想要让杆子产生摆动加速度，需要克服「自身重量惯性」和「杆子互相甩动的拖拽力」；提供动力的来源只有两个：地球自带的重力，以及我们电机拧出来的扭力。

## 补充文字：惯性矩阵$\boldsymbol{M(q)}$关键特性
原文说：$\boldsymbol{M(q)}$永远对称、正定，一定能求逆矩阵$\boldsymbol{M^{-1}(q)}$。
通俗解释：
正定+可逆 = 惯性阻力永远是正向阻碍，不存在“物体自己凭空加速”的情况；我们一定能把公式变形，单独解出加速度$\ddot{\boldsymbol{q}}$，不会出现数学无解的情况。

## 公式2：变形求加速度 $\boldsymbol{\ddot{q}=M^{-1}(q)\big[\tau_g(q)+Bu - C(q,\dot{q})\dot{q}\big]}$
### 1. 变形逻辑
把公式1左边的惯性矩阵移到右边，两边同时乘$\boldsymbol{M(q)}$的逆矩阵$\boldsymbol{M^{-1}(q)}$，单独把加速度$\ddot{\boldsymbol{q}}$放到等式左边。
### 2. 通俗拆解
加速度 = 总阻力倒数 ×（重力推力 + 电机推力 - 杆子互相拖拽的阻力）
完美对应之前网页里的拆分形式：$\ddot{\boldsymbol{q}}=f_1 + f_2 \boldsymbol{u}$
- $f_1 = \boldsymbol{M^{-1}}(\tau_g - C\dot{\boldsymbol{q}})$：重力、拖拽带来的天然运动，和电机无关；
- $f_2 = \boldsymbol{M^{-1}B}$：电机出力对加速度的影响系数。

## 原文判定规则：完全驱动的数学条件
原文：这套机械臂系统是完全驱动，**当且仅当矩阵$\boldsymbol{B}$是满行秩**。
### 通俗翻译
$\boldsymbol{B}$的秩 = 电机能独立控制多少个关节方向；
满行秩 = 能控制的方向数量 = 总关节自由度，也就是电机数量刚好匹配需要控制的关节数。

### 代入本双摆例子验证
1. 完整驱动双摆：肩膀、手肘各1台电机
$\boldsymbol{q}=[\theta_1,\theta_2]^T$，$\dim(\boldsymbol{q})=2$（2个关节角度）
$\boldsymbol{u}=[\tau_1,\tau_2]^T$，$\dim(\boldsymbol{u})=2$（2台电机扭力）
$\boldsymbol{B}$是2行2列单位矩阵$\boldsymbol{I}_2$，秩=2，等于$\dim(\boldsymbol{q})=2$ → 完全驱动。
单位矩阵$\boldsymbol{I}_2$大白话：电机1只控制肩膀、电机2只控制手肘，互不干扰，单独拧任意一个电机，只会改变对应杆子的加速度。

# 第三部分：欠驱动双摆案例（重点，走路机器人原型）
## 场景设定：去掉肩膀电机，只留手肘电机
1. 改动后：肩膀关节无电机，只有手肘能输出扭力
   $\boldsymbol{u}=\tau_2$，现在电机输入只有1个数值，$\dim(\boldsymbol{u})=1$；
2. 转换矩阵$\boldsymbol{B}$变成竖排$[0,1]^T$：
   第一行0=电机扭力完全影响不到肩膀关节；第二行1=扭力只作用在手肘；
3. 判定欠驱动：
   总自由度$\dim(\boldsymbol{q})=2$（肩膀+手肘两个角度要控制），电机可控方向只有1个，满足 $\mathrm{rank}(\boldsymbol{B})=1 < 2$，属于欠驱动系统。

## 原文关键比喻：这个简化模型就是走路机器人的基础
看着只是少一个电机的双摆，但其运动规律和人类走路高度相似：
人走路时髋关节（肩膀对应）没有单独电机直接发力，只能靠腿部摆动、重力联动维持平衡，和“只有手肘电机的双摆”底层运动逻辑一模一样，是课程后续讲行走机器人最简单的基础模型。

## 拓展：欠驱动不只有“电机比关节少”这一种情况
原文举人体肌肉反例：
人体每条肢体有几十块肌肉（驱动器数量 > 关节自由度），但依然属于欠驱动系统。
举例子：人在空中跳跃时，不管怎么收缩、放松全身肌肉，都没法改变自己重心的飞行抛物线。
原因：重力完全主导重心轨迹，肌肉发力只能转动四肢，无法抵消重力带来的整体下落运动——存在无法靠肌肉控制的运动方向，依然满足欠驱动定义。

### 通用欠驱动判定补充（对应之前公式3）
矩阵$f_2$行数 = 总关节自由度$\dim(\boldsymbol{q})$，列数 = 电机数量$\dim(\boldsymbol{u})$；
最常见欠驱动场景：电机数量少于自由度 $\dim(\boldsymbol{u}) < \dim(\boldsymbol{q})$，此时$f_2$一定不是满秩矩阵，也就是电机没法覆盖全部运动方向。

# 第四部分：全文符号书写规范说明（基础规则，看懂所有课件）
1. $\boldsymbol{q}$：只用来代表物体/关节的位置、角度（姿态）；
2. $\dot{\boldsymbol{q}}$：代表运动速度；
3. 完整系统状态$\boldsymbol{x}=[\boldsymbol{q}^T,\dot{\boldsymbol{q}}^T]^T$：同时记录当下姿态+当下速度，想要预测下一秒摆锤怎么动，必须同时知道这两个信息；
4. 补充小局限：这套写法不能直接套用在三维空间旋转（比如无人机翻滚），三维角速度有特殊规则，附录会单独说明，但二维双摆、小车倒立摆完全够用；
5. 书写格式硬性规则：
   - 向量、矩阵全部加粗（$\boldsymbol{q},\boldsymbol{M},\boldsymbol{B}$）；普通单个数字不加粗（$t,g,l_1$）；
   - 所有向量默认竖着写（列向量），$^T$只是把横行文字改成竖列方便排版。

# 整体逻辑串联总结（普通人一次性理清整条线）
1. 所有硬杆机械结构（双摆、机械臂）受力都遵守一条统一动力学公式，拆分出惯性、拖拽、重力、电机四种力；
2. 把公式变形就能直接算出关节摆动加速度，区分“重力自带运动”和“电机可控运动”；
3. 电机数量等于关节数=完全驱动，随便操控每一根杆；电机更少=欠驱动，只能靠联动、重力间接控制；
4. 少一个电机的双摆，是模拟人走路最简单基础模型；哪怕驱动器数量多，只要存在无法控制的运动方向，依然是欠驱动；
