# 完整深度剖析双摆仿真曲线图（结合代码、动力学公式、图像逐点拆解）
## 前置统一铺垫（串联代码、公式、图表三者关系）
### 1. 先回顾代码里的核心设定（图表数据来源）
1. **仿真初始条件（代码关键行）**
```python
context.SetContinuousState([1.0, 1.0, 0.0, 0.0])
# 对应：[θ₁(0), θ₂(0), θ̇₁(0), θ̇₂(0)]
# t=0：肩膀角度θ₁=1rad，手肘相对角度θ₂=1rad；初始摆动速度全为0
```
2. **控制输入**
```python
diagram.get_input_port(0).FixValue(context, [0.0, 0.0])
# u=[τ₁,τ₂]=[0,0]，全程电机不输出任何扭力，纯自由摆动，只受重力、惯性、耦合拖拽力
```
3. **仿真时长**：`simulator.AdvanceTo(10.0)`，横轴`t`代表0~10秒仿真时间
4. **绘图逻辑**
   - 上半张子图：`shoulder` = 肩膀关节（θ₁ 位置、θ̇₁ 速度）
   - 下半张子图：`elbow` = 手肘关节（θ₂ 位置、θ̇₂ 速度）
   - 蓝色线`position`：角度 $\boldsymbol{q}=[\theta_1,\theta_2]^T$
   - 橙色线`velocity`：角速度 $\dot{\boldsymbol{q}}=[\dot{\theta}_1,\dot{\theta}_2]^T$
5. **底层动力学公式（图表所有波动的根源）**
$$\ddot{\boldsymbol{q}}=\underbrace{M^{-1}(\boldsymbol{q})\big[\tau_g(\boldsymbol{q}) - C(\boldsymbol{q},\dot{\boldsymbol{q}})\dot{\boldsymbol{q}}\big]}_{f_1} + \underbrace{M^{-1}B}_{f_2}\boldsymbol{u}$$
本案例 $\boldsymbol{u}=0$，公式简化为：
$$\ddot{\boldsymbol{q}} = M^{-1}(\boldsymbol{q})\big[\tau_g(\boldsymbol{q}) - C(\boldsymbol{q},\dot{\boldsymbol{q}})\dot{\boldsymbol{q}}\big]$$
> 所有曲线的起伏、快慢、极值，全部由「重力力矩$\tau_g$、耦合离心力$C\dot q$、惯性矩阵$M$」三者共同决定，没有电机外力干扰。

### 2. 看图基础常识（普通人秒懂坐标）
- **横轴 t**：时间，单位秒，0到10秒全程仿真
- **纵轴数值含义**
  蓝色position：关节角度（单位弧度，1rad≈57°），正数杆向右偏，负数向左偏；
  橙色velocity：关节转动速度（rad/s），正数=顺时针摆，负数=逆时针摆；
- 物理关联：速度橙色线是蓝色角度线的**变化快慢**，加速度是橙色线的变化快慢。

## 一、通用物理规律：蓝线位置、橙线速度的基础对应关系（两张子图全部适用）
先记住3条万能规律，后面分析全部基于这个逻辑：
1. **蓝线最高点/最低点（角度极值）→ 橙线速度=0**
   杆子摆到最左、最右，瞬间停住换向，摆动速度为0；
   对应公式：$\dot q=0$，此时没有离心拖拽力 $C\dot q=0$，加速度只由重力$\tau_g$提供。
2. **蓝线穿过0（杆子竖直对齐）→ 橙线速度达到峰值（最高/最低）**
   杆子经过垂直下垂位置时，重力全部转化为摆动动力，速度最快；
   对应公式：$\tau_g$此时力矩最大，加速度拉满，速度冲到极值。
3. **橙线速度从正变负/负变正 → 蓝线角度到达波峰/波谷**
   速度方向反转=摆动方向换向，角度不再增大，开始往回摆。

对照图表任意一处都能验证：
比如肩膀图t=1s：蓝线到达最低谷（角度最左），橙色速度刚好跌到最低谷0；
t=2s蓝线回到0，橙色速度冲到正向峰值，完全匹配规律。

## 二、上半图：肩膀关节（shoulder, θ₁, θ̇₁）深度分析
### 1. 初始时刻 t=0 对应代码初始值
- 蓝线position起点=1.0（θ₁=1rad，和代码`SetContinuousState`完全对应）；
- 橙线velocity起点=0（初始速度$\dot\theta_1=0$，代码设定初始静止）。
#### 物理公式解释t=0瞬间：
$\dot q=0$ → 耦合拖拽项$C\dot q=0$，加速度仅由重力决定：$\ddot q=M^{-1}\tau_g$。
初始两根杆都向右偏，重力向下拽重物，肩膀立刻获得向左摆动的负加速度，因此：
t>0后蓝色角度线快速下跌，橙色速度线立刻向下变负（逆时针向左摆）。

### 2. 曲线整体形态特征
1. **蓝色位置线（肩膀角度θ₁）**
   波动周期长、振幅衰减很慢：波形平缓，峰值稳定在±1.5rad左右，10秒内没有明显变小；
   原因：肩膀是整个双摆的根关节，整体总惯性$M(q)$很大，重力改变它的摆动幅度很难，能量损耗极小。
2. **橙色速度线（肩膀角速度θ̇₁）**
   振幅极大，最低接近-4、最高突破4，起伏剧烈；
   关键：肩膀的速度波动频率，和手肘完全不同——两根杆互相拉扯产生**耦合共振**（对应公式里的$C(q,\dot q)$耦合离心项）。

### 3. 耦合效应（核心，对应公式$C(q,\dot q)\dot q$）
公式中$C(q,\dot q)$是两根杆旋转互相拖拽的力，也是肩膀曲线不规律、不是完美正弦波的根本原因：
- 每当手肘高速摆动（下半图橙色速度峰值），手肘的离心拉扯力会通过$C$矩阵传递到肩膀；
- 肩膀原本平稳的摆动被手肘拽着加速/减速，因此橙色速度线会出现额外的尖刺、高低不平，不像单摆那种光滑对称曲线。
例：t=2s手肘速度冲到极大值，肩膀橙色速度同步出现一个陡峭高峰，就是手肘拖拽肩膀的直观图像证据。

### 4. 无电机输入u=0的直观体现
全程$\tau_1=0$，没有电机抵消重力和耦合力，肩膀只能被动被重力、手肘拉扯来回摆动，角度无法稳定在0（竖直平衡位置），蓝色线永远在正负区间来回震荡。
如果代码修改`FixValue([2,0])`给肩膀电机施加扭力，蓝色线会慢慢收敛到0，不再持续震荡。

## 三、下半图：手肘关节（elbow, θ₂, θ̇₂）深度分析
### 1. 初始时刻 t=0
蓝线起点=1.0（θ₂=1rad，代码初始条件匹配）；橙色速度起点=0，初始手肘静止。
初始两根杆同向右偏，重力让下端重物下坠，手肘立刻向内收拢，蓝色角度快速下跌。

### 2. 曲线核心特征（和肩膀形成鲜明对比）
1. **蓝色位置线（手肘角度θ₂）**
   波动频率远高于肩膀，振幅更小，峰值仅±1rad；
   手肘是末端关节，惯性更小，轻微的重力、拉扯力就能快速改变角度。
2. **橙色速度线（手肘角速度θ̇₂）**
   波动剧烈程度远超肩膀，最低接近-7、最高接近8，尖峰极多；
   末端摆杆质量集中在最外侧，旋转时离心力$C\dot q$极强，微小角度变化就能产生巨大角速度。

### 3. 耦合作用的极致体现（公式$C(q,\dot q)\dot q$可视化）
手肘的运动完全被肩膀的摆动强烈干扰：
肩膀每一次换向（t=1、3、5、7、9s），手肘的速度曲线都会同步出现剧烈尖峰；
物理本质：肩膀旋转时，会给手肘带来巨大的离心拖拽力$C\dot q$，直接改变手肘加速度$\ddot\theta_2$。
这就是双摆和两个独立单摆最大的区别：**耦合项C带来互相干扰，波形不再是规则正弦曲线**，图像上所有不对称、尖刺全部来自这个公式项。

### 4. 能量传递图像证据
t=0~2秒：初始两根杆都张开，重力势能最大，快速转化为摆动动能；
手肘橙色速度在t=2秒冲到全图最高点，代表此刻整个系统动能全部集中在手肘摆杆；
随后手肘动能传递回肩膀，手肘速度下降，肩膀速度抬升，能量在两根杆之间来回交换，对应两条子图橙线峰值交替出现。
公式层面：惯性矩阵$M(q)$耦合了两根杆的动能，能量可以在$\theta_1、\theta_2$之间互相转移。

## 四、结合代码完整闭环：图像每一步数据如何生成
1. **仿真计算层（plant物理引擎）**
   代码中`MultibodyPlant`自动求解动力学公式 $\ddot q = M^{-1}(\tau_g - C\dot q)$，每0.01秒计算一次当前$\theta_1,\theta_2,\dot\theta_1,\dot\theta_2$；
2. **数据存储层（logger记录仪）**
   `LogVectorOutput`持续把每个时间步的 [t,θ₁,θ₂,θ̇₁,θ̇₂] 存入内存数组；
3. **绘图提取层**
   ```python
   log.sample_times() # 提取全部横轴时间点0~10s
   log.data()[(i, i + 2), :] # i=0取肩膀θ₁、θ̇₁；i=1取手肘θ₂、θ̇₂
   plt.plot(时间, 角度数组) # 蓝色position线
   plt.plot(时间, 速度数组) # 橙色velocity线
   ```
   图像里每一个坐标点，都是plant解方程算出、logger记录、代码提取绘制的结果，曲线形状完全由动力学公式决定。

## 五、欠驱动/完全驱动视角看图拓展（对应前文B矩阵、满秩理论）
当前代码$\boldsymbol{u}=[0,0]$，是**完全驱动硬件结构（2电机）但电机输出为0**；我们可以对比两种修改代码后的图像变化：
1. 场景1：保持2电机，输入$\boldsymbol{u}=[-k\theta_1,-k\theta_2]$（反馈平衡控制，完全驱动正常使用）
   图像蓝色position线会快速收敛到0，震荡消失，两根杆竖直稳定，因为电机扭力$Bu$抵消了重力$\tau_g$和耦合力$C\dot q$，加速度$\ddot q$被人为控制归零。
2. 场景2：修改模型为欠驱动双摆（删除肩膀电机，$\boldsymbol{u}=[\tau_2]$，B=[0,1]^T）
   此时秩(B)=1<dim(q)=2，无法单独控制肩膀；即便给手肘施加控制扭力，肩膀蓝色角度线永远无法稳定，会持续大幅度无规则震荡，和本图自由摆动的混乱波形类似。

## 六、全局总结：图表、代码、公式三者统一逻辑
1. **公式是底层规则**：$M、C、\tau_g$三个项决定了加速度$\ddot q$，加速度持续改变速度$\dot q$，速度持续改变角度$q$；
2. **代码是计算载体**：pydrake的plant自动求解这套微分方程，logger记录全过程数据，matplotlib将数据绘制成曲线；
3. **图表是物理直观结果**
   - 蓝线位置：存储的$\boldsymbol{q}$角度数据，由速度积分得到；
   - 橙线速度：存储的$\dot{\boldsymbol{q}}$角速度数据，由加速度积分得到；
   - 曲线不规则、互相干扰、能量交替起伏，全部是耦合离心项$C(q,\dot q)\dot q$的可视化证据；
   - 全程无衰减自由震荡，因为$\boldsymbol{u}=0$无电机外力，只有重力、惯性内部能量交换；
4. 图像完美验证前文理论：双摆两个自由度互相耦合，不存在独立运动，不能拆成两个单独单摆分析，这也是欠驱动机器人、行走模型的核心物理特性。
