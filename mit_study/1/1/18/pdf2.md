## 1. 问题表述（18.1）—— 把"反推图纸"写成优化

### 1.1 一切从数据开始 + 方程误差 vs 仿真误差

> 我们的问题表述**不可避免地从数据开始**。实践中，如果我们能接触一个**用数字电子仪器装好的物理系统**，那么我们就有一个系统：**我们能以某个离散速率施加输入命令 $u_n$，并以某个离散速率测量输出 $y_n$**。我们通常假设这些速率固定，并试图拟合一个**状态空间模型**：

$$x[n+1]=f_\alpha(x[n],u[n]),\qquad y[n]=g_\alpha(x[n],u[n])$$

其中 $\alpha$ 是**参数向量**。在这个设定下，一个自然的表述是**最小二乘**：

$$\min_{\alpha,x[0]}\ \sum_{n=0}^{N-1}\|y[n]-y_n\|_2^2,\quad \text{subject to 上式}$$

**人话**：**我手里有一串"我推了什么 $u$、我看到了什么 $y$"的记录。我想找一组参数 $\alpha$ 和一个初始状态 $x[0]$，使得"我的模型跑出来的 $y$"和"我真实测到的 $y_n$"**尽量贴合**。**

> 我一开始写的是**纯确定性模型**，但一般地，**状态演化和测量都该有随机性**。有时我们像上面那样，**拟合一个确定性模型，靠最小二乘目标去"吸收"误差**；更一般地，我们会**拟合随机模型**。

**类比（拟合照片 vs 拟合视频，必懂）**：
- 我们常常把辨识**拆成两步**：**第一步**，从输入-输出数据**估计状态 $\hat x$**；**第二步**，专注**估计状态演化动力学**。
- 第二步的算法分**两大类**：

**① 方程误差（equation error）**——**只最小化"一步预测误差"**：

$$\min_\alpha\ \sum_{n=0}^{N-2}\|f_\alpha(\hat x_n,u_n)-\hat x_{n+1}\|_2^2$$

**② 仿真误差（simulation error）**——**捕捉"长期预测误差"**：

$$\min_\alpha\ \sum_{n=1}^{N-1}\|x[n]-\hat x_n\|_2^2,\quad \text{s.t.}\ x[n+1]=f_\alpha(x[n],u_n),\ x[0]=\hat x_0$$

**类比（逐帧对齐 vs 整段对齐，这是理解两者区别的钥匙，必懂）**：
- **方程误差** = **逐帧对齐**：我拿"模型从第 $n$ 帧**真实状态**出发、预测的第 $n+1$ 帧"，去和"真实的第 $n+1$ 帧"比。**每一步都从'真实起点'重新出发**——**像每拍一张照片，单独对齐**。
- **仿真误差** = **整段视频对齐**：我让模型**从第 0 帧自己一路跑到底**，**中间不纠正**，看"模型自己跑出来的整条轨迹"和"真实轨迹"差多少。
- **为什么方程误差"好算但危险"**？因为它**每一步都偷看了真实状态**，**把误差"清零重启"了**——**所以即使一步误差很小，长期累积起来，模型自己跑可能**漂到十万八千里外**。**这就是作者说的"优化一步误差，仍可能导致任意大的仿真误差"**。
- **所以**：**仿真误差才是我们真正想要的目标，方程误差只是一个"可能有用"的代理（surrogate）**。

**类比（学开车）**：方程误差 = **教练每秒钟把你扶回正确车道，再让你开下一秒**——**你每一步看起来都对，但没人扶时你可能直接撞墙**。仿真误差 = **教练一开始放手，让你自己开完全程，看你能不能不撞**——**这才是真本事**。

> 在这个"模型学习"框架里，我们会遇到**监督学习里所有关于"样本效率"和"泛化"的标准问题**。

### 1.2 在线优化 + regret（后悔值）

> 理论 ML 给这个老问题带来了**新视角**，**最相关的是"在线优化"的视角**。除了把表述换成"**流式在线数据**"（而非离线批量分析），这个领域还**重新流行起决策论里的一个老想法：用 regret 当辨识的损失函数**。

> 在 **regret 表述**里，我们**承认**：我们搜索的"参数化模型类"**很可能无法完美表示**输入-输出数据。**与其直接用"预测误差"给自己打分，不如用"相对于'我们模型类里最好的那组参数'会做出的预测"来打分**。

> 对方程误差表述，第 $N$ 步的 regret 形如：

$$R[N]=\sum_{n=0}^{N-2}\|f_\alpha(\hat x_n,u_n)-\hat x_{n+1}\|_2^2-\min_{\alpha^*}\sum_{n=0}^{N-2}\|f_{\alpha^*}(\hat x_n,u_n)-\hat x_{n+1}\|_2^2$$

**人话**：**regret = "我在线选的参数 $\alpha$ 累积的误差" − "事后诸葛亮（知道全部数据后，在我这个模型类里能选到的最好参数 $\alpha^*$）的累积误差"**。**目标 = 设计一个在线算法，每步选 $\alpha$，让 regret 趋于零**。

**类比（和"事后诸葛亮"比差距，必懂）**：
- 你不和"完美真理"比（**因为你的模型类可能根本表示不了真理**，比了也白比、永远输）。
- 你和"**在你能力范围内、事后能做到的最好**"比——**如果你在线学的速度，能逼近'事后诸葛亮'，那你就赢了**。
- **作者说**：**这个区别很重要**（**下面会看到**）——**因为它把"模型不够好"和"我学得不够好"分开了**，**让你能公平地评价"学习算法本身"**。

### 1.3 为控制学习模型：预测所有输出 ≠ 做对决策

>  finora 我们把问题**纯粹描述成"捕捉系统的输入-输出行为"**。但如果我们的目标是**用这个模型做控制**，那这**可能不太对**，原因有好几个。

**第一，预测观测可能"超额"了。**
> 预测观测**可能超出了"做最优决策"的需要**；[4] 把这个故事讲得很好。想象你要** swing-up 并平衡一个 cart-pole，唯一的传感器是相机**。**背景图像是无关的**；我们知道**只有 cart-pole 的状态才重要**。**如果背景屏幕上在放电影，你不会想把模型的全部表示能力，都花在"预测电影的下一帧"上，而代价是"预测不好 cart-pole 的下一个状态"**。这些挑战催生了一个活跃的领域——**学习任务相关模型/表示**；我会在讲完基础后，专门用一节讲它。

**类比（学开车不需要预测广告牌，必懂）**：你学车时，**眼睛要盯路、盯车**，**不需要把路边每块广告牌的内容都记下来**。**如果你的"视觉模型"花 90% 算力去预测广告牌下一帧怎么变，那它就是个"烂驾驶模型"**——**尽管它"预测像素"预测得很好**。**这就是"预测得好 ≠ 对控制有用"**。

**第二，模型要"可观、可控"。**
> 还有其他考量。要让模型**对控制有用**，我们需要模型的**状态是可观的**（能从在线观测推出来）**且可控的**。

**第三，模型复杂度有 trade-off。**
> 模型复杂度也有 trade-off。**如果只学一个线性模型**，那我们有**非常强的控制设计工具**，**但可能捕捉不到世界的丰富动力学**。**如果模型太复杂**，那我们的**在线规划和控制技术可能成为瓶颈**。[5] 把这个点讲得很好。**截至写作时，我认为公允的说法是：深度学习模型能描述极其丰富的动力学，但我们"用这些模型做决策"的控制工具，仍然弱得可怜。**

**人话（这是全章最清醒的一句话，必懂）**：**"模型能拟合得多好"和"模型能用来控制得多好"是两回事**——**一个能完美预测像素的神经网络，可能让你**完全没法做规划**（因为规划器在它上面跑不动/找不到结构）。**所以辨识的目标，不该是"拟合得最准"，而该是"拟合得'对控制最有用'"**——**这正是 18.8 任务相关模型的主题**。

## 2. 机械系统的参数辨识（18.2）—— "已知结构，只填数字"

> 本书主要聚焦（欠驱动）机械系统，但辨识时**有一个重要区分**。**对某些机械系统，我们知道模型的结构**——**包括状态变量个数、运动学树的拓扑**。**Spot、Atlas 这类腿式机器人就是好例子**——**动力学当然不简单，但方程的'一般形式'是已知的**。这时，辨识的任务**其实就是"估计一个结构化模型里的参数"**。**这是本节的主题**。

> 而**叠衣服、做沙拉**这类例子**属于另一类**——**我可能事先连"需要多少个状态变量"都不知道**。这会逼我们做**更一般的辨识考察**，**剩下的章节会探索**。

**类比（填空 vs 白纸，必懂）**：
- **本节** = **填空题**：试卷（方程结构）印好了，**你只填括号里的数字**（质量、杆长、摩擦系数）。
- **后面** = **白纸作文**：连"有几道题"都不知道，**你得自己猜结构**。
- **显然填空题好做**——**所以本节先攻它**。

### 2.1 运动学参数与标定（先拿卷尺，再谈优化）

> 我们可以把机械臂方程里的参数**再分成"运动学参数"和"动力学参数"**。**运动学参数**（如杆长）描述**运动学树里"从一个关节到另一个关节"的坐标变换**。**当然可以写一个优化去标定这些参数**；[6] 第 11 章有相当彻底的讨论。

> **但我个人的看法是**：**如果你连杆长都估不准，那你大概该先投资一把卷尺，再投资非线性优化。** 😄

**类比（作者的金句，必懂）**：**"能量化就别瞎优化"**——**杆长拿尺子量就行，别搞个非线性优化去"拟合杆长"，那是杀鸡用牛刀，还可能杀歪**。

> **一个显著的例外 = 关节偏移（joint offset）的标定**。这个在实践中**真是个麻烦**。关节传感器会**打滑**，有些机器人甚至用**相对旋转编码器**，**每次上电都要把关节驱动到某个已知的硬限位，才能得到偏移**。我做过一个高级机器人，它有一套**相当繁琐痛苦的标定流程**——**要在关节上套额外硬件、确保它们在已知位置，再跑脚本**。**一个昂贵/不可靠的标定流程，能给任何机器人项目泼冷水**。

#### Example 18.1（带标定误差的 Acrobot 平衡）

> **小的运动学标定误差，在试图稳定 Acrobot 这类系统时，会导致大的稳态误差**。我做了个简单 notebook 展示这个效应。

> 我们用**鲁棒/随机控制**的工具，**很适合辨识（并界定/最小化）这些敏感度**——**至少对我们 LQR 里用的线性化模型如此**。

**人话**：**你以为杆偏了 1 毫米没事，结果 LQR 平衡时，机器人永远歪着 5 度停不下来**——**因为控制器"以为"杆是直的，按错的模型使劲，使出一个恒定的偏差**。**这就是"标定误差 → 稳态误差"的链条**。

> **从数据估计关节偏移的一般方法** = **把方程写成"关节偏移是参数"的形式**。比如双摆，前向运动学写成：

$$p_1=l_1\begin{bmatrix}\sin(\theta_1+\bar\theta_1)\\ -\cos(\theta_1+\bar\theta_1)\end{bmatrix},\quad p_2=p_1+l_2\begin{bmatrix}\sin(\theta_1+\bar\theta_1+\theta_2+\bar\theta_2)\\ -\cos(\theta_1+\bar\theta_1+\theta_2+\bar\theta_2)\end{bmatrix}$$

其中 $\bar\theta$ 是**偏移**。我们**设法独立测量末端执行器位置**（动捕、机载相机、机械标定架），**配上对应的关节读数**，得到形如 $\langle p_2,\theta_1,\theta_2\rangle$ 的数据点。**然后解一个小非线性优化，最小二乘估偏移**。

> 如果**没有独立的运动学测量**，**也可以把偏移和动力学参数一起估**——**用三角恒等式**，如 $\sin(\theta+\bar\theta)=\sin\theta\cos\bar\theta+\cos\theta\sin\bar\theta$，**然后把 $\sin\bar\theta,\cos\bar\theta$ 这些项，单独并进下面要讲的"lumped parameters"里**。

**人话**：**偏移 $\bar\theta$ 藏在 $\sin(\theta+\bar\theta)$ 里，看着非线性、难估**——**但用三角公式一展开，$\bar\theta$ 就变成"$\sin\theta$ 和 $\cos\theta$ 前面的两个常数系数"（$\cos\bar\theta,\sin\bar\theta$）**——**又变回"线性参数"了**！**这就是"把非线性藏进线性系数"的 trick**，**和下面 lumped parameters 是同一招**。

### 2.2 估计惯性参数（和摩擦）—— 本章第一个"硬核高潮"

> 现在想**估计机械臂系统的惯性参数**。我们一直把机械臂方程写成：

$$M(q)\ddot q+C(q,\dot q)\dot q=\tau_g(q)+Bu+\text{friction 等}$$

**方程里每一项都可能依赖我们要估的参数 $\alpha$**。但**参数进入机械臂方程的方式很特殊**：**逆动力学方程对惯性参数是仿射的**。**注意**：**正动力学（解 $\ddot q$）涉及一个 $M^{-1}(q)$**；**这些动力学对参数不仿射**。**那些把机械臂动力学当成 $x[n+1]=f(x[n],u[n])$ 的通用辨识方法，不会直接利用这个凸性**。

**人话（这是本节最关键的洞察，必懂，反复体会）**：
- **逆动力学** = **已知"怎么动"（$q,\dot q,\ddot q$）和"外力"，求"需要多少力矩 $\tau$"**。
- **正动力学** = **已知"力矩 $\tau$"，求"会怎么动"（$\ddot q$）**——**这要解 $M^{-1}$**。
- **关键**：**逆动力学对惯性参数是"线性的"（仿射）**——**质量翻倍，所需力矩也线性地变**。**但正动力学因为要除 $M$，对参数是"非线性"的**。
- **所以**：**用逆动力学做辨识 = 解一个线性回归（凸、好算、有全套统计理论）**；**用正动力学做辨识 = 解一个非线性回归（难、可能卡局部极小）**。**这就是为什么"机械系统辨识"偏爱逆动力学**。

**类比（称重量 vs 猜重量，必懂）**：
- **逆动力学** = **你把东西放天平上，已知"加速度"，读"力"**——**读数和重量成线性关系**，**像天平刻度均匀**。
- **正动力学** = **你已知"力"，要猜"加速度"**——**但加速度 = 力 ÷ 重量，是个除法**，**刻度不均匀**，**难反推**。

#### 惯性参数的"自然参数化"：密度加权矩矩阵

> 为了用逆动力学表述，先**选一个惯性的参数化**。**[8] 表明**：**对一个刚体，惯性项的"自然参数化"**，是用**密度加权矩矩阵**：

$$m_B=\iiint_{V_B}\rho(x)\,dV\in\mathbb{R},\quad h_B=\iiint_{V_B}x\,\rho(x)\,dV\in\mathbb{R}^3,\quad \Sigma_B=\iiint_{V_B}xx^T\rho(x)\,dV\in S^3$$

其中 $V_B$ 是刚体几何的体积，积分是 3D 体积分，$S^3$ 是 3×3 实对称矩阵群。

**人话（这三个量是什么，必懂）**：
- **$m_B$** = **总质量**（密度在体积上积分）。
- **$h_B$** = **"质量 × 质心位置"**（密度加权的位置积分）——**所以质心 $p_{com}=\frac{1}{m}h$**。
- **$\Sigma_B$** = **"二阶矩矩阵"**（密度加权的 $xx^T$ 积分）——**它和"标准惯性张量 $I$"的关系是**：

$$I_{B/B_o}=\operatorname{tr}(\Sigma_B)I_{3\times3}-\Sigma_B$$

> **因为 $\Sigma_B$ 对称**，我们可以**用 10 个实数**概括刚体 $B$ 的所有惯性参数：

$$\alpha_B=\begin{bmatrix}m_B,\ h_B^T,\ \operatorname{vec}_{sym}(\Sigma_B)\end{bmatrix}^T\in\mathbb{R}^{10}$$

其中 $\operatorname{vec}_{sym}$ 把 3×3 对称矩阵的 6 个上三角元素拉成向量。**自然，如果要同时估多个刚体，就把它们拼成一个大参数向量 $\alpha$**。

**类比（10 个数 = 一个刚体的"体重档案"，必懂）**：**一个刚体的惯性，被这 10 个数完全刻画**——**1 个总重 + 3 个"质量×质心" + 6 个"二阶矩"**。**这 10 个数就是你要从数据里"称"出来的东西**。

#### 逆动力学对这 10 个数是仿射的！

> **惊人地，逆动力学对这些参数是仿射的**。这意味着上面的机械臂方程**可以重构成**：

$$W(q_n,\dot q_n,\ddot q_n,u_n)\,\alpha_B+w_0(q_n,\dot q_n,\ddot q_n,u_n)=0$$

> 我们有时把 $W$ 称为"**数据矩阵（data matrix）**"——**它是把上面这个方程在所有时间样本上竖直堆叠起来得到的**。给定**位置轨迹 + 力矩测量**的数据，我们可以**用（非因果）滤波**估出 $\dot q,\ddot q$。**然后就能用最小二乘估参数**。

**人话（这就是"线性回归"的形态，必懂）**：
- **$W$** = **设计矩阵**（**每一行 = 一个时刻，由该时刻的 $q,\dot q,\ddot q,u$ 算出来的已知系数**）。
- **$\alpha_B$** = **未知参数**（**线性地出现在方程里**）。
- **$w_0$** = **已知的"偏置项"**。
- **方程 $W\alpha+w_0=0$** = **一个标准的线性方程组** → **最小二乘解 $\alpha=-\text{pinv}(W)w_0$**。
- **于是**：**所有线性估计的强结果和变体都能用上**——**加正则项**（让估计别偏离先验太远）、**用递归最小二乘做在线最优估计**。**我最爱的递归最小二乘，用增量 QR 分解** [9]。

**类比（这就是"多元线性回归"，必懂）**：**$W\alpha=-w_0$ 和你用 Excel 做"多元回归"是同一回事**——**$W$ 是自变量矩阵，$\alpha$ 是回归系数，$-w_0$ 是因变量**。**只不过这里的"自变量"是由物理方程算出来的特定组合**。

#### 物理有效性约束：伪惯性必须正定

> **不是所有 $\alpha$ 值都对应"物理上有效的惯性"**。比如我们知道 $m$ 必须为正。**惯性矩阵本身也有约束**。**[8] 表明，这些约束恰好等价于"伪惯性（pseudo-inertia）正定"**：

$$J(\alpha_B):=\begin{bmatrix}\Sigma_B & h_B\\ h_B^T & m_B\end{bmatrix}\succ 0$$

**人话**：**把 $\Sigma,h,m$ 拼成一个 4×4 矩阵 $J$，要求它正定**——**这一个约束，就把"质量正、惯性张量正定、质心合理"等所有物理要求，打包成了一条凸约束**。**这就是为什么"带物理约束的惯性辨识"能写成 SDP（半正定规划）**。

> 如果**知道刚体的几何 $B$**，还可以**额外加凸约束**。比如**质心必须在几何的凸包内**：

$$p_{com}\in\operatorname{conv}(V_B)\ \Rightarrow\ h_B\in m_B\operatorname{conv}(V_B)$$

**人话**：**质心不可能跑到零件外面**——**这又是一个凸约束**（**"凸集的非负缩放"仍是凸集，叫 perspective**）。**[8] 还给了基于"包含已知几何的最小体积 Loewner-John 椭球"的二阶矩凸约束**。

#### 这些约束有用吗？不可辨识参数的坑

> **这些额外约束重要吗**？**在数据无穷的极限下**，你也许希望最小二乘**不用约束也能估对**。**但有两个"绊脚石"**。**第一，我们常常想在"数据较少"的 regime 下工作**。**第二，更重要的是**：**不是所有惯性参数都可辨识**。

> 比如想象一个**机械臂用螺栓固定在桌上，第一个连杆是绕 $z$ 轴旋转**。**那么无论你从这个机器人收集多少数据，都得不到"第一个连杆绕 $x,y$ 轴的转动惯量"的任何信息**。**天真地把这些参数塞进估计问题，不仅会让不可辨识参数估得很烂，甚至会让"惯性参数的物理有效性约束"变得空洞（vacuous）**。

**类比（蒙眼摸象摸不到的部分，必懂）**：
- 你**蒙着眼摸一头大象**，**只摸到了它的腿**——**你永远摸不出它鼻子的形状**。
- 机械臂**只绕 $z$ 转**，**那"绕 $x,y$ 的惯性"就像"象鼻子"**——**数据里根本没有它的信息**。
- **如果你硬要估象鼻子，你估出来的就是"瞎猜"，而且这个瞎猜还会把"物理约束"搞乱**（**因为约束本该限制象鼻子，但你对鼻子的猜测是任意的，约束就形同虚设**）。

**两种处理不可辨识参数的方法**：
1. **把它们从优化里排除**。**有算法能符号地提取"可辨识参数"**，但**更常见（可能也一样有效）的做法** = **直接算"足够丰富的数据矩阵 $W$ 的零空间"**，**用 QR 分解找不可辨识参数**：

$$W=\begin{bmatrix}Q_1\\ 0\end{bmatrix}\begin{bmatrix}R_1 & 0\end{bmatrix}\ \Rightarrow\ W\alpha_B=Q_1(R_1\alpha_B)=Q_1\bar\alpha_B$$

其中 $\bar\alpha_B$ 是**可辨识参数**。**要实现物理有效性约束，得用"不可辨识参数的估计值"**。

2. **或者，直接对全部参数做优化，加一个正则项**——**让它" ideally 在主目标的零空间里操作"，把不可辨识参数往先验估计推**。**[10] 彻底处理了这个方法，并给了一个凸的、几何一致的正则器，叫"熵散度（entropic divergence）"**。

**人话**：**方法 1 = "承认摸不到鼻子，干脆不估鼻子，只估摸得到的部分"**；**方法 2 = "还是估鼻子，但加一条'鼻子别偏离我猜的样子太远'的规矩，而且这条规矩只在'摸不到的方向'上生效"**。

#### 还能顺便估别的：反射惯量、摩擦、阻尼

> 最小二乘逆动力学表述，**还能同时拟合一批"线性进入方程"的其他动力学参数**：**反射惯量**（对角矩阵 × $\ddot q$）、**关节摩擦**（常数力矩 × $\operatorname{sign}(\dot q)$）、**阻尼**（$\dot q$ 的线性倍数）。

> **提一个关于数值缩放的微妙点**：最小二乘逆动力学表述里的**所有方程，单位都是力矩**。但**机械臂基座连杆用的力矩，可能比末端关节的力矩大得多**。**[10] 的处理** = **先解一次无约束最小二乘，再把这个解的"误差协方差"带进约束最小二乘的目标**——**这让最小二乘目标"坐标无关"**。

#### Example 18.2（Kuka iiwa 的惯性辨识）

> **解这里描述的、带凸（半正定）约束的最小二乘优化，需要解小 SDP**。有一些不错的工作，**用参数化导出"无约束、光滑、但非凸"的优化问题，能用梯度下降解** [11]。**某些情况下，仍能保证所有局部极小都是全局极小**。

> **但我和作者们聊下来的印象是**：**SDP 表述的数值表现可能明显更好，如果有 SDP 求解器，应该优先用它**。

### 2.3 通过 lumped parameters 同时做运动学和惯性辨识

> **虽然强烈建议把运动学和惯性估计分开**，但**需要时也能做一定程度的联合估计**。我们知道逆动力学对惯性参数仿射。**但原来它也能写成对"lumped parameters（集总参数）"仿射**——**lumped parameters = 惯性和运动学的"非线性组合"，但这些组合不依赖数据**。我觉得**用几个简单例子解释最清楚**。

#### Example 18.3（单摆的 lumped parameters）

> 熟悉的单摆运动方程：

$$ml^2\ddot\theta+b\dot\theta+mgl\sin\theta=\tau$$

**为了参数估计，我们把它因式分解成**：

$$\begin{bmatrix}\ddot\theta & \dot\theta & \sin\theta\end{bmatrix}\begin{bmatrix}ml^2\\ b\\ mgl\end{bmatrix}-\tau=0$$

> **$ml^2,\ b,\ mgl$ 这三个量，合起来就是"lumped parameters"**。

**人话（lumped parameters 的精髓，必懂）**：
- 你**永远估不出 $m$ 和 $l$ 各自是多少**——**因为方程里它们总是以 $ml^2$ 和 $mgl$ 的"乘积组合"出现**。
- **你能估出的，是这三个"组合"**——**$ml^2$（一个数）、$b$（一个数）、$mgl$（一个数）**。
- **这就是 lumped parameters**：**数据能告诉你的，不是"每个原始参数"，而是"这些参数的特定组合"**。

> **值得停下来反思这个因式分解**。首先，它**确实代表了机械臂方程的一个有点特殊的性质**：**非线性只以特定方式进入**。比如**如果方程里有 $\sin(m\theta)$ 这种项**，我就**没法**做出"把 $m$ 和 $\theta$ 分开的仿射分解"。**幸好，我们的机械系统不会这样** [6]。**再次强调，这个结构只对"我们这里写的逆动力学"成立**。**如果你写正动力学，乘 $M^{-1}$ 去解 $\ddot q$，那就又破坏了这个仿射结构**。

#### Example 18.4（Drake 里的机械臂参数）

> **极少有机器人仿真器，能让你访问动力学的参数**。**在 Drake 里，我们把机械臂系统的所有参数，显式声明在一个单独的数据结构里**，**让它们可用**，**并能用 Drake 的符号引擎，对这些变量提取和操纵方程**。

> 举个简单例子：我从 URDF 加载 cart-pole 模型，建一个符号版 MultibodyPlant，用符号变量填充 Context。**然后求（逆）动力学，得到方程**。输出长这样：

```
Symbolic dynamics:
(0.1*v(0) - u(0) + (pow(v(1),2)*mp*l*sin(q(1))) + (vd(0)*mc)
(0.1*v(1) - (vd(0)*mp*l*cos(q(1))) + (vd(1)*mp*pow(l,2)) + ...
```

> **去和手推的 cart-pole 方程比一比**。Drake 提供一个方法 `DecomposeLumpedParameters`，**会把这个表达式因式分解成上面的仿射形式**。对这个 cart-pole 例子，它提取出 lumped parameters：

$$[mc+mp,\ mpl,\ mpl^2]$$

**人话**：**Drake 自动帮你做"把方程整理成 $W\alpha=w_0$"的活**——**你给它符号方程，它吐出 lumped parameters 和数据矩阵的结构**。

> **lumped-parameter 分解的存在，揭示了**：**用 lumped-parameter 估计的方程误差（误差取在力矩坐标），又能用最小二乘解**。**重要的是，因为我们把它化成了最小二乘，我们也能理解"它什么时候不 work"**。**再次，不是所有 lumped parameters 都可辨识**，**所以我们通常需要第二步，对"可辨识的 lumped parameters"操作，或加正则项**。

#### Example 18.5（Cart-Pole 的参数估计）

> 从 URDF 提取 lumped parameters 后，**就能把它做成了**。我让例子保持简单：**用简单正弦波输入，仿真 cart-pole 几秒，构造数据矩阵，做最小二乘拟合**。输出：

```
Estimated Lumped Parameters:
(mc+mp).     URDF: 11.0,    Estimated: 10.905...
(mp*l).      URDF: 0.5,     Estimated: 0.594...
(mp*pow(l,2)). URDF: 0.25,  Estimated: 0.302...
```

> **注意，用更多数据（或更精心选的数据），拟合能更准**。

> **只估出（可辨识的）lumped parameters，我们该满意吗？我们追的不是"真正的原始参数"吗**？**数据矩阵的线性代数分解（假设用在足够丰富的数据上），其实在揭示我们系统动力学的一个根本事实**。**与其因为"估不准某些参数"而失望，我们该拥抱"我们根本不需要估那些参数"——**因为**我们对方程做的任何动力学推理（仿真、验证、控制设计），都不需要它们**。**可辨识的 lumped parameters，恰恰就是"我们需要的那部分 lumped parameters 的子集"**。

**人话（这是本节最通透的一句话，必懂）**：**"估不出 $m$ 和 $l$ 各自"不是 bug，是 feature**——**因为控制、仿真、验证，只需要 $ml^2$ 这个组合，不需要 $m,l$ 分开**。**数据告诉你"哪些组合是必要的"，你就只估那些**——**多估的，纯属浪费，还可能引入噪声**。

### 2.4 用能量而非逆动力学做辨识

> 除了用线性代数的工具，**还有不少"利用力学理解"的精修**。**一个重要例子 = 参数估计的"能量表述"** [12]。

> 我们已经观察到：**在力矩空间（逆动力学）评估方程误差，可能比在状态空间（正动力学）好**——**因为能避免求 $M^{-1}$，并保持对 lumped parameters 线性**。**系统的总能量（动能+势能）也对 lumped parameters 仿射**。我们可以用关系：

$$\dot E(q,\dot q,\ddot q)=\dot q^T(Bu+\text{friction},\dots)$$

> **为什么可能更想用能量坐标，而非力矩**？**差别在数值细节**。**在力矩表述里，我们直接用了 $\ddot q$**。**常识是**：**关节传感器能可靠报告位置和速度，但关节加速度——常常靠数值微分两次得到——往往噪声大得多**。**某些情况下，对"系统总能量"做有限差分，可能比对"单个关节"做，数值上更好**。**[13] 研究了各种滤波表述，导致 [12] 推荐"能量表述往往数值更优"**。**这个区别在"在线参数估计"里可能更重要**——**因为滤波器必须因果**；**而离线估计能用非因果滤波器**。

**类比（一次微分 vs 两次微分，必懂）**：
- **力矩法**要用 $\ddot q$ = **对位置微分两次**——**每微分一次，噪声放大一次**，**两次下来噪声可能比信号还大**。
- **能量法**用 $\dot E$ = **对能量微分一次**——**少微分一次，噪声小一截**。
- **所以能量法"数值上更干净"**——**代价是公式稍微绕一点**。

### 2.5 带线性函数近似器的残差物理模型

> "**残差物理（residual physics）**"这个词近年很火（如 [14]）——**大家想找办法，把深度神经网络的建模能力，和我们最好的力学工具结合**。**但其实这个想法很老**，**而且有一类自然的残差模型，能非常漂亮地嵌进我们的最小二乘 lumped-parameter 估计**。具体地，我们可以考虑这种模型：

$$M(q)\ddot q+C(q,\dot q)\dot q=\tau_g(q)+\alpha_r\Phi(q,\dot q)+Bu+\text{friction 等}$$

其中 $\alpha_r$ 是**残差的额外参数**，$\Phi$ 是**一组（固定的）非线性基函数**。**希望**：**这些残差模型能捕捉动力学里"可预测、但我们没放进原始参数模型"的" sloppy 项"**。**非线性摩擦、空气阻力，是常被引用的例子**。

**人话**：**先用物理方程建个"主干模型"，再用"$\alpha_r\Phi$"去补"主干没覆盖的小尾巴"**——**$\Phi$ 是一组你挑的基函数（如径向基、小波），$\alpha_r$ 是它们的系数，照样线性回归**。

> 机械臂方程常用的基函数 $\Phi$ 包括**径向基函数** [15] 或**小波** [16]。**虽然让基函数依赖 $\ddot q$ 或 $u$ 也行**，但我们**通常限制它们只依赖 $q,\dot q$**——**以保持机械臂方程的其他好性质**（如 control-affine）。

> 由于最小二乘很成熟，**也能用最小二乘"有效地挑出一组能描述你系统动力学的基函数子集"**。比如 [17]，我们对**一大批物理启发的基函数**做最小二乘，**为栖停时的 post-stall 气动做更好的 ODE 近似**，**最终只留下最能描述数据的少数几个基函数**。

> 如今，我们能用 **LASSO**（带 $\ell_1$ 正则的最小二乘回归），或 [18] 用的**基于"序贯阈值最小二乘"的替代方法**。

**类比（先搭骨架，再补细节，必懂）**：**物理方程 = 骨架；残差基函数 = 肌肉和皮肤**。**你先用骨架保证"大方向对、结构对"，再用基函数去拟合"骨架没考虑的细枝末节"（摩擦、阻力）**。**LASSO/序贯阈值 = "自动挑出'真正有用的几块肌肉'，把没用的剔除"**。

### 2.6 实验设计 = 轨迹优化（让数据"信息量最大"）

> 关于"参数估计算法能恢复真可辨识 lumped parameters"的任何声明，**都有一个关键假设**：**数据集"足够丰富"**；**轨迹"参数激励（parametrically exciting）"充分**。**基本上，我们需要假设**：**轨迹产生的运动，使得数据矩阵 $W$ 包含"所有可辨识 lumped parameters"的信息**。**多亏了线性参数化，我们能通过对 $W$ 做数值线性代数来评估这点**。

> 而且，**如果我们有机会改变"机器人在收集辨识数据时执行的轨迹"**，那我们就能**设计轨迹，去"最大程度激励参数"，产生数值上良态的最小二乘问题**。**一个自然选择 = 最小化数据矩阵 $W$ 的条件数**。**条件数 = 最大奇异值 ÷ 最小奇异值 $\sigma_{\max}(W)/\sigma_{\min}(W)$**。**条件数按定义总 ≥ 1，越小越好**。**数据矩阵的条件数，是"整条轨迹数据"的非线性函数，但仍能在非线性轨迹优化里优化**（[6] §12.3.4）。

**类比（怎么"问"才能问出最多信息，必懂）**：
- 你想摸清一头大象的重量分布，**你不能只摸它的腿**（**那样 $W$ 的某些列全是 0，条件数爆表，估不出**）。
- 你得**设计"摸的动作"**——**让大象做各种姿势，把每个方向的惯性都"暴露"出来**。
- **条件数小 = "你问的问题'信息互补、不冗余'"**；**条件数大 = "你问的问题'都差不多，缺了某个方向'"**。
- **所以"收集数据的轨迹"本身，就是一个优化变量**——**优化它，让 $W$ 的条件数最小**。**这就是"实验设计 = 轨迹优化"**。

### 2.7 在线估计与自适应控制

> 自适应控制是个**巨大丰富的文献**；很多书专门写它（如 [19]）。我在这里快速引用几处。

> finora 我主要把参数估计当**离线过程**讨论，但**自适应控制的一个重要方法** = **在控制器执行时，在线估计参数**。由于我们的估计目标**可以对（lumped）参数线性**，**这常常归结为递归最小二乘估计**。要正确分析这种系统，我们可以**把它想成"增广状态空间"**，**联合研究"状态 + 参数"演化的闭环动力学**。**机械臂自适应控制里最强的一些结果，局限于全驱动机械臂**；但比如 [20] 给了一个**用本书开发的许多工具，分析欠驱动系统自适应控制器**的好例子。

> 正如我所说，自适应控制是个丰富的主题。**但该领域最大的教训之一** = **你可能不需要"收敛到真（lumped）参数"，也能完成任务**。**自适应控制的许多经典结果，对"任务执行"做保证，但明确不要求/不保证"参数收敛"**。

**类比（不必知道真相，也能把活干好，必懂）**：
- 你**不必精确知道大象鼻子多重**，**也能学会"怎么扶住大象不让它倒"**。
- 自适应控制 = **"边干边调参数，参数可能永远没调到'真值'，但'扶大象'这个任务已经做对了"**。
- **这是自适应控制的"反直觉智慧"**：**参数收敛 ≠ 任务成功；任务成功也不需要参数收敛**。

### 2.8 带接触的辨识

> **同样的技术，能用到"和环境做/断接触"的走路机器人上吗**？

> **确实有一个版本能立刻 work**：**如果我们知道接触雅可比、且有接触力的测量**，那我们**能把这些项直接加进机械臂方程**，**继续用最小二乘估 lumped parameters**——**甚至包括摩擦参数**。

> 也能研究**接触力不直接测量**的情况。比如 [21] 研究了**一个被动物体"有/没有显式接触力测量"时，惯性参数的可辨识性**这个极端情况。

**人话**：**接触 = 额外的"未知力"**——**如果你能测到这个力（力传感器），它就变成"已知的输入"，照样塞进 $W\alpha=w_0$**；**如果测不到，那就更难，但 [21] 研究了"到底还能不能辨识"**。

## 3. 辨识（时域）线性动力系统（18.3）—— 第二根支柱

> 如果"机械臂参数估计"是系统辨识已确立工作的**第一根支柱**，那么**线性系统的辨识就是第二根**。**线性模型自该领域建立以来，就是系统辨识的主要焦点**，**并在最近几年因 ML 的新结果而复兴**——**尤其在有限样本 regime 上贡献了新的界和收敛结果**（如 [22, 23, 24, 25]）。

> 线性系统辨识文献的**很大一部分**（如 [26]）聚焦**频域**辨识。**确实，传递函数实现提供了重要洞察，并避免了"状态空间实现"要面对的一些陷阱**。**但本章我聚焦时域描述**——**这里的某些教训更容易推广到非线性动力学**（**而且我们 unfortunately 还没在本书里建好频域技术的基础**）。

### 3.1 从状态观测（最简单的情况）

> 先从**简单情况**开始：**用"直接（可能带噪）的状态测量"拟合线性模型**。拟合离散模型 $x[n+1]=Ax[n]+Bu[n]+w[n]$ 到采样数据，**用方程误差目标，就是又一个线性最小二乘问题**。

> 通常我们**构造数据矩阵**，把最小二乘写成：

$$X'\approx\begin{bmatrix}A & B\end{bmatrix}\begin{bmatrix}X\\ U\end{bmatrix},\quad \text{其中}\ X=\begin{bmatrix}| & | & & |\\ x_0 & x_1 & \cdots & x_{N-2}\\ | & | & & |\end{bmatrix},\ X'=\begin{bmatrix}| & | & & |\\ x_1 & x_2 & \cdots & x_{N-1}\\ | & | & & |\end{bmatrix},\ U=\begin{bmatrix}| & | & & |\\ u_0 & u_1 & \cdots & u_{N-1}\\ | & | & & |\end{bmatrix}$$

> 由线性最小二乘的优点，**这个估计器对"不相关的过程/测量噪声"是无偏的**。

#### Example 18.6（用辨识模型平衡 Cart-Pole）

> 我提供了一个 notebook，演示**线性辨识的一个实际应用**，分几步。**首先**，我设计了一个 LQR 平衡控制器，**但用了 cart-pole 的错误参数**（我改了质量等）。**这个 LQR 能让 cart-pole 不倒，但不能漂亮地收敛到直立**。**我想问**：**我能用这个实验产生的数据，辨识一个"平衡点附近更好的线性模型"，并改进我的 LQR 吗**？

> **有趣的是，简单答案是"不能"**。**如果你只收集"跑这个控制器"的输入和状态数据，你会看到我们上面表述的最小二乘问题是"秩亏的"**。**估出的 $A,B$ 矩阵（记作 $\hat A,\hat B$）能描述数据，但不揭示真正的线性化**。**如果你基于这些估计设计控制器，你会失望**！

> **幸好，我们能通过"检查最小二乘解的秩"预见这个问题**。**生成更多样本也救不了**。**相反，要生成更丰富的数据集，我给输入加了一个小额外信号**：$u(t)=\pi_{lqr}(x(t))+0.1\sin(t)$。**这就 make all the difference**。

**人话（这是"实验设计"在辨识里的活教材，必懂）**：
- **LQR 把 cart-pole 稳稳控制在直立附近**——**太好了，以至于"状态几乎不动、输入几乎不变"**。
- 结果**数据矩阵 $W$ 的列"几乎线性相关"**（**因为系统没怎么被"激励"**）→ **秩亏** → **估出的 $A,B$ 是"能拟合这点死数据的无数组解之一"，但不是真模型**。
- **解法** = **往输入里"抖一点"（$0.1\sin t$）**——**逼系统动起来，把各个方向的动力学"暴露"出来**——**$W$ 满秩了，估计就对了**。
- **这就是 2.6 "实验设计"的线性版**：**"数据太乖 = 没信息"，你得"主动扰动"才能学到东西**。**这也呼应了 RL 里"探索"的必要性**。

#### 基于模型的迭代学习控制（ILC）

#### Example 18.7（水动力 Cart-Pole）

> 我最爱的"基于模型 ILC"例子之一，是一系列实验——**我们探索了"水动力 cart-pole"系统的动力学**。**把它想成"经典 cart-pole 和战斗机的杂交"**（**也许更接近 cart-pole 一点**）！

> 这里我们**把摆杆换成翼型（水翼），把整个系统侧过来，扔进水洞**。**任务不是"对抗重力 swing-up 平衡摆杆"，而是"对抗水动力，平衡翼型在它的不稳定构型"**。**这些力是"非定常流体-物体相互作用"的结果**；**和经典 cart-pole 不同，这次我们没有"可处理的参数化 ODE 模型"**。**这是系统辨识和 ILC 的完美问题**。

> 在一系列实验里，**首先我们试图用"近似模型（平板理论）导出的 LQR 控制器"稳定系统**。**这个控制器表现不好，但刚好够在"不稳定平衡点附近"收集相关数据**。**然后我们拟合线性模型，用模型重算 LQR 控制器，性能明显变好**。

> 为了研究**更激进的动作**，我们考虑**对小车期望位置做快速阶跃变化**（**像战斗机快速改变高度**）。**只用"带偏移设定点的时不变 LQR 平衡控制器"**，我们自然观察到**非常慢的阶跃响应**。**用"时不变线性模型"做轨迹优化**，能好得多。**但通过"在轨迹附近迭代拟合时变线性模型 + 做基于模型的 ILC"，我们达到了明显更好的性能**。

**人话（ILC 的精髓 = "边做边学模型，越做越好"，必懂）**：
- **第一遍**：用烂模型 + LQR，**勉强跑一遍，收集数据**。
- **第二遍**：用数据**在"平衡点附近"拟合一个好点的线性模型**，**重算 LQR，跑第二遍**。
- **更激进**：要做大动作时，**在"标称轨迹附近"拟合"时变线性模型"**，**用 iLQR 做 ILC**——**每做一遍，模型更准，控制更好**。
- **这就是"辨识 + 控制"的闭环迭代**——**模型和控制"互相喂养"，一起进步**。

#### 用主导特征模态压缩（DMD）

> 对**高维状态或输入向量**，可以用 **SVD**，**只用 $[A,B]$ 的"主导特征值（及对应特征向量）"解最小二乘** [28, Section 7.2]——**这就是所谓的"动态模态分解（DMD）"**。**用少数主导模态产生"对数据的极好拟合"，有很多经验成功故事**（**这在"状态向量 $x$ 可能是'对应流体的一整张图像'"的问题里尤其相关，如流体力学**）。**在 DMD 里，我们会在这些特征模态的坐标里写线性动力学**（**总能投影回全坐标**）。

**类比（用主成分描述复杂流动，必懂）**：**一张湍流的图像有百万像素，但"流动的主要模式"可能只有几个**——**DMD 找出这几个"主导模式"，在它们的低维坐标里建线性模型**——**用 5 个数描述百万像素的演化**。

#### 非线性基里的线性动力学（Koopman 的影子）

> 这里我们能考虑的一个**可能有用的推广** = **辨识"在某个（可能高维）基向量定义的坐标系里，线性演化"的动力学**。特别地，我们可能考虑这种动力学：$\dot\phi=\frac{\partial\phi}{\partial x}\dot x=A\phi(x)$。**由于和 Koopman 算子理论的联系，这种特定形式被大做文章**——**我们下面会简单提**。对我们的目的，**我们还需要控制输入**，所以可能考虑：$\dot\phi=A\phi(x)+Bu$。

> 再次，**多亏最小二乘的成熟**，**用这个方法，能"列一大堆可能的基函数，再用稀疏最小二乘/模态分解，有效地找出重要的子集"**。

> **注意**：上面描述的机械臂参数估计**不是这个**，**虽然密切相关**。**最小二乘 lumped-parameter 估计，揭示的动力学"对状态变量仍非线性"**。

**人话（区分两种"线性"，必懂）**：
- **机械臂 lumped** = **对"参数"线性，对"状态"非线性**（**方程还是 $\sin\theta,\dot\theta^2$ 那些非线性项**）。
- **Koopman/非线性基** = **对"状态"也"看起来线性"**——**但代价是把状态 lift 到一个高维（甚至无穷维）的 $\phi$ 空间**，**在那个空间里演化是线性的**。**这是另一种"用线性换简单"的赌注**。

### 3.2 从输入-输出数据（状态实现问题）—— Ho-Kalman / ERA

> 在**更一般的形式**里，我们想估计这种模型：

$$x[n+1]=Ax[n]+Bu[n]+w[n],\qquad y[n]=Cx[n]+Du[n]+v[n]$$

> 再次，我们用最小二乘估计，**但结合著名的"Ho-Kalman"算法**（**也叫"特征系统实现（ERA）"算法**）[29]。**我最爱的呈现是 [24]**。

> **首先观察**：

$$y[0]=Cx[0]+Du[0]+v[0]$$
$$y[1]=C(Ax[0]+Bu[0]+w[0])+Du[1]+v[1]$$
$$y[n]=CA^nx[0]+Du[n]+v[n]+\sum_{k=0}^{n-1}CA^{n-k-1}(Bu[k]+w[k])$$

> 对辨识目的，**把 $y[n]$ 写成"最近输入的函数"**（对 $k\ge N$）：

$$y[n]=\underbrace{\begin{bmatrix}CA^{N-1}B & CA^{N-2}B & \cdots & CB & D\end{bmatrix}}_{G[n]}\underbrace{\begin{bmatrix}u[n-N]\\ u[n-N+1]\\ \vdots\\ u[n]\end{bmatrix}}_{\bar u[n]}+\delta[n]$$

其中 $\delta[n]$ 捕捉**初值、噪声、和滑动窗口之前的控制输入**剩下的项。

> **重要地**，$\delta[n]$ 和 $\bar u[n]$ **不相关**：$\forall k>n,\ \mathbb{E}[u_k\delta_n]=0$。**这有时叫 Neyman 正交性**，**它意味着我们能"用简单最小二乘估 $G$"**。**[24] 给了"估计误差范数"关于"样本数和噪声方差"的界**。

**人话（Neyman 正交性 = "噪声和输入不串味"，必懂）**：
- $\delta[n]$ 里装着"噪声 + 老早以前的输入的余响"。
- $\bar u[n]$ 是"最近的输入"。
- **如果"最近的输入"和"噪声/老余响"不相关**，那最小二乘**就不会被噪声带偏**——**这就是 Neyman 正交性给的"无偏"保证**。

> **窗口大小 $N$ 怎么选**？**由 Neyman 正交性，任何 $N\ge 0$ 估计都无偏**。**但 $N$ 太小，$\delta[n]$ 项会很大**，**导致估计方差可能很大**。**对稳定系统，$N$ 增大，$\delta$ 项会变小**。**实践中，我们根据"数据里的特征 settling time"选 $N$**（**大致到"脉冲响应变得足够小"为止**）。

> **如果你学过线性系统，$G$ 看着眼熟**；**它正是这个（多输入多输出）矩阵脉冲响应，也叫"Markov 参数"**。**事实上，估 $G$ 甚至可能对控制设计就够了**——**因为它和"部分可观系统的 disturbance-based feedback 用的参数化"密切相关** [30, 31]。**但 Ho-Kalman 算法能用来，从 $G$ 提取"状态维数 $n_x$ 的好估计 $\hat A,\hat B,\hat C,\hat D$"**——**假设真系统可观可控、阶数至少 $n_x$、且我们下面构造的数据矩阵足够丰富** [24]。

**人话（Markov 参数 = "系统的'指纹'"，必懂）**：
- **$G=[CA^{N-1}B,\dots,CB,D]$** = **系统对"脉冲输入"的响应序列**——**你敲一下系统，看它怎么"咚、咚、咚"地回响**。
- **这串回响 = 系统的"指纹"**——**它完整刻画了输入-输出行为**。
- **Ho-Kalman = "从指纹反推'内部结构 $A,B,C,D$'"的算法**。

#### 相似变换 + 平衡实现

> **重要的是要意识到**：**许多系统矩阵，能描述同一份输入-输出数据**。特别地，**对任何可逆矩阵 $T$（相似变换）**，系统矩阵 $A',B',C'$ 满足：

$$A'=T^{-1}AT,\quad B'=T^{-1}B,\quad C'=CT$$

**描述同样的输入-输出行为**。**Ho-Kalman 算法返回一个"平衡实现（balanced realization）"**。**平衡实现 = 我们"有效地施加了一个相似变换 $T$"，让"可控性格拉姆和可观性格拉姆相等且对角"** [28, Ch.9]，**并按"对输入/输出行为的影响递减"给状态排序**。**这个排序，和"确定系统阶数 + 模型降阶"相关**。

**人话（同一个系统，无数种"内部坐标"，必懂）**：
- **$A,B,C$ 是"系统在某组内部坐标下的描述"**——**换一组坐标（$T$），$A,B,C$ 全变，但"输入-输出行为"不变**。
- **就像"描述同一个房间，可以用不同的坐标系"**——**房间没变，坐标变了**。
- **Ho-Kalman 返回的"平衡实现"** = **挑了一组"最整齐的坐标"**——**让"哪些状态重要（可控+可观）"一目了然**，**并按重要性排序**——**于是你想降阶，就"砍掉排后面的不重要状态"**。

> **注意 $D$ 是 $G$ 的最后一块**，**所以 trivial 地提取**。**Ho-Kalman 算法告诉我们怎么提取 $\hat A,\hat B,\hat C$**——**对"适当构造的数据矩阵"再做一次 SVD**（见 [24, §5.1]、[32, §10.5]、[28, §9.3]）。

#### Example 18.8（从 keypoints 用 Ho-Kalman 辨识 Cart-Pole）

> 重复 cart-pole 例子。**但这次，不直接拿关节位置和速度，我们考虑"从渲染场景的相机辨识动力学"**——**但让我们谨慎进行**。

> 标准相机的输出是 **RGB 图像**，**3 × 宽 × 高 个实值**。**我们当然能把它们拉成向量，当输出/观测 $y$**。**但我不推荐**。**这个"像素空间"不是个好空间**。比如**你很容易找到一个像素，某一帧是"小车的颜色"，但小车位置稍微一变，它就（不连续地）变成"背景的颜色"**。**深度学习给了我们 fantastic 的新工具，把原始 RGB 图像变换到更好的"特征空间"**——**鲁棒到能部署在真实系统上，但能让我们的建模努力 tractable 得多**。**我的组重度使用"keypoint 网络" [33] 和自监督"密集对应" [34, 35, 36]，把 RGB 输出转换成"更易消费的形式"**。

> 这些工具的存在，让"我们有一些观测，代表'刚性固定在小车和摆杆上的若干 keypoint 的 2D 位置'"这个假设变得合理。**摆杆上任何 keypoint $K$ 的位置，由 cart-pole 运动学给出**：

$${}^Wp^K=\begin{bmatrix}x\\ 0\end{bmatrix}+\begin{bmatrix}\cos\theta & -\sin\theta\\ \sin\theta & \cos\theta\end{bmatrix}{}^Pp^K$$

其中 $x$ 是小车位置，$\theta$ 是摆杆角度。

> **把 RGB 输出"作为 cart-pole 位置的函数"线性化，可能不合理**；**但"对小角度线性化这个 keypoint 方程"，是合理的**。

> 你会在例子里看到，**我们相当漂亮地恢复了脉冲响应**。

> **大问题是**：**Ho-Kalman 会发现"我们熟悉的那个 4 维状态向量"吗？还是发现别的**？**我们通常通过"看 Hankel 数据矩阵的奇异值大小"选阶数**。**这个例子里，无噪声时，你清楚看到 2 个状态描述了大部分行为，4 或 5 个之后收益递减**。

**人话（从像素到模型的"正确姿势"，必懂）**：
- **直接拿像素当 $y$** = **灾难**——**像素对位置"不连续、不光滑"**，**线性模型拟合不了**。
- **正确姿势** = **先用深度学习把像素变成"keypoint 的 2D 坐标"**——**keypoint 对位置"光滑、连续"**，**而且对"小角度"还能线性化**。
- **然后对 keypoint 序列跑 Ho-Kalman**——**就能干净地恢复脉冲响应、估出阶数**。
- **这就是"深度学习（感知）+ 经典辨识（建模）"的联手**——**DL 负责"把脏像素洗干净成好特征"，经典辨识负责"从好特征建线性模型"**。

### 3.3 加稳定性约束

> **细节 coming soon。见比如 [37]**。

**补充概念**：**普通最小二乘估出的 $A$，可能"不稳定"（特征值在单位圆外）**——**哪怕真系统是稳定的**（**有限数据 + 噪声的锅**）。**[37] 的方法 = 在最小二乘里加" $A$ 必须稳定"的约束**——**让估出的模型"先天稳定"**，**对后面做控制/仿真更安全**。

### 3.4 自回归模型（ARX）

> 另一类重要的线性模型，**直接用"最近的输入和输出历史"预测输出**：

$$y[n+1]=A_0y[n]+A_1y[n-1]+\cdots+A_ky[n-k]+B_0u[n]+B_1u[n-1]+\cdots+B_ku[n-k]$$

> 这就是所谓的"**带外生输入的自回归模型（ARX）**"。**ARX 模型的系数，能直接用线性最小二乘，从输入-输出数据拟合**。

> 虽然**当然可以把这些模型想成状态空间模型**——**把有限历史 $y,u$（**除了 $u[n]$**）收集进状态向量**。**但这不一定是高效的表示**；**Ho-Kalman 算法可能能找到小得多的状态表示**。**这对"可能需要很长历史"的部分可观系统，尤其重要**。

**类比（用"过去几秒"直接预测"下一秒"，必懂）**：
- **ARX** = **一个"记性好的预测器"**：**它不建"内部状态"，直接说"下一秒的输出 = 过去 $k$ 秒输出的加权和 + 过去 $k$ 秒输入的加权和"**。
- **优点** = **简单、直接最小二乘、不用 Ho-Kalman**。
- **缺点** = **状态 = 整段历史，可能很长、很冗余**——**Ho-Kalman 能把它"压缩"成几个内部状态**。

### 3.5 学习线性模型的统计分析

> （PDF 此节为标题，正文未展开，对应 [22–25] 的有限样本界。）

**补充概念**：**这一节是"给线性辨识配'误差条'"**——**前面 Ho-Kalman/最小二乘告诉你"估出 $\hat A,\hat B$"，这一节告诉你"在'只有 $N$ 个样本'时，$\hat A$ 离真 $A$ 最多差多少（以多大概率）"**。**这是 ML 给经典辨识补的"有限样本保证"**——**渐近理论说"$N\to\infty$ 时收敛"，有限样本理论说"$N$ 有限时，误差 $\le$ 某个关于 $N$ 和噪声的界"**。

## 4. 辨识有限 (PO)MDP（18.4）—— 第三种"能完全搞懂"的情况

> 还有**一种我们能很好理解的情况**：**状态、动作、观测（和时间）全离散**。**回忆**：在最优控制和动态规划讨论的最开头，我们用**图搜索 + 状态空间离散化**，给了值迭代一个特别漂亮的版本。**一般地，我们可以用条件概率写随机动力学**：

$$\Pr(s[n+1]\,|\,s[n],a[n]),\quad \Pr(o[n]\,|\,s[n],a[n])$$

其中 $s$ 离散状态，$a$ 离散动作，$o$ 离散观测。**全离散时，这些条件概率天然用矩阵/张量表示**。**我们用张量 $T_{ijk}\equiv\Pr(s[n+1]=s_i\,|\,s[n]=s_j,a[n]=a_k)$ 表示转移矩阵，$O_{ijk}\equiv\Pr(o[n]=o_i\,|\,s[n]=s_j,a[n]=a_k)$ 表示观测矩阵**。

### 4.1 从状态观测

> 类比线性动力系统的讨论，**先理解第一种情况**：**我们能直接访问状态和动作轨迹 $s[\cdot],a[\cdot]$**。**这对应辨识马尔可夫链或 MDP**。**转移矩阵能直接从转移的统计里提取**：

$$T_{ijk}=\frac{\text{从 }s_j,a_k\text{ 转移到 }s_i\text{ 的次数}}{\text{从 }s_j,a_k\text{ 转移的总次数}}$$

> 不奇怪，**要让这个估计渐近收敛到真转移概率，我们需要辨识（探索）动力学是遍历的**（**每个状态/动作对被访问无穷多次**）。

> 对**大 MDP**，类比线性系统的模态分解，**我们也能考虑转移矩阵的"因式分解表示"**。**[Coming soon...]**

**人话（数次数 = 估概率，必懂）**：**全离散 + 能看见状态 = 最简单的辨识**——**"从 $s_j$ 做 $a_k$，去了 $s_i$ 几次 ÷ 总共做了几次" = 转移概率**。**就是"数次数算频率"**。**唯一要求 = "每个 $(s,a)$ 都得被试过够多次"（遍历/探索）**。

### 4.2 辨识隐马尔可夫模型（HMM）

> （PDF 此节为标题，正文未展开。）

**补充概念**：**HMM = "状态看不见，只看见观测"的离散模型**——**辨识它 = 著名的 Baum-Welch 算法（EM 的一种）**。**它比"能看见状态"难，因为你要"一边猜隐藏状态、一边估转移/观测概率"，来回迭代**。

## 5. 神经网络模型（18.5）—— 第四根支柱

> 如果"机械臂参数估计、线性系统辨识、有限状态系统"是系统辨识的前几根支柱，那么**（至少如今）深度学习也许是最后一根主柱**。**我把这一节紧跟在线性系统之后，不是巧合**。**神经网络是强大的工具，但仔细想它们有点难**。**幸好，我们会看到，线性动力系统的许多基本教训和洞察，在这里仍然适用**。**特别地，我们能遵循同样的推进**：**从状态观测直接学动力学函数、从输入-输出数据学状态空间模型（用循环网络）、用前馈网络 + 输出历史学输入-输出（自回归）模型**。

> 深度学习工具能让我们**相当可靠地调网络去拟合训练数据**。**主要挑战在"数据效率/泛化"，以及"基于这些'描述如此复杂'的模型，设计规划器/控制器"**。

### 5.1 生成训练数据（鸡和蛋）

> 拟合神经网络这类丰富非线性模型时，**一个极有趣的问题 = 怎么生成训练数据**。**你大概有个直觉**：**我们希望数据对状态空间有一定"覆盖"**；**这对欠驱动系统尤其难**——**因为动力学约束限制了我们在状态空间里的轨迹**。

> 对机械臂参数估计，我们讨论过"用数据矩阵的条件数当实验设计的显式目标"。**这是"用线性最小二乘做回归 + 利用机械臂方程的结构知识"的奢侈**。**不幸的是，在"一般函数近似器做非线性最小二乘"的更一般情况下，我们没有类比的概念**。**这个方法对辨识线性动力系统也 work**。**这里的挑战也许没那么严重**——**因为对线性模型，无噪声时，连"脉冲响应产生的数据"都够辨识**。

> 这个话题最近在**基于模型的强化学习**里受到大量关注（如 [38]）。**广义上，理想情况下，我们希望"用于系统辨识的训练数据"匹配"执行最优策略时会遇到的数据分布"**。**但在设计出控制器之前，你不可能知道这个分布**——**而（在我们当前的讨论里）设计控制器又需要模型**。**这是经典的"鸡和蛋"问题**。**多数情况下，它指向"把系统辨识和控制设计交织进行"的重要性**——**而非"辨识一次、模型用 forever"的简单想法**。

**类比（鸡和蛋，必懂）**：
- **要学好模型，得用"最优策略会产生的数据"**——**但最优策略得先有模型才能算**。
- **要算最优策略，得先有好模型**——**但好模型得用"最优策略的数据"才能学**。
- **死循环**。**解法** = **别想"一次到位"，而是"学一点模型 → 改进一点策略 → 用新策略收集新数据 → 再学模型"，螺旋上升**。

### 5.2 从状态观测 / 5.3 循环网络的状态空间模型 / 5.4 自回归模型（Transformer）

> （5.2、5.3 为标题占位。）

> **5.4**：你可能听说过一种叫 **Transformer** 的神经网络模型。**网上有海量资源学 Transformer**。**它们起源于自然语言处理（NLP）社区**，**在那里它们迅速取代了循环神经网络模型**——**后者当时正挣扎于处理很长的句子（轨迹）**。**Transformer 通过"切回自回归式模型"绕过这个问题，但它们用 attention 机制，把"之前观测的很长历史"压缩成一个紧凑表示**。**这就是如今让大语言模型（如 chat-GPT）能"写一整篇文章、在文章很后面还正确'记住'前面用过的名字/概念"的原因**。

**人话（Transformer = "会划重点的自回归模型"，必懂）**：
- **ARX/循环网络** = **把过去 $k$ 步"全记住"或"压缩成一个隐藏状态"**——**序列一长，要么记不住、要么压缩丢信息**。
- **Transformer** = **用 attention"智能地划重点"**——**它不平等地看过去每一步，而是"动态地决定'此刻该重点参考过去的哪几步'"**——**于是能处理超长序列**。
- **对控制** = **它就是一个"超强的自回归动力学模型"**——**用过去一长串 $(u,y)$ 预测下一步**。

### 5.5 基于粒子的模型 / 5.6 以物体为中心的模型 / 5.7 建模随机性 / 5.8 神经网络模型的控制设计

> （均为标题占位，对应 [16, 17] 等。）

**补充概念**：
- **基于粒子的模型** = **把物体/流体表示成"一堆相互作用的粒子"，用网络学"粒子间怎么交互"**——**适合"推 rigid bodies、变形体、流体"** [17]。
- **以物体为中心的模型** = **先"把场景拆成一个个物体"，再对每个物体建模 + 学物体间关系**——**比"对整张图像建模"更结构化、更泛化**。
- **建模随机性** = **让网络输出"分布"而非"单个值"**——**捕捉"世界的不确定"**。
- **神经网络模型的控制设计** = **这是"弱得可怜"的那一环**——**网络拟合得好，但"在它上面做规划/控制"很难**（**因为网络是个"不透明的黑箱"，没有线性模型/机械臂方程那种"能 exploit 的结构"**）。

## 6. 替代方法 / 混合系统 / 任务相关模型（18.6–18.8）

### 18.6 非线性系统辨识的替代方法 / 18.7 混合系统的辨识

> （均为标题占位。）

**补充概念**：
- **18.6** = **除了神经网络，还有"稀疏回归发现方程"（如 SINDy）、"高斯过程"等非线性辨识替代方法**。
- **18.7** = **混合系统（带接触/碰撞）的辨识** = **难上加难**——**你不仅要估参数，还要估"什么时候发生接触/切换"**——**离散事件 + 连续动力学的联合辨识**。

### 18.8 任务相关模型（本章的"哲学高潮"）

> 如引言简述，**系统辨识的标准目标 = 匹配动力系统的输入-输出行为**。**当然，如果我们能找到一个"完美预测所有输出"的模型，那它应该够做最优决策**。**但当我们不能完美预测时**（**由于有限数据和/或有限模型表示能力**），**那"放在预测不同输出上的相对代价"就变得重要**。**当观测来自相机时，这感觉尤其重要**——**多数情况下，"准确预测场景里每个像素"对"想用相机完成特定任务的机器人"来说，不是正确的目标**。

> 幸好，**"学习任务相关模型/学习状态表示"这个问题，已成为 ML 社区的宠儿**。**很多聪明人在想它，领域在过去几年进步显著**。**在海量论文里，我认为有几个真正核心的想法**。

**什么才是"好的控制状态表示"？两个定义性性质**：
1. **它应该可观**；
2. **它应该够做最优决策**。

**换句话说**，如果 $z[n]$ 是动态控制器的状态（**我们可以把它想成"学习到的状态表示的观测器"**），那我们希望**给定这个状态的最优策略，采取的动作，和"用全部可用历史的最优策略"采取的动作相同**：

$$\pi^*(z[n])\approx\bar\pi^*(y[n],y[n-1],y[n-2],\dots,u[n-1],u[n-2],\dots)$$

> **当然，信念状态——按定义是"预测未来观测的充分统计量"——有这个性质**。**但更"极简"的表示也可能够**。所以**好状态表示的第三个、稍微弱一点的性质** = **我们希望它"对学习、表示、决策都 tractable"**。

**人话（好表示的三条标准，必懂）**：
- **可观** = **能从观测推出来**。
- **够决策** = **只看它，就能做出和"看全部历史"一样好的决策**（**信息没丢**）。
- **好算** = **维度别太高、别太难学**。
- **信念状态满足前两条，但常常"不好算"（维度爆炸）**——**所以我们要找"更极简、但仍够决策"的表示**。

> **"够做最优控制决策"是个难目标**——**因为它把"表示学习/系统辨识"和"控制设计"耦合了**。**不知道最优动作，怎么知道什么表示够**？**这是"模仿学习 [35, 39] 可能有价值"的一个原因**——**通过提供"最优策略的演示"，它把表示学习"降回"经典系统辨识**，**让我们能"专注状态表示问题，而不用同时解控制设计"**。**其他工作如 [40]，试图"在学习时也对学到的表示用规划器"，并用一个损失函数，要求"用当前状态策略采取的动作，匹配'用表示做规划、优化未来多步'采取的动作"**。

> **一个密切相关的想法** = **要求表示"够预测最优值函数"（而非最优动作）**。**当然，如果我们有"和模型一致的值函数"，那它够做最优决策**。**但要注意，有些情况下，预测最优 cost-to-go 实际上比预测最优动作更难**。

**类比（知道"往哪走" vs 知道"值多少分"，必懂）**：
- 想象一个 grid world 的 agent，**能走两条走廊，已学到"左走廊奖励总比右走廊多"**。
- **预测"走左走廊具体得多少分"** = **不需要**（**反正知道"左比右好"就够选动作了**）。
- **但"预测值"有时比"预测动作"更难**——**因为值要"精确算分"，动作只要"比大小"**。

#### 近似信息状态（AIS）—— 真正打破"鸡和蛋"

> **一个确实从根本上打破"鸡和蛋"问题的提议**，由 [41] 给出，叫"**近似信息状态（AIS）**"。**[41] 的核心想法** = **如果一个状态表示 $z[n]$：1）够预测一步奖励，且 2）够预测 $z[n+1]$，那它就够做最优决策**。**这激发了他们"近似信息状态"的概念**——**一个"近似完成这两个目标"的表示**。**他们给了一个"基于一步奖励和下一步状态预测的最坏情况误差"的、所得策略次优性的特定界**。**在我的组里，我们研究这个方法，试图理解"我们能完全搞懂的两种情况"的含义**：**有限（表格）MDP [42] 和线性高斯系统 [43]**。**特别地，[42] 给了一个算法，对一类 POMDP 最优地解 AIS 条件**；**它提供证据：按 AIS 指标最优的表示，不一定对"复现最优动作"最优，且 AIS 的性能界可能很松**。

**人话（AIS 的精髓 = "能预测奖励 + 能预测自己的下一步 = 够用了"，必懂）**：
- 你**不需要预测所有像素**，**也不需要预测最优值**。
- 你**只需要你的表示 $z$ 满足两件事**：① **从 $z$ 能预测"这一步得多少奖励"**；② **从 $z$ 和动作，能预测"下一步的 $z$"**。
- **满足这两条，$z$ 就"够做最优决策"**——**而且这两条都"不需要先知道最优策略"**（**奖励是环境给的，$z$ 的下一步是表示自己的演化**）——**于是"鸡和蛋"被打破了**！
- **作者的诚实补充**：**但 [42] 发现，AIS 最优的表示，不一定"动作复现得最好"，界也可能松**——**所以 AIS 是"理论上的突破"，但实践上还有差距**。

#### bisimulation 与 MuZero

> **近似信息状态本身，和"MDP 里通过所谓'bisimulation 度量'做状态聚合"的先前工作密切相关**。**基本想法** = **如果两个状态的"未来结果不可区分"，那它们能聚合成一个状态，从而减小状态空间**。**精确 bisimulation 见 [44]，近似见 [45]，POMDP 扩展见 [46]，用神经网络的现代版见 [4]**。

> 有趣的是，**DeepMind 著名的 MuZero [47]，用"预测动作 + 值函数 + 一步奖励"的组合损失，学习一个任务相关状态表示**。**但我见过几个项目，在机器人领域挣扎于复现它的成功**。

**人话（bisimulation = "未来一样的状态，就当同一个"，必懂）**：
- **两个状态，如果"从它们出发，未来所有动作-奖励的分布都一样"**，那**对决策而言，它俩没区别**——**合并成一个，状态空间就小了**。
- **这就是 bisimulation**——**"按'未来行为等价'来压缩状态"**。
- **MuZero** = **把"预测动作、值、奖励"三个损失合起来学表示**——**集大成者**，**但在机器人上"还没完全跑通"**。

## 7. 练习（18.9）—— 逐条讲透

### 练习 18.1（不同目标函数的线性系统辨识）

> 考虑离散线性系统 $x[n+1]=Ax[n]+Bu[n]$，$x[n]\in\mathbb{R}^p$，$u[n]\in\mathbb{R}^q$。**系统矩阵 $A\in\mathbb{R}^{p\times p}$ 和 $B\in\mathbb{R}^{p\times q}$ 是未知参数**，你的任务是**给定仿真轨迹辨识参数**。用 notebook 提供的轨迹仿真，实现下列问题的解。

**a.** 解 $\min_{A,B}\sum_{n=0}^{N-1}\|x[n+1]-Ax[n]-Bu[n]\|_2^2$。

**人话**：**标准最小二乘（L2）**——**最小化"误差的平方和"**——**对"高斯噪声"最优**，**解 = 闭式 $\begin{bmatrix}A&B\end{bmatrix}=X'U^+$（伪逆）**。**对"偶尔的大异常值"敏感**（**平方把大误差放大**）。

**b.** 解 $\min_{A,B}\sum_{n=0}^{N-1}\|x[n+1]-Ax[n]-Bu[n]\|_\infty$。

**人话**：**最小化"每一步误差的最大分量"（L∞ / 切比雪夫）**——**"让'最差的那一步'尽量好"**——**适合"我不能容忍任何一步误差太大"的场景**。**能写成线性规划（LP）**。

**c.** 解 $\min_{A,B}\sum_{n=0}^{N-1}\|x[n+1]-Ax[n]-Bu[n]\|_1$。

**人话**：**最小化"误差的绝对值之和"（L1）**——**对"异常值鲁棒"**（**绝对值不像平方那样放大离群点**）——**适合"数据里偶尔有坏点"的情况**。**也能写成 LP**。

**类比（三种"打分哲学"，必懂）**：
- **L2** = **"看平均表现"**——**但一个超级烂的步骤会拉爆平均分**（**平方惩罚**）。
- **L∞** = **"看最差表现"**——**"我不能有任何一步太离谱"**。
- **L1** = **"看总偏差，但不怕个别离群"**——**"偶尔一个坏点，我不在乎"**。
- **代码增补里我会让你亲手看"加几个离群点后，L2 被带歪、L1 仍然稳"**。

> 这个练习我们用**物理启发的基函数**拟合**栖停滑翔机的非线性动力学**。在 notebook 里，你要**实现最小二乘拟合，找出最能描述滑翔机动力学的基函数集合**。**花时间过一遍 notebook、理解代码，然后回答下列问题**。

**a.** 过一遍 notebook 的 coding 部分。

**b.** **我们测试的所有基函数配置，都用了"至多 3 个基函数"算一个加速度**。**如果把"算一个加速度用的基函数数"增加到 4，最小二乘残差会下降**。**既然用更多基函数能拟合得更好，为什么我们要限制在 3 个**？

**人话（过拟合 vs 泛化，必懂）**：
- **基函数越多，训练残差越小**——**因为模型"更灵活"，能"记住"训练数据的每个细节**。
- **但"记住细节"≠"学到规律"**——**多出来的基函数，可能在拟合"噪声"，而非"真动力学"**。
- **结果** = **训练误差小，但"在新数据上/用来做控制时"表现差**（**过拟合**）。
- **而且** = **基函数越多，模型越复杂，后面"用它做规划/控制"越贵/越难**。
- **所以限制 3 个 = "在'拟合得够好'和'别过拟合/别太复杂'之间取平衡"**——**这就是 18.1.3 "模型复杂度 trade-off"和 18.2.5 "稀疏基函数选择（LASSO/序贯阈值）"的实战体现**。

**类比（背答案 vs 懂原理，必懂）**：**用 10 个基函数把训练数据拟合到残差 0，像"把 100 道题的答案全背下来"**——**考试（新数据）一变就抓瞎**。**用 3 个基函数拟合到残差稍大，像"懂了 3 条原理"**——**考试能举一反三**。**所以"残差小"不是唯一目标，"泛化 + 简单"才是**。

## 增补一：把"还不够通俗"的 6 个概念，各加一个类比 / 澄清

1. **为什么"逆动力学仿射、正动力学不仿射"**？逆动力学 $\tau=M(q)\ddot q+\cdots$ 里，**$M,C,\tau_g$ 对惯性参数线性**（**质量翻倍，$M\ddot q$ 翻倍**）→ **$\tau$ 对参数线性**。正动力学 $\ddot q=M^{-1}(\tau-\cdots)$ 里，**$M^{-1}$ 对参数是"有理函数"（带除法）**→ **非线性**。**类比**：**$y=mx$ 对 $m$ 线性；$x=y/m$ 对 $m$ 非线性（双曲线）**。**所以"用 $\tau$ 当因变量做回归"= 线性回归；"用 $\ddot q$ 当因变量"= 非线性回归**。
2. **伪惯性 $J\succ 0$ 为什么打包所有物理约束**？**$J=\begin{bmatrix}\Sigma&h\\h^T&m\end{bmatrix}\succ0$** 这个 4×4 正定，**蕴含**：① $m>0$（**右下角**）；② $\Sigma-\frac{hh^T}{m}\succ0$（**Schur 补**，**即"绕质心的惯性张量正定"**）；③ 质心合理。**一条凸约束，顶三条**——**这就是为什么"带物理约束的辨识"是 SDP**。
3. **平衡实现为什么"按重要性排序"**？**平衡实现让"可控性格拉姆 = 可观性格拉姆 = 对角阵 $\operatorname{diag}(\sigma_1,\dots)$"**，**$\sigma_i$ 叫 Hankel 奇异值**——**$\sigma_i$ 大 = 第 $i$ 个状态"既好控制、又好观测、对输入输出影响大"**。**降阶 = 砍掉 $\sigma_i$ 小的状态**——**"砍掉既难控制又难观测、对行为没影响的内部坐标"**。**类比**：**给房间里的家具按"重要性"排序，搬家时先扔最不重要的**。
4. **Neyman 正交性 $\mathbb{E}[u_k\delta_n]=0$ 的直觉**：**$\delta_n$ 含"噪声 + 老输入的余响"**，**$\bar u_n$ 是"新输入"**。**如果"新输入"是"我主动加的、和噪声无关的激励"，那它和 $\delta$ 不相关**——**最小二乘就无偏**。**反过来，如果输入是"噪声驱动的反馈"，可能和 $\delta$ 相关 → 有偏**——**这就是"闭环数据辨识"的坑**（**Example 18.6 的秩亏是另一回事，但"闭环偏差"是姊妹坑**）。
5. **AIS 为什么"打破鸡和蛋"**？**普通任务相关表示要"够最优决策"→ 需要最优策略 → 鸡和蛋**。**AIS 改成"够预测奖励 + 够预测 $z$ 下一步"**——**奖励是环境直接给的（不需要策略），$z$ 下一步是表示自己的演化（也不需要策略）**——**两个目标都"不依赖最优策略"** → **蛋没了，鸡能孵了**。**代价** = **AIS 界可能松、表示不一定动作最优**（**[42] 的诚实发现**）。
6. **练习 18.2 为什么限制 3 个基函数**？**除了过拟合，还有"控制可用性"**：**基函数越多，残差模型 $\alpha_r\Phi$ 越复杂**，**后面"用它做规划/控制"时，动力学 $f$ 越难处理**（**可能破坏 control-affine、让优化非凸**）。**所以"3 个"是"拟合、泛化、可控"三者的折中**——**而 LASSO/序贯阈值 [17,18] 就是"自动找这个折中"的工具**。

### 实验 1：方程误差 vs 仿真误差 —— 亲眼见"一步准、长期漂"（可跑，对照 18.1.1）

**拟合一个非线性系统，对比"方程误差 LS"和"仿真误差"的长期表现**。

```python
import numpy as np
import matplotlib.pyplot as plt
rng = np.random.default_rng(0)
# 真系统: x_{n+1} = 0.9 x_n + 0.1 x_n^3 + u_n + noise  (弱非线性)
def true_f(x, u): return 0.9*x + 0.1*x**3 + u
N = 200
u = rng.uniform(-1, 1, N)                      # 丰富输入
x = np.zeros(N+1); x[0] = 0.5
for n in range(N): x[n+1] = true_f(x[n], u[n]) + 0.02*rng.randn()
# 方程误差 LS: 拟合 x_{n+1} = a x_n + b x_n^3 + c u_n  (线性于参数!)
Phi = np.column_stack([x[:-1], x[:-1]**3, u])  # 设计矩阵
theta, *_ = np.linalg.lstsq(Phi, x[1:], rcond=None)   # [a,b,c]
a, b, c = theta
print("方程误差 LS 估: a=%.3f b=%.3f c=%.3f (真 0.9, 0.1, 1.0)" % (a, b, c))
# 仿真误差: 用估的模型从 x[0] 自己跑到底, 对比真轨迹
xhat = np.zeros(N+1); xhat[0] = x[0]
for n in range(N): xhat[n+1] = a*xhat[n] + b*xhat[n]**3 + c*u[n]   # 不纠正!
plt.figure(); plt.plot(x, label='真轨迹'); plt.plot(xhat, '--', label='模型自跑(仿真误差)')
plt.legend(); plt.title('方程误差LS: 一步准, 但自跑长期可能漂'); plt.grid(alpha=.3); plt.show()
print("末态 真=%.3f 模型自跑=%.3f" % (x[-1], xhat[-1]))
```

**你会看到**：**LS 把 $a,b,c$ 估得挺准**，**但"模型自跑"的轨迹和真轨迹"慢慢分开"**——**亲手见"方程误差 ≠ 仿真误差"**。**把噪声调大、或非线性调强，漂移更明显**——**体会"为什么仿真误差才是真目标"**。

### 实验 2：逆动力学 lumped parameters —— 单摆"称重量"（可跑，对照 18.2.2/18.2.3/Example18.3）

**构造单摆数据，用 $W\alpha=w_0$ 最小二乘估 lumped parameters $[ml^2, b, mgl]$**。

```python
import numpy as np
rng = np.random.default_rng(1)
# 真参数
ml2_true, b_true, mgl_true = 1.0, 0.1, 9.8
# 生成"丰富"轨迹 (q, qd, qdd, tau) —— 用随机激励仿真
N = 1000; dt = 0.01
q = np.zeros(N); qd = np.zeros(N); tau = np.zeros(N)
q[0], qd[0] = 0.3, 0.0
for n in range(N-1):
    tau[n] = 2.0*np.sin(0.5*n*dt) + rng.uniform(-1,1)   # 激励!
    qdd = (tau[n] - b_true*qd[n] - mgl_true*np.sin(q[n]))/ml2_true   # 正动力学仿真
    qd[n+1] = qd[n] + qdd*dt; q[n+1] = q[n] + qd[n]*dt
# 数值微分得 qdd (模拟"从传感器估加速度")
qdd_meas = np.gradient(qd, dt)
# 数据矩阵 W: [qdd, qd, sin(q)] * [ml2, b, mgl]^T = tau  ->  W α = tau
W = np.column_stack([qdd_meas, qd, np.sin(q)])
alpha, *_ = np.linalg.lstsq(W, tau, rcond=None)
print("估 lumped [ml2, b, mgl] =", np.round(alpha, 3))
print("真 lumped              =", [ml2_true, b_true, mgl_true])
# 注意: 你估不出 m, l 各自, 只能估 ml2 和 mgl 这两个组合! (lumped 的精髓)
print("-> m,l 不可单独辨识, 但 ml2, mgl 组合估得准 (控制/仿真只需组合)")
```

**你会看到**：**$[ml^2, b, mgl]$ 估得接近真值**——**但你"永远拿不到 $m$ 和 $l$ 各自"**——**亲手见 lumped parameters 的"能估组合、不能估个体"**。**把激励 `tau` 换成常数 0**，**看 $W$ 秩亏、估计崩**——**体会"实验设计/激励"的必要性**。

### 实验 4：Ho-Kalman / ERA —— 从脉冲响应反推 $A,B,C$（可跑，对照 18.3.2，本章代码亮点）

**构造一个已知 LTI 系统，生成 Markov 参数，用 SVD 做平衡实现/ERA，验证还原**。

```python
import numpy as np
rng = np.random.default_rng(2)
# 真系统 (2 阶)
A = np.array([[0.9, 0.1],[-0.2, 0.8]]); B = np.array([[1.],[0.5]]); C = np.array([[1.,0.]]); D = np.array([[0.]])
n = A.shape[0]
# Markov 参数 G = [D, CB, CAB, CA^2B, ...]
def markov(k): 
    if k==0: return D
    return C @ np.linalg.matrix_power(A, k-1) @ B
N = 30
G = [markov(k) for k in range(N)]
# Ho-Kalman: 构造 Hankel 矩阵 H[i,j] = G[i+j+1] (i,j 从0), 做 SVD
p, q = 1, 1
H = np.block([[G[i+j+1] for j in range(N//2)] for i in range(N//2)])
U, s, Vt = np.linalg.svd(H)
# 选阶数 = 看奇异值 (这里应2个主导)
print("Hankel 奇异值前5:", np.round(s[:5], 4), " -> 2 个主导 => 估阶数 2")
nx = 2
# 平衡实现: 取 U[:,:nx], Vt[:nx,:], 用 sqrt(s) 构造 O, C 矩阵
Un, Vn, sn = U[:,:nx], Vt[:nx,:], s[:nx]
O = Un @ np.diag(np.sqrt(sn))              # 可观性矩阵 (平衡)
Cc = O[:p, :]                               # C = O 的第一块
Cc_mat = Cc.reshape(p, nx)
R = np.diag(np.sqrt(sn)) @ Vn               # 可控性矩阵
Bc = R[:, :q]                               # B = R 的第一块
# A 从 Hankel 移位: H' [i,j]=G[i+j+2]; A = O_pinv @ H' @ R_pinv (平衡坐标)
Hp = np.block([[G[i+j+2] for j in range(N//2-1)] for i in range(N//2-1)])
O_trunc = O[:-p, :] if O.shape[0]>p else O
R_trunc = R[:, :q] if R.shape[1]>q else R
Ac = np.linalg.pinv(O[p:, :]) @ Hp @ np.linalg.pinv(R[:, q:]) if (O.shape[0]>p and R.shape[1]>q) else np.linalg.pinv(O) @ H @ np.linalg.pinv(R)
print("估 C =", np.round(Cc_mat,3), " 真 C =", C)
print("估 B =", np.round(Bc,3).ravel(), " 真 B =", B.ravel())
print("估 A 特征值 =", np.round(np.sort(np.abs(np.linalg.eigvals(Ac)))[::-1],3),
      " 真 A 特征值模 =", np.round(np.sort(np.abs(np.linalg.eigvals(A)))[::-1],3))
```

**你会看到**：**Hankel 奇异值"2 个主导"→ 估阶数 2**；**估出的 $A$ 特征值模 ≈ 真 $A$**（**平衡实现下 $A$ 是相似变换后的，特征值不变**）——**亲手见 Ho-Kalman "从脉冲响应指纹反推内部结构"**。**加噪声**，**看奇异值"尾巴抬起"，阶数判断变难**——**体会 Example 18.8 "看奇异值选阶数"**。

### 实验 5：ARX 模型 —— 用历史直接预测（可跑，对照 18.3.4）

```python
import numpy as np
rng = np.random.default_rng(3)
# 真系统同实验4, 生成 y, u
A=np.array([[0.9,0.1],[-0.2,0.8]]); B=np.array([[1.],[0.5]]); C=np.array([[1.,0.]]); D=np.array([[0.]])

# ARX: y[n+1] = a1 y[n] + a2 y[n-1] + b0 u[n] + b1 u[n-1]
k=2

Phi = np.hstack([Y1, Y2, U0, U1])
theta, *_ = np.linalg.lstsq(Phi, Yp, rcond=None)
print("ARX 系数 [a1,a2,b0,b1] =", np.round(theta.ravel(),3))
# 用 ARX 自回归预测, 对比真 y
ypred=np.zeros_like(y); ypred[:k]=y[:k]
for n in range(k, N-1):
```

### 实验 6：练习 18.1 —— L2 vs L1 vs L∞，看"离群点"谁扛得住（可跑，对照练习 18.1）

```python
import numpy as np
from scipy.optimize import linprog
rng = np.random.default_rng(4)
# 真 A,B (标量简化: x_{n+1}=a x_n + b u_n)
a_true, b_true = 0.8, 1.0
N=100; u=rng.uniform(-1,1,N); x=np.zeros(N+1)
for n in range(N): x[n+1]=a_true*x[n]+b_true*u[n]+0.05*rng.randn()
# 加几个离群点 (坏数据)
x[20]+=5.0; x[60]-=4.0
Phi=np.column_stack([x[:-1], u]); target=x[1:]
# (a) L2
ab_L2, *_ = np.linalg.lstsq(Phi, target, rcond=None)
# (c) L1 = min Σ|resid| -> LP: min Σ t_i s.t. -t<=resid<=t, resid=Phi@ab-target
n_par=2; t=np.zeros(N)
# 变量 [ab(2); t(N)]
c=np.hstack([np.zeros(n_par), np.ones(N)])
# Phi@ab - target <= t  ->  [Phi, -I][ab;t] <= target
# -(Phi@ab - target) <= t -> [-Phi, -I][ab;t] <= -target
I=np.eye(N)
Aub=np.block([[Phi, -I],[-Phi, -I]]); bub=np.hstack([target, -target])
res=linprog(c, A_ub=Aub, b_ub=bub, bounds=(None,None), method='highs')
ab_L1=res.x[:n_par]
# (b) L∞ = min max|resid| -> LP: min t s.t. -t<=resid<=t (标量 t)
c2=np.hstack([np.zeros(n_par), [1.0]])
Aub2=np.block([[Phi, -np.ones((N,1))],[-Phi, -np.ones((N,1))]]); bub2=np.hstack([target,-target])
res2=linprog(c2, A_ub=Aub2, b_ub=bub2, bounds=(None,None), method='highs')
ab_Linf=res2.x[:n_par]
print("真 [a,b]      =", [a_true, b_true])
print("L2  (怕离群)  =", np.round(ab_L2,3))
print("L1  (抗离群)  =", np.round(ab_L1,3))
print("L∞ (控最差步) =", np.round(ab_Linf,3))
```

**你会看到**：**加了两个离群点后，L2 被明显带歪，L1 仍然接近真值**——**亲手见"L1 对异常值鲁棒"**。**去掉离群点重跑，三者都准**——**体会"数据干净时 L2 最好，数据脏时 L1 救命"**。

### 实验 7：Drake 符号 lumped 分解 + 参数估计骨架（对照 Example 18.4/18.5）


### 实验 8：加激励信号救秩亏（对照 Example 18.6，必跑）

**复现"只用 LQR 数据 → 秩亏；加 $0.1\sin t$ → 满秩"**。

```python
import numpy as np
# 简化: 线性系统 x_{n+1}=A x_n + B u_n, 用"很弱的控制"收集数据, 看 W 秩
A=np.array([[1,0.1],[0,1]]); B=np.array([[0],[0.1]])   # 双积分器离散
n=2
def collect(excite):
    rng=np.random.default_rng(5); x=np.array([0.05,0.0]); N=300; Xs=[]; Us=[]
    K=np.array([[0.5,0.8]])   # 一个"够稳但太温柔"的反馈
    for _ in range(N):
        u = -K@x + (excite*0.1*np.sin(0.3*_) if excite else 0) + 0.001*rng.randn(1)
        Xs.append(x.copy()); Us.append(u.copy()); x = A@x + B@u
    X=np.hstack(Xs); U=np.hstack(Us)
    W=np.vstack([X, U])
    return np.linalg.matrix_rank(W, tol=1e-6)
print("无激励 数据矩阵秩 =", collect(False), " (满秩应=3; 秩亏->估不准!)")
print("加0.1sin激励 秩   =", collect(True),  " (满秩->能估真A,B)")
```

**你会看到**：**无激励时秩 < 3（秩亏），加激励后满秩**——**亲手复现 Example 18.6 的"教训"**：**"数据太乖 = 没信息，得主动抖一下"**。**这就是辨识里"探索"的物理版**。

## 给初学者的"本章通关三句话"

1. **从"拿图纸"到"反推图纸"**：前面所有章节假设模型已知，本章承认现实——**模型要从数据里"听"出来**；**而"听"的第一步是分清"方程误差"（逐帧对齐，好算但长期会漂）和"仿真误差"（整段对齐，才是真目标）**，**并用 regret 公平评价"在模型类能力内，我学得有多好"**。
2. **机械系统辨识的杀手锏 = 逆动力学对参数线性**：**别用正动力学（要除 $M$，非线性）做回归，用逆动力学 $W\alpha+w_0=0$（线性回归，凸！）**；**惯性用 10 个密度加权矩 $(m,h,\Sigma)$ 参数化，物理有效性打包成"伪惯性 $J\succ0$"一条 SDP 约束**；**而且你只能估出"lumped 组合"（如 $ml^2$），估不出个体（$m,l$）——这不是缺陷，是"控制只需要组合"的事实**；**再加"能量法少微分一次、残差物理补尾巴、实验设计让 $W$ 满秩"，就是一套完整的机械辨识流水线**。
3. **线性/MDP/神经网络是三根补充支柱，而"对控制有用"才是终极标准**：**线性系统用 Ho-Kalman 从"脉冲响应指纹"反推平衡实现、ARX 用历史直接预测；有限 MDP 靠"数次数"；神经网络拟合强但"在它上面做控制"仍弱**——**所以最终极的洞察是"预测得准 ≠ 对控制有用"**：**好表示要"可观 + 够决策 + 好算"，AIS 用"能预测奖励 + 能预测自己下一步"打破了"辨识与控制"的鸡和蛋，bisimulation/MuZero 则按"未来行为等价"压缩状态**——**它们共同回答了一个比"拟合得准"更深的问题：什么样的模型，才值得用来做决策？**
