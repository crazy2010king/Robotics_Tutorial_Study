这张图片来自 **MIT《Underactuated Robotics》课程讲义**中的 **1.2 Definitions（定义）**部分。

它看起来是在讲一个非常数学化的概念：

> **什么是欠驱动系统（Underactuated System）？**

但是这个概念实际上是理解：

* 人形机器人为什么难；
* 四足机器人为什么比机械臂复杂；
* 为什么 Tesla Optimus、Atlas、宇树机器人不能简单照搬工业机械臂控制；
* 为什么 Russ Tedrake（Drake 创始人）一直强调动力学、接触、优化控制；

的核心入口。

下面我会完全从普通人的角度开始，然后逐步深入公式。

---

# 一、先建立一个直觉：机器人到底是什么？

想象一个机器人。

例如：

## 工业机械臂

比如：

ABB 六轴机械臂：

```
       手爪
        |
       J6
        |
       J5
        |
       J4
        |
       J3
        |
       J2
        |
       J1
        |
       底座
```

它有：

6个关节。

每个关节：

一个电机。

也就是说：

机器人有：

```
6个自由运动方向

↓

6个电机控制
```

这叫：

## Fully Actuated（全驱动）

简单理解：

> 每一个想动的地方，都有一个电机直接管。

# 二、人形机器人为什么困难？

看看人：

人有：

* 手臂
* 腿
* 身体
* 脚

但是：

人走路不是靠：

每个自由度一个电机。

比如：

人在站立：

你不是：

```
脚踝电机
膝盖电机
髋关节电机

精确计算角度
```

然后站起来。

实际上：

你不断：

* 摇摆身体
* 调整重心
* 利用惯性
* 利用地面反作用力

这就是：

## 欠驱动（Underactuated）

---

# 三、第一句话是什么意思？

图片第一段：

> According to Newton, the dynamics of mechanical systems are second order

翻译：

> 根据牛顿力学，机械系统的动力学通常是二阶的。

为什么？

因为：

牛顿第二定律：

[
F=ma
]

力：

决定：

加速度。

而：

加速度：

是位置的二阶导数。

---

例如：

汽车：

位置：

[
q
]

速度：

[
\dot q
]

加速度：

[
\ddot q
]

关系：

```
位置
 |
求导
 |
速度
 |
求导
 |
加速度
```

所以：

机器人动力学天然是：

[
\ddot q=f(q,\dot q,u,t)
]

---

# 四、这个公式到底是什么意思？

核心公式：

[
\boxed{\ddot q=f(q,\dot q,u,t)}
]

我们逐个拆。

---

## 1. q 是什么？

图片：

> vector of positions, q

q：

叫：

配置向量（configuration vector）

简单：

就是：

机器人当前姿态。

例如：

机械臂：

6个关节：

[
q=
\begin{bmatrix}
q_1\
q_2\
q_3\
q_4\
q_5\
q_6
\end{bmatrix}
]

比如：

```
q1=30°

q2=50°

q3=-20°
```

描述：

机械臂现在是什么形状。

---

人形机器人：

例如：

34自由度：

[
q=
[
腰角度,
腿角度,
手臂角度...
]
]

---

## 2. \dot q 是什么？

读：

q 点。

表示：

速度。

例如：

机械臂：

当前：

q1=30°

但是：

正在：

每秒增加5°。

那么：

[
\dot q=5^\circ/s
]

---

## 3. \ddot q 是什么？

读：

q 二阶导。

表示：

加速度。

例如：

电机突然加力：

速度变化。

---

所以：

整个系统：

```
现在姿态 q

+
现在速度 q点

+
控制输入 u


决定未来加速度 q二点
```

---

# 五、u 是什么？

图片：

> u is the control vector

意思：

控制输入。

简单：

机器人可以主动控制的东西。

例如：

机械臂：

u：

就是：

电机力矩。

例如：

```
电机1 输出 5Nm

电机2 输出 8Nm
```

组成：

[
u
]

---

# 六、完整理解公式

[
\ddot q=f(q,\dot q,u,t)
]

普通语言：

> 一个机器人的未来运动状态，由它现在的位置、速度、电机施加的力量以及时间共同决定。

类似：

开车：

未来速度：

取决于：

* 当前速度
* 当前方向
* 油门
* 时间

# 七、重点来了：什么叫 Fully Actuated？

图片定义：

> fully actuated if the resulting map f is surjective

这个数学表达比较难。

我们先不用数学。

假设：

机器人：

有：

6个关节。

你希望：

产生：

任意方向的运动。

例如：

想让：

```
手向上

腿向前

身体旋转
```

如果：

电机完全能够做到。

那么：

全驱动。

---

数学：

[
\ddot q=f(q,\dot q,u,t)
]

意思：

输入：

u

经过：

系统：

产生：

[
\ddot q
]

如果：

任何你想要的加速度：

都有一个u可以实现。

那么：

Fully Actuated。

---

简单：

```
你想怎么动

↓

电机都能实现
```

# 八、什么叫 Underactuated？

图片：

> Otherwise it is underactuated

意思：

否则：

欠驱动。

---

简单：

你想：

```
身体向左移动
```

但是：

你的机器人：

没有对应电机。

只能：

通过间接方式。

---

例子：

## 倒立摆

最经典。

一个杆：

下面一个小车。

```
    |
    |
    |
   人
---------
  小车
```

小车：

左右运动。

杆：

没有电机。

但是：

通过移动小车：

让杆保持平衡。

---

问题：

电机：

控制：

小车。

但是：

目标：

控制：

杆。

这就是：

欠驱动。

```
接触力
```

---

所以：

人形机器人不是：

机械臂问题。

而是：

动力学问题。

# 十、第二个重要公式

图片：

[
\ddot q
=======

f_1(q,\dot q,t)
+
f_2(q,\dot q,t)u
]

这个非常重要。

它叫：

## 控制仿射系统（Control Affine System）

什么意思？

机器人运动：

分成两部分。

---

## 第一部分：

[
f_1(q,\dot q,t)
]

叫：

自然动力。

没有电机。

比如：

* 重力
* 摩擦
* 惯性

例如：

球：

自然往下掉。

---

## 第二部分：

[
f_2(q,\dot q,t)u
]

叫：

控制影响。

也就是：

电机。

---

完整：

```
机器人运动

=

自然物理规律

+

电机作用
```

---

# 十一、为什么要拆成这样？

因为机器人控制的核心问题：

不是：

"怎么控制电机"

而是：

> 如何利用自然动力，让机器人完成动作。

---

例如：

人走路：

不是：

腿电机不停输出。

而是：

利用：

* 重力
* 摆动
* 惯性

降低能耗。

---

# 十二、关键判断：rank(f2)<dim[q]

这是全文最核心数学判断。

图片：

[
rank[f_2(q,\dot q)]<dim[q]
]

是什么意思？

---

先解释：

## dim[q]

机器人自由度。

例如：

机械臂：

6自由度。

那么：

[
dim(q)=6
]

---

## rank

简单理解：

控制能力数量。

例如：

6个电机：

可以控制6个方向。

rank=6。

---

如果：

机器人：

6自由度。

但是：

只有4个有效控制方向。

那么：

[
rank=4
]

于是：

[
4<6
]

欠驱动。
