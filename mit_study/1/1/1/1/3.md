### 先补最基础的高中物理背景
我们所有人只要学过都记得牛顿第二定律 `F=ma`：力F会让质量为m的东西产生加速度a（加速度的意思就是速度变化有多快）。凡是会动的硬东西——飞机、电动车、工厂里的机械臂、平衡车、机器狗、甚至你扔出去的石头、晃秋千的你——都属于「机械系统」，它们的运动本质都能用这个定律算出来。
---
### 先懂第一个核心通用公式 (1)：机器人运动的底层规则
论文开头的公式 `ü = f(q, q̇, u, t)` 就是把牛顿定律翻译成机器人的语言：
- `ü` 是一堆**加速度**排成的列向量：你可以理解成把机器人身上每个要动的部件的加速度都放进一个列表里。
- `q` 是**位置向量**：是一堆数字组成的列表，用来描述机器人当前到底长啥样、在哪——比如机械臂的三个关节分别转了多大角度、平衡车的两个轮子各转了多少圈/车身歪了多少度、无人机在坐标系里的x/y/z坐标和三个转动角度……所有能唯一确定当前机器人状态的所有参数加起来就是`q`。
- `q ̇` 是**速度向量**：就是位置q随时间变化的快慢，带一个点的符号在数学里代表求导/随时间变化率。
- `u` 是**控制指令向量**：是你发给机器人的命令——比如给电机发的扭矩、给轮子发的推力、给无人机风扇发的转速等你能主动给的调节量。
- `t` 是时间。
- `f()` 是一个通用的函数规则：你把上面这些参数（当前在哪、现在动多快、给了什么指令、当前时间）输进去，它就能直接算出整个系统的加速度ü——相当于给出了机器人运动的「底层物理规则」。
举个极简单的例子：你把一辆静止的电动车往前拧油门（给了控制指令u），把`q`=当前车速0、`q̇`=当前速度0、`t`=拧油门的时刻输进去`f`就能算出加速的加速度`ü`。

### 接下来搞懂两个核心概念：完全驱动 vs 欠驱动
这两个概念非常好懂：
#### ✅ 什么叫完全驱动？
把你想象成你想让机器人实现的**所有想要的运动效果**列成一个清单：
如果**无论你要什么效果/姿势/运动方式**只要想得出来总能找到一套对应的控制指令`u`来实现——那就是完全驱动。
举个最常见的例子：工厂里焊东西的6轴机械臂。
它有6个关节每个关节都有一个独立的电机；你想要它手臂转到什么角度、焊枪端到哪个空间位置/焊枪倾斜角度是多少……只要你能想到的姿态/轨迹只要你设计控制器的时候总能编出一套对应的6个电机的扭矩值`u`就能让机械臂精准到你想要的任何效果——这就是典型的完全驱动系统。
#### ❌ 什么叫欠驱动？
反过来如果需要实现的**想要的运动效果清单里的内容**比你能给的指令`u`的种类/数量要多——你不可能通过直接发指令实现所有想要的效果——那就是欠驱动。
举几个普通人天天见的例子：
1.  两轮自平衡车：它只有两个轮子的电机可以发指令`u`（左轮转多快/右轮转多快两个控制量）；但你想让它实现的运动效果有三个独立维度：「①两个轮子的转速 + ②机身向左/右歪的角度 + ③机身向前/后歪的角度」。你想让车头抬起来？没有电机直接推车头啊！你只能靠调整左右轮的转速差让车子往前拱才能间接实现车头抬起来的效果——你可以控制的维度只有2个但想要的运动效果有3个维度不可能直接实现所有想要的姿态这就是欠驱动系统。
2.  机器狗/四足机器人：很多机器狗每条腿有3个关节一共12个关节但同时最多只有8个电机有的关节是没有电机的被动关节只能跟着动没法直接控制这些关节的角度你想要抬腿/走路的动作没法直接精准控制所有关节的角度只能靠协调剩下的带电机的关节的运动来实现这也是欠驱动。
3.  人走路本身就是天生的顶级欠驱动系统：你能感知自己想迈多长的腿、脚抬多高、身体往哪歪这些想要的效果但你只能通过大腿肌肉/小腿肌肉/胯部肌肉这些控制量来实现没法直接精准控制每一个关节的角度靠的是身体的平衡协调能力才走得了路这也是欠驱动的体现。

这就是论文第一个框里的「定义1.1」的核心意思：
> 如果对于任意你想要的目标姿态/运动效果（desired response），总能找到一组`u`让它实现→完全驱动；否则→欠驱动。
另外框右边的备注是说这个规则不仅能用在连续运动的实体机器人上还能用在一个一个跳变的离散系统比如手机触控系统、机器人走一步再走下一步的步态系统也能套这个概念。

### 第二个核心公式 (2)：为什么要把通用规则拆成两部分？
论文里说大部分我们关心的机器人在固定姿态下动态是线性的：你给的控制力矩越大额外产生的加速度就成比例变没有乱七八糟的相互作用；而且如果位置/速度/时间都固定的话运动规律也满足线性特性为了方便我们算怎么让机器人听我们话要把通用公式拆成两部分：
$$
\ddot{\mathbf{q}} = \underbrace{\mathbf{f_1(q,\dot{q},t)}_{\text{「无指令时的固有运动」}}}_{\text{这部分是你什么都不发指令时机器人自己会有的加速度}} + \underbrace{\mathbf{f_2(q,\dot{q},t) \cdot u}_{\text{「你发指令带来的额外运动」}}}_{\text{这部分是你发指令后额外产生的线性加速度}}
$$
还是拿两轮平衡车举例子：
- `f1`部分：如果你不给任何控制指令把平衡车放在那不动它会自己因为歪倒产生的加速度——不用你管它自己就会倒的那个加速度就是`f1`算出来的。
- `f2·u`部分：你给的左右轮电机的扭矩各自产生什么额外的加速度的组合就是你发`u`之后产生的效果这部分和你的`u`成正比给你两倍的扭矩就多两倍的额外加速度。
这个拆分的好处是设计控制器的时候不用从头算整个物理规则只需要分别处理「固定的固有部分」和「我可以控制的线性部分」就行非常方便。
---
### 第三个核心公式 (3)：欠驱动的数学本质
$$
\mathrm{rank}\left[\mathbf{f_2(q,\dot{q},t)}\right] < \mathrm{dim}[\mathbf{q}]
$$
这行看起来专业的话其实是说透了欠驱动的本质我们把每个词都拆成大白话：
- `f2`是一个**矩阵**你可以理解成一个「转换表」：它列出来你给的每个控制指令`u`分别会对机器人的各个部分的加速度产生多大的影响。还是拿平衡车举例子你的`u`是两个电机的扭矩左轮扭矩和右轮扭矩；`q`有三个部分左轮转速右轮转速车身倾角。那你的`f2转换表`长这样：
| | 左轮扭矩`u1` | 右轮扭矩`u2` |
| ---- | ---- | ---- |
| 左轮转速的影响 | 很高 | 无 |
| 右轮转速的影响 | 无 | 很高 |
| 车身倾角的影响 | 无 | 无 |
- `rank[矩阵]`你可以理解成这个转换表最多能提供**多少个独立的、互不影响的作用**。上面的转换表只有左轮转速和右轮转速两行是独立的有用的最多只有2个独立的作用所以秩rank=2。
- `dim[q]`是你需要多少个独立的数字才能完全描述机器人的当前状态：刚才的平衡车的`q`有左轮转速+右轮转速+车身倾角一共3个数字所以dim[q]=3。

所以这行公式的意思翻译成大白话就是：
> 「你能发的控制指令最多能产生多少个独立的效果」 < 「描述机器人当前状态一共需要多少个数字」
说白了**你能控制的维度比机器人本身的运动维度少**——这就是欠驱动的唯一硬性判定标准！
刚才说的平衡车：能控制的只有轮的转速2个维度但是要描述完整的机器人的状态需要3个数字23<3满足公式(3)所以是欠驱动的。而前面的6轴机械臂有6个电机6个控制量需要6个参数描述状态66不满足小于所以是完全驱动的。

论文里还说这个式子只是单向约束：
满足它肯定是欠驱动的没错但**不满足它也不一定是完全驱动**：
举个例子你设计了一个90公斤级的工业机械臂有6个关节6个电机理论上`rank[f2]=6=dim[q]`是完全驱动的但你给它加了限制说每个电机的最大输出扭矩只能是10N现在要让它举100公斤的大铁块就算6个电机都开到最大力也举不起来——你想要的效果实现不了所以也算不上完全驱动。就像一辆车理论上有200马力但油门锁死最多只能踩到相当于100马力的程度虽然结构上是可以输出200匹马力的全驱车但实际上只能发挥一半的性能也算达不到想要的效果属于边界情况。

### 后面的几个容易混淆的点
#### 1. 「system」指的不是实体机器人而是数学模型
同一台实体机器人的模型可以是完全驱动也可以是欠驱动的完全看你怎么建模：
还是拿两连杆的机械臂举例子：
- 如果你把杆子当成绝对没有弯曲可能的刚体：只需要用「两个关节的角度」两个参数就能完全描述它的当前状态两个轴的电机刚好对应两个控制量`rank=dim=2`这时候模型是完全驱动的。
- 如果你考虑杆子是有韧性的用手掰会弯一点弯的程度也会影响它的运动：那你就要加额外的参数「第一根杆弯了多少」「第二根杆弯了多少」来描述现在的状态现在需要4个参数才能描述完整的状态但还是只有两个电机的控制器就算`rank=4>dim[q]`这时候模型就变成欠驱动的了。
也就是说**同一台硬件underactuation是模型的属性不是实物本身的性质**。

#### 2. 即使看起来是全驱的系统也可能是隐性的欠驱动
论文里提到大部分系统（包括书里的大多数内容）的underactuation是一个全局属性：
- 哪怕一个设计为完全驱动的系统也可能有关节限位（比如机械臂某个关节最多只能转到180度再也不能动了）或者需要避免共振振动的情况这时候有些状态你就是达不到也不会被归为完全全要求所有状态所有时间都能达到才算全驱。
特殊情况也是一种「灰区」不好硬归为完全或欠驱动。

#### 3. 为什么我们要研究欠驱动系统？
看起来好像全驱更厉害为什么还要专门研究又穷又不够用的欠驱动系统？
原因太实际了：
- **省钱省重量省电**：让多的没用啊！你要做一台12关节的机器狗如果每个关节都装一个电机得多少钱多重续航多久？如果只装8个电机牺牲一点点完美的姿态能力成本能降一半重量轻一倍电池能用三倍性价比直接拉满更轻量便宜的机器人才能大规模卖出去用到普通人的生活里除了机器狗无人机也是典型的大量的无人机只需要4个风扇电机就能实现6自由度的飞行也是典型的欠驱动系统所以才这么便宜普及；
- **耐用性更好**：零件越少越不容易坏少几个电机的机器狗摔了也更不容易坏成本也更低维修也便宜；
- **有些场景只能做欠驱动**比如人类的两条腿走路如果每个肌肉单独接一个控制器基本不可能所以我们只能用算法去协调有限的几个大的肌群来控制走路本质上也是设计欠驱动的控制器来实现目标效果。

市面上卖的普通机器人群体力其实大部分都是在解决有限的控制能力怎么实现尽可能好的效果的问题也就是在解决欠驱动下的最优控制问题这才是这本书研究的核心意义！
