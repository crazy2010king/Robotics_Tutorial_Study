# 零基础大白话完整讲解1.4 输入与状态约束整页内容
## 前置必懂基础（不看懂这些完全读不懂全文）
### 1. 核心符号统一通俗翻译
1. $\boldsymbol{x}$：机器人**完整状态**，= 所有关节位置$\boldsymbol{q}$ + 所有关节速度$\dot{\boldsymbol{q}}$，$\dot{\boldsymbol{x}}$就是状态的变化速度（加速度层面）
2. $\boldsymbol{q}$：单纯位置/姿态（小车坐标、摆杆角度、汽车朝向）
3. $\dot{\boldsymbol{q}}$：位置变化快慢（移动速度、转动角速度）
4. $\boldsymbol{u}$：电机控制输入（电机扭力、电机推力、汽车油门力度）
5. $\phi(\dots) \ge 0$ / $\phi(\dots)=0$：约束条件，**硬性限制**，机器人绝对不能突破这条规则

### 2. 两个前置核心概念回顾
1. **欠驱动**：电机数量 < 可自由活动的自由度，电机没法随心所欲控制每一个运动方向
2. 全驱动：电机数量刚好匹配自由度，理论上想让机器人朝任何方向加速都能做到

### 3. 两类基础约束大白话区分
- **输入约束**：只限制电机$\boldsymbol{u}$，电机出力有物理上限，比如电机最大只能拧10牛米，不能无限发力
- **状态约束**：只限制位置$\boldsymbol{q}$，机器人不能撞到障碍物，不能跑到墙里面

# 第一大块：开篇总述 + 定义1.2（输入、状态约束通用定义）
## 1. 开篇一句话人话
就算电机数量足够（硬件全驱动），现实机器人依然有各种硬性物理限制，照样不好控制：
1. 电机力气有上限，不能无限发力；
2. 空间里有墙、障碍物，机器人不能撞上去。
这些限制统一叫**约束**，会大幅增加控制难度。

## 2. Definition 1.2 通用约束定义
原文公式：系统运动规则 $\dot{\boldsymbol{x}} = f(\boldsymbol{x},\boldsymbol{u},t)$，同时必须满足至少一条硬性限制 $\phi(\boldsymbol{x},\boldsymbol{u},t) \ge 0$
### 逐段大白话拆解
1. $\dot{\boldsymbol{x}} = f(\boldsymbol{x},\boldsymbol{u},t)$：机器人正常运动规律
   机器人下一秒的状态变化，由现在的位置速度、电机出力、时间共同决定（之前双摆动力学公式本质就是这个）
2. $\phi(\boldsymbol{x},\boldsymbol{u},t) \ge 0$：所有硬性约束的通用数学写法
   括号里是约束要检查的内容，$\ge0$代表**合法区间**；一旦算出来数值小于0，代表机器人违反物理规则，属于不允许的行为。

### 两种拆分约束（方便工程师分开处理）
#### ① 仅输入约束 $\phi(\boldsymbol{u}) \ge 0$：只限制电机出力
例子：电机最大扭力10，最小扭力-10，约束写成 $10-|u|\ge0$
特点：只跟电机有关，和机器人在哪、跑多快无关，处理起来最简单。

#### ② 仅状态约束 $\phi(\boldsymbol{q}) \ge 0$：只限制机器人位置
例子：机器人离墙面至少0.5米，约束写成「机器人x坐标 - 墙的x坐标 - 0.5 ≥ 0」
特点：只看机器人现在在哪，不管电机开多大、跑多快，防止碰撞障碍物。

## 3. 关键核心结论（黄色高亮文字重点）
1. **输入约束也能让“硬件全驱动机器人”变成实际欠驱动**
举个简单例子：一台理论全驱动小车，电机理论能随便加速，但电机最大推力有限，想让小车瞬间超高速加速，电机力气不够，做不到，等效于欠驱动。
2. **位置等式约束（硬卡死的位置限制）**
比如机器人被轨道牢牢卡住，只能沿轨道走，会直接减少机器人能自由活动的维度；
这种系统想要完美控制，依然需要和自由度数量匹配的电机；
但只有把坐标换成“轨道专属最小坐标”，控制才会变简单，而这套坐标转换通常非常难算。

# 第二大块 Example 1.3 输入限制案例（最简单二阶系统带电机上限）
## 1. 案例公式
$$\ddot{x} = u,\quad |u| \le 1$$
### 逐句通俗拆解公式
1. $\ddot{x}=u$：极简小车模型，电机推力$u$直接等于小车加速度，**硬件是完全驱动**（只有1个自由度x，1台电机u）
2. $|u| \le 1$：输入约束，电机推力绝对值不能超过1，最大加速1，最大减速-1。

## 2. 为什么带约束后，实际变成欠驱动效果？
原文举例：我们想让小车瞬间加速度$\ddot{x}=2$（猛地往前冲）
公式要求$u=2$，但约束$|u|\le1$不允许电机输出2，**无论怎么调电机，都达不到想要的加速效果**。
人话总结：哪怕硬件电机数量足够，只要电机出力有上限，能实现的运动轨迹会变少，和天生少电机的欠驱动系统一样难控制。

## 3. 通用总结
输入约束、状态约束，都会缩小机器人能实现的运动路线范围；解决思路、控制算法，和处理天生欠驱动系统高度相似。

# 第三大块 1.4.1 非完整约束 Nonholonomic constraints（全文最难理解部分，超通俗拆解）
## 前置核心区分两个专业词（必看懂）
### 1. 完整约束（holonomic 完整约束）
约束**只限制位置$\boldsymbol{q}$**，完全不看速度$\dot{\boldsymbol{q}}$；
可以直接写成只包含位置的等式/不等式，能直接减少机器人自由度。
例子：火车轨道，火车永远只能卡在铁轨上，没法离开轨道，直接减少2个自由度。

### 2. 非完整约束（nonholonomic 非完整约束）
1. 约束必须带速度$\dot{\boldsymbol{q}}$，形式：$\phi(\boldsymbol{q},\dot{\boldsymbol{q}},t)=0$
2. **关键特点**：没法消掉速度、转换成只关于位置$\boldsymbol{q}$的约束
3. 不会减少机器人能抵达的位置，只会限制「移动方式」：所有坐标点都能到达，但不能直接横着走、斜着走。

### 一句话分清两者
- 完整约束：限制你**能去哪**；
- 非完整约束：不限制你能去哪，只限制你**怎么走过去**。

## 核心结论：非完整约束不会减少自由度，完整约束会减少自由度
- 火车轨道（完整约束）：只能沿轨道走，能抵达的地点变少，自由度下降；
- 普通家用小汽车（非完整约束）：全世界任意坐标都能开到，只是不能直接横向平移，自由度不变。

## Example 1.4 轮式小车（汽车）完整案例，逐公式拆解
### 1. 小车位置定义
小车坐标 $\boldsymbol{q}=[x,y,\theta]^T$
- $x$：小车水平左右坐标
- $y$：小车竖直前后坐标
- $\theta$：小车车头朝向角度（0度朝右，90度朝上）
总共有3个位置自由度。

### 2. 无侧滑约束（汽车不能横向漂移，非完整约束核心公式）
汽车轮子只能沿着车头朝向滚动，不能横着滑，由此推出3组等价公式：
#### 公式1 速度分解形式
$$
\begin{cases}
\dot{x} = v\cos\theta \\
\dot{y} = v\sin\theta
\end{cases}
$$
人话翻译：
- $\dot{x}$：小车左右移动速度；$v$：车轮滚动前进速度；$\cos\theta$把前进速度投影到x方向
- $\dot{y}$：小车前后移动速度；$\sin\theta$把前进速度投影到y方向
逻辑：小车所有移动速度，只能来自车头朝向的滚动，不能凭空产生横向速度。

#### 公式2 整合等价等式（去掉速度v）
$$\dot{y}\cos\theta - \dot{x}\sin\theta = 0$$
#### 大白话解读这条核心约束
$\dot{y}\cos\theta$ = 前后速度投影到车头垂直方向
$\dot{x}\sin\theta$ = 左右速度投影到车头垂直方向
两者相减等于0，代表**垂直于车头方向的速度必须等于0**，也就是不能横向打滑。

### 3. 为什么这是非完整约束？
这条公式里面同时包含位置$\theta$、速度$\dot{x},\dot{y}$，**没办法只写成x、y、θ三个位置的等式**：
不存在一个只含$x,y,\theta$的等式，能等价代替这条速度约束。
物理直观证据：汽车能开到地面任意(x,y,θ)位置，只是不能横着直接挪过去；你可以前后倒车、转弯绕路抵达任意点，没有地点去不了。

### 4. 和火车轨道（完整约束）对比，一眼分清
火车轨道约束可以直接写成只关于位置的等式：$y=f(x)$，火车永远不能脱离这条曲线，大量地点根本到不了，直接减少自由度，是完整约束。

## 5. 两个关键双向逻辑（黄色高亮重点）
1. **带非完整约束的系统，一定是欠驱动**
家用小车例子：3个位置自由度(x,y,θ)，只有2个电机控制（油门v、方向盘转角），电机数量少于自由度，属于欠驱动；且非完整约束进一步限制运动方式。
2. **反过来不成立：欠驱动系统不一定是非完整系统**
双摆就是完美反例：双摆少一台电机属于欠驱动，但它没有任何速度层面的非完整约束，运动约束只来自动力学$M\ddot q+C\dot q=\tau_g+Bu$，形式是$\phi(\boldsymbol{q},\dot{\boldsymbol{q}},\ddot{\boldsymbol{q}},\boldsymbol{u},t)=0$，不是一阶速度约束，不属于非完整系统。

## 6. 补充说明拉格朗日动力学方程
双摆、机械臂的动力学约束，里面包含位置、速度、加速度、电机输入，是二阶复杂约束，不符合非完整约束「仅位置+一阶速度」的简单形式，所以不算非完整系统。

# 全文整体逻辑一条线通俗总结
1. 现实机器人除了“电机不够”这种欠驱动，还有两类硬性限制：电机出力上限（输入约束）、不能撞墙（状态约束）；哪怕电机数量够，这些限制也会让机器人变难控制，等效欠驱动。
2. 约束分两种大类：完整约束直接限制能去哪，永久减少自由度；非完整约束不限制抵达地点，只限制移动路线，不会减少自由度。
3. 家用小汽车是典型非完整系统：能开到任意地点，但不能横向漂移，自带欠驱动属性；
4. 欠驱动和非完整不是一回事：所有非完整系统都是欠驱动，但少电机的欠驱动系统（双摆）不一定是非完整系统，区分核心看约束是否只带位置+一阶速度。
