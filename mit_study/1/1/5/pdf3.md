## 5.1 思想实验：从航天器到行走机器人

### 5.1.1 航天器模型：一切从"推"开始

想象一个**刚体航天器**，在重力场中飞行，身上装了若干个推进器（thrusters）。

**状态**：位置 $(x,z)$ + 朝向 $\theta$

**动力学方程**：
- 水平方向：$m\ddot{x} = \sum f_{i,x}^W$（所有推力的水平分量之和）
- 垂直方向：$m\ddot{z} = \sum f_{i,z}^W - mg$（推力向上减重力）
- 旋转方向：$I\ddot{\theta} = \sum (r_i \times f_i)_y$（推力产生的力矩）

> 🚀 **类比**：这就像一个装了多个小火箭的太空舱。你可以通过调整每个火箭的推力大小和方向，控制舱体的位置、高度和姿态。如果推进器足够多、约束足够简单（比如推力有上下限），这就是一个**相对容易**的控制问题——用线性化+LQR或MPC就能搞定。

**现在增加难度**：

假设只有**两个**推进器，而且：
1. 推进器可以**移动位置**（$r_i$ 变成控制量）
2. 但**移动时必须关闭**（$f_i = 0$ 当 $\dot{r}_i \neq 0$）
3. 移动速度有限制（$|\dot{r}_i| \leq v_{max}$）

> 🎮 **类比**：想象你玩一个太空游戏，但你的飞船只有两个可伸缩的炮管。你想调整炮管角度时必须先熄火，调整完才能重新开火。而且炮管转得不能太快。这下问题变得复杂了——你需要做**离散决策**（什么时候关/开）和**连续控制**（推力多大）的混合。

**再增加难度**：

推进器只能在**特定区域**开启（比如灰色方块内）。

> 🦶 **类比**：这就像你的脚只能踩在地面上特定位置。即使每个区域本身是凸的，它们的**并集**可能不是凸的。而且约束是在**世界坐标系**中表达的，不是随机器人一起转的。

### 5.1.2 带无质量腿的机器人：脚就是推进器

现在把上面的航天器想象成**机器人的躯干**，推进器想象成**脚**。

> 🦿 **核心洞察**：如果把行走机器人的腿看成**无质量的连杆**，那么脚对地面的作用力，本质上就是航天器的**推进器**！
> - 脚只能在地上时产生力（推进器只能在特定区域开启）
> - 脚在空中时可以自由移动（推进器移动时关闭）
> - 脚移动速度受关节速度限制（推进器移动速度受限）

**约束条件**：
- **只能推不能拉**：$f_{i,z} \geq 0$（地面只能向上推你，不能向下拉你）
- **摩擦锥**：$|f_{i,x}| \leq \mu f_{i,z}$（水平力不能超过垂直力的μ倍，否则会打滑）

> 🧊 **类比**：想象你在冰面上走路。冰的摩擦系数μ很小，所以你的脚不能施加太大的水平力，否则就会打滑摔个四脚朝天。摩擦锥就是告诉你："在这个地面上，你的脚能提供的水平推力是有上限的。"

**关键结论**：虽然腿的运动学和动力学约束很复杂，但**躯干（质心）的动力学仍然很简单**——它就是一个受外力作用的刚体！

## 5.2 压力中心（CoP）与零力矩点（ZMP）

### 5.2.1 平地特殊情况

当机器人在**平地**上行走时，即使同时有多个接触点（比如两脚各有两个接触点），所有接触力可以**等效**为一个非常有用的量。

#### 只能推不能拉的后果

因为每个接触点的垂直力 $f_{i,z} \geq 0$，所以总和也 $\geq 0$：

$$\sum_i f_{i,z} \geq 0 \Rightarrow m\ddot{z} + mg \geq 0 \Rightarrow \ddot{z} \geq -g$$

> 🌍 **直观**：你不能拉地面，所以你的质心向下加速度不可能超过重力加速度。即使你全身肌肉一起往上跳，你也不能让自己"比自由落体更快地砸向地面"——因为地面不会拉你。

#### 摩擦锥的后果

$$|\ddot{x}| \leq \mu(\ddot{z} + g)$$

如果保持质心高度不变（$\ddot{z} = 0$），则：
$$|\ddot{x}| \leq \mu g$$

> 🏃 **直观**：这就是为什么在冰面上（μ≈0.1）你几乎无法加速跑，而在橡胶跑道上（μ≈1）你可以全力冲刺。摩擦直接限制了你的水平加速度。

#### 压力中心（CoP）的定义

把所有接触力"压缩"到地面上的一个点：

$$x_{cp} = \frac{\sum_i p_{i,x} \cdot f_{i,z}}{\sum_i f_{i,z}}$$

> 🎯 **类比**：想象你站在体重秤上，但秤有无数个传感器。CoP就是所有传感器读数的"加权平均位置"——你身体重心在地面上的投影点。如果你单脚站立，CoP就在那只脚下面；如果你双脚站立，CoP在两脚之间。

#### 神奇的ZMP方程

通过力矩平衡，可以推导出：

$$(m\ddot{z} + mg)(x_{cp} - x) = (z_{cp} - z)m\ddot{x} - I\ddot{\theta}$$

其中 $z_{cp}$ 是地面高度（平地时等于地面z坐标）。

**如果质心高度不变且没有角加速度**（$\ddot{z} = 0, \ddot{\theta} = 0$），方程简化为著名的：

$$\boxed{\ddot{x} = g\frac{x - x_{cp}}{z - z_{cp}}}$$

> 🤯 **这个方程为什么重要？**
> 
> 它告诉你：**质心的水平加速度完全由CoP的位置决定！** 反之亦然。
> 
> 🎮 **类比**：想象你站在滑板上，手里拉着一根绳子。绳子的固定点就是CoP。你拉绳子的位置决定了你向前还是向后倒。如果你想往前走，CoP必须在你质心前面；想减速，CoP必须在质心后面。
> 
> 而且，CoP**必须**落在所有接触点的**凸包**内（比如两脚之间的区域）。所以，你的质心加速度不是想怎么加就怎么加——它被脚的位置严格限制了！

### 5.2.2 ZMP推导的旁注：到底什么是ZMP？

ZMP在文献中经常被混淆，作者在这里给出了清晰定义。

**核心思想**：对于刚体，所有外部力可以等效为一个**合力+合力矩**（wrench）。

> 🔧 **类比**：想象你用扳手拧螺丝。你手施加了很多力，但效果等同于在某个特定点施加一个力加一个扭转力矩。ZMP就是那个特殊的点——在这个点上，等效的扭转力矩为零。

**数学推导**：

对于任意点 $A$，外力产生的净力矩：
$$\tau_{net}^A = \sum_i (p_i^B - p_A^W) \times f_i^W$$

我们希望找到一个点 $ZMP$，使得 $\tau_{net}^{ZMP} = 0$。

解这个方程，在平地情况下，你会发现：

$$x_{ZMP} = \frac{\sum_i p_{i,x} \cdot f_{i,z}}{\sum_i f_{i,z}} = x_{cp}$$

> ✅ **结论**：在**平地**上，**ZMP = CoP**。它们是完全同一个点！

**定义5.1（零力矩点ZMP）**：
> 外部力对机器人的总贡献可以总结为作用在任意点P的一个空间力。如果在这个点P上，空间力的旋转分量（力矩）为零，则称P为"零力矩点"。

对于平地行走，按惯例，**"ZMP"特指地面上的那个零力矩点**。

**3D推广**：
在三维中，ZMP是地面上满足 $\tau_{net,y}^{ZMP} = \tau_{net,x}^{ZMP} = 0$ 的点（允许z轴力矩非零）。

### 5.2.3 关于碰撞动力学的说明

在第四章中，我们花了很多精力研究碰撞（impact）——用冲量力解释速度的不连续跳变。

但对于**高自由度机器人**，有一种策略可以**几乎避免碰撞能量损失**：

$$\dot{z} = c \Rightarrow \ddot{z} = 0, \quad \text{且} \quad I\dot{\theta} = 0 \Rightarrow I\ddot{\theta} = 0$$

> 🦶 **策略**：让质心以**恒定垂直速度**运动（通常是0，即保持高度），且**角动量为零**。这样，如果摆动脚刚好落在质心下方，即使腿是刚性的，碰撞时也不会损失能量——因为碰撞点就在质心正下方，没有水平动量需要"被地面吃掉"。

这就是为什么很多人形机器人文献在讨论质心动力学时**忽略碰撞**——因为它们采用了这种"软着陆"策略。

## 5.3 基于ZMP的规划

理解CoP/ZMP与质心运动的关系后，我们可以设计一个**三层规划管道**：

```
第1层： footsteps / 接触位置规划
    ↓
第2层： 质心（CoM）运动轨迹规划
    ↓
第3层： 全身关节运动规划（逆运动学/动力学）
```

> 🏗️ **类比**：就像盖房子。第一层决定"地基放哪里"（脚踩哪）；第二层决定"房子的重心怎么移动"（身体怎么走）；第三层决定"每根钢筋怎么摆"（每个关节怎么动）。

这种分解有代价：
- footsteps规划是**运动学**的，不直接考虑动力学
- CoM规划不知道关节极限和力矩极限

但换来了**巨大的计算简化**！

### 5.3.2 规划质心运动轨迹：ZMP规划器

这是本田ASIMO等早期人形机器人的核心技术。

**ZMP "稳定性"指标**：
> 如果ZMP始终保持在支撑多边形（两脚之间的凸包）内，则机器人"稳定"——不会翻倒。

> ⚠️ **注意**：Tedrake教授在手绘图中特意标注了 **"the timing also matters!"**（时机也很重要！）。ZMP在支撑多边形内只是必要条件，不是充分条件。你还需要在正确的时间把脚放到正确的地方。

#### 例5.1：ZMP规划器（代码实践）

Drake中提供了 `ZmpPlanner`，可以生成CoM轨迹。

```python
from pydrake.all import *

# 1. 定义 footsteps 位置（nominal footsteps）
footstep_positions = [
    np.array([0.0, -0.1]),   # 左脚
    np.array([0.3, 0.1]),    # 右脚
    np.array([0.6, -0.1]),   # 左脚
    # ...
]

# 2. 定义期望ZMP轨迹
# 简单策略：ZMP在双脚之间切换，每只脚支撑时ZMP在该脚中心
zmp_times = [0, 0.5, 1.0, 1.5, 2.0]
zmp_positions = [
    np.array([0.0, -0.1]),   # 左脚支撑
    np.array([0.15, 0.0]),   # 双支撑
    np.array([0.3, 0.1]),    # 右脚支撑
    np.array([0.45, 0.0]),   # 双支撑
    np.array([0.6, -0.1]),   # 左脚支撑
]

# 3. 创建ZMP规划器
zmp_planner = ZmpPlanner(
    zmp_positions,      # 期望ZMP轨迹
    zmp_times,          # 时间点
    zmp_planner_height=1.0,  # 质心高度（假设恒定）
    gravity=9.81,
    desired_com_position_at_t0=np.array([0.0, 0.0]),  # 初始CoM
    desired_com_velocity_at_t0=np.array([0.0, 0.0]),  # 初始速度
)

# 4. 获取CoM轨迹
com_trajectory = zmp_planner.get_com_trajectory()

# 5. ZMP规划器还产生反馈策略！
# 如果实际CoM偏离了计划，控制器会自动修正
feedback_policy = zmp_planner.get_feedback_policy()
```

> 🎮 **实验建议**：在Deepnote笔记本中，尝试改变 footsteps 的时间间隔（比如让单脚支撑时间从0.5秒变成0.3秒或0.7秒），观察CoM轨迹如何变化。你会发现：支撑时间越短，CoM的摆动幅度越小，但机器人走得越快越不稳。

**图5.7的结果**：
- 红色：期望ZMP（在双脚之间锯齿形摆动）
- 蓝色：名义CoM（平滑的正弦-like曲线，滞后于ZMP）
- 灰色方块：footsteps位置

> 🎯 **物理直觉**：ZMP像"缰绳"，CoM像"马"。缰绳往哪拉，马就往哪加速。但马有惯性，所以总是滞后于缰绳。ZMP先移到右脚，CoM才被拉向右脚；ZMP移到左脚，CoM再被拉回来。

## 5.4 质心动力学：从单刚体到多体系统

前面我们把机器人躯干当单刚体。现在推广到**任意多连杆机器人**。

### 5.4.1 空间动量（Spatial Momentum）

对于单刚体，定义**空间速度**（角速度+线速度的拼接）：

$${}^W V^{B_{cm}} = \begin{bmatrix} {}^W \dot{\theta}^B \\ {}^W \dot{p}^{B_{cm}} \end{bmatrix}$$

**空间惯量**（关于质心）：

$$M^{B/B_{cm}} = \begin{bmatrix} I & 0 & 0 \\ 0 & m & 0 \\ 0 & 0 & m \end{bmatrix}$$

**空间动量** = 空间惯量 × 空间速度：

$${}^W L^{B/B_{cm}} = \begin{bmatrix} I\dot{\theta} \\ m\dot{x} \\ m\dot{z} \end{bmatrix} = M^{B/B_{cm}} \cdot {}^W V^{B_{cm}}$$

> 🎯 **类比**：空间动量就像物体的"运动名片"。它不仅包含"动量"（平移的），还包含"角动量"（旋转的）。对于刚体，这两者是独立又统一的。

动力学方程的简洁形式：

$${}^W \dot{L}^{B/B_{cm}} = \sum_i F_i^{B_{cm}}$$

> 🎯 **大白话**：空间动量的变化率 = 所有外力的空间力之和。这就是牛顿第二定律的"空间版"。

---

### 5.4.2 推广到多体系统

对于整个多连杆机器人，**质心位置**是所有连杆质心的加权平均：

$${}^W p^{R_{cm}}(q) = \frac{\sum_i {}^W p^{B_i}(q) \cdot m_i}{\sum_i m_i}$$

**整个机器人的空间动量**：

$${}^W L^{R/R_{cm}}(q, \dot{q}) = A(q)\dot{q}$$

其中 $A(q)$ 是**质心动量矩阵（Centroidal Momentum Matrix, CMM）**。

> 🎯 **为什么重要？** 无论你的机器人有10个关节还是50个关节，整个系统的**质心运动+总角动量**只取决于这个矩阵乘以关节速度向量。它把高维关节空间映射到低维的质心运动空间。

**动力学方程仍然简洁**：

$${}^W \dot{L}^{R/R_{cm}} = \sum_i F_i^{R_{cm}}$$

> 🚀 **核心洞察**：这是**精确方程**，不是近似！无论机器人多复杂，质心的运动只由外力决定。约束（关节极限、力矩极限）只影响你能产生什么样的外力，不影响方程本身。

在Drake中计算：
```python
# 计算整个机器人的空间动量
plant = MultibodyPlant(time_step=0.001)
# ... 构建机器人模型 ...
context = plant.CreateDefaultContext()

# 计算关于质心的空间动量
spatial_momentum = plant.CalcSpatialMomentumInWorldAboutPoint(
    context, 
    plant.CalcCenterOfMassPositionInWorld(context)
)
```

## 5.8 练习详解与代码指南

### 练习5.1：通过混合整数优化的步态规划（MIQP）

**目标**：在崎岖地形上规划 footsteps 位置。

**场景**：地面有一系列"踏脚石"（stepping stones），机器人必须选择踩哪些石头。

```python
# 混合整数规划（MIP）的核心思想：
# 用二进制变量表示"是否踩某个石头"

# 变量：
# p_i = (x_i, y_i)  # 第i步的位置（连续变量）
# b_i_j ∈ {0,1}     # 第i步是否踩在石头j上（二进制变量）

# 约束：
# a. 最大步长约束：||p_{i+1} - p_i|| ≤ L_max
#    这保证了机器人不会迈得太大

# b. 每个脚不能同时在两个石头上：
#    Σ_j b_i_j = 1  （第i步只能踩一个石头）
#    或者对于双足：左右脚各有自己的约束

# c. 踩石头约束：如果踩在石头j上，p_i必须在石头j的区域内
#    p_i ∈ Stone_j  如果 b_i_j = 1
#    这通过"大M法"（Big-M method）线性化：
#    p_i ≥ stone_j_min - M*(1 - b_i_j)
#    p_i ≤ stone_j_max + M*(1 - b_i_j)

# d. 目标函数：最小化步长平方和
#    min Σ ||p_{i+1} - p_i||^2
#    这产生最"自然"的步态

# 使用Drake的MathematicalProgram求解
from pydrake.all import MathematicalProgram, Solve

prog = MathematicalProgram()
# ... 添加变量、约束、目标 ...
result = Solve(prog)
```

### 练习5.2：理解零力矩点

**模型**：一个简化腿式机器人（图5.8）
- 脚是三角形 $HTP$（H=heel脚后跟, T=toe脚尖, P=ankle踝关节）
- 腿长度 $l$，质量为0
- 末端质点 $m$（代表整个身体）
- 脚高 $h$， ankle 到H距离 $L_2$，到T距离 $L_1$

**a. 画自由体图**

为三个部分分别画受力：
- **质点m**：重力 $mg$ 向下，腿拉力/压力沿腿方向
- **腿**：两端受力（无质量，所以力必须沿腿方向且大小相等）
- **脚**：地面反力 $F_H$（heel）和 $F_T$（toe），腿传来的力在P点

> 🎨 **画图提示**：质点只受两个力（重力和腿力），腿是二力杆。脚受三个力（地面两处+腿一处），可以用力平衡和力矩平衡分析。

**b. $\theta = \pi/2 + 10^{-3}$ 时系统稳定吗？**

$\theta \approx \pi/2$ 意味着腿几乎水平。质点在 ankle 正上方（几乎）。

> 🤔 **分析**：如果腿完全水平（$\theta = \pi/2$），质点在 ankle 正上方。这是一个**不稳定平衡**——像铅笔倒立在指尖。给一点点扰动就会倒。所以 $\theta = \pi/2 + 10^{-3}$ 时，系统**不稳定**。

**c. 计算ZMP**

对脚取力矩平衡（关于地面上某点）。设ZMP距离P点的水平距离为 $d$。

由于腿无质量，腿对脚的力沿腿方向。设腿与竖直方向夹角为 $\theta$，则：

水平力平衡：$F_{T,x} + F_{H,x} = m g \tan\theta$（或类似，需仔细推导）
垂直力平衡：$F_{T,z} + F_{H,z} = mg$

对P点取力矩：$F_{T,z} \cdot L_1 - F_{H,z} \cdot L_2 = m g \cdot l \sin\theta$

ZMP是地面上力矩为零的点：
$$x_{ZMP} = \frac{F_{T,z} \cdot L_1 - F_{H,z} \cdot L_2}{F_{T,z} + F_{H,z}}$$

代入力矩平衡，并利用 $F_{T,z} + F_{H,z} = mg$：

$$x_{ZMP} = \frac{mg \cdot l \sin\theta - (F_{T,z}L_1 - F_{H,z}L_2) \text{的某种形式}}{mg}$$

更直接的方法：使用ZMP定义——ZMP是地面反力的等效作用点。

对脚（无质量）的力矩平衡，关于ZMP：
$$\sum M_{ZMP} = 0$$

由于脚无质量，所有力必须共点或通过ZMP。

经过推导（考虑腿传来的力有水平分量 $mg \tan\theta$ 和垂直分量 $mg$）：

$$x_{ZMP} = \frac{(mg)(l\sin\theta) - (mg\tan\theta)h}{mg} = l\sin\theta - h\tan\theta$$

或类似形式（具体符号取决于坐标定义）。关键是ZMP与 $\theta$ 的关系。

**d. ZMP到达脚尖/脚跟的条件**

i. ZMP到达脚尖T：$x_{ZMP} = L_1$（以P为原点，向右为正）

解出对应的 $\theta$ 值。

ii. 脚跟开始抬起：当 $F_{H,z} = 0$ 时，所有垂直力由脚尖承担。此时ZMP恰好在脚尖。

> 🦶 **类比**：这就像你踮起脚尖站立。一旦脚跟离地，ZMP就从两脚之间跳到了脚尖。对于机器人，如果ZMP到达支撑多边形的边界，机器人就开始绕该点旋转（即将摔倒）。

**e. 有ankle力矩时**

如果在P点有一个执行器，可以产生力矩 $\tau$ 来抵消重力力矩，使得 $\ddot{\theta} = 0$。

此时系统处于"准静态平衡"。

地面反力：
- 垂直分量：$F_{T,z} + F_{H,z} = mg$
- 对P点力矩：$\tau + F_{T,z}L_1 - F_{H,z}L_2 = mgl\sin\theta$

> 🎯 **关键**：通过调节 $\tau$，你可以改变 $F_{T,z}$ 和 $F_{H,z}$ 的分配，从而**主动控制ZMP的位置**！这就是为什么人可以通过脚踝微调来保持平衡。

**f. 不摔倒的 $\theta$ 范围**

ZMP必须在支撑多边形内：$-L_2 \leq x_{ZMP} \leq L_1$

利用(e)中的方程，解出 $\theta$ 的范围。

> 🧮 **推导**：当 $\ddot{\theta} = 0$ 且 ankle 力矩无限制时：
> - ZMP位置由 ankle 力矩决定
> - 最大 $\theta$ 发生在ZMP在脚尖或脚跟的极限情况
> - 具体范围取决于 $l, h, L_1, L_2$ 的关系

**g. 设计最优脚型**

i. **更高还是更平的脚（h更大还是更小）？**

$h$ 是脚的高度（ ankle 离地高度）。

> 🎯 **分析**：从ZMP方程看，$h$ 影响水平力产生的力矩。更高的脚（更大的 $h$）意味着同样的水平力会产生更大的力矩，更容易让ZMP移动。但具体"更好"取决于目标。
> 
> 对于静态站立稳定性：**更平的脚（小h）**更好，因为质点晃动时ZMP变化较小。
> 
> 实际上需要重新看几何关系。脚高 $h$ 影响的是 ankle 到地面的距离。如果 $h$ 大（ ankle 高），腿更倾斜，同样的 $\theta$ 变化会导致更大的力矩臂。

ii. **更长还是更短的脚（$L_1 + L_2$ 更大还是更小）？**

> 🎯 **显然**：更长的脚（更大的 $L_1 + L_2$）给出更大的支撑多边形，允许更大的 $\theta$ 范围而不摔倒。就像穿滑雪板比穿普通鞋更难摔倒。

iii. ** ankle 相对于脚跟和脚尖的位置？**

> 🎯 **最优位置**： ankle 应该在支撑多边形的中心附近，即 $L_1 \approx L_2$。这样前后稳定性对称。就像人脚， ankle 大致在脚心位置。

**h. 为前进行走设计脚型**

目标是让**脚跟更容易抬起**（便于迈步）。

i. **更高还是更平的脚？**

更高的脚（更大的 $h$）会让 ankle 力矩对ZMP的影响更显著，可能更容易控制脚跟抬起。但这不是主要因素。

ii. **$L_1$ 更长还是更短？$L_2$ 呢？**

> 🎯 **关键**：让脚跟容易抬起 = 让ZMP容易移到脚尖附近。
> - 更长的 $L_1$（脚尖更长）：给ZMP更多前向空间
> - 更短的 $L_2$（脚跟更短）：减少后向支撑，让重心前移时更快脱离脚跟

iii. ** ankle 位置？**

> 🎯 **靠前放置**：把 ankle 靠近脚尖（$L_1$ 小，$L_2$ 大）会让重心更容易前倾，脚跟更容易抬起。但这牺牲了后向稳定性。实际设计中需要权衡。

### 练习5.3：通过凸集图（GCS）的步态规划

这是比MIP更高效的 footsteps 规划方法。

**核心思想**：
- 每个踏脚石是一个**凸集**（顶点）
- 如果从一个石头可以迈到另一个石头，画一条**边**
-  footsteps 规划 = 在这个**图**中找到**最短路径**

> 🗺️ **类比**：想象你在城市导航。每个街区是一个"凸集"，街道是"边"。GCS规划就像Google Maps找最短路线，但每个"街区"内你可以自由选择具体走哪条人行道（连续优化），而街区之间的连接是离散的（图搜索）。

**为什么GCS比MIP快？**

MIP需要求解混合整数二次规划（NP-hard），而GCS的凸松弛可以简化为**线性规划（LP）**——多项式时间可解，规模大得多。

```python
# GCS规划的核心代码结构
from pydrake.all import *

# a. 构建GCS顶点（每个踏脚石一个顶点）
gcs = GraphOfConvexSets()
for stone in stepping_stones:
    vertex = gcs.AddVertex(stone.convex_region)  # 石头区域是凸集
    vertices.append(vertex)

# b. 构建边（如果两个石头之间距离在步长范围内）
for i, v1 in enumerate(vertices):
    for j, v2 in enumerate(vertices):
        if can_step(v1, v2):  # 距离约束
            edge = gcs.AddEdge(v1, v2)
            edges.append(edge)

# c. 添加边约束（运动学约束）
for edge in edges:
    # 步长限制：||p_j - p_i|| ≤ L_max
    edge.AddConstraint(p_j - p_i <= L_max)
    # 其他约束...

# d. 添加边代价（目标：最小化总步数或总步长）
for edge in edges:
    edge.AddCost(length(p_j - p_i))

# e. 求解最短路径
result = gcs.SolveShortestPath(start_vertex, goal_vertex)
```

> 🚀 **优势**：GCS把 footsteps 规划从"NP-hard的整数规划"变成了"可大规模求解的凸优化"。这是Tedrake团队2023年的前沿工作。

| **三层规划管道** |  footsteps → CoM → 全身 | 分解复杂问题，牺牲少许最优性换取可计算性 |
| **GCS footsteps 规划** | 把 footsteps 规划变成图上的最短路径 | 从NP-hard到多项式时间，可处理大规模地形 |
