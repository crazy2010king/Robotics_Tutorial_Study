## 0. 开篇：扯下"全状态反馈"这块遮羞布

### 0.1 一句话概括

> **前面 14 章都假设控制器能"开卷考试"（直接读真实状态 $x$）；本章承认现实是"闭卷考试"——你只有带噪声、可能残缺的传感器读数 $y$。于是控制问题从"怎么控制"升级成"在看不清的情况下，怎么一边猜世界、一边控制"，而这正是机器人操作、自动驾驶、乃至"从像素直接出力矩"的核心难题。**

### 0.2 作者开场白的逐句翻译（信息量极大，逐层拆）

**第一层：方程里多了两个字母 $y$ 和 $v$。**
> 本章我们终于开始考虑这种形式的系统：

$$x[n+1]=f(x[n],u[n],w[n]),\qquad y[n]=g(x[n],u[n],v[n])$$

> 大部分符号以前见过，但现在**新增了 $y$（系统的输出/观测）**，以及 **$v$（测量噪声）**，$v$ 通常是某个随机过程的输出。**换句话说，我们终于开始面对一个事实：我们必须基于传感器测量来做决策**——而 finora 的讨论都**默认**我们能拿到系统的真实状态用于反馈（而这本身已经是个难题了）。

**类比（开卷 vs 闭卷，全章总纲，请刻进脑子）**：
- **全状态反馈（前14章）** = **开卷考试**：考官把标准答案（真实状态 $x$）摊在你面前，你只管"对照答案做动作"。
- **输出反馈（本章）** = **闭卷考试 + 近视眼镜**：答案被收走了，你只能透过一副**起雾的眼镜**（带噪声 $v$ 的传感器 $y$）**猜**答案是什么，再据此作答。
- **$w$（过程噪声）vs $v$（测量噪声）**：$w$ = "**路本身在抖**"（世界捣乱，第6/13章讲过）；$v$ = "**你的眼镜起雾**"（你**看**不准）。**这是两种完全不同的"不确定"**，本章主攻后者。

**第二层：有时"开卷假设"没那么糟——但估计器会"拖后腿"。**
> 在某些情况下，"全状态反馈"的假设**没那么糟**——我们确实有**从原始传感器数据做状态估计**的好工具。但**即使最好的状态估计算法，也会给系统额外加一些动力学**（为了滤掉噪声测量）；**如果这些滤波器的时间常数，接近我们系统动力学的时间常数**，那么**把估计器的动力学纳入闭环分析**就变得重要了。

**类比（戴了副"会延迟"的眼镜）**：状态估计器 = 一副"**智能降噪眼镜**"，它能把雾滤掉，但**处理需要时间**（有时间常数）。如果这副眼镜"**反应太慢**"（时间常数大），慢到和"**车本身转弯的速度**"差不多，那你**戴着它开车，眼镜显示的"前方路况"已经是 0.5 秒前的了**——**这时你不能假装眼镜是透明的，必须把"眼镜的延迟"也算进驾驶策略里**。

**第三层：有时"开卷假设"乐观到离谱——有些东西根本测不到。**
> 在另一些情况下，**假设"我们能估计出全状态"简直乐观得离谱**。有些状态变量**可能完全不可观测**；另一些**可能需要控制器主动做"信息收集"动作**。

**类比（蒙眼摸象 + 主动探头）**：
- **不可观测** = 你蒙着眼摸一头大象，**你永远摸不出它的颜色**——颜色这个状态，对你的"触摸传感器"来说**根本不存在**。
- **信息收集动作** = 你**故意把头歪一下、换个角度摸**，**就为了多获取一点信息**——**这个"歪头"动作本身不推进任务，纯粹是为了"看清楚"**。**机器人有时也得"为了看而动"**。

**第四层（作者的私心）：机器人操作，是输出反馈的"主战场"。**
> 对我来说，**机器人操作（manipulation）** 是"更灵活的输出反馈方法"变得**至关重要**的一个重要应用领域。

> 想象你要给一个机器人设计控制器，让它**扣你衬衫上的扣子**。我们现有的工具会要求我们**先估计衬衫的状态**——可**我的衬衫有多少个自由度？** 但**扣一个扣子，绝不应该需要知道衬衫的完整状态**。或者你想编程让机器人**做沙拉**——**沙拉的状态是什么？** 我真的需要知道**每一片生菜的位置和速度**才能成功吗？

**类比（这是全章最动人的类比，必懂）**：
- **扣扣子**：你**自己**扣扣子时，**脑子里有没有"衬衫的 300 维状态向量"？** 没有！你只是**看着扣眼、伸手、对准、穿过去**——你用的是**极其精简的"视觉线索"**，而不是"衬衫全状态"。
- **做沙拉**：你切生菜时，**会在心里给每片生菜建一个物理模型吗？** 不会！你**看着刀和菜，凭手感切**。
- **作者的潜台词**：**人类从不"先估计全状态再控制"**，我们**直接从"看到的东西"映射到"手的动作"**——**而现有控制理论却死磕"先估计全状态"，这是在用大炮打蚊子，而且蚊子还打不中**。**这就是为什么"输出反馈/像素到力矩"如此重要**。

**第五层：和机器学习的交汇——"学习状态表示"。**
> 这些问题（终于）在研究社区得到了大量关注，归在"**学习状态表示（learning state representations）**"这把大伞下。但**什么才算"好的状态表示"？** 控制论里输出反馈的**一些简单教训**，能照亮这个根本问题。

**人话**：深度学习现在很流行"**让神经网络自己学一个'内部表示'**"（不直接估计物理状态，而是学一个"对任务有用的压缩表示"）。但**"有用"到底是什么意思？** 控制论研究"输出反馈"几十年，**早就积累了一堆"什么样的信息足以做决策"的判据**——**这些判据，正好能告诉机器学习"该学什么样的表示"**。**这是本章想搭的桥**。

## 1. 背景（15.1）—— "最老的方法"和"最新的方法"，其实在解同一个问题

### 1.1 经典视角：原来"输出反馈"才是控制论的"老祖宗"

> 某种程度上，把"输出反馈"单拎出来当"高级话题"，是个**相对新的问题**。在**状态空间 + 基于优化的方法**（即"现代控制"） usher 进来**之前**，我们有"**经典控制**"。经典控制**主要**（虽非唯一）聚焦**线性时不变（LTI）系统**，**重度使用频域分析**（如通过傅里叶变换/拉普拉斯变换）。[1, 2] 是不错的现代教材（从状态空间讲起，但也讲频域视角）。"**极点配置（pole placement）**"和"**环路整形（loop shaping）**"是这行的工具。

> **这里对我们重要的是**：在经典控制里，**几乎一切都围绕"输出反馈"这个想法构建**。基本概念是**传递函数（transfer function）**——一个**频域的输入-输出映射**，能**完全刻画一个 LTI 系统**。极点配置、环路整形这些核心概念，**本质上就是在解决我们这里讨论的"输出反馈"挑战**。

> **作者的个人担忧（很有味道，保留）**：有时我觉得，**尽管现代优化控制带来了这么多东西，我担心我们丢掉了一些东西**——**对闭环性能的丰富刻画**（上升时间 rise time、驻留时间 dwell time、超调 overshoot……），**甚至可能丢掉了系统对未建模误差的实际鲁棒性**。

**类比（经典控制 = "老中医把脉"，现代控制 = "CT 扫描"，必懂）**：
- **现代控制（状态空间）** = **CT 扫描**：它要求你**先把身体内部（全状态 $x$）完全成像**，再据此开刀。**精确，但前提是"你得先拍得到 CT"**（全状态可观测/可估计）。
- **经典控制（频域/传递函数）** = **老中医把脉**：他**不拍 CT**，他**只摸你的脉搏（输出 $y$）**，**从"脉搏怎么随时间/频率变化"反推你身体好不好**，然后开药。**他从头到尾就没见过你的"内部状态"，但他照样能治病**——**因为传递函数/频域响应，本身就是"输入-输出"的语言，天生就是输出反馈**。
- **作者的担忧** = "**CT 扫描时代，我们是不是把'把脉'的手艺弄丢了？**"——**那些"上升时间、超调、对未建模误差的鲁棒性"，是'把脉'时代天天盯的'临床指标'，而现代优化控制有时只盯着'代价函数最小'，反而忽略了这些'临床手感'**。

**人话（这一节的真正信息）**：**"输出反馈"不是新难题，它是控制论的"初心"**——**只是现代控制用"先估计全状态"这个拐杖，暂时绕开了它**。本章要把拐杖扔掉。

### 1.2 从像素到力矩：最新的方法，也在解同一个问题

> 正如我们**最老的**控制方法**本质上在解输出反馈问题**，我们**最新的**控制方法**也在解它**。

> **深度学习革新了计算机视觉**，而"**深度模仿学习**"和"**深度强化学习**"，近来产出了**大量令人印象深刻的、能直接从像素操作的控制演示**（比如**消费深度感知系统的输出**），**既不显式表示、也不估计系统的完整状态**。

**类比（"端到端"= "不背交规，只看老司机怎么开"）**：
- 传统路线 = **先学交规（建模）→ 再装摄像头识别路况（状态估计）→ 再决策（控制）**，**三步分开**。
- 端到端深度学习 = **不学交规、不识别路况**，**直接让神经网络看"老司机开车的视频"，学会"看到这种画面，就该打这么多方向"**——**从像素（pixels）直接到方向盘/力矩（torques）**。**中间没有"状态"这个概念**。

**模仿学习的现状与局限**：
> **模仿学习如今效果好得惊人**，即使对非常复杂的任务（如 [3, 4]）。有人会说**模仿学习并没有解"完整的控制问题"**——**一旦有人解了某个控制问题，模仿学习系统就能用监督学习，在一个高容量神经网络里，把像素映射到力矩**。未来章节详述。**为了泛化到训练数据里没有的状态、或（语言条件下的）多任务框架里的新任务，模仿学习者必然在获取某种"对世界的隐式状态表示"**。**也许我们能利用这些学到的状态表示，为新任务综合额外的控制器**。

**人话**：模仿学习 = "**抄作业**"——**别人（teacher）先把题解出来，模仿学习只是'学会抄'**。**但它抄得太好了，好到我们怀疑'它抄的时候，脑子里是不是偷偷建了个世界模型（隐式状态表示）'**——**否则它怎么会在没见过的题上也抄对（泛化）？** 如果能**把这个'偷偷建的模型'挖出来**，就能**用它去解新题**。

**强化学习的现状**：
> **强化学习（RL）确实在解难的控制问题**，尽管它**目前仍需要相当多的引导**（通过调代价函数/环境），且**需要天文数字的计算量**。有趣的是，**RL 里很常见的做法是：先解一个全状态反馈问题，再用 "teacher-student"（又是一种模仿学习）把全状态反馈控制器"蒸馏"成输出反馈控制**（如 [5, 6]）。通常动机是**训练效率**——**这样在学习早期不必把渲染器（renderer）放进仿真**——但**这到底对优化器本身帮助多大，我并不完全清楚**。无疑，我们想要**更强、更常成功、且需要更少前期仿真工程和算力的 RL 算法**。

**类比（teacher-student = "老司机带徒弟，徒弟只看后视镜"）**：
- **Teacher** = **坐在驾驶座、看得到所有仪表（全状态）的老司机**，先学会开。
- **Student** = **坐在后座、只能看后视镜（像素/观测）的徒弟**，**模仿老司机的方向盘动作**。
- **为什么先教老司机？** 因为**让老司机学，比让徒弟直接学容易得多**（信息全）；**等老司机学会了，再让徒弟'照着他的动作学'**，**比让徒弟'从零摸索'省太多事**。**这就是"先全状态 RL，再蒸馏成输出反馈"的逻辑**。

**作者的乐观与本章目标**：
> **机器学习（理论 + 应用）与控制理论的融合，是当今最令人兴奋、最多产的研究前沿之一**。我**高度乐观**，相信我们能**揭示底层原理**，帮这个萌芽领域**过渡成一门技术**。**本章我的目标 = 总结控制论的一些关键教训，希望能帮上这场讨论**。

**人话**：作者在这一节其实是在"**喊话**"——**他对机器学习社区说**："**你们用深度学习'端到端'搞出了很多炫酷演示，但你们其实在重新发明控制论几十年前就在研究的东西（输出反馈）。来，我把控制论的'教训'整理给你们，咱们别各搞各的。**" **这就是本章的"立意"**。

## 2. 静态输出反馈（15.2）—— "只看现在这一步，够不够？"

### 2.1 一个"几乎没明说"的重要教训

> 加性代价的动态规划 + Bellman 方程，有一个**极其重要、却几乎没被明说**的教训：**最优策略总能表示成一个函数 $u^*=\pi^*(x)$**。 finora 我们假设控制器**直接访问真实状态 $x$**。本章我们**终于移除这个假设**。现在控制器**只直接访问可能带噪的观测 $y$**。

> 于是**自然的第一个问题**可能是：**如果我们把策略写成 $y$ 的函数 $u=\pi(y)$，会怎样？** 这叫"**静态（static）**"输出反馈，**对比"动态（dynamic）"输出反馈**——后者里**控制器不是一个静态函数，而是它自己又是一个输入-输出动力系统**。

> **不幸的是，一般情况下，最优策略并不能用静态输出反馈完美表示。** 但我们**仍可以尝试**解一个"**把搜索限制在静态策略类里**"的最优控制问题；**我们的目标 = 在这个类里，找那个最小化代价的、最好的控制器**。

**类比（静态 vs 动态 = "只看现在" vs "记着小本本"，必懂）**：
- **静态输出反馈 $u=\pi(y)$** = 一个"**金鱼司机**"：**他没有任何记忆**，**每一秒只看'现在后视镜里的画面'，立刻决定打多少方向**——**上一秒发生了什么，他全忘了**。
- **动态输出反馈** = 一个"**记小本本的司机**"：**他脑子里有个'内部状态'（小本本）**，**把'过去几秒看到的'都记下来**，**综合起来决策**。**这个'小本本'本身随时间更新**——**所以控制器'自己是个动力系统'**。
- **为什么静态可能不够？** 因为**"现在这一帧画面"可能信息不全**（比如一张照片看不出速度），**你必须"结合过去几帧"才能补全信息**——**这就需要记忆 = 动态**。

### 2.2 一个"困难性结果"：连"线性 + 静态"都是 NP-hard！

> 考虑**为线性系统设计静态输出反馈**的问题（**这总该是简单情况了吧！**）：

$$\dot x=Ax+Bu,\qquad y=Cx$$

> **不幸的是**，[7] 证明：**"对给定形如上式的系统，是否存在一个能稳定它的静态输出反馈"这个问题，是 NP-hard 的**。稳定 $K$ 矩阵的集合，**不仅可能非凸，而且可能不连通（disconnected）**。下面这个简单例子能让我们看到这点（Alex Megretski 在一次谈话中给我的）。

#### Example 15.1（静态输出反馈的参数化）

$$A=\begin{bmatrix}0&0&2\\1&0&0\\0&1&0\end{bmatrix},\quad B=\begin{bmatrix}1\\0\\0\end{bmatrix},\quad C=\begin{bmatrix}1&1&3\end{bmatrix}$$

> 这里**线性静态输出反馈策略**可写成 $u=-ky$，**只有一个标量参数 $k$**。

**人话（这个例子为什么"扎心"，必懂）**：
- 闭环矩阵 $A_{cl}=A-BkC$。**$k$ 只是一个数**——**你以为"调一个旋钮"总能调稳吧？**
- 但画出来你会发现：**只有"某几段 $k$"能让系统稳定，中间夹着"一调就炸"的 $k$**——**稳定的 $k$ 是"几段断开的区间"，不是一整段**。
- **这意味着**：你用梯度下降调 $k$，**可能卡在一段稳定区间里，永远跳不到另一段"更好的"稳定区间**——**因为中间隔着"炸区"，梯度过不去**。**这就是"不连通"的灾难**：**优化景观里有"孤岛"**。

**类比（调音响旋钮，必懂）**：
- 想象一个音响，**音量旋钮 $k$**。你以为"从小拧到大，总有个区间不啸叫"。
- 结果发现：**$k$ 在 1–3 不啸叫，4–7 啸叫，8–10 又不啸叫**——**两个"安静岛"中间隔着一片"啸叫海"**。
- 你**从 2 开始调，永远调不到 9 那个"更安静"的岛**——**因为中间 4–7 一碰就啸叫，你不敢过去**。**这就是"稳定集不连通"**。
- **而 [7] 说：判断"到底有没有安静的档位"这件事本身，就是 NP-hard**——**连"有没有解"都难判定，更别说"找最优解"**。

> **作者的关键态度（很重要，保留）**：
> **仅仅因为这个问题是 NP-hard，并不意味着我们在实践中找不到好控制器。** RL 的一些近期结果**提醒了我们这点**。**我们不应期望"对每个问题实例都有效的、全局最优的高效算法"**；**但我们绝对应该继续研究这个问题**。**也许我们的机器人在真实世界真正会遇到的问题，比这个一般情况要容易**（线性系统里那些"坏情况"的标准例子，比如**交错的极点和零点**，**确实感觉有点刻意、实践中不太可能出现**）。

**人话**：**NP-hard 是"最坏情况的理论判决"，不是"实践的死刑"**——**就像"旅行商问题是 NP-hard"，但快递公司的路线规划照样跑得挺好**，因为**真实路线不是"最坏的那种"**。**作者的态度 = "理论上认怂（NP-hard），实践上不服（继续干，真实问题可能没那么坏）"**。

### 2.3 也许……用观测的"历史"？

> 除了可能给一个**坏的优化景观**，你**很容易说服自己**：**"只基于当前观测做决策"，在所有问题里是不够的**。

> 举个例子：我们为平衡 Acrobot 或 Cart-Pole 推导的 **LQR 控制器，是全状态（位置 + 速度）的函数**。如果我们的机器人**只装了位置传感器**（如编码器），**或者观测来自一个对着机器人的相机**，那么**只看瞬时观测，就完全没有任何关于关节速度的信息**。虽然这需要证明，但**合理预期**：**这种形式的控制器，无法从所有初值完成平衡任务**（即使对线性化系统）。

**类比（一张照片看不出速度，必懂）**：
- 你**拍一张单杠上运动员的照片**，**能看出他转得多快吗？** 不能！**一张照片只有"位置"，没有"速度"**。
- 但**平衡倒立摆，恰恰最需要"速度"信息**（要知道往哪边倒、倒多快，才能反向推）。
- 所以**"只看现在这一帧（静态输出反馈）"，物理上就缺了速度信息**——**神仙也平衡不了**。

> **今天一个常见的回应**：**如果让控制器成为"最近一段观测历史"的函数呢？** 如果**没有测量噪声**，那么**最近两个位置测量，就足以做一个（略微延迟的）速度估计**（**两点位置相减 ≈ 速度**）。**如果有测量噪声**，那么**取稍长一点的历史，就能滤掉一部分噪声**。**对！这是正确的方向。**

> **技术上，这就不再是"静态"控制器了**；**它需要内存来存储先前的观测，而"内存"正是"动态"控制器的定义特征**。**但我们需要多少历史/内存呢？**

**类比（"两帧差分 = 速度"，必懂）**：
- **静态** = 看**一张照片** → 没速度。
- **看两帧** = 看**两张连拍** → **位置差 ÷ 时间差 = 速度**（**这就是"用历史补信息"**）。
- **看更多帧** = 看**一段视频** → 能**平滑掉噪声**，**估得更准**。
- **所以"加记忆" = "把静态救活成动态"**——**记忆的长度，就是"你愿意看多长的视频"**。**而"到底看多长够"，下一节 POMDP 给上界**。

## 3. 部分可观测马尔可夫决策过程 POMDP（15.3）—— "侦探的案情板"

### 3.1 内存的"上界"：用整个历史，但压缩成"信念"

> 对"**我们需要多少内存**"这个问题，**一个上界**，可以转向 **POMDP 框架**的关键结果。**简短答案**：**如果你用"动作和观测的整个历史"，那显然足以做最优决策**。**与其显式维护这个不断膨胀的历史，不如维护一个"作为该历史充分统计量"的表示**。在"好情况"下，我们能找到**有有限表示**的充分统计量。

**类比（侦探的案情板，全节核心类比，请刻进脑子）**：
- 一个侦探破案，**理论上要记住"所有线索的完整流水账"**（整个历史）——**但流水账越来越长，记不住**。
- 聪明的侦探**不记流水账**，他在墙上钉一块**案情板**，上面写着"**目前每个嫌疑人是凶手的概率**"——**每来一条新线索，他就更新这块板**。
- **这块板 = 信念状态（belief state）**：**它把"无穷长的历史"压缩成"一张概率分布表"**，**而且这张表"包含了历史里所有对'预测未来'有用的信息"**（**充分统计量**）——**有了它，你**可以扔掉流水账**，照样做最优决策**。

### 3.2 POMDP 的正式定义

> 一个（有限）**部分可观测马尔可夫决策过程（POMDP）** 是一个**随机状态空间动力系统**，带有**离散（但可能无限）的**：状态 $S$、动作 $A$、观测 $O$、**初值概率** $p_{s_0}(s)$、**转移概率** $p(s'|s,a)$、**观测概率** $p_{o|s}(o|s)$、以及**确定性代价函数** $\ell:S\times A\to\mathbb{R}$ [8]。**我们的目标 = 最小化有限时域期望代价**：

$$\mathbb{E}\Big[\sum_{n=1}^{N}\ell(s[n],u[n])\Big]$$

**人话**：和 MDP 比，**POMDP 只多了一件事**——**你看不见真状态 $s$，只能看见一个"和 $s$ 有关、但带噪声/可能含糊"的观测 $o$**（由 $p_{o|s}(o|s)$ 描述，即"真状态是 $s$ 时，看到观测 $o$ 的概率"）。**其余（状态、动作、转移、代价）和 MDP 一样**。

### 3.3 信念状态：把"历史"压成"概率分布"

> POMDP 的一个重要思想是**信念状态（belief state）**：

$$b_i[n]=P\big(s[n]=s_i\ \big|\ a_0,o_0,\dots,a_{n-1},o_{n-1}\big)$$

> 其中 $b[n]\in B[n]\subset\Delta^{|S|}$，$\Delta^m\subset\mathbb{R}^m$ 是 $m$ 维**单纯形**（即"所有分量非负、加起来=1 的向量"的集合），$b_i[n]$ 表示第 $i$ 个元素。

**人话**：**$b[n]$ 就是一个"概率分布向量"**——**第 $i$ 个分量 = "在第 $n$ 步，给定我至今看到/做的一切，真状态是 $s_i$ 的概率"**。**它落在单纯形上**（概率和=1）。**这就是侦探案情板上的"各嫌疑人概率"**。

> **$b[n]$ 是 POMDP 的充分统计量**——**它捕获了历史中所有"能用来预测过程未来状态（从而也预测观测和奖励）"的信息**。用 $h_n=[a_0,o_0,\dots,a_{n-1},o_{n-1}]$ 表示所有动作和观测的历史，我们有：

$$P\big(s[n+1]=s\ \big|\ b[n]=b_n,\ h_n,\ a[n]=a_n\big)=P\big(s[n+1]=s\ \big|\ b[n]=b_n,\ a[n]=a_n\big)$$

**人话（"充分统计量"的人话，必懂）**：**一旦你知道了"案情板 $b[n]$"，"流水账 $h_n$"就没用了**——**预测未来时，看板和看流水账，结果一样**。**所以你可以"扔掉流水账，只带案情板"**。

> **它也对最优控制充分**——**最优策略可以写成 $a^*[n]=\pi^*(b[n],n)$**。**信念状态是可观测的**，**最优贝叶斯估计器/观测器**由下面的（信念）状态空间形式给出：

$$b_i[n+1]=f_i(b[n],a[n],o[n]),\qquad b_i[0]=p_{s_0}(s_i)$$

$$f_i(b,a,o)=\frac{p_{o|s}(o|s_i)\sum_{j}p(s_i|s_j,a)\,b_j}{\sum_{i}p_{o|s}(o|s_i)\sum_{j}p(s_i|s_j,a)\,b_j}$$

**人话（信念更新 = 贝叶斯公式，逐字翻译，必懂）**：
- **分子** = "**先按动作 $a$ 预测状态会怎么变**（$\sum_j p(s_i|s_j,a)b_j$ = 旧的信念经转移后的'先验'），**再乘上'如果真状态是 $s_i$，看到观测 $o$ 的可能性'**（$p_{o|s}(o|s_i)$ = 似然）"。
- **分母** = **归一化常数**（让概率加起来=1，= 看到观测 $o$ 的总概率）。
- **这就是贝叶斯定理**：**后验 ∝ 似然 × 先验**。**侦探每来一条线索 $o$，就用贝叶斯公式更新案情板**。

> **用 MDP 的转移矩阵记号**，我们可以把它写成**向量形式**：

$$f(b,a,o)=\frac{\operatorname{diag}(c(o))\,T(a)\,b}{c^T(o)\,T(a)\,b}$$

> 其中 $c(o)$ 是列向量，其第 $i$ 个元素 $c_i(o)=p_{o|s}(o|s_i)$。

**人话**：**$T(a)b$ = "旧信念经动作 $a$ 转移后的先验"（向量）；$\operatorname{diag}(c(o))$ = "把每个分量乘上对应的似然"（逐元素乘）；分母 $c^T(o)T(a)b$ = "归一化"**。**和上面的分式完全一致，只是写成矩阵乘法，方便算**。

### 3.4 Belief MDP：在"信念"上规划——"在案情板的分布上，再套一层分布"

> 我们可以用这个信念更新，**通过对未来观测做边缘化**，构造用于规划的 **"belief MDP"**：

$$p_{b\text{MDP}}(b'|b,a)=\sum_{i\in|O|}p(b'|b,a,o_i)\,p_{o|b,a}(o_i|b,a)$$

> 其中 $p(b'|b,a,o)$ 在 $b'=f(b,a,o)$ 时为 1、否则为 0。

**人话**：**belief MDP 的"状态" = 信念 $b$**（不再是真状态 $s$）。**从信念 $b$ 做动作 $a$，下一个信念 $b'$ 是确定的吗？** **不！** 因为**下一个观测 $o$ 是随机的**——**不同的 $o$ 会把 $b$ 更新成不同的 $b'=f(b,a,o)$**。**所以 belief MDP 的转移 = "对所有可能的 $o$，算出对应的 $b'$，再按 $o$ 的概率加权"**。**这就是上面那个求和**。

> **belief MDP 有点吓人——我们在"演化'信念上的分布'"！**（**套娃**：真状态不确定 → 用信念描述 → 信念的演化又不确定 → 用"信念的分布"描述……）**也许一点小小的安慰**：对**离散问题**，尽管 $b[n]$ 用实值向量表示，**它实际活在一个有限空间 $B[n]$ 里**——**因为给定有限的动作和观测，$n$ 步内只有有限个信念是可达的**。**对 belief MDP 做最优状态反馈的策略，恰好就是原 POMDP 的最优输出反馈**。

**类比（套娃 + 有限安慰，必懂）**：
- **吓人之处** = "**我在'猜测的分布'上，再算'猜测的分布的分布'**"——**像俄罗斯套娃，没完没了**。
- **安慰之处** = "**幸好，离散情况下，'案情板'的可能样子只有有限种**"——**因为线索和动作都只有有限种组合，$n$ 步后案情板"最多长成这几种样子"**。**所以套娃"套到有限层就停了"**。
- **最关键的一句** = "**在 belief MDP 上解出的'最优策略'，搬回原问题，就是'最优的输出反馈策略'**"——**这就是 POMDP 的"魔法"：把'看不见的输出反馈问题'，变成'看得见信念的全状态 MDP 问题'**（**信念是可观测/可算的！**）。**代价 = 状态空间从"有限个 $s$"爆炸成"单纯形上的 $b$"**。

#### Example 15.2（奶酪迷宫 Cheeze Maze）

> POMDP 世界里的**经典简单例子**之一是"**奶酪迷宫**" [9]（**虽然它不太算个迷宫**）。**机器鼠一次移动一格**，**观测 = 地图上画的整数标签**，**目标 = 阴影区域**。

> **想象你被放在迷宫的一个均匀随机位置**。**你知道地图，但你不知道自己的位置**。**你导航到目标的策略是什么？** 如果你的**初始观测是 5**，你**有个决策要做**……**你是乐观地试着往下走**（**指望能撞见目标？**），**还是往上走，去看看是 1、3 还是 4？** **如果初始观测是 2 呢？**

> **人们可以为这个具体问题，用恰好 7 个离散（信念）状态，写出最优策略。你能找到它们吗？**

**人话（奶酪迷宫的"决策直觉"，必懂）**：
- **你蒙着眼站在迷宫里，摸到墙上的数字"5"**。**但地图上"有好几个格子都标着 5"**——**你不知道自己在哪个 5**。
- **这时你的"案情板" = "我在这几个 5 格子的概率分布"**（**初始均匀，所以每个 5 等概率**）。
- **决策**：
  - **往下走** = **赌一把**：**如果某个 5 的下面就是目标，你就赚了**；**但如果不是，你可能白走甚至走死**。
  - **往上走** = **收集信息**：**往上走会摸到 1、3 或 4**——**这些数字能帮你"排除"一些 5 的可能位置**，**让案情板更确定**——**但这一走不直接朝目标**。
- **这就是 POMDP 的核心张力**：**"利用（exploit，乐观冲目标）" vs "探索/信息收集（explore，先摸清自己在哪）"**——**和第13章自适应控制的"探索-利用"是同一个灵魂**。
- **"7 个信念状态"** = **虽然"位置×历史"组合很多，但"案情板的可能样子"被压缩到只有 7 种**——**最优策略只需对这 7 种案情板，各规定一个动作**。**这就是"belief 有限"的体现**。

> **更一般地，在连续状态空间**，信念状态是一个**函数** $b(x,n)=p_{x|h}(x[n]\,|\,h_n)$：

> **[图：$y\to$ Bayes Filter $\to b(x)\to$ Belief Policy $\to u$]**（**观测 $y$ 喂进贝叶斯滤波器，更新信念 $b(x)$，信念再喂给"信念策略"产出动作 $u$**）。

> **机器人领域的 POMDP 文献极其丰富，POMDP 求解技术也是**。见 [10] 一篇不错的近期综述。

**人话**：**连续版的"案情板"不再是一张有限概率表，而是一个"概率密度函数 $b(x)$"**（**每个连续状态 $x$ 一个概率密度**）。**贝叶斯滤波器 = 连续版的"案情板更新器"**。**结构完全一样，只是"表"变成了"函数"**。

**补充概念（LQG = 线性 + 二次代价 + 高斯噪声，必懂）**：

- **它的最优解 = "卡尔曼滤波器（估状态）+ LQR（用估计的状态做控制）"的拼接**——**这就是下一节的"分离原理"**。

**补充概念（iLQG，必懂）**：
- **iLQG** = **把 iLQR（第10章 10.8.2，非线性轨迹上的迭代 LQR）推广到"带噪声"的情况**——**在迭代线性化时，把噪声协方差也算进去**，**得到"考虑了噪声的局部最优反馈"**。
- **它是"非线性 + 随机 + 轨迹优化"三者的交汇**，**也是"基于模型的 RL / 轨迹优化"处理观测噪声的常用工具**。

## 5. 基于观测器的反馈（15.5）—— "先猜状态，再控制"

### 5.0 分离原理：两步分开做，居然还最优（但仅限 LQG！）

> 既然我们对**设计全状态反馈控制器**知道得这么多，**最自然（也是占主导地位）的方法之一** = **先设计一个观测器（又名"状态估计器"），再用状态反馈**。**著名地，对线性高斯系统上的二次调节目标，这个方法实际是最优的（LQG）——这就是所谓的"分离原理（separation principle）"**。**但一般情况下，它绝不最优！**

**类比（分离原理 = "先猜后做，两步分开还最优"，必懂）**：
- **观测器** = **一个"猜状态的侦探"**：他看观测 $y$，**猜**真实状态 $\hat x$。
- **状态反馈** = **一个"看答案做动作的司机"**：他拿侦探猜的 $\hat x$，**当真的**去控制。
- **分离原理说**：**在 LQG（线性+高斯+二次）这个特殊世界里，"侦探"和"司机"可以"各干各的、分开设计"，拼起来居然还是全局最优**——**侦探不用管司机怎么开，司机不用管侦探怎么猜**。
- **但作者警告**：**这只是 LQG 的"特权"！一旦非线性、或非高斯、或非二次，"分开设计"就不再最优**——**这时侦探和司机必须"合谋"（联合设计）才行**。

**人话**：**分离原理是"控制论里最美丽的'巧合'之一"，但它是个"美丽的陷阱"**——**它让几代人以为"估计和控制可以永远分开做"，结果在真实非线性世界里栽跟头**。**作者点出"一般不最优"，就是在拆这个陷阱**。

### 5.1 Luenberger 观测器（15.5.1，占位标题）

> **正文留白（占位）。**

**补充概念（Luenberger 观测器，必懂）**：
- **Luenberger 观测器** = **线性系统最经典的"状态猜测器"**：它**自己内部跑一份系统模型**，**同时拿"真实观测 $y$"和"自己预测的观测 $C\hat x$"做比较**，**用差值（创新/残差）去修正自己的猜测 $\hat x$**。
- **公式直觉**：$\dot{\hat x}=A\hat x+Bu+L(y-C\hat x)$——**$L$ 是"修正增益"**，**$y-C\hat x$ 是"我猜的和实际看到的差多少"**，**差得越多，修正越狠**。
- **它就是卡尔曼滤波器的"确定性祖宗"**——**卡尔曼滤波 = Luenberger + "用最优的方式选 $L$（考虑噪声协方差）"**。

## 6. 基于扰动的反馈（15.6）—— "不猜状态，猜'被踢了几脚'"

> 有一个**有趣的替代方案**，**不去试图观测/估计系统的真实状态**，**在某些情况下能导出输出反馈目标的凸表述**。我们在**随机/鲁棒 MPC** 语境引入的**基于扰动的反馈**概念，可以**扩展到基于扰动的输出反馈**：

$$x[n+1]=Ax[n]+Bu[n]+w[n],\qquad y[n]=Cx[n]+v[n]$$

> **通过参数化一个如下形式的输出反馈策略**：

$$u[n]=K_0[n]\,y[0]+\sum_{i=1}^{n-1}K_i[n]\,e[n-i]$$

> 其中 $e[n]=\dots$ [11]。

**人话（这个思路的精髓，必懂）**：
- 回顾第13章 13.4.3：**基于扰动的反馈** = **不直接对"状态 $x$"反馈，而是对"过去被扰动踢的那几脚 $w[n-i]$"反馈**——**因为 $w$ 能从 $x$ 的历史反推出来，且这么参数化能让优化变凸**。
- **本章把它搬到"输出反馈"**：**没有 $x$，只有 $y$** → **改成对"从 $y$ 历史里估出来的'扰动/残差'序列 $e[n-i]$"反馈**。
- **$e[n]$ 是什么？** **PDF 此处用省略号 $e[n]=\dots$ 略去了定义**（**诚实标注**）。**合理的补充**：$e[n]$ 通常是"**观测创新/残差**"或"**由输出历史重构出的扰动代理**"——**即"我预期该看到什么 vs 实际看到什么"的差**，**它携带了"扰动 + 测量噪声"的信息**。**[11] 的细节正是"如何在只有 $y$ 时，把这套扰动反馈做成凸的"**。
- **为什么值钱？** 因为**它绕开了"估计全状态"这个非凸泥潭**，**直接对"可观测的残差"做线性反馈**，**把输出反馈的搜索变成凸优化**——**和第13章"扰动反馈让鲁棒 MPC 变凸"是同一招的输出反馈版**。

**类比（不猜"车在哪"，猜"刚才被风刮了几级"）**：
- **观测器路线** = **拼命猜"车现在的精确位置"**（难，非凸）。
- **扰动反馈路线** = **不猜位置，只记"过去每秒被风刮了几级"（$e$）**，**然后"按被刮的历史"打方向**——**因为"被刮的历史"能从"车的晃动记录 $y$"里算出来**，**而且这么打方向，优化是凸的**。

## 增补一：把"还不够通俗"的 5 个概念，各加一个类比 / 澄清

1. **为什么"静态输出反馈"一般不能表示最优策略？** 因为**最优决策往往需要"速度/动量"信息**，而**单帧观测 $y$ 不含速度**——**你必须"对 $y$ 求导/差分"才有速度**，**而"求导/差分"需要"过去几帧"= 记忆 = 动态**。**静态 = 不许记忆 = 物理上信息不够**。**所以"静态不够"不是数学巧合，是"信息论必然"**。
2. **belief MDP 为什么"状态空间爆炸"却又"离散时有限"？** 连续看，$b$ 是单纯形上的点（无穷多）；**但离散 POMDP 里，$n$ 步内"动作×观测"的序列只有有限条**，**每条序列对应一个确定的 $b$** → **可达的 $b$ 只有有限个**。**所以"套娃套到第 $n$ 层，只有有限种案情板"**。**但 $n$ 一大，这个"有限"也指数涨**——**这就是 POMDP "难"的根（belief 空间随 horizon 指数膨胀）**，**也是为什么"精确解 POMDP"只对极小问题可行，大问题要靠近似（点基 PBVI、蒙特卡洛树等）**。
3. **分离原理为什么"一般不最优"？** 因为**分离原理依赖"高斯 + 线性 + 二次"三者**——**高斯保证"信念更新是线性的（卡尔曼滤波）"，线性+二次保证"用估计值 $\hat x$ 当真的去控制，误差的影响是'可分离的'"**。**一旦非线性**，**"估计误差"和"控制动作"会"耦合"**（**控制动作会影响"未来能估多准"，即"对偶效应/dual control"**）——**这时"侦探和司机必须合谋"**，**分开设计就次优**。**这个"对偶效应"= "控制动作既推进任务、又收集信息"，是 POMDP/自适应控制的灵魂**。
4. **$e[n]$（15.6 被省略的定义）的合理补充**：在 disturbance-based output feedback [11] 里，$e[n]$ 通常取为**"观测创新/残差"或"由输出历史重构的扰动代理"**——**即 $e[n]\approx y[n]-C\hat x[n]$ 这类"我看到 vs 我预期"的差**，**它把"扰动 $w$ + 测量噪声 $v$"的信息打包**。**用 $e$ 的过去值做线性反馈，能保持凸性**——**这正是 [11] 的贡献**。**（PDF 原文 $e[n]=\dots$ 省略，此处为忠实于思想的补充，非 PDF 原文。）**
5. **"像素空间不光滑"到底什么意思？** 控制工具（梯度、SOS、LQR）大多要"**目标/动力学对输入光滑可微**"。**但"像素 → 有用信息"这个映射极不光滑**：**机器人手臂移动 1 毫米，可能"遮挡/露出"一个物体，导致像素"剧烈跳变"**（**遮挡的不连续**）；**光照一变，整张图像像素全变，但"物理状态"没变**。**这种"像素对物理状态的高度非线性/不连续"，让"基于像素做梯度优化"极难**——**这就是作者说"传统综合工具被打断"的根**，**也是他"意难平"的点**（**他认为"有用的结构"藏在这些不光滑之下，该挖出来**）。

### 实验 1：复现 Example 15.1 —— 静态输出反馈的"不连通稳定集"（PDF 唯一实验，必跑）

**扫 $k$，算闭环 $A-BkC$ 的最大特征值实部，画出来——亲眼看"稳定 $k$ 是断开的几段"**。

```python
import numpy as np
import matplotlib.pyplot as plt
A = np.array([[0,0,2],[1,0,0],[0,1,0.]]); B = np.array([[1.],[0],[0]]); C = np.array([[1,1,3.]])
BC = B @ C                                  # 3x3，闭环 = A - k*BC
ks = np.linspace(-3, 6, 2000)
max_real = [max(np.real(np.linalg.eigvals(A - k*BC))) for k in ks]
max_real = np.array(max_real)
plt.figure(figsize=(8,4))
plt.plot(ks, max_real, 'b')
plt.axhline(0, color='r', ls='--', label='稳定边界(实部=0)')
plt.fill_between(ks, max_real, 0, where=(max_real<0), color='green', alpha=.25, label='稳定 k 区间')
plt.xlabel('静态反馈增益 k'); plt.ylabel('闭环最大特征值实部')
plt.title('Example 15.1：稳定 k 的集合是"不连通"的几段（中间夹着炸区）'); plt.legend(); plt.grid(alpha=.3)
plt.show()
# 打印稳定区间，亲眼确认"断开"
stable = ks[max_real < 0]
# 找断点
breaks = np.where(np.diff(stable) > 0.05)[0]
print("稳定 k 大致区间数 =", len(breaks)+1, " -> 不连通！梯度下降会卡在某一岛，跳不过炸区")
```

**你会看到**：**绿色稳定区是"断开的两三段"，中间被红色炸区隔开**——**亲手验证 [7] 的"稳定集不连通"**。**这就是"为什么静态输出反馈难优化"的视觉铁证**：**你的梯度下降若落在左边那个岛，永远游不到右边那个"也许更优"的岛**。

### 实验 2：信念更新 —— 侦探案情板的"贝叶斯更新"（对照 15.3，可跑）

**一个 3 状态迷你 POMDP，手动喂观测序列，看信念 $b$ 怎么被贝叶斯公式更新**——**亲手摸"历史压缩成信念"**。

```python
import numpy as np
# 3 状态 S={0,1,2}, 2 动作(这里固定 a=0), 2 观测 O={0,1}
T = np.array([[[0.7,0.3,0.0],[0.0,0.7,0.3],[0.3,0.0,0.7]]])   # T[a][i,j]=p(s_i|s_j,a) 列=from
O = np.array([[[0.9,0.1],[0.1,0.9],[0.5,0.5]]])                # O[a][o,i]=p(o|s_i)
def belief_update(b, a, o):
    c = O[a][o]                                  # 似然向量 c_i = p(o|s_i)
    prior = T[a] @ b                             # 先验 = 转移 × 旧信念
    unnorm = c * prior                           # 似然 × 先验
    return unnorm / unnorm.sum()                 # 归一化 = 后验（即 diag(c)T b / cᵀT b）
b = np.ones(3)/3                                 # 初始均匀信念（"完全不知道在哪"）
print("初始信念(均匀):", np.round(b,3))
for o in [0, 0, 1, 0]:                           # 喂一串观测
    b = belief_update(b, 0, o)
    print("看到观测 %d 后信念:" % o, np.round(b,3))
# 观察：信念从"均匀"逐渐"尖"到某个状态 -> 历史被压缩成一张概率表，且越来越确定
```

**你会看到**：**信念从 $[.33,.33,.33]$ 逐渐"尖"向某一状态**——**亲手验证"每来一条观测，案情板就更确定一点"**。**改观测序列，看信念往不同方向尖**——**这就是 POMDP 的"信息收集"**。

### 实验 3：LQG 分离原理 —— 卡尔曼滤波 + LQR 拼接（对照 15.4/15.5，可跑）

**线性系统 + 高斯噪声，分别设计卡尔曼滤波器（估 $\hat x$）和 LQR（用 $\hat x$ 控制），拼起来跑——验证"分离原理：两步分开做还稳"**。

```python
import numpy as np
from scipy.linalg import solve_discrete_are, solve_discrete_lyapunov
A=np.array([[1,1],[0,1]]); B=np.array([[0],[1]]); C=np.array([[1,0.]])   # 只测位置
Q=np.eye(2); R=np.eye(1); W=0.01*np.eye(2); V=0.1*np.eye(1)              # 过程/测量噪声协方差
# LQR 增益 K（用真状态的理想控制）
S = solve_discrete_are(A,B,Q,R); K = np.linalg.solve(R+B.T@S@B, B.T@S@A)
# 卡尔曼增益 L（对偶：把 (A,C,W,V) 当 (Aᵀ,C,...) 解）
P = solve_discrete_are(A.T, C.T, W, V); L = (A@P@C.T) @ np.linalg.inv(C@P@C.T + V)
# 闭环仿真：真状态 x + 估计 xhat，控制 u = -K xhat
rng=np.random.default_rng(0); x=np.array([2.,1.]); xhat=np.zeros(2); cost=0.
for _ in range(200):
    y = C@x + rng.multivariate_normal([0],V).ravel()      # 带噪观测
    xhat = A@xhat + B@(-K@xhat) + L@(y - C@xhat)          # 卡尔曼更新(含控制项)
    u = -K@xhat
    x = A@x + B*u + rng.multivariate_normal([0,0],W)      # 真系统+过程噪声
    cost += x@Q@x + u@R@u
print("LQG(分离原理) 累计代价 =", round(cost,2), " -> 卡尔曼+LQR 分开设计，闭环仍稳定")
print("最终真状态 x ≈", np.round(x,3), " 估计 xhat ≈", np.round(xhat,3))
```

**你会看到**：**真状态 $x$ 被稳到原点附近，且估计 $\hat x$ 紧跟 $x$**——**亲手验证"分离原理：观测器和控制器各干各的，拼起来还 work"**。**把噪声 $W,V$ 调大**，**看 $\hat x$ 跟得变差、但闭环仍稳**——**体会"分离原理的鲁棒边界"**。

### 实验 4：静态 vs 动态输出反馈 —— "加记忆"救活平衡任务（对照 15.2.2，可跑）

**双积分器，只测位置。静态反馈 $u=-k\,y$（无记忆）稳不住；动态反馈 $u=-k_p y - k_d (y-y_{prev})$（用差分估速度=1 步记忆）能稳住**——**亲手验证"静态不够，加记忆=动态，就够"**。

```python
import numpy as np
A=np.array([[1,1],[0,1.]]); B=np.array([[0],[1.]]); C=np.array([[1,0.]])   # 只测位置
rng=np.random.default_rng(1)
def sim(use_memory):
    x=np.array([1.0,0.5]); y_prev=None; 
    for _ in range(300):
        y = C@x
        if not use_memory:
            u = -0.5*y                                   # 静态：只用当前 y（无速度信息）
        else:
            vy = 0.0 if y_prev is None else (y-y_prev)   # 动态：差分估速度（1步记忆）
            u = -1.2*y - 1.8*vy                          # 位置+估计速度 反馈
            y_prev = y
        x = A@x + B*u
        if np.linalg.norm(x)>1e3: return False, x        # 发散
    return np.linalg.norm(x)<0.5, x
ok_static, xf_s = sim(False); ok_dyn, xf_d = sim(True)
print("静态输出反馈(无记忆) 稳住? %s  终态=%s" % (ok_static, np.round(xf_s,2)))
print("动态输出反馈(1步记忆) 稳住? %s  终态=%s" % (ok_dyn, np.round(xf_d,2)))
# 结论：一张照片(静态)没速度->稳不住；两帧差分(动态)补出速度->稳住。呼应15.2.2
```

**你会看到**：**静态反馈 `False`（发散或稳不住），动态反馈 `True`**——**亲手验证 15.2.2 的论断**：**"只看当前观测"物理上缺速度，平衡不了；"加一步记忆做差分"补出速度，就平衡得了**。**这就是"静态→动态"的必要性**。

### 实验 5：Teacher-Student 蒸馏 —— 全状态 LQR 当 teacher，只用位置的 student 学（对照 15.1.2/15.7.4，可跑）

**teacher = 全状态 LQR（看得到速度）；student = 一个只用"位置历史窗口"的小线性模型，模仿 teacher 的动作**——**亲手摸"把全状态反馈蒸馏成输出反馈"**。

```python
import numpy as np
from scipy.linalg import solve_discrete_are
A=np.array([[1,1],[0,1.]]); B=np.array([[0],[1.]]); C=np.array([[1,0.]])
S=solve_discrete_are(A,B,np.eye(2),np.eye(1)); Kt=np.linalg.solve(1+B.T@S@B, B.T@S@A)  # teacher
# 收集 teacher 在随机初值下的 (位置历史窗口 -> 动作) 数据
rng=np.random.default_rng(2); H=3  # 历史窗口长度
Xs, Us = [], []
for _ in range(4000):
    x=rng.randn(2)*2; hist=[]
    for _ in range(H+1):
        hist.append((C@x)[0]); u=-(Kt@x)[0]
        if len(hist)==H: Xs.append(hist[:]); Us.append(u)
        x=A@x+B*u
Xs=np.array(Xs); Us=np.array(Us)
# student = 线性回归：u = W @ [y_{t},y_{t-1},y_{t-2}]  （只用位置历史，无真速度）
W = np.linalg.lstsq(Xs, Us, rcond=None)[0]
# 测试 student 闭环
x=np.array([1.0,0.5]); hist=[0.]*H; 
for _ in range(300):
    y=(C@x)[0]; hist=[y]+hist[:-1]; u=W@np.array(hist)   # student 只用位置历史
    x=A@x+B*u
print("teacher-student 蒸馏：student(只看位置历史) 终态 =", np.round(x,3),
      " -> 把全状态LQR'蒸馏'成了输出反馈")
```

**你会看到**：**student 只用"位置历史窗口"（没有真速度），却能把状态稳到原点附近**——**亲手复现 15.1.2 / 15.7.4 的 teacher-student**：**全状态 teacher 当"老司机"，只看后视镜（位置历史）的 student 模仿他，照样学会开车**。**窗口 $H$ 调大**，**student 学得更好**——**呼应"记忆越长，信息越全"**。

## 给初学者的"本章通关三句话"

1. **扯下遮羞布：你只有 $y$，没有 $x$**：前14章"开卷"，本章"闭卷+近视"——**控制器只能基于带噪、可能残缺的观测 $y$ 决策**；**有些状态永远测不到，有些要靠"主动探头"（信息收集动作）才能看清**——**而机器人操作（扣扣子、做沙拉）根本不需要"全状态"，这正是输出反馈的主战场**。
2. **静态不够，信念来凑**：**只看当前一帧 $u=\pi(y)$（静态）一般不够**（单帧没速度），**且线性静态稳定都是 NP-hard + 稳定集不连通**（Example 15.1）；**救法是加记忆变"动态"，而 POMDP 给出"记忆的上界"——把整段历史压缩成"信念状态 $b$"（贝叶斯案情板），在 $b$ 上规划（belief MDP）就等价于原问题的最优输出反馈**。
3. **分离原理是美丽的陷阱，像素反馈是意难平**：**LQG 的"卡尔曼+LQR 分开做还最优"（分离原理）只是线性高斯的特权，一般不最优**（控制与估计会"耦合"=对偶效应）；**而相机像素"高维+不光滑"打断了传统综合工具，逼大家全押模仿/黑盒 RL——但作者"意难平"，认为"有用的结构"藏在像素之下，呼吁"学习的表示 + 控制的保证"联手，把婴儿从洗澡水里捞回来**。
