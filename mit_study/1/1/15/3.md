你引用的这段话，其实代表了**现代机器人控制领域一个非常重要的思想冲突和未来方向**：

> 传统控制理论的人认为：

> 深度学习 / RL / 模仿学习的人认为：

而这段话的作者站在中间：

这其实就是目前具身智能（Embodied AI）最核心的技术路线之一。近年来大量研究都在尝试把学习策略和 Lyapunov、Barrier Function、MPC、Reachability、SOS 等形式化保证结合起来。([Proceedings of Machine Learning Research][1])

这是机器人最现实的问题。

[
x
]

[
y
]

例如：

[
y=h(x)
]

---

问题：

如何从：

图片

推断：

状态？

这就是：

Pixels → Torques

MIT Russ Tedrake 的课程中专门讨论了输出反馈问题，即控制器必须根据传感器输出而非真实状态做决策。([Underactuated Robotics][4])

---

传统方法：

Kalman Filter：

[
估计x
]

深度学习：

Encoder：

[
图片→z
]

结合：

```
Camera

↓

Neural Encoder

↓

belief state

↓

Controller

↓

Torque
```

# 第四块：SOS交替

SOS：

Sum Of Squares。

平方和优化。

帮助计算：

“这个系统是否稳定”。

---

例如：

寻找：

Lyapunov函数：

[
V(x)
]

要求：

[
V(x)>0
]

并且：

[
\dot V(x)<0
]

证明：

不会倒。

---

但是：

神经网络非常复杂。

所以：

现在研究：

学习神经控制器：

同时寻找：

证明。

例如：

2024年的工作已经尝试让神经网络控制器和 Lyapunov 稳定性证书一起学习，并验证稳定区域。([Proceedings of Machine Learning Research][1])

过去：

```

```

```
深度学习：
懂世界，不懂物理
```

```
机器人智能 =
学习的世界理解能力
+
```
