# 从“上帝视角”到“盲人视角”：输出反馈与从像素到力矩
## 1. 引言：我们不再是“上帝”了
在之前的所有章节（LQR、轨迹优化等）中，我们都有一个隐含的假设：**机器人精确知道自己当下的状态**。比如，它知道自己的关节角度是 30.5 度，角速度是 2.1 弧度/秒。这叫**全状态反馈**。
但在现实中，这几乎是不可能的。
*   **传感器噪声**：编码器有误差，摄像头画面有噪点。
*   **不可观测状态**：你看得见机器人的位置，但你看不见它关节内部的摩擦力变化。
*   **高维输入**：如果你用摄像头，输入是一张几百万像素的图片，而不是几个数字。
本章的核心问题就是：**既然不能直接获取状态 $x$，只能获取测量值 $y$，我们该怎么设计控制器 $u$？** 这就是**输出反馈**。
---
## 2. 经典控制与现代控制：频率域与状态域的对话
在“现代控制”（状态空间法，我们一直在学的）出现之前，“经典控制”主要处理的就是输出反馈。
*   **工具**：传递函数、波特图、频域分析。
*   **核心任务**：调整系统的频率响应，比如“极点配置”和“回路整形”。
*   **比喻**：经典控制就像调收音机。你不知道收音机内部每个电容电阻的具体数值（状态），但你知道旋钮转到哪（输出反馈），声音就会变好（系统稳定）。
现代控制虽然强大，但 Tedrake 教授提醒我们，经典控制对**鲁棒性**和**动态性能**（如超调量、调节时间）的刻画非常丰富，这些是我们从纯数学优化中容易忽略的宝贵财富。
---
## 3. 静态输出反馈：为什么不能只看现在？
最直觉的想法是：**直接用测量值 $y$ 来计算控制量 $u$**。
比如 $u = -K y$。这叫**静态输出反馈**（Static Output Feedback），因为它没有记忆，只看当前的 $y$。
### 3.1 一个令人沮丧的数学结论：NP-Hard
你可能会想，找那个增益矩阵 $K$ 应该不难吧？
不幸的是，数学家证明了：**寻找一个能稳定系统的静态输出反馈矩阵 $K$，是 NP-Hard 问题。**
**比喻**：
想象一个布满地雷的平原。
*   平原上的每一个点代表一个可能的 $K$ 值。
*   大部分地区都是地雷（导致系统不稳定）。
*   只有少数几个孤立的“安全岛”能让系统稳定。
**Example 15.1 的启示**：
文档中举了一个简单的例子：$\dot{x} = Ax + Bu, y = Cx$。
它画了一个图，横轴是增益 $k$。你会发现，只有当 $k$ 落在几个非常狭窄的区间时，系统才是稳定的。这就像在玩“跳房子”，你必须极其精准地跳到安全格子里，稍微偏一点点就炸了。这就是为什么我们通常不能简单地用 $u=Ky$ 来控制复杂系统。
### 3.2 为什么要看历史？（记忆的重要性）
如果你只看当前的测量值，在某些任务中是**不可能**完成的。
*   **例子**：平衡一根摆杆。
    *   传感器只能测**角度**（位置）。
    *   但是，LQR 控制器需要**角度**和**角速度**两个量。
    *   如果你只看当前角度，你永远不知道它是往哪边倒（因为速度信息隐藏在历史里）。
*   **解决方法**：你需要看“历史”。比如记录前 0.01 秒和现在的角度，算出差值，这就是速度。
*   **代价**：一旦控制器需要记忆（存储历史），它就变成了**动态输出反馈**（Dynamic Output Feedback），这就更复杂了。
---
## 4. 理论上限：部分可观测马尔可夫决策过程（POMDP）
既然需要记忆，那到底需要多少记忆？这就引出了控制理论的终极Boss：**POMDP**。
### 4.1 信念状态
在 POMDP 中，机器人不知道自己确切在哪（状态 $x$），它只能根据看到的（观测 $o$）来**猜**。
我们用一个概率分布来表示这个“猜测”：
$$ b = [P(x_1), P(x_2), ..., P(x_n)] $$
这个 $b$ 就叫**信念状态**。
*   **核心性质**：信念状态包含了所有历史信息的精华。你不需要记住过去发生了什么，只要现在的信念状态对了，你就能做出最优决定。
**代码/实验补充（Example 15.1：奶酪迷宫）**：
这是一个经典的 POMDP 例子。
*   **场景**：一个迷宫，你是一个盲鼠。你不知道自己在哪。
*   **观测**：你只能闻到格子里的数字（1, 2, 3, 4, 5）。
*   **目标**：找到有奶酪的格子。
*   **策略**：
    *   如果你一开始闻到 '5'，你知道你在中间。你很纠结：是往左走找奶酪，还是往上走确认位置？
    *   这就是在做**信念更新**。你的信念 $b$ 是一个关于位置的分布。你的策略 $\pi(b)$ 告诉你：基于现在的概率分布，往哪走期望收益最大。
*   **编程实践**：在写 POMDP 求解器时，核心代码就是实现**贝叶斯滤波**来更新这个概率分布向量。

## 5. 线性高斯系统：LQG 与分离原理
如果系统是线性的，噪声是高斯分布（正态分布），那么我们有一个完美的解决方案：**LQG（线性二次型高斯控制）**。
**分离原理**：
这是控制理论中最令人欣慰的结论之一。
它说：你可以把问题拆成两步独立解决：
1.  **设计观测器**：只负责从 noisy 的 $y$ 估计状态 $\hat{x}$（比如用卡尔曼滤波 Kalman Filter）。
2.  **设计控制器**：只管怎么用 $\hat{x}$ 算出 $u$（比如用 LQR）。
把这两个东西串联起来，就是**最优**的输出反馈控制器。
**代码实践补充**：
在 Python (Control Systems Library) 或 MATLAB 中，LQG 的实现非常标准：
1.  定义系统矩阵 $A, B, C, Q, R$。
2.  定义噪声协方差矩阵 $W$ (过程噪声) 和 $V$ (测量噪声)。
3.  调用 `dlqr(A, B, Q, R)` 求控制增益 $K$。
4.  调用 `kalman(A, C, W, V)` 求滤波增益 $L$。
5.  闭环系统：$\hat{x}_{new} = A\hat{x} + Bu + L(y - C\hat{x})$。
6.  控制输出：$u = -K\hat{x}$。

## 6. 基于干扰的反馈：另辟蹊径
既然估计真实状态 $x$ 这么难，我们能不能换个思路？
**不去估计 $x$，而是直接估计干扰 $w$。**
**直觉**：
*   假设机器人想保持静止（$x=0$）。
*   有一阵风（干扰 $w$）把它吹跑了。
*   我们不需要知道它现在确切在哪，我们只需要知道刚才那阵风是往左吹还是往右吹，然后往反方向推杆子。
**参数化形式**：
控制器的输入变成了过去所有的“误差”历史 $e[n]$（即测量值与预期的偏差）。
$$ u[n] = K_0 y[0] + K_1 e[1] + ... + K_n e[n] $$
这实际上是一个**有限脉冲响应（FIR）**滤波器。这把输出反馈问题变成了一个凸优化问题（可以通过 SDP 求解），这比 NP-Hard 的静态 $K$ 搜索要好得多。

## 7. 从像素到力矩：深度学习的浪潮
最后，我们来到了最前沿的话题：**直接用摄像头图像（像素）控制机器人**。这就是“Pixels-to-Torques”。
### 7.1 为什么这很难？
*   **高维**：一张 $640 \times 480$ 的图片有 30 万个像素，而且还有颜色通道。
*   **非平滑**：改变一个像素的颜色，对图像的影响是离散的、突变的。模型控制最喜欢平滑的函数，讨厌这种突变。
### 7.2 师徒学习
这是目前解决这个问题的主流方法。
1.  **老师**：一个拥有全状态反馈（上帝视角）的专家控制器（比如用 MPC 或 LQR 训出来的）。
2.  **学生**：一个神经网络，它只能看到摄像头拍到的像素图。
3.  **训练**：老师演示怎么走，学生在一旁模仿。
    *   老师输入的是状态 $x$，输出力矩 $u$。
    *   学生输入的是像素 $y$，输出力矩 $u$。
    *   只要学生学得像，它就学会了**从像素中隐式地提取状态信息**，并学会了控制。
**代码实践补充**：
实现这个流程通常需要 PyTorch 或 TensorFlow。
*   **数据采集**：在模拟器里跑 Expert（状态控制），记录 `(image, torque)` 对。
*   **网络架构**：通常是一个 CNN（卷积神经网络）接一个 MLP（多层感知机）。
*   **损失函数**：MSE Loss，最小化学生输出和老师输出（力矩）的差距。
### 7.3 现状与未来
目前，在这个领域，**模仿学习**和**黑盒强化学习**占据主导地位，而传统的基于模型的控制显得有些力不从心。但 Tedrake 教授认为，我们不应该抛弃模型控制的智慧。未来的方向是将两者结合：用深度学习来处理感知（像素到状态），用模型控制来处理决策（状态到力矩）。

## 9. 给工程师的最后建议
在构建实际的机器人系统时：
1.  **优先使用分离原理**：如果你能写出物理模型，先用卡尔曼滤波估计状态，再用 LQR/MPC 控制。这是最稳健的工程路径。
2.  **不要轻视 P-控制器**：虽然它只是静态输出反馈，但在很多简单的电机控制回路里，它依然好使且便宜。
3.  **拥抱“像素”**：如果你在做视觉抓取，不要试图建立精确的 3D 模型。利用深度学习（师徒学习）来建立“像素 -> 力矩”的端到端映射，是目前最有效的捷径。
4.  **理解“状态”的本质**：状态不仅仅是物理量（位置、速度），它本质上是一个“充分统计量”。在复杂任务中，好的状态表征甚至是神经网络中间层的一组特征向量。
