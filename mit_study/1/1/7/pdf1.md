# 用大白话讲透《Underactuated Robotics》第7章：动态规划与最优控制

> 这份教材（Russ Tedrake, MIT）讲的是机器人控制里一个"换脑袋"的想法：**别再绞尽脑汁手写控制器了，把"控制"变成一个"找最优解"的数学题**。下面我用完全通俗的方式，把这一章从头到尾拆给你看。

---

## 一、先建立一个核心直觉：控制 = 给机器人打分

想象你在教一个小机器人从房间一角走到另一角的充电器。你会怎么教？

**传统思路（PID/反馈控制）**："偏左了就向右走，偏右了就向左走"——靠"纠错"来行动。

**最优控制思路（本章核心）**：先定一个**"扣分规则"**，然后让机器人自己找到"总扣分最少"的走法。比如：
- 每走一步扣 1 分（鼓励快点到）
- 离充电器越远，每秒额外扣分（鼓励走直线）
- 动作太猛也扣分（鼓励平稳）

**机器人要做的，就是找到一条"总扣分最少"的路径和动作序列**。这就是**最优控制（Optimal Control）**。

📌 **本章最核心的一句话**：把"设计控制器"变成"最小化一个标量代价函数"。这就是动态规划（Dynamic Programming）的出发点。

## 二、双重积分器：一个能用手算的最简单例子

教材用一个超级简单的系统开场——**"双重积分器"**。

### 2.1 物理画面：冰面上的砖头

想象一块单位质量的砖头，放在**无摩擦的冰面**上，可以沿 x 轴滑动。你可以施加一个水平的力 `u`。

砖头的运动方程：
$$\ddot{q} = u, \quad |u| \leq 1$$

- `q` = 砖头位置
- `\dot{q}` = 砖头速度  
- `\ddot{q}` = 砖头加速度 = 你施加的力 `u`
- `|u| ≤ 1` = 你的力气有限，最大只能推到 1 或 -1

**任务**：让砖头从任意初始位置、任意初始速度，**尽快停下来，且正好停在原点 q=0, q̇=0**。

### 2.2 最短时间问题：Bang-Bang 控制

教材问：力气有限的情况下，怎么最快停到原点？

直觉答案非常漂亮——**Bang-Bang 控制**（"砰砰"控制）：
- 如果砖头在原点左边（q<0）且向右运动（q̇>0），你就**全力向左推（u=-1）**，让它减速
- 当速度减到某个"临界时刻"，**反过来全力向右推（u=+1）**，让它刹停在原點

换句话说：**先全力加速冲向目标，到了临界切换面就全力刹车**。

教材通过积分运动方程，推导出切换面是一条**抛物线**：
- 当 `u = -1` 时：`q = -½q̇² + c₋`
- 当 `u = +1` 时：`q = ½q̇² + c₊`

这条抛物线就是"切换面"——砖头一旦落到这条线上，就反转推力方向，然后顺着抛物线滑入原点。

> 💡 **直观理解**：就像停车入库。你先踩油门冲向车位，在恰当时机猛踩刹车，车正好停进车位不撞墙。这个"恰当时机"就是切换面。

### 2.3 二次代价问题：另一种打分方式

除了"最短时间"，教材还提出另一种打分：
$$\min \int_0^\infty [q^2 + \dot{q}^2 + u^2] dt$$

翻译：位置偏差要小 + 速度要小 + 用力要省。三者权衡，总分最低。

这种"二次代价"会导致**指数级趋近原点**（慢慢靠近，而不是有限时间到达）。而且教材后面会用 HJB 方程证明，最优控制器是：
$$u^* = -q - \sqrt{3}\dot{q}$$

这是一个**线性反馈控制器**——和 PID 长得像！但它是最优控制算出来的，不是拍脑袋调参调出来的。

### 2.4 为什么要用"双重积分器"这个小玩具？

教材特意选这个例子，是因为它**简单到能用手推公式解出最优控制器**。但对于更复杂的系统（比如单摆、人形机器人），解析解几乎不可能写出来——这时候就要靠**数值方法（动态规划）**了。

## 三、动态规划的核心思想：从终点往回"算账"

### 3.1 值函数（Value Function）：每个状态的"预估总扣分"

定义 **J*(x)** = 从状态 x 出发，执行最优策略后，未来累计的总代价。

- J* 越大 = 这个状态越"糟糕"（到目标要扣很多分）
- J* = 0 = 已经到目标，不再扣分

**J* 就是"值函数"**，它把"未来会扣多少分"压缩成了一个数字，附着在每一个状态上。

### 3.2 贝尔曼方程：动态规划的"递归魔法"

贝尔曼方程（Bellman Equation）是这一章的数学灵魂：

$$J^*(x) = \min_u [\ell(x, u) + J^*(f(x, u))]$$

翻译成人话：
> **从状态 x 出发的最优总代价 = 当前这一步的代价 ℓ(x,u) + 下一步状态的最优总代价 J***

这就是**"最优性原理"**：不管前面怎么走，从现在开始走的这段路，必须是最优的。

### 3.3 值迭代算法（Value Iteration）：从终点往回传播扣分

教材给出的算法非常简单：

```
1. 初始化：对所有状态 s，令 J*(s) = 0
2. 重复以下更新，直到收敛：
   对每个状态 s：
     J*(s) = min_{a∈A} [ ℓ(s,a) + J*(f(s,a)) ]
3. 收敛后，最优策略就是：
   π*(s) = argmin_{a∈A} [ ℓ(s,a) + J*(f(s,a)) ]
```

🎯 **直觉比喻**：想象一个迷宫，出口处写着"代价 0"。你站在迷宫里，想知道"从这里到出口最少要扣多少分"。做法是从出口开始，**一圈一圈往外传播代价数字**——每向外扩一格，就把"当前格的代价 + 走一步的代价"写到相邻的格子上，取最小的那个。多轮传播后，每个格子都拿到了"到自己到出口的最小代价"。**这就是值迭代**。

教材强调：**这个算法保证收敛到最优值函数**（差一个常数因子）。

## 四、网格世界：值迭代的直观演示

教材用了一个经典例子——**网格世界（Grid World）**：

- 机器人住在网格里
- 目标格子代价为 0
- 障碍物格子代价为 10
- 其他格子每待一步代价为 1
- 动作：上下左右移动或不动

**值迭代过程**：
1. 开始时所有格子都是 0
2. 第一轮更新：目标格子旁边的格子发现自己"走一步就到目标"，于是把自己的 J 设为 1
3. 第二轮更新：更远的格子发现自己"走一步能到 J=1 的格子"，于是把自己的 J 设为 2
4. 如此扩散……
5. 最终每个格子都有了"到目标的最小步数"

提取策略时，机器人只需"往 J 值更小的相邻格子走"即可。

> 💡 **关键洞察**：值迭代算法**完全不知道机器人在和什么物理系统打交道**——它只知道"状态、动作、转移规则、单步代价"。正因如此，同一个算法可以套用到双重积分器、单摆、人形机器人……**这就是动态规划的通用性**。

## 五、从离散到连续：哈密顿-雅可比-贝尔曼方程（HJB）

前面的值迭代是针对**离散状态、离散动作**的。但真实机器人是**连续状态、连续动作**的。教材把贝尔曼方程推广到连续情形，得到**HJB 方程**：

$$0 = \min_u \left[ \ell(x, u) + \frac{\partial J^*}{\partial x} f(x, u) \right]$$

翻译：在每一个状态 x，存在一个最优动作 u*，使得"当前代价 + 值函数沿系统动力学的变化率"之和为零。

**HJB 方程是一个偏微分方程（PDE）**。教材给出 HJB 充分性定理：如果能找到一个可微函数 J* 满足这个方程，那么对应的策略 π* 就是最优的。

### 5.1 用 HJB 验证双重积分器的最优控制器

教材展示了如何用 HJB 验证前面提到的二次代价最优控制器：

假设 `J*(x) = √3·q² + 2q·q̇ + √3·q̇²`

代入 HJB 方程，可以解出：
$$u^* = -q - \�3 q̇$$

正好就是我们之前声称的最优控制器！**这证明了它确实是最优的**。

> ⚠️ **注意**：对于最短时间问题，J* 在切换面处有"尖点"（不可微），不满足 HJB 充分性定理的"处处可微"假设。但教材指出，在梯度定义良好的地方，HJB 方程依然成立——这提供了"bang-bang 控制是最优的"的有力证据。

### 5.2 控制仿射系统：能写出闭式解的特例

对于一大类系统（称为**控制仿射**，control-affine）：
$$f(x, u) = f₁(x) + f₂(x)u$$

且代价函数为：`ℓ(x,u) = ℓ₁(x) + uᵀRu`（R 正定）

这时 HJB 方程关于 u 是一个正定二次函数，**可以直接求解析最小值**：

$$u^* = -\frac{1}{2}R^{-1}f₂^T(x) \frac{\partial J^*}{\partial x}^T$$

这就是后面 LQR（线性二次调节器）的理论基础——**线性系统 + 二次代价 → 最优控制器是线性反馈**。

## 六、连续系统的数值求解：函数逼近 + 拟合值迭代

HJB 方程很难解析求解（偏微分方程）。教材给出几条数值路线：

### 6.1 网格离散化（Mesh-based）

把状态空间划分成网格，在网格点上存储 J* 的近似值，用**重心插值（barycentric interpolation）**估算非网格点的值。然后在每个网格点上做值迭代更新。

**问题**：
- 维度灾难：状态维度 d，每维 n 个网格点 → 总点数 n^d。人形机器人状态空间可能 40+ 维，网格法直接崩溃。
- 切换面处的 J* 不光滑（如 bang-bang 控制的抛物线切换面），离散化会引入误差。

### 6.2 线性函数逼近

用一组基函数的线性组合来近似 J*：
$$\hat{J}_α^*(x) = \sum_i α_i ψ_i(x) = ψ^T(x) α$$

其中 ψ(x) 可以是多项式、径向基函数等。通过最小二乘法求解最优的 α。

**优点**：对于线性函数逼近器，值迭代**保证收敛到全局最优的 α***。

### 6.3 神经网络拟合值迭代（Neural Fitted Value Iteration）

用神经网络近似 J*。这是当今最流行的方法——也就是**深度强化学习**的核心思想。

更新规则：
$$α ← argmin_α \sum_k (\hat{J}_α^*(x_k) - J_k^d)^2$$

其中 `J_k^d = min_u [ℓ(x_k, u) + \hat{J}_α^*(f(x_k, u))]` 是"目标值"。

**工程技巧**：
- 使用 **Target Network**（目标网络）：用缓慢更新的网络 β 来计算目标值，避免训练不稳定
- 旋转坐标用 sin/cos 表示（避免 360°=0° 的周期性断裂）
- 简单 MLP 通常就够用，卷积网络只在状态像图像时（如围棋棋盘）才有用

## 七、代码实践重点说明（这是本章最该动手的部分）

教材在 Drake 中提供了多个可运行的 Notebook 示例。我按"从易到难"的顺序梳理实践路径：

### 7.1 实验一：网格世界值迭代

**目的**：直观理解值迭代如何从终点往回传播代价。

**动手要点**：
1. 实现一个 4×4 或 5×5 网格
2. 初始化 J(s) = 0 对所有状态
3. 迭代更新：`J(s) ← min_a [ℓ(s,a) + J(f(s,a))]`
4. 可视化每轮迭代后的 J 值和最优策略箭头
5. 观察：目标格子的"代价波"如何一圈圈扩散到全图

**预期现象**：经过若干轮迭代，每个格子都拿到了"到目标的最小步数"，策略箭头会形成从起点到目标的"河流"。

### 7.2 实验二：双重积分器的值迭代

**目的**：验证数值值迭代能否复现解析的 bang-bang 控制。

**动手要点**：
1. 用重心插值在 q ∈ [-2, 2], q̇ ∈ [-2, 2] 的网格上离散化
2. 实现值迭代更新
3. 提取策略：π*(x) = argmin_u [ℓ(x,u) + J*(f(x,u))]
4. 闭环仿真：从随机初始状态运行策略，观察轨迹

⚠️ **关键现象（教材 Exercise 7.5 明确要求观察）**：
- 数值得到的轨迹**近似**抛物线切换面，但不完全贴合
- 控制输入**不是严格的 -1/0/+1**，而是在切换面附近出现中间值
- **原因**：离散化网格的粒度不够细，插值把 bang-bang 控制"平滑化"了
- **解决办法**：加密网格（如从 49×49 增加到 199×199），轨迹会显著更接近解析解

> 📌 **这是 Sim2Real 思苦的雏形**：离散化误差会让"理论最优"在数值实现中变形。这和人形机器人仿真迁移到真机的道理一模一样。

### 7.3 实验三：单摆的值迭代

**目的**：展示动态规划对**解析不可解系统**的强大能力。

**动手要点**：
1. 单摆动力学：`θ̈ = -(g/L)sinθ + u`
2. 同样用重心插值离散化状态空间
3. 运行值迭代
4. 提取策略并仿真

**预期**：值迭代能自动学出"先蓄能摆起，再到最高点稳定"的摆动-up 策略——而这是解析方法很难推导的。

### 7.4 实验四：神经网络拟合值迭代

**目的**：体验现代深度强化学习的雏形。

**动手要点**：
1. 用 PyTorch 定义一个简单的 MLP 近似 J*(x)
2. 采样状态点 x_k
3. 计算每个点的目标值 `J_k^d = min_u [ℓ(x_k, u) + J_α*(f(x_k, u))]`
4. 用 MSE loss 更新网络权重
5. 重复直到收敛

**技巧**：
- 使用 Target Network 稳定训练
- 旋转坐标用 (sinθ, cosθ) 代替 θ
- 优化器用 Adam

## 八、扩展话题（教材后半部分）

### 8.1 折扣因子与无穷时域

无穷时域代价 `∫₀^∞ ℓ dt` 可能不收敛。教材引入**折扣因子 γ**：
$$\min \sum_{n=0}^\infty γ^n ℓ(x[n], u[n])$$

γ ∈ (0,1] 保证了级数收敛。**但代价是改变了最优策略**——折扣越大（接近1），越接近原问题；折扣越小，越"短视"。

连续时间对应：`(1/τ)J* = min_u [ℓ + ∂J*/∂x·f]`

### 8.2 随机控制与 MDP

把确定性转移 `x[n+1] = f(x[n], a[n])` 换成**概率转移**：
$$Pr(s[n+1] = s' | s[n]=s, a[n]=a)$$

值迭代依然成立，只是把 `J*(f(s,a))` 替换为期望 `Σ_{s'} Pr(s'|s,a)·J*(s')`。

**惊人之处**：随机系统的值迭代和确定性系统**几乎一样的贵**——只是多了个求和。

### 8.3 线性规划动态规划

把值迭代改写成线性规划问题：
$$\max c^T J \quad \text{s.t.} \quad ∀a, J ≤ ℓ(a) + T(a)J$$

其中 T(a) 是转移概率矩阵。**惊喜**：线性规划解法可以扩展到线性函数逼近情形，引出"状态相关性权重"的概念。

### 8.4 和积平方动态规划（Sums-of-Squares DP）

对于某些连续系统，可以用**半定规划（SDP）+ 和积平方多项式**来求解值函数，获得**带有稳定性证明**的控制器。这是连接动态规划与李雅普诺夫稳定性理论的桥梁。

## 九、核心要点回顾

把这一章浓缩成几句话：

1. **最优控制 = 把控制问题转化为标量代价最小化问题**
2. **值函数 J*(x)** = 从状态 x 出发执行最优策略的未来累计代价
3. **贝尔曼方程**：`J*(x) = min_u [ℓ(x,u) + J*(f(x,u))]`——动态规划的递归灵魂
4. **值迭代**：从终点往回传播代价，保证收敛到最优值函数
5. **HJB 方程**：连续时间版本的贝尔曼方程，是一个偏微分方程
6. **维数灾难**：网格法在高维状态空间不可行 → 引出函数逼近（线性基、神经网络）
7. **拟合值迭代 + 目标网络** = 现代深度强化学习的核心范式
8. **同一套算法适用于任何系统**：双重积分器、单摆、人形机器人、自动驾驶……

### 通俗性补充

对于基础薄弱的读者，我再补充几个原文可能不够直观的点：

1. **为什么叫"动态规划"？** "动态"指系统是随时间演化的，"规划"指在时间序列上做决策。合起来就是"对随时间变化的系统做序列决策"。

2. **"值函数"为什么叫"值"？** 就像经济学里的"现值"——未来所有收益的当前等价。J*(x) 就是"从状态 x 出发的未来总代价的当前估值"。

3. **HJB 方程为什么难解？** 因为它是**偏微分方程**，且 J* 出现在方程两边（自己等于含有自己的最小值）。这就像"用镜子里的自己定义自己"——只能通过数值迭代逼近。

4. **代码实践中最重要的洞见**：数值值迭代得到的策略**永远有误差**，因为：
   - 离散化网格有限 → 切换面被平滑
   - 函数逼近能力有限 → J* 近似有偏
   - 这正是为什么真实机器人需要**Sim2Real 迁移**——和值迭代的数值误差是同一类问题
