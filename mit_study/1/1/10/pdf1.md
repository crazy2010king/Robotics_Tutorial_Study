## 🏞️ 一、核心直觉：下山类比与"能量桶"

想象一个**小球放在山谷里**。如果你推它一下，它会来回滚动，但最终会因为摩擦而停在谷底。为什么？因为**高度（重力势能）一直在减少**，直到达到最小值（谷底）。

李雅普诺夫函数的想法一模一样：
- 给系统的每个状态 x 分配一个"高度值" V(x)
- 证明沿着系统演化的轨迹，这个高度值**只会下降或保持不变**
- 那么系统最终一定会"滑到" V(x) 最小的地方（通常是平衡点）

📌 **李雅普诺夫直接法**：如果能找到一个函数 V(x) 满足：
1. **正定**：V(0)=0，且对所有 x≠0 有 V(x)>0（像一个碗的形状）
2. **导数非正**：V̇(x) = ∂V/∂x · f(x) ≤ 0（沿着系统轨迹，V 只会下降或不变）

那么原点 x=0 是**稳定**的（在 Lyapunov 意义下）。

如果 V̇(x) < 0（严格小于零），那么原点是**渐近稳定**的。
如果 V̇(x) ≤ -αV(x)（α>0），那么原点是**指数稳定**的。

### 单摆的经典例子

无阻尼单摆的总能量就是一个天然的 Lyapunov 函数候选。对于更简单的系统，比如一维三次系统：

$$\dot{x} = -x + x^3$$

取 $V(x) = x^2$（即 $\frac{1}{2}x^2$ 的 2 倍），则：

$$\dot{V} = 2x\cdot\dot{x} = 2x(-x+x^3) = -2x^2 + 2x^4$$

- 当 |x| < 1 时，$\dot{V} < 0$（下坡）
- 当 |x| > 1 时，$\dot{V} > 0$（上坡）

因此，**从 |x|<1 出发的轨迹，最终一定会收敛到原点**——这个区间 (-1, 1) 就是原点的吸引域 。

> 💡 **关键洞察**：我们不用求解三次系统复杂的微分方程，只要看到"在 (-1,1) 内能量一直在减少"，就能断定它最终会停在原点。这就是李雅普诺夫分析的威力。

## 🌍 二、LaSalle 不变集原理：当 V̇ 只是"半负定"时怎么办

### 2.1 单摆的尴尬

有些系统里，V̇ ≤ 0，但 V̇ = 0 不只发生在平衡点。例如单摆中，无阻尼时能量导数 $\dot{E} = -b\dot{\theta}^2 \leq 0$，但 $\dot{E}=0$ 在**所有** $\dot{\theta}=0$ 的状态上都成立——也就是摆锤在最高点时速度也为 0。

如果只用基本 Lyapunov 直接法，只能证明"稳定"，证明不了"渐近稳定"。但实际上我们知道：有阻尼的单摆**最终一定会停在正下方**。

### 2.2 LaSalle 的天才补丁

**LaSalle 不变集原理**：如果 V 正定、V̇ ≤ 0，那么系统会收敛到**"V̇=0 的集合中最大的不变集"**。

**什么是不变集**？就像一个"只能进不能出的旅馆"——一旦你进去了，就永远留在里面。

**单摆分析**：
- V̇=0 的集合 = {所有 $\dot{\theta}=0$ 的状态}
- 但在这个集合中，只有"$\dot{\theta}=0$ 且 $\theta=2\pi k$"的状态是**真正不变的**——因为摆锤如果停在最高点（$\theta=\pi$），一个微小的扰动就会让它离开
- 所以**最大不变集 = 各个平衡点（正下方）**
- 结论：单摆**渐近稳定**到正下方

> 💡 **LaSalle 的价值**：放宽了条件——不再要求 V̇ 严格小于 0，只要半负定 + 分析"平坦区域里的不变集"，就能判定收敛到哪里。

## 🔗 三、李雅普诺夫函数与 HJB 方程的关系

回想上一章动态规划的 HJB 方程：
$$0 = \min_u \left[\ell(x,u) + \frac{\partial J^*}{\partial x}f(x,u)\right]$$

如果我们解出了最优代价函数 $J^*(x)$ 和最优控制 $u^*(x)$，代入后得到：
$$\dot{J}^*(x) = -\ell(x, u^*)$$

**对比李雅普诺夫条件**：$\dot{V}(x) \leq 0$

**核心差异**：
- **HJB 要求严格相等**：J* 的梯度必须精确匹配每个状态的代价率——极其困难，要解高维偏微分方程
- **李雅普诺夫要求不等式**：只要找到一个函数，使其**在任何状态下都在下降**（下降速率随意）——宽松得多

> 📌 **重要推论**：如果找到了最优代价函数 J\*，它**同时也是一个李雅普诺夫函数**（只要 ℓ ≥ 0）。也就是说：**最优控制的解 ⊇ 李雅普诺夫函数的解**——李雅普诺夫条件是 HJB 的"放宽松"版本。
>
> 这就是为什么李雅普诺夫分析既可以用于理论证明，也可以用于数值搜索——条件越宽，越容易满足。

## 🎯 四、吸引域估计：李雅普诺夫函数的"水平集"就是不变集

**定义**：对于渐近稳定的平衡点 x\*，其**吸引域（Region of Attraction, RoA）**是所有满足"从那里出发最终收敛到 x\*"的初始状态的集合。

**定理**：如果 V 正定，且在水平集 $\mathcal{G} = \{x | V(x) \leq \rho\}$ 上 V̇ ≤ 0，那么 $\mathcal{G}$ 是**不变集**，且包含在吸引域内。

### 4.1 三次系统的例子（核心案例）

系统：$\dot{x} = -x + x^3$

取 $V(x) = x^2$，则 $\dot{V} = -2x^2 + 2x^4$。

- 当 |x| < 1 时，$\dot{V} < 0$
- 当 |x| > 1 时，$\dot{V} > 0$

因此，**水平集 V < 1（即 |x| < 1）是不变集**，且包含在吸引域内。这个估计恰好是紧的（tight） 。

> 💡 **直观理解**：在"碗"里画一个水位线 ρ=1，水位线以下的区域是个"盆地"——小球一旦进入这个盆地，就永远出不去，最终必定滚到碗底。

### 4.2 鲁棒性分析：公共李雅普诺夫函数

现实世界的模型参数总有不确定性。比如系统 $\dot{x} = -x + \alpha x^3$，其中 $\frac{3}{4} < \alpha < \frac{3}{2}$。

取 V = x²，则：
$$\dot{V} = -2x^2 + 2\alpha x^4$$

要 $\dot{V} < 0$ 对所有 α 成立，需要：
$$|x| < \frac{1}{\sqrt{\alpha_{max}}} = \sqrt{\frac{2}{3}} \approx 0.816$$

因此，|x| < 0.816 是**鲁棒吸引域**——无论 α 在这个范围内取何值，系统都稳定 。

> 💡 **工程意义**：即使你不知道机器人精确的负载重量，只要重量在某个范围内，你就能保证"机器人永不会翻车"——这就是用公共李雅普诺夫函数做安全证书。

## 🚧 五、障碍函数：证明"系统永远不会进入失败区域"

李雅普诺夫函数证明"系统会收敛到好地方"，**障碍函数（Barrier Function）**则证明"系统永远不会去坏地方"。

**核心思想**：构造障碍函数 $\mathcal{B}(x)$，使得 $-\dot{\mathcal{B}}(\bx) \text{ 是 SOS}$ 且 $\mathcal{B}(0) = 1$。

那么，**超水平集 $\{ \bx | \mathcal{B}(\bx) \ge 0\}$ 是真实吸引域的外近似（outer approximation）** 。

换句话说：
- 如果系统从 $\mathcal{B}(x) < 0$ 的区域出发
- 且 $-\dot{\mathcal{B}} \geq 0$（即 B 不会增加）
- 那么系统**永远无法跨越 $\mathcal{B}(x) = 0$ 这个屏障**进入失败区域

**应用**：
- 自动驾驶：证明"汽车永远不会撞上障碍物"
- 行走机器人：证明"机器人永远不会摔倒"

> 💡 **这是 HALOS 安全层的数学本质**：定义 B(x) 为"距离摔倒禁区的裕度"，要求 Ḃ(x)≤0，从安全状态出发的轨迹永远不会进入禁区——这是比紧急停机更主动的安全策略。

### 5.1 如何找到"最小的外近似"？

为了让外近似尽可能紧，我们引入另一个多项式函数 $W(\bx)$，要求：
$$W(\bx) \ge 0 \quad \text{且} \quad W(\bx) \ge \mathcal{B}(\bx) + 1$$
（都用 SOS 约束实现）

然后最小化积分 $\int_\bx W(\bx)d\bx$——这可以看成在"push down"B(x) 的值 。

Majumdar 等人（2016）更进一步：把目标写成"最小化覆盖椭球的体积"，这是凸优化问题 。

## 💻 六、用凸优化做李雅普诺夫分析：从"手推公式"到"计算机自动证明"

前面所有内容都是"理论框架"——但要真正用于复杂机器人，我们需要**让计算机自动找到李雅普诺夫函数并验证条件**。这一节是本章最硬核也最实用的部分。

### 6.1 线性系统：李雅普诺夫方程与 SDP

对于线性系统 $\dot{x} = Ax$，李雅普诺夫条件是：
$$PA + A^TP \prec 0,\quad P \succ 0$$

这个方程有解析解：$PA + A^TP = -Q$（Q 正定）。但更重要的是，它可以写成**半定规划（SDP）**：
$$\text{find } P \quad \text{subject to } P \succeq 0,\; PA + A^TP \preceq 0$$

**为什么用 SDP？** 因为 SDP 是凸优化，能高效求全局最优解。

### 6.2 多项式系统：平方和（SOS）优化——本章的计算核心

**核心想法**：把"V 正定"这个条件，转化为"V 可以写成平方和（SOS）"——而 SOS 优化是凸的！

对于多项式系统，我们搜索：
$$V(x) = m^T(x) P m(x),\quad P \succeq 0$$
其中 m(x) 是非线性基函数。再要求 -V̇ 也是 SOS。这整个问题就是**凸优化**。

### 6.3 S-procedure：处理"在区域内"的约束

**基本思想**：要证明"在区域 g(x) ≤ 0 内，p(x) ≥ 0"，可以找一个多项式乘子 λ(x) ≥ 0，使得：
$$p(x) + \lambda^T(x)g(x) \text{ 是 SOS}$$

直觉：λ(x) 可以加任意正的项来帮助 p(x) 成为 SOS，但这些项在 g(x)=0 时贡献为零 。

### 6.4 三次系统的 SOS 吸引域估计（**最重要的代码案例**）

Drake 源码 `region_of_attraction.cc` 给出了完整实现 ：

```cpp
// 系统: ẋ = -x + x³
// 候选 Lyapunov 函数: V = x²
const Expression V = x.dot(x);
const Expression Vdot = (Jacobian(Vector1(V), xvar) * derivatives->CopyToVector())[0];

// 最大化 ρ，约束为: (V(x) - ρ)·x² - λ(x)·V̇(x) 是 SOS，且 λ(x) 是 SOS
const Variable rho{prog.NewContinuousVariables("rho").coeff(0)};
const Expression lambda{ prog.NewSosPolynomial(Variables(xvar), 4).first.ToExpression()};
prog.AddSosConstraint((V - rho) * x.dot(x) - lambda * Vdot);
prog.AddLinearCost(-rho);  // 最大化 ρ

const auto result = Solve(prog);
// 断言: ρ ≈ 1.0（即吸引域为 |x| < 1）
DRAKE_DEMAND(std::abs(result.GetSolution(rho) - 1.0) < 1e-6);
```

**Python 等价调用**（Drake 封装）：
```python
x = Variable("x")
sys = SymbolicVectorSystem(state=[x], dynamics=[-x+x**3])
context = sys.CreateDefaultContext()
V = RegionOfAttraction(sys, context)
# 返回的 V 就是 x²，认证吸引域为 |x| < 1
```

> ⚠️ **重要提醒**（Russ Tedrake 原话）："虽然我们尽量让调用这些函数变得方便，但它们**不是黑盒**。我强烈建议打开 RegionOfAttraction 方法的源码，理解它的工作原理。"

### 6.5 多元多项式系统的例子

Parrilo 经典例子 ：
$$\dot{x} = -x + y$$
$$\dot{y} = 0.1x - 2y - x^2 - 0.1x^3$$

Drake 测试代码验证：用 Lyapunov 候选 $V = x^2 + y^2$，SOS 优化找到最大水平集参数 γ ≈ 2.66673² 。

## 🔄 七、有限时间可达性分析

前面讲的都是"t→∞"的稳定性。但很多应用场景关心**有限时间**内系统会怎样：
- 无人机 5 秒内是否会撞树？
- 机器人 2 秒内能否到达目标？

### 7.1 时变李雅普诺夫函数

允许 V 是时变的：$V(t, x)$。条件变为 ：

$$\forall t, \forall \bx \ne 0, \quad \dot{V}(t,\bx) = \pd{V}{\bx}f(\bx) + \pd{V}{t} \le 0$$

### 7.2 有限时间不变集认证

要证明在 $[t_1, t_2]$ 时间段内系统不会离开某个集，只需证明在水平集边界上：

$$\forall t \in [t_1, t_2], \quad \forall \bx \in \{\bx | V(t,\bx) = \rho(t)\}, \qquad \dot{V}(t, x) \le \dot\rho(t)$$

**直觉**：如果在边界上 V 的下降速度比 ρ(t) 的变化速度更快，那么轨迹永远无法从边界逃逸 。

> 💡 **关键点**：有限时间可达性证明的是**不变性（invariance）**，不是稳定性。我们只需在水平集边界上认证 $\dot{V}$ 条件。

### 7.3 用 S-procedure 处理时变约束

由于把 t 也当作未定元（indeterminate），我们可以用 S-procedure 再次认证条件 $\forall t \in [t_1, t_2]$ 成立 。

实践中，我们经常只在有限个采样时刻 $t_i \in [t_1, t_2]$ 上认证 Lyapunov 条件——作者说"我并不反对在一维上采样" 。

## 🎮 八、代码实践重点补充说明（这是本章最该动手的部分）

教材配套的 Drake Notebook `lyapunov.ipynb` 是理解本章的**必经之路** 。以下是按重要性排序的实践路径：

### 实验一：三次系统的吸引域（**最重要**）

**目的**：理解 SOS 优化如何从零开始认证吸引域。

**动手要点**：
1. 定义系统：`SymbolicVectorSystem(state=[x], dynamics=[-x+x**3])`
2. 调用：`V = RegionOfAttraction(sys, context)`
3. 观察：返回的 V 是什么形式（应该是 x²）
4. **打开 `RegionOfAttraction` 源码**，理解 SOS 约束如何构建
5. 修改选项：尝试隐式形式（`options.use_implicit_dynamics = True`）
6. 验证：非零平衡点的情况（`ShiftedCubicPolynomialTest`）

**预期现象**：ρ ≈ 1.0，即认证吸引域为 (-1, 1)，与理论完全一致。

### 实验二：单摆的 Lyapunov 分析与 RoA

**目的**：体验 SOS 在三角函数系统上的威力。

**动手要点**：
1. 单摆动力学：$\dot{\theta} = \omega$，$\dot{\omega} = -(1/ml^2)(b\omega + mgl\cdot\sin\theta)$
2. 用 LQR 设计控制输入，得到 cost-to-go 作为 Lyapunov 候选：$V = x^T S x$
3. 用 S-procedure 做 RoA 分析，确定 Lyapunov 函数和 Lagrange 乘子 
4. 验证：找到最大的 ρ 使得水平集 $V < \rho$ 是不变集

**关键代码段**：
```python
# LQR 的 cost-to-go 作为 Lyapunov 候选
V = x.dot(S.dot(x))
Vdot = Jacobian([V], x).dot(fn)[0]

# S-procedure: 定义 Lagrange 乘子
lambda_ = prog.NewSosPolynomial(Variables(x), 2)[0].ToExpression()

# 优化设置
rho = 2
prog.AddSosConstraint(-Vdot + lambda_*(V-rho))
prog.AddSosConstraint(V)
prog.AddSosConstraint(lambda_)

result = Solve(prog)
```

### 实验三：障碍函数与安全认证

**目的**：用障碍函数证明"机器人永远不会进入禁区"。

**动手要点**：
1. 构造障碍函数 B(x)，要求 $-\dot{B}$ 是 SOS 且 $B(0) = 1$
2. 引入 W(x) 使得 $W(x) \ge 0$ 且 $W(x) \ge B(x) + 1$
3. 最小化 $\int W(x)dx$
4. 观察：超水平集 $\{B(x) \ge 0\}$ 是真实吸引域的外近似

### 实验四：非零平衡点的处理

**目的**：理解 `ShiftedCubicPolynomialTest` 的原理 。

**动手要点**：
```python
x0 = 2  # 非零平衡点
system = SymbolicVectorSystemBuilder().state(x).dynamics(-(x - x0) + pow(x - x0, 3)).Build()
context->SetContinuousState(Vector1d(x0))
V = RegionOfAttraction(*system, *context)
# 预期 V = (x - 2)²
```

### 实验五：Parrilo 多元多项式例子

**目的**：体验多元系统的 SOS 优化 。

**动手要点**：
```python
system = SymbolicVectorSystemBuilder().state({x, y}).dynamics(
    [-x + y, 0.1 * x - 2 * y - x * x - 0.1 * x * x * x]).Build()
options.lyapunov_candidate = x * x + y * y
V = RegionOfAttraction(*system, *context, options)
# 预期水平集参数 γ ≈ 2.66673²
```

### 实验六：隐式动力学形式

**目的**：理解 Drake 的 `use_implicit_dynamics = True` 选项 。

**动手要点**：
- 对于某些系统，显式动力学 ẋ = f(x) 可能是有理函数（因为需要求 M⁻¹）
- 隐式形式 g(x,ẋ)=0 是多项式的
- 用 S-procedure 直接在隐式形式上验证 Lyapunov 条件

### 通俗性补充（针对基础薄弱读者的额外解释）

1. **"正定"是什么意思？** 就像碗的形状——碗底最低（V=0），其他地方都比碗底高（V>0）。

2. **"半负定"为什么比"负定"弱？** 负定是"严格下坡"，半负定是"平坦或下坡"。半负定时，小球可能停在半山腰——所以需要 LaSalle 来找"真正不变的平坦点"。

3. **SOS（平方和）为什么是凸优化？** 因为"一个多项式能否写成平方和"可以转化为"是否存在半正定矩阵 P"——而这是 SDP，属于凸优化，能高效求解。

4. **S-procedure 的直觉**：想象你要证明"在红灯区域内，车速 ≤ 限速"。S-procedure 说：如果能找到一个"非负乘子"λ，使得"车速 - 限速 + λ·(红灯区域边界)"是平方和，那么就证明了原命题。λ 的作用是"在红灯区域外放松约束"。

5. **为什么交替优化能工作？** 就像两个人合作画图：甲画 V，乙画 K。甲固定时乙能画得最好，乙固定时甲能画得最好。反复轮流，最终收敛到一个不错的解（虽然不是全局最优，但递归可行）。

6. **障碍函数与 Lyapunov 函数的对偶关系**：
   - Lyapunov 函数：V(x) ≥ 0，V̇ ≤ 0 → 证明"收敛到好地方"
   - 障碍函数：B(x) ≤ 0，Ḃ ≥ 0 → 证明"不会进入坏地方"
   - 两者是"阴阳互补"的关系

## 🎁 十、整体综合：李雅普诺夫分析在机器人控制中的真正地位

把这一章放到整个机器人控制版图里看：

```
传统稳定性分析（求解微分方程）
    ↓ 非线性系统几乎不可解
李雅普诺夫直接法（找能量函数）
    ↓ 手工找 V 很难
SOS 凸优化（自动搜索 V）
    ↓ 结合
吸引域估计 / 鲁棒性分析 / 障碍函数 / 有限时间可达性
    ↓ 进一步结合
MPC + RL + World Model 混合架构的安全认证层
```

**李雅普诺夫分析是连接"理论稳定性"与"计算可解性"的桥梁**。理解了这一章，你就理解了：

- 为什么 LQR 的解 P 可以作为非线性系统的本地李雅普诺夫函数
- 为什么 HALOS 安全层可以用障碍函数证明"机器人不会摔倒"
- 为什么 MPC 的约束优化与李雅普诺夫不变集是同构的
- 为什么"端到端神经网络控制"需要神经李雅普诺夫函数提供稳定性证书
- 为什么 SOS 优化在多项式系统上能给出严格的稳定性证明

### 五个最关键的认识

1. **稳定性证明 = 找下坡函数**：李雅普诺夫函数 V(x) 满足 V̇≤0，系统就像小球滚向谷底
2. **LaSalle 定理**：V̇≤0（不是严格<0）也能证明渐近稳定性，只要看"最大不变集"
3. **凸优化赋能**：线性系统用 SDP，多项式系统用 SOS——把 NP-hard 的稳定性证明转化为凸优化
4. **吸引域估计**：任何子水平集 V(x)≤ρ 都是不变集，可以认证"从这儿出发一定能稳定"
5. **障碍函数**：反向使用李雅普诺夫思想，证明"系统永远不会进入禁区"——安全控制的核心

### 对工程实践的五个启示

1. **SOS 是充分非必要条件**：有些稳定的多项式系统可能找不到多项式李雅普诺夫函数，但实践中 SOS 极其有效
2. **度数选择是艺术**：多项式度数越高，表达能力越强，但数值条件越差。通常从二次开始，逐步提升
3. **Drake 的 RegionOfAttraction 不是黑盒**：Russ Tedrake 明确说"强烈建议打开源码理解" ——这是掌握本章数学与工程桥梁的核心
4. **隐式形式处理有理函数**：对于需要求逆的矩阵动力学，用隐式形式 + S-procedure 可以避免显式求逆
5. **有限时间可达性是安全认证的基石**：无人机避障、机器人防摔，本质都是用时变 Lyapunov 函数证明"在 t∈[t₁, t₂] 内轨迹不会离开安全集"

### 三个深度洞察

**洞察一**：HALOS 安全层的数学本质是障碍函数。定义 B(x) 为"距离摔倒禁区的裕度"，要求 Ḃ(x)≤0，从安全状态出发的轨迹永远不会进入禁区——这是比紧急停机更主动的策略，也是李雅普诺夫分析在机器人安全领域的杀手级应用。

**洞察二**：MPC 与 HJB 的同构性。MPC 在每个控制周期求解有限时域动态规划，本质上是 HJB 方程的离散时间、有限时域版本；而 MPC 的可行性和闭环稳定性，需要用李雅普诺夫函数（通常是终端代价函数）证明——终端约束 + 终端李雅普诺夫函数 = MPC 稳定性证明的标准框架。

**洞察三**：Sim2Real Gap 的安全证书监控。仿真中通过 SOS 找到的 V(x) 在真机可能因模型误差导致 V̇>0，这就是"Sim2Real Gap 的安全边界被突破"的数学信号。HALOS 监测 V̇ 的符号，一旦发现 V̇>0 立即触发降级——这是用控制理论本身的工具来解决 Sim2Real。
