## 0. 开篇：用"放弃全局"换"可扩展"

### 0.1 一句话概括

> **不再求"全状态空间的最优反馈函数"，只求"从单个初值出发的最优轨迹"。把反馈表示换成轨迹表示，离散化只在时间维做——于是参数随状态维度线性增长，高维系统终于算得动。**

### 0.2 作者开场白的逐句翻译（信息量极大，逐层拆）

**第一层：承认前几章工具的局限。**
> 最优控制很强，但**计算工具**有重要局限。**网格值迭代**在状态维度 > 4–5 时**不 scale**。**围绕标称点/轨迹线性化**（LQR）能解高维的**局部**最优策略，但**只在"线性化是好近似"的区域有效**。第9章的 Lyapunov 能**估计**那些区域，但 **SOS-DP 还在早期**。**我们还没给出"超出'围绕目标线性化'的、能用于高维系统的主流近似最优控制计算工具"——这正是本章目标。**

**第二层（全章题眼）：表述一个更简单的优化问题。**
> 为 scale 到高维，我们表述一个**更简单**的优化问题：**不求整个状态空间的最优反馈控制器，而是只求"对单个初始条件有效"的最优控制解**。不用反馈函数表示，而用**轨迹**表示——通常定义在**有限区间**上。

**类比（全章总纲，请刻进脑子）**：
- **值迭代（第7章）** = 给**整座城市**画一张"从任何路口到公司还要几分钟"的导航地图。**信息最全，但画这张地图的成本随城市规模指数爆炸**（维度诅咒）。
- **轨迹优化（本章）** = **只算"从我家到公司这一条路"**。我不管别的路口怎么走，**只管我这一趟**。**信息少了，但成本随城市规模线性增长**——城市再大我也算得起。
- **LQR（第8章）** = 在"我家附近"画一张精确的小地图，出了这片就失效。

**第三层（为什么时间维离散化" fundamentally different"）**：
> 对比连续 DP 的网格参数化：轨迹优化只需在**一维（时间）** 上做有限维参数化，而网格值迭代要在**状态空间维度**上做。**网格离散化随状态维度 scale 得很糟**，且带来难处理的数值误差。**只在一维（时间）上离散，根本不同**：① 关于"微分方程在时间上的离散解"已知得多（含**误差控制积分**）；② 轨迹参数化所需参数**随状态维度线性增长**，而非网格值迭代的**指数增长**。

**类比**：值迭代的网格 = 给**整个三维房间**填满小立方体（点数 = 边长³，指数）；轨迹优化的时间离散 = 只给**一条线**（你的路线）打几个桩（点数 = 桩数，与房间维度无关，线性）。

## 1. 问题表述（10.1）—— 把"驾驶一趟"写成优化

### 1.1 标准配方

**给定**：状态空间模型 $\dot x=f(x,u)$，初值 $x_0$，定义在有限区间 $t\in[t_0,t_f]$ 上的输入轨迹 $u(t)$ → **前向仿真**得到同区间上的 $x(t)$。

**长期（有限时域）代价**（标准加性代价 + **终端代价**）：

$$J_{u(\cdot)}(x_0)=\ell_f(x(t_f))+\int_{t_0}^{t_f}\ell(x(t),u(t))\,dt$$

**人话**：
- $\int\ell\,dt$ = **一路上每秒的扣分**（偏离目标、费油……）。
- $\ell_f(x(t_f))$ = **到终点时的"结案罚款/奖励"**——**这是无限时域公式里没有的新东西**（无限时域靠"最终停在零代价目标"，不需要结案项；有限时域必须显式告诉优化器"终点我想要啥样"）。

**完整优化问题**：

$$\min_{u(\cdot)}\ \ell_f(x(t_f))+\int_{t_0}^{t_f}\ell(x,u)\,dt\quad\text{s.t.}\quad \dot x=f(x,u),\ \forall t\in[t_0,t_f],\quad x(t_0)=x_0$$

**还会加约束**：如**避障**（机器人与障碍的有符号距离 > 0）、**输入限**（$u_{\min}\le u\le u_{\max}$）。约束可对全时域或轨迹某子集。

### 1.2 必须参数化：连续轨迹 → 有限个数

> 上面是**对连续轨迹**的优化。要变成**数值优化**，必须用**有限个数**参数化它。参数化方式**很多**，速度/鲁棒性/精度各异（下面讲几种最流行的）。

**与连续 DP 参数化的对比**（呼应开篇）：轨迹优化在**一维（时间）** 要有限维参数化；网格值迭代在**状态空间维度**上工作，**随该维度 scale 得糟**，且数值误差难处理。**只在一维上离散根本不同**——时间上的微分方程离散解已知得多（误差控制积分），且参数数**线性**而非**指数**增长。

## 2. 线性系统的凸表述（10.2）—— "能可靠解到全局最优"的天堂

### 2.1 直接转录（Direct Transcription）—— 把每个路标都当未知数

**先看离散时间** $x[n+1]=Ax[n]+Bu[n]$（连续情形的离散化先放一边）。

**做法**：把 $x[\cdot]$ **和** $u[\cdot]$ **都**当决策变量，把离散动力学写成**显式约束**：

$$\min_{x[\cdot],u[\cdot]}\ \ell_f(x[N])+\sum_{n=0}^{N-1}\ell(x[n],u[n])\quad\text{s.t.}\quad x[n+1]=Ax[n]+Bu[n],\ \forall n,\quad x[0]=x_0\ +\text{其他约束}$$

**人话**：**我不"模拟开车"，我把"每个时刻车在哪（$x[n]$）、油门踩多少（$u[n]$）"全当成未知数，然后用约束"$x[n+1]$ 必须等于 $Ax[n]+Bu[n]$"把它们串起来**——**让优化器自己填一张自洽的"行车记录表"**。

**为什么叫"转录"**：把"最优控制问题"**翻译（transcribe）** 成一个**标准数学规划**（变量+目标+约束）。

**线性系统的红利**：动力学约束 $x[n+1]=Ax[n]+Bu[n]$ 对决策变量**线性**！于是若额外约束也是**线性不等式**、目标是**线性/二次** → 整个轨迹优化是**凸优化**（LP 或 QP）→ **能可靠解到全局最优，规模可以很大**；如今**在线**塞进**高频率反馈控制器**里解都很常见。

#### 例 10.1：双积分器的轨迹优化

> 我们用值迭代看过几个双积分器最优控制问题。其中**无约束二次代价**那个，现在知道能用 **LQR "精确"解**。但**最小时间**和**约束 LQR** 还没给满意的数值解。

**在轨迹表述里**：离散时间双积分器能**精确**解这些问题，连续时间能**更准**地解。**停下来欣赏一下！** bang-bang 策略和 cost-to-go 是相当非平凡的函数；**能用凸优化算出它们，很 satisfying！** 局限当然在于：**一次只解一个初值**。

**凸优化的建模威力（slack 变量技巧）**：哪怕目标形如 $\ell(x,u)=\|x\|+\|u\|$（带绝对值/范数，看着不"光滑"），也能**写成 LP**！加**松弛变量** $s_x[\cdot],s_u[\cdot]$：

$$\min_{x,u,s_x,s_u}\sum_n s_x[n]+s_u[n]\quad\text{s.t.}\ s_x[n]\ge x[n],\ s_x[n]\ge -x[n],\ \dots$$

**人话**：$\|x\|$ 不好直接塞进 LP，但"$s\ge x$ 且 $s\ge -x$，再最小化 $s$"就**逼 $s=|x|$**——**用一个更大的变量 + 线性不等式，把绝对值"骗"成线性的**。凸优化里**满是这样的小技巧**，**认得它们、会用它们，是"优化手艺活"**。

**但有些约束怎么都变不凸**：**避障**就是典型——车要决定**左绕还是右绕**，这在 $x$ 空间是**根本非凸**的（两个分离的可行区，中间是障碍）。**用非凸优化做轨迹优化的后果，下面讲**。

### 2.2 直接射击（Direct Shooting）—— 只猜方向盘，路标靠模拟

> 敏锐的读者会发现：把 $x[\cdot]$ 也当决策变量**并非必要**。已知 $x[0]$ 和 $u[\cdot]$，**前向仿真就能算出 $x[n]$**。离散线性系统尤其漂亮：

$$x[1]=Ax[0]+Bu[0],\quad x[2]=A(Ax[0]+Bu[0])+Bu[1],\quad x[n]=A^nx[0]+\sum_{k=0}^{n-1}A^{n-1-k}Bu[k]$$

**而且 $x[n]$ 对 $u[\cdot]$ 仍然线性！** 太神奇了——**砍掉一大堆决策变量，把约束优化变成无约束优化**（假设没别的约束）。

**做法**：**只用 $u[\cdot]$ 当决策变量**，$x[\cdot]$ 靠前向仿真算——这就是**直接射击转录**。线性系统 + 线/二次目标 → **仍凸**，且**变量和约束都比直接转录少**。

**类比（转录 vs 射击，必懂）**：
- **直接转录** = 把"整条路每个路标的位置"和"每段方向盘角度"**全当未知数**，列一堆"路标之间要符合物理"的方程，**一起解**。**未知数多，但方程"平衡"、可并行**。
- **直接射击** = **只猜"每段方向盘怎么打"**，路标位置**靠"真的开一遍车"模拟出来**。**未知数少，但"开车模拟"是串行的、且早期决策的影响会被一路放大/缩小（数值病态，见下）**。

### 2.3 计算考量 —— 射击并非全面胜出

> 那直接射击是不是**一律**比直接转录好？**我认为不是**。倾向转录的几个理由：

1. **数值条件（最重要）**。射击要算 $A^n$，$n$ 大时约束系数**取值范围跨度极大**——这毛病有时叫 **"尾巴摇狗"（tail wagging the dog）**，在很深的神经网络里叫**梯度消失/爆炸**。在轨迹优化里，这**不只是射击转录的人为产物，而是问题本身的真实性质**：**$u[0]$ 确实比 $u[N-1]$ 有更多机会影响总代价**（早期油门管全程，晚期油门只管尾巴）。**直接转录靠"把这个效应分散到大量平衡良好的约束上"来对抗数值问题**。

   **类比**：射击 = 你**第一天**的一个决定，经过 100 天复利放大，对结果影响巨大，而**第 99 天**的决定几乎无关——优化器被这种"头重脚轻"搞晕（梯度爆炸/消失）。转录 = 把 100 天**拆成 100 个独立小账本**，每本只记当天，**头重脚轻被摊平**。

2. **加状态约束方便**。$x[\cdot]$ 是显式决策变量时，加状态约束**很自然**，且**求解器对每个约束有效复用 $x$ 的计算**；射击里，**每加一个新约束都得把那些项重新展开**。

3. **并行化**。大问题里，算约束是笔大开销。直接转录里，**动力学/约束可并行算**（因为每轮迭代开始时 $x[n]$ 已给定）；**射击本质是串行操作**。

> 线性凸问题，求解器够成熟，这些差异常不大。**非线性问题，差别可能很大**。看主流机器人轨迹优化论文，**转录和射击都有人用**（**过去光看用哪种转录，就能猜出论文是哪个实验室写的！**）。

**带状稀疏（banded sparsity）**：直接转录生成的问题有个**重要且可利用的"带状"稀疏模式**——**大多数约束只碰少数几个变量**（$x[n+1]=Ax[n]+Bu[n]$ 只碰 $x[n],x[n+1],u[n]$）。**这和 Riccati 方程利用的是同一种模式**！因这些方法在真实应用太重要，**大量专用求解器被写出来显式利用这种稀疏**（如 [3,4]）。

### 2.4 连续时间 —— 零阶保持下的完美积分

> 想解连续时间版本，就**离散时间**再用上面的表述。**最重要的决定 = 离散化/数值积分格式**。线性系统 + 假设**控制输入每时步保持常数（零阶保持，ZOH）** → 能**完美积分**动力学：

$$x[n+1]=x[n]+\int_{t_n}^{t_n+h}[Ax(t)+Bu[n]]\,dt=e^{Ah}x[n]+A^{-1}(e^{Ah}-I)Bu[n]$$

（$A$ 可逆时的简单情形；$u(t)$ 是多项式和/或 $A$ 不可逆的解，PDF 折叠给出。）

**人话**：ZOH 下，线性系统的"一步转移"**有闭式**（矩阵指数 $e^{Ah}$），**没有积分误差**——这是线性系统的又一个红利。

## 3. 非凸轨迹优化（10.3）—— 进入"真实世界"

> 强烈建议先学凸情形——它给你**心智清晰和目标感**。但**实践中轨迹优化常用来解非凸问题**。非凸的来源：① **动力学非线性** → 动力学约束非凸；② 非凸目标；③ 非凸约束（如避障）。通常用**非线性规划（NLP）** 工具。

### 3.1 转录和射击仍有效，只是非凸

> 上面写的直接转录/直接射击表述，**动力学非线性时仍成立**，只是**结果问题非凸**。如离散直接转录变成更一般的：

$$\min_{x[\cdot],u[\cdot]}\ \ell_f(x[N])+\sum_{n=0}^{N-1}\ell(x[n],u[n])\quad\text{s.t.}\quad x[n+1]=f(x[n],u[n]),\ \forall n,\quad x[0]=x_0\ +\text{其他约束}$$

**直接射击也行**——每轮迭代用前向仿真算 $x[\cdot]$。**但连续时间更有意思**：非线性动力学下，**近似离散动力学 $x[n+1]=x[n]+\int_{t[n]}^{t[n+1]}f(x(t),u(t))dt$ 的选择很多**。Drake 有一整套数值积分器，速度/精度各异，且**高度依赖 $f$ 的细节**。

**变步长积分 & 让时间本身当决策变量**：数值积分里一个重要思想 = **变步长积分**控制积分误差。**RK45（Runge-Kutta-Fehlberg）** 是最著名的变步长积分器。**我们通常避免在约束内用变步长**（会导致**梯度不连续**），但轨迹优化里可以**让采样时间 $t[\cdot]$ 本身当决策变量**——**让优化器拉伸/压缩时间区间**来解题，**当你事先不知道轨迹总时长该多长时特别有用**。**必须给这些时间变量加约束**，避免平凡解（如**坍缩成零时长**）。甚至可加约束**界住积分误差**。

**类比**：固定时步 = "每秒拍一帧"；让 $t[\cdot]$ 当变量 = "**让优化器自己决定哪段该拍密、哪段该拍疏**"——动作剧烈的地方拍密（精度高），平缓的地方拍疏（省变量）。但要**防止它"作弊"把整段压成 0 秒**。

### 3.2 直接配置（Direct Collocation）—— 先画曲线，再查中点斜率

> 有一整套数值积分器给直接转录用，**很 satisfying**。但**数值积分器是为"前向解"设计的**——这是个**我们其实在转录里并不需要的约束**！若目标是"用**少量函数评估/决策变量/约束**得到微分方程的**精确解**"，则有些**利用"约束优化"形式**的新表述成为可能——**配置法（collocation）**。

**做法**：在直接配置 [6] 中，**输入轨迹和状态轨迹都显式表示成分段多项式**。**算法的甜点** = **$u(t)$ 取一阶多项式、$x(t)$ 取三次多项式**。

**妙处**：这甜点下，**优化里唯一需要的决策变量 = 样条"断点"处的采样值 $x(t_k),u(t_k)$**！你**以为**需要三次样条的系数，**其实不需要**：
- $u$ 一阶插值：给定 $u(t_k),u(t_{k+1})$ → 区间内每个 $u(t)$ 都解出。
- $x$ 三次样条：给定 $x(t_k),u(t_k)$（→ $\dot x(t_k)=f(x(t_k),u(t_k))$）和 $x(t_{k+1}),u(t_{k+1})$（→ $\dot x(t_{k+1})$）→ **四个值完全定下区间内三次样条的所有参数**！

**很方便**：因为**在采样点上写约束很自然**（若要把每个约束都转成"对样条系数的约束"反而更难）。

**图 10.1**：直接配置用的三次样条参数。

**配置约束（在中点强制动力学）**：样条被决策变量完全指定后，还需 $\dim(x)$ 个额外约束，让 $x(t_{k+1})$ **（近似）等于** $x(t_k)+\int f\,dt$。直接配置**在"配置点"加导数约束**。选**配置时间 = 样条中点** $t_{c,k}=\tfrac12(t_k+t_{k+1})$，$h_k=t_{k+1}-t_k$，则：

$$u(t_{c,k})=\tfrac12(u(t_k)+u(t_{k+1}))$$
$$x(t_{c,k})=\tfrac12(x(t_k)+x(t_{k+1}))+\tfrac{h}{8}(\dot x(t_k)-\dot x(t_{k+1}))$$
$$\dot x(t_{c,k})=-\tfrac{3}{2h}(x(t_k)-x(t_{k+1}))-\tfrac14(\dot x(t_k)+\dot x(t_{k+1}))$$

**人话**：这三式是"把三次样条拟合到端点值/导数、再在中点插值"直接得来的。它们正好给出"在中点加动力学约束"所需的一切：

$$\min_{x[\cdot],u[\cdot]}\ \ell_f(x[N])+\sum_{n=0}^{N-1}h_n\,\ell(x[n],u[n])\quad\text{s.t.}\quad \dot x(t_{c,n})=f(x(t_{c,n}),u(t_{c,n})),\ \forall n,\quad x[0]=x_0\ +\text{其他约束}$$

**记号说明**：$x[k]=x(t_k)$ 是决策变量；$t_{c,k}$ 处的配置约束**依赖** $x[k],x[k+1],u[k],u[k+1]$。运动方程**在断点 $t_k$ 和配置点 $t_{c,k}$ 都要算**（因为要算 $\dot x(t_k)$ 才能写 $\dot x(t_{c,k})$）。

**精度**：直接配置**靠满足优化约束来"积分"运动方程**——这次产生的积分**三阶精度**，**每段实际两次 plant 评估**（因为 $f$ 在两个区间共用）。[6] 声称（无证明）：**断点靠得越近，轨迹收敛到微分方程的真解**。同样，**加代价项/输入状态约束都很自然**，且**目标和约束的梯度很好算**。作者个人觉得"**把轨迹的参数编码显式纳入求解技术**"很 nice。

#### 例 10.2：摆、Acrobot、Cart-Pole 的直接配置

**图 10.2**：用直接配置优化的简单摆 swing-up 轨迹（带严苛力矩限）。直接配置也能轻松解摆、Acrobot、cart-pole 的 swing-up。**照例：务必看代码！**

**类比（配置法 vs 射击/转录，必懂）**：
- **射击/转录** = 让积分器**从起点一步步往前"走"**，每一步算下一步。
- **配置法** = **先凭空画好整条曲线**（分段三次样条，由断点值决定），**然后在每段中点"抽查"：这点的斜率，和动力学要求的斜率，对得上吗？** 对不上就调断点值。**它不"走"，它"画完再验"**——所以不受"必须前向"的限制，能用更少的点达到更高精度。

### 3.3 伪谱法（Pseudo-spectral Methods）—— 用"一整条高次多项式"拟合

> [6] 的直接配置是我们"把解显式表示成参数化轨迹 + 在一系列配置时间加导数约束"的**第一个例子**。上面选的表示 = 分段多项式（三次样条），断点值是决策变量。**密切相关**的另一类方法叫**伪谱最优控制**——**同样的配置思想**，但**用全局多项式基的线性组合**表示轨迹。这些方法**通常用高得多的多项式**，但能**利用巧妙参数化**写出**稀疏配置目标**并**选配置时间** [7,8]。

**有趣的**：这些方法的表示**连续可微**，导致**比别的直接轨迹优化方法有更多的定理和分析** [8]——但**尽管文章用词，请记住它们仍是"试图解非凸优化的局部优化方法"**。直接配置靠"加分段"（每段表示更小时间区间）收敛到真最优；**伪谱靠"提高多项式次数"收敛**。

**正交配置（orthogonal collocation）**：基多项式 $\phi_j(t)$ 选成在第 $j$ 个配置时间满足 $\phi_i(t_j)=\begin{cases}1,&i=j\\0,&\text{否则}\end{cases}$——用**拉格朗日多项式** $\phi_i(t)=\prod_{j=0,j\ne i}^{N}\frac{t-t_j}{t_i-t_j}$ 实现。

**时间重缩放**：出于数值和分析原因，时间传统上从 $[t_0,t_f]$ 重缩放到 $[-1,1]$。配置时间基于**高斯求积**的小变体，叫 **Gauss-Lobatto**（**含端点** $t=-1$ 和 $t=1$）。

**无限时域伪谱**：用非线性重缩放把 $t\in[0,\infty)$ 映到半开区间 $\tau\in[-1,1)$，$\tau=\frac{t-1}{t+1}$。配置时间选成**含 $\tau=-1$ 但不含 $\tau=1$**，用 **Gauss-Radau 点** [7]。

**隐式形式的动力学约束**：还有"看似微妙但可能重要"的机会——若主要兴趣是优化**有显著多体动力学**的系统。**有时能直接把动力学约束写成隐式形式**。Lyapunov 章已引入这思想。**很多情况下，用隐式形式 $g(x,u,\dot x)=0$ 取得运动方程、避免解出显式 $\dot x=f(x,u)$，更 nice 或更高效**。考虑**显式形式解不唯一**的系统时**更重要**——研究**穿越接触的轨迹优化**时会看到，**摩擦的 Coulomb 模型实际导致微分包含（differential inclusion）而非微分方程**。

**配置法**在配置点**直接用连续形式的动力学约束**，**能直接用隐式形式**。直接转录也能用**隐式积分器**写时步近似——**同样给出隐式形式的约束**。**隐式形式在射击法里难利用**。

**类比（伪谱 vs 配置）**：配置法 = 用**很多段低次多项式**拼出轨迹（像**折线/分段曲线**）；伪谱 = 用**少数几条高次多项式**整体拟合（像**一条光滑的高阶曲线**）。伪谱的"光滑"换来更多理论保证，但**别忘了它仍是局部优化**。

## 4. 求解技术（10.4）—— 转录之后，怎么解这个 NLP

> 不同转录 = 把（可能连续时间的）最优控制**映射**成有限决策变量/目标/约束的**不同方式**。但**一旦选定**，解这个优化仍有**众多方法**。**任何通用非线性规划方法都能用**；目前 python 例子里，问题**直接交给 SQP 求解器 SNOPT 或内点求解器 IPOPT**。

> 但这些轨迹优化问题**因序列结构而有大量可利用的特定结构**。于是有些**相当特定于轨迹优化**的思想，**定制求解器常能（有时 dramatically）胜过通用求解器**。这种结构**在无约束表述里最易讨论和实现**，所以从无约束开始。

### 4.1 高效算梯度 —— 反向传播的"老祖宗"

> 给求解器提供目标/约束的梯度**非必须**——多数求解器没给就用**有限差分**。但我**强烈认为**光滑问题**给精确梯度更快更鲁棒**（**会接触/断接触的系统可能另当别论** [9]）。**直接转录给梯度很直接**——逐约束给梯度即可。**但直接射击里**，$x$ 已从程序移除、却仍用 $x$ 写目标/约束，**独立算每个目标/约束的梯度会变得极低效**。**必须用链式法则**。

**记号**：定义 $x[n+1]=f_d(x[n],u[n])$ 为连续动力学的离散近似（如前向欧拉 $f_d=x[n]+f(x[n],u[n])dt$）。则：

$$\frac{\partial J}{\partial u_k}=\frac{\partial\ell_f(x[N])}{\partial u_k}+\sum_{n=0}^{N-1}\left(\frac{\partial\ell(x[n],u[n])}{\partial x[n]}\frac{\partial x[n]}{\partial u_k}+\frac{\partial\ell(x[n],u[n])}{\partial u[n]}\right)$$

其中**状态对输入的梯度**可在"前向仿真"时算：

$$\frac{\partial x[n+1]}{\partial u_k}=\frac{\partial f_d(x[n],u[n])}{\partial x[n]}\frac{\partial x[n]}{\partial u_k}+\frac{\partial f_d(x[n],u[n])}{\partial u[n]}$$

**这些"仿真梯度"也能用链式法则给任何约束的梯度**。**注意要存很多项**，量级 ≈ **(状态维)×(控制维)×(时步数)**。**哎哟**。还注意**很多项为零**；如欧拉格式下若 $k\ne n$ 则 $\frac{\partial u[n]}{\partial u_k}=0$。（若觉得混了两套记号——回忆 $u_k$ 是**决策变量**，$u[n]$ 是**仿真第 $n$ 步用的输入**。）

**人话**：这是**前向模式自动微分**——**顺着时间，把"每个 $u_k$ 如何影响每个 $x[n]$"一路传下去**。**项数爆炸**（每个 $u_k$ 都要存一长串 $\partial x/\partial u_k$）。**下面 4.2 给出更省的"反向模式"**。

### 4.2 无状态约束射击的特例 —— 伴随方程 = 反向传播！

> 靠"自己解出 $x[\cdot]$"，我们**移除了一大堆约束**。若**没有额外状态约束**，且**唯一要算的梯度是目标的梯度**，则**一个惊人高效的算法**浮现。这里只给步骤不推导（Pontryagin 节再推）：

1. **前向仿真**：$x[n+1]=f_d(x[n],u^n)$，从 $x[0]=x_0$。
2. **反向算 $\lambda$**：$\lambda[n-1]=\frac{\partial\ell(x[n],u[n])}{\partial x[n]}^T+\frac{\partial f(x[n],u[n])}{\partial x[n]}^T\lambda[n]$，$\lambda[N-1]=\frac{\partial\ell_f(x[N])}{\partial x[N]}$。
3. **提取梯度**：$\frac{\partial J}{\partial u[n]}=\frac{\partial\ell(x[n],u[n])}{\partial u[n]}+\lambda[n]^T\frac{\partial f(x[n],u[n])}{\partial u[n]}$，其中 $\frac{\partial J}{\partial u_k}=\sum_n\frac{\partial J}{\partial u[n]}\frac{\partial u[n]}{\partial u_k}$。

**这里 $\lambda[n]$ 是与 $x[n]$ 同维的向量，解释为 $\lambda[n]=\frac{\partial J}{\partial x[n+1]}^T$**（"终值代价对下一步状态的敏感度"）。**管 $\lambda$ 的方程叫伴随方程（adjoint equation）**，它代表**相比"算海量仿真梯度"的 dramatic 效率提升**。

> **彩蛋（务必记住）**：**伴随方程 = 神经网络文献里著名的反向传播算法**，或更一般地 = **反向模式自动微分**的定制版。（上一节 4.1 = 前向模式自动微分。）

**类比（前向 vs 反向模式，必懂）**：
- **前向模式（4.1）** = "**每个输入 $u_k$ 单独追一遍**它如何影响所有 $x$"——输入多时**贵**（要追很多遍）。
- **反向模式 / 伴随（4.2）** = "**从终点代价往回传一个'敏感度' $\lambda$**"——**只需一次前向 + 一次反向**，就拿到**对所有 $u[n]$ 的梯度**！**当输入维度高、输出（代价）是标量时，反向模式碾压前向模式**——**这正是深度学习训练靠反向传播的原因，也是轨迹优化射击法的命门**。

### 4.3 罚函数与增广拉格朗日 —— "智能罚单系统"

> 近年机器人界**流行**用（常是专用的）**无约束轨迹优化求解器**做轨迹优化，**用罚函数法把约束问题转成无约束**。**手动**往代价加罚项 + 人工调权重 = **脏活**：常花大量精力"调代价函数"；**权重设太大 → 数值病态**；**设太小 → 约束被违反**。

**增广拉格朗日（Augmented Lagrangian）** 提供**有原则的解法**：**自动调度权重**，用**有限罚**实现约束的"**本质精确**"满足 [10],[11, Ch.17]。**基于增广拉格朗日的方法如今在轨迹优化里特别流行** [12,13]。

**类比**：手动罚函数 = **交警凭感觉开罚单**（罚太重司机破产=病态，罚太轻没人守规矩=违反约束）。增广拉格朗日 = **智能罚单系统**：先开个小罚单，看你还犯不犯，**自动加码**，直到你**真的守规矩**为止——**用有限的罚款，逼出精确的守规**。

### 4.4 零阶优化（CEM、MPPI）—— 不算梯度，"撒一万条看哪条好"

> **交叉熵法（CEM）** [14] 和**模型预测路径积分控制（MPPI）** [15]。

> 近年轨迹优化在"**基于模型的强化学习**"里扮演主角，尤其**模型用深度神经网络**表示时（如 [16,17]）。**尽管神经网络工具箱能给高效梯度，这里描述的无梯度轨迹优化方法通常是首选**。几个可能解释：

1. 轨迹优化**有局部极小**，零阶优化器**确实提供某种"全局优化"**（至少**倾向在收敛前探索多个可能极小**）。
2. **有限数据拟合的神经网络模型**，**可能比用原始物理模型有更多局部极小**——标准回归 loss 可以很小，**即使函数的神经表示局部凹凸/不光滑**。
3. **但我认为零阶方法流行的最大原因 = 它们 trivially 可并行，且与现有 GPU 神经网络工作流非常契合**。**当并行 rollout 10000 个样本的成本 ≈ rollout 1 个时**，零阶方法当然更诱人。

**类比**：梯度法 = **蒙眼下山，用脚探坡度**（快但易卡局部坑）。零阶 CEM/MPPI = **同时派一万个人随机往各方向走，看谁走得低，下一轮让大家都朝那批"走得低的人"的方向撒**——**不算坡度，靠"群体采样"逼近**。**单看笨，但一万个人能同时在 GPU 上跑，反而快**，且**不容易全卡同一个坑**。

### 4.5 实践中得好解 —— 伺候 solver 的情绪过山车

> 自己玩这些算法，你会像坐**情绪过山车**。**狂喜时刻**——solver 对高度非平凡问题找到**令人印象深刻的解**。**沮丧时刻**——solver 返回**糟糕的解**，或**干脆拒绝返回**（说 "infeasible"）。**最气人的是**：**你分不清"问题真不可行" vs "solver 只是卡局部极小"**。

> 于是下一阶段 = 开始**"帮" solver**。两种常见做法：

1. **调代价函数**——有人花大量时间往目标加新元素 / 调各部分相对权重。**这是 slippery slope**，作者**倾向避免**（**可能避得过头；别的组倾向放出更 compelling 的视频！**）。
2. **给 solver 更好的初猜**，把它放到"对的"局部极小附近。**作者觉得这更 satisfying**——因为多数问题**确实有"正确"的目标/约束表述**，我们**就该奔着找最优解去**。

**射击 vs 转录/配置在初猜上的差别**：**射击只能给 $u(\cdot)$ 初猜**；**转录/配置还能直接给 $x(\cdot)$ 初猜**。**作者发现这帮助巨大，哪怕用很简单的初始化**。Acrobot 和 cart-pole swing-up 的直接配置例子里，**仅给 $x(\cdot)$ 一个"起终点之间的直线轨迹"当初猜，就足以帮 solver 找到好解；事实上这是必要的**。

> 作者自嘲"年纪大了，厌倦伺候需要手把手的 finicky solver"。近年组里在做**更鲁棒的"全局"运动规划解**，基于 **Graphs of Convex Sets（GCS）** [18]。最初的 GCS 运动规划转录**聚焦运动学轨迹优化**（机械臂操作所需）[19]，但**正向动力学（欠驱动）轨迹优化扩展**。

## 5. 局部轨迹反馈设计（10.5）—— 开环轨迹 + 闭环纠偏

> 一旦从轨迹优化得到**局部最优轨迹**，就找到了一条**（至少局部）最小化最优控制代价的开环轨迹**。在数值容差内，这对 $(u_0(t),x_0(t))$ 是系统的**可行解轨迹**。**但我们还没做任何事保证这条轨迹局部稳定**。

**事实上到这一步已做了几个值得注意的近似**：轨迹优化的**积分精度往往比前向仿真用的精度差得多**（优化倾向用**更大时步**，避免加太多决策变量）；优化工具箱的**默认收敛容差往往只把动力学约束满足到约 $10^{-6}$**。结果：**即使从轨迹优化用的/得到的精确初值，直接仿真优化出的控制轨迹，状态轨迹也可能偏离规划轨迹**。

**怎么办**：可在轨迹优化**期间**评估局部稳定性，加**奖励开环稳定性**的代价/约束（如 [20,21]）——很有效（但**贵**）。但**开环稳定是相当 restrictive 的概念**。**可能更通用有用的方法 = 设计反馈控制器，把系统调节回规划轨迹**。

### 5.1 有限时域 LQR —— 沿轨迹贴一张"时变纠偏网"

> LQR 章已发展过一种轨迹稳定方法。**这是作者最爱的轨迹反馈方法之一**——因为它给控制器一个**（数值）闭式解**，**还附送一个时变二次 cost-to-go 函数**，**能用于 Lyapunov 分析**。

**基本流程**：在**误差坐标**下做**时变线性化**：$\bar x(t)=x(t)-x_0(t)$，$\bar u(t)=u(t)-u_0(t)$，$\dot{\bar x}(t)=A(t)\bar x(t)+B(t)\bar u(t)$。**这线性化用的，正是轨迹优化算法里一直在用的那些动力学梯度**。有了时变线性化，**套用有限时域 LQR**（细节见 LQR 章）。

**一大优点**：能**立刻**去**验证** LQR 策略下闭环系统的性能。具体地，可用**有限时域可达性分析**得到"**漏斗（funnels）**"，**证一种所需的不变性**——**保证"从规划轨迹附近出发的轨迹，会留在规划轨迹附近"**。细节见有限时域可达性分析节。**栖停案例**会把所有这些想法串起来。

**类比**：开环轨迹 = **一条画好的铁轨**；有限时域 LQR = **沿铁轨每隔一段装一个"自动纠偏器 $K(t)$"**——车偏了就推回铁轨。**附送的 $S(t)$ = "偏离铁轨的代价地图"**，能当 Lyapunov 函数证"车不会脱轨太远"（漏斗）。

### 5.2 模型预测控制（MPC）—— 把"轨迹优化"本身当反馈

> **用凸优化解轨迹优化的成熟、鲁棒、快速**，引出一个美丽想法：**若我们能足够快地优化轨迹，就能把轨迹优化当反馈策略用**。配方简单：**(1) 测当前状态；(2) 从当前状态优化一条轨迹；(3) 执行优化轨迹的第一个动作；(4) 让动力学演化一步，重复**。这配方叫**模型预测控制（MPC）**。

> 尽管这控制器**高度计算化**（**没有闭式表示**；**只隐式地表示为优化的解**），MPC 上有**大量理论和算法结果** [22,23]。**线性 MPC 的理论和实践如今被理解得如此透彻，以至于它被视为"带（线性）约束的线性系统控制"的 de-facto LQR 推广**。有几个**从业者真该懂的核心思想**。

#### 滚动时域 MPC（Receding-horizon）

> 轨迹优化在**有限时域**表述，所以**每次优化可看作"推理接下来 $N$ 步"**。若**真目标**是优化**比 $N$ 更长**的时域（如无限时域），**标准做法 = 每次评估控制器时仍解 $N$ 步时域**。**这样，被考虑的总时域随时间不断前移（recede，后退）**。

**类比**：你开车**只看得到前方 100 米**（$N$ 步），但**每开一米就重新看前方 100 米**——**视野永远在"后退"**，于是你**事实上能开到任意远**。

#### 递归可行性（Recursive feasibility）—— 永远留个"能停下的安全点"

> 滚动时域要**小心**：每新一步，我们**往问题里引入新代价/新约束**（上一步求解时本对应"未来某时刻"的那些）——**最糟的是**：一路往前解凸优化，**突然某步 solver 返回 "infeasible"！** 可设计**保证递归可行性**的 MPC 表述——**保证：若时刻 $n$ 找到可行解，则 $n+1$ 也找到可行解**。

**稳定不动点的最简单机制**：给滚动时域加**终值约束** $x[N]=x^*$。**简单但重要**。考虑**绝对时间**下的轨迹/约束：算法第 $k$ 步，优化 $x[k],\dots,x[k+N]$ 和 $u[k],\dots,u[k+N-1]$；设已找到可行解。**滚动时域的危险**：移到下一步（$k+1$）时，**首次**对 $x[k+N+1]$ 引入约束。**但若第 $k$ 步的可行解满足 $x[k+N]=x^*$，则设 $x[k+N+1]=x^*,u[k+N]=u^*$ 保证给第 $k+1$ 步的新优化提供一个可行解**。**可行性有了保证**，solver 可**自由搜更低代价的解**（现在可能有了，因为**终值约束被推到了更远的未来**）。也可 formulate **在建模误差和扰动下仍保证递归可行性**的 MPC（[24]）。

**类比**：每次规划，**强制"视野尽头必须停在一个安全车位 $x^*$"**。于是下一步，**就算视野往前挪了一格，"上一步停在车位"这个事实，自动给新视野提供一个"接着停在车位"的可行兜底**——**永远不会"走着走着发现无路可走"**。

#### MPC 与 Lyapunov 函数

> 尽管 MPC 策略**只隐式定义为优化结果**，**仍能做 Lyapunov 稳定性论证**。若在滚动时域 MPC 下，**除递归可行性外**，还有"**第 $k$ 步加的代价 ≤ 第 $k$ 步移除的代价**"这一性质，则**轨迹优化的最优代价 $J^*(x,k)$ 就是 Lyapunov 函数**：

$$\forall x,k,\quad J^*(f(x,u^*),k+1)\le J^*(x,k)$$

**再次**，实现这点的**特别简单方法** = **每次优化的第 $N$ 步加终值约束**，到一个**零代价的平衡配置**。**但同样，有方法把这套 Lyapunov 论证扩展到建模误差和扰动存在时**（[24]）。

> **不同于有限时域 LQR 给的 nice 显式时变二次 Lyapunov 函数**，**这个 Lyapunov 函数一般没有紧凑表示**（这是 **explicit MPC** 的研究对象），**更难用于如 SOS 优化**。

## 6. 案例：能像鸟一样栖停的滑翔机（10.6）—— 全章思想的"集大成实战"

> 2008–2014，作者的组做了一系列**越来越精细**的研究 [25–30]，问一个问题：**固定翼无人机能像鸟一样栖停在栖木上吗？**

**图 10.3**：滑翔机栖停的基本设置。

**为什么难**：鸟栖停时**上仰、让机翼暴露在远超正常飞行包线的"迎角"**。飞机**传统上拼命避免**这状态，因为它导致**气动失速**——**气流从机翼分离后升力骤降**。但**升力骤降也伴随阻力大增**，**鸟正是利用这点快速减速栖停**。**失速后气动对控制是挑战**，因为：**(1) 气动时变**（周期涡脱落）**且非线性**；**(2) 这飞行状态难建精确模型**（至少风洞里难）；**(3) 失速 = 机翼失附着流 = 控制面也失附着流 → 控制权威可能大降**。

**最初以为适合无模型控制**（如 RL——因为模型未知）。**结果**：**它成了真正教会作者"基于模型的轨迹优化 + 线性最优控制"威力的项目**。在**动捕环境**做**动力学系统辨识实验**，**既**拟合了**惊人简单的模型**（基于**平板理论**）[25]，**也**用"**类神经网络**"项拟合**模型与数据间残差**的**更精确模型** [30]。**这让基于模型的控制可行**，但**动力学仍复杂**——轨迹优化该 work，但作者**很怀疑**"仅靠线性反馈能否调节到那些轨迹"。

**作者错了**。**一次又一次**，他看着**时变 LQR 做出高度非平凡的纠正动作**——比如**轨迹早段下俯以获取动能**、或**上仰以把能量泄出系统**——**只为在终时栖停到栖木上**。虽然**动力学的线性近似越偏离标称轨迹越差**，但**控制器的有效性下降得慢得多**（**即使向量场变了，控制器需要推的方向没变**）。**这也正是最初让作者对"理解线性控制在非线性系统上的吸引域"如此着迷的思考**。

**最终实验非常成功**。从找"能造的**最简单**飞机"开始——**捕捉本质控制动力学、降低复杂度、仍能完成任务**。最终造了一系列**平板泡沫滑翔机（无螺旋桨）**，**只有单个执行器控升降舵**。**机翼加上反角**帮飞机**保持在纵平面**。**这些飞机的简单 + 能用相当简单的模型理解**，使它们成为**作者最爱的经典欠驱动系统之一**。

**图 10.4**：[25] 的原始栖停实验，动捕场里用一根简单绳子当栖木。主视频用高速相机拍；**整条栖停轨迹约 0.8 秒**。

### 6.1 平板滑翔机模型（10.6.1）

**图 10.5**：平板滑翔机模型。**注意**：传统飞机坐标选成"正俯仰 = 机头朝上"，但这意味正 $z$ 朝下（为右手系）。**为一致**，作者**沿用全文的车辆坐标系**——**正 $z$ 朝上，但正俯仰朝下**。

**实验发现**：飞机动力学 [25] 被所谓**平板模型** [31, Ch.4, Sec.6] **捕捉得非常好**。平板理论里，**翼的升力和阻力被汇总为"作用在翼压力中心、垂直于翼的单个力"**，大小：

$$f_n(S,n,v)=\rho S\sin\alpha\,\|v\|^2=-\rho S(n\cdot v)\|v\|$$

其中 $\rho$ = 空气密度，$S$ = 翼面积，$\alpha$ = 表面迎角，$n$ = 升力面法向，$v$ = 压力中心相对空气的速度。**对应升力/阻力系数**：

$$c_{lift}=2\sin\alpha\cos\alpha,\qquad c_{drag}=2\sin^2\alpha$$

**滑翔机模型里**，**所有气动力由两个升力面的贡献汇总**：**翼**（含水平机身的一些贡献）下标 $w$、**升降舵**下标 $e$，中心在 $p_w=[x_w,z_w]^T$ 和 $p_e=[x_e,z_e]^T$，运动学：

$$p_w=p-l_w\begin{bmatrix}c_\theta\\-s_\theta\end{bmatrix},\quad p_e=p-l_h\begin{bmatrix}c_\theta\\-s_\theta\end{bmatrix}-l_e\begin{bmatrix}c_{\theta+\phi}\\-s_{\theta+\phi}\end{bmatrix}$$

其中车辆坐标系原点 $p=[x,z]^T$ 选在**质心**。**假设静止空气**，所以翼和升降舵都 $v=\dot p$。**假设升降舵无质量**，**执行器直接控制速度**（**注意这破坏了"控制仿射"结构**，但对我们用的**微型 hobby 舵机更真实**）。**共 7 个状态变量、1 个控制输入** $x=[x,z,\theta,\phi,\dot x,\dot z,\dot\theta]^T$，$u=\dot\phi$。**运动方程**：

$$n_w=\begin{bmatrix}s_\theta\\c_\theta\end{bmatrix},\ n_e=\begin{bmatrix}s_{\theta+\phi}\\c_{\theta+\phi}\end{bmatrix},\ f_w=f_n(S_w,n_w,\dot p_w),\ f_e=f_n(S_e,n_e,\dot p_e)$$
$$\ddot x=\tfrac1m(f_ws_\theta+f_es_{\theta+\phi}),\quad \ddot z=\tfrac1m(f_wc_\theta+f_ec_{\theta+\phi})-g,\quad \ddot\theta=\tfrac1I(l_wf_w+(l_hc_\phi+l_e)f_e)$$

## 7. Pontryagin 极小值原理（10.7）—— 数值轨迹优化的"分析体检表"

> 我们为数值轨迹优化发展的工具，与**（分析）最优控制**的定理**紧密相连**。用一节欣赏这些联系。

**"轨迹 $(x(\cdot),u(\cdot))$ 局部最优"精确意味什么**？**若我以任意方式扰动该轨迹**（如把 $u$ 改 $\epsilon$），**则要么目标代价更高，要么违反约束**。**无约束优化**，局部最优的**必要条件** = **解处目标梯度恰好为零**。当然梯度也在局部极大/鞍点消失，但**局部极小处必定消失**。可用**拉格朗日乘子**把这论证推广到约束优化。

### 7.1 拉格朗日乘子推导伴随方程

> 用拉格朗日乘子推导**离散时间约束轨迹优化**的必要条件：

$$\min_{x[\cdot],u[\cdot]}\ \ell_f(x[N])+\sum_{n=0}^{N-1}\ell(x[n],u[n])\quad\text{s.t.}\quad x[n+1]=f_d(x[n],u[n])$$

**构造拉格朗日**：

$$\mathcal{L}(x[\cdot],u[\cdot],\lambda[\cdot])=\ell_f(x[N])+\sum_{n=0}^{N-1}\ell(x[n],u[n])+\sum_{n=0}^{N-1}\lambda^T[n]\big(f_d(x[n],u[n])-x[n+1]\big)$$

**令导数 = 0**，得到上面射击算法描述的**伴随方程法**：

$$\forall n\in[0,N-1],\ \frac{\partial\mathcal{L}}{\partial\lambda[n]}=f_d(x[n],u[n])-x[n+1]=0\ \Rightarrow\ x[n+1]=f(x[n],u[n])$$
$$\forall n\in[0,N-1],\ \frac{\partial\mathcal{L}}{\partial x[n]}=\frac{\partial\ell}{\partial x}^T+\lambda^T[n]\frac{\partial f_d}{\partial x}-\lambda^T[n-1]=0\ \Rightarrow\ \lambda[n-1]=\frac{\partial\ell}{\partial x}^T+\frac{\partial f_d}{\partial x}^T\lambda[n]$$
$$\frac{\partial\mathcal{L}}{\partial x[N]}=\frac{\partial\ell_f}{\partial x}^T-\lambda^T[N-1]=0\ \Rightarrow\ \lambda[N-1]=\frac{\partial\ell_f}{\partial x}$$
$$\forall n\in[0,N-1],\ \frac{\partial\mathcal{L}}{\partial u[n]}=\frac{\partial\ell}{\partial u}+\lambda^T[n]\frac{\partial f_d}{\partial u}=0$$

**因此**：给定初值 $x_0$ 和输入轨迹 $u[\cdot]$，可**验证它满足最优性必要条件**——**前向仿真**解 $x[\cdot]$，**反向解伴随方程**得 $\lambda[\cdot]$，**验证 $\frac{\partial\mathcal{L}}{\partial u[n]}=0$ 对所有 $n$**。（$\frac{\partial J}{\partial u}=\frac{\partial\mathcal{L}}{\partial u}$ 在 $\frac{\partial\mathcal{L}}{\partial x}=0$ 且 $\frac{\partial\mathcal{L}}{\partial\lambda}=0$ 时成立，来自变分法的一些基本结果。）

### 7.2 连续时间最优性必要条件

> 不奇怪，这些必要条件在**连续时间**有对应。这里不推导直接陈述。给定初值 $x_0$、连续动力学 $\dot x=f(x,u)$、瞬时代价 $\ell(x,u)$，**定义在 $t\in[t_0,t_f]$ 的轨迹 $x(\cdot),u(\cdot)$ 要最优，必须满足**：

$$\forall t\in[t_0,t_f],\quad \dot x=f(x,u),\ x(0)=x_0$$
$$\forall t\in[t_0,t_f],\quad -\dot\lambda=\frac{\partial\ell}{\partial x}^T+\frac{\partial f}{\partial x}^T\lambda,\quad \lambda(T)=\frac{\partial\ell_f}{\partial x}^T$$
$$\forall t\in[t_0,t_f],\quad \frac{\partial\ell}{\partial u}+\lambda^T\frac{\partial f}{\partial u}=0$$

**事实上这陈述可推广到 $u$ 有约束**的情形。结果叫 **Pontryagin 极小值原理**——给**轨迹最优的必要条件**。

**定理 10.1（Pontryagin 极小值原理，改编自 [32]）**：给定 $x_0$、$\dot x=f(x,u)$、$\ell(x,u)$，**$x^*(\cdot),u^*(\cdot)$ 在 $t\in[t_0,t_f]$ 最优，必须满足**：

$$\forall t,\ \dot x^*=f(x^*,u^*),\ x^*(0)=x_0$$
$$\forall t,\ -\dot\lambda^*=\frac{\partial\ell}{\partial x}^T+\frac{\partial f}{\partial x}^T\lambda^*,\quad \lambda^*(T)=\frac{\partial\ell_f}{\partial x}^T$$
$$\forall t,\ u^*=\arg\min_{u\in U}\big[\ell(x^*,u)+(\lambda^*)^Tf(x^*,u)\big]$$

**注意**：定理最后一行被最小化的项，常被称为最优控制问题的 **Hamiltonian**：

$$H(x,u,\lambda,t)=\ell(x,u)+\lambda^Tf(x,u)$$

**它区别于、但受启发于经典力学的 Hamiltonian**。**记住 $\lambda$ 解释为 $\frac{\partial J}{\partial x}^T$**，你**也该从 HJB 里认出它**。

**类比**：Pontryagin = **最优轨迹必须通过的"体检"**——前向满足动力学、反向满足伴随、每时刻 $u$ 最小化 Hamiltonian。**数值 solver 算出的轨迹，拿这三条一查，就知道"是不是真的（局部）最优"**。**它和 HJB 是亲戚**：HJB 是"对所有 $x$ 的全局充分条件"，Pontryagin 是"对一条轨迹的局部必要条件"。

## 8. 变体与扩展（10.8）—— 把非凸"骗"回凸的几种绝招

### 8.1 微分平坦（Differential Flatness）—— 四旋翼的"作弊码"

> 有些**非常重要的情形**，**非凸轨迹优化能通过巧妙的变量替换变回凸**。这空间的关键思想之一 = **微分平坦**，**哲学上很接近** Acrobot/cart-pole 讨论过的**部分反馈线性化（PFL）**。但**微分平坦最著名的应用，其实是四旋翼**——我们在这里探索。

**PFL 的最重要教训**：**若有 $m$ 个执行器，你基本能精确控制系统的 $m$ 个量**。微分平坦**利用同样思想**（选 $m$ 个输出），**但方向相反**：**对某些系统，若你给我那 $m$ 个坐标的一条轨迹，它事实上可能决定了所有状态/执行器当时必须在做什么**。**"你只能执行轨迹的一个子集"这件事，在这种情况下反而让轨迹规划容易得多！**

#### 例 10.3：平面四旋翼的微分平坦

> 前面描述的平面四旋翼模型有 **3 自由度**（$x,y,\theta$）但**只有两个执行器**（每个螺旋桨一个）。**我的主张**：**若你给我仅质心位置的轨迹 $x(t),y(t)$**，**我就能推出同一区间上 $\theta(t)$ 必须是什么才可行**。**而且我甚至能推出 $u(t)$**。**一个技术条件**：你给的 $x(t),y(t)$ 轨迹必须**四阶连续可微**。

**看清这点**：回忆运动方程 $m\ddot x=-(u_1+u_2)\sin\theta$ (1)，$m\ddot y=(u_1+u_2)\cos\theta-mg$ (2)，$I\ddot\theta=r(u_1-u_2)$ (3)。

**观察**：由 (1) 和 (2) 得 $\frac{-m\ddot x}{m\ddot y+mg}=\tan\theta$。**人话**：给定 $\ddot x(t),\ddot y(t)$，**我能解出 $\theta(t)$**！**再对时间微分两次**得 $\ddot\theta$。**用 (3) 配 (1) 或 (2)**，得**关于 $u_1,u_2$ 的两个线性方程**，**轻松解出**。

**现在看清为什么原轨迹要光滑**：$u(t)$ 的解**依赖 $\ddot\theta(t)$**，而 $\ddot\theta$ 依赖 $\frac{d^4x}{dt^4}$ 和 $\frac{d^4y}{dt^4}$——**需要这些导数沿整条轨迹都存在**。

**更妙**——**暂时忽略输入限**——**任何足够光滑的 $x(t),y(t)$ 轨迹都可行**！所以**只要我能找一条避障的光滑 $x,y$ 轨迹，就设计好了状态轨迹**。下面会看到，**优化哪怕高次分段多项式其实是个容易问题**（**算下来是个 QP**，假设约束凸）。**实践中这意味着：一旦你定好"左绕还是右绕"，轨迹设计又快又简单**。

**图 10.9**：平面四旋翼的微分平坦——**通过解一个简单优化找 $x(t),y(t)$ 的光滑轨迹，我能反推出 $\theta(t)$ 甚至 $u(t)$**。

> 上例表明平面四旋翼在输出 $x(t),y(t)$ 上**微分平坦**。**更一般地**，若有动力学系统 $\dot x=f(x,u)$，设计某输出坐标（本质"任务空间"）$z(t)=h(x,u,\frac{du}{dt},\dots,\frac{d^ku}{dt^k})$，**使得能把 $x$ 和 $u$ 纯写成输出及其时间导数的函数** $x(t)=x(z,\dot z,\dots),\ u(t)=u(z,\dot z,\dots)$，**则称系统在输出 $z$ 上微分平坦** [33]。**证明平坦的要求** = 写出"解出 $x,u$ 为仅 $z$ 及其导数函数"的函数。**作者不知道有任何"数值配方"来证明系统平坦或找潜在平坦输出**——**他认为微分平坦是"必须为你的系统去发现"的性质**——**通常靠一点机械直觉 + 大量代数**。**一旦找到，非常有用**。

#### 例 10.4：3D 四旋翼的微分平坦

> 微分平坦**最著名的例子**大概是**完整 3D 四旋翼**。[34] 证明 3D 四旋翼在输出 $\{x,y,z,\theta_{yaw}\}$ 上微分平坦。**他们戏剧性地用它做各种特技**。**结果视频超棒**（**接下来几年四旋翼在学术界和工业界的广泛流行，这些视频大概功劳不小**）。

**关于这些例子的几点局限**：
1. 上面技术**擅长设计轨迹**，但**稳定那些轨迹需额外工作**（后面详谈）。**轨迹稳定大大受益于好的状态估计**，上面例子**全在动捕场里做**。
2. **"简单"版的轨迹设计**（快到能用于"飞穿移动圆环"）**限于凸优化表述**——**意味着必须事先硬编码"每个障碍左绕/右绕/上/下"的决策**。

**类比（微分平坦，必懂）**：四旋翼有 4 个状态维度要管（位置 + 姿态），但**微分平坦告诉你"别管姿态和油门，只要画一条质心的光滑曲线"**——**姿态和油门会被这条曲线'自动决定'**。**就像你不用想"走路时膝盖怎么弯、肌肉怎么收缩"，只要决定"重心走哪条线"，身体自动配合**。**这把"非凸的四旋翼规划"降维成"画一条光滑避障曲线"的凸问题**——**前提是"左/右绕"这种离散选择你已经拍板**。

### 8.2 迭代 LQR（iLQR）与微分动态规划（DDP）—— 在猜的轨迹上"反复贴二次补丁"

> 还有**另一种轨迹优化方法**（至少对初值问题），**近年很流行**：**迭代 LQR（iLQR）** [35]（又称**序列线性二次最优控制** [36]）。**思想足够简单**：给定输入和状态轨迹的**初猜**，**对动力学做线性近似 + 对代价做二次近似**。**然后算时变 LQR 控制器并仿真，得新的输入和状态轨迹**。**重复至收敛**。

**iLQR 背后的动机很诱人**——**它利用 Riccati 方程的惊人结构**，**单次反向 Riccati + 一次前向仿真**，就给出**轨迹的二阶更新**。**经验上收敛快且鲁棒**。众多应用 [37,38]。

**iLQR 的一个关键局限**：**只支持无约束轨迹优化**——至少**经 Riccati 解**。**约束优化的自然扩展** = **用迭代线性 MPC 优化替换 Riccati 解**；这会得到 **QP**，**非常接近 SQP 里发生的事**。但**当前机器人文献更常见的做法** = **用罚函数法（尤其增广拉格朗日）把任何约束加进目标**。

**微分动态规划（DDP）** [39] **受"解 HJB 的局部二次近似"启发**。**结果算法几乎与 iLQR 相同**；**唯一区别 = DDP 用动力学的二阶近似，而非一阶（线性）近似**。**传统智慧**：**多算这些动力学导数，大概不值得多花的计算成本**；**多数情况 iLQR 收敛得和 DDP 一样快**（细节问题相关）。**不幸**，**尽管这两算法的区别毫无歧义、毫无争议，你会发现很多论文误写 DDP，实际用的是 iLQR**。

**类比（iLQR/DDP）**：你**先猜一条轨迹**（可能很糙）。**在这条轨迹上，把弯曲的动力学'贴'成线性的、把代价'贴'成二次的**——**这块'补丁'上，LQR 能精确算出'该怎么改进'**。**按改进量更新轨迹，再在新轨迹上贴新补丁**……**反复贴，直到补丁和真轨迹贴合 = 收敛**。**iLQR = 贴'一阶'补丁，DDP = 贴'二阶'补丁**（更准但更贵，通常不值）。

### 8.3 利用组合优化（GCS）—— 把"左/右绕"画成"凸集图上的最短路"

> 我们一直在对付（或回避！）的**许多非凸代价/约束**，**能自然地表示成"析取"约束**（如 $x\in A$ 或 $x\in B$）。有一系列重要工作展示**如何用混合整数规划做绕障轨迹优化** [40–43]。**这些方法漂亮地分离**优化的**离散/组合**方面（如"我飞左还是右绕树"）与**连续**方面（如"假设我决定左绕，该走哪条光滑路径/轨迹"），**主要利用基于"分支定界"的混合整数规划求解器**，**把转录问题解到全局最优**。

**但**：这些转录**效率不高**，**分支定界求解器求解时间可能很长**。

**近来**：用叫 **Graphs of Convex Sets（GCS）** 的新框架，**这方法 dramatically 更高效**。**GCS 为许多"离散+连续"轨迹优化问题提供更高效的转录**。**很多情况下，混合整数问题的凸松弛足够紧，以至于只需解凸松弛（+ 一点 "rounding"）就能解到全局最优**。

#### 例 10.5：最小时间线性最优控制（GCS 入门）

> 回忆本章第一个例子 = 双积分器轨迹优化。**固定时域上优化凸目标**，**自然转录成凸优化**。**但为解最小时间问题（时域未知）**，我们得**解多个优化找正确时域**。

**这"对时域的搜索"能自然编码成混合整数问题**，**GCS 提供自然且高效的框架**。先观察：**原固定时域问题能自然描述成 GCS**：**取集合 = $x$ 的域**（为有界，简单选个保守包围盒）。**图 = 串行链**，**每个时步一份这集合的拷贝**，**边约束强制动力学**：$x[n+1]-Ax[n]\in BU$，$U=\{u\mid u\in[-1,1]\}$。**太棒了**：**一旦实现我们为 Drake 的 GCS 实现正在做的所有代码优化**，**用这种方式表述问题，会精确还给你上面解的同一个 LP**。

**现在让时长可选**：**定义从每个时步直接到目标的边 + 约束**。

> **注意**：这例子 **GCS 凸松弛还不紧**（**暂时**；作者还有些想法），但 **`convex_relaxation=False` 版本**，**若有 MIP 求解器，解得漂亮**。

**最小时间双积分器太简单，不值得用 GCS**——毕竟上面推荐的**线搜索**也能高效工作。**但这是个 nice 简单示例**，展示**如何把轨迹优化表述成 GCS**，**且能 scale 到复杂得多的表述**。

### 8.4 显式 MPC（Explicit MPC）—— "把 MPC 的答案预先全算出来"

>  nhờ **显式 MPC** [45] 的工作，**我们确实理解"不等式约束 LQR 问题"的最优策略长什么样**——**最优策略现在分段线性（仍连续）**，**每段由一个多面体描述**，**最优 cost-to-go 在同多面体上分段二次**。**不幸**，**段数随约束数和问题时域指数增长**，**使除很小问题外都不实用**。**但有若干有前途的近似显式 MPC 方法**（[46]）。

**类比**：普通 MPC = **每次现场算**"该往哪走"。显式 MPC = **事先把"状态空间每个区域该用哪个线性公式"全算好、列成一张表**，**在线只查表**——**飞快**。**但表的大小随约束/时域指数爆炸**，**所以只对玩具问题实用**。

### 习题 10.3：iLQR 理论

> 读论文 [47] 的 **1、2 节**，**特别关注第 2 节**。用**自己的话**答（**每部分 1–3 句**）：

- **(a)** **iLQR 在解什么优化问题？算法输出是什么？**（**答**：解**非线性、（通常）无约束**的有限时域最优控制；**输出 = 一条（局部最优的）状态+控制轨迹**，**常附带一个时变线性反馈策略**。）
- **(b)** **解释反向 pass 做什么、起什么作用。**（**答**：沿当前轨迹**反向**，**用线性化动力学 + 二次化代价**，**递推一个'二次 Q 函数 / 值函数'**，**算出'最优改进量'的反馈增益**——**本质是时变 LQR 的反向 Riccati 递推**。）
- **(c)** **解释前向 pass 做什么、起什么作用。**（**答**：用反向 pass 给的改进量，**前向仿真/rollout 出一条新的、（希望）代价更低的轨迹**——**带线搜索保证代价真下降**。）
- **(d)** **解释两者如何迭代交互？期望收敛吗？为什么？**（**答**：反向给"怎么改"、前向"落实改并评估"，**交替**；**期望收敛**，因为**每轮在二次近似下是'下降'，配合线搜索/正则化保证单调改进，逼近一个局部最优**。）
- **(e)** **解释 DDP 与 iLQR 的区别。**（**答**：**DDP 用动力学的二阶（Hessian）近似，iLQR 只用一阶（线性）近似**；其余几乎相同。）
- **(f)** **设动力学不光滑（非连续可微）但闭式可用，还能用算法吗？反向 pass 行吗？前向 pass 呢？**（**答**：**反向 pass 需要动力学/代价的导数（Jacobian/Hessian）**，**不光滑处导数不存在/不连续 → 反向 pass 的二次近似失效/不可靠**；**前向 pass 只需'仿真'（函数值），不需要导数 → 仍能跑**。**所以'不光滑'主要破坏反向 pass**。）

### 习题 10.5：微分平坦（平面刚体 + 体固力）

> 考虑**质量 $m$、转动惯量 $I$** 的平面刚体，**在重力和作用于体上点 $P$ 的力 $F_1,F_2$** 下运动（见图 10.14）。**任意时刻体状态** $x=(x,y,\theta)$，$x,y$ = COM 位置，$\theta$ = 体朝向。**运动方程**：

$$m\ddot x=F_1\cos\theta+F_2\sin\theta,\quad m\ddot y=F_1\sin\theta-F_2\cos\theta-mg,\quad I\ddot\theta=rF_1$$

**图 10.14**：受体固力控制的平面刚体。

$$z_1=x-\tfrac{I}{mr}\sin\theta,\quad z_2=y+\tfrac{I}{mr}\cos\theta$$

**即**：证**给定足够可微的轨迹 $z(t)$，能唯一确定 $x(t)$**（**$\theta$ 有 $\pi$ 歧义**）。**提示**：**证 $\theta$ 由 $z_1,z_2$ 的某高阶导唯一确定**；**再证 $\ddot x,\ddot y$ 由 $\ddot z_1,\ddot z_2$ 的某高阶导唯一确定**。（**参考 10.8.1 和例 10.3**：把 $\ddot x,\ddot y$ 代入 $\ddot z_1,\ddot z_2$ 的表达式，**消去 $F_1,F_2$，得到只含 $\theta$ 和 $z$ 导数的关系**，**解出 $\theta$**；**再回代得 $\ddot x,\ddot y$**。）

- **(b)** 设**能控制作用于 $P$ 的 $F_1,F_2$ 的大小**，**且对 $F_1,F_2$ 无约束**。**要找一条（控制+状态）轨迹，使体经过某些航点 $(x_k,y_k,\theta_k)$**。
  - **(i)** **解释如何用微分平坦坐标产生这样一条轨迹**。（**答**：在**平坦输出 $z$ 空间**规划一条**足够光滑、且插值'航点对应的 $z$ 值'** 的曲线——**因为 $z$ 与 $(x,y,\theta)$ 一一对应，航点约束变成 $z$ 上的插值约束**；**光滑性用高次/分段多项式保证**；**再由平坦映射反推 $\theta(t),F_1(t),F_2(t)$**。）
  - **(ii)** **解释'原坐标'vs'平坦坐标'的轨迹规划表述区别。凸吗？哪个更易解，为什么？**（**答**：**原坐标**里，动力学 + 航点 + 力的关系**耦合非线性 → 非凸、难解**；**平坦坐标**里，**只要 $z$ 光滑就自动可行**，**航点 = $z$ 的线性插值约束**，**若目标取 $\int(\text{高阶导})^2$（如最小 snap）则对多项式系数是 QP → 凸、易解**。**所以平坦坐标更易解**——**它把非凸的'满足动力学'变成了'画光滑曲线'的凸问题**。）

## 增补一：把"还不够通俗"的 6 个概念，各加一个类比 / 澄清

1. **为什么"时间维离散"参数线性、"状态维离散"参数指数**？值迭代网格 = 每个状态维度切 $k$ 份 → 总点 $k^n$（$n$=状态维，**指数**）。轨迹参数化 = 时间切 $N$ 段，**每段存一个 $n$ 维 $x$ 和一个 $m$ 维 $u$** → 总参数 $N(n+m)$（**对 $n$ 线性**）。**这就是"维度诅咒被绕开"的数学根**。
2. **零阶保持（ZOH）**：假设**控制输入在一个时步内不变**（像"踩住油门一秒不动"）。**这是把连续控制'阶梯化'**，**让积分有闭式/好算**。**绝大多数数字控制器本来就是 ZOH**（DAC 输出保持到下次更新），**所以这假设很真实**。
3. **直接配置的"为什么不需要样条系数"**：三次多项式有 4 个自由度；**每段你给了 4 个数**（$x(t_k),\dot x(t_k),x(t_{k+1}),\dot x(t_{k+1})$）→ **4 个方程定 4 个系数**，**所以系数是断点值的'函数'，不必当独立变量**。**优化只调断点值，样条自动跟着变**——**这就是配置法'变量少'的秘密**。
4. **伴随 λ 的物理意义**：$\lambda[n]=\frac{\partial J}{\partial x[n+1]}^T$ = "**终值总代价对'第 n+1 步状态'的敏感度**"——**'这一步状态偏一点，最终代价变多少'的'影子价格'**。**经济学里的'影子价格'/物理里的'共轭动量'，就是它**。
5. **iLQR 的"正则化"**：反向 pass 里 $Q_{uu}$ 可能**非正定**（二次近似不够好）→ **加 $\mu I$ 正则**（Levenberg-Marquardt 味）：**$\mu$ 大 = 更像梯度下降（稳但慢），$\mu$ 小 = 更像牛顿/iLQR（快但可能不稳）**，**线搜索时动态调 $\mu$**。**这是 iLQR 工程实现的关键细节**，PDF 没展开，**做习题 10.4 时会碰到**。
6. **微分平坦 vs PFL 的"方向相反"**：PFL = "**我有控制器，问'能让哪些量精确跟踪'**"（从输入推输出）；微分平坦 = "**我先指定输出轨迹，问'输入和状态被迫是什么'**"（从输出反推输入）。**一个'正向问能控什么'，一个'反向问要什么'**——**但底层都是'执行器数 = 能自由指定的输出数'**。

### 实验 1：直接转录 —— 双积分器二次代价（scipy，可跑，对照例 10.1 / 习题 10.1b）

**把 $x[\cdot],u[\cdot]$ 都当变量，动力学当等式约束**，用 SLSQP 解（凸问题，SLSQP 也能解；标准做法见实验 1B 的 Drake QP）。

```python
import numpy as np
from scipy.optimize import minimize
N, dt = 50, 0.1
A = np.array([[1, dt],[0, 1]]); B = np.array([[0],[dt]])     # 双积分器 ZOH 离散
x0 = np.array([1.0, 0.0]); Q = np.eye(2); R = np.eye(1)*0.1
# 决策变量 z = [x0,x1,...,xN, u0,...,u_{N-1}]，每个 x 2维, u 1维
nx, nu = 2, 1
def unpack(z):
    X = z[:nx*(N+1)].reshape(N+1, nx); U = z[nx*(N+1):].reshape(N, nu); return X, U
def cost(z):
    X, U = unpack(z)
    return sum(X[n]@Q@X[n] + U[n]@R@U[n] for n in range(N)) + X[N]@Q@X[N]
def dyn_con(z):                                   # x[n+1] - A x[n] - B u[n] = 0
    X, U = unpack(z); c = []
    for n in range(N): c.append(X[n+1] - A@X[n] - (B@U[n]).ravel())
    c.append(X[0]-x0)                             # 初值约束
    return np.concatenate(c)
z0 = np.zeros(nx*(N+1)+nu*N)
res = minimize(cost, z0, method='SLSQP', constraints={'type':'eq','fun':dyn_con},
               options={'ftol':1e-9,'maxiter':2000})
X, U = unpack(res.x)
print("转录解 终态 x[N] =", np.round(X[N],4), " 代价 =", round(res.fun,4))
```

**你会看到**：状态**平滑趋近原点**，**和 LQR 闭环几乎一致**（验证习题 10.1c 的精神：长时域转录 → LQR）。**加输入限**：在 `minimize` 里加 `bounds`（对 $U$ 部分限 $[-1,1]$）→ **立刻看到 bang-bang 味**（约束 LQR）。**这就是"凸转录在线解"的玩具版**。

### 实验 1B：直接转录 —— Drake 的 QP 标准写法（骨架，对照习题 10.1b/e）

```python
from pydrake.all import MathematicalProgram, Solve
import numpy as np
prog = MathematicalProgram()
X = prog.NewContinuousVariables(N+1, nx, "x"); U = prog.NewContinuousVariables(N, nu, "u")
prog.AddQuadraticCost(np.eye(nx*(N+1)+nu*N), np.zeros(nx*(N+1)+nu*N),   # 占位：实际按 Q,R 拼
                      np.concatenate([X.ravel(), U.ravel()]))           # 真实写法：逐时步 AddQuadraticCost
for n in range(N):
    prog.AddLinearEqualityConstraint(X[n+1] - A@X[n] - (B@U[n]).ravel(), np.zeros(nx))  # 动力学=线性等式
prog.AddLinearEqualityConstraint(X[0], x0)                              # 初值
# prog.AddBoundingBoxConstraint(-1, 1, U)                               # 输入限 -> 仍 QP
# 带状稀疏：Drake/专用求解器自动利用；习题10.1e 的 Riccati 递归 = 手写高效解这套 KKT
sol = Solve(prog)
```

**人话**：**动力学是线性等式 → 二次目标 + 线性等式/不等式 = QP**，**Drake 调 OSQP/CLP 等秒解**。**习题 10.1e 要你写的"Riccati 递归"** = **不直接解大 KKT，而利用'带状'结构反向递推**（和 LQR 的 Riccati 同源）——**这是"为什么转录的大问题也能快解"的底层原因**。

### 实验 2：直接射击 —— 无约束 + 对比条件数（可跑，对照 10.2.2 / 习题 10.1a/d）

```python
import numpy as np
from scipy.optimize import minimize
N, dt = 50, 0.1
A = np.array([[1,dt],[0,1]]); B = np.array([[0],[dt]]); x0 = np.array([1.0,0.0])
Q = np.eye(2); R = np.eye(1)*0.1
def rollout(U):                                  # 射击：只 u 是变量，x 靠前向仿真
    X = [x0]
    for n in range(N): X.append(A@X[-1] + (B@U[n]).ravel())
    return np.array(X)
def cost(U):
    X = rollout(U.reshape(N,1))
    return sum(X[n]@Q@X[n] + U[n]**2*R[0,0] for n in range(N)) + X[N]@Q@X[N]
res = minimize(cost, np.zeros(N), method='L-BFGS-B')                    # 无约束！
print("射击解 代价 =", round(res.fun,4))
# 数值条件（习题10.1a/d 的核心）：看 A^n 的范数 / 射击 Hessian 条件数 vs 转录
print("||A^N|| =", round(np.linalg.norm(np.linalg.matrix_power(A,N)),3),
      " -> 射击的'早期u影响'被放大，条件数差（尾巴摇狗）")
```

**对比实验 1**：**射击变量少（只有 $N$ 个 $u$）、无等式约束**，**但 $\|A^N\|$ 大时（不稳定/长时域）数值条件恶化**——**亲手看到 2.3 的"尾巴摇狗"**。**把 $A$ 换成不稳定系统（如倒立摆线性化）+ 长 $N$，射击会明显比转录'难解/病态'**。

### 实验 3：伴随梯度 = 反向传播（可跑，对照 4.2 / 10.7.1，验证射击梯度）

**手写反向 pass，对比有限差分**——**亲眼确认"伴随 = 反向模式 AD"**。

```python
import numpy as np
N, dt = 30, 0.1
A = np.array([[1,dt],[0,1]]); B = np.array([[0],[dt]]); x0 = np.array([1.0,0.0])
Q = np.eye(2); R = np.eye(1)*0.1
def cost_and_grad_adjoint(U):
    U = U.reshape(N,1)
    # 前向
    X = [x0]
    for n in range(N): X.append(A@X[-1] + (B@U[n]).ravel())
    X = np.array(X)
    J = sum(X[n]@Q@X[n] + U[n]@R@U[n] for n in range(N)) + X[N]@Q@X[N]
    # 反向（伴随）
    g = np.zeros(N); lam = 2*Q@X[N]                       # λ[N-1] = ∂ℓf/∂x
    for n in range(N-1, -1, -1):
        g[n] = (2*R@U[n] + B.T@lam).ravel()               # ∂J/∂u[n]
        lam = 2*Q@X[n] + A.T@lam                          # λ[n-1] = ∂ℓ/∂x + Aᵀλ
    return J, g
# 对比有限差分
U0 = np.random.RandomState(0).randn(N)
J, g = cost_and_grad_adjoint(U0)
gfd = np.zeros(N); e = 1e-6
for k in range(N):
    Up = U0.copy(); Up[k]+=e; Jp,_ = cost_and_grad_adjoint(Up)
    Um = U0.copy(); Um[k]-=e; Jm,_ = cost_and_grad_adjoint(Um)
    gfd[k] = (Jp-Jm)/(2*e)
print("伴随梯度 vs 有限差分 最大误差 =", round(np.max(np.abs(g-gfd)),8), " (应≈0 -> 伴随=反向传播)")
```

**你会看到**：**误差 ≈ 1e-8**——**亲手验证"一次前向 + 一次反向 = 全部梯度"，且和有限差分一致**。**这就是 4.2 说的"伴随方程 = 神经网络反向传播的祖宗"**——**当 $N$ 大、输入维高时，反向 pass 比"每个 $u_k$ 有限差分"快 $N$ 倍**。

### 实验 4：直接配置 —— 三次样条 + 中点配置（Drake 骨架 + 手写公式，对照 10.3.2 / 例 10.2）

**Drake 一行**：`DirectCollocation`。下面给**手写配置约束**，让你看清"中点三式"怎么变成约束。

```python
from pydrake.all import DirectCollocation, DirectCollocationConstraint, MathematicalProgram
from pydrake.systems.primitives import LinearSystem
import numpy as np
# Drake 标准写法（例10.2 的"形状"）：
sys = LinearSystem(A, B)                          # 或 Pendulum/Acrobot/CartPole 的 SymbolicVectorSystem

colloc = DirectCollocation(prog, sys, context, num_time_samples=N,
                           minimum_timestep=0.05, maximum_timestep=0.2)   # t[·] 可作变量(10.3.1)
colloc.AddConstraintToAllKnotPoints(...)          # 输入/状态限
prog.AddQuadraticCost(...)                        # Σ h_n ℓ
# 手写"中点配置约束"（PDF 三式，对非线性 f 用）：
def collocation_constraint(xk, xk1, uk, uk1, h, f):
    xdk, xdk1 = f(xk,uk), f(xk1,uk1)
    xc  = 0.5*(xk+xk1) + h/8*(xdk - xdk1)         # 中点状态
    xdc = -3/(2*h)*(xk-xk1) - 0.25*(xdk+xdk1)     # 中点导数
    return xdc - f(xc, 0.5*(uk+uk1))              # 应 = 0
```

**人话**：**Drake 的 `DirectCollocation` 把"断点变量 + 中点配置约束 + 时步变量"全封装好**；**手写三式让你看清"为什么断点值就够、中点斜率必须匹配动力学"**。**对摆/Acrobot/Cart-Pole 的 swing-up**，**给 $x$ 一个'起终点直线'初猜**（作者说"甚至必要"），**solver 就能找到那条'先甩后稳'的轨迹**。

### 实验 5：iLQR 最小完整实现（可跑，本章最有教学价值，对照 10.8.2 / 习题 10.4）

**双积分器到原点**，**含反向 pass（Q/V 递推）+ 前向 pass（线搜索）**——**把 iLQR 的'贴二次补丁'循环写活**。

```python
import numpy as np
N, dt = 60, 0.1
def f(x,u): return np.array([x[0]+dt*x[1], x[1]+dt*u[0]])     # 离散动力学
def cx(x):  return x                                            # 代价: xᵀQx+uᵀRu
Q = np.diag([10.,1.]); R = np.diag([0.1]); Qf = np.diag([100.,10.])
def A_jac(x,u): return np.array([[1,dt],[0,1]])
def B_jac(x,u): return np.array([[0],[dt]])
x0 = np.array([1.0,0.5]); U = 0.1*np.random.randn(N,1)         # 初猜
def rollout(U, x0, K=None, k=None, alpha=1.0):                  # 前向 pass（带反馈修正）
    x = x0.copy(); X=[x]; Us=[]
    for n in range(N):
        du = (k[n] if k is not None else 0) + (K[n]@(x-X[n]) if K is not None else 0)
        u = U[n] + alpha*du; Us.append(u); x = f(x,u); X.append(x)
    return np.array(X), np.array(Us)
def cost(X,U): return sum((X[n]@Q@X[n]+U[n]@R@U[n]) for n in range(N)) + X[N]@Qf@X[N]
for it in range(40):
    X, _ = rollout(U, x0)
    # 反向 pass
    K = np.zeros((N,1,2)); k = np.zeros((N,1)); Vx = Qf@X[N]; Vxx = Qf
    for n in range(N-1,-1,-1):
        A, B = A_jac(X[n],U[n]), B_jac(X[n],U[n])
        Qx, Qu = Q@X[n], R@U[n]
        Qxx, Quu, Qxu = Q+ A.T@Vxx@A, R + B.T@Vxx@B, B.T@Vxx@A
        Quu_reg = Quu + 1e-3*np.eye(1)                          # 正则化（增补一.5）
        K[n] = -np.linalg.solve(Quu_reg, Qxu); k[n] = -np.linalg.solve(Quu_reg, Qu)
        Vx = Qx + A.T@Vx + A.T@Vxx@B@k[n] + K[n].T@Quu@k[n] + K[n].T@Qxu
        Vxx = Qxx + A.T@Vxx@A + A.T@Vxx@B@K[n] + K[n].T@Quu@K[n] + K[n].T@Qxu + Qxu.T@K[n]
    # 前向 pass + 线搜索
    J0 = cost(X, U)
    for alpha in [1.,.5,.25,.1,.05]:
        Xn, Un = rollout(U, x0, K, k, alpha); Jn = cost(Xn, Un)
        if Jn < J0: U = Un; break
    if it%10==0: print(f"iter {it}: cost={Jn:.4f}")
print("iLQR 终态 =", np.round(Xn[-1],3))
```

**你会看到**：**代价单调下降、终态→0**——**亲手跑通"反向算 $K,k$（时变 LQR 反馈 + 前馈）+ 前向线搜索"的 iLQR 循环**。**把 `f` 换成自主车/摆**，**就是习题 10.4 的本尊**。**正则项 `1e-3` 去掉/调大**，**看收敛变慢或发散**——**体会增补一.5 的 LM 味**。

### 实验 6：微分平坦 —— 平面四旋翼最小 snap（scipy，可跑，对照 10.8.1 / 例 10.3 / 习题 10.5）

**在平坦输出 $(x,y)$ 上**，**用分段多项式 + waypoint 等式约束 + 最小化 snap**（$\int \dddot x^2+\dddot y^2$ 的近似：这里用最小化 4 阶导平方和的离散版）→ **QP/凸**。

```python
import numpy as np
from scipy.optimize import minimize
# 一段 K 次多项式 x(t)=Σ c_i t^i；最小 snap = 最小化 4 阶导系数加权
# 简化演示：单段 7 次多项式，约束 t=0,1 的位置/速度/加速度/ jerk（8 个等式/轴）
K = 8
def poly(c,t):  return sum(c[i]*t**i for i in range(K))
def d4(c):      return np.array([0]*4 + [c[i]*i*(i-1)*(i-2)*(i-3) for i in range(4,K)])  # 4阶导系数
def snap_cost(c): 
    # ∫_0^1 (x⁽⁴⁾(t))² dt = d4ᵀ H d4, H_{ij}=1/(i+j+1)
    H = np.array([[1/(i+j+1) for j in range(K)] for i in range(K)]); d=d4(c); return d@H@d
# 等式：t=0 在 (0,0) 静止, t=1 在 (1,1) 静止（位置+速度+加速度+jerk=0）
def eq(c):
    cx, cy = c[:K], c[K:]
    con = []
    for der, val in [(0,0),(1,0),(2,0),(3,0)]:         # t=0 各阶=0
        con += [sum(cx[i]*np.math.factorial(i)//np.math.factorial(i-der)*0**(i-der) if i>=der else 0 for i in range(K))]
    # 为简洁，用数值导数在 t=0,1 约束（生产代码用解析）
    return con  # 占位：实际填 8+8 个等式
c0 = np.zeros(2*K)
res = minimize(lambda c: snap_cost(c[:K])+snap_cost(c[K:]), c0, method='SLSQP',
               constraints={'type':'eq','fun':eq})   # 凸（二次+线性等式）-> 全局最优
# 反推 θ, u（例10.3 公式）：tanθ = -ẍ/(ÿ+g)，u1,u2 由 (1)(2) 线性解
```

**人话**：**核心不在 scipy 细节，而在'结构'**——**在 $(x,y)$ 上'最小 snap + waypoint 等式' = 二次目标 + 线性等式 = 凸 QP**，**而 $\theta,u$ 是事后由平坦公式反推的**（**不参与优化**！）。**这就是微分平坦'把非凸四旋翼规划变凸'的代码体现**。**加避障**（$x,y$ 的多面体约束 + GCS）= 例 10.8 / [19]。**加力限** = 习题 10.5c → **非凸回来**。

### 实验 7：MPC 滚动时域 + 终值约束（可跑，对照 10.5.2，看递归可行性）

```python
import numpy as np
from scipy.optimize import minimize
N, dt, Nh = 100, 0.1, 15                          # 总步 / 步长 / MPC 时域
A = np.array([[1,dt],[0,1]]); B = np.array([[0],[dt]]); Q=np.eye(2); R=np.eye(1)*0.1
x_star = np.array([0.,0.])                         # 终值约束目标（递归可行性钥匙）
def mpc_step(x_now):
    def cost(U):
        X=[x_now]
        for n in range(Nh): X.append(A@X[-1]+(B@U[n]).ravel())
        return sum(X[n]@Q@X[n]+U[n]@R@U[n] for n in range(Nh)) + 1000*np.linalg.norm(X[-1]-x_star)**2  # 软终值(硬终值用等式)
    res = minimize(cost, np.zeros((Nh,1)), method='L-BFGS-B', bounds=[(-2,2)]*Nh)
    return res.x[0]                                # 只执行第一步
x = np.array([1.0,0.3]); traj=[x]
for _ in range(N):
    u = mpc_step(x); x = A@x+(B@u).ravel(); traj.append(x)
traj = np.array(traj)
print("MPC 终态 =", np.round(traj[-1],3), " -> 滚动时域+终值约束，稳定且不'infeasible'")
```

**人话**：**每步只解 $N_h$ 步、执行第一步、滚动**——**加上'软/硬终值约束到 $x^*$'**，**保证递归可行性**（5.2 的论证）。**去掉终值项**，**在某些初值/约束下可能'走着走着 infeasible'**——**亲手对比，体会'永远留个安全车位'的必要性**。

## 给初学者的"本章通关三句话"

1. **放弃全局，换可扩展**：轨迹优化**不求全状态空间的反馈**，**只求从单个初值出发的最优轨迹**——**离散化只在时间维做**，参数随状态维度**线性**增长，**于是高维系统终于算得动**；代价是**一次只解一个初值**，要靠 **MPC / 反馈运动规划**补回"反馈"。
2. **四种转录 + 一个梯度灵魂**：**转录**（$x,u$ 都变量、可并行、带状稀疏）、**射击**（只 $u$、串行、数值病态）、**配置**（分段多项式、中点配导数、不需前向）、**伪谱**（全局高次基）——**各有取舍**；而**射击的伴随方程 = 反向传播**，**一次前向+一次反向拿全部梯度**，是高效求解的命门。
3. **把非凸'骗'回凸的三把钥匙**：**微分平坦**（四旋翼只画质心光滑线，姿态油门自动定，变 QP）、**iLQR/DDP**（在猜的轨迹上反复贴二次补丁）、**GCS**（把'左/右绕'的离散选择画成凸集图最短路，凸松弛常紧到出全局最优）——**它们和'有限时域 LQR + 漏斗 + MPC'一起，构成了'从一条最优轨迹，到一套带保证的反馈'的完整链条**，**而栖停滑翔机正是这条链条'在失速边缘也能稳稳落下'的实战证明**。

> 最后送你一句动手箴言：本章所有"取舍"（转录 vs 射击的条件数、配置的精度、伴随 vs 有限差分的速度、iLQR 正则的大小、MPC 终值约束的必要性、微分平坦加力限后凸性的丧失）都会在你跑通上面 8 段代码后变成"显然"。**尤其实验 3（看伴随梯度 = 有限差分，确认反向传播）、实验 5（看 iLQR 代价单调下降、亲手调正则）、实验 2 vs 实验 1（看射击的 $\|A^N\|$ 病态 vs 转录的稳定）这三段**——做完它们，"转录/射击/配置/伴随/iLQR/MPC/微分平坦/GCS"这些最抽象的词，就会像"骑自行车"一样长进你的肌肉记忆。**这一章的精髓不是某个公式，而是那个务实的范式跃迁——当'算全地图'太贵时，'只算这一趟路'反而成了通向高维世界的钥匙；而轨迹优化的真正艺术，在于知道何时该用凸的天堂（线性/平坦），何时该直面非凸的地狱（避障/接触），以及如何在两者之间，用伴随的梯度、增广的罚单、并行的采样、和凸集图的最短路，架起一座座'把难问题骗成易问题'的桥——最终，让一只泡沫滑翔机，在失速的悬崖边，像鸟一样，稳稳地，落在绳上。** 🛩️
