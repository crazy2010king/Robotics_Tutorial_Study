## 开篇：当机器人遇上"风"

前几章我们研究的都是**确定性系统**——给定初始状态和控制输入，未来完全确定：
$$\dot{x} = f(x, u)$$

但真实世界从来不是确定的。机器人会遭遇：
- 阵风（时变随机扰动）
- 地面湿滑程度不确定（模型参数误差）
- 电机扭矩的微小波动

所以本章把动力学扩展为：
$$\dot{x} = f(x, u, w)$$

其中 $w$ 是**随机过程**的输出。

> 🎲 **类比**：确定性系统像照剧本演戏——每一句台词都预先写好。随机系统像即兴表演——演员根据现场反应（噪声）随时调整，但大体情节（动力学）仍在。

**本章的假设**：我们能**完美测量**状态（还没有测量噪声），只关注**过程噪声**（process noise）如何塑造系统的长期行为。

**主要工具**：离散时间系统（比连续时间更容易想象），且大多数例子采用**加性噪声**：
$$x[n+1] = f(x[n], u[n]) + w[n]$$

> 💡 **为什么加性噪声"不损失太多"？** 虽然噪声是直接加的，但它会经过下一步的非线性函数 $f$，所以仍然能产生极其丰富的行为。

**Drake中的随机性**：Drake对随机性处理很严谨——仿真时给定**随机种子**（random seed），结果是**确定可复现**的。这既支持随机算法，又方便调试。

## 6.1 主方程（Master Equation）：不问"在哪"，问"概率在哪"

在确定性世界，我们问："系统最终停在 $x=1$ 吗？"

在随机世界，这个问题没意义——系统可能今天在 $x=1$，明天跳到 $x=-1$。我们应该问：

> **"系统在 $x=1$ 附近的概率密度是多少？"**

### 例6.1：双稳系统 + 噪声

**确定性版本**：$\dot{x} = x - x^3$

- 稳定固定点：$x^* = \pm 1$（两个山谷底）
- 不稳定固定点：$x^* = 0$（山顶）

> 🏔️ **类比**：想象一个双山谷地形。没有噪声时，小球从左边滚下就永远待在左山谷，从右边滚下就永远待在右山谷。山顶是分水岭。

**离散化 + 加性噪声**：
$$x[n+1] = x[n] + h\left(x[n] - x[n]^3 + w[n]\right)$$

$w[n]$ 是**零均值高斯白噪声**：
- $E[w[n]] = 0$
- $E[w[i]w[j]] = \sigma^2$ 如果 $i=j$，否则为 $0$

> 🎲 **白噪声类比**：每一步都掷一个正态分布的骰子，均值0，标准差 $\sigma$。步与步之间完全独立（不记得之前掷过什么）。

**仿真观察（图6.1）**：
- 小 $\sigma$ 时：轨迹大致趋向 $\pm 1$ 之一，但不断随机跳动
- 即使到达 $\pm 1$，下一步几乎肯定会离开（只是不会走太远）
- 偶尔，噪声足够大时，小球能**翻过山顶**，从左边山谷跳到右边山谷！

> 🏔️ **类比**：现在山谷里刮着随机风。小球在风中颤动，大部分时间待在一个山谷里，但强风偶尔能把它吹过山顶到另一边。

**直方图动画（图6.2）**：
如果同时放一万个小球，每个都受独立噪声驱动，你会发现：
- 初始时所有球挤在一起（尖峰）
- 逐渐分裂成两团，分别聚集在 $x \approx 1$ 和 $x \approx -1$
- 最终形成稳定的**双峰分布**

> 🎯 **核心洞察**：单个轨迹永远不收敛，但**概率分布**收敛了！

---

### 主方程（Master Equation）的登场

设 $p_x(x; n)$ 为时刻 $n$ 状态的概率密度函数。它满足：
$$\int_{-\infty}^{\infty} p_x(x; n) dx = 1$$

分布的演化遵循**主方程**：
$$p_x(x; n+1) = \int_{-\infty}^{\infty} p(x | x') p_x(x'; n) dx'$$

> 🚗 **类比**：想象全国人口迁移。明天北京的人口 = 从河北迁来的概率 × 河北人口 + 从山东迁来的概率 × 山东人口 + …… 对所有省份积分。$p(x|x')$ 就是"迁移概率"——从 $x'$ 迁到 $x$ 的概率。

**惊人的事实**：这个更新是**线性的**！即使原始动力学 $f$ 是非线性的，概率密度的演化也是线性积分方程。

能这样写的系统叫**连续状态马尔可夫过程**。主方程可以算出很多有用的长期统计量，比如**平均失效时间**、**首次通过时间**。

### 例6.2：逻辑斯蒂映射（Logistic Map）——混沌中的秩序

甚至**不需要随机动力学**，随机初始条件就足以让主方程大放异彩。

**逻辑斯蒂映射**：
$$x[n+1] = 4x[n](1 - x[n]), \quad x \in [0, 1]$$

这是最简单的**混沌系统**。

> 🌪️ **类比**：混沌就像天气系统。北京今天温度 25°C，明天 25.0001°C——只差 0.0001 度，但一个月后两地的天气可能完全不同。对初值极度敏感。

**楼梯法**（Cobweb）：在 $x[n+1]$ vs $x[n]$ 图上，蓝色抛物线与橙色45度线交点是不动点。你会发现轨迹在 $(0,1)$ 区间内疯狂弹跳，永不重复（图6.4）。

**但分布的行为极其简单！**

这个系统罕见地有**闭式主方程**：
$$p_x(x; n+1) = \frac{1}{4\sqrt{1-x}}\left[p_x\left(\frac{1}{2}-\frac{1}{2}\sqrt{1-x}; n\right) + p_x\left(\frac{1}{2}+\frac{1}{2}\sqrt{1-x}; n\right)\right]$$

**稳态分布**（闭式解！）：
$$p_x(x; \infty) = \frac{1}{\pi\sqrt{x(1-x)}}, \quad x \in [0,1]$$

> 🎯 **这是什么形状？** 两端高（靠近0和1处概率密度无穷大），中间低。像一口倒扣的钟，或者一个U型。

**图6.5**：从均匀分布 $p_0(x)=1$ 出发：
- $p_1(x)$：已经开始向两端堆积
- $p_2(x)$：迅速逼近稳态分布（橙色虚线）

> 🌊 **类比**：虽然每滴水（单个轨迹）的运动不可预测，但整个水池（分布）的水位变化却遵循简单定律。混沌系统的"混乱"只存在于微观轨迹，宏观统计极其规则。

**术语**：
- 确定性动力学 + 分布初值 → 线性映射叫 **Perron-Frobenius 算子**
- 对应的方程叫 **Liouville 方程**

**更一般的主方程**（多维 + 控制输入）：
$$p_x(\mathbf{x}; n+1) = \int_{\mathcal{X}} p(\mathbf{x} | \mathbf{x}', \mathbf{u}) p_x(\mathbf{x}'; n) d\mathbf{x}'$$

这就是**连续状态马尔可夫决策过程（MDP）**。

**连续时间版本** → **Fokker-Planck 方程**。

## 6.2 稳态分布：聚拢与扩散的拉锯战

前面的例子都有一个共同特征：**概率分布收敛到一个稳态分布**——主方程的"不动点"。

### 例6.3：一维线性高斯系统——弹簧与风的平衡

$$x[n+1] = a x[n] + w[n], \quad |a| < 1$$

$w[n]$ 是零均值高斯白噪声，标准差 $\sigma_w$。

> 🪁 **类比**：$a$ 像弹簧的收缩力（$|a|<1$ 把系统往原点拉），$w[n]$ 像随机阵风（把系统吹散）。

**高斯分布的魔法**：

如果 $p_x(x; n)$ 是零均值高斯，标准差 $\sigma_n$，那么经过主方程后，$p_x(x; n+1)$ **仍然是零均值高斯**！

方差更新公式：
$$\sigma_{n+1}^2 = \sigma_w^2 + a^2 \sigma_n^2$$

> 🧮 **推导直觉**：新方差 = 风的方差（新增不确定性）+ 旧方差被压缩 $a^2$ 倍（系统本身把状态往中间拉，缩小了分散程度）。

**稳态分布**：
令 $\sigma_{n+1} = \sigma_n = \sigma_*$：
$$\sigma_*^2 = \frac{\sigma_w^2}{1 - a^2}$$

> ⚖️ **类比**：这是"聚拢"与"扩散"的完美平衡。
> - $a$ 越接近 0（强稳定）：稳态分布很窄（风一吹就被拉回来）
> - $a$ 越接近 1（弱稳定）：稳态分布很宽（系统懒得拉，风把状态吹得老远）
> - $\sigma_w$ 越大：风越猛，分布越宽

**多变量版本** → 卡尔曼滤波的过程更新（如果你学过卡尔曼滤波，这就是那个"预测步"的协方差更新）。

### 例6.4：单稳系统 + 大噪声——漏水的浴缸

$$\dot{x} = -x + x^3$$

离散化 + 噪声：
$$x[n+1] = x[n] + h\left(-x[n] + x[n]^3 + w[n]\right)$$

**确定性行为**：
- 原点 $x=0$ 是唯一稳定点
- 吸引域：$x \in (-1, 1)$（像碗的边界）
- 如果 $|x| > 1$，系统发散到无穷（像掉下悬崖）

> 🛁 **类比**：想象一个浴缸，底部是排水口（稳定点），但边缘只有10厘米高。水龙头在注水（噪声），水在底部打转。但如果某次波动太大，水花溅出边缘——水就永远流走了，不会回来。

**仿真观察（图6.6 / 6.7）**：
- 初始分布聚集在 $x=0$ 附近
- 但每一步都有**微小概率**越过 $x=\pm 1$（不稳定点）
- 一旦越过，就被 $x^3$ 项推向无穷，永不返回

**结论：这个系统没有稳态分布！**

概率密度不断从中心"泄漏"到无穷远处。长时间后，$x=0$ 附近没有任何概率剩下。

> 🚪 **关键区别**：例6.1的双稳系统，两个山谷都是"封闭"的——风虽然吹，但小球在山谷之间跳来跳去，不会跑到无穷远。而本例的"碗"有缺口，概率会漏光。

### 例6.5：随机范德波尔振荡器——极限环上的"墨水扩散"

确定性范德波尔振荡器：
$$\ddot{q} + (q^2 - 1)\dot{q} + q = 0$$

有**稳定极限环**（第四章学过）。轨道稳定：垂直于环的方向被拉回环上，但**沿环的方向既不收敛也不发散**（中性稳定）。

现在加噪声：
$$\ddot{q} + (q^2 - 1)\dot{q} + q = w(t)$$

**仿真（图6.8 → 6.9 → 6.10）**：
- **$t=0$**：所有粒子聚集在极限环上某一点（蓝色小团）
- **随时间推移**：垂直方向的扰动被拉回环上，但**沿环方向的扰动无人纠正**
- **$t=1000$**：粒子均匀覆盖了整个极限环！

> 🎨 **类比**：像一滴墨水滴入一个环形水槽。水槽的横截面很窄（垂直方向稳定，墨水不会散开），但环的周向没有约束（沿环方向自由）。墨水最终均匀涂满整个环。

**深刻结论**：
确定性系统有**周期轨道**，但随机系统没有周期分布。相反，分布收敛到一个**稳态分布**——一个"环形的概率云"。

> 🎯 **为什么？** 因为沿环方向的相位误差会累积。噪声不断给粒子"推"新的相位，最终所有相位都等概率出现。

## 6.3 有限马尔可夫决策过程（Finite MDP）

当状态和动作空间都是**有限**的，我们可以把主方程写成矩阵形式。

**转移概率**：
$$p(s' | s, a) = P(s[n+1] = s' \mid s[n] = s, a[n] = a)$$

**概率分布向量**：
$$\mathbf{b}[n], \quad \text{其中 } b_i[n] = p_s(s_i; n)$$

**转移矩阵**（对每个动作 $a$）：
$$T_{ij}(a) = p(s_i \mid s_j, a)$$

> 🏙️ **类比**：$T_{ij}$ 是"从城市 $j$ 迁到城市 $i$ 的概率"。矩阵的每一列（对应固定 $j$）之和为 1——因为所有人必须从某处迁出，概率总和是100%。

**动力学**：
$$\mathbf{b}[n+1] = \mathbf{T}(a[n]) \mathbf{b}[n]$$

### 6.3.1 马尔可夫链动力学

固定策略（无控制输入或策略固定）：
$$\mathbf{b}[n+1] = \mathbf{T} \mathbf{b}[n] \Rightarrow \mathbf{b}[n] = \mathbf{T}^n \mathbf{b}[0]$$

**随机矩阵的性质**：
- 所有特征值 $\lambda_i \in [0, 1]$
- **至少一个特征值 = 1**（对应稳态分布）
- 如果马尔可夫链是**不可约**（irreducible，任何状态都能到达任何状态）且**非周期**（aperiodic，不会陷入"只能在奇数步/偶数步到达"的循环），则稳态分布**唯一**，且从任何初态收敛。

> 🚇 **类比**：不可约 = 地铁网络连通（没有孤岛）；非周期 = 没有"只能隔一天到达"的奇怪规律。满足这两点，无论现在人口分布如何，最终都会稳定到一个固定分布。

### 例6.6：离散化带噪声的三次多项式

将例6.4的系统（$\dot{x} = -x + x^3$ + 噪声）的状态空间 $[-2, 2]$ 切成100个区间。

**构建转移矩阵**：
- 对每个区间 $j$，计算噪声作用下转移到各个区间 $i$ 的概率
- 得到 $100 \times 100$ 的随机矩阵 $\mathbf{T}$

**分析特征值**：
- 至少一个特征值为 1（稳态分布）
- 其他特征值的模 $< 1$（决定收敛速度）

```python
import numpy as np

# 离散化状态空间
N = 100
x_bins = np.linspace(-2, 2, N+1)
x_centers = (x_bins[:-1] + x_bins[1:]) / 2
dx = x_bins[1] - x_bins[0]

# 系统参数
h = 0.1
sigma = 1.5

# 构建转移矩阵 T[i,j] = 从状态j转移到状态i的概率
T = np.zeros((N, N))

for j, xj in enumerate(x_centers):
    # 确定性部分：x_next_det = xj + h*(-xj + xj**3)
    x_next_det = xj + h * (-xj + xj**3)
    
    # 噪声是高斯，标准差 sigma。计算转移到每个bin的概率
    # 积分高斯分布落在每个bin里的概率
    for i in range(N):
        # bin i 的范围 [x_bins[i], x_bins[i+1]]
        # 需要计算 P(x_next_det + w \in [x_bins[i], x_bins[i+1]])
        # 即 P(w \in [x_bins[i] - x_next_det, x_bins[i+1] - x_next_det])
        from scipy.stats import norm
        T[i, j] = norm.cdf(x_bins[i+1] - x_next_det, scale=sigma) - \
                  norm.cdf(x_bins[i] - x_next_det, scale=sigma)
    
    # 归一化（数值安全）
    T[:, j] /= T[:, j].sum()

# 检查随机矩阵性质
print(f"每列和: {T.sum(axis=0)}")  # 应该都是1

# 计算特征值
eigenvalues, eigenvectors = np.linalg.eig(T)
print(f"最大特征值: {np.max(np.real(eigenvalues))}")  # 应该接近1

# 稳态分布（对应特征值1的特征向量）
steady_state = np.real(eigenvectors[:, np.argmax(np.real(eigenvalues))])
steady_state = steady_state / steady_state.sum()  # 归一化

import matplotlib.pyplot as plt
plt.plot(x_centers, steady_state)
plt.xlabel('x')
plt.ylabel('Probability')
plt.title('Stationary Distribution (Discrete Approximation)')
plt.show()
```

> 🎯 **注意**：由于这个系统有泄漏（概率跑到无穷），严格来说在有限截断 $[-2,2]$ 内的"稳态分布"是近似的。你会看到概率质量集中在0附近，但边界处仍有非零概率（表示泄漏）。

## 6.4 扩展例子：粗糙地形上的无轮缘轮

还记得第四章的无轮缘轮吗？它在恒定斜坡上能走出稳定极限环。

现在让**地形随机化**：每步的斜坡角 $\gamma[n]$ 独立随机抽取（i.i.d.）。

> 🎲 **类比**：像下楼梯，但每级台阶高度随机——有的高有的低。你上一步的速度和当前台阶高度共同决定下一步的速度。

**顶点到顶点映射**（apex-to-apex，从一条腿竖直到下一条腿竖直）：

$$\dot{\theta}[n+1] = \sqrt{\cos^2\alpha\left(\dot{\theta}^2[n] + \frac{2g}{l}(1-\cos(\alpha+\gamma[n]))\right) - \frac{2g}{l}(1-\cos(\alpha-\gamma[n]))}$$

> 🎯 **关键变化**：$\gamma[n]$ 是随机变量，所以 $\dot{\theta}[n+1]$ 也是随机的。即使初始速度确定，下一步的速度也是概率分布。

这形成了一个**随机返回映射**。分析它的稳态分布可以告诉我们：在随机地形上，机器人最终的速度分布是什么？会不会有时太慢而停下来？会不会有时太快而摔倒？

## 6.5 接触动力学的随机平滑

这是本章最"实用"的部分，解释了为什么强化学习（RL）在接触丰富的机器人问题中表现得出奇地好。

### 硬接触的麻烦

机器人碰撞、抓取、行走都涉及**硬接触**（非穿透约束）。数学上：
$$q \geq 0 \quad \text{（不能穿过地面/墙壁）}$$

**例6.7：1D方块靠墙的确定性动力学**

墙在 $q \leq 0$。如果方块在 $q > 0$，它自由运动；如果噪声/力把它推到 $q < 0$，物理上不可能，必须"投影"回边界：

$$f(q) = \max(q, 0) = \begin{cases} q & \text{if } q \geq 0 \\ 0 & \text{otherwise} \end{cases}$$

> 🧱 **类比**：像一堵墙。你站在墙前（$q>0$），可以自由走动；但如果你试图穿墙（$q<0$），墙会把你推回 $q=0$。

这个函数在 $q=0$ 处**不可导**（尖角）。对基于梯度的优化是噩梦——梯度在 $q<0$ 时为0，在 $q>0$ 时为1，在 $q=0$ 处不存在。

### 加入噪声：神奇的平滑效果

现在每步先加高斯噪声，再投影：
$$q[n+1] = f(q[n] + w[n]) = \max(q[n] + w[n], 0)$$

**图6.12分析**：

**(b) 分布视角**：
- 从 $q_0 > 0$ 出发，加噪声后 $q_0 + w$ 是高斯分布（粉色钟形）
- 经过 $\max(\cdot, 0)$ 后，负值部分被"截断"并堆积在0处（绿色直方图在0处有一根尖刺）

**(c) 期望视角**：
- 绿线：$E_w[f(q + w)]$ —— 随机系统的期望下一步位置
- 黑线：$f(q)$ —— 确定性系统的下一步位置

**惊人发现**：绿线是**光滑的**！原来锋利的墙角被噪声"磨圆"了。

> 🧈 **类比**：确定性接触像黄油刚从冰箱拿出来——硬邦邦、有棱角。加入噪声像让黄油在室温下放一会儿——边缘融化变圆滑了。

**(d) 梯度视角**：
- 绿线：$E_w[\partial f/\partial q]$ —— 随机系统的期望梯度
- 黑线：$\partial f/\partial q$ —— 确定性系统的梯度（在0处跳变）

随机系统的梯度也是**光滑**的！

> 🎯 **这对优化意味着什么？**
> 
> 在确定性仿真中，接触点梯度是0或无穷，优化器"看不到"墙后面的信息。但在随机仿真中，期望梯度非零且光滑——优化器能"感知"到墙的存在，即使还没碰到它！这被称为**"远距离接触力"**。

### 为什么RL在接触问题中表现好？

RL算法通常在策略输出中**主动注入随机噪声**（探索）。当这种随机性遇上确定性接触仿真时，产生的动力学正好就是上述"平滑接触"的效果！

> 🎮 **类比**：确定性接触像玩"蒙眼摸墙"——你只有撞到墙才知道墙在哪。随机接触像"用喷雾喷墙"——雾碰到墙会反弹，你还没走到墙前，就看到雾被挡回来了。你提前感知到了墙的存在。

参考文献[3,4,5,6]进一步将这一思想用于：
- **Bundle Gradients**：通过随机平滑计算接触问题的梯度
- **全局规划**：用局部平滑的准动态接触模型做接触丰富的操作规划

## 6.6 真实噪声模型（简短提及）

- **传感器模型**：如概率机器人学中的**波束模型**（beam model），用于激光雷达/深度相机
- **RGB-D**：深度相机噪声不是简单高斯，存在缺失值、边缘噪声
- **域随机化（Domain Randomization）**：在仿真中随机化摩擦、质量、地形等参数，训练出的策略对真实环境更鲁棒

> 🎲 **类比**：域随机化就像让运动员在各种各样的场地上训练——草地、沙地、泥地——这样到了正式比赛，无论遇到什么场地都能适应。

## 总结：第六章教给我们的六件事

| 核心概念 | 通俗理解 | 实践意义 |
|---------|---------|---------|
| **主方程** | 概率密度的"人口迁移方程" | 即使轨迹混沌/随机，分布可能简单且可预测 |
| **稳态分布** | 聚拢与扩散的平衡 | 设计机器人时要考虑长期行为的统计规律，而非单条轨迹 |
| **双稳 vs 单稳泄漏** | 封闭山谷（有稳态）vs 缺口浴缸（无稳态） | 噪声过大时，原本稳定的系统可能"崩溃"（概率泄漏） |
| **极限环 + 噪声** | 环上墨水扩散 | 相位不确定性会累积，最终均匀覆盖整个周期轨道 |
| **随机矩阵/MDP** | 人口迁移的线性代数 | 有限状态系统的强大分析工具，特征值决定收敛 |
| **随机平滑接触** | 噪声把锋利的墙角磨圆 | 解释了为什么RL能在碰撞、抓取等接触问题中成功 |

## 给初学者的寄语

Tedrake教授在本章揭示了一个**反直觉的真理**：

> 当你加入噪声，单个轨迹变得不可预测，但**系统的统计规律却可能更简单、更稳定**。

**关键洞察**：
- **不要只盯着一条轨迹看**：在随机世界中，"系统最终在哪"是错误的问题；"系统在各处的概率是多少"才是正确的问题
- **稳态分布是新的"固定点"**：确定性系统的稳定性分析推广到随机系统，就是寻找主方程的不动点
- **噪声可以是朋友**：在接触问题中，适当的随机性反而让优化变得可行

> 🌟 **一句话记住这章**：随机性没有让问题更混乱——它只是把"确定性收敛"换成了"分布收敛"，而后者往往更强大、更通用。
