## 🎯 一、为什么需要运动规划？（章首动机）

Russ 指出三个核动因：

1. **环境变杂乱时，"手写脚本"不够用了**
   第5章那种"直接给夹爪写一段位姿轨迹"的办法，在简单场景能凑合。但环境一复杂，手臂可能和料箱、相机发生碰撞，必须自动化处理。

2. **移动操作（mobile manipulation）需要适应不同环境**
   如果机器人手臂装在移动底盘上，每次操作的环境都略有不同，哪怕工作空间几何不复杂，也需要自动（但可以比较简单）的规划。

3. **长时间重复的任务需要优化轨迹**
   如果机器人在简单已知环境里日复一日工作，那优化它执行的轨迹就很有意义——通常能显著加快操作速度。

> 💡 **Russ 的重要反思**：
> "尽管在机械操作的运动规划中，很多重点放在避免碰撞的问题上。尽管我自己在这个领域做过一些工作，我其实真的很不喜欢'无碰撞运动规划'这种问题表述。我认为总体而言，机器人太害怕碰到世界了（因为碰了之后事情还是会出错）。我不认为人类每次伸手时都在解决这些复杂的几何问题……即使是伸进密集杂乱中。我其实怀疑我们在这方面做得很差。我更愿意看到机器人即使在穿过杂乱环境时只用非常粗略/近似的计划也能表现良好，它们不害怕发生偶然接触，并且即使发生了也能完成任务！"

**生活类比**：你伸手去拿桌上的杯子时，并不会精确计算手臂每个关节的角度、确认不会碰到旁边的键盘——你大致一伸，偶尔蹭到键盘也无所谓，最终还是拿到了杯子。**Russ 认为机器人也应该这样"粗犷"一点**。但在这章，我们还是先从经典的"精确无碰撞规划"学起，打好基础。

## 🦾 二、逆运动学（6.1 INVERSE KINEMATICS）

### 2.1 逆向思维：从"夹爪位姿"反推"关节角"

正运动学是：$X^G = f_{kin}(q)$——给定关节角 $q$，算出夹爪位姿 $X^G$。

**逆运动学（IK）**则是反过来：给定想要的夹爪位姿 $X^G$，求关节角 $q$。

**生活类比**：正运动学就像"我知道方向盘打多少度、油门踩多深，就能算出车停在哪"；逆运动学则是"我想让车停到那个车位，方向盘该打多少、油门该踩多深？"

### 2.2 Russ 对 IK 的重新定义

Russ 强调：**IK 不只是求逆映射 $q = f_{kin}^{-1}(X^G)$，而是一个带丰富成本和约束的优化问题**。

为什么？因为：
- 6自由度机械臂求解6自由度位姿约束时，通常有多个（甚至无限个）解
- 7自由度机械臂更是如此——多出来的自由度可以用来优化其他目标
- 实际应用中我们几乎总是有关节空间的成本或约束（如关节限位）和笛卡尔空间的成本或约束（如不穿透约束）

**生活类比**：你要把手伸到桌上的杯子前——这个动作有无数种完成方式（手可以从左边绕、右边绕、上面伸、下面钻）。IK 就是要从所有这些可能性中，挑出"最舒服"的那一个。

### 2.3 解析解与 IKFast（6.1.1 From end-effector pose to joint angles）

有趣的数学事实：

> "前向运动学 $f_{kin}$ 通常是非线性函数，但它有非常特殊的结构。事实上，除了极少数例外（比如你的机器人有螺旋关节），支配机器人有效笛卡尔位置的方程组实际上是多项式。"

**为什么是多项式？** 因为刚体上两点间的距离平方 $\|p^A - p^B\|^2$ 是常数，关节就是相邻体上位置之间的多项式约束。

**生活类比**：虽然你看到的运动学方程里有 sin、cos，但那些三角函数出现在"关节角↔笛卡尔坐标"的转换里。如果我们用距离平方这种量，方程就变成多项式了。

**IKFast**：目前6/7自由度机械臂实时 IK 最流行的工具。它利用"6自由度位姿约束在6自由度机械臂上有封闭式解（有限个解）"这一事实，对"简单"运动学问题提供快速数值鲁棒的解。对7自由度机械臂，它在6自由度求解器之上加一层对最后一个自由度的采样。

> ⚠️ **IKFast 的局限**：它主要针对等式约束。一旦我们有不等式约束（如关节限位、碰撞避免），就需要转向优化方法。

### 2.4 IK 作为约束优化（6.1.2 IK as constrained optimization）

Russ 推荐的现代 IK 公式：

$$\min_{q} \quad |q - q_0|^2$$
$$\text{subject to} \quad X^G = f_{kin}(q)$$

其中 $q_0$ 是某个"舒适"的标称位置。

**这个公式的妙处**：
- 如果有多个关节角都能达到同一夹爪位姿，我们选离 $q_0$ 最近的那个
- 更重要的是，它允许我们接入丰富的成本和约束库

**与微分 IK 的关系**：

| 方法 | 特点 |
|---|---|
| **微分 IK** | 在当前 $q$ 附近求小变化 $\Delta q$，对非线性/非凸约束做线性/凸近似 |
| **完整 IK** | 直接求解非线性/非凸优化，不限制只能在初始 $q$ 附近小步移动 |

Russ 指出："你可以把微分 IK 算法看作是对完整非线性问题做一步（投影）梯度下降或一步序列二次规划（SQP）。"

**Drake 的 InverseKinematics 类**：提供了丰富的约束类型——
- 两个物体间的相对位置和/或方向约束
- 两个物体间的最小距离约束（用于非穿透）
- 等等

#### 🧪 实验重点：Example 6.1（Interactive IK）

Russ 提供了交互式 IK 演示：

**版本1**：用滑块控制夹爪目标位姿。这是 IK 的简单版本，但我们用完整的非线性优化 IK 引擎求解（包含关节限位约束）。这个演示和第3章最开始的"遥操作让机器人捡红砖"看起来差不多——其实微分 IK 也能很好解决这问题。

**版本2**：在机器人正前方加一个障碍物（柱子）。

**生活类比**：想象一堵墙把房间分成左右两半，你要从左侧够到右侧的东西。完整 IK 就像你能"意识到"可以绕到墙后面从右侧伸手；微分 IK 就像你紧贴着墙左侧试探，永远想不到绕过去的方案——因为它只敢做小步调整。

### 2.5 IK 建模的两个黄金建议

Russ 给出了实用建议：

1. **保持目标（成本）简单**：通常只用 $q$ 的"关节居中"二次成本。把本应是约束的项放进成本作为惩罚，会导致大量的成本函数调参——这是件讨厌的事。

2. **写最小的约束**：你希望可行配置的集合尽可能大。例如，如果你不需要完全约束夹爪的方向，那就不要约束它。

#### 🧪 实验重点：Example 6.2（Grasp the cylinder）

**场景**：用 IK 抓取一个圆柱（你可以把它想象成扶手）。

**关键洞察**：假设我们不在乎沿圆柱的哪里抓、也不在乎以什么方向抓。那我们应该**只用这些约束的最小版本**。

Russ 在 notebook 里把圆柱的位姿放在滑块上，你可以让它在工作空间里移动，观察 IK 求解器如何决定机器人的位置。

**神奇现象**：如果你在 ±y 方向移动圆柱，你会发现机器人**根本不试图跟随**……直到手到达圆柱的末端。非常优雅！

**生活类比**：就像你抓一根横杆——你不需要精确抓在杆的某个点，也不需要手以特定角度握上去。只要手能碰到杆，IK 会自动选最舒服的握法。这种"最小约束"让 IK 有更多自由度来找到好解。

### 2.7 全局逆运动学（6.1.3 Global inverse kinematics）

前面讲的 IK 是**局部优化**——可能陷入局部极小值，即使解存在也返回"不可行"。

**全局 IK** 的目标是：放弃交互式速率，争取**鲁棒地求解更丰富的 IK 公式，最好是全局最优**。

**应用场景**：
- 生成训练数据来训练神经网络学习你的 IK
- 工作空间分析——看机器人能否到达工作空间中的所有需要位置

**Drake 的实现**：`GlobalInverseKinematics` 类，使用**混合整数凸优化**（mixed-integer convex optimization）。求解时间在几秒量级；可以在一分钟内求解完整的双臂约束问题。

### 2.8 IK vs 微分 IK（6.1.4）

| 特性 | IK | 微分 IK |
|---|---|---|
| 问题规模 | 更全局 | 增量运动 |
| 成功率 | 不保证成功 | 对小步调整非常有效 |
| $\Delta q$ 大小 | 可能很大 | 小步调整 |
| 适用场景 | 需要全局解时 | 能在末端执行器空间设计平滑指令并跟踪 |

下一节的轨迹优化算法是产生实际 $q$ 轨迹的自然延伸。

### 2.9 用 IK 做抓取规划（6.1.5 Grasp planning using inverse kinematics）

第5章我们用采样做抓取选择时，加了一个奖励"从物体上方抓取"的目标。这是个（有时很差的）替代品——我们真正想解决的是：**这个抓取在给定的"舒适"机器人位置下是否可实现**。

**自然扩展**：
- 对抓取候选解 IK 问题
- 直接用关节居中成本作为目标（而不是在末端执行器方向上放成本）
- 如果 IK 返回不可行，拒绝这个样本

**TRI 洗碗项目的关键洞见**：

如果需要不仅在杂乱中拿起物体，还要在杂乱中小心放下物体，那么一个好的抓取涉及**相对于物体的手的位姿，同时优化拾取配置和放置配置**。

可以建立一个优化问题，决策变量同时包括 $q_{pick}$ 和 $q_{place}$，用约束强制 ${}^{O}X^{G_{pick}} = {}^{O}X^{G_{place}}$。当然还可以加入所有其他丰富的成本和约束。在 TRI 的装盘项目中，这种方法被证明非常重要——在水槽中捡起杯子和在洗碗机架上放置杯子都受到高度约束，所以我们需要同时优化来找到成功的抓取。

## 📈 三、运动学轨迹优化（6.2 KINEMATIC TRAJECTORY OPTIMIZATION）

### 3.1 从多个 IK 到一条轨迹

理解了 IK 的优化视角，就理解了轨迹优化的一大半。

基本思路：与其独立求解多个 IK 问题，不如**在单个优化中同时求解一系列关节角**。

更妙的是：定义一个参数化关节轨迹 $q_\alpha(t)$，其中 $\alpha$ 是参数向量。然后优化问题可以写成：

$$\min_{\alpha, T} \quad T$$
$$\text{subject to} \quad X^{G_{start}} = f_{kin}(q_\alpha(0)),$$
$$X^{G_{goal}} = f_{kin}(q_\alpha(T)),$$
$$\forall t, \quad |\dot{q}_\alpha(t)| \leq v_{max}.$$

翻译：找一条轨迹 $q_\alpha(t)$，$t \in [0, T]$，让夹爪从起点到终点以**最短时间**移动。

最后一个方程（速度限制）是我们告诉优化器"机器人不能瞬间从起点传送到终点"的唯一方式。除了这一行看起来有点不标准外，它几乎完全像联合求解两个 IK 问题——只不过我们不是对 $q$ 求梯度，而是用链式法则对 $\alpha$ 求梯度。

### 3.2 轨迹参数化：B 样条（6.2.1 Trajectory parameterizations）

**为什么用 B 样条？**

对于 Fully-actuated 机器人手臂的运动规划，我们通常较少担心动态可行性，而是专注于运动学。B 样条有几个特别好的性质：

1. **B 样条的微分仍是 B 样条**（阶数减一），系数对原始系数是线性的
2. **基函数本身非负且稀疏**。这使得 B 样条多项式的系数（称为**控制点**）具有很强的几何解释
3. **整个轨迹保证位于活动控制点的凸包内**（其基不为零的控制点）

**凸包性质的威力**：我们可以用线性约束优化有限参数化的轨迹，同时利用凸包性质确保关节位置及其任何导数的限制在 $\forall t \in [0, T]$ 上都得到满足。这种保证在大多数其他多项式基上要昂贵得多才能获得。

> 💡 **生活类比**：B 样条就像用几根"控制棍"来塑形一条橡皮筋。橡皮筋（轨迹）一定会待在控制棍（控制点）的"凸包"——大致就是这几根棍子围成的时空区域内。你移动控制棍，橡皮筋跟着变形，但永远不会跳出这个区域。这就让"轨迹始终不撞"的约束变得容易处理。

**注意**：B 样条和 Bézier 曲线密切相关，但"B"在 B 样条中代表"基"（basis），不是 Bézier。

### 6.2.2 优化算法

Drake 默认的 `KinematicTrajectoryOptimization` 类优化一条用 B 样条表示的轨迹：
- 路径 $r(s)$ 在区间 $s \in [0, 1]$ 上用 B 样条表示
- 额外一个标量决策变量对应轨迹持续时间 $T$
- 最终轨迹结合时间重参数化：$q(t) = r(t/T)$

这种表示方式特别适合表示未知持续时间的轨迹，并且具有凸包性质仍可利用的优秀特性。速度约束仍是线性的；加速度和更高导数的约束确实变成非线性的，但如果满足，仍意味着 $\forall t \in [0, T]$ 的严格界限。

由于 `KinematicTrajectoryOptimization` 是用 Drake 的 `MathematicalProgram` 编写的，默认情况下它会根据可用的求解器自动选择我们认为最好的求解器。如果优化只有凸成本和约束，它将被分派给凸优化求解器。但大多数情况下我们加入来自运动学的非凸成本和约束。因此在大多数情况下，默认求解器再次是 SQP 求解器 SNOPT。

我们可以在运动学轨迹优化问题中添加的最有趣的约束之一是 `MinimumDistanceLowerBoundConstraint`；当所有潜在碰撞对之间的最小距离大于零时，我们就避免了碰撞。但请注意，这些碰撞约束只能在离散样本 $s_i \in [0,1]$ 沿路径强制执行。它们不保证轨迹在 $\forall t \in [0,T]$ 上无碰撞。利用导数约束的非常特殊的属性来利用凸包性质是必要的；我们对更一般的非线性约束没有这些属性。一个常见的策略是：在优化期间沿区间在一些适度数量的样本上添加约束，然后在对机器人执行优化后的轨迹之前更密集地检查碰撞。

### 3.3 相关方法

文献中许多相关方法，区别在于参数化或求解技术（或两者）：
- **CHOMP**：梯度优化技术
- **STOMP**：随机轨迹优化
- **KOMO**：使用增广拉格朗日方法将约束优化问题转写为无约束问题

> ⚠️ **轨迹优化的阿喀琉斯之踵**：因为它们基于非凸优化，容易受到局部极小值的影响，即使存在可行路径也可能找不到。

#### 🧪 实验重点：Example 6.7（无碰撞轨迹优化中的局部极小值）

Russ 用了一个极简例子：点机器人在下图从起点（蓝圈）到终点（绿圈）的最短路径，避免与红框碰撞。

**数学形式**：
$$\min_{q_0,\ldots,q_N} \sum_{n=0}^{N-1} |q_{n+1} - q_n|_2^2$$
$$\text{subject to} \quad q_0 = q_{start}$$
$$q_N = q_{goal}$$
$$|q_n|_1 \geq 1 \quad \forall n$$

**两种解**：
- 左边的解是问题的（全局）最小值
- 右边的解明显是局部极小值

**为什么困在局部极小值？** 一旦非线性求解器在考虑绕过障碍右侧的路径，它非常不可能找到绕过左侧的路径，因为解必须先变差（违反碰撞约束）才能变好。

> 💡 **生活类比**：这就像你在迷宫里，一旦你选择了一条路往下走，就算这条路是死胡同，你要退回去换另一条路，必须先把"错误"走到底（撞墙）才能意识到要回头。这就是局部优化的宿命。

**应对之道**：运动规划领域严重倾向于**基于采样的方法**。

## 🔷 五、基于凸集图的运动规划（6.4 MOTION PLANNING W/ GRAPHS OF CONVEX SETS, GCS）

这是 Russ 团队的**王牌技术**，试图结合轨迹优化和采样规划的优点。

### 5.1 动机：两种方法的优缺点

| 方法 | 优点 | 缺点 |
|---|---|---|
| **轨迹优化** | 能表达丰富的成本/约束（包括连续曲线的导数约束），可扩展到高维配置空间 | 基于局部（基于梯度）优化，受困于局部极小值 |
| **采样规划** | 推理更全局，提供（概率）完备性概念 | 难以适应连续曲线的导数约束，在高维中挣扎 |

**GCS 的目标**：鱼与熊掌兼得。

### 5.2 核心思想：把点"膨胀"成凸区域

Russ 的关键洞察：

> "对 PRM 工作流程做一个相对小的改变是这样的：每次我们选择一个样本时，不仅仅把配置空间点添加到图中，让我们将这个点扩展为配置空间中的一个（凸）区域。"

**为什么这样做？**

1. **离线计算投资，在线收益巨大**：我们乐意支付一些离线计算来寻找漂亮的大区域
2. **图可以更稀疏**：少量区域可以覆盖配置空间的很大一部分，这也允许我们扩展到更高维度
3. **在线优化灵活性**：只要连续曲线停留在凸区域内，我们现在可以灵活地在线优化连续曲线

这需要推广图搜索算法，以联合优化通过图的离散路径和连续曲线的参数；这正是 GCS 提供的推广。

### 5.3 GCS 框架（6.4.1 Graphs of Convex Sets）

GCS 框架最初在[13]中引入，我们在 Drake 中有一个成熟的实现。它是结合组合优化（如图搜索）和连续优化（如上面研究的运动学轨迹优化）的一般优化框架。

**经典图最短路径的 GCS 推广**：

在 GCS 中，每当我们访问图中的一个顶点时，我们也允许从该顶点关联的凸集中选择一个元素。边长度可以是相应集中连续变量的凸函数，我们还可以在边上写凸约束（任何解决方案路径都必须满足）。

**计算特性**：
- 凸集图上的最短路径问题可以编码为 NP-Hard 的问题，但可以表述为混合整数凸优化（MICP）
- 这个 MICP 有一个非常强且高效的凸松弛；这意味着如果你把二进制变量松弛为连续变量，你会得到（几乎）原始 MICP 的解
- 这意味着你可以比以前的转写方法快几个数量级地求解 GCS 问题到全局最优
- 但在实践中，我们发现只求解凸松弛（加上一点舍入）几乎总是足以恢复最优解。如今，在我们的 GCS 机器人应用里，我们几乎从不求解完整的 MICP。

### 5.4 GCS 运动学轨迹优化（6.4.2 GCS (Kinematic) Trajectory Optimization）

**核心问题**：如何把运动规划问题转写为 GCS？

**假设**：我们给定一个无碰撞空间的凸分解。这是一个强假设，我们下面会证明其合理性。

**关键观察**：如果我们在同一个凸无碰撞区域中有两个点，那么我们知道连接它们的直线也保证是无碰撞的。当点位于两个 C 空间区域的交集中时，它们可以通过多个区域连接连续路径。

**转写方法**：
- GCS 中的凸集**不是** C 空间区域本身
- 它们是具有 2n 个变量的集合（对于 n 维配置空间），其中前 n 个和后 n 个都在 C 空间区域内
- 用集合符号说，它是集合与自身的笛卡尔积
- 这些集合之间形成无向边，当且仅当 C 空间区域相交
- 在每条边上放置约束，说明第一个集合中的第二个点必须等于第二个集合中的第一个点

2. 运行最小时间目标（带速度约束）

#### 进一步推广：高阶 Bézier 曲线

我们可以用 Bézier 曲线的凸包性质保证固定阶次的整个连续路径都位于集合内。利用 Bézier 曲线的导数性质，我们可以添加速度的凸约束（例如速度限制），并保证曲线在区域之间的交叉点处也是平滑的。

为了定义这些速度，我们需要知道遍历路径的速率的一些信息，所以我们还引入了时间缩放参数化，就像我们在上面的运动学轨迹优化中所做的那样，在每个凸集中带有时间缩放参数。

**结果**：一个相当丰富的轨迹优化框架，编码了我们希望用于 GCS 凸优化框架中的轨迹优化的许多（但诚然不是全部）成本和约束。例如，我们可以写目标包括：
- 时间（轨迹持续时间）
- 路径长度（用上界近似）
- 路径"能量"的上界（例如 $\int|\dot{q}(t)|_2^2$）

约束包括：
- 路径导数连续性（到任意阶）
- 速度约束（对所有 t 严格执行，而不仅仅在采样点）
- 额外的凸位置和/或路径导数约束，如初始和最终位置和速度

我们自动施加路径连续性约束，以及区域约束（整个轨迹停留在 C 空间区域的并集中），这些约束保证在所有 t 上都成立，而不仅仅在采样点上。

## 🔬 六、无碰撞配置空间的凸分解（6.4.3 Convex decomposition of (collision-free) configuration space）

### 6.1 如何获得无碰撞配置空间的凸分解？

**起点**：认真采纳与 PRM 的类比。如果我们在配置空间中采样一个无碰撞点，那么将这个点膨胀成凸区域的正确方法是什么？

**简单情况**：在处理凸几何时答案更简单。在我看来，用欧几里得空间 $R^3$ 中的凸形状来近似机器人的几何是合理的。即使许多机器人（如 iiwa）具有非凸网格几何，我们经常可以将它们很好地近似为更简单凸几何的并；有时这些是圆柱体和球体等基元，或者我们可以直接在网格上执行凸分解。但即使几何在欧几里得空间中是凸的，在配置空间中将其视为凸的通常也是不合理的。

**例外情况**：
- 如果你的配置空间只涉及平移
- 或者如果你的机器人几何对旋转是不变的（例如点机器人或球形机器人）

那么配置空间仍然是凸的；这是将配置空间概念确立为机器人学中核心数学对象的第一个关键观察[18]。这可以用于移动机器人（即使是近似为球体的四旋翼）。在这种情况下，可以轻松计算采样点处任何凸体对之间的最小欧几里得距离，例如，将该点膨胀为适当半径的球体[19]。为了找到更大的区域，我们重度使用了在[20]中引入并在 Drake 中实现的**通过半定规划的迭代区域膨胀（IRIS）算法**。该算法在寻找分离超平面和寻找最大体积的内接椭圆以"膨胀"区域之间交替，以局部最大化区域的（有效的）体积近似。

### 6.2 将 IRIS 扩展到一般（非凸）配置空间

可以通过两种方式扩展 IRIS 算法以在更一般的（非凸）配置空间中找到大凸区域：

**方法1：IRIS-NP（非线性规划）**
在 IRIS-NP 算法[21]（在 Drake 中实现）中，我们用 SNOPT 等非线性优化求解器替换寻找最近碰撞的凸优化。我们随机采样潜在碰撞以使算法在概率上可靠；在实践中这个算法相对快，但不保证区域完全无碰撞。最近我们通过 IRIS-NP2[22]显著提高了这个流水线的性能，它创建更大的区域，比原始 IRIS-NP 快几个数量级。

**方法2：IRIS-ZO（零阶优化）**
通过在 IRIS-NP 中用零阶优化（不需要梯度；仅使用样本）替换非线性优化，IRIS-ZO 产生稍小的区域，但可以平凡地并行化[22]。

**方法3：代数运动学 + 平方和（SOS）优化**
利用大多数机器人的运动学可以用（有理）多项式表达的思想，我们可以使用多项式优化工具来搜索非碰撞的严格证书[23]（在 Drake 中实现）。这种方法往往较慢，但结果是严格的。我们在这里必须做出的一个牺牲是，我们在原始空间的球极投影坐标中寻找凸区域。在实践中，这代表了坐标系统的轻微扭曲（以及随之而来的轨迹长度）。

## 🚀 七、GCS 轨迹优化的变体和扩展（6.4.5 Variations and Extensions）

Russ 简要列出了正在发展的方向：

1. **快速路径规划（FPP）[25]**：许多运动规划实例不需要 GCS 的全部能力；启发式近似通常可以找到非常好的解。FPP 不是求解完整的 GCS 问题（同时考虑离散和连续变量），而是在离散和连续问题之间交替以找到局部极小值。FPP（通常）比 GcsTrajectoryOptimization 更快，并且通过使用交替，它可以处理 GcsTrajectoryOptimization 无法处理的导数约束（例如加速度约束）。但 FPP 在它可以支持的凸集/约束类别上更受限制。

4. **通过接触规划**：令人惊讶的是，我们现在有用于带接触的类静态操作的紧密凸松弛[28]

5. **不确定性下的规划**（即将到来！）

6. **任务和运动规划**（即将到来！）[29]展示了从时序逻辑到 GCS 的自然转写

## ⏱️ 八、时间最优路径参数化（6.5 TIME-OPTIMAL PATH PARAMETERIZATIONS）

### 8.1 问题

一旦我们有了运动计划，一个自然的问题是：**在速度、加速度和扭矩限制约束下，我们执行该计划的最快速度是多少？**

### 8.2 参数化方法

再次定义在区间 $t \in [t_0, t_f]$ 上的轨迹 $q(t)$，通过路径参数化 $r(s)$ 和时间参数化 $s(t)$：

$$q(t) = r(s(t)), \text{ 其中 } s(t) \in [0,1], s(t_0)=0, s(t_f)=1$$

我们约束 $\forall t \in [t_0, t_f], \dot{s}(t) > 0$，以便从 s 到 t 的逆映射始终存在。

**优势**：当 $r(s)$ 固定时，我们可能想放在 $q(t)$ 上的许多目标和约束实际上是 $s(t)$ 导数的凸函数。

**链式法则**：
$$\dot{q} = r'(s)\dot{s}$$
$$\ddot{q}(t) = r''(s)\dot{s}^2 + r'(s)\ddot{s}$$

**关键代入操作方程**：
$$u(s) = m(s)\ddot{s} + c(s)\dot{s}^2 + \bar{\tau}_g(s)$$

其中 $u(s)$ 是在缩放时间 $s(t)$ 时的指令扭矩。

### 8.3 变量替换：$b(s(t)) = \dot{s}^2(t)$

注意到 $b'(s) = 2\ddot{s}$。

我们可以用参数化轨迹表示 $b(s)$ 在 $s \in [0,1]$ 上。然后在采样时间点 $s_i = s(t_i)$ 处，我们可以将一组极其有用的成本和约束写成 $b(s)$ 的凸函数：

**1. 单调性约束**：
$$b(s_i) \geq \epsilon \Rightarrow \dot{s}(t_i) > 0$$

**2. 速度限制是包围盒约束**：
$$\forall j, \dot{q}_{min,j}^2 \leq r_j'(s_i)^2 b(s_i) \leq \dot{q}_{max,j}^2 \Rightarrow \dot{q}_{min} \leq \dot{q}(t_i) \leq \dot{q}_{max}$$

**3. 加速度限制是线性约束**：
$$\ddot{q}_{min} \leq r''(s_i)b(s_i) + \frac{1}{2}r'(s_i)b'(s_i) \leq \ddot{q}_{max} \Rightarrow \ddot{q}_{min} \leq \ddot{q}(t_i) \leq \ddot{q}_{max}$$

**4. 扭矩限制是线性约束**：
$$u_{min} \leq \frac{1}{2}m(s_i)b'(s_i) + c(s_i)b(s_i) + \bar{\tau}_g(s_i) \leq u_{max} \Rightarrow u_{min} \leq u(t_i) \leq u_{max}$$

**5. 最小化时间持续时间是凸目标**：
$$t_f - t_0 = \int_{t_0}^{t_f} 1 dt = \int_0^1 \frac{1}{\sqrt{b(s)}} ds$$

虽然这看起来非凸，但可以用……来写（原文在此省略，但 Drake 的 `PathParameterizedTrajectory` 类实现了这一功能）。

**实践中的妥协**：虽然我们希望有限数量的约束足以暗示这些约束在整个时间间隔 $[t_0, t_f]$ 上成立，但实际上，我们只在足够大量的采样时间强制执行约束，放弃严格保证。

> 📚 **历史背景**：这些时间最优路径参数化（TOPP）在 1980 年代被广泛研究[30]，有专门算法尝试揭示 bang-bang 轨迹的所有切换时间。[31, 32, 33] 做出了这里描述的与凸优化的联系。[34] 制作了一个名为 TOPPRA（基于可达性分析的时间最优路径参数化）的流行数值实现。我们在[16]中大量使用这些思想（并详细阐述了与 Bézier 曲线参数化的联系）。

**常见问题**：TOPP 是否可用于写对轨迹 jerk（或更高导数）的凸约束？[32] 解决了这个问题的某个版本。

### Exercise 6.3（Improving RRT Path Quality）
由于生成节点的随机过程，RRT 输出的路径通常看起来有些生涩（"RRT 舞蹈"是许多机器人学家的 Favorite 舞蹈动作）。有许多策略可以改善路径质量，在这个问题中我们将探索两种。

**a. Shortcutting（捷径化）**：
一种改善路径质量的策略是通过"捷径化"对路径进行后处理，它尝试用更短的段替换现有的路径部分[35]。这通常用以下算法实现：
1) 沿路径随机选择两个非连续节点
2) 尝试用 RRT 的 extend 算子连接它们
3) 如果得到的路径更好，用新的、更好的路径替换现有路径
步骤 1-3 重复直到终止条件（通常是有限步数或时间）

对于给定的图（RRT 找到了从 $q_{start}$ 到 $q_{goal}$ 的相当生涩的路径，有障碍物（红色显示），$q_{start}$ 和 $q_{goal}$ 用蓝色高亮），**命名一对节点，捷径化算法将导致更短路径**（即沿我们当前解决方案路径的两个节点，如果我们直接连接它们可以产生更短路径）。你应该假设距离度量是 2D 欧几里得距离。

**b. RRT* 的 rewiring 思想**：
标准 RRT 在将 $q_{new}$ 添加到树时，其父节点是 $q_{near}$。但如果我们想让树编码从起始节点到树中每个节点的最短路径，$q_{new}$ 的父节点应该是谁？

这个动态"rewiring"以发现最小成本路径（对我们来说是最短距离）的思想是 RRT 的渐近最优变体（称为 RRT*[36]）的关键方面。**当样本数量趋于无穷时，RRT* 找到通往目标的最优路径！** 这与"普通" RRT 不同，后者被证明是次优的（这个证明直觉是 RRT"困住"了自己，因为它在搜索时找不到更好的路径）。

**生活类比**：普通 RRT 就像你随机探索城市街道，第一次从家到公司找到一条路就满足了，即使这条路绕远。RRT* 则是持续探索，每次发现更短的路就更新——最终（探索足够久后）会收敛到真正最短的路径。
