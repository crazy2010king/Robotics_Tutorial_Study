## 1. 对应 C.1：优化软件 —— "为什么别自己造轮子"

### 1.1 逐句翻译

> 有些优化算法**简单到自己能实现**——随机梯度下降（SGD）是经典例子。更多算法**概念上相当简单**，但**实现细节至关重要**——**专家实现 vs 新手实现，在速度和/或鲁棒性上的差异可以是戏剧性的**。这些软件包常用一堆技巧做**数值条件化**、**丢弃平凡有效的约束**、**在多次求解之间 warm-start（热启动）**。**不是所有求解器支持所有类型的目标和约束**；即使两个商业求解器都声称能解 QP，它们在**你问题的特定结构/条件**上表现也可能不同。有时我们也有**设计良好的开源替代**（常由优化专家学者编写）——有时它们在特定问题类型上能与商业求解器竞争甚至胜出。

> 因此也有一批软件包，试图在**数学规划的表述**和**该问题在每个具体求解器里的实例化**之间提供**一层抽象**。著名的有 MATLAB 的 **CVX、YALMIP**，Julia 的 **JuMP**。**Drake 的 `MathematicalProgram` 类就是 C++/Python 的这样一层中间层**；它的创建**最初且专门**是为了支持本书用到的优化表述。

> Drake 有一系列数学规划教程，从通用介绍开始。Drake 支持多种**自研、开源、商业**求解器（**甚至部分商业求解器对学术用户免费**）。

**类比（中间层 = "万能翻译官"，必懂）**：
- 你想说"我要解一个 QP"，但底下有十几个求解器（Gurobi、Mosek、OSQP、SCS……），**每个的"方言"（输入格式）都不一样**。
- **CVX / JuMP / Drake 的 `MathematicalProgram`** = **一个翻译官**：你用**一种统一语言**写"最小化 X，满足 Y"，**它自动翻译成你指定的求解器听得懂的方言**。
- **为什么别自己写求解器**？因为专家在里头塞了**几十年的" tricks "**——**热启动**（上次解的答案当这次的初猜，省一大半时间）、**丢掉"显然成立"的约束**（别浪费算力检查"太阳从东边升起"）、**数值条件化**（把"病态"的方程调理成"健康"的）。**自己写 = 重新发明这些 trick，且通常写得差**。

**人话**：**这一节的核心劝告 = "当消费者，别当制造商"**。用 `MathematicalProgram` 写问题，让 Drake 帮你挑求解器。**但**——作者也提醒——**别把它当纯黑盒**：懂一点"盖下面"的事，能帮你**调参数、选求解器、看出为什么慢**。

## 2. 对应 C.2：通用概念 —— "优化问题长什么样"

### 2.1 通用表述 + 它的局限

> 通用表述是……（**PDF 此处公式未印出**；标准形式见 C.4：$\min_z c(z)$ s.t. $\phi(z)\le 0$，下面会讲）。

> **重要**：即使这个表述**极其通用**，它**也有局限**。举一个例子：写机器人轨迹优化时，在这个表述里我们**通常要先验选定**编码解的**决策变量个数**。虽然当然可以写"改变变量数再调用优化器"的算法，但作者觉得这个"通用"表述**没能捕捉**例如 **sample-based optimization planning（基于采样的优化规划）** 里发生的那种数学规划——**那里的解可由任意有限个参数描述，且计算在它们之间灵活转换**。

**类比（"先定格子数"的局限，必懂）**：
- 通用表述像"**先画好 100 个格子，再在格子里填答案**"——**格子数先定死了**。
- 但基于采样的规划像"**答案需要几个点描述，就用几个点，边算边加减点**"——**更灵活**。
- **通用表述的"通用"是假的通用**——**它假定了"变量个数固定"**，而有些问题天然不该固定。

### 2.2 对应 C.2.1：凸 vs 非凸 —— "碗 vs 丘陵"，以及"过参数化的魔法"

> **局部最优。凸函数，凸约束。**

> 如果一个优化问题**非凸**，**不一定意味着它难**。**深度学习里有很多情况，我们能可靠地解看似非常高维、非凸的优化问题**。我们对这些现象的理解在快速演化，作者怀疑他写的任何东西很快会过时。但**当前监督学习的主流思想**主要围绕 **over-parameterization（过参数化）**——**许多成功故事发生在一个 regime：决策变量比数据还多**，**搜索空间里"能完美拟合数据的解"实际上是稠密的**（所谓 **interpolating solutions，插值解**），**并非所有全局最小都同样鲁棒**，**优化算法在做某种隐式正则化**，以挑出一个"好的"插值解。

**类比（碗 vs 丘陵，必懂）**：
- **凸** = **一个碗**：任何"局部最低"就是"全局最低"，**闭眼滚到底**，**好解**。
- **非凸** = **丘陵**：有很多洼地，**滚到哪个洼地看运气**，**难**。
- **但深度学习的"反直觉"** = **当丘陵的维度高到离谱、且"变量比数据多"时，"能完美拟合的洼地"多到连成一片"平地"**——**随便滚都能找到一个"完美拟合"的解**，**难的不是"找拟合"，而是"在这些完美解里挑一个泛化好的"**——**而梯度下降这个"滚"的过程本身，悄悄在做"挑好的"（隐式正则化）**。

**人话**：**这是当下深度学习"为什么 work"的主流解释之一**——**不是"非凸变凸了"，而是"非凸的坑多到连成海，反而好游了"，真正的难题变成了"在海里挑一个好岛"**。

### 2.3 对应 C.2.2：拉格朗日乘子 —— "把围栏变成罚款"

> 给定**等式约束**优化问题 $\min_z \ell(z)$ s.t. $\phi(z)=0$，其中 $\phi$ 是向量。定义**拉格朗日乘子向量** $\lambda$（与 $\phi$ 同大小），及**标量拉格朗日函数**：

$$\mathcal{L}(z,\lambda) = \ell(z) + \lambda^T \phi(z)$$

> $z^*$ 为约束优化最优的**必要条件**是 $\mathcal{L}$ 对 $z$ 和 $\lambda$ 的梯度都为零：$\frac{\partial \mathcal{L}}{\partial z}=0,\ \frac{\partial \mathcal{L}}{\partial \lambda}=0$。

> 注意 $\frac{\partial \mathcal{L}}{\partial \lambda}=\phi(z)$，**所以要求它为零，等价于要求约束被满足**。

**类比（围栏变罚款 / 影子价格，必懂，这是拉格朗日乘子的灵魂）**：
- **等式约束 $\phi(z)=0$** = "**你必须站在围栏线上**"。
- **拉格朗日乘子 $\lambda$** = **围栏的"罚款单价"**。
- **拉格朗日函数 $\mathcal{L}=\ell+\lambda^T\phi$** = "**真实代价 + 罚款**"。
- **求 $\frac{\partial \mathcal{L}}{\partial z}=0$** = "**在'含罚款的总代价'里找最低点**"——**这时你不用管围栏了，因为"想离开围栏"会被罚款拉回来**。
- **求 $\frac{\partial \mathcal{L}}{\partial \lambda}=0$** = "**让罚款生效 = 逼你站回围栏线**"（$\phi(z)=0$）。
- **$\lambda$ 的大小** = "**这条围栏有多'贵'/"影子价格"**——**$\lambda$ 大 = 这条约束"卡得很紧"，放松一点目标就改善很多**。

**人话**：**拉格朗日乘子法的精髓 = "把'硬约束'（必须满足）软化成'罚款'，于是带围栏的问题变成无围栏问题，但罚单价 $\lambda$ 自动调到'刚好让你乖乖站线上'"。** 这把"难处理的约束"变成了"多几个变量 $\lambda$ 的无约束问题"。

#### Example C.1（单位圆上的优化）—— 亲手走一遍

> 考虑 $\min_{x,y} x+y$ s.t. $x^2+y^2=1$。$x+y$ 的等高线是**斜率 $-1$ 的直线**，约束要求解在**单位圆**上。

> **肉眼**就能看出最优解应是 $x=y=-\frac{\sqrt{2}}{2}$（圆上最"左下"的点）。用拉格朗日乘子验证：

$$\mathcal{L} = x+y+\lambda(x^2+y^2-1)$$

$$\frac{\partial \mathcal{L}}{\partial x}=1+2\lambda x=0 \Rightarrow \lambda=-\frac{1}{2x}$$
$$\frac{\partial \mathcal{L}}{\partial y}=1+2\lambda y=1-\frac{y}{x}=0 \Rightarrow y=x$$
$$\frac{\partial \mathcal{L}}{\partial \lambda}=x^2+y^2-1=2x^2-1=0 \Rightarrow x=\pm\frac{1}{\sqrt{2}}$$

> 两个解里，**负的那个显然是目标的最小化者**。

**人话**：**$y=x$ 说明最优解在"45° 线"上**（目标等高线斜率 $-1$，与圆相切处法线斜率 $1$）；**$x=\pm 1/\sqrt2$ 是这条线与圆的两个交点**；**取负的 = 最小化 $x+y$**。**拉格朗日乘子法 = "找等高线与围栏相切的点"**——**几何上，最优处目标的梯度与约束的梯度平行，$\lambda$ 就是那个比例**。

### 🧪 代码 1：拉格朗日乘子法 —— 单位圆（可跑，对照 Example C.1）

> 用 scipy 直接解带等式约束的优化，**验证解析解 $x=y=-1/\sqrt2$**，并打印拉格朗日乘子 $\lambda$（影子价格）。

```python
import numpy as np
from scipy.optimize import minimize
# min x+y  s.t. x^2+y^2=1
res = minimize(lambda z: z[0]+z[1], [0.5,0.5],
               constraints={'type':'eq','fun':lambda z: z[0]**2+z[1]**2-1})
x, y = res.x
print("数值解 x=%.4f y=%.4f  (解析 -1/√2=%.4f)" % (x, y, -1/np.sqrt(2)))
print("目标值 x+y=%.4f  (解析 -√2=%.4f)" % (x+y, -np.sqrt(2)))
# 影子价格 λ: 由 1+2λx=0 反推
lam = -1/(2*x)
print("拉格朗日乘子 λ≈%.4f  (围栏'贵'的程度)" % lam)
```

**你会看到**：数值解精确等于 $-1/\sqrt2\approx-0.7071$，目标 $-\sqrt2\approx-1.4142$，**与解析一致**。**$\lambda$ 就是"把圆半径放松一点，目标能改善多少"的影子价格**。

## 3. 对应 C.3：凸优化 —— "碗状问题的全家桶"

### 3.1 对应 C.3.1：LP / QP / SOCP —— "三类最好解的碗"

> **Linear Programs / Quadratic Programs / Second-Order Cones**。**Example: Balancing force control on Atlas**（**PDF 此处只列标题，未展开**）。

**补充概念（三类"好碗"，必懂）**：
- **LP（线性规划）** = **目标线性 + 约束线性** = **一个"斜碗被几面平墙切"**，**最优解总在墙角（顶点）**，**极快**。
- **QP（二次规划）** = **目标二次（碗底是抛物面）+ 约束线性** = **一个抛物碗被平墙切**，**也快**，**LQR、MPC 的底层就是它**。
- **SOCP（二阶锥规划）** = **约束是"圆锥形"**（如 $\|Ax+b\|\le c^Tx+d$，"一个锥里"），**能表达"范数/长度"约束**，**比 LP 强、仍快**。

**类比**：**LP = 平底锅，QP = 圆底炒锅，SOCP = 锥形漏斗**——**都是"规则形状"，求解器有专门快算法**。

**补充（Atlas 平衡力控制）**：**人形机器人 Atlas 双脚踩地，地面给一堆接触力，要在"力在摩擦锥内（SOCP 约束）+ 力平衡（线性等式）"下，选一组力让身体稳住**——**这正是一个 SOCP/QP**。**这就是 C.3.1 那个例子的内容**（PDF 没展开，但全书第 5 章 ZMP、第 13 章 TubeMPC 反复用到这个"接触力 = QP/SOCP"的套路）。

### 3.2 对应 C.3.2：SDP 与 LMI —— "把'矩阵正定'当约束"

> **Semidefinite Programming and Linear Matrix Inequalities**。

> **脚注 †**：注意这个特定 SDP 约束**简单到本可以用二阶锥约束写**。

**补充概念（SDP / LMI 是什么，必懂）**：
- **LMI（线性矩阵不等式）** = **约束形如 $F_0+\sum x_i F_i \succeq 0$**（一个矩阵"半正定"，即所有特征值 $\ge 0$）。
- **SDP（半正定规划）** = **目标线性 + 约束是 LMI**。
- **它 generalize 了 LP/QP/SOCP**——**"标量 $\ge 0$" 是 "$1\times1$ 矩阵半正定"的特例**。
- **为什么有用**？因为**"Lyapunov 函数正定"、"系统稳定"、"协方差正定"** 这些控制里的核心条件，**天然就是 LMI**——**所以第 9 章 Lyapunov、第 8 章 LQR 的凸优化版，全落在 SDP 里**。

**类比（SDP = "要求一整张表'不亏'"，必懂）**：
- 标量约束 $x\ge0$ = "**一个账户不亏**"。
- 矩阵约束 $X\succeq0$ = "**一整张资产负债表，任何'组合投资'都不亏**"——**比"每个账户不亏"强得多**（**它要求所有方向都不亏**）。

#### SDP 松弛一般二次优化 —— "把弯月亮用圆盘包起来"

> SDP **最强大的用途之一** = **写更一般的非凸优化问题的凸松弛**。一个特别有用的例子是**一般二次优化**，写成：

$$\min_x\ x^TQx\quad\text{s.t.}\quad x^TA_ix\ge0,\ Bx\ge0,\quad x=\begin{bmatrix}y\\1\end{bmatrix}$$

> 下面**不对 $Q$ 或 $A_i$ 做 PSD 假设**。例如**二次等式约束** $x^TAx=0$（**一般非凸**）可用**两个约束**编码：$x^TAx\ge0$ 和 $-x^TAx\ge0$。**SDP 松弛** [3,4] 为：

$$\min_X\ \operatorname{tr}(QX)\quad\text{s.t.}\quad e_1^TXe_1=1,\ \operatorname{tr}(A_iX)\ge0,\ BXe_1\ge0,\ BXB^T\ge0,\ X\succeq0$$

> 其中 $e_1$ 是首元素为 1、其余为 0 的向量。

**类比（lift = "把弯的拉直"，必懂，这是 SDP 松弛的灵魂）**：
- 原问题里有 $x^TQx$ 这种"**变量的平方/乘积**"——**这是非凸的根源**（$x_1x_2$ 是马鞍面）。
- **松弛的 trick** = **引入一个新矩阵 $X$，假装 $X=xx^T$**。于是 $x^TQx=\operatorname{tr}(Qxx^T)=\operatorname{tr}(QX)$——**平方项变成了 $X$ 的线性函数！**
- **但 $X=xx^T$ 这个约束本身非凸**（秩 1 约束）——**松弛 = 把它放松成 $X\succeq0$**（**只要求 $X$ "像个 $xx^T$"，不要求秩 1**）。
- **结果**：**非凸问题变成了一个 SDP（凸）**——**"弯月亮"被"圆盘"包住了**。
- **$e_1^TXe_1=1$** = **强制 $X$ 的左上角 $=1$**（**因为 $x$ 的最后一个分量是 1，$xx^T$ 左上角 $=1$**）。

**人话**：**SDP 松弛 = "把'变量的乘积'提升成一个新矩阵变量 $X$，于是非凸变线性；再把' $X$ 必须是秩 1'这个难约束，放松成' $X$ 半正定'这个凸约束"。** 代价是**解可能"松"**（$X$ 不是真 $xx^T$，得回不到原 $x$）；**好处是"凸，能解"**。**当松弛"紧"（tight）时，$X$ 恰好秩 1，能精确还原原解**——**这是下面例子的看点**。

#### Example C.2（非凸二次约束的 SDP 松弛）

> 考虑 $\min_x \|x-a\|^2$ s.t. $\|x-b\|^2\ge1$（**标量 $x$**）。非凸，但可用 SDP 松弛写：引入 $y\ge x^2$，写成

$$\min_{x,y}\ y-2ax+a^2\quad\text{s.t.}\ y-2bx+b^2\ge1,\quad y\ge x^2$$

> 其中 $y\ge x^2$ 写成 SDP 约束 $\begin{bmatrix}y & x\\ x & 1\end{bmatrix}\succeq0$（**Schur 补**）。

> **Figure C.2** 画了 $a=.8,b=.5$ 的景观：可行域是 $y=x^2$ 的**上方图（epigraph）** 与线性约束的交。**关键点**：对**线性目标**，最优解**几乎从不会**在线性约束上 active，**除非在可行集顶点**。**本例中，约束只在 $a=b$ 时 inactive**；**对所有其他目标，这个松弛给出 $y=x^2$，给出原问题最优解**。注意本可写二次等式约束。

**类比（Schur 补 = "把' $y\ge x^2$' 翻译成矩阵正定"，必懂）**：
- $y\ge x^2$ 是**非凸**的（抛物线上方）。
- 但 $\begin{bmatrix}y&x\\x&1\end{bmatrix}\succeq0 \iff y\cdot1-x^2\ge0 \iff y\ge x^2$（**这就是 Schur 补**：$2\times2$ 矩阵正定 $\iff$ 对角块正定且 Schur 补 $\ge0$）。
- **于是"非凸的抛物线约束"被"凸的矩阵正定约束"精确等价表示**——**这里没松，是精确的！**（**因为 $y$ 是新变量，目标会逼 $y$ 尽量小，正好压到 $x^2$**）。

**人话**：**Schur 补是"把'平方/范数约束'塞进 SDP 的万能胶水"**——**全书的 SDP 表述几乎都靠它**。

#### Example C.3（单位圆的 SDP 松弛）—— 看"紧 vs 松"

> 另一个有用例子：$\min_x\ x^TAx+b^Tx$ s.t. $x^Tx=1$。非凸，但 SDP 松弛为：

$$\min_{Y,x}\ \operatorname{tr}(AY)+b^Tx\quad\text{s.t.}\quad \operatorname{tr}(Y)=1,\ Y\succeq xx^T$$

> PSD 约束用 Schur 补写。对 $x\in\mathbb{R}^2$，$Y_{11}\ge x_1^2,\ Y_{22}\ge x_2^2$；结合迹约束得 $Y_{22}=1-Y_{11}\ge x_2^2\Rightarrow 1-x_2^2\ge Y_{11}\ge x_1^2\Rightarrow 1\ge x_1^2+x_2^2$。

> 给定线性目标，期望最优解无界或在某约束上 active。**当最优解唯一时，优化会得到 PSD 约束的秩一解**（$Y=xx^T$ 秩一，Schur 补矩阵也秩一），**意味着 $x^Tx=1$**。**当凸松弛给出原问题最优解时，称凸松弛"tight"（紧）**。

> 对比**更简单的松弛** $\min_x\ x^TAx+b^Tx$ s.t. $x^Tx\le1$，可写成 **SOCP**。**当目标线性**（$A=0,b\ne0$），**即使这个更简单的松弛也紧**。**但当目标二次，若二次最小值落在单位圆盘内，则松弛不紧（loose）**——**最优解满足 $x^Tx\le1$ 但不会有 $x^Tx=1$**。**在 PSD 松弛里，凸松弛会紧**，因为**目标现在（在提升坐标里）是线性的**，**只要 $b\ne0$ 就会推向边界**。

> **神奇的是，这个 SDP 松弛即使目标非凸也给最优解**。notebook 给了凹目标例子（如 $A\preceq0$）。

**类比（紧 vs 松 = "包得严不严"，必懂）**：
- **松弛 = 用凸的"气球"包住非凸的"石头"**。
- **紧（tight）** = **气球刚好贴着石头**，**解气球 = 解石头**，**完美**。
- **松（loose）** = **气球比石头大一圈**，**解气球得到的点"在气球上但不在石头上"**，**得回原问题，错了**。
- **本例的看点**：**简单松弛（SOCP，$x^Tx\le1$）在"目标二次且最小值在圆内"时松**（**气球鼓到圆心去了，但石头在圆周上**）；**SDP 松弛（提升坐标）总是把目标变线性，气球被压到贴圆周 → 紧**。

### 🧪 代码 2：SDP 松弛 —— Example C.2 与 C.3，验证"紧/松"（可跑，cvxpy）

> 用 cvxpy（自带开源 SDP 求解器 SCS）跑两个例子，**亲眼见 SDP 松弛"紧"、简单松弛何时"松"**。

```python
import cvxpy as cp
import numpy as np

# ---- Example C.2: min (x-a)^2 s.t. (x-b)^2>=1, 标量 x ----
a, b = 0.8, 0.5
x, y = cp.Variable(), cp.Variable()
# y >= x^2 用 Schur 补 [[y,x],[x,1]] >> 0 ;  (x-b)^2>=1 -> y-2b x+b^2>=1
prob = cp.Problem(cp.Minimize(y - 2*a*x + a**2),
                  [cp.bmat([[y, x],[x, 1]]) >> 0,        # y >= x^2 (SDP)
                   y - 2*b*x + b**2 >= 1])               # (x-b)^2 >= 1
prob.solve(solver=cp.SCS)
print("C.2 SDP: x=%.4f y=%.4f (y应=x^2=%.4f -> 紧)" % (x.value, y.value, x.value**2))
# 解析: 可行 x>=1.5 或 x<=-0.5; 目标(x-.8)^2 最小在 x=1.5

# ---- Example C.3: 简单松弛(SOCP) vs SDP 松弛, x in R^2 ----
def simple_relax(A, bvec):
    x = cp.Variable(2)
    cp.Problem(cp.Minimize(cp.quad_form(x, A) + bvec.T@x), [cp.norm(x) <= 1]).solve(solver=cp.SCS)
    return x.value, np.linalg.norm(x.value)
def sdp_relax(A, bvec):
    x = cp.Variable(2); Y = cp.Variable((2,2), symmetric=True)
    cp.Problem(cp.Minimize(cp.trace(A@Y) + bvec.T@x),
               [cp.trace(Y)==1, cp.bmat([[Y, cp.reshape(x,(2,1))],
                                          [cp.reshape(x,(1,2)), np.eye(1)]]) >> 0]).solve(solver=cp.SCS)
    return x.value, np.linalg.norm(x.value)
A, bvec = np.eye(2), np.zeros(2)        # 目标二次, 最小值在圆内
xs, ns = simple_relax(A, bvec); xd, nd = sdp_relax(A, bvec)
print("C.3 目标=x'x, 等式约束|x|=1 真最优=1.0")
print("  简单松弛(SOCP): |x|=%.3f 目标=%.3f -> 松(鼓到圆心)" % (ns, xs@xs))
print("  SDP 松弛      : |x|=%.3f 目标=%.3f -> 紧(贴圆周)" % (nd, xd@xd))
A2, bvec2 = np.zeros((2,2)), np.array([1.,0.])   # 目标线性
xs2, ns2 = simple_relax(A2, bvec2)
print("  目标线性时简单松弛也紧: |x|=%.3f" % ns2)
```

**你会看到**：① **C.2 的 $y$ 精确等于 $x^2$**（**Schur 补精确，紧**）；② **C.3 目标 $x^Tx$ 时，简单松弛把 $x$ 鼓到圆心（$|x|\approx0$，松），SDP 松弛贴回圆周（$|x|\approx1$，紧）**；③ **目标线性时简单松弛也紧**。**亲手验证 PDF 关于"紧/松"的全部论断**。

### 3.3 对应 C.3.3：SOS 优化 —— "把'永远非负'翻译成'平方和'"

> 就像能用 SDP 搜**正二次式**，可推广到搜**正多项式**。对二次式 $P\succeq0\Rightarrow x^TPx\ge0,\ \forall x$。推广到：

$$P\succeq0\ \Rightarrow\ m^T(x)Pm(x)\ge0,\ \forall x$$

> 其中 $m(x)$ 是**多项式向量**，通常选**单项式向量**。**这样参数化的正多项式集合，恰好是能写成平方和（SOS）的多项式集合** [5]。**已知并非所有正多项式都能写成这种形式，但关于这个 gap 已知很多**；**对我们而言 gap 很小**（有人专门写论文找"一致正但非 SOS"的多项式）；**应记住它存在，但不会妨碍太多用例**。

> 更好：**关于如何选 $m(x)$ 的项，已知很多**。例如给多项式 $p(x)=2-4x+5x^2$，问是否对所有实 $x$ 正，可用 SOS 分解说服：$p(x)=1+(1-2x)^2+x^2$，或 $p(x)=\begin{bmatrix}x&1\end{bmatrix}\begin{bmatrix}2&-2\\-2&5\end{bmatrix}\begin{bmatrix}x\\1\end{bmatrix}$，**因为该二次型矩阵 PSD**。一般可产生**含所有次数到 $p$ 次数一半的单项式**的 $m(x)$（**实际可做得更好，但不讲细节**）。**实践中** = **有人写了优化前端，接受"多项式正性约束"的高层规格，自动生成 SDP**，**不用想 $m(x)$ 该有哪些项**（见 [6] SOSTOOLS）。**这类优化叫 SOS 优化**。

> **特别地，$m(x)$ 的选择对所得 SDP 的数值（及能否用商业求解器解）影响巨大**。Drake 实现了一些**特别新颖/先进的算法**让它工作良好 [7]。

> 用 SOS 约束写优化时，写 **"$p(x)$ is SOS"** 作为 **"$p(x)\ge0,\ \forall x$，由找到 SOS 分解证明"** 的简写。

> **这出奇地强大**：**允许用凸优化解看似非常非凸的优化问题**。

**类比（SOS = "永远非负 = 能写成几个平方的和"，必懂）**：
- **问**：多项式 $p(x)$ 是不是"对所有 $x$ 都 $\ge0$"？——**这问题本身难**（要查无穷多个 $x$）。
- **SOS 的 trick** = "**如果 $p$ 能写成 $p=\sum q_i(x)^2$，那它当然永远 $\ge0$**"（**平方和当然非负**）。
- **而"能写成平方和" = "存在 PSD 矩阵 $P$ 使 $p=m^TPm$" = 一个 SDP！**
- **于是"查无穷多个 $x$" 变成了 "解一个 SDP"**——**非凸的"永远非负"被凸的"平方和"抓住了**。
- **gap** = **有些多项式"永远非负"但"写不成平方和"**——**但这种"漏网之鱼"极少**，**实践中几乎碰不到**。

**人话**：**SOS = "把第 9 章 Lyapunov 里' $V$ 正定、$\dot V$ 负定'这种'对所有 $x$ 成立'的条件，翻译成 SDP 能解的凸约束"的钥匙**——**所以第 9 章的 SOS Lyapunov、吸引域估计，全建立在 C.3.3 之上**。

#### Example C.4（通过 SOS 全局最小化）—— six-hump-camel

> 考虑著名的两变量非线性函数 **"six-hump-camel"**：

$$p(x)=4x^2+xy-4y^2-2.1x^4+4y^4+\tfrac{1}{3}x^6$$

> 有**六个局部极小，两个全局极小** [8]。通过简单的 SOS 优化，可找到该函数**最小值**（**技术上只是下界，但本例及很多情况下出奇地紧**）：

$$\max_\lambda\ \lambda\quad\text{s.t.}\quad p(x)-\lambda\ \text{is sos}$$

> 玩代码（**大部分行只为画图；实际优化问题表述简洁**）。

> **注意**：这找到**最小值**，但**不直接给出最小化者的 $x$ 值**。要提取最小化者需检查**对偶程序**（见 [8]）。**很多应用如 Lyapunov 分析，获得最小化者甚至不必要**。

**类比（SOS 求全局最小 = "把地板往上抬，抬到刚好碰到最低坑"，必懂）**：
- $p(x)-\lambda$ is SOS = "**$p(x)\ge\lambda$ 对所有 $x$ 成立**" = "**$\lambda$ 是 $p$ 的一条'地板线'，$p$ 全在它上面**"。
- **最大化 $\lambda$** = "**把地板尽量往上抬**"——**抬到顶，地板就**贴住最低的坑底** = 全局最小值**。
- **六个坑里只有两个最深**——**地板抬到顶，正好贴这两个最深的坑**——**SOS 一举找到全局最小，绕过所有局部极小**——**这就是"用凸优化解非凸全局优化"的魔法**。

#### 其余子项（PDF 只列标题，补概念）

- **Sums of squares on a Semi-Algebraic Set / The S-procedure** = "**$p\ge0$ 不必对所有 $x$ 成立，只需在' $g(x)\ge0$ 的区域'成立**"——**用乘子 $\lambda$（本身 SOS）把区域条件吸收进来**（**第 9 章吸引域估计的 S-procedure 就是它**）。
- **Sums of squares on an Algebraic Variety / quotient ring / sampling** = "**$p\ge0$ 只需在' $h(x)=0$ 的曲面'上成立**"（**如第 9 章单摆的 $s^2+c^2=1$**）——**用"在曲面上 $h=0$，所以 $p$ 和 $p+\lambda h$ 等价"来简化**；**quotient ring / sampling** 是"在曲面上采样点代替整张曲面"的加速技巧。
- **DSOS and SDSOS** = **SOS 的"廉价近似"**——**把 SDP 换成更快的 LP（DSOS）或 SOCP（SDS）**，**牺牲一点精度换速度**，**适合超大规模**。

### 3.4 对应 C.3.4：求解技术 —— "谁来解这些碗"

> **Interior point (Gurobi, Mosek, Sedumi,...), First order methods**（**PDF 只列名字**）。

**补充概念（两类求解器，必懂）**：
- **内点法（Interior point）** = "**从碗的内部，沿着'中心路径'滑到底**"——**精度高、步数少，但每步贵**，**适合中小规模、要精确解**（**Gurobi/Mosek 是商业王者，SeDuMi 开源**）。
- **一阶法（First order，如 ADMM、投影梯度）** = "**只看坡度（一阶导），小步快跑**"——**每步便宜、能上超大规模，但精度低、步数多**，**适合深度学习那种"差不多就行"的大问题**。

**类比**：**内点法 = 坐缆车直达谷底（快但缆车贵）；一阶法 = 自己一步步走下山（慢但鞋便宜，山再大也能走）**。

## 4. 对应 C.4：非线性规划 —— "丘陵地带怎么找最低点"

### 4.1 通用表述 + 脑中图像

> 非线性优化通用表述：

$$\min_z\ c(z)\quad\text{s.t.}\quad \phi(z)\le0$$

> $z$ 决策变量向量，$c$ 标量目标，$\phi$ 约束向量。**注意**：虽然写 $\phi\le0$，但这表述**捕捉了**决策变量**正性约束**（约束乘 $-1$）和**等式约束**（同时列 $\phi\le0$ 和 $-\phi\le0$）。

> **脑中图像**：定义在（多维）$z$ 上的**非线性、可能非凸目标**，有一个**满足约束的可能值子集**。**Figure C.3**：一维非线性优化卡通。**红点 = 局部极小，蓝点 = 最优解**。**注意极小可能源于目标导数为零，或源于斜目标顶到约束**。

> 数值方法需要**初猜 $\hat z$**，然后试图沿目标下降到极小。**常见方法**：**梯度下降**（计算或估计目标梯度），或**二阶方法如 SQP**（对目标做**局部二次近似**、对约束做**局部线性近似**，每次迭代解一个 QP 直接跳到局部近似的最小值）。

> 虽非严格要求，但这些算法**常 greatly 受益于显式计算目标和约束梯度**；替代是用**数值微分**。**除纯速度考虑，作者强烈偏好显式算梯度**，因为能**避免有限差分的数值精度问题**。**显式算梯度将是下面讨论的大主题**，Drake 在**提供函数显式梯度**和**用户函数自动微分**上下了大力气。

> 作者起步时认为**实现梯度下降甚至二阶方法没什么难的，自己写了所有求解器**。**现在意识到错了**。**商业非线性规划求解器性能远高于自己写的**，有一堆**技巧、微妙处、参数选择**，实践中差异巨大。**有些求解器能利用问题稀疏性**（如约束稀疏地作用于决策变量）。**如今最重用 SNOPT** [9]（**已捆绑进 Drake 二进制发行版**），但也支持一大套数值求解器。**注意**：虽然提倡用这些工具，但**不必把它们当黑盒**——**很多情况可通过理解并选非默认配置参数改善优化性能**。

**类比（非线性规划 = "在丘陵里，从初猜出发，一步步往低处走"，必懂）**：
- **初猜 $\hat z$** = "**你被空投到丘陵某处**"。
- **梯度下降** = "**摸脚下坡度，朝最陡的下坡方向迈一步**"——**简单，但可能卡局部洼地**。
- **SQP** = "**在脚下用'抛物碗'近似这片丘陵，直接跳到这个碗的碗底**"——**一步迈得远，但每步要解一个 QP**。
- **显式梯度 vs 数值微分** = "**拿精确地图看坡度** vs **往四周各探一步估坡度**"——**后者有误差，且慢**，**所以作者强烈偏好显式/自动微分**。
- **作者"自己写求解器"的悔悟** = "**别自己造缆车，商业缆车快得多**"——**但懂缆车怎么开，能调参数**。

**人话**：**这一节的核心 = "非线性优化靠初猜 + 迭代下降，初猜好不好决定成败；梯度要算准（用自动微分）；别自己写求解器，用 SNOPT 但别当黑盒"**。

### 4.2 各子项（PDF 只列标题，补概念）

- **C.4.1 二阶方法（SQP / 内点）** = **SQP**：每步把非凸问题**局部近似成 QP**，解之，迭代——**非线性规划的"主力"**。**内点**：把不等式约束用"障碍函数"软化，从内部逼近。
- **C.4.2 一阶方法（SGD / ADMM）**：
  - **SGD（随机梯度下降）** = "**每次只用一小批数据估坡度**"——**深度学习标配**。
  - **ADMM** = "**把大问题拆成几块，各块轮流解，再协调一致**"——**适合分布式/带结构约束**。
  - **Penalty methods（罚函数）** = "**把约束变成'违反就罚款'加进目标**"——**简单，但罚太重会病态**。
  - **Augmented Lagrangian（增广拉格朗日）** = "**罚函数 + 拉格朗日乘子**"——**自动调罚重，比纯罚函数稳**（**第 10 章轨迹优化常用**）。
  - **Projected Gradient Descent（投影梯度下降）** = "**先按梯度迈一步，再'投影'回可行域**"——**像"迈出围栏外再被弹回来"**。
- **C.4.3 零阶方法（CMA）** = "**完全不用梯度，靠'撒一群点、看谁好、朝好的方向撒下一群'**"——**CMA-ES**，**适合梯度算不了/噪声大**（**第 10 章 MPPI/CEM 是亲戚**）。
- **C.4.4 Example: Inverse Kinematics（逆运动学）** = "**给定手要到哪，求各关节角度**"——**一个带约束的非线性优化**（**关节限位、避障**），**Drake 的 `InverseKinematics` 就是把它写成 `MathematicalProgram`**。

## 5. 对应 C.5：混合离散 + 连续优化 —— "既要选路，又要选怎么开"

### 5.1 对应 C.5.1 / C.5.2（PDF 只列标题，补概念）

- **C.5.1 Search, SAT, First order logic, SMT solvers, LP interpretation** = **把"逻辑约束"（"A 或 B"、"如果…则…"）交给 SAT/SMT 求解器**；**SMT = SAT + 数学理论**（**能处理" $x>0$ 且 $\sin x<0.5$"这种混合**）；**LP interpretation** = "**把逻辑选择也写成线性约束**"（**大 M 法等**）。
- **C.5.2 Mixed-integer convex optimization（MICP）** = "**变量里既有连续 $x$，又有整数/0-1 $z$，但'固定 $z$ 后关于 $x$ 是凸的'**"——**用 branch-and-bound 搜 $z$，每个节点解一个凸问题**。**高级但可读的 MIP 书 [10]，MILP 综述 [11]**。

**类比（混合整数 = "先选路线（离散），再选怎么开（连续）"，必懂）**：
- **0-1 变量** = "**左绕还是右绕**"（**离散选择**）。
- **连续变量** = "**选定左绕后，具体走哪条光滑曲线**"（**连续优化**）。
- **MICP** = "**固定'左/右'后，'怎么走'是凸的**"——**所以 branch-and-bound 每试一种"左/右组合"，解一个凸问题**，**挑最好的**。

### 5.2 对应 C.5.3：Graphs of Convex Sets（GCS）—— "凸房间迷宫里的最短路"

> **GCS** 是**组合优化问题**（自然在图上描述，如最短路 [12]、TSP、最小生成树、设施选址等）**与连续优化结合**的通用优化框架。最初在 [13] 引入，Drake 有成熟实现。**GCS 对"最短路问题"的扩展在最优控制里很自然**，所以用**最短路**作贯穿例子。见 [14] 更完整。

#### 最短路问题（离散版 = LP）

> 经典问题：图上找从源 $s$ 到目标 $t$ 的（加权）最短路。**Figure C.4** 左：标准有向图最短路；右：推广到凸集图。

> 已知**离散图搜索可表述为线性规划**。定义图顶点 $V$、边 $E$、代价 $c_{ij}\ge0$ 对应边 $(i,j)$。定义决策变量 $\phi_{ij}$，寻求 $\phi_{ij}=1$ 若边在最短路里，否则 $0$。LP：

$$\min_\phi\ \sum_{(i,j)\in E} c_{ij}\phi_{ij}\quad\text{s.t.}\quad \sum_{j\in E_i^{out}}\phi_{ij}+\delta_{ti}=\sum_{j\in E_i^{in}}\phi_{ji}+\delta_{si},\ \forall i\in V,\quad \phi_{ij}\in\{0,1\}$$

> **path length** = 解路径所有边代价之和。**flow constraints** 巧妙编码"**流入之和 = 流出之和**"（**除源和目标，由 $\delta_{si},\delta_{ti}$ 修改**）。

**类比（最短路 = 水流守恒，必懂）**：
- 把 $\phi_{ij}$ 想成"**边 $(i,j)$ 上流不流水**"（1 = 流，0 = 不流）。
- **flow constraint** = "**每个路口，流进来的水 = 流出去的水**"（**源多流出一单位，目标多流进一单位**）。
- **目标** = "**让流水经过的边代价之和最小**"。
- **神奇**：**这个 LP 的解自动是整数 0/1**（**因为网络流的特殊结构**）——**所以"放松成 $\phi\in[0,1]$"也得到整数解**——**最短路 = LP**！

#### GCS 推广：每个顶点是一个"凸房间"

> GCS 提供**简单但强大的推广**：**每当访问图的一个顶点，还允许从该顶点关联的凸集里挑一个元素**。**边长允许是对应集合里连续变量的凸函数**，还可在**边上写凸约束**（任何解路径必须满足）。推广的最短路：

$$\min_{\phi,x}\ \sum_{(i,j)\in E}\ell_{ij}(x_i,x_j)\phi_{ij}\quad\text{s.t.}\quad x_i\in X_i\ \forall i,\quad \sum_{j\in E_i^{out}}\phi_{ij}+\delta_{ti}=\sum_{j\in E_i^{in}}\phi_{ji}+\delta_{si}\le1,\quad \phi_{ij}\in\{0,1\}$$

> $\ell_{ij}\ge0$ 边长，可为关联顶点变量的**凸函数**；$X_i$ 顶点 $i$ 关联的**有界凸集**。Drake 的 `GraphOfConvexSets` 还允许在顶点和边加额外凸约束。

> GCS 相对新，但关于原最短路问题的整数规划表述已知很多。**特别地，已知若所有代价正，则取最后一行的自然凸松弛**（$\phi_{ij}\in\{0,1\}\to\phi_{ij}\in[0,1]$），**则这个凸松弛总是紧的**。**这个 LP 的解给出最短路问题的最优解**！**技术上本例甚至可把最后一行松弛到 $\phi_{ij}\ge0$**。

> 虽然凸集图最短路如写有**双线性目标**，但它可自然描述为 **MICP**。确实 GCS 可编码 **NP-Hard** 问题，但同样可研究二值变量自然凸松弛的紧性。

> **框架如此强大的原因**：开发了**既高效又很强的 GCS 凸松弛**。**意味着可以比以前的转录快几个数量级解 GCS 问题到全局最优**。

> **但实践中发现，只解凸松弛（加一点 rounding）几乎总足以恢复最优解**。**如今机器人应用 GCS 几乎从不解完整 MICP**。

> **能不用 MIP 求解器解组合问题，对作者在这些笔记里很重要**：**最好的 MIP 求解器全是商业许可（且很贵）**。**说能用纯凸优化解难实例，也意味着能用开源求解器解它们**。

**类比（GCS = "凸房间组成的迷宫，找最短路"，必懂，这是 GCS 的灵魂）**：
- **普通最短路** = **迷宫的每个路口是一个"点"**。
- **GCS** = **每个路口是一个"凸房间"**（**如一个多边形自由空间**），**你进房间后还能在房间里"挑一个具体位置 $x_i$"**。
- **边** = "**房间 $i$ 到房间 $j$ 的走廊**"，**走廊代价 $\ell_{ij}(x_i,x_j)$ 取决于你在两房间挑的位置**（**如走廊长度**）。
- **于是"绕障轨迹优化" = "在凸房间迷宫里找最短路，同时在每个房间挑位置让走廊连通且最短"**——**离散（走哪几个房间）+ 连续（房间里站哪）一起解**。
- **为什么强**？因为**这个组合问题的"凸松弛"出奇地紧**——**放松"0/1 选房间"为"0 到 1 的比例"，解出来几乎总是整数**——**所以"解一个凸优化"就得到全局最优**，**不用昂贵的 branch-and-bound**——**这就是 GCS 比老 MIP 转录快几个数量级的秘密**。

**人话**：**GCS = 把"绕障/接触/脚步规划"这些"离散+连续"的硬问题，画成"凸房间迷宫"，然后用"紧到离谱的凸松弛"一举解到全局最优**——**这是作者组（Marcucci 等）近年的招牌成果**，**全书第 10、17 章的 GCS 应用全建立在 C.5.3 之上**。

#### Example C.5（2D 凸集图例子）

> 用各种不同集合拼了个 **2D 玩具 GCS 问题**。**解凸松弛**得总代价（路径长）的**下界**。**然后 rounding** 得可行解，给出**上界**。**由于它们在数值容差内相等，本例可确认——从不解混合整数版——凸松弛是紧的**。

#### Applications（GCS 在本书各处的反向引用）

> 轨迹优化，如 **Minimum-time linear optimal control, Piecewise-affine MPC (PWAMPC), Quadrotor planning around obstacles (with differential flatness), Planning through contact, Footstep planning for humanoids and quadrupeds**。还能在 **manipulation notes** 找更多 GCS 应用，尤其**运动学轨迹优化**。

### 🧪 代码 4：最短路 = LP + GCS 骨架（可跑 / 骨架，对照 C.5.3）

> **(A)** 用 cvxpy 把"4 节点有向图最短路"写成 LP，**验证松弛自动给整数解**；**(B)** Drake GCS 骨架（2D 凸房间最短路）。

```python
# ---- (A) 离散最短路 = LP, 验证整数性 ----
import cvxpy as cp
import numpy as np
# 4 节点, 边 (from,to,cost): 0->1:1, 0->2:4, 1->2:2, 1->3:5, 2->3:1  (源0 目标3)
edges = [(0,1,1),(0,2,4),(1,2,2),(1,3,5),(2,3,1)]
phi = {e: cp.Variable() for e in edges}
cons = []
for i in range(4):
    out = [phi[e] for e in edges if e[0]==i]; inn = [phi[e] for e in edges if e[1]==i]
    rhs = (1 if i==0 else 0) - (1 if i==3 else 0)     # 源流出1, 目标流入1
    cons.append((cp.sum(out) if out else 0) - (cp.sum(inn) if inn else 0) == rhs)
cons += [phi[e] >= 0 for e in edges]                 # 松弛到 >=0 (PDF: 甚至可只 >=0)
cp.Problem(cp.Minimize(cp.sum(e[2]*phi[e] for e in edges)), cons).solve(solver=cp.SCS)
print("最短路 LP 解 phi =", {e: round(phi[e].value,3) for e in edges})
print("  -> 全是 0/1 (整数!), 最短路 0->1->2->3 代价=4")

# ---- (B) Drake GCS 骨架: 2D 凸房间最短路 ----
# from pydrake.geometry.optimization import GraphOfConvexSets, HPolyhedron, Point
# gcs = GraphOfConvexSets()
# v0 = gcs.AddVertex(Point([0,0])); v1 = gcs.AddVertex(HPolyhedron(...)); vt = gcs.AddVertex(Point([3,3]))
# e = gcs.AddEdge(v0, v1); e.AddCost((e.xu()-e.xv()).squaredNorm())   # 边长=走廊长度(凸)
# res = gcs.SolveShortestPath(v0, vt)   # 内部用紧凸松弛, 通常无需 MIP 即得全局最优
```

**你会看到**：**(A) 的 $\phi$ 全是 0 或 1**——**最短路 LP 松弛自动整数**，**最短路 $0\to1\to2\to3$ 代价 $=1+2+1=4$**。**亲手验证"最短路 = LP"**，**而 GCS 把这招推广到"凸房间"**——**绕障轨迹优化的全局最优，就这样用凸优化拿到**。

## 6. 对应 C.6："黑盒"优化 —— "连梯度都没有时"

> **Derivative-free methods. Some allow noisy evaluations.**（**PDF 只一句话**）。

**补充概念（黑盒优化，必懂）**：
- **黑盒优化** = "**目标函数是个黑盒，连梯度都拿不到，甚至每次评估带噪声**"——**如"真机器人跑一次给个分"**。

**类比**：**黑盒优化 = "蒙眼调音台，连'拧哪个旋钮影响哪个音'都不知道，只能'拧一下听一下'**"——**最贵、最慢，但"连模型都没有"时是唯一办法**（**第 20 章 model-free RL 是它的"学策略"版本**）。

## 增补一：把"还不够通俗"的 6 个概念，再各加一个类比

1. **为什么"同一个问题换种写法快慢差十倍"**？因为**求解器对"凸/稀疏/结构好"的问题有专门快算法**；**把非凸写成凸（松弛）、把稠密写成稀疏、把"变量乘积"用提升变量线性化**，**就是"换张好地图"**——**地图好，缆车直达；地图差，徒步累死**。
2. **warm-start 为什么有用**？因为**MPC/迭代优化里，"这一次的解"和"上一次的解"很像**——**用上次的解当初猜，求解器"少走很多路"**——**像"昨天停的车位今天还在附近，不用从停车场入口找起"**。
3. **Schur 补的直觉**：$\begin{bmatrix}A&B\\B^T&C\end{bmatrix}\succeq0\iff C\succeq0$ 且 $A-BC^{-1}B^T\succeq0$（$C\succ0$ 时）——**"大块正定 = 对角块正定 + '扣掉耦合后'也正定"**——**像"一锅汤不咸 = 每勺不咸 + 撇掉浮油后也不咸"**。
4. **SOS 的 gap 为什么"实践中碰不到"**？因为"正但非 SOS"的多项式**通常次数高、系数极端**——**控制里遇到的 $V,\dot V$ 都是"温和"的低次多项式**，**几乎总能写成 SOS**——**所以"理论上有漏网之鱼，实践中鱼池里没这种鱼"**。
5. **GCS 凸松弛为什么"紧到离谱"**？直觉是**凸房间迷宫里，"走半个房间"在物理上没意义，所以松弛解自动"要么全走要么不走"**——**但严格证明靠 GCS 的特殊结构（凸集 + 凸边代价 + 流守恒）**，**[13] 的核心定理**。
6. **自动微分 vs 数值微分 vs 显式微分**：**显式** = 人手推公式（**最准，最累**）；**数值** = 扰动估坡度（**省事，有误差，慢**）；**自动微分** = 让计算机"按链式法则自动拼梯度"（**准如显式，省事如数值**）——**所以作者"强烈偏好自动微分"，Drake 下了大力气做它**。

## 增补二：代码实践补充说明（重点）

这一章是**全书优化的地基**，代码尤其要"玩透"。集中说明**怎么玩**：

- **代码 3（SOS）**：**没装 Drake 的人**，至少跑 scipy 部分，**记住 six-hump-camel 全局最小 $\approx-1.0316$**；**装了 Drake 的**，跑 SOS 看 $\lambda$ 下界贴到这个值——**这是"凸优化解非凸全局优化"的最直观演示**，**也是第 9 章 SOS Lyapunov 的同一引擎**。**进阶**：把 `AddSosConstraint(p-lam)` 改成 `AddSosConstraint(p-lam, {g})`（带 S-procedure 区域约束），**体会"只在某区域非负"**。

## 给初学者的"本章通关三句话"

1. **优化 = 在山地找最低点，约束 = 围栏；凸 = 碗（好解），非凸 = 丘陵（难解），而"同一个问题换种写法"= 换张地图，决定快慢**——**这是全书反复用优化的总纲**；**别自己造求解器，用 `MathematicalProgram` 当翻译官，但别当黑盒**。
2. **拉格朗日乘子把"硬围栏"软化成"罚款"（$\lambda$ = 影子价格）；SDP 松弛用"提升 $X=xx^T$ + 放松秩 1"把非凸变凸，靠 Schur 补把平方/范数约束塞进去；SOS 把"永远非负"翻译成"平方和 = SDP"，于是"把地板抬到顶"就用凸优化抓住了非凸全局最小**——**这三招是"用凸优化解非凸/全局/带约束"的三把钥匙**，**第 8、9 章的 LQR-SDP、Lyapunov-SOS 全建立在它们之上**。
3. **非线性优化靠"初猜 + 迭代下降"，梯度要算准（自动微分），别自己写求解器；混合整数 = "先选路（0-1）再选怎么开（连续）"，而 GCS 把"绕障/接触/脚步"画成"凸房间迷宫"，用"紧到离谱的凸松弛"一举解到全局最优，连昂贵的 MIP 求解器都省了**——**这正是作者组近年的招牌，也是"离散+连续"硬问题在凸优化时代的解法**。
