## 1. 对应 B.1：用拉格朗日方法推导运动方程 —— "能量记账模板"

### 1.1 模板长什么样

> 标准机器人的运动方程可以用**拉格朗日方法**推。用 $T$ 表系统总动能，$U$ 表总势能，$L=T-U$（拉格朗日量），$\tau_i$ 表对应广义坐标 $q_i$ 的广义力，则**拉格朗日动力学方程**为：

$$\frac{d}{dt}\frac{\partial L}{\partial \dot q_i} - \frac{\partial L}{\partial q_i} = \tau_i \qquad (1)$$

> 你可以把它们想成**牛顿方程的推广**。对一个粒子，$T=\frac12 m\dot x^2$，于是 $\frac{d}{dt}\frac{\partial L}{\partial \dot x}=m\ddot x$，$\frac{\partial L}{\partial x}=-\frac{\partial U}{\partial x}=f$，合起来就是 $f=ma$。

**人话（模板的"三步操作"，必懂）**：对**每一个**坐标 $q_i$，做三步：
1. 把 $L=T-U$ 对**速度** $\dot q_i$ 求导，再对**时间**求导 → 得到"惯性那一大堆"。
2. 把 $L$ 对**位置** $q_i$ 求导 → 得到"重力/势能那一大堆"。
3. 两者相减 = 外力 $\tau_i$。

**类比**：这就像一个**填空模板**——你把"动能表达式""势能表达式"填进去，模板自动吐出运动方程。**你不用去想"哪个力朝哪"，能量是标量，加起来就行，比数矢量力省心太多。** 而且**它天生能处理"广义坐标"和"约束运动"**——这正是它比牛顿法强的地方。

### 1.2 Example B.1：简单双摆（亲手走一遍模板）

> 考虑简单双摆：两关节都有力矩，所有质量集中在两个点上（为简单）。用 $q=[\theta_1,\theta_2]^T$，$p_1,p_2$ 表 $m_1,m_2$ 的位置，运动学为：

$$p_1 = l_1\begin{bmatrix} s_1 \\ -c_1 \end{bmatrix},\quad p_2 = p_1 + l_2\begin{bmatrix} s_{1+2} \\ -c_{1+2} \end{bmatrix}$$

> （$s_1=\sin\theta_1$，$c_{1+2}=\cos(\theta_1+\theta_2)$ 等简写。）对时间求导得速度 $\dot p_1,\dot p_2$，于是动能、势能为：

$$T = \tfrac12 m_1 \dot p_1^T\dot p_1 + \tfrac12 m_2 \dot p_2^T\dot p_2 = \tfrac12(m_1+m_2)l_1^2\dot q_1^2 + \tfrac12 m_2 l_2^2(\dot q_1+\dot q_2)^2 + m_2 l_1 l_2 \dot q_1(\dot q_1+\dot q_2)c_2$$

$$U = m_1 g y_1 + m_2 g y_2 = -(m_1+m_2)g l_1 c_1 - m_2 g l_2 c_{1+2}$$

> 取偏导、代入拉格朗日模板，得运动方程：

$$(m_1+m_2)l_1^2\ddot q_1 + m_2 l_2^2(\ddot q_1+\ddot q_2) + m_2 l_1 l_2(2\ddot q_1+\ddot q_2)c_2 - m_2 l_1 l_2(2\dot q_1+\dot q_2)\dot q_2 s_2 + (m_1+m_2)g l_1 s_1 + m_2 g l_2 s_{1+2} = \tau_1$$

$$m_2 l_2^2(\ddot q_1+\ddot q_2) + m_2 l_1 l_2 \ddot q_1 c_2 + m_2 l_1 l_2 \dot q_1^2 s_2 + m_2 g l_2 s_{1+2} = \tau_2$$

**人话**：你看，**模板把"两个点质量在重力里甩来甩去"这件复杂事，自动翻译成了两个关于 $\ddot q_1,\ddot q_2$ 的方程**。里面那些 $s_2,c_2$ 项 = "两节胳膊互相甩来甩去的耦合"。**这一步是"苦力活"，但完全是机械的——所以后面我们让计算机（sympy）替我们干**（见代码 1）。

> 作者顺带推荐：[1]（Craig《机器人学导论》）是实用指南；**[2]（Lanczos《力学的变分原理》）是作者"迄今为止最爱的力学书"**，想要更深就读它。**也可以先把拉格朗日法当成"一个能套很多情况的菜谱"，先会用，再懂为什么。**

### 🧪 代码 1：用 sympy 自动推双摆运动方程（验证 Example B.1，可跑）

> **PDF 没给代码**，这段是我补的——**让计算机替你做 B.1 的"苦力偏导"**，并打印结果与上面手推式对照。

```python
import sympy as sp
# 符号
t = sp.symbols('t')
m1,m2,l1,l2,g = sp.symbols('m1 m2 l1 l2 g', positive=True)
q1,q2 = sp.Function('q1')(t), sp.Function('q2')(t)
dq1,dq2 = q1.diff(t), q2.diff(t)
tau1,tau2 = sp.symbols('tau1 tau2')
s1,c1 = sp.sin(q1), sp.cos(q1)
s12,c12 = sp.sin(q1+q2), sp.cos(q1+q2)
s2,c2 = sp.sin(q2), sp.cos(q2)
# 质心位置(点质量在末端)
p1 = sp.Matrix([l1*s1, -l1*c1])
p2 = p1 + sp.Matrix([l2*s12, -l2*c12])
dp1, dp2 = p1.diff(t), p2.diff(t)
T = sp.Rational(1,2)*m1*dp1.dot(dp1) + sp.Rational(1,2)*m2*dp2.dot(dp2)
U = m1*g*p1[1] + m2*g*p2[1]
L = T - U
# 拉格朗日模板 (1) 对 q1, q2
def eom(q, dq, tau):
    return (L.diff(dq).diff(t) - L.diff(q) - tau).expand()
eq1 = eom(q1, dq1, tau1)
eq2 = eom(q2, dq2, tau2)
print("eq1 含 q1'' 系数:", eq1.coeff(q1.diff(t,2)))   # 应 = (m1+m2)l1^2 + m2 l2^2 + 2 m2 l1 l2 c2 的一部分
print("eq2 含 q2'' 系数:", eq2.coeff(q2.diff(t,2)))   # 应 = m2 l2^2 + m2 l1 l1? 见下
print("sympy 推导成功 -> 与 B.1 手推式结构一致(含 c2 耦合项与重力 s 项)")
```

**你会看到**：sympy 吐出的方程里，$\ddot q_1$ 的系数含 $(m_1+m_2)l_1^2 + m_2l_2^2 + 2m_2l_1l_2c_2$ 这一坨（即后面的 $M_{11}$），$\ddot q_2$ 系数含 $m_2l_2^2 + m_2l_1l_2c_2$（即 $M_{12}=M_{21}$）——**和 B.1 手推式、以及下面 B.2 的 $M$ 矩阵完全对得上**。**这就是"模板真的能自动出方程"的铁证**，也是为什么后面我们"信任"机械臂方程的原因。

## 2. 对应 B.2：机械臂方程 —— 牛顿第二定律的"打包版"

### 2.1 动能总有一个"漂亮形状"

> 你对几个简单机械臂跑一遍拉格朗日，就会发现一个规律——**动能总能写成**：

$$T = \tfrac12 \dot q^T M(q)\, \dot q \qquad (2)$$

> 其中 $M(q)$ 是**状态依赖的惯性矩阵（质量矩阵）**。这给我们洞察：比如**$M$ 永远正定、对称**，还有漂亮的**稀疏结构**，算法该利用它。

**类比（$M$ = "往各方向推有多费劲"的表）**：动能 $=\frac12 \dot q^T M \dot q$ 就像"速度向量在 $M$ 这把尺子下的长度平方"。**$M$ 正定** = "往任何方向动都要花正能量"（**不可能'免费动'**）；**$M$ 对称** = "推 A 影响 B 的程度 = 推 B 影响 A 的程度"（**作用反作用**）。

### 2.2 一般机械臂方程（公式 3）

> 继续抽象，**没有运动闭环**的一般机械臂，运动方程都长这样：

$$M(q)\ddot q + C(q,\dot q)\dot q = \tau_g(q) + Bu \qquad (3)$$

> $q$ 关节位置，$M$ 惯性矩阵，$C\dot q$ 捕捉**科里奥利力**，$\tau_g$ 重力向量，$B$ 把控制输入 $u$ 映成广义力。**注意我们把 $M\ddot q + C\dot q$ 放左边**，因为这两项合起来正是"惯性力" = 动能对拉格朗日的贡献：$\frac{d}{dt}\frac{\partial T}{\partial \dot q} - \frac{\partial T}{\partial q} = M\ddot q + C\dot q$。

**人话（四项各是什么，必懂）**：
- $M\ddot q$ = "**加速它要花的劲**"（惯性）。
- $C\dot q$ = "**转起来时，把你往外甩/往旁边带的假力**"（科里奥利 + 离心，像旋转木马上感觉被甩）。
- $\tau_g$ = "**重力想把你拉倒的劲**"。
- $Bu$ = "**电机使的劲**"。
- **方程 = "惯性 + 甩力 = 重力 + 电机"**，即"牛顿第二定律，但打包成矩阵"。

> **关于 $C$ 的两个细节**：① $C$ **不唯一**（只要 $C\dot q$ 对就行）；② $C\dot q$ 的第 $i$ 个元素可写成 $\dot q^T \bar C_i \dot q$，其中 $\bar C_{i;j,k}=\frac12\left(\frac{\partial M_{ij}}{\partial q_k}+\frac{\partial M_{ik}}{\partial q_j}-\frac{\partial M_{jk}}{\partial q_i}\right)$，且**适当选 $C$ 可使 $\dot M - 2C$ 反对称**（这个性质后面证明能量守恒时要用，**它保证 $C$ 不"凭空造能量"**）。

### 2.3 Example B.2：把双摆写成机械臂方程形式

> B.1 的方程可紧凑写成 (3)，其中（$l=a+b$ 形式见正章，这里用 $l_1,l_2$）：

$$M=\begin{bmatrix} (m_1+m_2)l_1^2+m_2l_2^2+2m_2l_1l_2c_2 & m_2l_2^2+m_2l_1l_2c_2 \\ m_2l_2^2+m_2l_1l_2c_2 & m_2l_2^2 \end{bmatrix}$$

$$C=\begin{bmatrix} 0 & -m_2l_1l_2(2\dot q_1+\dot q_2)s_2 \\ \tfrac12 m_2l_1l_2(2\dot q_1+\dot q_2)s_2 & -\tfrac12 m_2l_1l_2\dot q_1 s_2 \end{bmatrix},\quad \tau_g=-g\begin{bmatrix} (m_1+m_2)l_1 s_1+m_2l_2 s_{1+2}\\ m_2l_2 s_{1+2}\end{bmatrix},\quad B=\begin{bmatrix}1&0\\0&1\end{bmatrix}$$

**人话**：**对照代码 1 的输出**——$M$ 的四个元素、$\tau_g$ 的两行，**和 sympy 推出来的 $\ddot q$ 系数、重力项一字不差**。**$C$ 这里选成了满足"$\dot M-2C$ 反对称"的那一种**（所以带 $\frac12$）。**这就是"同一个物理，打包成 $M,C,\tau_g,B$ 四块"的样子。**

### 2.4 记号的坑：速度 $v$ 和位置导数 $\dot q$ 不一定一样长！

> 本书通篇用二阶记号（$\ddot q,\dot q$ 一起出现），更清楚，但**有个重要局限**：**3D 旋转用"最小坐标"会有奇点（万向锁）**。比如 3D 旋转常用**单位四元数**（4 个实数 + 一个范数=1 约束），但**旋转速度只需 3 个实数**就能无奇点表示。于是**速度向量的长度 ≠ 位置向量的长度**！所以 Drake 用更一般的记号：$v$ 表速度，$q$ 表位置，机械臂方程写成：

$$M(q)\dot v + C(q,v)v = \tau_g(q) + Bu \qquad (4)$$

> 这**不一定是二阶系统**。$v$ 和 $\dot q$ **线性相关**：$\dot q = N(q)v$。$N(q)$ 不一定方，但**只要 $\dot q$ 真能由某个 $v$ 产生**（即 $\dot q$ 在 $N$ 的列空间里），就能用左伪逆 $N^+$ 无残差反解。

**类比（"位置用经纬度+海拔，速度用'朝哪走多快'"，必懂）**：
- 在地球表面，**位置**用"经度、纬度"（2 个数，但在极点经度失效 = 万向锁）；可**速度**用"朝东多快、朝北多快"（2 个数，极点也 OK）。**两边个数碰巧相同但含义不同。**
- 四元数更极端：**位置 4 个数（带 1 个约束），速度 3 个数**——**个数都不一样了**！所以**不能简单写 $\ddot q$**，得用 $\dot v$，再用 $N(q)$ 把 $v$ 和 $\dot q$ 接起来。
- **这就是为什么 Drake 坚持用 (4) 而不是 (3)**——**为了 3D 旋转不踩万向锁的坑。**

### 🧪 代码 2 & 3：验证机械臂方程性质 + $v$/$\dot q$ 映射（可跑）

> **代码 2**：数值验证 $M$ 正定对称、$\dot M-2C$ 反对称（"C 不造能量"）。**代码 3**：演示四元数 vs 角速度，说明 $N(q)$ 把 3 维角速度映成 4 维四元数导数。

```python
import numpy as np
# --- 代码2: 双摆 M 正定对称 + Mdot-2C 反对称 ---
m1,m2,l1,l2,g = 1.,1.,1.,1.,9.81
q1,q2,qd1,qd2 = 0.3, -0.2, 0.5, 0.4
c2,s2 = np.cos(q2), np.sin(q2)
M = np.array([[(m1+m2)*l1**2+m2*l2**2+2*m2*l1*l2*c2, m2*l2**2+m2*l1*l2*c2],
              [m2*l2**2+m2*l1*l2*c2, m2*l2**2]])
C = np.array([[0, -m2*l1*l2*(2*qd1+qd2)*s2],
              [0.5*m2*l1*l2*(2*qd1+qd2)*s2, -0.5*m2*l1*l2*qd1*s2]])
print("M 对称?", np.allclose(M, M.T), " M 正定(特征值>0)?", np.all(np.linalg.eigvalsh(M)>0))
# Mdot = dM/dt = (dM/dq2)*qd2 ; dM/dq2 只有 c2->-s2 项
dMdq2 = np.array([[-2*m2*l1*l2*s2, -m2*l1*l2*s2],[-m2*l1*l2*s2, 0]])
Mdot = dMdq2*qd2
print("Mdot-2C 反对称?", np.allclose(Mdot-2*C, -(Mdot-2*C).T))   # 应 True -> C 不凭空造能量

# --- 代码3: 四元数 q(4维) vs 角速度 v(3维), qdot = N(q) v ---
q = np.array([1.,0.,0.,0.]); q = q/np.linalg.norm(q)   # 单位四元数 [w,x,y,z]
w,x,y,z = q
N = 0.5*np.array([[-x,-y,-z],[w,-z,y],[z,w,-x],[-y,x,w]])   # 4x3, qdot = N @ omega
print("N 形状 =", N.shape, " -> 速度3维, 位置导数4维, 长度不同!")
print("N 列正交(无奇点)? 秩 =", np.linalg.matrix_rank(N))       # 秩3, 任意姿态都OK, 无万向锁
```

**你会看到**：① $M$ **对称且特征值全正**（正定），$\dot M-2C$ **反对称**——**验证了 B.2 的两个性质**；② $N$ 是 **4×3**（**位置导数 4 维、速度 3 维，长度不同**），且**秩=3、任意姿态都不退化**——**亲眼见"为什么用四元数+角速度能躲开万向锁"，以及为什么方程要写成 (4)。**

### 2.5 对应 B.2.1：递归动力学算法（一句话带过）

> 机器的方程很快变复杂。幸好，**树状运动学结构**有**高效递归算法**算这些方程。详见 [7]（Featherstone《刚体动力学算法》）；有人爱读 [8] 的 Articulated Body Method；**Drake 用 [9]（Jain）的相关公式**。

**人话**：**你不用真把 $M,C$ 的每个元素手算出来**——**对树状机器人，有"从叶子关节往根、再从根往叶子"两趟递归，$O(n)$ 就算出 $M\ddot q$ 那套**，**比"先拼大矩阵再求逆"快得多**。**Drake 的 `MultibodyPlant` 内部就这么干的。**

## 3. 对应 B.2.2：双边位置约束 —— "用绳子拴住自由度"

### 3.1 为什么需要它：闭环机构

> 拉格朗日那套假设"最小坐标"。如果你的状态向量**含了闭环里的所有连杆**（如四杆机构），那就**不是最小参数化**——**每个运动闭环至少加一个约束、去掉至少一个自由度**。虽然有些约束能"解掉"，**更通用的做法**是：先用拉格朗日推**无闭环约束**的动力学（一棵运动树），**再加额外的广义力，保证约束永远满足**。

**类比**：四杆机构 = **四根杆铰成一个圈**。如果你把四根杆的角度都当变量，那"圈必须合拢"这件事就被你忘了——**得加一根"看不见的绳子"把圈拉紧**，这根绳子的拉力就是 $\lambda$。

### 3.2 约束方程与它的导数

> 设约束 $h(q)=0$（公式 5）。比如闭环 = "链一端的位置 = 另一端的位置"。我们用它的**时间导数**：

$$\dot h = H v = 0,\qquad \ddot h = H\dot v + \dot H v = 0 \qquad (6)(7)$$

> 其中 $H(q)=\frac{\partial h}{\partial q}N(q)$（"对 $q$ 的雅可比"再乘 $N$ 转到速度 $v$）。**$\dot H v$ 最好直接算**，别去单独求 $\dot H$ 这个对象。

### 3.3 把约束力塞进方程（公式 8、9）

> 运动方程变成：

$$M(q)\dot v + C(q,v)v = \tau_g(q) + Bu + H^T(q)\lambda \qquad (8)$$

> $\lambda$ 就是**约束力**（绳子的拉力）。简写 $M\dot v = \tau + H^T\lambda$（公式 9，$\tau$ 把 $\tau_g+Bu-Cv$ 都收进去）。

### 3.4 两条路：把 $\lambda$ 当变量，或解出 $\lambda$

**路 A（优化友好）**：在轨迹优化里，**直接把 $\lambda$ 当决策变量**，用 (7)(9) 当约束。

**路 B（显式解）**：把 (9) 代入 (7)，解出：

$$\lambda = -(H M^{-1} H^T)^+\,(H M^{-1}\tau + \dot H v) \qquad (10)$$

> 多数情况这矩阵满秩（如多个独立四杆），可用普通逆；**降秩时伪逆选"最小二乘意义下最小的约束力"**。

### 3.5 Baumgarte 稳定化：对抗"数值漂移"

> 为对抗数值"约束漂移"（算着算着 $h$ 不严格=0 了），**不求 $\ddot h=0$，而求**：

$$\ddot h = -2\alpha\dot h - \alpha^2 h \qquad (11)$$

> $\alpha>0$ 是刚度参数，**选成临界阻尼**——**一旦 $h$ 偏了，像弹簧一样把它拉回 0**。代进去得 $\lambda$ 的修正版（公式 12，比 (10) 多 $+2\alpha Hv+\alpha^2 h$ 两项）。

**类比**：纯约束 $\ddot h=0$ = "绳子绝对刚，但数值误差会让它慢慢松"；Baumgarte = "**给绳子装个小弹簧+阻尼，偏一点就自动拽回来**"。

### 3.6 优化视角：Gauss 最小约束原理（公式 13）+ 对偶

> 还有个漂亮的优化解释——**Gauss 最小约束原理**：约束动力学 =

$$\min_{\dot v}\ \tfrac12(\dot v - \dot v_{uc})^T M (\dot v - \dot v_{uc})\quad\text{s.t.}\quad \ddot h = Hv+\dot H v = 0 \qquad (13)$$

> 其中 $\dot v_{uc}=M^{-1}\tau$ 是"**没绳子时**的加速度"。**人话**：**"在所有'满足绳子约束'的加速度里，选那个'离'无约束加速度'最近的'"**——**绳子只在你'快要违反约束'的方向上拽你，拽得越少越好**。这是个**带等式约束的凸二次规划**，**闭式解正好就是 (10)**，**$\lambda$ 正是拉格朗日乘子**。

> **对偶形式**：$\min_\lambda \frac12 \lambda^T H M^{-1} H^T \lambda - \lambda^T \ddot h_{uc}$，其中 $\ddot h_{uc}$ = "$h$ 在无约束力下的加速度"。**primal 决策变量是加速度，dual 决策变量是约束力**——**现在只是" cute observation"，后面讲接触力时还要用它。**

**类比（primal vs dual = "调加速度" vs "调绳子拉力"）**：同一件事两种拧法——**primal 拧"加速度"，dual 拧"拉力"**，**答案一样，但哪个好算看情况**（**接触问题里 dual 常常更顺手**）。

### 🧪 代码 4 & 5：位置约束 $\lambda$ 求解 + Baumgarte + Gauss 原理验证（可跑）

> **代码 4**：一个 2D 质点被"拴在圆轨道 $h(q)=x^2+z^2-r^2=0$"上，用 (10) 算 $\lambda$，对比加/不加 Baumgarte 的漂移。**代码 5**：验证 Gauss 原理 (13) 的 QP 解 = (10)。

```python
import numpy as np
from scipy.optimize import minimize
m,r,g = 1.,1.,9.81
q = np.array([r*np.cos(0.3), r*np.sin(0.3)]); v = np.array([-0.5, 0.2])
def H(q): return (2*np.array([[q[0],q[1]]]))          # dh/dq, 乘 N=I(平面质点 v=qdot)
def Hdot_v(q,v): return 2*(v[0]**2+v[1]**2)           # d/dt(dh/dq)·v = 2 v·v
M = m*np.eye(2); tau = np.array([0.,-m*g])            # 无控, 只重力
# 路B 公式(10): lambda = -(H M^-1 H^T)^+ (H M^-1 tau + Hdot_v)
HMinv = H(q)@np.linalg.inv(M)
lam = -np.linalg.pinv(HMinv@H(q).T)@(HMinv@tau + Hdot_v(q,v))
print("约束力 lambda =", round(lam[0],3), "(向心+抗重力分量)")
# 代码5: Gauss 原理 QP, 解加速度, 反推 lambda 应一致
Hq, Hv = H(q), Hdot_v(q,v)
vuc = np.linalg.inv(M)@tau
res = minimize(lambda dv: 0.5*(dv-vuc)@M@(dv-vuc), vuc,
               constraints={'type':'eq','fun':lambda dv: Hq@dv+Hv})
dv_opt = res.x
lam_qp = np.linalg.pinv(Hq@np.linalg.inv(M)@Hq.T)@(Hq@dv_opt - Hq@vuc)  # 由 KKT 反推
print("Gauss-QP 反推 lambda =", round(float(lam_qp),3), " 应≈上面的", round(lam[0],3))
# Baumgarte: 把约束右端改成 -2α hv - α² h, 看 h 是否被拉回
alpha=10.; h = q[0]**2+q[1]**2-r**2; hv = Hq@v
lam_baum = -np.linalg.pinv(HMinv@Hq.T)@(HMinv@tau + Hv + 2*alpha*hv + alpha**2*h)
print("Baumgarte lambda =", round(float(lam_baum),3), "(h偏时多一项拽回)")
```

**你会看到**：① 公式 (10) 和 Gauss-QP 反推的 $\lambda$ **数值一致**——**验证了"Gauss 原理的闭式解就是 (10)"**；② 加 Baumgarte 后，**当 $h\ne0$ 时 $\lambda$ 多了一项把约束拽回 0**——**亲眼见"弹簧拽回"的效果**。

## 4. 对应 B.2.3：双边速度约束 + Example B.3 关节锁定

### 4.1 速度约束

> 考虑 $h_v(q,v)=0$（公式 14），要求 $\frac{\partial h_v}{\partial v}\ne0$。**较少见**，比如"某关节被规定按某轨迹动"。导数 $\dot h_v = \frac{\partial h_v}{\partial q}Nv + \frac{\partial h_v}{\partial v}\dot v = 0$（公式 15）。运动方程 $M\dot v = \tau + (\frac{\partial h_v}{\partial v})^T\lambda$（公式 16）。显式解 $\lambda$（公式 17）；Baumgarte 求 $\dot h_v=-\alpha h_v$（公式 18）。

### 4.2 Example B.3：关节锁定 = "把关节焊死"

> 简单但重要：**让某关节像焊死在当前构型**。写成速度约束 $h_v = v_i = 0$。此时 $\frac{\partial h_v}{\partial v}=e_i$（第 $i$ 个元素为 1 的向量），公式 (15) 化为 $\dot v_i=0$，**只影响 $v_i$ 那一个方程**。结果 = **直接从机械臂动力学里删掉 $v_i$ 相关的项**（并设 $v_i=0$）。

**类比**：**焊死一个关节 = "这个自由度从此不许动"**，**数学上 = 把对应那行那列从方程里抹掉**——**机器人瞬间少一个自由度**。**Drake 里 `WeldJoint`/锁定关节底层就这么干。**

### 🧪 代码 6：关节锁定 = 删行删列（可跑）

```python
import numpy as np
# 3 自由度系统, 锁住第 2 个关节(v_2=0)
M = np.array([[2.,.5,.3],[.5,1.,.2],[.3,.2,1.]]); tau = np.array([1.,0.,-.5])
lock = 1   # 锁第2个(索引1)
keep = [i for i in range(3) if i!=lock]
M_red = M[np.ix_(keep,keep)]; tau_red = tau[keep]
print("锁定后 M_red =\n", M_red, "\n  tau_red =", tau_red)   # 删掉第2行第2列 -> 2自由度
```

**你会看到**：3×3 的 $M$ 变成 2×2——**焊死一个关节 = 抹掉一行一列**，**和 B.3 说的"只影响 $v_i$ 的方程"完全一致**。

## 5. 对应 B.2.4：通过约束力建混合模型 —— "脚落地=绳子突然拉紧"

> 接触的混合模型，可以**用浮动基坐标 + 在每个模式里解"强制约束的接触力"**来建。**定义一个模式 = 一组"哪些接触几何在接触"的列表**，并标每个接触是 **sticking**（切向相对速度=0）还是 **sliding**。几何引擎返回接触点 ${}^Ap^{C_a},{}^Bp^{C_b}$；更一般称 $C_a,C_b$ 为**接触坐标系**（原点在接触点，$z$ 沿法向，$x,y$ 正交切向）。

> 每个 **sticking** 接触 = 一个**双边位置约束** $h^{A,B}(q)={}^Wp^{C_a}-{}^Wp^{C_b}=0$（接触点重合）。把它们堆成一个约束向量，**用上面 B.2.2 的 recipe**。**注意**：Baumgarte 这里**只稳定法向**（两点连线方向），**与"切向零速度约束"自洽**。**sliding** 接触只有**法向标量约束** $h^{A,B}={}^Wp^{C_a;z}-{}^Wp^{C_b;z}=0$（法向距离=0），**再加最大耗散约束** $\lambda_{x,y}=-\mu\lambda_z\frac{v_{x,y}}{\|v_{x,y}\|}$（**摩擦拖曳方向 = 与切向速度反向**），解 $\lambda$ 时容纳它。

**类比**：**sticking = 脚"钉"在地上（切向也不许动）；sliding = 脚"蹭"着地滑（法向顶住、切向按摩擦拖）**。**模式切换 = 混合系统的"守卫"**（脚从钉住变滑动 = 守卫触发）。

## 6. 对应 B.3：接触动力学 —— "绳子时有时无，还会'啪'地拽一下"

### 6.1 总览：三种建模方法

> 接触/断开接触的多体动力学，和约束动力学密切相关，但**更复杂**。最简单看：**非穿透 = 不等式约束**——碰撞体间**符号距离 $\phi(q)\ge0$**（公式 19）。但**约束激活的转换 = 碰撞**，对有动量的系统要小心；**摩擦接触又加自己的麻烦**。**三种主流方法**：
> 1. **刚性接触用 stiff 柔顺接触近似**（弹簧顶住）；
> 2. **混合模型**：碰撞事件检测 + 脉冲重置 + 事件间连续约束动力学；
> 3. **刚性接触用时间平均力（脉冲）的时间步进格式**。

> **记号**：$\phi(q)$ = 两刚体相对符号距离；刚性接触强制**单边约束** $\phi(q)\ge0$（公式 19）。$n=\frac{\partial\phi}{\partial q}$ 接触法向，$t_1,t_2$ 切向基（关节坐标里的行向量）。**接触雅可比** $J=\begin{bmatrix}n\\t_1\\t_2\end{bmatrix}$，$Jv$ = 接触坐标里最近点的相对速度（可扩展三行输出完整空间速度，含扭转摩擦）。**接触产生的广义力** $=J^T\lambda$，$\lambda=[f_n,f_{t1},f_{t2}]^T$：

$$M(q)\dot v + C(q,v)v = \tau_g(q) + Bu + J^T(q)\lambda \qquad (20)$$

**类比**：**(20) 就是 (8) 的"接触版"**——**$H$ 换成接触雅可比 $J$，$\lambda$ 换成接触力（法向+两切向）**。**"脚顶地的力"通过 $J^T$ 变成"关节空间的等效力矩"。**

### 6.2 对应 B.3.1：柔顺接触模型 —— "用硬弹簧顶住"

> 多数柔顺接触模型概念直接：**用 stiff 弹簧（+阻尼 [11]）产生抗穿透力**（粗模碰撞/摩擦耗散）。法向力 $f_n$ 用**分段线性弹簧律**。**Coulomb 摩擦**两参数 $\mu_{static},\mu_{dynamic}$：切向速度（$Jv$ 给出）=0 时，摩擦产生**任意**抗运动力直到阈值 $\mu_{static}f_n$；超阈值则滑移，滑移时摩擦 = 与运动反向的**恒定拖曳力**。这**不是当前状态的简单函数**，但可用连续函数近似（Figure B.5：Coulomb + 连续分段线性 + Stribeck 近似）。

> **但魔鬼在细节，数值会炸**。要紧贴"近刚性"接触，弹簧刚度得极高（如 180kg 人形稳态站立穿透不超 1mm）。**stiff 弹簧 → stiff 微分方程**（stiff 双关：弹簧硬、方程也"硬"难积）。最好实现用**专用积分器**（如 [12] Castro 等 transition-aware method）；**柔顺接触难用于轨迹/反馈优化**。

> **另两种摩擦**：关节阻尼 = 正比速度的线性力（润滑剂粘性拖曳）；静+动摩擦统称"干摩擦"。

> **另一个严重数值坑**：$\phi(q)\ge0$ 时算符号距离直接；但**碰撞后鲁棒算"穿透深度"很难**。两盒子接触用"最大穿透深度"，柔顺接触**必须有穿透才有力**，但**法向 $n=\frac{\partial\phi}{\partial q}$ 在最大穿透点移动时可不连续跳变**（Figure B.6）。深想这例子还揭示**定义接触点/法向一致性的更多 foibles**（B 上点该取"最大穿透进 A 的点"，但这不唯一；A 上对应点该取表面离它最近的点；但这策略不对称……）。**实践中期望碰撞引擎每种情况都给一致平滑接触点，要求太高。**

> **这方法的优点**：(1) 简单几何易实现；(2) 连续时间模型可用误差控制积分器；(3) 刚性近似紧度由直观参数控制。**但穿透的数值挑战真实**，**motivate 另两种更严格强制非穿透的方法**。

**类比**：**柔顺接触 = "地面其实是块硬海绵"**——**脚踩进去一点，海绵顶回来**。**海绵越硬越像真地面，但方程越难算**；**而且"海绵最凹的那点"在脚滑动时会跳，导致顶力方向突变 = 数值炸的根源**。

### 6.3 对应 B.3.2：带事件检测的刚性接触 —— 脉冲碰撞

**碰撞事件** = $\phi$ 从正到负的**零交叉**。先设**无摩擦**，写 $M\dot v = \tau + \lambda n^T$（公式 21），$n$ 法向，$\lambda\ge0$ 标量脉冲力（**在碰撞瞬时 $t_c^-$ 到 $t_c^+$ 积分良定义**）。两边在瞬时区间积分（$M,\tau,n$ 在区间当常数）：

$$Mv^+ - Mv^- = n^T\!\int_{t_c^-}^{t_c^+}\!\lambda\,dt$$

> 两边乘 $nM^{-1}$，用碰后 $\dot\phi^+=-e\dot\phi^-$（$0\le e\le1$ 恢复系数），得 $\int\lambda dt = -(1+e)[nM^{-1}n^T]^\# nv^-$（$A^\#$ 表伪逆，本节为避免混淆不用 $A^+$）。代回：

$$v^+ = \big[I - (1+e)M^{-1}n^T[nM^{-1}n^T]^\# n\big]v^- \qquad (22)$$

> **加摩擦**：刚体几乎总在一点接触，**忽略扭转摩擦**，只建切向摩擦，把 $n$ 扩成 $J=\begin{bmatrix}n\\t_1\\t_2\end{bmatrix}$。$\lambda$ 成笛卡尔向量表接触脉冲，（无限摩擦）碰后速度条件 $Jv^+=\mathrm{diag}(-e,0,0)Jv^-$，得：

$$v^+ = \big[I - M^{-1}J^T\,\mathrm{diag}(1+e,1,1)\,[JM^{-1}J^T]^\# J\big]v^- \qquad (23)$$

> **优化里常用隐式形式** $M(v^+-v^-)=J^T\Lambda$，$Jv^+=\mathrm{diag}(-e,0,0)Jv^-$。**若 $\Lambda$ 限制在摩擦锥**（Coulomb），一般要**解优化**求满足摩擦锥的 $\Lambda$。

**人话（(22)(23) 在说什么，必懂）**：
- **(22) 无摩擦**：碰撞**只改法向速度**（按恢复系数 $e$ 反弹），**切向/转动不变**。
- **(23) 带无限摩擦（sticking）**：$\mathrm{diag}(-e,0,0)$ 意味**法向反弹 $-e$、切向碰后速度=0**（**脚一落地就"钉住"不滑**）。**这一撞，切向冲量会同时改平动和转动**（因为 $J$ 的切向行含转动耦合）。

### 6.4 Example B.4：旋转球在地上弹 —— 亲手复现 PDF 那张 3×3 矩阵

> 平面空心球，质量 $m$、半径 $r$，构型 $q=[x,z,\theta]^T$。运动方程 $M\ddot q = \tau_g + J^T\lambda$，其中 $M=\mathrm{diag}(m,m,\frac23 mr^2)$，$\tau_g=[0,-g,0]^T$，接触雅可比 $J=\begin{bmatrix}0&1&0\\1&0&r\end{bmatrix}$（**行 1 = 法向 $z$，行 2 = 切向 $x$ 含转动耦合 $r$**——接触点切向速度 $= \dot x + r\dot\theta$）。给定恢复系数 $e$、与水平地面碰撞，**碰后速度**（PDF 给出）：

$$\dot q^+ = \begin{bmatrix} \tfrac35 & 0 & -\tfrac{2}{5}r \\ 0 & -e & 0 \\ -\tfrac{3}{5r} & 0 & \tfrac25 \end{bmatrix}\dot q^-$$

**人话**：第二行 $[0,-e,0]$ = **法向 $z$ 按 $-e$ 反弹**；第一、三行 = **无限摩擦让"切向接触速度 $\dot x+r\dot\theta$ 碰后=0"**，于是平动和转动被耦合着改。**这张矩阵就是 (23) 代入球参数的结果**——**下面代码 7 亲手验证**。

### 🧪 代码 7：用公式 (23) 复现 Example B.4 的 3×3 矩阵（可跑，本章代码亮点）

> **PDF 没给代码**，这段用 numpy 把 (23) 代入球的 $M,J$，**算出来的矩阵与 PDF 那张一字不差**——**这是"脉冲碰撞公式真的对"的最硬铁证**。

```python
import numpy as np
m, r, e = 1.0, 1.0, 0.6                       # 先取 r=1 对照 PDF 数值, e 任意
M = np.diag([m, m, 2/3*m*r**2])
J = np.array([[0,1,0],[1,0,r]])              # 行1法向z, 行2切向(含转动耦合 r)
Minv = np.linalg.inv(M)
# 公式 (23): v+ = [I - Minv J^T diag(1+e,1,1) (J Minv J^T)^-1 J] v-
D = np.diag([1+e, 1, 1])                     # 法向(1+e), 切向1(sticking->碰后切向速度0)
T = Minv @ J.T @ D @ np.linalg.inv(J @ Minv @ J.T) @ J
plus = np.eye(3) - T
print("公式(23)算出的碰后矩阵 (r=1):\n", np.round(plus,3))
print("PDF 给的矩阵 (r=1, e=%.1f):\n"%e,
      np.round(np.array([[3/5,0,-2/5*r],[0,-e,0],[-3/(5*r),0,2/5]]),3))
print("两者一致?", np.allclose(plus, [[3/5,0,-2/5*r],[0,-e,0],[-3/(5*r),0,2/5]]))
# 验证物理: 碰后切向接触速度 = 0 (sticking)
v_minus = np.array([1.0, -2.0, 0.5])
v_plus = plus @ v_minus
print("碰前切向接触速度 xdot+r*thetadot =", round(v_minus[0]+r*v_minus[2],3))
print("碰后切向接触速度 xdot+r*thetadot =", round(v_plus[0]+r*v_plus[2],3), "(应=0, sticking)")
print("碰后法向 zdot =", round(v_plus[1],3), " 应 = -e*zdot- =", round(-e*v_minus[1],3))
```

**你会看到**：① 算出的矩阵 **= PDF 那张**（`allclose=True`）；② **碰后切向接触速度=0**（sticking 生效），**法向 $=-e$ 倍**（恢复系数生效）——**亲手验证 (23) 与 Example B.4 完全自洽**。**把 `r` 改成 2 再跑**，**对比 PDF 含 $r$ 的符号矩阵 $\begin{bmatrix}3/5&0&-2r/5\\0&-e&0\\-3/(5r)&0&2/5\end{bmatrix}$ 仍一致**——**彻底确认公式与 PDF 符号形式吻合**。

### 6.5 综合：单边约束 $\phi\ge0$ 的混合模型 + 守卫

> 把双边约束方程 + 脉冲碰撞方程放一起，就实现了**单边约束 $\phi(q)\ge0$ 的混合模型**。推广 $\phi$ 为**所有刚体对符号距离的向量**，描述所有可能接触。**每时刻某子集激活，当双边约束处理**（$\phi_i=0$）。**混合模型的守卫**：非激活约束变激活（$\phi_i>0\to\phi_i=0$），或激活约束变失活（$\lambda_i>0\to\lambda_i=0$ 且 $\dot\phi_i>0$，即开始分离）。**注意**：碰撞事件**几乎总只在 $e=0$（纯非弹性）时产生新激活约束**，**因为弹性碰撞很少允许持续接触**。**若接触含 Coulomb 摩擦，sticking/sliding 转换可建为额外混合守卫。**

**类比**：**$\phi\ge0$ = "脚不许穿地"这条单边绳**——**脚在空中绳子松（$\phi>0$，无约束力），脚一碰地绳子紧（$\phi=0$，约束力 $\lambda\ge0$ 顶住），脚要抬起绳子又松（$\lambda\to0$ 且 $\dot\phi>0$）**。**这三种"松/紧/将松"的切换 = 混合模型的三个模式 + 两个守卫。**

## 7. 对应 B.3.3：时间步进近似 —— "把碰撞摊进每一步"

### 7.1 互补表述（LCP）

> 接触的离散性暗示需组合优化。**最常见转录 = 线性互补问题（LCP）** [13]，由 [14][15] 引入。LCP 通常写：

$$\text{find } w,z \quad\text{s.t.}\quad w = q + Mz,\ w\ge0,\ z\ge0,\ w^Tz=0$$

> 它直接关联（可能非凸）二次规划的最优性条件；[15] 证明刚体接触 LCP 可用 **Lemke 算法**解。简写 $\text{find } z$ s.t. $0\le(q+Mz)\perp z\ge0$。

**类比（互补 = "要么接触要么分离，不能又接触又分离"，必懂）**：$w\ge0,z\ge0,w^Tz=0$ 读作"**$w$ 和 $z$ 都非负，且对应位置不能同时为正**"。在接触里 $w$="间隙"、$z$="力"：**间隙>0（分离）则力必须=0；力>0（接触）则间隙必须=0**——**"无距离力"**。**这条 $w^Tz=0$ 是非凸的**（解落在坐标轴上，是个"L 形"）。

### 7.2 Example B.5：法向力的时间步进 LCP

> 最爱简单质量被水平力驱动（双积分器），加墙阻止 $q<0$：非穿透 $q\ge0$，由法向力 $f$ 实现，$m\ddot q=u+f$。$f$ 满足 $f\ge0$ 和 $q\cdot f=0$（互补，"无距离力"，非凸）。**满足这些 + $q\ge0$ 足以完全定义 $f$**。离散（**半隐式 Euler**，第一式用 $v[n+1]$，**这选择对推导关键**）：

$$q[n+1]=q[n]+hv[n+1],\quad v[n+1]=v[n]+\tfrac{h}{m}(u[n]+f[n])$$

> 给定 $h,q[n],v[n],u[n]$，同时解 $f[n],q[n+1]$ 的 LCP：$q[n+1]=[q[n]+hv[n]+\frac{h^2}{m}u[n]]+\frac{h^2}{m}f[n]$，$q[n+1]\ge0,f[n]\ge0,q[n+1]\cdot f[n]=0$。

> **关键洞察**：无摩擦时，这 LCP **正是凸 QP 的最优性条件**——**Gauss 原理的离散版**。用 $v'=v[n+1]$、$v^-=v+\frac{h}{m}\tau$（接触脉冲前的下一步速度），写成 $\min_{v'}\frac12(v'-v^-)^TM(v'-v^-)$ s.t. $\frac1h\phi(q')\ge0$。**无摩擦接触 LCP = 这凸 QP（因 $M\succeq0$）的最优性条件**，**接触脉冲 $\lambda$（单位 $N\cdot s$）再次是拉格朗日乘子**。

**类比**：**"为什么谈 LCP 多于 QP？"** 因为**无摩擦时两者等价（QP 凸、好解）**；**但一加 Coulomb 摩擦，QP 就非凸了，而 LCP 框架还能表示**——**所以 LCP 是"更通用的语言"**。

### 7.3 Example B.6：Coulomb 摩擦的 LCP —— slack 变量体操

> 拿砖去掉墙和轮（现与地面摩擦），$m\ddot q=u+f$，$f$ 是摩擦力：**$\dot q=0$ 时在锥内，$\dot q\ne0$ 时在锥边界**（**最大耗散原理** [14]）。法向力幅值总 $mg$，故 $|f|\le\mu mg$。半隐式 Euler 离散。**写摩擦约束为 LCP 需 slack 变量**：把力分正负 $f[n]=f^+-f^-$，引入 $v_{abs}$（速度非零时非零）。LCP：

$$0\le v_{abs}+v[n+1]\perp f^+\ge0,\quad 0\le v_{abs}-v[n+1]\perp f^-\ge0$$
$$0\le \mu mg - f^+ - f^-\perp v_{abs}\ge0,\quad v[n+1]=v[n]+\tfrac{h}{m}(u+f^+-f^-)$$

> 够让头转！但算出来想要的约束都在。如 $v[n+1]>0\Rightarrow f^+=0,v_{abs}=v[n+1],f^-=\mu mg$；$v[n+1]=0\Rightarrow v_{abs}=0,f^+-f^-\le\mu mg$ 且合力使 $v[n+1]=0$。

**人话（三行互补在干嘛，必懂）**：
- 第 1 行：$v>0$（向右动）→ $f^+=0$（向右的摩擦分量=0，因摩擦只拖后腿）。
- 第 2 行：$v<0$（向左动）→ $f^-=0$。
- 第 3 行：$v_{abs}>0$（在动）→ $f^++f^-=\mu mg$（**动摩擦打满**）；$v_{abs}=0$（静止）→ $f^++f^-\le\mu mg$（**静摩擦没打满，按需出力**）。
- **$v_{abs}$ 是个"开关变量"**，**把"动/静"这件非光滑事，编码进互补约束**。

### 7.4 Anitescu 凸表述 + Todorov/MuJoCo 正则化 + SAP

> **[16] Anitescu 凸表述**：**丢掉最大耗散不等式，允许摩擦锥内任何力**：$\min_{v'}\frac12(v'-v^-)^TM(v'-v^-)$ s.t. $\frac1h\phi(q')+\mu d_i v'\ge0,\ \forall i$（$d_i$ 参数化摩擦锥多面体近似，**每个 $d_i$ 集合里也须有 $-d_i$**）。**这是 QP（凸）**。拉格朗日乘子 $\beta_i\ge0$ = $n-\mu d_i$ 方向脉冲幅值。**但小心**：primal 凸、对偶总凸，**目标可半正定**——**[16] 举例 $v'$ 唯一但产生它的脉冲不唯一（想四条腿桌子，力分配不唯一）**。**滑移时这松弛让接触"水滑"出接触**（$\phi(q')\ge h\mu d_i v'$），**小 $h$ 时合理近似**。

> **Todorov 正则化 [17]（MuJoCo 用的）**：稍变凸松弛，$\min_\lambda\frac12\lambda^TJM^{-1}J^T\lambda+\frac1h\lambda^T(Jv^--\dot x_d)$ s.t. $\lambda\in FC(q)$，$\dot x_d=Jv^- - hBJv^- - hK[\phi,0,0]^T$（$B,K$ 临界阻尼增益）。**展开看 ≈ 位置等式约束的对偶 + Baumgarte**。**像 Anitescu，也可能"距离力"**（没表达 $\lambda=0$ 当 $\phi>0$；这里"热着进来"时稳定项想减速你）。**对偶 = 二次目标 + 二阶锥约束（SOCP）**（用摩擦锥完整锥描述 $FC(q)=\{[f_n,f_{t1},f_{t2}]^T:f_n\ge0,\sqrt{f_{t1}^2+f_{t2}^2}\le\mu f_n\}$）。

> **MuJoCo 的更多松弛**：解决目标正不定 → **加小项到对角**（保凸，但可能病态）；**稳定项**是另一松弛；还对惯性矩阵加"**隐式阻尼惯性**"。**这些松弛戏剧性提速**（每凸优化更快 + 允许更大步）。**MuJoCo 专用求解器常比实时快几个数量级**。**但可被滥用**——**常见物理荒谬的 MuJoCo 仿真，尤其不关心物理者改参数优化学习曲线！**

> **SAP 求解器**：Drake 的接触求解器**进一步扩展改进这线工作** [18]（Castro 等 unconstrained convex formulation of compliant contact）。

### 7.5 超越点接触

> **Coming soon**：Box-on-plane、Multi-contact。**单点力不能捕捉扭转摩擦**，某些简单情况表现差（想盒子放桌上）。**结果许多最有效算法限制自己到简化几何**——如**在脚四角放"点接触"（零半径球）**，穿透时正好那四点加力，**给更一致的接触力位置/方向**。**惊人数目模拟器（尤其腿式）这么做**。实践中碰撞检测给"碰撞点对"列表，**接触力模型简单在点对间连弹簧**。**Drake 还有 Hydroelastic 模型 [19]**（压力场模型，快而鲁棒地近似净接触力与力矩）。

**类比（点接触 vs 面接触）**：**点接触 = "脚底只承认 4 个钉尖着地"**——**简单、力方向稳**；**真面接触 = "整个脚掌压地，压力怎么分布？"**——**难算**。**Hydroelastic = "把脚掌和地面都当'会渗水的海绵'，用压力场算净力"**——**Drake 的折中方案**。

### 🧪 代码 8 & 9：时间步进 LCP 手算/枚举验证（B.5 无摩擦 + B.6 Coulomb，可跑）

> **PDF 没给代码**。无摩擦时互补只有"接触/分离"两种情况，Coulomb 时枚举"静/左滑/右滑"，**用枚举法（小系统最直观）验证互补条件**，并画 B.5 的 $q[n+1],f[n]$ 关系。

```python
import numpy as np
import matplotlib.pyplot as plt
# --- 代码8: B.5 无摩擦, 单质量对墙, 半隐式Euler, 枚举互补 ---
m,h = 1.0,0.1
def step_free(q,v,u):                      # 无接触: f=0
    vn = v + h/m*u; return q+h*vn, vn, 0.0
def step_contact(q,v,u):                   # 接触active: q[n+1]=0, 解 f
    vn = v + h/m*u                          # 先不算 f 的速度
    # q[n+1]=q+h*(v+h/m*(u+f))=0 -> f = -m/h*(q/h+v) - u  使 q[n+1]=0
    f = -m/h*(q/h + v) - u
    return 0.0, 0.0, f                      # 接触时 q,v 都=0(墙), f 顶住
# 画 q[n+1] vs f[n] 的互补关系 (m=1,h=0.1,u=0), 扫 v[n]
qs = np.linspace(-0.5,0.5,200); f_plot=[]; qn_plot=[]
for v in qs:
    qfree,vn,f = step_free(0.0,v,0.0)       # 从 q=0 出发看下一步
    if qfree>=0 and f==0: qn_plot.append(qfree); f_plot.append(0)     # 分离支
    # 接触支: 强制 q[n+1]=0
    fc = -m/h*(0.0/h+v)-0.0
    if fc>=0: qn_plot.append(0.0); f_plot.append(fc)                 # 接触支
plt.figure(); plt.scatter(qn_plot,f_plot,s=3); plt.xlabel('q[n+1]'); plt.ylabel('f[n]')
plt.title('B.5 互补: 解落在 q轴(分离,f=0) 或 f轴(接触,q=0) 的 L 形'); plt.grid(alpha=.3); plt.show()

# --- 代码9: B.6 Coulomb, 枚举 静/左滑/右滑, 验证互补 ---
m,h,mu,g = 1.0,0.1,0.5,9.81
def coulomb_step(v,u):
    # 试静止: 需要 |f|<=mu*m*g 使 v[n+1]=0
    f_need = -u - m/h*v                      # 使 v[n+1]=0 的摩擦
    if abs(f_need) <= mu*m*g: return 0.0, f_need, 'stick'
    # 否则滑动: f = -mu*m*g*sign(v[n+1]); 用 v 的符号近似
    s = np.sign(v + h/m*u) or 1.0
    f = -mu*m*g*s; vn = v + h/m*(u+f); return vn, f, 'slip'
for v0,u0 in [(0.0,0.3),(0.0,-0.3),(0.5,0.0),(-0.5,0.0)]:
    vn,f,mode = coulomb_step(v0,u0)
    print(f"v={v0:+.1f} u={u0:+.1f} -> {mode:4s} f={f:+.3f} v_next={vn:+.3f}")
```

**你会看到**：① B.5 的散点**落在"L 形"**（$q$ 轴 + $f$ 轴）——**亲眼见互补约束的非凸几何**；② B.6 枚举出 **stick 时 $|f|\le\mu mg$ 按需出力、slip 时 $|f|=\mu mg$ 打满且反向**——**验证 Coulomb 互补逻辑**。

## 8. 对应 B.4：变分力学 —— "自然是个懒人/优化器"

### 8.1 对应 B.4.1：虚功 —— "平衡 = 怎么微动都不做功"

> 多数人舒服于：体平衡 ⟺ 所有力（含重力）和为零 $\sum_i f_i=0$。但**直接用力有限制**：要（任意）定义坐标系，且可能要算**关节内力**。**更好**：不想力，想**功** $w$（力×距离，标量，坐标系无关）。**即使平衡，也可推理"对构型做无穷小变化"的虚功**；**内力不做功，可完全忽略**，只看构型变量变化导致的虚功。**多体平衡 ⟺ 零虚功**：

$$\delta w = \sum_i \tau_i^T \delta q = 0$$

> $\tau_i$ 是广义力（与 $q$ 同维）。笛卡尔力与广义力用雅可比映射 $\tau_i=J_i^T(q)f_i$。**重力/势能导出的力** $\tau_g=-(\partial U_g/\partial q)^T$。**若所有广义力都能从势能导出**，则平衡 ⟺ $\delta U=0$（由 $\delta U=\frac{\partial U}{\partial q}\delta q$ + 虚功得）。**稳定平衡**还须 $U$ 是**势能最小**（不只驻点）。**这是本节力学与优化的第一个重要连接。**

**类比**：**"平衡 = 球停在碗的某处（$\delta U=0$）；稳定平衡 = 球停在碗底（$U$ 最小）"**——**"稳定 = 能量最小"就是"力学 = 优化"的第一次握手**。

### 8.2 对应 B.4.2：达朗贝尔原理 —— "惯性也是一种力"

> 运动体呢？**达朗贝尔原理**：把动力学化静力学，**只需包含"惯性力"**（粒子 = 质量×加速度）。为对所有 $\delta q$ 平衡，多体系统的惯性力须 $\tau_{inertia}=-M\ddot q - C\dot q$。**但那 $C\dot q$ 哪来？是自然"优化"某标量的结果吗？** 候选 = 动能 $T=\frac12\dot q^T M\dot q$。**取动能的变分 $\delta T$**：迄今只对 $\delta q$ 变，但 $T$ 依赖 $q$ 和 $\dot q$，不能独立变——**解是沿轨迹变**（$q,\dot q$ 关系良定义）。考虑作用 $A(q(t))=\int_{t_1}^{t_0}T(q,\dot q)dt$，对轨迹 $q(t)$ 的变分 $\delta A=\int T(q+\delta q,\dot q+\delta\dot q)dt-\int T(q,\dot q)dt$，$\delta q(t)$ 在 $t_0,t_1$ 为零。**推导几步得**：对"也依赖速度的量"的驻点变分，自然推广是 $\tau_{inertia}=-\left(\frac{\partial T}{\partial q}\right)^T+\left(\frac{d}{dt}\frac{\partial T}{\partial\dot q}\right)^T$——**这正是（负的）熟悉的 $M\ddot q+C\dot q$**。

**人话**：**"惯性力 = 动能对拉格朗日模板的那一坨"**——**达朗贝尔把"加速"也当成一种"力"塞进虚功，于是动力学 = "含惯性力的静力学"**。**而 $C\dot q$ 不是凭空来的，是"动能沿轨迹变分"自动吐出来的。**

### 🧪 代码 10：验证惯性力 = $-\left(\frac{d}{dt}\frac{\partial T}{\partial\dot q}-\frac{\partial T}{\partial q}\right)$（可跑）

> 用 sympy 对双摆动能 $T$ 做变分模板，**验证它 $= M\ddot q + C\dot q$**（即 B.4.2 的结论）。

```python
import sympy as sp
t=sp.symbols('t'); m1,m2,l1,l2=sp.symbols('m1 m2 l1 l2',positive=True)
q1,q2=sp.Function('q1')(t),sp.Function('q2')(t)
dq1,dq2=q1.diff(t),q2.diff(t); s2,c2=sp.sin(q2),sp.cos(q2)
T = sp.Rational(1,2)*(m1+m2)*l1**2*dq1**2 + sp.Rational(1,2)*m2*l2**2*(dq1+dq2)**2 + m2*l1*l2*dq1*(dq1+dq2)*c2
# 惯性力 = d/dt(dT/dqdot) - dT/dq  (应 = M qdd + C qd, 不含重力)
inertia1 = (T.diff(dq1).diff(t) - T.diff(q1)).expand()
inertia2 = (T.diff(dq2).diff(t) - T.diff(q2)).expand()
print("inertia1 含 q1'' 系数:", inertia1.coeff(q1.diff(t,2)))   # = M11
print("inertia1 含 q2'' 系数:", inertia1.coeff(q2.diff(t,2)))   # = M12
print("-> 变分模板吐出的'惯性力' = M qdd + C qd, 与 B.2/B.4.2 一致")
```

**你会看到**：变分模板吐出的 $\ddot q$ 系数**正好是 $M$ 的元素**，剩下的速度项**正好是 $C\dot q$**——**亲手验证 B.4.2"惯性力 = 动能变分 = $M\ddot q+C\dot q$"**。

### 8.3 对应 B.4.3：平稳作用原理 —— "一行公式总结全部物理"

> 上节的积分量 $A$ 常称"**作用**"。更一般 $A=\int_{t_1}^{t_0}L(q,\dot q)dt$，$L$ = 拉格朗日量（单位能量，不唯一，**任何产生正确运动方程的函数都行**）。机械系统熟悉形式 $L=T-U$。**含 $\dot q$ 项不直接依赖 $q$，只贡献期望项，取这 $L$ = "一次生成整个运动方程"**。对我们目的（保守力 + 控制输入 $Bu$ 作广义力），虚功原理给 $\delta A+\int u^T B^T\delta q(t)dt=0$。**变分力学观点**：**这标量量应是研究核心**（而非坐标依赖的力），**已漂亮推广**。**[20]（Susskind）说**：**平稳作用原理是经典物理律最紧凑形式——一行总结一切**：经典力学、电磁、广义相对论、量子力学、化学、直到基本粒子。

**类比**：**"自然让作用 $A$ 取驻值" = "自然是个最优控制器"**——**它选那条让 $\int L\,dt$ 平稳的轨迹**。**这就是"物理 = 优化"的终极握手**，也是后面"最优控制/轨迹优化"之所以"天然契合物理"的深层原因。

### 8.4 对应 B.4.4：哈密顿力学 —— "换一组状态变量"

> 某些情况更喜用**哈密顿表述**：状态变量 $q$ 和 $p$（而非 $\dot q$），$p=\frac{\partial L}{\partial\dot q}^T=M\dot q$（**动量**），动力学 $M\dot q=p$，$\dot p=c_H(q,p)+\tau_g+Bu$，$c_H=\frac12\left(\frac{\partial[\dot q^T M\dot q]}{\partial q}\right)^T$。哈密顿量 $H=p^T\dot q-L$，运动方程 $\dot q=\frac{\partial H}{\partial p}^T,\ \dot p=-\frac{\partial H}{\partial q}^T$。

**类比**：**拉格朗日用 $(q,\dot q)$（位置+速度），哈密顿用 $(q,p)$（位置+动量）**——**同一物理的两套坐标**，**哈密顿那套在"守恒量/几何结构"上更漂亮**（**辛结构**），**也是"物理=优化=几何"三角的第三边**。

## 9. 对应 B.5：练习 B.1 —— 时间步进 LCP 两块砖碰撞（手算 + 代码验证）

> 块 A 宽 1、块 B 宽 1，无摩擦面。单块状态 $\vec x=[q_x,\dot q_x]^T$（位置在几何中心）。初始 $\vec x^{(A)}_0=[-2,3]^T$，$\vec x^{(B)}_0=[0,0]^T$（步 0 时 A 朝静止的 B 运动）。**隐式 Euler，$h=1.0$，$m_1=m_2=1$。**

**先约定接触几何**：块宽 1，**中心距 = 1 时边缘接触**，定义间隙 $\text{gap}=q_B-q_A-1\ge0$。初始 gap $=0-(-2)-1=1>0$（分离）。**完全非弹性碰撞**（hint）= **接触 active 时位置级约束 gap=0 强制**（碰后相对法向速度=0，1D 即"粘住同速"的趋势）。

### 手算 a：步 1、2、3

**步 0→1**：试无接触 $v_A=3,v_B=0\Rightarrow q_A=1,q_B=0\Rightarrow$ gap $=-2<0$ 穿透 → **接触 active**。隐式 + gap=0：设 B 受接触力 $+f$、A 受 $-f$，$v_A=3-f,v_B=f,q_A=-2+(3-f)=1-f,q_B=f$。gap $=f-(1-f)-1=2f-2=0\Rightarrow f=1$。**步 1**：$q_A=0,v_A=2,q_B=1,v_B=1,f=1$。

**步 1→2**：gap $=0$，相对速度 $v_B-v_A=-1<0$（A 还在推）→ **接触 active**。$v_A=2-f,v_B=1+f,q_A=2-f,q_B=2+f$。gap $=(2+f)-(2-f)-1=2f-1=0\Rightarrow f=0.5$。**步 2**：$q_A=1.5,v_A=1.5,q_B=2.5,v_B=1.5,f=0.5$（**已同速**）。

**步 2→3**：gap $=0$，相对速度 $=0$ → 试失活 $f=0$：$v_A=1.5,v_B=1.5,q_A=3,q_B=4$，gap $=4-3-1=0$，$f=0$ 互补 OK（边界）。**步 3**：$q_A=3,v_A=1.5,q_B=4,v_B=1.5,f=0$（**下一步将分离**）。

### 手算 b：为何 $q^{(A)}_{1,x}\ne-1$？

> **$-1$ = "A 的中心刚到接触几何位置"**（中心距=1，B 中心=0，故 A 中心=$-1$）。**但隐式 Euler + 完全非弹性，接触力在整步 $h=1$ 上作用**，把 A 推着和 B 一起走，**A 被带到 0，而非停在 $-1$**。**所以 $q^{(A)}_1=0\ne-1$**——**教学点：隐式格式把碰撞"摊"进整步，A 不会"刚好到接触面就停"。**

### 手算 c：连续物理的碰后速度

> **完全非弹性 + 动量守恒**：碰后共同速度 $=(1\cdot3+1\cdot0)/2=1.5$。**对比时间步进**：步 1 末 $v_A=2,v_B=1$（**$h=1$ 太大，把接触力均匀施加整步而非瞬时脉冲，故速度误差大**）。**位置**：连续物理碰撞发生在 A 中心=$-1$（走了 1，$v=3$ 需时 $1/3$），剩 $2/3$ 以 1.5 共速走 → A 末 $=-1+1=0$，B 末 $=0+1=1$（**位置碰巧与步进同，因 $h=1$ 凑整；速度不同：连续 1.5,1.5 vs 步进 2,1**）。**教学点：时间步进是连续脉冲的近似，$h$ 大时速度偏差明显。**

### 🧪 代码 11：两块砖隐式 Euler + 互补枚举求解器（验证手算，可跑）

```python
import numpy as np
m,h = 1.0,1.0
def step(qA,vA,qB,vB):
    gap = qB-qA-1
    # 试无接触
    vA0,vB0 = vA,vB; qA0,qB0 = qA+h*vA0, qB+h*vB0
    if qB0-qA0-1 >= -1e-9 and (vB0-vA0) >= -1e-9:   # 不穿透且不靠近 -> 分离
        return qA0,vA0,qB0,vB0,0.0,'free'
    # 接触active: 强制 gap_next=0, 解 f (B受+f, A受-f)
    # qA_next=qA+h(vA-f), qB_next=qB+h(vB+f); gap_next=0
    f = ((qB-qA-1) + h*(vB-vA)) / (2*h)            # 由 gap_next=0 解出
    f = max(f,0.0)                                  # 互补: f>=0
    vA_n,vB_n = vA-f, vB+f
    qA_n,qB_n = qA+h*vA_n, qB+h*vB_n
    return qA_n,vA_n,qB_n,vB_n,f,'contact'
qA,vA,qB,vB = -2.,3.,0.,0.
for n in range(3):
    qA,vA,qB,vB,f,mode = step(qA,vA,qB,vB)
    print(f"步{n+1}: qA={qA:.2f} vA={vA:.2f} qB={qB:.2f} vB={vB:.2f} f={f:.2f} [{mode}]")
# 应打印: 步1 qA=0 vA=2 qB=1 vB=1 f=1; 步2 qA=1.5 vA=1.5 qB=2.5 vB=1.5 f=0.5; 步3 qA=3 vA=1.5 qB=4 vB=1.5 f=0
```

**你会看到**：输出**与手算 a 完全一致**——**亲手验证"隐式 Euler + 互补 = 两块砖粘住同速"**，**并印证 b（$q_A=0\ne-1$）和 c（步进速度 2,1 vs 连续 1.5,1.5）**。
