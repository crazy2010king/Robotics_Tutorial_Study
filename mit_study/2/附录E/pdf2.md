## 1. 对应 E.1：怎么引用这本书

### 1.1 PDF 实际给了什么

> **PDF 原文**：感谢你在工作里引用这些笔记。请使用以下引用格式：
>
> Russ Tedrake. *Underactuated Robotics: Algorithms for Walking, Running, Swimming, Flying, and Manipulation* (Course Notes for MIT 6.832). Downloaded on [date] from https://underactuated.csail.mit.edu/
>
> 并附了一段 BibTeX：

```bibtex
@book{underactuated,
  title          = "Underactuated Robotics",
  subtitle       = "Algorithms for Walking, Running, Swimming, Flying, and Manipulation",
  howpublished   = "Course Notes for MIT 6.832",
  author         = "Tedrake, Russ",
  year           = 2023,
  url            = "https://underactuated.csail.mit.edu",
}
```

### 1.2 通俗讲解

**类比（引用 = 给知识"打欠条"，必懂）**：
- 你写论文/报告时用了别人的想法，**引用 = 写一张"欠条"**，注明"这个想法不是我原创的，来自某某"。
- **BibTeX** = **一张"标准化的欠条模板"**——你把作者、标题、年份、网址填进固定格式，LaTeX 等排版工具就能**自动**把它渲染成漂亮的参考文献列表。
- 这段 BibTeX 里每个字段的意思：`@book` = "这是一本书"；`title/subtitle` = 书名/副标题；`howpublished` = "它是怎么发布的"（这里是 MIT 6.832 的课程讲义，不是正式出版社出的书）；`author = "Tedrake, Russ"` = 作者（**姓在前名在后**，这是 BibTeX 的惯例）；`year = 2023`；`url` = 下载网址。
- **`Downloaded on [date]`** 里的 `[date]` 要你**自己填下载日期**——因为这是**在线讲义，会不断更新**（封面写"Last modified 2024-…"），所以注明"你哪天看的版本"很重要，**就像引用一个会改动的网页要注明访问日期**。

**人话**：**这一节就是作者礼貌地告诉你"如果这本书帮了你，请在你的论文里这样引用它"。** 对读者唯一的实用价值 = **抄走那段 BibTeX，填上你的下载日期**。

### 🧪 代码 1：自动生成正确引用（补充实践，呼应 E.1，能跑）

> 这段**不是 PDF 原文**，是帮你"一键生成带今天日期的引用"的小工具，省得手动填 `[date]`。

```python
import datetime
today = datetime.date.today().strftime("%B %d, %Y")   # 如 "July 28, 2026"
plain = (f"Russ Tedrake. Underactuated Robotics: Algorithms for Walking, Running, "
         f"Swimming, Flying, and Manipulation (Course Notes for MIT 6.832). "
         f"Downloaded on {today} from https://underactuated.csail.mit.edu/")
bibtex = """@book{underactuated,
  title          = "Underactuated Robotics",
  subtitle       = "Algorithms for Walking, Running, Swimming, Flying, and Manipulation",
  howpublished   = "Course Notes for MIT 6.832",
  author         = "Tedrake, Russ",
  year           = 2023,
  url            = "https://underactuated.csail.mit.edu",
  note           = "Accessed: %s"
}""" % today
print("【纯文本引用】\n" + plain + "\n")
print("【BibTeX（已自动填访问日期）】\n" + bibtex)
```

**你会看到**：自动填好"今天的日期"的两种引用格式，**直接复制进你的论文即可**。

# 第三部分：增补——把"还不够通俗"的 4 个点再各加一个类比/澄清

### 🧪 代码 2：所有轨迹优化期末项目的"共同起点"（补充实践，能跑）

> E.3 里一半以上的项目都是"轨迹优化"。它们的**最小内核**都是同一个：**把控制序列 $u[0..N-1]$ 当决策变量，用优化器找一条满足动力学、从起点到终点的轨迹。** 这段代码用 scipy 演示这个内核（双积分器，第 7/10 章的"Hello World"）。**跑通它，你就理解了那些项目最底层的逻辑**；想做到项目级别，再去看**第 10 章的 Drake direct collocation notebook** 和 **第 24 章的 GCS**。

```python
import numpy as np
from scipy.optimize import minimize

# 双积分器: x=[位置,速度], x[n+1] = x[n] + h*[v, u]   (第7/10章的Hello World)
N, h = 20, 0.1
x0 = np.array([0.0, 0.0])      # 起点: 位置0,速度0
xg = np.array([1.0, 0.0])      # 终点: 位置1,速度0

def rollout(u):                # 给定控制序列, 前向仿真出状态轨迹
    xs = [x0]
    for k in range(N):
        v = xs[-1][1]
        xs.append(xs[-1] + h*np.array([v, u[k]]))
    return np.array(xs)

def objective(u):              # 目标: 到终点误差 + 控制能量(最小努力)
    xs = rollout(u)
    return 100*np.sum((xs[-1]-xg)**2) + 0.01*np.sum(u**2)

res = minimize(objective, np.zeros(N), method='BFGS')
xs = rollout(res.x)
print("终点状态 =", np.round(xs[-1],3), "(目标 [1,0])")
print("控制序列前5个 =", np.round(res.x[:5],3))
# 画图看轨迹
try:
    import matplotlib.pyplot as plt
    plt.plot(xs[:,0], xs[:,1], 'o-'); plt.xlabel('位置'); plt.ylabel('速度')
    plt.title('最小轨迹优化: 双积分器从[0,0]到[1,0] (E.3项目的共同起点)'); plt.grid(alpha=.3); plt.show()
except Exception as e:
    print("(无绘图环境)", e)
```

**你会看到**：优化器找出一段控制序列，把双积分器**从 $[0,0]$ 平滑开到 $[1,0]$**（位置到 1、速度回 0）。**这就是"轨迹优化"四个字的全部含义**——**E.3 里那些"四旋翼绕障""翻煎饼""后空翻"，本质上都是这个内核，只是动力学更复杂、约束更多、用了 GCS/MIP 等更强的转录方式而已。**
